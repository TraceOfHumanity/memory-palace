## 1. Центральна догма: потік інформації

```
        реплікація (копіювання)
            ↺
          ДНК ──транскрипція──► РНК ──трансляція──► БІЛОК
                                  ▲
                зворотна транскрипція (ретровіруси, напр. ВІЛ)
```
- **ДНК** — довготривале сховище інструкцій (як жорсткий диск/код у репозиторії).
- **РНК** — робочі копії (як скомпільований/кешований фрагмент або повідомлення).
- **Білки** — виконавці: ферменти, каркас, рецептори, транспортери, антитіла.
- Сформулював **Френсіс Крік (1958)**. Винятки: **зворотна транскрипція** (Темін і Балтімор, 1970, Нобель 1975), **пріони** (білки, що «заражають» інші білки; Прузінер, Нобель 1997).

### Аналогія для програміста
| Біологія | Програмування |
|---|---|
| Геном | репозиторій з вихідним кодом |
| Ген | функція/модуль |
| Транскрипція | компіляція в проміжне представлення (mRNA) |
| Трансляція | виконання (рибосома = процесор), результат — білок |
| Промотор / енхансер | точка входу / умови виклику (if-умови) |
| Транскрипційний фактор | прапорець у конфігурації |
| Мутація | помилка в коді (bug), commit без тестів |
| Репарація | автоматичні тести та патчі |
| Епігенетика | config-файл поверх коду: коду не змінює, але вмикає/вимикає |

## 2. Що таке ДНК

### 2.1. Склад
- **ДНК (дезоксирибонуклеїнова кислота)** — полімер з **нуклеотидів**. Нуклеотид = **цукор дезоксирибоза** + **фосфат** + **азотиста основа**.
- Чотири основи:

| Клас | Основи |
|---|---|
| **Пурини** (подвійне кільце) | **A** — аденін, **G** — гуанін |
| **Піримідини** (одинарне кільце) | **C** — цитозин, **T** — тимін |

- Ланцюг: цукор–фосфат «хребет», основи стирчать усередину. Ланцюг має **напрямок**: 5' → 3' (за нумерацією вуглецю цукру).

### 2.2. Подвійна спіраль
- Два ланцюги **антипаралельні** (один 5'→3', інший 3'→5') і сплетені в спіраль.
- **Комплементарність** — правило Чаргаффа (1950): **A ↔ T** (2 водневі зв'язки), **G ↔ C** (3 водневі зв'язки). Тому кількість A = T, G = C.
- GC-пари міцніші → ділянки, багаті на GC, плавляться при вищій температурі (важливо для ПЛР).
- Розміри: діаметр ~**2 нм**, один виток ~**3,4 нм** (≈10,5 пар основ), відстань між парами ~**0,34 нм**.
- Один ланцюг повністю визначає другий: це і є ключ до копіювання й репарації.

### 2.3. Розрахунки (порядки величин)
- Гаплоїдний геном людини: ~**3,2 млрд пар основ** (3,2 Гб). Диплоїдна клітина — **~6,4 Гб**.
- Довжина: `6,4·10⁹ × 0,34 нм` = **~2,2 м** ДНК в кожному ядрі (діаметр ~6 мкм) — «нитка, упакована у футбольний м'яч у масштабі». Для порівняння: 6,4 Гб ≈ 1,6 ГБ даних (кожна основа 2 біти).
- Усі клітини тіла разом (~3·10¹³, більшість з ядрами) містили б ДНК довжиною порядку **10¹¹ км** — кілька сотень відстаней Земля–Сонце (груба оцінка: еритроцити без ядра, не всі клітини диплоїдні).
- Різниця між двома людьми ~**0,1 %** (≈3–5 млн варіантів); з шимпанзе ~1,2–1,5 % (за заміщеннями).
- Кількість генів: ~**20 000** білок-кодувальних. **~1,5 %** геному кодує білки. Решта: інтрони, регуляторні ділянки, транспозони (~45 %), некодуюча РНК.

### 2.4. Упаковка
| Рівень | Структура |
|---|---|
| ДНК | подвійна спіраль 2 нм |
| **Нуклеосома** | 147 пар основ ДНК обмотані навколо **октамера гістонів** (H2A, H2B, H3, H4 × 2) — «намисто» |
| Хроматин | нуклеосоми, зв'язані лінкерною ДНК + гістон H1 |
| **Еухроматин / гетерохроматин** | розпущений (активний) / щільний (неактивний) |
| **Хромосома** | максимально ущільнений хроматин під час поділу |

- Людина: **46 хромосом** = 23 пари (22 пари аутосом + пара статевих XX/XY). По одній від кожного з батьків.
- **Мітохондріальна ДНК:** ~16,5 тис. пар основ, 37 генів, кільцева, **від матері** (див. `../metabolism/`).

## 4. Реплікація ДНК (копіювання перед поділом)

### 4.1. Принцип
**Напівконсервативна:** кожна нова молекула містить **один старий і один новий** ланцюг (Мезельсон–Сталь, 1958). Старий ланцюг — шаблон.

### 4.2. Учасники (еукаріоти)
| Компонент | Роль |
|---|---|
| **Ориджини реплікації** | тисячі точок початку на хромосому (бо ДНК величезна) |
| **Хеліказа** | розплітає спіраль (витрачає АТФ) |
| **Топоізомераза** | знімає скручування (інгібують ліки: іринотекан, етопозид, фторхінолони у бактерій) |
| **SSB-білки** | утримують розведені ланцюги |
| **Праймаза** | ставить короткий РНК-праймер |
| **ДНК-полімерази (δ, ε)** | будують новий ланцюг **лише в напрямку 5'→3**, вимагають праймера |
| **Лігаза** | зшиває фрагменти |
| **Теломераза** | добудовує кінці хромосом |

### 4.3. Провідний і відстаючий ланцюги
Полімераза йде лише 5'→3', а вилка розкривається в один бік. Тому:
- **Провідний** ланцюг синтезується безперервно.
- **Відстаючий** — короткими **фрагментами Оказакі** (у людини ~100–200 нуклеотидів), які потім зшиваються лігазою.

### 4.4. Швидкість і точність
- Полімераза додає **десятки нуклеотидів на секунду** (еукаріоти ~50; бактерії ~1000).
- Увесь геном людини копіюється за **~8 годин** (S-фаза) завдяки тисячам ориджинів одночасно.
- **Точність** — три рівні контролю:

| Етап | Частота помилки |
|---|---|
| Підбір основи полімеразою | ~10⁻⁴–10⁻⁵ |
| + власна коректура (3'→5' екзонуклеаза) | ~10⁻⁷ |
| + репарація невідповідностей (MMR) | **~10⁻⁹–10⁻¹⁰** |

При 6,4·10⁹ основ це все одно **кілька нових мутацій** на поділ. Мутації — джерело різноманіття й хвороб.

### 4.5. Теломери
- **Теломери** — кінці хромосом з повторами TTAGGG (у людини, тисячі повторів). Відстаюча нитка не добудовується до кінця → теломери **вкорочуються при кожному поділі**.
- **Ліміт Хейфліка** (1961): нормальні клітини діляться ~**40–60 разів**, потім старіють.
- **Теломераза** (Блекберн, Грейдер, Шостак; Нобель 2009) добудовує теломери: активна в стовбурових, статевих клітинах і **~85–90 % раків** (звідси безсмертя пухлинних клітин).

## 5. Мутації й репарація

### 5.1. Типи мутацій
| Тип | Опис | Приклад |
|---|---|---|
| **Точкова: міссенс** | заміна основи → інша амінокислота | серпоподібноклітинна анемія: GAG→GTG, Glu→Val у β-глобіні (див. `../blood-gases/`) |
| **Нонсенс** | заміна → стоп-кодон | деякі форми муковісцидозу, м'язової дистрофії |
| **Мовчазна (синонімічна)** | інший кодон, та сама амінокислота | без наслідків |
| **Зсув рамки зчитування (frameshift)** | вставка/делеція не кратна 3 → «з'їзд» усіх наступних кодонів | багато каскадних порушень |
| **Делеція трьох основ** | втрата 1 амінокислоти | муковісцидоз **ΔF508** (втрата фенілаланіну) |
| **Експансія повторів** | збільшення триплетних повторів | хвороба Гентінгтона (CAG), синдром ламкої Х-хромосоми |
| **Хромосомні** | втрата/дублювання великих ділянок, транслокації | Філадельфійська хромосома |
| **Анеуплоїдія** | зайва/відсутня хромосома | трисомія 21 (синдром Дауна) |
| **Варіації кількості копій (CNV)** | дублі генів | |

- **Спонтанні** (помилки реплікації, дезамінування цитозину) і **індуковані**: УФ (утворює **тимінові димери**), рентген, хімічні канцерогени (бензпірен у тютюновому димі), афлатоксин, вільні радикали.
- **Соматичні** (в тілі, не передаються) і **зародкові** (в гаметах, успадковуються).

### 5.2. Репарація
| Система | Що виправляє |
|---|---|
| **Прямий реверс** | деякі алкілювання |
| **Ексцизійна репарація основ (BER)** | окиснені/дезаміновані основи |
| **Ексцизійна репарація нуклеотидів (NER)** | УФ-димери, об'ємні адукти (дефект → **пігментна ксеродерма**: рак шкіри від сонця) |
| **Репарація невідповідностей (MMR)** | помилки реплікації (дефект → **синдром Лінча**: колоректальний рак) |
| **Гомологічна рекомбінація, NHEJ** | подвійні розриви (**BRCA1/2**; дефект → рак грудей/яєчників) |

- Нобелівська премія 2015 (Ліндаль, Моділл, Сансар) — механізми репарації ДНК.
- **PARP** — фермент репарації, використовує **NAD⁺** (вітамін B3!). Інгібітори PARP (олапариб) вбивають пухлини з дефектом BRCA («синтетична летальність»).
- **p53** — «охоронець геному»: при пошкодженні зупиняє цикл, запускає репарацію чи апоптоз.

## 6. Транскрипція: ДНК → РНК

### 6.1. РНК відрізняється
- Цукор **рибоза**, основа **урацил (U)** замість T, зазвичай **одноланцюгова**.
- Типи: **мРНК** (повідомлення), **тРНК** (адаптери, ~76 нуклеотидів), **рРНК** (каркас рибосоми), **мікроРНК, siRNA** (регуляція), **lncRNA** (довгі некодуючі), **snRNA** (сплайсинг).

### 6.2. Процес
1. **Ініціація.** Транскрипційні фактори і **РНК-полімераза II** збираються на **промоторі** (часто з ділянкою TATA на ~25–30 нуклеотидів вище). **Енхансери** (можуть бути за десятки-сотні тисяч основ) підсилюють транскрипцію, «згинаючи» ДНК.
2. **Елонгація.** Полімераза рухається по матричному ланцюгу 3'→5', будує РНК 5'→3' (з комплементарністю, але U замість T). Швидкість ~**1–2 тис. нуклеотидів/хв**.
3. **Термінація.** Сигнал закінчення; РНК відщеплюється.

### 6.3. Дозрівання мРНК (лише еукаріоти, у ядрі)
- **5'-кеп** (7-метилгуанозин) — захист і сигнал для рибосоми.
- **Сплайсинг:** **інтрони** (некодуючі вставки) вирізаються, **екзони** зшиваються. Роблять це **сплайсосоми**. Середній ген людини ~8–10 екзонів.
- **Альтернативний сплайсинг** (~95 % генів з кількома екзонами): з одного гена — **різні білки**. Саме тому 20 тис. генів дають значно більше різних білків.
- **Полі-A-хвіст** (~200 аденінів) — стабільність.
- Далі мРНК виходить крізь ядерні пори у цитоплазму.

## 7. Генетичний код і трансляція

### 7.1. Генетичний код
- Читається **триплетами (кодонами)** по 3 основи: `4³ = 64` кодони.
- **61 кодон** кодує **20 амінокислот** (код **надлишковий**/виродженний: кілька кодонів → одна амінокислота), **3 стоп-кодони** (UAA, UAG, UGA).
- **AUG** — старт і метіонін.
- Код майже **універсальний** для всіх живих істот (у мітохондріях є невеликі відмінності).
- Розшифрували Ніренберг і Маттеї (1961): полі-U → поліфенілаланін (UUU = Phe).

### 7.2. Рибосома і тРНК
- **Рибосома** (еукаріоти 80S = 60S + 40S) — молекулярна машина з РНК і білків; **каталізує пептидний зв'язок** РНК-ферментом (рибозим, див. `../enzymes/`).
- **тРНК** одним кінцем несе амінокислоту, іншим має **антикодон**, комплементарний кодону.
- Три місця рибосоми: **A** (прихід тРНК), **P** (ланцюг), **E** (вихід).

### 7.3. Етапи
1. **Ініціація:** мала субодиниця знаходить кеп і AUG, приєднується Met-тРНК, потім велика субодиниця.
2. **Елонгація:** тРНК приходить у A → пептидний зв'язок → зсув (**транслокація**) → повтор. Швидкість еукаріот ~**5–6 амінокислот/с** (бактерії ~20).
3. **Термінація:** стоп-кодон → фактор вивільнення → білок відходить.

Енергія: кожен пептидний зв'язок коштує ~4 макроергічних зв'язки (АТФ/ГТФ).

### 7.4. Після синтезу
- **Фолдинг:** білок згортається в 3D-форму; **шаперони** допомагають (HSP). Неправильне згортання → хвороби (амілоїдоз, Альцгеймер, Паркінсон, пріонні).
- **Модифікації:** фосфорилювання, глікозилювання, розрізання, приєднання ліпідів. Наприклад, **γ-карбоксилювання** факторів згортання (вітамін K), **гідроксилювання** проліну колагену (вітамін C), **розрізання проінсуліну**.
- **Сигнальний пептид** спрямовує білок на ЕР і мембрану (`Клітина і мембрана.md`).
- **Убіквітин–протеасомна система** (Чехановер, Гершко, Роуз; Нобель 2004): ненависні/зламані білки позначають убіквітином і розрізають протеасомою. Час життя білків — від хвилин до років.

```python
CODON_TABLE = {  # tiny subset of the genetic code (RNA codons)
    "AUG": "Met", "UUU": "Phe", "GGC": "Gly", "GAG": "Glu",
    "GUG": "Val", "UAA": "STOP",
}
COMPLEMENT = {"A": "T", "T": "A", "G": "C", "C": "G"}

def transcribe(coding_strand: str) -> str:
    """mRNA has the same sequence as the coding strand, with U instead of T."""
    return coding_strand.replace("T", "U")

def translate(mrna: str) -> list[str]:
    protein = []
    for i in range(0, len(mrna) - 2, 3):
        aa = CODON_TABLE.get(mrna[i:i + 3], "???")
        if aa == "STOP":
            break
        protein.append(aa)
    return protein

mrna = transcribe("ATGTTTGAGTAA")
print(mrna, translate(mrna))  # AUGUUUGAGUAA ['Met', 'Phe', 'Glu']
# Sickle-cell: GAG -> GUG changes Glu -> Val
print(translate("AUGGUGUAA"))  # ['Met', 'Val']
```

## 8. Регуляція генів

### 8.1. Чому клітини різні при однаковій ДНК
Усі соматичні клітини мають **той самий геном**, але нейрон, гепатоцит і еритроцит використовують різні гени. **Диференціація** = різний набір активних генів. У кожній клітині працює лише частина генів, і саме набір активних генів робить клітину нейроном чи гепатоцитом.

### 8.2. Рівні регуляції
| Рівень | Механізм |
|---|---|
| **Хроматин** | метилування ДНК, модифікації гістонів |
| **Транскрипція** | транскрипційні фактори, енхансери, репресори |
| **РНК** | сплайсинг, стабільність, мікроРНК |
| **Трансляція** | швидкість, репресори |
| **Білок** | модифікації, розпад |

### 8.3. Приклади
- **Лактозний оперон** (Жакоб і Моно): у кишкової палички гени ферментів, що розщеплюють лактозу, увімкнені лише коли є лактоза і немає глюкози (економія ресурсів). Перша модель регуляції генів.
- **Гормони (ядерні рецептори):** стероїди, T3/T4, **вітамін D (кальцитріол)**, **ретиноєва кислота (вітамін A)** зв'язуються з рецепторами, які діють як транскрипційні фактори (див. `../hormones/`, розд. 7). Тому вітаміни A і D прямо **регулюють гени** — розвиток, імунітет, кісткова тканина.
- **Транскрипційні фактори розвитку:** HOX-гени задають план тіла. Мутації → змінені структури.
- **HIF** (кисень) і **p53** (пошкодження) — стресові TF.

### 8.4. Епігенетика
**Епігенетика** — зміни активності генів **без зміни послідовності ДНК**, що можуть передаватись при поділі клітини.
- **Метилування ДНК** (CH₃ на цитозині в ділянках CpG): зазвичай **вимикає** ген. Метильні групи постачає цикл метіоніну → **S-аденозилметіонін (SAM)**, для нього потрібні **B9 (фолат), B12, B6, B2, холін** (див. `../vitamins/`).
- **Модифікації гістонів:** ацетилювання (зазвичай вмикає), метилювання (залежно від позиції).
- **Інактивація Х-хромосоми:** у жінок одна з двох X «вимкнена» (тільця Барра).
- **Імпринтинг:** ген діє залежно від того, від кого з батьків (синдроми Прадера–Віллі, Ангельмана).
- **Некодуюча РНК:** **РНК-інтерференція** (Файр і Мелло; Нобель 2006), мікроРНК (Амброс, Рувкун; Нобель 2024).
- Суперечлива тема: чи спадкуються набуті ознаки? У людини докази обмежені.

### 8.5. Стовбурові клітини й перепрограмування
- **Тотипотентні** (зигота) → **плюрипотентні** (ембріональні) → **мультипотентні** (кровотворні) → **диференційовані**.
- **Яманака (2006):** 4 фактори (Oct4, Sox2, Klf4, c-Myc) перетворюють дорослу клітину на **iPSC**.
- **Гердон (1962):** ядро з дорослої клітини жаби, пересаджене в яйцеклітину, дає цілу істоту → геном не втрачається.

## 9. Клітинний цикл і мітоз

### 9.1. Фази
| Фаза | Що відбувається | Тривалість (культура клітин, ~24 год цикл) |
|---|---|---|
| **G1** | ріст, нормальна робота, збір ресурсів | ~11 год |
| **S** | реплікація ДНК (2n → 4c) | ~8 год |
| **G2** | перевірка, підготовка | ~4 год |
| **M (мітоз + цитокінез)** | поділ | ~1 год |
| **G0** | вихід зі циклу (спокій, диференціація) | нейрони, кардіоміоцити, багато клітин |

(У тілі цикл від 8 год у кишківнику до року в печінці, вічно — у нейронів. Кишковий епітелій оновлюється за 3–5 днів, шкіра ~4 тижні, еритроцити ~120 днів, нейрони майже не оновлюються.)

### 9.2. Мітоз
| Стадія | Події |
|---|---|
| **Профаза** | хромосоми конденсуються (кожна з двох **сестринських хроматид**, з'єднаних **центромерою**), центросоми розходяться, формується веретено |
| **Прометафаза** | ядерна оболонка руйнується, мікротрубочки прикріплюються до **кінетохорів** |
| **Метафаза** | хромосоми вишиковуються на екваторі |
| **Анафаза** | сестринські хроматиди розходяться до полюсів (когезин розрізаний сепаразою) |
| **Телофаза** | нові ядерні оболонки, декондексація |
| **Цитокінез** | актин-міозиновий перетяжок ділить цитоплазму |

Результат: дві генетично ідентичні дочірні клітини (2n, 2c кожна).

### 9.3. Керування циклом
- **Циклін–залежні кінази (CDK)** активуються **циклінами**, концентрація яких коливається, як годинник (Хартвелл, Нерс, Гант; Нобель 2001).
- **Контрольні точки (checkpoints):**
  1. **G1/S** — «чи ДНК ціла, чи достатньо ресурсів?» (p53, Rb).
  2. **G2/M** — «чи ДНК повністю скопійована?»
  3. **Метафазна (spindle checkpoint)** — «усі хромосоми прикріплені до веретена?»
- Помилка тут → анеуплоїдія → рак.

## 10. Мейоз і спадковість

### 10.1. Мейоз
Поділ для утворення **гамет** (сперматозоїди, яйцеклітини): 1 диплоїдна клітина (2n=46) → 4 гаплоїдні (n=23) за **два поділи**.
- **Мейоз I:** гомологічні хромосоми розходяться; в профазі — **кросинговер** (обмін ділянками між гомологами) → унікальні комбінації.
- **Мейоз II:** розходяться сестринські хроматиди (як у мітозі).
- **Різноманіття:** незалежне розходження дає `2²³ = 8 388 608` комбінацій хромосом від однієї людини, плюс кросинговер, плюс 2 батьки → кількість можливих дітей практично необмежена.
- **Нерозходження** хромосом → **анеуплоїдія**: трисомія 21 (синдром Дауна; частота зростає з віком матері: ~1/1500 у 20 років, ~1/100 у 40), синдром Тернера (45,X), Клайнфельтера (47,XXY).
- Оогенез: клітини зупиняються на мейозі I ще до народження; завершують — під час овуляції (яйцеклітини десятиліттями чекають завершення поділу — одна з причин вікових ризиків).

### 10.2. Основи спадковості (Мендель)
- **Ген** має варіанти — **алелі**. **Генотип** — набір алелей; **фенотип** — прояв.
- **Домінантний** алель проявляється навіть в одній копії; **рецесивний** — лише коли обидві копії.
- Типи успадкування хвороб:

| Тип | Приклад | Особливості |
|---|---|---|
| **Аутосомно-домінантний** | хвороба Гентінгтона, сімейна гіперхолестеринемія, синдром Марфана | 50 % ризик дитині |
| **Аутосомно-рецесивний** | муковісцидоз, ФКУ, серпоподібноклітинна анемія, Тея–Сакса | обидва батьки — носії (по 1/4 хвора, 1/2 носій) |
| **X-зчеплений рецесивний** | гемофілія A, м'язова дистрофія Дюшенна, дефіцит G6PD, дальтонізм | частіше хворіють чоловіки |
| **X-зчеплений домінантний** | деякі рідкісні | |
| **Мітохондріальний** | хвороба Лебера, MELAS | передається від матері |
| **Мультифакторний** | діабет 2 типу, гіпертензія, більшість ознак | гени + середовище |

- **Пенетрантність, експресивність:** не кожен носій мутації хворіє.
- **GWAS** шукають багато варіантів з малим ефектом; **поліморфізм** (напр. MTHFR C677T — див. `../vitamins/Вітамін B9.md`) — поширена варіація, не обов'язково хвороба.

## 11. Рак як хвороба гену і циклу

- Рак виникає із накопичення **мутацій** у клітині, що дає перевагу в рості.
- Дві групи генів:

| Група | Роль | Мутація | Приклади |
|---|---|---|---|
| **Онкогени** | «газ» (стимулюють поділ) | набуття активності (достатньо 1 алеля) | RAS, MYC, HER2, BCR-ABL |
| **Супресори пухлин** | «гальма» (зупиняють цикл, репарація, апоптоз) | втрата функції (обидва алелі, «дві мутації» Кнудсона, 1971) | **TP53**, RB1, BRCA1/2, APC |

- **Ознаки раку** (Ханахан і Вайнберг, 2000/2011): автономія ростових сигналів, ігнорування стоп-сигналів, ухилення від апоптозу, безмежна реплікація (теломераза), ангіогенез, інвазія й метастази, перепрограмування метаболізму (ефект Варбурга), ухилення від імунітету.
- Чинники ризику: вік (накопичення мутацій), тютюн, УФ, ВПЛ (рак шийки матки), гепатит B/C, надмірна вага, спадкові мутації.
- **Цільова терапія:** **іматиніб** блокує тирозинкіназу BCR-ABL при хронічному мієлоїдному лейкозі (**Філадельфійська хромосома**, транслокація 9;22, відкрита 1960 — перша цитогенетична ознака раку) — рак, що з смертельного став керованим. **Імунотерапія** (інгібітори контрольних точок; Еллісон, Хонджо; Нобель 2018).
- За життя в тілі відбувається порядку 10¹⁶ клітинних поділів, але рак виникає не при кожному: його стримує багаторівневий захист (репарація, p53, апоптоз, імунітет).

## 14. Цікаві факти

- Щосекунди в тілі відбувається **кілька мільйонів** клітинних поділів (кров, кишківник, шкіра).
- **99,9 %** ДНК двох людей збігається.
- Розмір геному не корелює зі складністю: у лілії *Paris japonica* геном близько 150 Гб, майже в 50 разів більший за людський.
- Найбільший відомий геном — у деяких рослин і амфібій (у ~50× більший за людський), тобто розмір геному не корелює зі складністю.
- «Фотографія 51» Розалінд Франклін — рентгенограма, що стала ключем до структури ДНК; її внесок довго недооцінювали. Франклін померла 1958 року; Нобелівську премію 1962 року отримали Вотсон, Крік і Вілкінс.
- **Близнюки-монозиготи** мають однакову ДНК, але з віком їхні епігенетичні профілі розходяться.
- Вірусні фрагменти (ендогенні ретровіруси) складають **~8 %** людського геному; ген **синцитину** з вірусу потрібний для формування плаценти.

## 15. Типові помилки в розумінні

1. «Один ген — одна ознака». Більшість ознак поліфакторні; один ген → багато білків (сплайсинг).
2. «Мутація завжди шкідлива». Більшість нейтральні; деякі корисні (стійкість до малярії, лактазна персистенція).
3. «ДНК — це гени». Лише ~1,5 % кодує білки.
4. «Клітини різні, бо мають різну ДНК». Однакова ДНК, різна експресія.
5. «Репарація ідеальна». Помилки лишаються: так виникають мутації й рак.
6. «Епігенетика переписує ДНК». Ні, вона змінює активність, не послідовність.
7. «Домінантний = частіший/кращий». Домінантність — про прояв, не про поширеність.
8. «Генетичний тест дає діагноз». Показує ризик/варіант; інтерпретація потребує лікаря.
9. «Мітоз і мейоз — те саме». Мітоз → 2 ідентичні диплоїдні клітини; мейоз → 4 різні гаплоїдні.

## 16. Шпаргалка

- **Центральна догма:** ДНК → (транскрипція) → РНК → (трансляція) → білок; реплікація ДНК→ДНК; винятки: зворотна транскрипція, пріони.
- **ДНК:** нуклеотид = дезоксирибоза + фосфат + основа (A, T, G, C); A=T (2 H-зв'язки), G≡C (3); антипаралельна подвійна спіраль 2 нм; 0,34 нм/пара.
- **Геном:** 3,2 Гб (гаплоїдний), ~20 тис. генів, 1,5 % кодує; ~2 м ДНК в клітині; 46 хромосом; нуклеосома — 147 п.н. на 8 гістонів.
- **Реплікація:** напівконсервативна; хеліказа, праймаза, полімераза (лише 5'→3'), фрагменти Оказакі, лігаза; точність 10⁻⁹–10⁻¹⁰; теломери вкорочуються (ліміт Хейфліка ~50), теломераза в раках.
- **Мутації:** міссенс (серпоподібна анемія, Glu→Val), нонсенс, зсув рамки, ΔF508, експансія повторів, анеуплоїдія.
- **Репарація:** BER, NER (ксеродерма), MMR (Лінч), HR/NHEJ (BRCA); p53; PARP (NAD⁺).
- **Транскрипція:** промотор, РНК-пол II; кеп, сплайсинг (інтрони геть), полі-A; альтернативний сплайсинг.
- **Код:** 64 кодони, 61 → 20 амінокислот, 3 стоп; AUG = старт/Met; тРНК-антикодон; рибозим-рибосома; ~5 амінокислот/с.
- **Регуляція:** TF, енхансери, епігенетика (метилування CpG — вимикає; ацетилювання гістонів — вмикає; SAM потребує B9/B12/B6), мікроРНК, X-інактивація.
- **Цикл:** G1 → S → G2 → M; CDK/цикліни; контрольні точки G1/S, G2/M, веретено; G0.
- **Мітоз:** про-, прометафаза, мета-, ана-, телофаза, цитокінез → 2 ідентичні клітини. **Мейоз:** 2 поділи, кросинговер, 4 гаплоїдні; 2²³ ≈ 8,4 млн комбінацій.
- **Спадковість:** АД, АР, X-зчеплений, мітохондріальний, мультифакторний.
- **Рак:** онкогени (газ) + супресори (гальма, TP53, BRCA); ознаки Ханахана–Вайнберга; іматиніб/BCR-ABL.
- **Вітаміни:** B9, B12, B6 — ДНК і метилування; B3 — репарація; D, A — ядерні рецептори.
- **Історія:** Мендель 1865 → Евері 1944 → Вотсон/Крік 1953 → Мезельсон–Сталь 1958 → код 1961–66 → Сенгер 1977 → ПЛР 1985 → Геном 2003 → CRISPR 2012 → мРНК-вакцини 2020.
