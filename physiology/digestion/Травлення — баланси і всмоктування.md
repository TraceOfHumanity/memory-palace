# Травлення: баланси, всмоктування та мікробіом

> Незрозумілі слова — у словнику `../Терміни.md` (розділ 31). Освітній конспект, не медична порада. Числа й дати наведені зі знань автора, без перевірки за першоджерелами.
>
> **Що тут і чого тут немає.** Будова та органна фізіологія травлення вже докладно описані в `anatomy/organs/digestive/` (шлунок, тонка й товста кишка, печінка, підшлункова, регуляція травлення, мікробіом, хвороби). Тут — **наскрізна картина**: рідинний і енергетичний баланс усього тракту, шляхи всмоктування кожного нутрієнта, регуляція всмоктування мікроелементів і вітамінів, розрахунки калорій і часу, мікробіом як «орган». Пов'язано: `../enzymes/` (травні ферменти), `../cell/` (транспорт через епітелій — SGLT, GLUT, ENaC), `../metabolism/` (що відбувається з поживними речовинами далі), `../hormones/` (кишкові гормони), `../vitamins/` (всмоктування кожного вітаміну).

## 1. Навіщо травлення і що воно робить

- **Травлення** — розщеплення їжі до молекул, які можуть пройти крізь стінку кишки. **Всмоктування** — перенесення цих молекул у кров і лімфу. Решта — відходи.
- Чому недостатньо їсти «сирі» молекули? Крохмаль, білки, жири — **полімери**, занадто великі для транспортерів (`../cell/`). Тому їх треба розрізати **гідролазами** (`../enzymes/`, клас 3): амілази, протеази, ліпази — реакції гідролізу (з додаванням води).
- Тракт — це, по суті, **зовнішня трубка**: його просвіт, строго кажучи, **поза тілом**. Тому слизова одночасно **всмоктує** потрібне і **захищає** від мікробів і токсинів (бар'єр, імунітет: за поширеними оцінками, близько 70 % імунних клітин організму пов'язані з кишківником — GALT).

### Шість процесів
1. **Надходження** (ковтання). 2. **Подрібнення й перемішування** (жування, моторика). 3. **Секреція** (травні соки). 4. **Гідроліз** (ферменти). 5. **Всмоктування**. 6. **Видалення** (дефекація).

## 2. Рідинний баланс: дев'ять літрів на добу

### 2.1. Надходження в просвіт
| Джерело | Об'єм (л/добу) |
|---|---|
| Випите й з їжі | ~2,0 |
| Слина | ~1,0–1,5 |
| Шлунковий сік | ~1,5–2,5 |
| Жовч | ~0,5–1,0 |
| Сік підшлункової | ~1,0–1,5 |
| Кишковий сік | ~1,0–1,5 |
| **Разом у просвіті** | **~8–9 л** |

### 2.2. Куди все діється
| Відділ | Всмоктує |
|---|---|
| Тонка кишка | **~6,5–7,5 л** |
| Товста кишка | **~1,0–1,5 л** (резерв до 4–5 л) |
| З калом виходить | **~0,1–0,15 л** |

Висновок: 98–99 % води, що надходить у тракт, **повертається**. Більша частина цієї води — власні секрети організму, тому різке порушення (діарея, холера) може за години вивести **десяток літрів**: смертельне зневоднення.

### 2.3. Як вода слідує за розчиненими речовинами
Вода всмоктується **пасивно** (осмос, `../cell/`) слідом за активним переносом **Na⁺** та поживних речовин:
- Na⁺ + глюкоза (SGLT1) → осмотичний градієнт → вода.
- У товстій кишці Na⁺ всмоктується через ENaC (альдостерон).
- Це основа **оральної регідратації**: суміш солі й глюкози лікує діарею, навіть холеру (`../cell/`).

### 2.4. Діарея за механізмом
| Тип | Механізм | Приклад |
|---|---|---|
| **Осмотична** | нерозчинені осмоліти утримують воду; припиняється при голодуванні | лактазна недостатність, сорбітол, магнієві проносні |
| **Секреторна** | секреція Cl⁻ і води; триває і натще | холера, ентеротоксичні бактерії, VIP-ома |
| **Запальна** | ураження слизової, ексудат | коліт, інфекції, хвороба Крона |
| **Порушення моторики** | швидкий транзит | синдром подразненого кишківника, тиреотоксикоз |
| **Мальабсорбція (стеаторея)** | непереварений жир | панкреатична недостатність, целіакія |

## 3. Кислотність, ферменти та їх «режими»

| Середовище | pH | Чому |
|---|---|---|
| Слина | 6,8–7,0 | амілаза слини працює при нейтральному pH |
| Шлунок (натще) | 1,5–2 | HCl активує пепсиноген, денатурує білки, вбиває мікроби |
| Шлунок (після їжі) | 3–5 | їжа буферує кислоту |
| Дванадцятипала кишка | 6–7 | кислий хімус нейтралізують бікарбонатом підшлункової (до 140 ммоль/л) і жовчі |
| Тонка кишка | 6–7,5 | оптимум ферментів підшлункової (7,5–8,5) |
| Товста кишка | 5,5–7 | бактеріальна ферментація знижує pH |

- Ферменти мають **вузький оптимум pH** (`../enzymes/`, розд. 6): пепсин (1,5–2) недієздатний у кишці — тому так важлива нейтралізація. Якщо кислоти надлишок (синдром Золлінгера–Еллісона), ферменти кишки інактивуються → стеаторея.
- **Інгібітори протонної помпи** (омепразол, `../cell/`) та антациди знижують кислотність: менше пошкодження слизової, але **гірше всмоктування B12, заліза, кальцію, магнію** (їм потрібна кислота), вищий ризик кишкових інфекцій.

## 4. Час і швидкість

| Відрізок | Типовий час |
|---|---|
| Ротоглотка | ~1 с |
| Стравохід | ~8–10 с |
| Шлунок (змішана їжа) | 2–4 год |
| Тонка кишка | 3–5 год (2–6) |
| Товста кишка | 20–70 год |
| **Весь шлях** | **24–72 год** |

### Евакуація зі шлунка
- Рідини залишають шлунок з **t½ ≈ 10–20 хв**.
- Тверда їжа: спершу **латентна фаза 20–60 хв** (подрібнення до частинок <2 мм), потім t½ ≈ 1–2 год.
- Швидкість евакуації: **~2–4 ккал/хв** — шлунок навмисно «дозує» калорії в кишку, регулюючи рефлексами (CCK, GLP-1, кислота, осмолярність) — «гальмо».
- Жири й білки уповільнюють, холодна й гіпертонічна їжа теж.
- Наслідок: жирна їжа довше лежить у шлунку, але насичує довше.

### Мігруючий моторний комплекс (ММК)
- Натще кожні **~90–120 хв** по кишці проходить хвиля «прибирання» (мотилін, ентеральна нервова система). Зникає після їжі. Ліквідує залишки та бактерії; при його порушенні — **надлишковий ріст бактерій у тонкій кишці (SIBO)**.

## 5. Тонка кишка: інженерія всмоктування

### 5.1. Площа поверхні
| Рівень | Збільшення поверхні |
|---|---|
| Колові складки (Керкрінга) | ×3 |
| Ворсинки (0,5–1 мм) | ×10 |
| Мікроворсинки щіточної облямівки (~1 мкм) | ×20 |
| **Разом** | **~×600** |

Реальна площа — порядку **30–40 м²** (теніс-корт, 250 м², який часто цитують, — перебільшення, що виникло з вимірювань мертвої кишки).

### 5.2. Ворсинка
- Усередині: капілярна сітка (→ ворітна вена), **лімфатична судина (лактеаль)** (→ грудна протока), гладкі м'язи.
- **Протиточний обмін** у ворсинці створює високу концентрацію O₂ біля основи, але нижчу на верхівці → верхівки першими страждають від ішемії.
- Епітелій оновлюється за **3–5 діб**: клітини народжуються в криптах і мігрують на верхівку — тому слизова швидко реагує на хіміотерапію (нудота, діарея) та швидко відновлюється.

### 5.3. Три шляхи через епітелій
1. **Трансцелюлярний** — крізь клітину (транспортери на апікальній і базолатеральній мембранах). Основний.
2. **Парацелюлярний** — між клітинами крізь щільні з'єднання (вода, Ca²⁺, невеликі іони).
3. **Ендоцитоз/мембранні білки** — великі молекули (антитіла у новонароджених, дрібні пептиди).

Принцип поляризації: **апікальна мембрана** (до просвіту) має одні транспортери, **базолатеральна** — інші, а **Na⁺/K⁺-АТФаза** на базолатеральній створює градієнт, який живить усе (`../cell/`).

## 6. Нутрієнти: шлях кожного

### 6.1. Вуглеводи
- Крохмаль → **α-амілаза** (слина, підшлункова) → мальтоза, декстрини → ферменти **щіточної облямівки** (мальтаза, ізомальтаза, **сахараза**, **лактаза**) → моносахариди.
- Всмоктування: **глюкоза й галактоза** — **SGLT1** (Na⁺-залежний, активно); **фруктоза** — **GLUT5** (пасивно); вихід у кров — **GLUT2**.
- Швидкість: глюкоза з напою — майже вся за ~30–60 хв; крохмаль, клітковина — повільніше.
- **Глікемічний індекс (ГІ)** — наскільки швидко їжа піднімає глюкозу порівняно з чистою глюкозою (100). Білий хліб ~75, рис ~70, яблуко ~35. Клітковина, жир, білок і кислота знижують пік. Практично важливіше **глікемічне навантаження** (GI × кількість вуглеводів).
- **Лактоза:** лактаза знижується після дитинства у більшості людей світу (`../enzymes/`, розд. 12). Непереносимість лактози — діарея й гази через осмотичну дію та ферментацію. Діагностика: водневий дихальний тест.
- **Клітковина** не гідролізується ферментами людини, але **ферментується** бактеріями (розд. 9).
- Виключення: **целіакія** — не про вуглеводи, а про білок глютену (розд. 11).

### 6.2. Білки
- Шлунок: **пепсин** (з пепсиногену, HCl) → поліпептиди.
- Підшлункова: **трипсин, хімотрипсин, еластаза, карбоксипептидази** (з зимогенів, активатор — ентеропептидаза).
- Щіточна облямівка: **аміно- й дипептидази**.
- Всмоктування: вільні амінокислоти (Na⁺-залежні переносники) та **ди-/трипептиди (PepT1, H⁺-залежний)** — вони всмоктуються **швидше** за вільні амінокислоти, цю властивість використовують у «гідролізатах».
- **Засвоюваність** білка: тваринний ~90–97 %, рослинний ~75–90 % (залежить від антипоживних речовин, обробки). Для оцінки використовують показники PDCAAS/DIAAS.
- За добу в кишку надходить ~**70 г білка з їжі + 50–70 г власного** (ферменти, злущений епітелій); майже все всмоктується.

### 6.3. Жири
- **Проблема:** жир не розчиняється у воді.
- Етапи:
  1. **Емульгування:** жовчні кислоти (амфіфільні) розбивають краплі на дрібні (збільшують площу ліпази).
  2. **Гідроліз:** **панкреатична ліпаза** + **коліпаза** → 2 жирні кислоти + 2-моноацилгліцерол.
  3. **Міцели:** жовчні кислоти утворюють міцели (діаметр 3–10 нм), які несуть продукти до щіточної облямівки.
  4. **Всмоктування** дифузією (і білками CD36, FATP4).
  5. **Ресинтез** тригліцеридів у ЕР ентероцита → **хіломікрони** (з апопротеїном B-48).
  6. Хіломікрони виходять екзоцитозом у **лімфу** (лактеалі → грудна протока → ліва підключична вена). **Обходять печінку при першому проходженні.**
- **Середньоланцюгові жирні кислоти (C6–C12):** розчинніші, всмоктуються безпосередньо в ворітну вену без міцел і хіломікронів (використовують при мальабсорбції).
- **Стеаторея:** жир у калі >7 г/добу при дієті ~100 г жиру; світлий, жирний, смердючий, плаває.
- **Фармакологія:** **орлістат** блокує ліпазу (до 30 % жиру не засвоюється) → знижується й всмоктування жиророзчинних вітамінів A, D, E, K.

### 6.4. Жовчні кислоти: ентерогепатична циркуляція
- Печінка синтезує жовчні кислоти з **холестерину** (первинні: холева, хенодезоксихолева; кон'югуються з глікоколом/таурином).
- **Пул** жовчних кислот у тілі лише **~2–4 г**, але проходить цикл «печінка → кишка → печінка» **6–10 разів на добу**: тобто виділяється ~**12–36 г/добу**.
- У клубовій кишці **~95 %** реабсорбується (транспортер ASBT, вторинний активний, `../cell/`), назад до печінки ворітною веною.
- З калом втрачається **~0,3–0,6 г/добу** (5 %); стільки ж печінка синтезує заново. Це **основний шлях виведення холестерину** з організму.
- **Ліки:** смоли (холестирамін) зв'язують жовчні кислоти в кишці → печінка бере більше холестерину з крові для синтезу → ЛПНЩ знижується.
- Порушення: резекція клубової кишки, хвороба Крона → втрата жовчних кислот → діарея, стеаторея, дефіцит жиророзчинних вітамінів.
- **Холестерин:** надходить ~300–500 мг/добу з їжі, всмоктується ~50 % (білок NPC1L1; блокує **езетиміб**); власний синтез ~800–1000 мг/добу (ГМГ-КоА-редуктаза, статини). Тому дієта дає лише невелику частку.

### 6.5. Нуклеїнові кислоти
Нуклеази підшлункової → нуклеотиди → нуклеозиди → основи; пурини перетворюються на сечову кислоту (подагра).

## 7. Мінерали та вітаміни: «двері» з охоронцями

### 7.1. Залізо
- Надходження ~10–20 мг/добу; всмоктується лише **1–2 мг (10 %)**. Втрати теж ~1–2 мг/добу (злущення клітин, кров); **регульованого виведення немає**, тому організм контролює **всмоктування**.
- **Гемове залізо** (м'ясо, 10–15 % загального заліза їжі) — всмоктується **15–35 %**, мало залежить від складу їжі. **Негемове** (рослини, добавки) — **2–20 %**.
- Механізм негемового: Fe³⁺ → Fe²⁺ (редуктаза DcytB, **вітамін C** допомагає) → переносник **DMT1** → всередині клітини або в **феритин** → вихід через **феропортин** → трансферин.
- **Гепсидин** (гормон печінки) — головний регулятор: коли заліза багато (або запалення), гепсидин **блокує феропортин** → залізо залишається в ентероциті й виводиться зі злущенням. Мало заліза → гепсидин падає.
- **Посилюють:** вітамін C, м'ясо («м'ясний фактор»), кислота. **Зменшують:** фітати (злаки, бобові), поліфеноли (чай, кава), кальцій, антациди та ІПП.
- Хвороби: залізодефіцитна анемія (найпоширеніший дефіцит у світі), гемохроматоз (мутація HFE — надмірне всмоктування). Зв'язок — `anatomy/organs/blood-immune/` і `../blood-gases/`.

### 7.2. Кальцій
- Всмоктується ~**25–35 %** (більше при дефіциті, у дітей та вагітних).
- **Активний трансцелюлярний** (дванадцятипала кишка): TRPV6 → кальбіндин → Ca²⁺-АТФаза; **залежить від кальцитріолу** (вітамін D). Без D всмоктується 10–15 %, з D — 30–40 %.
- **Пасивний парацелюлярний** — при високому надходженні.
- Зменшують: щавлева кислота (шпинат), фітати, надлишок жиру (мило), ІПП (карбонат потребує кислоти — цитрат кращий).

### 7.3. Вітамін B12 (кишкова естафета)
1. Їжа: B12 зв'язаний з білком; **кислота й пепсин** вивільняють його.
2. Зв'язується з **гаптокорином** (R-білок слини).
3. У дванадцятипалій кишці протеази підшлункової руйнують гаптокорин → B12 передається **внутрішньому фактору (IF)**, який виробляють **парієтальні клітини** шлунка.
4. Комплекс B12–IF всмоктується в **термінальному відділі клубової кишки** через рецептор **кубілін**.
5. У крові B12 несе **транскобаламін II**.
- Ємність: ~**1,5 мкг на прийом** через IF; великі дози (500–1000 мкг) всмоктуються ~1 % пасивно — достатньо для лікування.
- Дефіцит: **перніціозна анемія** (автоімунна проти IF/парієтальних клітин), атрофічний гастрит, ІПП і метформін (довго), резекція шлунка/клубової, дієта веган, інфекція *D. latum*, хвороба Крона. Запас у печінці 2–5 мг → дефіцит розвивається роками. Деталі — `../vitamins/Вітамін B12.md`.

### 7.4. Інші вітаміни
| Вітамін | Особливість всмоктування |
|---|---|
| **A, D, E, K** (жиророзчинні) | потребують жовчі, міцел; шлях через хіломікрони й лімфу; з жиром у їжі краще; при стеаторесі дефіцит |
| **C** | переносник SVCT1 **насичується**: при 100–200 мг всмоктується ~70–90 %, при >1 г — менше 50 % |
| **B1, B2** | специфічні переносники (тіамін — THTR; насичуються при великих дозах) |
| **B3** | пасивна і активна дифузія, всмоктується добре |
| **B5, B7** | спільний Na⁺-залежний переносник **SMVT** (високі дози B7 можуть конкурувати з B5) |
| **B6** | пасивна дифузія |
| **B9 (фолат)** | у проксимальній кишці; PCFT (кислий pH); поліглутамати спершу розщеплює GCPII |
| **B12** | розд. 7.3 |
| **K2** | частково синтезується мікрофлорою; внесок у потреби дискусійний |

(Докладно для кожного — відповідні файли `../vitamins/`.)

### 7.5. Магній, цинк, мідь, йод
- **Mg²⁺**: ~30–50 % (ІПП знижують). **Zn²⁺**: ~20–40 % (фітати, надлишок заліза знижують; цинк конкурує з міддю → надлишок цинку викликає дефіцит міді). **I⁻**: майже повністю, транспортер NIS (ще у щитоподібній залозі).

## 8. Калорії: що насправді засвоюється

### 8.1. Фактори Атватера
| Нутрієнт | ккал/г (оцінка на етикетці) |
|---|---|
| Вуглеводи | 4 |
| Білки | 4 |
| Жири | 9 |
| Алкоголь | 7 |
| Клітковина | ~2 (залежно від ферментації) |
| Цукрові спирти (еритритол ~0,2; ксиліт ~2,4) | |

Приклад: 50 г вуглеводів, 20 г білка, 15 г жиру → `50·4 + 20·4 + 15·9` = 200 + 80 + 135 = **415 ккал**.

### 8.2. Реально засвоюється менше
- Коефіцієнт засвоєння змішаної дієти ~**90–95 %** (вуглеводи ~97–99 %, жири ~95 %, білки ~92 %).
- **Цілі горіхи** (мигдаль): засвоюється на ~20–30 % менше калорій, ніж пишуть на етикетці, бо частина жиру лишається в клітинах (структура їжі).
- **Приготування та подрібнення** збільшують засвоєння (крохмаль у вареній картоплі; за гіпотезою Річарда Вренгема, готування їжі сприяло еволюційному збільшенню мозку).
- **Переробка:** ультрапереробна їжа легше розщеплюється → більше засвоюється; у відомому дослідженні (Hall 2019) люди на ультрапереробній дієті з'їдали на ~500 ккал більше на день.

### 8.3. Термічний ефект їжі (TEF)
Витрати енергії на перетравлення, всмоктування й обробку:
| Нутрієнт | % від калорій, що йде на обробку |
|---|---|
| Білки | 20–30 % |
| Вуглеводи | 5–10 % |
| Жири | 0–3 % |
| Змішана їжа | ~10 % |

Чистий внесок: 100 ккал білка дають організму ~75 ккал, 100 ккал жиру — ~97 ккал.

### 8.4. Рівняння балансу
`ΔЗапас = Надходження (засвоєні ккал) − Витрати (BMR + TEF + активність)`. 1 кг жирової тканини ≈ 7000–7700 ккал, але «правило 7700» працює лише на короткому проміжку: організм адаптується (метаболізм і поведінка змінюються), див. `../homeostasis/` (лептин, грелін).

## 9. Мікробіом

### 9.1. Масштаб
- В кишківнику живе ~**3,8·10¹³** мікробів (приблизно стільки ж, скільки клітин людини; ~0,2 кг). У товстій кишці ~10¹¹–10¹² на грам вмісту; у шлунку й тонкій кишці — значно менше.
- Домінують *Bacteroidetes* і *Firmicutes*; склад унікальний, формується в перші роки (пологи, годування) і змінюється дієтою, антибіотиками, віком.
- Кількість генів мікробіому — у ~100 разів більша за людський геном («другий геном»).

### 9.2. Що робить
| Функція | Деталі |
|---|---|
| **Ферментація клітковини** | утворює **коротколанцюгові жирні кислоти (КЛЖК): ацетат, пропіонат, бутират**; дають організму ~5–10 % енергії |
| **Бутират** | головне джерело енергії колоноцитів (60–70 %), протизапальний |
| **Вітаміни** | синтез K2 (менахінони) та деяких B (B7, B9, B12 в основному в товстій кишці, де всмоктування обмежене) — внесок у потреби дискусійний |
| **Жовчні кислоти** | перетворюють первинні на вторинні (дезоксихолева) |
| **Розвиток імунітету** | тренування імунної системи, толерантність |
| **Колонізаційна резистентність** | витісняють патогени (*C. difficile*) |
| **Метаболізм ліків** | активація/інактивація (дигоксин, леводопа) |
| **Вісь кишка–мозок** | через блукаючий нерв, імунітет, метаболіти (серотонін на 90 % виробляється в кишці, але не проходить у мозок) |

### 9.3. Гази
Ферментація дає водень, CO₂, метан: людина виділяє **0,5–1,5 л газів на добу** (10–20 разів). Боби, цибуля, фруктани, сорбітол (FODMAP) збільшують. Запах — сульфурові сполуки (<1 % газу).

### 9.4. Втручання
- **Пребіотики** (клітковина, інулін) — живлять корисні бактерії. **Пробіотики** — живі мікроби; докази сильні лише для окремих станів (діарея, асоційована з антибіотиками; штами важливі).
- **Трансплантація фекальної мікробіоти (FMT)** лікує рецидивну *C. difficile*-інфекцію (~80–90 % ефективності); затверджені препарати (2022–2023).
- **Антибіотики** порушують баланс: діарея, ризик *C. difficile*. Приймати «на всяк випадок» не варто.
- Клітковина ~25–30 г/добу рекомендується; більшість людей отримує вдвічі менше.

## 10. Регуляція (стисло — деталі в `anatomy/organs/digestive/Регуляція травлення.md`)

- **Ентеральна нервова система** — «мозок кишки», сотні мільйонів нейронів (меісснерове та ауербахове сплетення): працює автономно, рефлекси без мозку.
- **Вегетативна:** парасимпатична (n. vagus) стимулює, симпатична гальмує.
- **Гормони:**

| Гормон | Звідки | Стимул | Дія |
|---|---|---|---|
| **Гастрин** | G-клітини антруму | білки, розтягнення | кислота в шлунку |
| **CCK (холецистокінін)** | I-клітини дванадцятипалої | жири, амінокислоти | скорочення жовчного міхура, ферменти підшлункової, гальмує евакуацію, ситість |
| **Секретин** | S-клітини | кислота в дванадцятипалій | бікарбонат підшлункової (перший відкритий гормон, 1902) |
| **GIP** | K-клітини | глюкоза, жир | інсулін (інкретин) |
| **GLP-1** | L-клітини | їжа в клубовій | інсулін ↑, глюкагон ↓, ситість, гальмує евакуацію (мішень семаглутиду) |
| **Мотилін** | M-клітини | натще | ММК |
| **Грелін** | шлунок | голод | апетит |
| **PYY** | L-клітини | їжа | ситість |
| **Соматостатин** | D-клітини | кислота | гальмує майже все |

- **Фази:** цефалічна (вигляд, запах → ~30 % секреції кислоти), шлункова (розтягнення, білки), кишкова (гальмування).

## 11. Коли травлення ламається (логіка)

### 11.1. Три рівні порушення
| Рівень | Що не так | Приклади |
|---|---|---|
| **Мальдигестія** (не розщеплено) | немає ферментів/жовчі/кислоти | панкреатична недостатність (панкреатит, муковісцидоз), холестаз |
| **Мальабсорбція слизової** (не всмоктано) | ушкоджена поверхня | целіакія, хвороба Крона, резекція, інфекції (лямбліоз) |
| **Лімфатичні/судинні** | порушення відтоку | лімфангіектазія, ішемія |

### 11.2. Целіакія
- Автоімунна реакція на **глютен** (гліадин у пшениці, жита, ячмені) у людей з **HLA-DQ2/DQ8** (~1 % населення).
- Фермент **тканинна трансглутаміназа (tTG)** модифікує пептиди глютену → Т-клітини → **атрофія ворсинок** → мальабсорбція (залізо, фолат, B12, кальцій, жиророзчинні вітаміни).
- Діагностика: антитіла **IgA анти-tTG** + біопсія; **перед тестом не припиняти глютен**.
- Лікування: довічна безглютенова дієта.

### 11.3. Інші
- **Гастроезофагеальна рефлюксна хвороба (ГЕРХ)** — недостатність нижнього стравохідного сфінктера.
- **Виразка:** *Helicobacter pylori* (Маршалл і Воррен, 1982; Нобель 2005) + НПЗП; лікування — ІПП + антибіотики.
- **Синдром подразненого кишківника (IBS):** функціональний (критерії Rome IV), без структурних змін.
- **Запальні захворювання (ВЗК):** хвороба Крона, виразковий коліт.
- **Хвороби підшлункової, жовчного міхура** — камені (холестеринові ~80 %), панкреатит (алкоголь, камені).
- **Цироз** — порушення метаболізму, портальна гіпертензія (`anatomy/organs/digestive/liver/`).
- **Шкала Бристоля** (стілець типів 1–7): тип 1–2 запор, 3–4 норма, 5–7 діарея. Нормальна частота — від 3 разів на день до 3 разів на тиждень.

### 11.4. Дослідження
Ендоскопія (гастро-, колоноскопія), УЗД, КТ, дихальні тести (водневий; уреазний на *H. pylori*), еластаза калу (підшлункова), кальпротектин калу (запалення), антитіла до tTG.

## 13. Цікаві факти

- Шлунок виробляє соляну кислоту, сильнішу за 0,1 М; слизовий бар'єр (муцин + бікарбонат) і постійне оновлення епітелію (3–5 днів) не дають їй перетравити стінку.
- Середня людина за життя з'їдає порядку **60 тонн** їжі.
- Ентеральна нервова система налічує сотні мільйонів нейронів і може керувати кишкою без участі мозку.
- ~90 % серотоніну людини міститься в кишці (ентерохромафінні клітини), але на настрій впливає опосередковано.
- Бактерія *Oxalobacter formigenes* розщеплює оксалат; її відсутність, ймовірно, пов'язана з більшим ризиком оксалатних каменів — приклад впливу мікробіому на хвороби.
- **Часткове засвоєння горіхів** і **різний глікемічний відгук** на ту саму їжу у різних людей (Zeevi 2015) показують, що універсальних порад «що краще» небагато.

## 14. Типові помилки в розумінні

1. «Травлення починається в шлунку». Починається в роті (амілаза, жування) і навіть раніше (цефалічна фаза).
2. «Майже все всмоктується в шлунку». Лише вода, алкоголь, деякі ліки; основне — **тонка кишка**.
3. «Клітковина не потрібна, бо не засвоюється». Годує мікробіом, дає КЛЖК, регулює транзит.
4. «Кислота завжди шкідлива». Вона потрібна (захист, всмоктування заліза, B12, кальцію).
5. «Всі калорії однакові». За Атватером так, але засвоєння, TEF та насичення різні.
6. «Детокс-дієти очищають кишку». Печінка, нирки й кишка очищають організм постійно.
7. «Мікробіом — це лише пробіотики». Це екосистема, яку формує насамперед дієта.
8. «Чим більше вітаміну, тим більше всмоктається». Переносники **насичуються** (C, B1, B2).
9. «Холестерин у їжі = холестерин у крові». Печінка синтезує більшу частину; дієтичний холестерин впливає помірно.

## 15. Шпаргалка

- **Рідина:** в просвіт ~8–9 л/добу; тонка кишка всмоктує ~7, товста ~1,5, з калом ~0,1 л.
- **pH:** слина 7; шлунок 1,5–2; дванадцятипала 6–7; ферменти підшлункової 7,5–8,5.
- **Час:** шлунок 2–4 год, тонка 3–5 год, товста 20–70 год; вся дорога 1–3 доби. Евакуація ~2–4 ккал/хв; ММК кожні 90–120 хв натще.
- **Поверхня:** складки ×3, ворсинки ×10, мікроворсинки ×20 → ×600, ~30–40 м². Оновлення епітелію 3–5 діб.
- **Вуглеводи:** амілаза → дисахаридази → SGLT1 (глюкоза, галактоза), GLUT5 (фруктоза), GLUT2 (вихід).
- **Білки:** пепсин → трипсин/хімотрипсин → пептидази → AA + PepT1 (ди-/трипептиди).
- **Жири:** жовч → ліпаза + коліпаза → міцели → ентероцит → хіломікрони → лімфа (обходять печінку); MCT — прямо у ворітну вену.
- **Жовчні кислоти:** пул ~3 г, 6–10 циклів/добу, 95 % реабсорбція (ASBT, клубова); основний шлях виведення холестерину; смоли знижують LDL.
- **Залізо:** всмоктується 1–2 мг; гем 15–35 %, негем 2–20 %; DMT1, феропортин, **гепсидин**; вітамін C ↑, фітати/чай/Ca ↓.
- **Кальцій:** 25–35 %; TRPV6, залежить від вітаміну D; **B12:** кислота → R-білок → IF → клубова (кубілін) → TCII.
- **Вітаміни:** A, D, E, K — жовч + хіломікрони; C — насичення; B5/B7 — SMVT; B9 — PCFT, GCPII.
- **Калорії:** 4/4/9/7; реально 90–95 %; TEF: білки 20–30 %, вуглеводи 5–10 %, жири 0–3 %.
- **Мікробіом:** ~3,8·10¹³, КЛЖК (бутират — паливо колоноцитів), K2/B-вітаміни, FMT проти *C. difficile*.
- **Гормони:** гастрин, CCK, секретин, GIP, GLP-1, мотилін, грелін.
- **Хвороби:** целіакія (tTG, HLA-DQ2/8), *H. pylori* (виразка), лактазна недостатність, SIBO, IBS, ВЗК.
- **Історія:** Бомонт 1822 → Павлов (Нобель 1904) → секретин 1902 → *H. pylori* 1982 → мікробіом 2000-ті.
