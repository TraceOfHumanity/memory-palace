## 1. Що спільного і чим відрізняються м'язи

| Тип | Керування | Структура | Роль |
|---|---|---|---|
| **Скелетний** | довільне (моторні нейрони) | посмугований, багатоядерні волокна | рух, поза, тепло |
| **Серцевий** | автономне (вузол + вегетативна) | посмугований, одно-/дво-ядерні клітини, вставні диски, синцитій | насос |
| **Гладкий** | автономне, гормони, місцеві чинники | немає саркомерів; актин-міозин | судини, кишка, матка, бронхи |

Спільне: скорочення = **ковзання актину по міозину** за рахунок АТФ та **Ca²⁺** (Хью Хакслі з Жан Хансон та Ендрю Хакслі з Рольфом Нідергерке, 1954: теорія ковзних ниток). Нагадування про Ca²⁺: у скелетному м'язі Ca²⁺ звільняється з саркоплазматичного ретикулума за рахунок **механічного зв'язку** DHPR-RyR1; у серцевому — за механізмом **кальцієм-індукованого вивільнення кальцію** (CICR, розд. 9).

## 2. Механіка скелетного м'яза

### 2.1. Сила залежить від перерізу, швидкість — від довжини
- **Питома сила** — сила на одиницю фізіологічного поперечного перерізу (PCSA): приблизно **20–40 Н/см²** (≈ 0,2–0,4 МПа), майже однакова в різних м'язах.
- Отже **сила ∝ товщина** (кількість паралельних саркомерів), **швидкість скорочення ∝ довжина** (кількість послідовних саркомерів).
- Приклад: чотириглавий м'яз з PCSA ~ 100 см² може розвивати ~ 3000 Н (≈ 300 кг-сили) ізометрично; м'язи очей — маленькі й надшвидкі.
- Тренування сили збільшує переріз (гіпертрофія), а не питому силу.

### 2.2. Співвідношення «довжина–сила» (Гордон, Хакслі, Джуліан, 1966)
Пасивна й активна сила залежать від довжини саркомера (товсті нитки ~1,6 мкм, тонкі ~1,0 мкм з кожного боку):

| Довжина саркомера (мкм) | Що відбувається | Активна сила |
|---|---|---|
| **< 1,3** | тонкі нитки перекриваються, товсті впираються у Z-диски | падає |
| **1,6–2,0** | кінці тонких ниток перекриваються | зростає |
| **2,0–2,25** | **оптимальне перекриття**, максимум містків | **100 %** |
| **2,25–3,6** | перекриття зменшується | падає лінійно |
| **~3,6** | нитки не перекриваються | 0 |

- Пасивна сила (титин, сполучна тканина) зростає при розтягненні, тому загальна сила зберігається в діапазоні.
- Практика: максимальна сила вправи — у середньому діапазоні руху; в крайніх положеннях сила нижча (напр. присід у глибині, біцепс на повністю зігнутій руці).
- **Активна недостатність:** багатосуглобові м'язи (двоголовий стегна) не можуть створити силу, коли вкорочені до межі.

### 2.3. Співвідношення «сила–швидкість» (Арчібальд Гілл, 1938)
Чим швидше м'яз вкорочується, тим меншу силу він розвиває. Гіперболічне рівняння Гілла:
```
(F + a) · (v + b) = (F₀ + a) · b
```
- **F** — сила, **v** — швидкість вкорочення, **F₀** — максимальна ізометрична сила, **a** і **b** — константи (a має розмірність сили, b — швидкості).
- Звідси швидкість: `v = b · (F₀ − F) / (F + a)`.
- **F = F₀ → v = 0** (ізометричне). **F = 0 → v₀ = b·F₀ / a** (максимальна швидкість).

**Числовий приклад** (нормалізовано F₀ = 1, a = 0,25, b = 0,25 → v₀ = 1):
| Сила F/F₀ | Швидкість v/v₀ | Потужність P = F·v |
|---|---|---|
| 0,0 | 1,000 | 0 |
| 0,2 | 0,444 | 0,089 |
| **0,3** | 0,318 | **0,095 (максимум)** |
| 0,5 | 0,167 | 0,083 |
| 0,8 | 0,048 | 0,038 |
| 1,0 | 0 | 0 |

- **Потужність максимальна при ~30 % F₀ і ~30–35 % від максимальної швидкості**; Pmax ≈ 0,1 · F₀ · v₀ (близько 10 % добутку).
- Саме тому існують **оптимальні навантаження** (штанга ~30 % від 1ПМ для потужності ривка; велосипедисти підбирають передачу).
- Ексцентричне скорочення (м'яз подовжується під навантаженням) розвиває **більшу силу** (1,2–1,5 × F₀), потребує менше АТФ — і спричиняє більше мікропошкоджень (**відстрочений м'язовий біль, DOMS**, 24–72 год).
- Код:
```python
def hill_velocity(force: float, f0: float = 1.0, a: float = 0.25, b: float = 0.25) -> float:
    """Shortening velocity (normalised) for a given load; Hill (1938)."""
    return b * (f0 - force) / (force + a)

best = max((f / 100 * hill_velocity(f / 100), f / 100) for f in range(1, 100))
print(best)   # (0.0955..., 0.31)  -> power peaks near 30 % of F0
```

### 2.4. Типи скорочень
| Тип | Довжина | Приклад |
|---|---|---|
| **Ізометричне** | стала | утримання вантажу |
| **Концентричне** | м'яз вкорочується | підйом штанги |
| **Ексцентричне** | м'яз подовжується під навантаженням | опускання штанги, біг з гори |
| **Ізотонічне/ауксотонічне** | сила стала / змінна | — |

### 2.5. Одиночне скорочення, сумація, тетанус
- Одиночний потенціал дії → **посмикування (twitch)**: латентний період ~ 2 мс, скорочення 10–100 мс (швидкі волокна ~ 20–40 мс; повільні ~ 100 мс).
- Серія імпульсів з частотою вище порога злиття дає **зубчастий**, потім **гладкий тетанус** (сила до ~3–4 разів більша за посмикування). Злиття: ~ 10–20 Гц для повільних, 50–100 Гц для швидких.
- Причина: Ca²⁺ в цитозолі не встигає відкачатися (SERCA) між імпульсами — його рівень накопичується.
- У скелетному м'язі **рефрактерний період короткий** (~ 2–4 мс), тому тетанус можливий — на відміну від серця.

## 3. Керування силою: рухові одиниці

- **Рухова (моторна) одиниця** = α-мотонейрон + усі волокна, які він іннервує (всі волокна одиниці однакового типу).
- **Коефіцієнт іннервації**: ~ **1:10** у м'язах очей (точність), ~ **1:100–1:200** у пальцях, ~ **1:1000–2000** у литковому м'язі (сила).
- Сила регулюється двома способами:
  1. **Набір (рекрутування) одиниць** — додається більше одиниць.
  2. **Частотне кодування** — вища частота імпульсів кожної.
- **Принцип розміру (Генніман, 1957):** одиниці залучаються **від малих до великих**. Малі нейрони легше збуджуються (вищий вхідний опір) → першими залучаються повільні, стійкі до втоми одиниці; великі швидкі — лише при великому зусиллі. Тому легка робота не втомлює швидкі волокна.
- Різні зусилля: ~ 20–30 % максимальної довільної сили — вже включені майже всі одиниці малих м'язів; у великих — рекрутування триває до 80 %.
- **Нервова адаптація** (перші 2–8 тижні тренувань): краще залучення і синхронізація одиниць, менше гальмування (орган Гольджі) — сила росте без росту м'яза.

## 4. Типи волокон: порівняння

| Властивість | **Тип I** (повільне окисне) | **Тип IIa** (швидке окисно-гліколітичне) | **Тип IIx** (швидке гліколітичне) |
|---|---|---|---|
| Швидкість скорочення | повільна | швидка | найшвидша |
| Міозин-АТФазна активність | низька | висока | висока |
| Діаметр | малий | середній | великий |
| Мітохондрії, міоглобін («червоне») | багато | багато/середньо | мало («біле») |
| Капіляри | багато | середньо | мало |
| Основне джерело енергії | жири, окисний обмін | змішане | креатинфосфат, гліколіз |
| Стійкість до втоми | висока | середня | низька |
| Сила (на волокно) | мала | середня | велика |
| Приклад | поза, марафон | середні дистанції | спринт, вибух |

- Розподіл **генетично зумовлений** (спринтери ~ 70–80 % швидких у чотириглавому, марафонці ~ 70–80 % повільних), але тренування змінює частки: витривалість — IIx → IIa; силові — також.
- Втрата IIx і їхня атрофія — головна ознака старіння м'язів.

## 5. Енергетика м'яза та ККД

### 5.1. Три джерела АТФ (повтор і доповнення до `../metabolism/`, розд. 3)
| Система | Паливо | Потужність | Тривалість | Продукт |
|---|---|---|---|---|
| **Фосфагенна** | АТФ + креатинфосфат (КФ) | найвища | ~ 10 с | Креатин, Pi |
| **Гліколітична** | глікоген, глюкоза | висока | 10 с – 2 хв | Лактат, H⁺ |
| **Окисна** | жири, вуглеводи (O₂) | найнижча, але необмежена | хвилини–години | CO₂, H₂O |

- Запас АТФ у м'язі — лише на **1–2 с** роботи, тому АТФ швидко відновлюється з КФ (креатинкіназа).
- Креатин: добавка **креатин моногідрат** (3–5 г/добу) — одна з найкраще вивчених спортивних добавок, підвищує запаси КФ.
- Співвідношення: окисна система виробляє АТФ найповільніше, але з 1 молекули глюкози — ~ 30–32 АТФ проти 2 при гліколізі.
- **Лактатний поріг** — інтенсивність, вище якої лактат накопичується швидше, ніж утилізується (приблизно 50–80 % VO₂max залежно від тренованості). Це не «брудна кислота», яка болить: лактат — паливо для серця, печінки, інших м'язів (цикл Корі).

### 5.2. ККД
- Лише **20–25 %** хімічної енергії перетворюється на механічну роботу; **75–80 % — тепло** (дає тремтіння, що зігріває).
- **Розрахунок:** велосипедист віддає 200 Вт при ККД 22 %.
  - Метаболічна потужність: `200 / 0,22` = **909 Вт**.
  - 1 л O₂ ≈ 20,1 кДж ≈ 335–350 Вт·хв → `909 / 348` = **2,6 л O₂/хв**.
  - Тобто 200 Вт механічних — це споживання ~ 2,6 л O₂/хв (~ 55 % VO₂max типової тренованої людини) і ~ 700 Вт тепла, яке тіло повинно розсіяти (потіння, `../homeostasis/`).
- Метаболічний еквівалент: 1 MET = 3,5 мл O₂/кг/хв (спокій); біг 10 км/год ≈ 10 MET; максимум у елітних біговиків ~ 80–90 мл/кг/хв (≈ 23–25 MET).

### 5.3. Втома
Причини різні залежно від навантаження:
- **Периферична:** накопичення Pi (інгібує містки і викид Ca²⁺), зниження викиду Ca²⁺ ретикулумом, виснаження глікогену (довга робота), K⁺ у Т-трубочках, активні форми кисню. **Рівень H⁺ — менш важливий, ніж вважали.**
- **Центральна:** зниження сигналу від мозку (серотонін, температура, мотивація).
- **Глікоген:** марафонці «б'ються об стіну» на ~ 30-му км, коли глікоген виснажується (запаси ~ 400 г у м'язах + 100 г у печінці = 2000 ккал); відновлення ~ 24–48 год при повноцінній дієті.

### 5.4. Біль, судоми
- **DOMS** — наслідок мікротравм від ексцентричної роботи, не лактату.
- **Судоми** — нічні (ймовірно, нервово-м'язова збудливість); у спеку — електроліти; чинники — нестача Mg²⁺, K⁺, Ca²⁺ (часто не доведено).
- **Rigor mortis** — АТФ зникає, містки не розриваються → трупне задубіння (через 2–6 год, зникає через 1–2 доби).

## 6. Тренування й адаптація

| Тренування | Що змінюється | Терміни |
|---|---|---|
| **Силові** | спочатку нервова адаптація; потім **гіпертрофія** (синтез білка через mTOR; сателітні клітини додають ядра) | нервова 2–8 тижнів; ріст м'яза 8–12+ тижнів |
| **Витривалість** | **мітохондріальний біогенез (PGC-1α)**, капіляри, міоглобін, ферменти окиснення жиру; серце: більший ударний об'єм; VO₂max ↑ 15–20 % (до 40 %) | 4–12 тижнів |
| **Інтервальні (HIIT)** | комбінований ефект за короткий час | 2–6 тижнів |

- Найважливіше для росту: **механічне навантаження** до майже відмови, **достатній білок** (порядку 1,4–2,0 г/кг/добу у тих, хто тренує силу), калорії, **сон** (`../sleep-rhythms/`, GH, відновлення).
- Синтез білка підвищений **24–48 год** після тренування.
- **Детренування:** сила зникає повільніше, ніж витривалість (VO₂max падає за 2–4 тижні).
- **Саркопенія:** втрата м'язової маси ~ 3–8 % за десятиліття після 30 років, швидше після 60; страждають передусім волокна IIx і рухові одиниці (денервація). Профілактика: силові вправи, білок, вітамін D, не недоїдати.
- **Міокіни** (IL-6, іризин та ін.): м'яз як ендокринний орган (`../hormones/`).

### 6.1. Допінг та добавки (кратко)
- Анаболічні стероїди, ЕПО (збільшує гематокрит, в'язкість; `../blood-gases/`), клен-бутерол — заборонені, мають серйозні ризики (серце, печінка, гормональна вісь, `../hormones/`).
- Із добавок докази стійкі для: креатину, кофеїну (3–6 мг/кг), бета-аланіну (короткі інтервали), нітратів (буряк) — помірний ефект.

## 8. Серце як насос: кількісна картина

### 8.1. Основні показники (дорослий у спокої)
| Показник | Значення |
|---|---|
| Частота (HR) | 60–100 уд/хв (в середньому ~ 70) |
| Кінцево-діастолічний об'єм (EDV) | ~ 120 мл |
| Кінцево-систолічний об'єм (ESV) | ~ 50 мл |
| Ударний об'єм (SV = EDV − ESV) | ~ 70 мл |
| Фракція викиду (EF = SV/EDV) | `70/120` ≈ **58 %** (норма 55–70 %) |
| Серцевий викид (CO = HR × SV) | `70 × 70` = **4,9 л/хв** (≈ 5) |
| Серцевий індекс (CO/площа тіла) | ~ 2,5–4 л/хв/м² |
| Середній АТ (MAP) | ≈ DBP + ⅓·(SBP − DBP) = 80 + 13 = **93 мм рт. ст.** |
| Загальний периферичний опір (TPR) | MAP / CO ≈ 93 / 5 ≈ **18,6 мм рт. ст.·хв/л** |

**Закон Ома для кровообігу:** `MAP − CVP = CO × TPR` (як U = I·R). Це пояснює: тиск підвищується або через більший викид, або через вищий опір (більшість гіпертензій — з підвищеним опором).

За життя (80 років) серце скорочується ~ **3 мільярди разів** і перекачує ~ **200 мільйонів літрів**.

### 8.2. Три детермінанти ударного об'єму
1. **Переднавантаження (preload)** — наскільки розтягнуто шлуночок перед скороченням (венозне повернення, EDV).
2. **Післянавантаження (afterload)** — опір, який потрібно подолати (аортальний тиск, стеноз клапана, TPR).
3. **Скоротливість (contractility, інотропія)** — внутрішня сила при заданому переднавантаженні (симпатика, ліки).

### 8.3. Закон Франка–Старлінга (1895 / 1914)
- **Більше наповнення → сильніше скорочення**: серце викидає все, що отримало (в межах).
- Механізм: розтягнення збільшує перекриття ниток і **чутливість тропоніну C до Ca²⁺** (довжинозалежна активація, роль титину і зменшення відстані між нитками).
- Значення: **автоматично вирівнює** викид правого й лівого шлуночків (інакше рідина накопичувалася б у легенях або в тілі), реагує на зміну пози й дихання.
- Крива Старлінга має плато, а потім падіння при надмірному розтягненні (декомпенсована серцева недостатність).
- Кров'яний тиск ↔ серце ↔ нирка ↔ об'єм (`../kidney/`).

### 8.4. Крива «тиск–об'єм» шлуночка (петля)
Четвірка фаз:
1. **Наповнення** (діастола): об'єм ↑ при низькому тиску (мітральний клапан відкритий).
2. **Ізоволюмічне скорочення**: тиск різко росте, об'єм сталий (усі клапани закриті).
3. **Викид**: аортальний клапан відкривається, об'єм ↓ (з EDV до ESV).
4. **Ізоволюмічне розслаблення**: тиск падає, об'єм сталий.

- **Площа петлі = робота за удар** (stroke work).
- Приблизно: `SW ≈ SV × середній тиск` = `70 мл × 100 мм рт. ст.` = `70·10⁻⁶ м³ × 13,3 кПа` ≈ **0,93 Дж** на удар лівого шлуночка.
- ×70 ударів/хв = ~ 65 Дж/хв ≈ **1,1 Вт** (лівий). Правий шлуночок виконує ~ 1/5 від лівого. Усього гідравлічна потужність ~ **1,3 Вт**.
- Як зміни зсувають петлю: **більше переднавантаження** → петля вправо (більший SV); **більша скоротливість** → зсув верхньої лівої точки вгору (менше ESV); **більше післянавантаження** → вужча і вища петля (менше SV).

### 8.5. Серцева недостатність (кілька слів)
- **HFrEF** (знижена фракція викиду: слабка систола) і **HFpEF** (збережена EF, але жорстка діастола).
- Компенсація: активація симпатики й РААС (`../homeostasis/`) — спочатку допомагає, потім **шкодить** (перевантаження об'ємом, ремоделювання). Звідси стандартна терапія: інгібітори АПФ/сартани/ARNI, β-блокатори, антагоністи альдостерону, гліфлозини, діуретики.
- **BNP/NT-proBNP** — гормони розтягнення шлуночків, маркер недостатності.

## 9. Збудження–скорочення в серці

### 9.1. Потенціал дії кардіоміоцита (5 фаз; докладно `anatomy/organs/cardiovascular/heart/Серце — провідна система.md`)
| Фаза | Іони | Мембрана |
|---|---|---|
| **0** | швидкий вхід Na⁺ | різка деполяризація до +20 мВ |
| **1** | вихід K⁺ (Ito) | короткий спад |
| **2 (плато)** | вхід **Ca²⁺ (L-тип)** ≈ вихід K⁺ | ~ 200–300 мс |
| **3** | вихід K⁺ | реполяризація |
| **4** | K⁺ (IK1) | −85…−90 мВ спокій |

**Плато** (~ 250 мс) тримає клітину в рефрактерності майже до кінця скорочення → **тетанус неможливий**, серце встигає розслабитись і наповнитись (життєво важливо!). Тому тривалість АД майже дорівнює тривалості скорочення (на відміну від скелетного, де АД 2 мс, а скорочення 50 мс).

### 9.2. CICR (кальцієм-індуковане вивільнення Ca²⁺)
1. Вхід невеликої кількості **Ca²⁺ через L-тип каналів (DHPR)** під час плато.
2. Цей Ca²⁺ відкриває **RyR2** на саркоплазматичному ретикулумі.
3. Вивільнення великої порції Ca²⁺ (≈ 70–90 % від загального у людини) → Ca²⁺ зв'язується з тропоніном C → скорочення.
4. Розслаблення: Ca²⁺ видаляється **SERCA2a** (назад у ретикулум; регулюється фосфоламбаном) і **Na⁺/Ca²⁺-обмінником (NCX)** → назовні.
- **Висновок:** серце залежить від позаклітинного Ca²⁺ (бо запускає каскад) — на відміну від скелетного м'яза. Тому блокатори кальцієвих каналів (верапаміл, ділтіазем, амлодипін) змінюють роботу серця і судин.

### 9.3. Як адреналін підсилює серце (β₁ → Gs → цАМФ → PKA)
Фосфорилюються:
- **L-тип каналів** → більше Ca²⁺ входить (**позитивна інотропія**);
- **фосфоламбан** → швидший SERCA → швидше розслаблення (**лузитропія**) і більший запас Ca²⁺;
- **тропонін I** → швидше відпускає Ca²⁺ (розслаблення);
- (в пейсмейкері) **If-канали** → частіше розряди (**позитивна хронотропія**).
Ацетилхолін (n. vagus) → M₂ → Gi → ↓ цАМФ → навпаки: брадикардія (`../cell/`, розд. 11).

### 9.4. Дигоксин (приклад)
Блокує Na⁺/K⁺-АТФазу → ↑ Na⁺ всередині → NCX працює гірше → ↑ Ca²⁺ → сильніше скорочення (`../cell/`, розд. 9).

## 10. Кисень і енергетика серця

### 10.1. Серце не може «взяти більше» — воно збільшує потік
- Споживання O₂ міокардом у спокої: ~ **8–10 мл/хв на 100 г** (у десятки разів більше за скелетний м'яз у спокої в розрахунку на масу), тобто для серця 300 г ≈ **25–30 мл/хв** (≈ 10 % від VO₂ всього тіла).
- Коронарний кровотік у спокої ~ **250 мл/хв (5 % CO)**.
- **Екстракція O₂ — 70–75 % уже в спокої** (артеріо-венозна різниця ~ 11 мл/дл проти 5 для тіла в цілому). Отже при збільшенні потреби екстракцію підвищувати **майже нікуди**: єдиний шлях — **збільшити кровотік** (коронарний резерв ×4–5 при максимальному навантаженні завдяки розширенню судин через аденозин, NO).
- Лівий шлуночок отримує кров переважно в **діастолу** (під час систоли судини стиснуті). Тому тахікардія (коротка діастола), низький діастолічний тиск (аортальна недостатність), набряк стінки погіршують живлення.
- **Ішемія** (недокрів'я) виникає, коли потреба > доставка: стабільна стенокардія при навантаженні (бляшка звужує просвіт).

### 10.2. Від чого залежить потреба серця
Основні детермінанти споживання O₂: **частота**, **напруга стінки** (закон Лапласа: ∝ тиск × радіус / товщина), **скоротливість**.
- Подвійний добуток **HR × SBP** — клінічний показник робочого навантаження серця.
- Тому серцю шкодять підвищення тиску (гіпертрофія), тахікардія, дилатація. А β-блокатори знижують потребу, а нітрати — переднавантаження.

### 10.3. ККД і паливо
- Механічна потужність ~ **1,3 Вт**, метаболічна ~ **6–9 Вт** → ККД **~ 15–25 %**.
- Паливо: **жирні кислоти 60–70 %**, плюс лактат, глюкоза, кетони (гнучкий «всеїдний» метаболізм). Мітохондрії — ~ 30–35 % об'єму клітини.
- Недостатня енергетика → слабке серце (при серцевій недостатності зменшується АТФ та креатинфосфат).

## 11. Серце при навантаженні

### 11.1. Що змінюється
| Параметр | Спокій | Максимальне навантаження (нетренована) | (тренована) |
|---|---|---|---|
| HR | 70 | ~ 190 | ~ 190 |
| SV | 70 мл | ~ 100–110 мл | ~ 150–200 мл |
| CO | 5 л/хв | ~ 20 л/хв | ~ 30–40 л/хв |
| Частка CO до м'язів | ~ 20 % | ~ 80–85 % | ~ 85 % |
| Вилучення O₂ | 25 % | ~ 75 % | ~ 80 % |
| VO₂ | 0,25 л/хв | 3–3,5 л/хв | 5–6 л/хв |

(`VO₂max = CO_max × (CaO₂ − CvO₂)_max`; розрахунок: `250 дл/хв × 16 мл/дл` = **4000 мл/хв** — як у розділі 2 в `../blood-gases/`.)

- ЧСС росте майже лінійно з навантаженням; SV зростає лише до ~ 40–60 % VO₂max у нетренованих, у спортсменів продовжує.
- **Максимальна ЧСС:** `220 − вік` (груба); точніша формула Танаки `208 − 0,7 × вік`. Тренування її не змінює, а **знижує ЧСС у спокої** (спортсмени 40–55 уд/хв) — завдяки більшому SV та вагусу.
- **Перерозподіл кровотоку:** симпатика звужує судини нирок, кишки, шкіри; судини активних м'язів розширюються (метаболіти: аденозин, K⁺, NO, ↓pH) — незалежно від нервів («активна гіперемія»).
- Тиск: систолічний ↑ (до 180–200), діастолічний не змінюється чи ↓ (розширення судин).
- **Відновлення ЧСС** через 1 хв після навантаження (падіння >12 уд) — маркер здоров'я вегетативної регуляції.

### 11.2. Серце спортсмена
- Фізіологічна гіпертрофія (збільшення порожнини + стінки), брадикардія, іноді зміни на ЕКГ — **норма**, не хвороба. Відрізняти від кардіоміопатій (особливо коли це спричиняє симптоми або ризик у сім'ї).
- Раптова серцева смерть у молодих спортсменів рідка (~ 1 на 50–100 тис. на рік), причини — гіпертрофічна кардіоміопатія, аномалії коронарних, аритмогенні кардіоміопатії.

### 11.3. Пасивна й активна поза
- Лежачи → стоячи: ~ 500–700 мл крові переходить у ноги; барорефлекс за кілька ударів підвищує ЧСС і тонус (`../homeostasis/`). Тривале лежання ослаблює цю реакцію (космонавти, прикуті до ліжка).
- **М'язова помпа** ніг: скорочення м'язів стискають вени з клапанами, повертаючи кров у серце. Тому тривале стояння → набряки, а ходьба допомагає.

## 12. Гладкі м'язи (коротко для повноти)
- Немає тропоніну: Ca²⁺ → **кальмодулін** → **кіназа легких ланцюгів міозину (MLCK)** → фосфорилювання міозину → скорочення.
- Дуже **повільне** і **економне** скорочення («латч-стан»: утримання тонусу з мінімумом АТФ).
- Розслаблення: фосфатаза легких ланцюгів; **NO → цГМФ** розширює судини (нітрогліцерин, силденафіл).
- Регулюється: нервами, гормонами, місцевими чинниками, розтягненням. Мішені ліків: β₂-агоністи (бронхи), блокатори Ca²⁺-каналів (судини), окситоцин (матка).

## 14. Цікаві факти

- Міокард має **ритмічність без нервів**: ізольоване серце тварини продовжує битися (Гарвей, Гальвані та ін.).
- Серце не втомлюється, бо багате мітохондріями, має широку капілярну сітку і розслаблення в кожному циклі.
- Рекорд ЧСС спокою: у деяких елітних біговиків — 30–35 уд/хв.
- Серцева тканина практично **не регенерує** після інфаркту (оновлюється ~ 0,5–1 % кардіоміоцитів на рік), тому рубець; досліджують клітинну терапію.
- Колібрі: ЧСС до 1200 уд/хв, у синього кита — 8–10 уд/хв; загальне число ударів за життя в ссавців приблизно подібне (близько мільярда ударів) — але в людини втричі більше.
- Найбільший м'яз — великий сідничний, один із найсильніших (на одиницю маси) — жувальний, найшвидший — очні м'язи (~ 10 мс скорочення).
- «Біль у серці» часто — ішемія з іррадіацією в щелепу, ліву руку; у жінок і діабетиків симптоми менш типові.

## 15. Типові помилки в розумінні

1. «Лактат — причина м'язового болю». Біль після тренування (DOMS) — від мікропошкоджень, лактат очищається за годину.
2. «Збільшуючи сили, м'яз стає „твердішим“ за питомою силою». Росте переріз, не питома сила.
3. «Серце — це один м'яз, що працює як скелетний». Ні: плато ПД, CICR, неможливість тетануса, залежність від зовнішнього Ca²⁺.
4. «Максимальна ЧСС зростає з тренуванням». Не зростає; знижується ЧСС спокою.
5. «EF 55 % означає, що серце викидає 55 % усієї крові». Це частка від кінцево-діастолічного об'єму одного шлуночка.
6. «Чим повільніше серце, тим краще». Брадикардія у спортсмена норма; у хворого — симптом.
7. «Серце отримує кров під час систоли». Лівий шлуночок — переважно в діастолу.
8. «Жир спалюється лише при низькій інтенсивності». Окиснення жиру максимальне при помірній інтенсивності (~ 60 % VO₂max), але загальні витрати вище при інтенсивній.
9. «Більше тренування завжди краще». Потрібне відновлення; перетренованість.

## 16. Шпаргалка

- **Сила ∝ PCSA** (20–40 Н/см²); швидкість ∝ довжина. Оптимальна довжина саркомера 2,0–2,25 мкм (ковзні нитки).
- **Гілл:** (F+a)(v+b) = (F₀+a)b; Pmax при ~ 30 % F₀ та ~ 30–35 % v₀ (≈ 0,1·F₀·v₀). Ексцентричне > ізометричне > концентричне за силою.
- **Тетанус:** злиття при 10–20 Гц (повільні) і 50–100 Гц (швидкі); короткий рефрактерний період.
- **Рухова одиниця:** принцип розміру (малі першими); коефіцієнт іннервації 1:10 (очі) – 1:2000 (литка).
- **Волокна:** I (окисні, стійкі) → IIa → IIx (швидкі, втомлюються).
- **Енергія:** КФ (~ 10 с) → гліколіз (до 2 хв) → окиснення; ККД 20–25 %; 1 л O₂ ≈ 20 кДж ≈ 348 Вт·хв; 200 Вт при ККД 22 % = 2,6 л O₂/хв.
- **Втома:** Pi, Ca²⁺, глікоген, центральна; DOMS — мікротравми.
- **Тренування:** сила = нерви (2–8 тиж) + гіпертрофія; витривалість = мітохондрії, капіляри, ударний об'єм.
- **Серце:** SV = EDV − ESV = 70; EF = 58 %; CO = HR × SV = 4,9 л/хв; MAP = DBP + ⅓PP; MAP = CO·TPR.
- **Старлінг:** більше наповнення → сильніше скорочення. Петля P–V: площа = робота ≈ 0,93 Дж/удар; потужність ≈ 1,3 Вт.
