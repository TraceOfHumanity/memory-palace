## 1. Що це таке

- **Гомеостаз** (грец. *homoios* — «подібний», *stasis* — «стан») — здатність організму **підтримувати внутрішнє середовище майже сталим**, незважаючи на зміни зовні й навантаження всередині.
- Не «нерухомість», а **динамічна рівновага**: параметр постійно трохи коливається навколо **заданого значення** (уставки), а системи керування повертають його назад.
- Що саме тримається сталим: температура ядра тіла, pH, концентрація глюкози, іонів (Na⁺, K⁺, Ca²⁺), осмолярність, об'єм рідини, тиск, вміст O₂ і CO₂ у крові.
- **Чому це критично.** Ферменти (див. `../enzymes/`) працюють лише у вузькому діапазоні температури й pH; нервові та м'язові клітини залежать від градієнтів K⁺/Na⁺/Ca²⁺ (див. `../cell/`). Вихід за межі швидко ламає клітинну роботу.
- **Хвороба** з цієї точки зору — це **зрив регуляції**: сенсор, центр, виконавець або сам канал зв'язку перестають працювати правильно (розд. 11).

### Внутрішнє середовище
- **Клод Бернар (1850–70-ті)**: ввів поняття *milieu intérieur* — «внутрішнє середовище». Його знаменита фраза: **стала внутрішнього середовища — умова вільного життя**.
- Внутрішнє середовище = **позаклітинна рідина** (тканинна рідина + плазма), у якій «купаються» клітини. Клітини змінюють її (вживають O₂, виділяють CO₂), а системи органів постійно «чистять» і «поповнюють».

### Рідинні відсіки (орієнтовно для дорослого 70 кг)
| Відсік | Частка маси тіла | Обсяг |
|---|---|---|
| **Загальна вода тіла** | ~60 % (у чоловіків), ~50 % (у жінок, більше жиру) | ~42 л |
| **Внутрішньоклітинна (ВКР)** | ~40 % (2/3 води) | ~28 л |
| **Позаклітинна (ПКР)** | ~20 % (1/3 води) | ~14 л |
| — тканинна (міжклітинна) | ~15 % | ~10–11 л |
| — плазма крові | ~5 % | ~3–3,5 л |

(Кров загалом ~5 л = плазма ~55 % + клітини ~45 %.) У немовлят води більше (до ~75 %), у літніх людей менше.

## 3. Анатомія петлі регуляції

Будь-яка регуляційна система містить чотири «деталі»:

```
          ┌──────── Відхилення (подразник) ───────┐
          ▼                                        │
  [1. СЕНСОР / РЕЦЕПТОР]  — вимірює параметр       │
          │ (аферентний шлях: нерв або гормон)     │
          ▼                                        │
  [2. ЦЕНТР КЕРУВАННЯ]  — порівнює із УСТАВКОЮ     │
          │ (еферентний шлях)                      │
          ▼                                        │
  [3. ВИКОНАВЕЦЬ / ЕФЕКТОР] — змінює параметр ─────┘
```

| Частина | Що робить | Приклади |
|---|---|---|
| **Сенсор** | вимірює змінну | терморецептори, барорецептори, хеморецептори, осморецептори, β-клітини (відчувають глюкозу), клітини прищитоподібної залози (відчувають Ca²⁺) |
| **Аферентний шлях** | передає сигнал до центру | нерв (блукаючий, язикоглотковий), кров (гормони, метаболіти) |
| **Центр (інтегратор)** | порівнює вимір з **уставкою** (set point), обчислює помилку | гіпоталамус, довгастий мозок, ендокринна залоза, нирка |
| **Еферентний шлях** | передає команду | нерви (симпатичні, парасимпатичні, рухові), гормони |
| **Ефектор** | виконує зміну | м'язи, залози, судини, нирка, печінка, жирова тканина |

> Програмна аналогія: **sensor → comparator → actuator** — як у thermostat, autoscaler, watchdog, rate limiter, circuit breaker. Різниця: біологічні «контролери» розподілені й часто багаторівневі.

## 4. Негативний зворотний зв'язок

### 4.1. Суть
Результат дії **гальмує або скасовує** початкове відхилення. Це **основний** тип регуляції: стабілізує.

> Підвищилось → система знижує. Знизилось → система підвищує. (Як термостат.)

### 4.2. Математично (без страху)
Нехай **S** — уставка, **X** — поточне значення, **e = S − X** — «помилка». Виконавець діє **пропорційно помилці**: ΔX = G · e (G — підсилення, «gain»).

Мінікод (симуляція температури з пропорційним регулятором):
```python
def simulate(setpoint: float = 37.0, temp: float = 39.0,
             gain: float = 0.3, steps: int = 8) -> None:
    for t in range(steps):
        error = setpoint - temp      # how far from the set point
        temp += gain * error         # effector corrects a fraction of the error
        print(t, round(temp, 2))

simulate()
# 38.4, 37.98, 37.69, 37.48, 37.34, 37.24, 37.16, 37.12  -> converges to 37.0
```
- Кожен крок усуває **30 %** залишку помилки → експоненціальне наближення до уставки.
- **Більший gain** → швидше, але ризик **перерегулювання й коливань** (як занадто різкий душ).
- **Затримка** в петлі + великий gain = **осциляції** (наприклад, коливання тиску, періодичне дихання Чейна–Стокса).

### 4.3. Що таке «підсилення петлі» (loop gain)
Gain = (виправлення) / (залишкова помилка). Чим більший, тим точніше тримається параметр.
- Для **температури тіла** gain, за оцінкою Гайтона, дуже високий (близько 27): формула G/(1+G) дає, що система усуває близько 96 % збурення, тож залишається лише ~4 %.
- Для **артеріального тиску** короткостроковий gain (барорефлекс) ~ 2–3; але **нирка** працює як **інтегральний регулятор** — «не заспокоюється», поки тиск не повернеться до рівня, при якому виводиться стільки солі та води, скільки надходить (нескінченний gain у довгостроковій перспективі, Гайтон).

### 4.4. Зсув уставки (набуті й тимчасові)
Уставка — не константа:
- **Лихоманка:** пірогени (інтерлейкін-1, простагландин E₂) **підвищують уставку** гіпоталамуса, і тіло «замерзає» (озноб, звуження судин), поки температура не досягне нового рівня. Жарознижувальні (парацетамол, ібупрофен, аспірин) знижують синтез PGE₂ — повертають уставку. Лихоманка ≠ **гіпертермія** (перегрів без зсуву уставки: тепловий удар, ліки).
- **Вправи:** під час навантаження температура ядра росте до 38–39 °C (регульований підйом).
- **Доба:** температура вранці нижча (мінімум ~4–6 год), ввечері вища (~±0,5 °C).
- **Висота:** у гірській місцевості вентиляція «налаштовується» на нижчий PaO₂.

## 5. Позитивний зворотний зв'язок

### 5.1. Суть
Результат **підсилює** початковий зсув — «снігова куля». Не стабілізує, а **доводить процес до кінця** (подія з початком і кінцем). Зазвичай коротка й обмежена зовнішньою умовою.

### 5.2. Приклади
| Процес | Як петля працює | Чим закінчується |
|---|---|---|
| **Пологи** | голівка плода розтягує шийку матки → сигнал у гіпоталамус → **окситоцин** → скорочення → сильніший тиск на шийку → ще більше окситоцину (рефлекс Фергюсона) | народження плода |
| **Згортання крові** | тромбін активує фактори, які дають ще більше тромбіну (каскад) | згусток закриває пошкодження |
| **Потенціал дії** | деполяризація відкриває Na⁺-канали → входить Na⁺ → ще більша деполяризація | мембрана досягає піку, канали закриваються |
| **Овуляція (пік ЛГ)** | високий естрадіол (>~200 пг/мл протягом ~48 год) **у цьому вікні** не гальмує, а стимулює ЛГ | овуляція |
| **Лактація** | смоктання → окситоцин → викид молока → більше смоктання | годування |
| **Вивільнення Ca²⁺ в серці** | Ca²⁺-індуковане вивільнення Ca²⁺ з ретикулума | синхронне скорочення |
| **Апоптоз** | каспаза активує інші каспази | загибель клітини |
| **Шлунок: пепсиноген → пепсин** | пепсин активує інший пепсиноген | перетравлення |

### 5.3. Небезпечний позитивний зворотний зв'язок («хибне коло»)
- **Геморагічний шок.** Втрата крові → падіння тиску → слабше серце й менший кровотік у серці → ще менший викид → ще нижчий тиск … Спочатку компенсація (негативна петля: тахікардія, звуження судин), потім **декомпенсація** — стан стає незворотним.
- **Тепловий удар.** Перегрів → підвищення швидкості реакцій → більше тепла … (Q10 ≈ 2).
- **Сепсис, вогнищева ішемія** — теж.
- **Серцева недостатність.** Слабке серце → нирка збільшує об'єм → більше навантаження → слабше серце.

## 6. Інші типи керування

| Тип | Суть | Приклад |
|---|---|---|
| **З випередженням (feedforward)** | реагує на **сигнал, що передбачає** зміну, ще до відхилення | вигляд і запах їжі → слина, шлунковий сік, **інсулін** (цефалічна фаза); підготовка до вправ — серце прискорюється ще до старту; звикання організму до режиму сну |
| **Каскад підсилення** | кожен етап посилює попередній | гормональні осі, згортання крові |
| **Ієрархічний** | кілька рівнів контролю | гіпоталамус → гіпофіз → залоза (розд. 7) |
| **Поведінковий** | людина свідомо змінює середовище | одягнути куртку, випити води, піти в тінь |
| **Багаторівневе резервування** | кілька механізмів на один параметр | pH: буфери, легені, нирки (розд. 8.4) |

> **Принцип Кеннона:** важливі параметри захищають **кілька різних механізмів**, які можуть діяти **в протилежні боки** (антагонізм: інсулін / глюкагон; симпатична / парасимпатична системи). Це дозволяє тонку регуляцію і відмовостійкість.

## 7. Нервова та гормональна регуляція

| Ознака | Нервова | Гормональна |
|---|---|---|
| Канал | нерв (потенціал дії, синапс) | кров (гормони) |
| Швидкість | **мілісекунди-секунди** | **секунди-години-доби** |
| Адресність | точна | широка (усі клітини з рецептором) |
| Тривалість | коротка | довга |
| Приклад | барорефлекс, зіничний рефлекс | регуляція глюкози, росту, водно-сольового обміну |

Вони **поєднані**: гіпоталамус — нервовий центр, що керує гіпофізом (нейроендокринна система); мозкова речовина надниркових залоз — «нервовий вузол», що виробляє адреналін. Докладно — `../hormones/` та `anatomy/organs/endocrine/`.

## 8. Приклади петель

### 8.1. Температура тіла
- **Норма (ядро):** ~**36,5–37,5 °C** (середнє ≈ 37). Стабільніше за температуру шкіри: кінцівки холодніші.
- **Сенсори:** терморецептори шкіри (холодові, теплові) + **центральні** в гіпоталамусі (преоптична ділянка), спинному мозку, органах.
- **Центр:** передній і задній гіпоталамус.
- **Виконавці:**

| Умови | Реакції |
|---|---|
| **Жарко** | **розширення судин шкіри** (віддача тепла), **потовиділення** (випаровування ~2400 кДж на літр поту), зменшення м'язового тонусу, поведінка (тінь, роздягання) |
| **Холодно** | **звуження судин шкіри**, **тремтіння** (м'язове тепло, ×4–5), **бурий жир** (немовлята), адреналін/тиреоїдні гормони (підвищення обміну), мурашки на шкірі, згортання тіла, одягання |

- Способи віддачі тепла: **випромінювання** (радіація, ~60 % у спокої), **кондукція** (дотик), **конвекція** (рух повітря), **випаровування** (єдиний, коли довкілля тепліше за шкіру). Висока вологість — випаровування гірше → гірше переноситься спека.
- **Термонейтральна зона** (~28 °C для голої людини): тіло не витрачає додаткову енергію.
- Критичні межі: **гіпотермія** (<35 °C), **гіпертермія/тепловий удар** (>40 °C; ферменти починають денатурувати).

### 8.2. Глюкоза крові
- **Норма (натще):** ~**3,9–5,5 ммоль/л** (70–99 мг/дл); після їжі зростає до ~7,8 і повертається протягом 2 год.
- **Сенсор:** β-клітини (через GLUT2 і глюкокіназу) й α-клітини підшлункової, гіпоталамус.
- **Негативна петля:** глюкоза ↑ → **інсулін** → поглинання клітинами (GLUT4), глікогенез, ліпогенез → глюкоза ↓. Глюкоза ↓ → **глюкагон**, адреналін, кортизол, гормон росту → глюкоза ↑.
- **Дві протилежні сили** (антагоністи) — принцип Кеннона. Деталі — `../metabolism/` і `anatomy/organs/endocrine/pancreas-endocrine/`.
- **Зрив:** діабет (немає інсуліну чи рецептор не реагує) — «термостат зламався».
- **Гіпоглікемія без відчуття:** повторні епізоди притупляють адреналінову відповідь.

### 8.3. Артеріальний тиск
- **Норма:** приблизно **120/80 мм рт. ст.**
- **Швидка петля (секунди): барорефлекс.**
  - Сенсори: **барорецептори** каротидного синуса й дуги аорти.
  - Шлях: IX і X черепні нерви → **ядро одинокого шляху** (довгастий мозок) → симпатична й парасимпатична системи.
  - Виконавці: серце (частота, сила), судини (діаметр).
  - Підвищився тиск → більше імпульсів → парасимпатика ↑, симпатика ↓ → брадикардія, розширення судин → тиск ↓.
  - Приклад: різко встали, тиск упав → барорефлекс за 1–2 с піднімає частоту й тонус судин. При збою — **ортостатична гіпотензія** (темніє в очах).
- **Середня петля (хвилини-години): ренін–ангіотензин–альдостерон (РААС).** Мало крові → нирка виділяє **ренін** → ангіотензин II (звужує судини) → альдостерон (затримує Na⁺ і воду).
- **Повільна петля (доби): нирка.** Тиск ↑ → нирка виводить більше солі й води (**натрійурез під тиском**) → об'єм ↓ → тиск ↓.
- **Ліки на цих петлях:** інгібітори АПФ, сартани, діуретики, β-блокатори.

### 8.4. pH крові і CO₂
- **Норма артеріальної крові:** pH **7,35–7,45**; **PaCO₂ 35–45 мм рт. ст.**; бікарбонат **22–26 ммоль/л**.
- **Рівняння Гендерсона–Гассельбальха:**
```
pH = 6,1 + log10( [HCO₃⁻] / (0,03 × PaCO₂) )
```
Перевірка: [HCO₃⁻] = 24, PaCO₂ = 40 → 0,03 × 40 = 1,2; 24/1,2 = 20; log10(20) = 1,30; **pH = 6,1 + 1,30 = 7,40**.
- **Три лінії захисту:**

| Рівень | Час відповіді | Механізм |
|---|---|---|
| **Буфери** (бікарбонатний, білки, гемоглобін, фосфати) | **миттєво** | зв'язують H⁺ |
| **Легені** | **хвилини** | швидше дихаємо → видаляємо CO₂ → pH ↑ |
| **Нирки** | **години-доби** | виводять H⁺, регенерують HCO₃⁻ |

- **Сенсори дихання:** **центральні хеморецептори** (довгастий мозок, реагують на H⁺ у спинномозковій рідині — тобто на CO₂), **периферичні** (каротидні тільця; реагують на падіння O₂, ріст CO₂ і H⁺).
- Парадокс: нас змушує дихати **надлишок CO₂**, а не нестача O₂ (O₂ реагує, лише коли PaO₂ < ~60 мм рт. ст.).
- **Порушення:**

| Стан | pH | Первинна зміна | Причина (приклади) |
|---|---|---|---|
| **Метаболічний ацидоз** | ↓ | HCO₃⁻ ↓ | кетоацидоз, лактоацидоз, діарея, ниркова недостатність |
| **Метаболічний алкалоз** | ↑ | HCO₃⁻ ↑ | блювання (втрата HCl), діуретики |
| **Дихальний ацидоз** | ↓ | CO₂ ↑ | гіповентиляція (ХОЗЛ, опіоїди) |
| **Дихальний алкалоз** | ↑ | CO₂ ↓ | гіпервентиляція (паніка, висота) |

Організм **компенсує** протилежним органом (напр. при метаболічному ацидозі легені дихають частіше — дихання Куссмауля).

### 8.5. Вода та осмолярність
- **Норма осмолярності плазми:** ~**285–295 мОсм/л** (див. `../cell/` про осмос).
- **Сенсор:** **осморецептори** гіпоталамуса (ділянка поза гематоенцефалічним бар'єром — OVLT). Підвищення осмолярності лише на **1–2 %** запускає реакцію.
- **Виконавці:** **АДГ (вазопресин)** → нирка вставляє аквапорини-2, затримує воду; **спрага** → людина п'є.
- Знизилась осмолярність → АДГ ↓ → нирки виводять розведену сечу.
- **Збої:** нецукровий діабет (немає АДГ або нирка не відповідає) — багато розведеної сечі; синдром неадекватної секреції АДГ — розведення крові, низький Na⁺.
- Об'єм крові окремо: **барорецептори** + **передсердний натрійуретичний пептид (ANP)** + РААС.

### 8.6. Кальцій
- Ca²⁺ у плазмі: загальний **2,2–2,6 ммоль/л**; **іонізований ~1,1–1,3** (активна частка).
- Сенсор: **Ca-чутливий рецептор** (GPCR) у паращитоподібних залозах.
- Низький Ca²⁺ → **ПТГ** → кістка віддає Ca, нирка затримує Ca і активує вітамін D (кальцитріол) → кишка всмоктує більше. Високий Ca²⁺ → ПТГ ↓ (негативна петля). Деталі — `anatomy/organs/endocrine/thyroid-parathyroid/` і `../vitamins/Вітамін D.md`.
- Чому важливо: низький іонізований Ca²⁺ → нервова збудливість (судоми, тетанія); високий — слабкість, камені, аритмії.

### 8.7. Калій
- Норма **3,5–5,0 ммоль/л**; вузький діапазон, бо визначає потенціал спокою (див. `../cell/`).
- Регулятори: **альдостерон** (виводить K⁺ нирками), **інсулін** і **адреналін** (заганяють K⁺ в клітини).
- Збій: гіперкаліємія → зупинка серця; гіпокаліємія → слабкість, аритмії.

### 8.8. Кисень
- Низький O₂ у тканинах → фактор **HIF** (відкрили Семенца, Реткліфф, Келін) вмикає ген **еритропоетину (EPO)** в нирці → більше еритроцитів → більше O₂ в тканини. Повільна петля (дні). Висотна акліматизація: ~2–3 тижні, гематокрит росте.

### 8.9. Енергетичний баланс
- **Лептин** (жирові клітини, відкрито 1994 Джеффрі Фрідманом) → гіпоталамус (аркуатне ядро) гальмує апетит; **греліну** («гормон голоду», шлунок) стимулює.
- Довгострокова вага «захищається»: схуднення знижує лептин, посилює голод і зменшує витрати → організм прагне повернути вагу (одна з причин, чому важко утримувати втрату ваги).

### 8.10. Циркадні ритми
- Центральний «годинник» — **супрахіазматичне ядро** гіпоталамуса, синхронізується світлом через сітківку. Керує мелатоніном, кортизолом, температурою, сном. Нобелівська премія 2017 (Голл, Росбаш, Янг) — гени годинника.

## 9. Стрес, алостаз і адаптація

### 9.1. Стрес (Сельє)
**Загальний адаптаційний синдром:** 1) **тривога** (викид адреналіну й кортизолу), 2) **резистентність** (пристосування), 3) **виснаження** (при затяжному стресі).

### 9.2. Алостаз
- **Стабільність через зміну** (Стерлінг, Ейєр 1988): система **заздалегідь** змінює уставки під очікуване навантаження (тиск зростає перед пробудженням, кортизол — вранці).
- **Алостатичне навантаження** — «зношення» від хронічно високих реакцій: гіпертензія, інсулінорезистентність, порушення сну, депресія.

### 9.3. Акліматизація й адаптація
- **Акліматизація** — оборотна зміна при новому середовищі (гори: більше еритроцитів і глибше дихання; спека: пітливість раніше й з меншою втратою солі, 1–2 тижні).
- **Тренування:** серце більше, мітохондрій більше, нижча частота спокою.
- **Адаптація** (еволюційна) — спадкова: наприклад, висотні популяції тибетців мають варіант гена EPAS1.

## 10. Старіння та резерв

- Із віком **резервні можливості** зменшуються: той самий стрес (спека, втрата рідини, ліки) спричиняє більше порушень. Регуляція спраги слабшає, тому літні легше зневоднюються; терморегуляція гірша; барорефлекс повільніший.
- **Резерв:** нирка зі втратою 50 % нефронів лишається в нормі за аналізами — це приклад запасу; зменшення резерву виявляється при навантаженні.

## 11. Коли регуляція ламається

| Частина петлі | Приклад збою | Наслідок |
|---|---|---|
| **Сенсор** | β-клітини не відчувають глюкозу; нейропатія (не відчуває біль, ортостаз) | діабет 2 типу, ушкодження |
| **Аферентний шлях** | пошкодження нерва | порушення рефлексів |
| **Центр** | пошкодження гіпоталамуса (пухлина, травма) | порушення температури, спраги, апетиту |
| **Еферентний шлях** | відсутність гормону (інсулін, АДГ) | діабет, нецукровий діабет |
| **Ефектор** | рецептор не реагує (резистентність), нирка не відповідає | діабет 2 типу, нефрогенний нецукровий діабет |
| **Автономна секреція** | пухлина виробляє гормон поза контролем | тиреотоксикоз від «гарячого» вузла, синдром Кушинга |
| **Втрата негативного зв'язку** | вихід з-під контролю | гіперсекреція |
| **Хибне коло** | позитивні петлі | шок, сепсис |
| **Перевантаження** | зовнішнє навантаження > ємності | тепловий удар, гіпонатріємія від надмірної води |

### Компенсація і декомпенсація
Хвороба часто довго **компенсується**: регуляція «тягне» і показник у нормі, але з напруженням (наприклад, серце росте, щоб подолати високий тиск). Коли резерв вичерпано — **раптове погіршення (декомпенсація)**.

## 12. Типові помилки в розумінні

1. «Гомеостаз — це незмінність». Це **динамічне** утримання біля уставки з коливаннями.
2. «Негативний зворотний зв'язок — це погано». «Негативний» = «гальмуючий»: це **стабілізатор**.
3. «Позитивний — це добре». Це «підсилення»: корисне для коротких подій (пологи), небезпечне при шоку.
4. «Лихоманка — перегрів». Це **зсув уставки**; гіпертермія — інше.
5. «Нас змушує дихати нестача кисню». Передусім **надлишок CO₂**.
6. «Одна лабораторна норма однакова для всіх». Норми залежать від віку, статі, часу доби, умов.
7. «Все регулюється одним гормоном». Зазвичай **кілька протилежних сил**.
8. «Організм завжди повертається точно до однієї цифри». Уставки зсуваються (доба, вправи, хвороба).

## 13. Шпаргалка

- **Гомеостаз** (Кеннон, 1926–29) — динамічна сталість внутрішнього середовища (Бернар, *milieu intérieur*).
- **Петля:** сенсор → аферентний шлях → центр (порівняння з уставкою) → еферентний шлях → ефектор.
- **Негативний зв'язок** — стабілізує (термостат). **Позитивний** — підсилює до завершення (пологи, згортання, потенціал дії, пік ЛГ), небезпечний при шоку.
- **Feedforward** — передбачення (запах їжі → інсулін).
- **Gain:** більший = точніше, але ризик коливань; затримка + gain = осциляції.
- **Зсув уставки:** лихоманка (PGE₂), доба, вправи.
- **Норми:** T ядра 36,5–37,5 °C; pH 7,35–7,45; PaCO₂ 35–45; глюкоза 3,9–5,5 ммоль/л; Na⁺ 135–145; K⁺ 3,5–5,0; осмолярність 285–295; АТ ~120/80.
- **Вода:** 60 % маси; 2/3 всередині клітин, 1/3 ззовні (плазма ~1/4 позаклітинної).
- **pH:** pH = 6,1 + log([HCO₃⁻]/(0,03·PaCO₂)) = 7,40; буфери (миттєво) → легені (хвилини) → нирки (дні).
- **Тиск:** барорефлекс (секунди) → РААС (хвилини-години) → нирка (доби).
- **Осмолярність:** осморецептори → АДГ + спрага. **Кальцій:** ПТГ + вітамін D. **Кисень:** HIF → EPO. **Вага:** лептин/грелін.
- **Принцип Кеннона:** кілька механізмів, протилежна дія, запас міцності.
- **Алостаз** — стабільність через зміну; **алостатичне навантаження** — зношення від хронічного стресу.
- **Хвороба** = збій сенсора / центру / каналу / ефектора / резерву; компенсація → декомпенсація.
