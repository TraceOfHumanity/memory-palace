## 1. Що таке сон

- **Сон** — оборотний, періодичний стан **зниженої реактивності** на зовнішні подразники та **зміненої свідомості**, під час якого мозок і тіло виконують важливу «обслуговуючу» роботу.
- Відрізняється від:
  - **коми** (немає пробудження навіть на сильні подразники, немає циклів);
  - **наркозу** (фармакологічна втрата свідомості без нормальної архітектури);
  - **гібернації** (довготривале зниження обміну);
  - **смерті мозку** (немає активності).
- Сон **обов'язковий**: ні для кого з вивчених тварин не знайдено виду без сну. Дельфіни й деякі птахи сплять **одною півкулею** (унілатерально), щоб дихати/літати.
- Тривалість сну у ссавців: кажан ~ 17–20 год, кіт ~ 12–16, людина ~ 7–9, слон ~ 3–4, жираф ~ 4–5 (за оцінками).

### Дві головні складові
| | **NREM** (non-REM, повільний сон) | **REM** (rapid eye movement, швидкий сон) |
|---|---|---|
| Мозок | синхронна повільна активність | активність, схожа на неспання |
| М'язи | тонус знижений, але зберігається | **атонія** (параліч) |
| Сновидіння | рідкісні, «думки» | яскраві, сюжетні |

## 2. Як вимірюють сон

- **Полісомнографія (ПСГ)** — «золотий стандарт»: ЕЕГ (мозок), ЕОГ (рух очей), ЕМГ (тонус м'язів підборіддя), ЕКГ, дихання, сатурація, рух ніг.
- **Актиграфія** — браслет-акселерометр; оцінює цикл сон/неспання (не стадії).
- **Споживчі пристрої** (годинники, кільця) оцінюють сон за рухом і пульсом: непогано щодо тривалості, **гірше щодо стадій**.
- **Показники:**

| Показник | Означення | Норма |
|---|---|---|
| **TIB** (time in bed) | час у ліжку | — |
| **TST** (total sleep time) | загальний час сну | 7–9 год |
| **SOL** (sleep onset latency) | час засинання | <20–30 хв |
| **WASO** | неспання після засинання | <30 хв |
| **Ефективність сну** | TST / TIB | **≥ 85 %** |
| **AHI** | індекс апное-гіпопное (за годину) | <5 |
| **Шкала Епворт (ESS)** | сонливість, 0–24 | >10 — надмірна |

## 3. Стадії сну (за AASM)

Раніше: стадії 1–4 + REM (Лумис, 1937; Рехтшаффен і Калес, 1968). Нині: **N1, N2, N3, REM**.

### 3.1. Електрична картина (ЕЕГ)
| Стан | Ритм ЕЕГ | Частота | Особливості |
|---|---|---|---|
| **Неспання, очі відкриті** | β (бета) | 13–30 Гц | низька амплітуда |
| **Спокій, очі закриті** | α (альфа) | 8–13 Гц | задні відділи |
| **N1** | θ (тета) | 4–7 Гц | повільні рухи очей; «засинання», сіпання |
| **N2** | змішана + **веретена сну** (12–15 Гц, 0,5–2 с) + **К-комплекси** | | ~ половина всього сну |
| **N3** («повільнохвильовий», глибокий) | δ (дельта) | 0,5–4 Гц, амплітуда >75 мкВ | ≥ 20 % епохи; найважче розбудити |
| **REM** | змішана низькоамплітудна (подібна до неспання), «пилкоподібні» хвилі | | швидкі рухи очей, атонія |

- Ганс Бергер записав першу ЕЕГ людини в **1924**.
- **REM відкрили Юджин Азеринскі та Натаніель Клейтман (1953)**; Мішель Жуве (1959) показав, що в REM зникає тонус м'язів.

### 3.2. Структура ночі (архітектура)
- Цикл триває **~90 хв (80–110)**: N1 → N2 → N3 → N2 → REM.
- За ніч **4–6 циклів**.
- **Глибокий сон (N3)** переважає в **першій третині ночі**; REM — в **другій половині**, і кожного циклу довше (від 5–10 хв до 30–60 хв).
- Приблизні частки дорослого:

| Стадія | % ночі | Хвилин (при 7,5 год) |
|---|---|---|
| N1 | 2–5 % | ~ 15 |
| N2 | 45–55 % | ~ 225 |
| **N3** | 15–25 % | ~ 90 |
| **REM** | 20–25 % | ~ 100 |

### 3.3. Віковий розвиток
| Вік | Сон/добу | Коментар |
|---|---|---|
| Новонароджений | 16–18 год | REM (активний сон) ~ 50 % |
| Немовля 4–12 міс | 12–16 | |
| 1–2 роки | 11–14 | |
| 3–5 | 10–13 | |
| 6–12 | 9–12 | |
| Підлітки | 8–10 | **фазовий зсув у «совину» сторону** |
| Дорослі | 7–9 | |
| 65+ | 7–8 | N3 і спектр повільних хвиль зменшуються, більше пробуджень |

(Рекомендації AASM/Sleep Research Society — **не менше 7 год** для дорослих.)

## 4. Що відбувається в тілі

| Показник | NREM | REM |
|---|---|---|
| **Свідомість** | знижена | сновидіння |
| **Частота серця, тиск** | падають на 10–20 % (нічне «зниження» АТ — **dipping**) | нестабільні, спалахи (вегетативні «бурі») |
| **Дихання** | повільне, регулярне | нерегулярне, чутливість до CO₂ знижена |
| **Температура** | знижується (мінімум ~ за 2 год до пробудження) | терморегуляція майже **вимкнена** |
| **Тонус м'язів** | знижений | **атонія** (крім очей, діафрагми) |
| **Мозковий кровотік, метаболізм** | знижені (~ 20–25 % в N3) | як при неспанні або вище |
| **Ерекція / набухання клітора** | — | типові |
| **Нервові медіатори** | ацетилхолін ↓, моноаміни помірні | **ацетилхолін ↑↑, норадреналін, серотонін, гістамін ≈ 0** |

- **Атонія в REM:** нейрони підсудочного (сублатеродорсального) ядра моста → глутамат → гальмівні інтернейрони → гліцин/ГАМК гальмує α-мотонейрони спинного мозку. Захищає від «розігрування» снів.
- **Гормони сну** (див. `../hormones/`, розд. 10):
  - **Гормон росту** — до ~ 70 % добової секреції в першому епізоді N3.
  - **Кортизол** — мінімум близько опівночі, ріст перед пробудженням (відповідь пробудження).
  - **Пролактин** росте; **ТТГ** росте вночі (пригнічується сном-позбавленням); **лептин** росте (ситість); **мелатонін** — пік вночі.
  - Нічне підвищення **тестостерону** у чоловіків залежить від REM.

## 5. Керування сном і неспанням

### 5.1. Двопроцесова модель (Александр Борбей, 1982)
Потреба і час сну визначаються двома незалежними процесами:
- **Процес S (гомеостатичний «тиск сну»)** — росте під час неспання, падає у сні. Матеріальна основа: **аденозин**, нагромаджений у мозку, та інші сомногени; електричний маркер — **повільнохвильова активність (δ) ЕЕГ** (чим довше неспання, тим сильніші повільні хвилі на початку ночі).
- **Процес C (циркадний)** — «годинник», який визначає, **коли** сон можливий: підвищує сигнал неспання протягом дня і знижує вночі.

Математика (спрощена):
```
Неспання:  S(t) = 1 − (1 − S₀) · e^(−t/τ_і),   τ_і ≈ 18,2 год   (насичення)
Сон:       S(t) = S₀ · e^(−t/τ_д),             τ_д ≈ 4,2 год    (швидкий спад)
```
```python
import math

def two_process(days: int = 5, wake_h: float = 16, sleep_h: float = 8,
                tau_i: float = 18.2, tau_d: float = 4.2, s0: float = 0.2) -> None:
    s = s0
    for day in range(days):
        s = 1 - (1 - s) * math.exp(-wake_h / tau_i)   # pressure builds while awake
        peak = s
        s = s * math.exp(-sleep_h / tau_d)            # and dissipates during sleep
        print(day, round(peak, 3), round(s, 3))

two_process()   # settles near peak 0.62 and morning 0.09
```
- Після 16 год неспання S ≈ 0,62–0,67 від максимуму, після 8 год сну падає до ~ 0,09–0,10.
- Висновок: **сон накопичується як борг**: чим довше неспання, тим сильніший тиск; але «борг» повертається нерівномірно (відновлення йде насамперед за рахунок глибокого сну).

### 5.2. Аденозин і кофеїн
- Клітини розщеплюють АТФ (`../metabolism/`) → **аденозин** накопичується у позаклітинному просторі (особливо в базальних відділах переднього мозку) і через A₁/A₂A-рецептори **пригнічує** збуджуючі системи.
- **Кофеїн** — **антагоніст** рецепторів аденозину: не додає енергії, а «маскує» сигнал втоми. Аденозин нікуди не зникає, тому після кави «повертається» (відчуття краху).
- Період напіврозпаду кофеїну **~ 5 год** (3–7; довше у вагітних, на оральних контрацептивах; швидше у курців). Через 5 год лишається 50 %, через 10 год — 25 %.
- Дослідження: 400 мг кофеїну за 6 год до сну скорочували сон більш ніж на годину. Орієнтир — **не пити кофеїн за 8 і більше годин до сну**.
- Максимальна безпечна доза для дорослих — ~ **400 мг/добу** (≈ 4 чашки кави), для вагітних ~ 200 мг.

### 5.3. «Перемикач» сон–неспання (Кліффорд Саупер, 2001)
- **Система збудження (неспання):** моноамінергічні ядра стовбура та гіпоталамуса:
  - **Locus coeruleus** (норадреналін), **ядра шва** (серотонін), **туберомамілярне ядро** (гістамін), **вентральна покришка** (дофамін), холінергічні ядра (ацетилхолін).
  - Вони активують кору і таламус (**висхідна ретикулярна активуюча система, Моруцці і Мегун, 1949**).
- **Центр сну:** **вентролатеральне преоптичне ядро (VLPO)** гіпоталамуса — ГАМК/галанін; гальмує всі центри збудження.
- **Взаємне гальмування** між VLPO та системою збудження → як електронний **тригер-«флип-флоп»**: стан швидко перемикається і стійкий лише в одному з двох положень (так не буває «наполовину спати»).
- **Орексин (гіпокретин)** — нейропептид латерального гіпоталамуса (відкрито 1998, де Леса і Сакураї): **стабілізує** неспання, утримує перемикач від раптових падінь. Втрата орексинових нейронів → **нарколепсія 1 типу** (сонні напади, катаплексія).
- Історично: **Костянтин фон Економо** (енцефаліт 1917–1926): ураження переднього гіпоталамуса → безсоння; заднього → летаргічна сплячка. Так було відкрито гіпоталамічні центри.
- **REM-перемикач:** окремий флип-флоп у мосту (REM-on / REM-off); холінергічні нейрони (LDT/PPT) і сублатеродорсальне ядро вмикають REM; моноаміни його вимикають. Антидепресанти (SSRI) пригнічують REM.

### 5.4. Глимфатична система та «прибирання»
- Під час NREM-сну міжклітинний простір мозку у мишей **розширюється** (до ~ 60 %), що збільшує потік спинномозкової рідини навколо судин (**глимфатична система**, Майкен Недергаард, 2012–2013) і прискорює виведення продуктів обміну, зокрема **β-амілоїду** (пов'язаний з хворобою Альцгеймера).
- У людей докази непрямі: одна безсонна ніч збільшує амілоїд у мозку (ПЕТ). Втім, механізм і масштаб ще обговорюють.

## 6. Циркадні ритми (біологічний годинник)

### 6.1. Основа
- **Циркадний** (лат. *circa diem* — «приблизно доба») **ритм** — ендогенні коливання ~ **24 год**, що тривають без зовнішніх сигналів.
- Експерименти в ізоляції (Мішель Сіфр у печері, 1962; Юрген Ашофф у бункері, 1960-ті) показали, що вільнобіжний період у людини **~ 24,2 год** (Чейслер, 1999: 24,18 год).
- Змінні, що **синхронізують** годинник з реальною добою (**zeitgeber**, «дарувальник часу»): **світло** (головний), їжа, фізична активність, температура, соціальні контакти.

### 6.2. Головний годинник: супрахіазматичне ядро (SCN)
- Розташоване в гіпоталамусі над перехрестом зорових нервів, ~ **20 000 нейронів**.
- **Світло → сітківка → ipRGC (внутрішньо світлочутливі гангліозні клітини з меланопсином, пік чутливості ~ 480 нм — блакитне світло, Провенсіо 1998, Берсон 2002) → ретиногіпоталамічний шлях → SCN.** Колбочки й палички не потрібні — навіть сліпі (без очей-формування зображення) можуть синхронізуватись.
- SCN — «диригент» періфірійних годинників у печінці, серці, м'язах, жирі тощо (вони є майже в кожній клітині).
- **Їжа** у вибраний час переналаштовує годинник печінки незалежно від SCN.

### 6.3. Молекулярний годинник
Автономна петля зворотного зв'язку в кожній клітині (~ 24 год):
```
CLOCK + BMAL1 ──► вмикають гени Per і Cry
                       │
        PER + CRY накопичуються (повільно)
                       │
        PER/CRY ──► гальмують CLOCK/BMAL1  (негативний зворотний зв'язок)
                       │
        PER/CRY деградують (CK1δ/ε фосфорилює PER) → цикл починається знову
```
- Відкриття: **Рональд Конопка і Сеймур Бензер (1971)** — мутанти мушки *Drosophila* з іншим періодом (ген *period*); **Голл, Росбаш, Янг (Нобель 2017)**. У хом'яків — мутація *tau* (Ральф і Менакер, 1988; CK1ε).
- Це ще один приклад **негативного зворотного зв'язку із затримкою** (`../homeostasis/`) — і саме затримка створює коливання.
- Приблизно **~ 40 %** (за деякими даними — більше) генів ссавців змінюють активність упродовж доби в якійсь тканині.

### 6.4. Мелатонін
- Синтезується **епіфізом** в темряві: триптофан → серотонін → N-ацетилсеротонін (фермент AANAT) → **мелатонін**. (Для метилювання потрібен **SAM**, тобто B9/B12/B6, `../cell/`.)
- Сигнал **ночі**, а не «снотворне»: початок виділення (**DLMO**, dim light melatonin onset) — за ~ 2–3 год до звичного сну; пік ~ 2–4 год ночі; різко пригнічується світлом (особливо блакитним).
- Вперше виділений Аароном Лернером (1958).
- Застосування: **низькі дози (0,3–3 мг)** за 2–4 год до бажаного сну зсувають фазу (джетлаг, зсув ритму); безпосередньо як снодійне — слабкий ефект. Висока доза не краща; у багатьох країнах добавки погано стандартизовані.

### 6.5. Крива реакції на фазу (PRC)
- **Світло ввечері й на початку ночі** → **затримує** (зсуває годинник пізніше).
- **Світло рано вранці** (після мінімуму температури) → **випереджає** (зсуває раніше).
- Мінімум температури ядра (CBTmin) припадає на ~ 2–3 год до звичного пробудження (~ 4–5 год ранку).
- **Мелатонін** має протилежну PRC.

### 6.6. Хронотип
- **Жайворонки / сови** — індивідуальна схильність (генетична частково: PER3, CRY1, CK1δ). Пік сов — пізній; у підлітків фізіологічний зсув у пізній бік (шкільні години, що починаються о 7:30, шкодять).
- **Синдром випередженої фази сну** (сімейний, мутація PER2 S662G) і **затриманої фази** (DSPS, поширений серед підлітків).
- **Соціальний джетлаг** — різниця між «робочим» і «вихідним» часом сну: пов'язаний із ризиком ожиріння, метаболічних порушень.

### 6.7. Джетлаг і змінна робота
- **Джетлаг:** годинник підлаштовується приблизно на **1 день на 1 годину зсуву на схід** і швидше на захід (подорож на схід важча: потрібно вкорочувати день). Допомагають: світло у вірний час, мелатонін, розклад їжі, поступовий зсув перед польотом.
- **Змінна робота** (особливо нічна) — зсув ритму, підвищений ризик метаболічних, серцево-судинних проблем, деяких видів раку (IARC: «ймовірно канцерогенна», група 2А).
- **Розлад змінної роботи** — безсоння/сонливість, пов'язана з графіком.

### 6.8. Інші біологічні ритми
| Ритм | Період | Приклад |
|---|---|---|
| **Ультрадіанний** | <24 год | цикл сну ~ 90 хв; пульсація гормонів; BRAC |
| **Циркадний** | ~24 год | сон, температура, кортизол, АТ |
| **Інфрадіанний** | >24 год | менструальний цикл (~ 28 днів), сезонні |
| **Циркадіанні температури** | ±0,5 °C | мінімум ~ 4–5 год ранку, максимум пізнього дня |

- Продуктивність і м'язова сила мають пік пізнього дня; серцево-судинні події частіше вранці (підйом кортизолу, АТ, агрегації тромбоцитів).
- **Хронотерапія** (прийом ліків у певний час) та **обмежене за часом харчування** — теми досліджень; докази поки змішані.

## 7. Навіщо потрібен сон

Сон виконує багато функцій, і всі вони — активні гіпотези з різним рівнем доказів:

| Функція | Суть | Рівень доказів |
|---|---|---|
| **Консолідація пам'яті** | N2 (веретена) і N3 (повільні хвилі) закріплюють декларативну пам'ять (факти) — діалог гіпокампу з корою; REM — емоційну і процедурну | Добрі (для декларативної) |
| **Синаптичний гомеостаз** (Тононі і Чирелі) | протягом дня синапси «пухнуть»; уночі «нормалізуються» (зменшуються), звільняючи ресурси для навчання | Помірні |
| **«Прибирання» (глимфатика)** | вимивання метаболітів, амілоїду | Помірні (дані з мишей, непрямі людські) |
| **Енергетика** | зниження обміну (~ 10–15 %) | Помірні |
| **Імунітет** | сон посилює відповідь на вакцини (при <6 год — слабша відповідь на грип/гепатит B); недосип збільшує ризик застуди (Коен, 2009: <7 год — у ~ 3 рази частіше) | Добрі |
| **Метаболізм** | недосип знижує чутливість до інсуліну; у 2004 р. Шпігель: два дні по 4 год сну → лептин −18 %, грелін +28 %, голод +24 % | Добрі |
| **Серце та судини** | нічне зниження АТ — захисне | Добрі |
| **Емоції** | REM «нейтралізує» емоційний заряд спогадів; недосип підвищує реактивність мигдалини (~ на 60 %, Вокер 2007) | Помірні |
| **Ріст і відновлення** | GH у N3, відновлення м'язів (`../muscle-heart/`) | Добрі |

## 8. Сни

- **Сни** найяскравіші в REM (будять із REM → сни у ~ 80 % випадків), але є й у NREM (менше емоційні, «думкоподібні»).
- Теорії:
  - **Фрейд (1899)** — виконання прихованих бажань (не підтверджено).
  - **Активація–синтез (Хобсон і Мак-Карлі, 1977)** — випадкова активація стовбура → кора будує історію.
  - **Консолідація та емоційна обробка пам'яті.**
  - **Симуляція загрози.**
- **Усвідомлені (лайсидні) сновидіння** — свідомість у REM; можливо тренування.
- **Кошмари** — в REM; **нічні жахи, сомнамбулізм** — у N3 (парасомнії), діти.
- Чому забуваємо: у REM низький норадреналін і гіпокампальна консолідація знижена, якщо не прокинутись.

## 9. Недосип

### 9.1. Кількісно
- 17–19 год неспання → когнітивні порушення, подібні до рівня алкоголю в крові **0,05 %**; 24 год → ~ **0,10 %** (Вільямсон і Фейєр, 2000).
- **Мікросни** (1–30 с) — небезпека за кермом.
- Хронічний недосип (<6 год) асоціюється з: підвищенням ризику гіпертензії, діабету 2 типу, ожиріння, депресії, серцево-судинних подій, інфекцій; зниженням уваги, працездатності, настрою.
- «Привчити себе до 5–6 год» — люди **відчувають**, що адаптувалися, але **об'єктивні показники продовжують погіршуватись** (Ван Донген, 2003).
- **Рекорди** безсоння — Ренді Гарднер, 1964, 264 год (11 днів) — не наслідувати. У щурів, позбавлених сну, смерть настає за 2–3 тижні (Рехтшаффен, 1989).
- **Фатальна сімейна безсонниця** — рідкісна пріонна хвороба (PRNP D178N), прогресивна втрата сну, смерть через місяці–роки.

### 9.2. Боргів не віддати
Можна частково «відіспатись» (повторний сон зсувається до N3/REM), але накопичений хронічний дефіцит повністю вихідними не компенсується.

### 9.3. Дрімоти
- 10–20 хв — освіжають; >30 хв — **інерція сну** (дезорієнтація 15–30 хв).
- Післяобідній спад — частково циркадний (подвійний пік сонливості: 2–4 год ночі та 13–15 год).

## 10. Розлади сну

| Розлад | Суть | Ключові моменти |
|---|---|---|
| **Інсомнія** | труднощі засинання/підтримки сну при достатніх умовах + денні наслідки; ≥ 3 ночі/тиждень ≥ 3 міс (хронічна) | **КПТ-I** (когнітивно-поведінкова терапія безсоння) — перша лінія, ефективніша за таблетки; етапи: контроль стимулів, обмеження сну, гігієна, релаксація |

| **Нарколепсія** | денні напади сну, катаплексія (раптова слабкість при емоціях), сонний параліч, галюцинації; втрата орексину (тип 1) | HLA-DQB1*06:02; лікування — модафініл, оксибат, ліки |

| **Парасомнії NREM** | сомнамбулізм, нічні жахи (N3) | діти, сімейні, провокують недосип, стрес |

| **Сонний параліч** | пробудження з атонією REM | короткі, нешкідливі, пов'язані з недосипом |
| **Гіперсомнії** | надмірний сон | ідіопатична та ін. |

### 10.1. ОАС: чому небезпечний
Повторні гіпоксемія + пробудження → симпатика ↑ → гіпертензія, аритмії, інсулінорезистентність, інсульт. Скринінг: шкала STOP-BANG. Діагноз — ПСГ або домашній тест.

## 13. Гігієна сну (докази)

1. **Режим:** однаковий час підйому щодня (включно з вихідними, ±1 год).
2. **Світло:** яскраве денне світло зранку (10–30 хв на вулиці); вечорами — приглушене; уникати яскравих екранів за 1–2 год, нічник — теплий і тьмяний.
3. **Спальня:** темна, тиха, прохолодна (**~ 16–19 °C**: падіння температури ядра полегшує засинання); ліжко — для сну.
4. **Кофеїн** — не пізніше ніж за 8 год до сну; алкоголь не допомагає.
5. **Вправи** — загалом покращують сон; інтенсивні — не за 1–2 год до сну для частини людей.
6. **Їжа** — не переїдати перед сном; не ходити голодним.
7. **Ритуал** — стабільні 30–60 хв розслаблення; не лежати без сну 20+ хв — встати, зайнятись спокійною справою.
8. **Годинник** — не дивитись на час, коли не спиться.
9. **Дрімота** — коротка (10–20 хв), до 15 год.
10. **Якщо проблеми >3 тижнів** — розмова з лікарем; перша лінія — КПТ-I.

## 15. Цікаві факти

- Людина проводить уві сні **приблизно третину життя** (близько 25–30 років).
- **Тепло і засинання:** перед сном падає температура ядра, а шкіра рук і ніг теплішає (розширення судин) — тому теплі стопи допомагають заснути.
- **Ефект першої ночі:** у новому місці одна півкуля (за даними Токіо, 2016 — ліва) спить легше, залишаючись «на варті».
- Тварини: **дельфіни** сплять одною півкулею; **кашалоти** сплять вертикально; **птахи-фрегати** можуть спати під час польоту; **слони** сплять ~ 2 год.
- Мозок уві сні не «вимикається»: у REM він споживає стільки ж енергії, як у неспанні, а в N3 — лише приблизно на 20–25 % менше.
- Розбудити лунатика не небезпечно, але краще м'яко повернути його в ліжко.
- Рідкісні варіанти генів *DEC2* (*BHLHE41*) та *ADRB1* пов'язані з **природним коротким сном** (~ 6 год) без видимих наслідків.

## 16. Типові помилки в розумінні

1. «Дорослому достатньо 5–6 год». Об'єктивно ефективність падає; відчуття звикання оманливе.
2. «Вихідними можна повністю відіспатись». Лише частково; соціальний джетлаг.
3. «Алкоголь допомагає спати». Допомагає засинути, але порушує сон.
4. «Мелатонін — снодійне». Він сигналізує про ніч; ефект зсуву фази.
5. «У REM мозок відпочиває». Він дуже активний; відпочиває тіло (м'язи).
6. «Сни бувають лише в REM». Бувають і в NREM.
7. «Кофеїн дає енергію». Лише блокує сигнал втоми (аденозин).
8. «Хропіння — нормальна дрібниця». Може бути ознакою ОАС.
9. «Блакитне світло — єдина проблема екранів». Важлива також яскравість, час і зміст.
10. «Снодійні — безпечне довготривале рішення». КПТ-I ефективніша і безпечніша.
11. «Зайвий сон шкідливий». Постійний сон >9 год асоціюється з хворобами, але частіше як наслідок хвороб (причинність неясна).

## 17. Шпаргалка

- **Сон:** NREM (N1, N2, N3) + REM; цикл ~ 90 хв; 4–6 циклів; N3 — на початку ночі, REM — під ранок. Частки: N1 5 %, N2 50 %, N3 20 %, REM 20–25 %.
- **ЕЕГ:** β 13–30, α 8–13, θ 4–7, δ 0,5–4 Гц; N2 — веретена + К-комплекси; REM — активна кора + атонія + рухи очей.
- **Потреба:** дорослі 7–9 год; підлітки 8–10; новонароджені 16–18.
- **Двопроцесова модель:** S (аденозин, δ-активність; τ нарост. 18 год, спад 4 год) + C (SCN).
- **Кофеїн:** антагоніст аденозину; T½ ~ 5 год; не пізніше ніж за 8 год до сну; ≤ 400 мг/добу.
- **Перемикач:** VLPO (ГАМК) ⇄ моноаміни (LC, шов, TMN); орексин стабілізує; REM-on/off в мосту.
- **Годинник:** SCN (~ 20 тис. нейронів); період ~ 24,2 год; ipRGC/меланопсин (~ 480 нм); CLOCK/BMAL1 → Per/Cry ⇝ гальмування; Нобель 2017.
- **Мелатонін:** епіфіз, ніч, DLMO за 2–3 год до сну; низькі дози (0,3–3 мг) зсувають фазу; світло ввечері затримує, вранці випереджає.
- **Функції:** пам'ять, синаптичний гомеостаз, глимфатика, імунітет, метаболізм (↓лептин, ↑грелін), емоції, GH.
- **Недосип:** 17–19 год ≈ 0,05 % алкоголю, 24 год ≈ 0,10 %; хронічний <6 год — ризики гіпертензії, діабету, депресії.
- **Розлади:** інсомнія (КПТ-I), ОАС (AHI, CPAP), RLS (залізо, ферритин), нарколепсія (орексин), RBD (→ синуклеїнопатії), парасомнії N3.
- **Речовини:** алкоголь порушує REM і фрагментує; бензо/Z — менше N3; нові — антагоністи орексину; B6 високі дози — яскраві сни.
- **Гігієна:** режим, ранкове світло, темно й прохолодно (16–19 °C), без кофеїну пізно, ритуал.
- **Історія:** Бергер 1924 → Азеринскі/Клейтман 1953 (REM) → Конопка/Бензер 1971 → Борбей 1982 → орексин 1998 → Нобель 2017.
