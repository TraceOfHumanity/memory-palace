# Словотвір (Word Formation)

Знаючи **префікси, суфікси та спосіб утворення слів**, можна з одного кореня отримати 4–5 слів. Це швидко збільшує словниковий запас і допомагає здогадуватись про незнайомі слова.

## 2. Префікси (змінюють значення, не частину мови)

| Префікс | Значення | Приклади |
| --- | --- | --- |
| **un-** | не, протилежність | happy → **un**happy, do → **un**do, lock → **un**lock |
| **in- / im- / il- / ir-** | не | possible → **im**possible, legal → **il**legal, regular → **ir**regular, correct → **in**correct |
| **dis-** | не, протилежність | agree → **dis**agree, like → **dis**like, appear → **dis**appear |
| **mis-** | неправильно | understand → **mis**understand, spell → **mis**spell |
| **re-** | знову | do → **re**do, write → **re**write, build → **re**build |
| **pre-** | до | pay → **pre**pay, history → **pre**history |
| **post-** | після | war → **post**war, graduate → **post**graduate |
| **over-** | занадто | eat → **over**eat, work → **over**work |
| **under-** | недостатньо | pay → **under**pay, estimate → **under**estimate |
| **out-** | перевершити | live → **out**live, run → **out**run |
| **inter-** | між | national → **inter**national, net → **inter**net |
| **sub-** | під | way → **sub**way, marine → **sub**marine |
| **super-** | над | market → **super**market |
| **semi- / half-** | напів | circle → **semi**circle |
| **anti-** | проти | war → **anti**war, social → **anti**social |
| **co-** | разом | operate → **co**operate, worker → **co**worker |
| **ex-** | колишній | wife → **ex**-wife |
| **bi- / tri- / multi-** | два / три / багато | cycle → **bi**cycle, **multi**national |
| **de-** | протилежна дія | frost → **de**frost, code → **de**code |
| **en- / em-** | зробити | large → **en**large, power → **em**power |
| **mid-** | середина | night → **mid**night |
| **non-** | не | stop → **non**-stop, fiction → **non**-fiction |

**Правило вибору заперечного префікса:** un- (найчастіший: unhappy), in- (перед m/p → im-: impossible; перед l → il-: illegal; перед r → ir-: irregular), dis- (disagree).

## 3. Конверсія (без змін): одне слово — різна частина мови
- **water** (n) — to water (v); **email** — to email; **text** — to text; **google** — to google
- **a visit** — to visit; **a drink** — to drink; **a walk** — to walk
- **Різний наголос:** **record** (n) / re**cord** (v); **present** / pre**sent**; **import / export**.

## 4. Складні слова (compound words)

| Тип | Приклади |
| --- | --- |
| іменник + іменник | **toothbrush**, **bookshop**, **airport**, **classroom** |
| прикметник + іменник | **blackboard**, **greenhouse**, **highway** |
| дієслово + іменник | **swimming pool**, **washing machine** |
| іменник + дієслово-ing | **ice-skating**, **film-making** |
| прикметник складний | **well-known**, **old-fashioned**, **good-looking**, **hard-working**, **five-year-old** |
| Разом / через дефіс / окремо | відповідно до словника: **homework**, **mother-in-law**, **post office** |

- Наголос на **першій частині**: **BLACKboard** (дошка) ↔ black **BOARD** (чорна дошка).
- Множина — на останній частині: bookshops; **виняток:** mothers-in-law, passers-by.

## 5. Скорочення та злиття
- **Абревіатури:** FAQ, ASAP (as soon as possible), CEO. Читаються по буквах.
- **Акроніми:** NASA /ˈnæsə/, laser.
- **Blends:** brunch (breakfast + lunch), motel (motor + hotel), smog (smoke + fog), internet.
- **Clipping:** photo (photograph), phone, gym, exam, ad.
- **Backformation:** edit (з editor), enthuse (з enthusiasm).

## 6. Як користуватись словотвором

1. **Розкладай** слово: *unbelievable* = un + believe + able.
2. **Знаючи корінь + суфікс**, здогадайся про частину мови: *-ness* → іменник, *-ly* → прислівник.
3. **Вчи сім'ю слів**: create → creation, creative, creator, creatively, recreate.
4. **Перевір правопис** при додаванні:
   - німа **-e** зникає перед голосним суфіксом: create → creative, make → making. (Але **-ful, -less, -ment** не змінюють: hope**ful**.)
   - **-y → -i**: happy → happiness, beauty → beautiful.
   - **подвоєння**: big → bigger, begin → beginning.
   - **-ly**: true → truly (e зникає), but: complete → completely.
5. **Вчи сімейство** разом з наголосом: *PHOtograph* — *phoTOgrapher* — *photoGRAPHic*.

## 7. Типові помилки

| ❌ Неправильно | ✅ Правильно | Чому |
| --- | --- | --- |
| unpossible | impossible | im- перед p |
| unlegal | illegal | il- перед l |
| incorrect → uncorrect | incorrect | in- |
| carefull | careful | -ful з одним l |
| happyness | happiness | y → i |
| beutiful | beautiful | правопис |

> **Різні значення за суфіксом:** economic (економічний) / economical (ощадливий); historic (знаменний) / historical (історичний); sensible (розумний) / sensitive (чутливий); childish (по-дитячому, погано) / childlike (як дитина, добре).

---

## 8. Алгоритм

1. Побач незнайоме слово → **розбий на префікс + корінь + суфікс**.
2. **Суфікс** → частина мови (-tion, -ness, -ity — іменник; -ful, -able, -ous — прикметник; -ize, -ify — дієслово; -ly — прислівник).
3. **Префікс** → зміна значення (un-, dis-, re-, over-, under-).
4. Вчи **родину слів**, а не одне слово.
5. Звертай увагу на **зміни правопису** та **наголос**.

---

## 9. Вправи

1. Утворіть іменник: create, happy, teach, decide, free.
2. Утворіть прикметник: care, danger, use, nation, rain.
3. Додайте префікс: possible, legal, agree, regular, do.
4. Знайдіть помилку: unpossible / carefull / happyness.
5. Складіть складне слово: tooth + brush, black + board, five + year + old.

**Відповіді:**
1. creation, happiness, teacher, decision, freedom
2. careful, dangerous, useful, national, rainy
3. impossible, illegal, disagree, irregular, undo
4. impossible / careful / happiness
5. toothbrush, blackboard, five-year-old
