Present Continuous використовується, коли ми говоримо про дію або процес, який триває зараз або в поточний період, описує тимчасову ситуацію чи процес зміни.

### Формула звмчайного ресення:
Subject + am/is/are + verb-ing

### Заперечення:
Subject + am/is/are + not + verb-ing

### Питання:
am/is/are + subject + verb-ing?

### Формування закінчення слів
1. Базове правило: V1 + ing → V-ing
2. Якщо дієслово закінчується на глухе `e` (make, write, write) то кінцеву німу `e` зазвичай прибираємо, а потім додаємо `-ing`.
    make → making
    write → writing
    take → taking
    use → using
    come → coming

Але якщо останнє `e` не є глухою то її не потрібно прибирати: `see → seeing`
3. Якщо сломо закінчується на наголошений склад приголосний + голосний + приголосний (C  V  C) то остання приголосна подвоюʼться.
    sit → sitting
    stop → stopping
    swim → swimming
    get → getting
    put → putting

Але open не підходить під ню умову, тому що наголос на першу букву `o` тому `open → opening` без подвоєння.

4. Дієслова на y не змінюються як у Present Simple, а просто додають `-ing`.
    play → playing
    enjoy → enjoying
    worry → worrying
    try → trying
    study → studying
    visit → visiting
    watch → watching
    wash → washing
    go → going
    come → coming

5. Дієслова на `ie`.
    lie → lying
    die → dying
    tie → tying

    ie → y + ing

### Зміни
Present Continuous також дуже часто використовується, коли ми говоримо про процес зміни, який відбувається зараз.
The weather is getting colder.
Your English is improving.
The robot is getting faster.
Technology is changing quickly.
