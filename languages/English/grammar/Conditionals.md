# Умовні речення (Conditionals)

Умовне речення складається з **двох частин**: **умова** (if-clause) і **наслідок** (main clause). Тип речення залежить від **реальності** умови і **часу**.

> Головне правило: **після if не ставимо will / would** (крім ввічливих прохань). Час в if-частині «зсунутий» назад: Present → про майбутнє; Past → про теперішнє; Past Perfect → про минуле.

Порядок частин вільний. Якщо **if-частина на початку — ставимо кому**, в кінці — без коми:
If it rains, we will stay home. = We will stay home if it rains.

---

## 1. Zero Conditional — факти й закони

**If + Present Simple, Present Simple**
If you heat water to 100°C, it boils.
If I drink coffee at night, I can't sleep.
Plants die if they don't get water.
Замість if можна **when**: When you heat ice, it melts.

---

## 2. First Conditional — реальна ситуація в майбутньому

**If + Present Simple, will + V1**
If it rains tomorrow, we will stay at home.
If you study, you will pass the exam.
I will call you if I have time.
What will you do if you miss the train?

У головній частині можна: **can, may, might, should, imperative**:
If you see him, tell him to call me.
If it's sunny, we might go to the beach.

> ❌ If it will rain, we will stay. ✅ If it **rains**, we will stay.
> **Після when, as soon as, before, after, until, by the time — теж Present Simple**, а не will: I'll call you when I arrive.

### unless, as long as, provided, in case
- **unless = if … not**: Unless you hurry, you will be late. (If you don't hurry…) — після unless **не** ставимо not.
- **as long as / provided (that) / so long as** — «за умови, що»: You can go out as long as you finish your homework.
- **in case** — «на випадок»: Take an umbrella in case it rains. (не «if it rains» — це різне: in case = на випадок; if = якщо станеться).

---

## 3. Second Conditional — нереальна (малоймовірна) ситуація зараз/в майбутньому

**If + Past Simple, would + V1**
If I had a million dollars, I would buy a house.
If I were you, I would apologize.
What would you do if you won the lottery?
If he knew the answer, he would tell us.

- Past Simple тут не про минуле, а про **нереальність**.
- **were для всіх осіб** (формально): If I **were** you… If he **were** here… (в розмові допускається was: If I was you).
- **If I were you, I would…** — фразова порада.
- У головній можна: **could, might**: If I had money, I could buy it. (зміг би) If it stopped, we might go out.

---

## 4. Third Conditional — нереальне минуле

**If + Past Perfect, would have + V3**
If I had known, I would have helped you. (але я не знав)
If she had studied, she would have passed. (але не вчилась)
What would you have done if you had missed the plane?

- Говоримо про те, що **могло би бути, але не було**; **змінити вже не можна**; часто — жаль чи критика.
- У головній: **could have, might have, should have**: If I had left earlier, I could have caught the train.

---

## 5. Mixed Conditionals — змішані

### Минула причина → теперішній наслідок
**If + Past Perfect, would + V1**
If I had studied medicine, I would be a doctor now. (не вчився → не лікар зараз)
If you had told me, I would know. 

### Теперішня умова → минулий наслідок
**If + Past Simple, would have + V3**
If I were a better driver, I would have avoided the accident.
If she wasn't so shy, she would have said something.

---

## 6. Підсумкова таблиця

| Тип | Реальність | If-частина | Головна частина | Приклад |
| --- | --- | --- | --- | --- |
| **Zero** | завжди | Present Simple | Present Simple | If you heat ice, it melts. |
| **1st** | реальна, майбутнє | Present Simple | will + V1 | If it rains, I will stay. |
| **2nd** | нереальна, зараз / майбутнє | Past Simple | would + V1 | If I were rich, I would travel. |
| **3rd** | нереальна, минуле | Past Perfect | would have + V3 | If I had known, I would have come. |
| **Mixed 1** | минула причина → тепер | Past Perfect | would + V1 | If I had left, I would be there now. |
| **Mixed 2** | теперішня умова → минуле | Past Simple | would have + V3 | If I were smart, I would have won. |

---

## 7. Бажання (wish / if only)

| Про що | Структура | Приклад |
| --- | --- | --- |
| **Теперішнє** (шкода, що не так) | wish + **Past Simple** | I wish I had a car. (шкода, що нема) · I wish I were taller. |
| **Минуле** (шкода, що було так) | wish + **Past Perfect** | I wish I had studied. (шкодую) |
| **Дратівливе / майбутнє** (хотів би, щоб змінилося) | wish + **would + V1** | I wish he would stop smoking. |

**If only** = сильніше wish: If only I knew! If only I had listened!
**I'd rather** + Past Simple (про інших): I'd rather you stayed. · **It's time** + Past Simple: It's time we left.

---

## 8. Інверсія (формальний стиль, без if)

| Звичайне | З інверсією |
| --- | --- |
| If I were you… | **Were I** you… |
| If I had known… | **Had I** known… |
| If you should need help… | **Should you** need help… |

Had I known, I would have come. = If I had known, I would have come.

---

## 9. Інші сполучники умови
**otherwise** (інакше): Hurry up, otherwise you'll be late.
**what if** (а що, якщо…): What if it rains?
**suppose / supposing**: Suppose he comes, what will you say?
**provided, providing, as long as, on condition that.**
**if not = unless**; **even if** (навіть якщо) vs **if**; **only if** (тільки якщо): You can go only if you finish.

---

## 10. Типові помилки

| ❌ Неправильно | ✅ Правильно | Чому |
| --- | --- | --- |
| If it will rain, we will stay. | If it rains, we will stay. | після if — Present Simple |
| If I would have time, I would come. | If I had time, I would come. | would не в if-частині |
| If I had known, I will help. | If I had known, I would have helped. | узгодження 3-го типу |
| If I was you, I … | If I were you, I … | were для всіх (формально) |
| If I have money, I would buy. | If I had money, I would buy. | змішання типів |
| Unless you don't hurry… | Unless you hurry… | unless вже заперечення |
| I'll call you when I will arrive. | I'll call you when I arrive. | when → Present Simple |
| If I knew, I would have come. | If I had known, I would have come. | 3-й тип: Past Perfect |
| In case it will rain… | In case it rains… | Present Simple |
| If he came, I would be happy (він прийде). | If he comes, I will be happy. | реальна ситуація — 1-й тип |

---

## 11. Алгоритм вибору типу

1. Це **завжди / закон природи**? → **Zero** (Present + Present).
2. **Реальна** можливість у майбутньому? → **1st** (Present Simple + will).
3. **Малоймовірна / вигадана** ситуація зараз чи в майбутньому? → **2nd** (Past Simple + would).
4. Про **минуле**, якого вже не змінити? → **3rd** (Past Perfect + would have V3).
5. Минуле впливає на **теперішнє** → **Mixed 1**; теперішня властивість → минуле → **Mixed 2**.
6. Перевір: **після if — ніколи will / would**. Кома, якщо if на початку.
7. Для «шкода, що…» → **wish**.

---

## 12. Вправи

1. Вставте форму: If it (rain), we (stay). / If I (be) you, I (apologize). / If she (study), she (pass).
2. Тип: If I had a car, I would drive. / If you heat ice, it melts. / If I had known, I would have come.
3. Знайдіть помилку: If it will rain, we stay. / If I would have time, I'd come. / Unless you don't hurry, you'll be late.
4. Перекладіть: «Якби я був тобою, я б зателефонував». «Якби я знав, я б допоміг». «Шкода, що в мене нема часу».

**Відповіді:**
1. rains, will stay; were, would apologize; had studied, would have passed
2. 2nd; Zero; 3rd
3. If it rains, we will stay. / If I had time, I'd come. / Unless you hurry, you'll be late.
4. If I were you, I would call. / If I had known, I would have helped. / I wish I had time.
