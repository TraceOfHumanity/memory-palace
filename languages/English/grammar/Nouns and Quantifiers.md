# Іменники та кількісні слова (Nouns and Quantifiers)

## 1. Злічувані та незлічувані

| | Злічувані (countable) | Незлічувані (uncountable) |
| --- | --- | --- |
| Що | можна порахувати: one book, two books | не можна: water, money |
| Артикль | a/an, the, множина без артикля | the або нуль (без a/an) |
| Множина | є: books | **нема** |
| Дієслово | is / are | **is** (однина) |
| Питання «скільки» | **How many**? | **How much**? |

**Типові незлічувані:** water, milk, coffee, tea, bread, rice, sugar, money, time, information, advice, news, furniture, luggage, music, weather, work, knowledge, traffic, homework, progress, equipment, hair, jewellery.

> ❌ a furniture / informations / advices / the news are bad. ✅ some furniture, some information, a piece of advice, the news **is** bad.
> Незлічуване рахуємо **одиницями**: a **piece** of advice, a **glass** of water, a **cup** of coffee, a **loaf** of bread, a **slice** of cake, **two bottles** of water.

### Подвійна природа
I like **coffee**. (незл.) — Two **coffees**, please. (= чашки) · **Paper** (папір) — a **paper** (стаття/газета) · **Hair** (волосся) — a **hair** (волосина).

## 2. Множина іменників

| Правило | Приклад |
| --- | --- |
| більшість: +s | book → books, car → cars |
| після s, x, z, ch, sh: +es | bus → buses, box → boxes, watch → watches, dish → dishes |
| приголосна + y → ies | city → cities, baby → babies |
| голосна + y: +s | boy → boys, key → keys |
| -f / -fe → -ves | leaf → leaves, wife → wives, knife → knives, life → lives (але: roof → roofs, chef → chefs) |
| приголосна + o: +es (іноді +s) | tomato → tomatoes, hero → heroes; photo → photos, piano → pianos |
| **Неправильні** | man → men, woman → women, child → children, foot → feet, tooth → teeth, mouse → mice, person → people |
| **Не змінюються** | sheep, fish, deer, series, species, aircraft |
| Лише множина | trousers, jeans, scissors, glasses, clothes, people, police |
| -s, але однина | news, mathematics, physics, economics, politics, athletics |
| З латини/грецької | analysis → analyses, crisis → crises, phenomenon → phenomena, criterion → criteria, datum → data |

> **people, police, clothes** — множина: The police **are** here. **Staff / family / team** (BrE) — можуть бути і однина, і множина.

## 3. Присвійний відмінок ('s)

- Одна особа: **'s** — my brother's car, Anna's book.
- Множина на -s: **'** — the girls' room, the students' books.
- Неправильна множина: **'s** — the children's toys, the men's room.
- Імена на -s: James's book / James' book (обидва).
- Речі — **of**: the door **of** the room, the end **of** the film (а не «the room's door»).
- Час/відстань/вартість: today's news, a week's holiday, a mile's walk.
- Подвійна форма: a friend **of mine**; **Mary's** is better (її/її; без іменника): at the doctor's, at Mary's.

## 4. Кількісні слова (quantifiers)

| Слово | З чим | Приклади |
| --- | --- | --- |
| **some** | ствердження (злічув. множ. і незлічув.) | I have some friends. I need some water. |
| **any** | питання, заперечення | Do you have any questions? I don't have any money. |
| **no** | = not any | I have no time. |
| **a lot of / lots of** | обидва типи, ствердження | a lot of friends, a lot of money |
| **many** | злічувані множина (питання, заперечення) | How many books? I don't have many friends. |
| **much** | незлічувані (питання, заперечення) | How much time? I don't have much money. |
| **(a) few** | злічувані: **a few** = кілька (позитивно), **few** = мало (негативно) | I have a few friends. Few people came. |
| **(a) little** | незлічувані: **a little** = трохи, **little** = мало | I have a little time. There is little hope. |
| **plenty of** | багато, достатньо | plenty of time |
| **enough** | достатньо (перед іменником, після прикметника) | enough money; old enough |
| **too much / too many** | занадто | too much sugar, too many cars |
| **all, most, some, none** + of | all of them, most of the people, none of us | |
| **every, each** | кожен, однина | every day, each student |
| **both, either, neither** | обидва, будь-який, жоден (з двох) | both parents, neither of them |
| **another / other / others** | ще один / інші | another cup, other people, the others |

### some / any — додаткові правила
- **some** у питаннях-пропозиціях/проханнях: Would you like **some** tea? Can I have **some** water?
- **any** у ствердженнях = «будь-який»: You can take **any** book.
- **something / anything / nothing / everything**, **somebody / anybody / nobody / everybody**, **somewhere…** — за тими ж правилами.

### much / many у ствердженнях
У ствердженнях краще **a lot of**: ❌ I have much money. ✅ I have **a lot of** money. (**much / many** — ствердження лише з too, so, as: so much, too many).

### few / a few; little / a little — зміна значення
I have **a few** friends. (є кілька → добре) · I have **few** friends. (майже нема → сумно)
I have **a little** time. (є трохи) · I have **little** time. (майже нема)

## 5. Типові помилки

| ❌ Неправильно | ✅ Правильно | Чому |
| --- | --- | --- |
| informations, advices | information, advice | незлічувані |
| a furniture | a piece of furniture | незлічуване |
| The news are good. | The news is good. | однина |
| How many money? | How much money? | money — незлічуване |
| How much books? | How many books? | books — злічувані |
| I have much friends. | I have a lot of friends. | much у ствердженні |
| I have a few money. | I have a little money. / some money | незлічуване |
| I have few friends. (хотів сказати «кілька») | I have a few friends. | few = майже нема |
| childs, mans, foots | children, men, feet | неправильні |
| the door's room | the door of the room | of з речами |
| peoples | people | вже множина |
| I don't have some money. | I don't have any money. | any у запереченні |
| Everybody are here. | Everybody is here. | однина |

---

## 6. Алгоритм вибору кількісного слова

1. Іменник **злічуваний чи ні**? (Можна порахувати «один, два»?)
2. **Злічуваний множина:** many / a few / few / a lot of / several.
3. **Незлічуваний:** much / a little / little / a lot of / plenty of.
4. **Ствердження:** some / a lot of; **питання/заперечення:** any / many / much.
5. Чи кількість **позитивна** («є кілька») чи **негативна** («майже нема»)? → a few / a little чи few / little.
6. Не забудь: незлічуване = **is**, і **одиниця виміру** (a piece of, a cup of).

## 7. Вправи

1. Злічуване чи ні: advice, furniture, apple, news, water, car.
2. much / many / a lot of: How ___ people came? / I don't have ___ money. / She has ___ friends.
3. few / a few / little / a little: I have ___ friends (кілька). / There is ___ hope (майже нема).
4. Множина: child, wife, city, tomato, sheep, person.
5. Знайдіть помилку: I have many informations. / The news are bad. / How much books?

**Відповіді:**
1. незл., незл., злічув., незл., незл., злічув.
2. many; much; a lot of
3. a few; little
4. children, wives, cities, tomatoes, sheep, people
5. I have a lot of information. / The news is bad. / How many books?
