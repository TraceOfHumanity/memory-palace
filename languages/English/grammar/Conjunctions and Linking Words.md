# Сполучники та сполучні слова (Linking Words)

Сполучники й сполучні слова **пов'язують частини речення і думки**, роблять мову логічною.

## 1. Сурядні сполучники (FANBOYS) — з'єднують рівні частини
**F**or (бо), **A**nd (і), **N**or (і не), **B**ut (але), **O**r (або), **Y**et (проте), **S**o (тому).
- Перед сполучником між двома повними реченнями — **кома**: I was tired, **but** I kept working. She studied hard, **so** she passed.
- Однорідні члени — без коми: tea **and** coffee. (в переліку — Oxford comma: apples, oranges, **and** bananas.)
- **and** (додавання), **but / yet** (протилежність), **or** (вибір), **so** (наслідок), **for** (причина; формально).
- **both … and**, **either … or**, **neither … nor**, **not only … but also**: He is **both** smart **and** kind. **Neither** he **nor** she knows.

---

## 2. Підрядні сполучники

| Значення | Сполучники | Приклад |
| --- | --- | --- |
| **Час** | when, while, as, before, after, until, since, as soon as, once, by the time | I'll call you **when** I arrive. |
| **Причина** | because, since, as | I stayed home **because** I was ill. |
| **Мета** | so that, in order to, to | He studies **so that** he can pass. |
| **Умова** | if, unless, as long as, provided that, in case | **If** you study, you'll pass. |
| **Протиставлення** | although, though, even though, whereas, while | **Although** it rained, we went out. |
| **Наслідок** | so … that, such … that | It was **so** cold **that** we stayed home. |
| **Порівняння / спосіб** | as, like, as if, as though | She looks **as if** she is tired. |

> **Після when / while / before / after / until / as soon as / if (про майбутнє) — Present Simple**, не will.
> **Не** ставимо **but** разом з although: ❌ Although it rained, but we went. ✅ **Although** it rained, we went. / It rained, **but** we went.

---

## 3. Сполучні слова (linking words) за функціями

### Додавання
**and, also, too, as well, in addition, moreover, furthermore, besides, what is more.**
She is smart. **Moreover**, she is kind.

### Протиставлення
**but, however, yet, nevertheless, on the other hand, in contrast, whereas, while, although, even though, despite, in spite of.**
- **although / though / even though + підмет + дієслово**: **Although** he was tired, he worked.
- **despite / in spite of + іменник / V-ing**: **Despite** the rain, we went out. **Despite** being tired…
- **however** (на початку, з комою): It was cheap. **However**, I didn't buy it.
- **whereas / while** — контраст між двома: He is tall, **whereas** she is short.

### Причина та наслідок
**because / since / as** (причина) · **because of / due to / owing to + іменник** · **so / therefore / consequently / as a result / thus** (наслідок).
**because** + підмет + дієслово: I stayed because I was ill. · **because of** + іменник: because **of** the rain.
It rained, **so** we stayed home. / It rained. **Therefore**, we stayed home.

### Мета
**to + V1 · in order to · so as to · so that + clause**: He works hard **so that** he can buy a house.

### Приклад та пояснення
**for example, for instance, such as, namely, in other words, that is.**

### Послідовність
**first(ly), second(ly), then, next, after that, finally, at last, in the end, eventually, meanwhile.**

### Підсумок
**in conclusion, to sum up, overall, in short, all in all, to conclude.**

### Уточнення й емфаза
**in fact, actually, indeed, especially, in particular, of course, obviously.**

## 4. Різниця між схожими

| Пара | Різниця |
| --- | --- |
| **because / because of** | because + речення; because of + іменник |
| **although / despite** | although + підмет-дієслово; despite + іменник / V-ing |
| **so / such** | so + adj; such + (a) + adj + noun |
| **while / during** | while + підмет-дієслово; during + іменник |
| **in case / if** | in case — на випадок; if — якщо станеться |
| **as / like** | as — у ролі; like — подібно: He works **as** a teacher. He sings **like** a bird. |
| **so / therefore / however** | so — розмовне; therefore, however — формальне, з комою |
| **when / while** | when — момент; while — процес |

---

## 5. Розділові знаки зі сполучними словами
- **however, therefore, moreover** на початку — **кома** після: **However,** I disagree. Або крапка з комою перед: It was cheap; **however,** I didn't buy it.
- **Підрядна на початку** → кома: **Although** it rained, we went out. В кінці — без коми: We went out although it rained.
- Перед **and / but / or / so** між двома повними реченнями — кома.

---

## 6. Типові помилки

| ❌ Неправильно | ✅ Правильно | Чому |
| --- | --- | --- |
| Although it rained, but we went. | Although it rained, we went. | не але + although |
| Despite it rained… | Despite the rain / Although it rained | despite + іменник |
| Because the rain, we stayed. | Because of the rain… | because of + іменник |
| I'll call when I will arrive. | …when I arrive. | Present Simple |
| He works as hard like me. | He works as hard as me. | as … as |
| She looks like she is tired. (формально) | …as if she were tired. | as if |
| I don't know if will he come. | …if he will come / whether he will come. | прямий порядок |
| both Tom or Mary | both Tom and Mary | both … and |
| Neither he doesn't know | Neither he nor she knows | neither … nor |

---

## 7. Алгоритм

1. **Яка логіка** між частинами? Додавання / протиставлення / причина / наслідок / мета / умова / час.
2. Обери **сполучник** за логікою (див. таблицю).
3. **Після сполучника що йде?** Речення (although, because, while) чи іменник / V-ing (despite, because of, during)?
4. **Розділові знаки:** підрядна на початку — кома; however — кома після.
5. **Час (майбутнє) після when/if/as soon as** — Present Simple.
6. Не ставь **but** разом із **although**.

---

## 8. Вправи

1. although / despite: ___ the rain, we went out. / ___ it rained, we went out.
2. because / because of: We stayed home ___ the rain. / We stayed home ___ it rained.
3. so / such: It was ___ a nice day. / The day was ___ nice.
4. Знайдіть помилку: Although it rained, but we went. / Despite it rained… / Because the rain…
5. Перекладіть: «Хоча було холодно, ми пішли». «Він працює, щоб купити будинок». «Однак я не погоджуюсь».

**Відповіді:**
1. Despite; Although
2. because of; because
3. such; so
4. Although it rained, we went. / Despite the rain… / Because of the rain…
5. Although it was cold, we went. / He works so that he can buy a house. / However, I disagree.
