# Степеневі функції

**Степенева функція** — y = xⁿ (або загальніше y = x^p з будь-яким дійсним показником p). Змінна стоїть в **основі**, показник фіксований. Цим вона відрізняється від показникової функції y = aˣ, де змінна — у показнику (див. [[Показникова функція]]).

Степеневі функції — це «родина» з кількох характерних форм: парабол, кубічних парабол, гіпербол і коренів. Вони описують закони масштабу: площа зростає як квадрат розміру, об'єм — як куб, сила тяжіння спадає як 1/r², період планети ∝ a^(3/2).

Пов'язані нотатки: [[Функції]], [[Степені з цілим показником]], [[Корінь n-го степеня і дробові показники]], [[Квадратична функція]], [[Найважливіші графіки]], [[Похідна]], [[Математика — зміст]].

## 1. Чотири сім'ї графіків

| Показник | Приклади | Форма | Парність | D | E |
|---|---|---|---|---|---|
| **n парне натуральне** | x², x⁴, x⁶ | «чаша» | парна | ℝ | [0; +∞) |
| **n непарне натуральне** | x, x³, x⁵ | «S»-крива через 0 | непарна | ℝ | ℝ |
| **n = −1, −3, …** (непарне від'ємне) | 1/x, 1/x³ | гіпербола в I і III чвертях | непарна | x ≠ 0 | y ≠ 0 |
| **n = −2, −4, …** (парне від'ємне) | 1/x², 1/x⁴ | «вулкан» у I і II чвертях | парна | x ≠ 0 | (0; +∞) |
| **p = 1/n** (корені) | √x, ∛x | «лежача» півпарабола | — / непарна | [0; +∞) або ℝ | [0; +∞) або ℝ |

**Всі графіки y = xⁿ проходять через (1; 1).** Бо 1ⁿ = 1 для будь-якого n. Для x > 0 вони всі «віялом» розходяться з цієї точки.

## 2. Кілька способів зрозуміти степеневу функцію

| Модель | Приклад |
|---|---|
| **Масштабування** | збільшимо розмір у k разів — площа зросте в k² разів, об'єм у k³ |
| **Закон «обернених квадратів»** | світло, звук, гравітація на відстані r ∝ 1/r²: удвічі далі — учетверо слабше |
| **Обернена пропорційність** | y = k/x: час дороги при сталій відстані, кількість робітників і час роботи |
| **Обернені функції** | √x обертає x², ∛x обертає x³ |
| **Лінія на логарифмічному папері** | y = x^p ⇒ log y = p·log x — пряма з нахилом p (див. [[Логарифми]]) |

**Чому парність показника дає парність функції:** (−x)ⁿ = (−1)ⁿxⁿ. При парному n множник (−1)ⁿ = 1 — значення однакові для x і −x. При непарному — протилежні.

## 3. Як степінь впливає на форму

### 3.1. Порівняння x, x², x³ (x > 0)

| x | 0,5 | 1 | 2 | 3 |
|---|---|---|---|---|
| x | 0,5 | 1 | 2 | 3 |
| x² | 0,25 | 1 | 4 | 9 |
| x³ | 0,125 | 1 | 8 | 27 |

- **На (0; 1)** більший показник — **менше** значення: число, менше за 1, при множенні на себе зменшується.
- **При x > 1** більший показник — **більше** значення і швидше зростання.
- Тому біля нуля x⁴ «пласкіша» за x², а далеко — значно крутіша.

### 3.2. Гіпербола y = k/x

- **Асимптоти:** x = 0 і y = 0. Чим ближче x до 0, тим більше |y|; чим більше |x|, тим ближче y до 0.
- k > 0 — гілки в I і III чвертях, функція спадає на кожному проміжку (−∞; 0) і (0; +∞). **Не** «спадає на всій області»: −1 < 1, але 1/(−1) < 1/1.
- k < 0 — гілки в II і IV чвертях.
- **xy = k** — площа прямокутника під будь-якою точкою гіперболи стала. Звідси обернена пропорційність: подвоїли x — y зменшилось удвічі.

```
 y
 │ *
 │  \
 │   `*._
 │       ``*----____  y = 1/x
 ┼──────────────────► x
 ─────____
          ``--*._
                 `*
                   \
                    *  (III чверть)
```

**Зсунута гіпербола:** y = k/(x − m) + n має асимптоти x = m і y = n. Будь-який дріб (ax + b)/(cx + d) зводиться до такого виду виділенням цілої частини (див. [[Алгебраїчні дроби]]).

### 3.3. Корені

- y = √x — верхня половина параболи, «покладеної на бік»: x = y², y ≥ 0. D = E = [0; +∞), зростає, сповільнюючись.
- y = ∛x — обернена до x³; визначена на всій прямій, непарна, у нулі вертикальна дотична.

**Чому √x зростає повільно:** щоб √x збільшилося на 1 (з 10 до 11), x має зрости з 100 до 121 — на 21.

## 4. Монотонність і нерівності

| Функція | Поведінка при x > 0 | Наслідок |
|---|---|---|
| xⁿ, n > 0 | зростає | 0 < a < b ⇒ aⁿ < bⁿ — можна підносити нерівності з додатними частинами до степеня |
| xⁿ, n < 0 | спадає | 0 < a < b ⇒ 1/a > 1/b — при «перевертанні» знак змінюється |

**Порівняння:** що більше, 2^(1/2) чи 3^(1/3)? Піднесемо до 6-го степеня: 2³ = 8 і 3² = 9 ⇒ 3^(1/3) більше.

## 5. Перетворення і задачі

- y = (x − 2)³ + 1 — кубічна парабола з «центром» у (2; 1).
- y = √(x + 4) − 3 — корінь, що починається в (−4; −3).
- y = 2/(x + 1) — гіпербола з асимптотами x = −1 і y = 0.

**Задача:** при яких x справджується x³ > x? x³ − x = x(x − 1)(x + 1) > 0 ⇒ (−1; 0) ∪ (1; +∞) (див. [[Квадратні нерівності і метод інтервалів]]). Графічно: кубічна парабола вище прямої y = x саме там.

## 6. Закони масштабу (алометрія)

- Якщо збільшити всі розміри тварини в 2 рази, маса (об'єм) зросте у 8 разів, а переріз кісток (площа) — лише в 4. Кістки мусять бути непропорційно товщими. Тому слон не схожий на збільшену мишу, а мурахи можуть піднімати вагу, у десятки разів більшу за власну.
- Інтенсивність світла на відстані r: I ∝ 1/r². Лампа вдвічі далі — учетверо тьмяніша.
- Третій закон Кеплера: T ∝ a^(3/2). Планета вчетверо далі від Сонця має рік у 8 разів довший.
- Опір повітря при великій швидкості ∝ v², потужність на його подолання ∝ v³: удвічі швидше — увосьмеро більша потужність.

## 7. Типові помилки

| Помилка | Правильно |
|---|---|
| x³ — парна, бо «x у степені» | непарна: (−x)³ = −x³ |
| 1/x спадає на всій області | на кожному проміжку окремо |
| На (0; 1) x² > x | x² < x |
| Плутати x² і 2ˣ | степенева vs показникова |
| √x визначена при x = −4 | лише x ≥ 0 |
| ∛(−8) не існує | = −2 |
| 1/x² < 0 при x < 0 | 1/x² > 0 завжди |
