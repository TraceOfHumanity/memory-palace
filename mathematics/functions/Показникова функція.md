# Показникова функція

**Показникова (експоненційна) функція** — y = aˣ, де основа a > 0, a ≠ 1, а змінна стоїть **у показнику**. Це модель **сталого відносного зростання**: за кожну одиницю часу величина множиться на одне й те саме число a. Відсотки на вклад, розмноження бактерій, поширення епідемії на початку, радіоактивний розпад, охолодження чаю, падіння атмосферного тиску з висотою — усе це показникові функції.

Пов'язані нотатки: [[Степені з цілим показником]], [[Корінь n-го степеня і дробові показники]], [[Зміна у відсотках і складні відсотки]], [[Прогресії]], [[Логарифми]], [[Ряди і число e]], [[Степеневі функції]], [[Математика — зміст]].

## 1. Лінійне і показникове зростання

| Крок | Лінійне (+2) | Показникове (·2) |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 3 | 2 |
| 2 | 5 | 4 |
| 5 | 11 | 32 |
| 10 | 21 | 1024 |
| 20 | 41 | 1 048 576 |
| 30 | 61 | ≈ 1,07·10⁹ |

- **Лінійне:** однаковий **приріст** за однаковий час (+2).
- **Показникове:** однакове **відношення** за однаковий час (·2), тобто однаковий відсоток приросту.

Спочатку показникове може відставати, але **згодом обганяє будь-яку лінійну і навіть будь-яку степеневу функцію**. Людська інтуїція «лінійна», тому показникові процеси (складні відсотки, епідемії, борги) постійно нас дивують.

**Аркуш паперу** завтовшки 0,1 мм, складений навпіл 42 рази, мав би товщину 0,1·2⁴² мм ≈ 440 000 км — більше, ніж відстань до Місяця.

## 2. Кілька способів зрозуміти aˣ

| Модель | Що означає 2ˣ |
|---|---|
| **Повторне множення** | 2³ = 2·2·2 — для натуральних x |
| **Подвоєння** | скільки разів величина подвоїлася за x періодів |
| **Геометрична прогресія з «неперервним» номером** | bₙ = b₁qⁿ⁻¹, тільки x — будь-яке дійсне |
| **Множник за час** | aˣ⁺ʸ = aˣ·aʸ: зростання за час x + y — добуток зростань за x і за y |
| **Обернена до логарифма** | 2ˣ = 8 ⇔ x = log₂8 = 3 |
| **Функція, швидкість якої пропорційна значенню** | чим більше бактерій, тим швидше їх стає більше |

**Як розуміти 2^0,5 або 2^√2.** Дробовий показник — корінь: 2^(1/2) = √2 (див. [[Корінь n-го степеня і дробові показники]]). Ірраціональний — границя: 2^1,4, 2^1,41, 2^1,414, … наближаються до 2^√2 ≈ 2,665. Функція aˣ визначена для всіх дійсних x і «плавно» заповнює проміжки між цілими точками.

**Головна властивість:** **aˣ⁺ʸ = aˣ·aʸ** — додавання показників перетворюється на множення значень. Показникова функція — це «міст» від додавання до множення. Логарифм — міст назад.

## 3. Графік і властивості

```
 y        y = (1/2)ˣ       y = 2ˣ
 │    \                    /
 4    *                   *
 │     \                 /
 2      *               *
 │       `*._       _.*'
 1 ─ ─ ─ ─ ─ `*──*─' ─ ─ ─
 │      ___..--'  `--..___
 ┼──────────────┼──────────► x
               0
```

| Властивість | a > 1 (наприклад 2ˣ) | 0 < a < 1 (наприклад (1/2)ˣ) |
|---|---|---|
| D | ℝ | ℝ |
| E | (0; +∞) | (0; +∞) |
| Монотонність | зростає | спадає |
| Точка (0; 1) | так | так |
| Асимптота | y = 0 при x → −∞ | y = 0 при x → +∞ |

- **a⁰ = 1** — усі графіки проходять через (0; 1).
- **aˣ > 0 завжди.** Множенням додатних чисел не вийде нуль чи від'ємне.
- **(1/a)ˣ = a⁻ˣ** — графіки 2ˣ і (1/2)ˣ симетричні відносно осі Oy.
- **Чому a > 0 і a ≠ 1:** при a = 1 функція стала; при a < 0 значення (−2)^(1/2) не існує серед дійсних.

## 4. Число e

Серед усіх основ особлива — **e ≈ 2,71828**. Функція eˣ — єдина показникова, в якої **швидкість зростання в кожній точці дорівнює значенню**: (eˣ)′ = eˣ (див. [[Похідна]]).

**Звідки e — неперервні відсотки.** Вклад 1 грн під 100% річних:
- нарахування раз на рік: 2;
- двічі на рік по 50%: 1,5² = 2,25;
- щомісяця: (1 + 1/12)¹² ≈ 2,613;
- щодня: (1 + 1/365)³⁶⁵ ≈ 2,7146;
- неперервно: lim (1 + 1/n)ⁿ = **e**.

Більше — у [[Ряди і число e]]. Будь-яку показникову можна записати через e: aˣ = e^(x·ln a).

## 5. Моделі

### 5.1. Загальна формула

**N(t) = N₀·aᵗ** або **N(t) = N₀·(1 + r)ᵗ**, де r — відсоток зміни за період (від'ємний для спадання).

### 5.2. Час подвоєння і період напіврозпаду

- Подвоєння за T: N(t) = N₀·2^(t/T). Через 3T — у 8 разів більше.
- Напіврозпад за T: N(t) = N₀·(1/2)^(t/T). Цезій-137, T ≈ 30 років: за 90 років лишається 1/8.
- **Правило 72:** при r% за період подвоєння ≈ 72/r періодів (див. [[Зміна у відсотках і складні відсотки]]).

### 5.3. Охолодження (закон Ньютона)

T(t) = T_кімн + (T₀ − T_кімн)·e^(−kt). Різниця температур з кімнатою спадає показниково: чай з 90°C у кімнаті 20°C через певний час має різницю 70·(частка).

### 5.4. Ключовий приклад кількома способами

**Задача.** Бактерій 500, кількість подвоюється щогодини. Скільки буде через 5 год і коли їх стане 64 000?

1. **Таблиця кроків:** 500 → 1000 → 2000 → 4000 → 8000 → 16 000 (через 5 год). Далі 32 000, 64 000 — через 7 год.
2. **Формула:** N = 500·2ᵗ; N(5) = 500·32 = 16 000; 500·2ᵗ = 64 000 ⇒ 2ᵗ = 128 = 2⁷ ⇒ t = 7.
3. **Логарифм:** t = log₂(64 000/500) = log₂128 = 7 (див. [[Логарифми]]).

## 6. Показникові рівняння

### 6.1. Зведення до однієї основи

aᶠ⁽ˣ⁾ = aᵍ⁽ˣ⁾ ⇔ f(x) = g(x). **Чому:** показникова функція строго монотонна, тому різним показникам відповідають різні значення.

- 2ˣ = 32 ⇒ 2ˣ = 2⁵ ⇒ x = 5.
- 9ˣ = 27 ⇒ 3²ˣ = 3³ ⇒ x = 3/2.
- (1/4)ˣ = 8 ⇒ 2⁻²ˣ = 2³ ⇒ x = −3/2.
- 5^(x² − 3x) = 1/25 ⇒ x² − 3x = −2 ⇒ x = 1, 2.

### 6.2. Винесення спільного множника

3ˣ⁺² − 3ˣ = 72 ⇒ 3ˣ(9 − 1) = 72 ⇒ 3ˣ = 9 ⇒ x = 2.

### 6.3. Заміна

4ˣ − 5·2ˣ + 4 = 0. t = 2ˣ > 0: t² − 5t + 4 = 0 ⇒ t = 1, 4 ⇒ x = 0, 2.

**Не забувати:** t = aˣ > 0, тож від'ємні t відкидаємо.

### 6.4. Коли основи не зводяться — логарифм

2ˣ = 7 ⇒ x = log₂7 ≈ 2,807.

### 6.5. Графічний спосіб

2ˣ = 3 − x: показникова зростає, пряма спадає — перетин рівно один, і він видно одразу: x = 1.

## 7. Показникові нерівності

- a > 1: aᶠ > aᵍ ⇔ f > g (знак зберігається).
- 0 < a < 1: aᶠ > aᵍ ⇔ f < g (**знак змінюється**, бо функція спадає).

2ˣ > 8 ⇒ x > 3. (1/3)ˣ > 9 ⇒ (1/3)ˣ > (1/3)⁻² ⇒ x < −2.

## 8. Типові помилки

| Помилка | Правильно |
|---|---|
| 2³·2⁴ = 4⁷ | 2⁷ |
| 2ˣ + 2ˣ = 4ˣ | 2·2ˣ = 2ˣ⁺¹ |
| (2ˣ)² = 2^(x²) | 2²ˣ |
| 3ˣ = 0 має корінь x = 0 | 3ˣ > 0 — коренів немає (3⁰ = 1) |
| (1/2)ˣ > 4 ⇒ x > −2 | знак змінюється: x < −2 |
| 2ˣ = −4 ⇒ x = −2 | коренів немає |
| «Зростання 10% щороку — це +10 одиниць щороку» | +10% від поточного значення |
| x² і 2ˣ — «однакові» | степенева vs показникова: 2ˣ зрештою незрівнянно більша |
