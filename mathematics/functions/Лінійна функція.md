# Лінійна функція

**Лінійна функція** — функція вигляду **y = kx + b**. Її графік — пряма. Це модель **сталої швидкості зміни**: кожен крок по x на одиницю змінює y на одне й те саме число k. Таксі з посадкою і ціною за кілометр, рівномірний рух, переведення градусів Цельсія у Фаренгейта, зарплата з окладом і премією за кожну угоду — усе це лінійні функції.

Пов'язані нотатки: [[Функції]], [[Графіки — основи]], [[Лінійні рівняння і нерівності]], [[Системи рівнянь]], [[Відношення і пропорції]], [[Похідна]], [[Регресія і кореляція]], [[Математика — зміст]].

## 1. Сенс коефіцієнтів

| Коефіцієнт | Назва | Що означає | На графіку |
|---|---|---|---|
| **k** | кутовий коефіцієнт, нахил | на скільки зміниться y, коли x збільшиться на 1 | крутизна прямої |
| **b** | вільний член, початкове значення | значення y при x = 0 | точка перетину з віссю Oy: (0; b) |

**Таксі:** C = 15d + 40. k = 15 грн/км — ціна кожного кілометра, b = 40 грн — посадка (ціна при d = 0).

## 2. Кілька способів зрозуміти нахил k

| Модель | k = 2 означає |
|---|---|
| **Підйом/пробіг** | на кожну 1 клітинку праворуч — 2 клітинки вгору |
| **Швидкість** | y зростає на 2 одиниці за одиницю x (2 м/с, 2 грн/шт) |
| **Відношення приростів** | k = Δy/Δx = (y₂ − y₁)/(x₂ − x₁) для будь-яких двох точок |
| **Кут** | k = tg α, де α — кут між прямою і віссю Ox |
| **Множник масштабу** | y = kx розтягує числову пряму в k разів |
| **Похідна** | нахил дотичної; для прямої він однаковий у кожній точці |

**Чому нахил однаковий скрізь.** Для будь-яких точок (x₁; y₁), (x₂; y₂) на прямій: y₂ − y₁ = (kx₂ + b) − (kx₁ + b) = k(x₂ − x₁). b скорочується, а відношення приростів завжди k. Саме тому графік — пряма: прирости пропорційні. І навпаки, якщо функція має сталу швидкість зміни, вона лінійна.

**Знак k:**
- k > 0 — функція зростає (пряма «піднімається» зліва направо);
- k < 0 — спадає;
- k = 0 — стала функція y = b, горизонтальна пряма.

Чим більше |k|, тим крутіша пряма.

## 3. Як побудувати графік — три способи

y = 2x − 3:

1. **Дві точки:** x = 0 ⇒ y = −3; x = 2 ⇒ y = 1. Провести пряму через (0; −3) і (2; 1).
2. **Точка і нахил:** від (0; −3) — крок 1 праворуч і 2 вгору, ще раз — і так далі.
3. **Перетини з осями:** з Oy — (0; −3); з Ox: 2x − 3 = 0 ⇒ (1,5; 0).

```
 y
 │      /
 1 ─ ─ ─*(2; 1)
 │    /
 ┼───*────────► x
 │  /1,5
 │ /
−3*
```

## 4. Рівняння прямої — як скласти

| Що відомо | Формула | Приклад |
|---|---|---|
| нахил k і b | y = kx + b | k = 3, b = −1: y = 3x − 1 |
| нахил k і точка (x₀; y₀) | y − y₀ = k(x − x₀) | k = 2, (1; 5): y = 2x + 3 |
| дві точки | k = (y₂ − y₁)/(x₂ − x₁), далі як вище | (1; 2), (4; 11): k = 3, y = 3x − 1 |
| перетини з осями a і b | x/a + y/b = 1 | a = 2, b = 6: y = −3x + 6 |

**Ключовий приклад кількома способами.** Пряма через (2; 1) і (6; 9).

- **Спосіб 1 (нахил + точка):** k = (9 − 1)/(6 − 2) = 2; y − 1 = 2(x − 2) ⇒ y = 2x − 3.
- **Спосіб 2 (система):** { 1 = 2k + b, 9 = 6k + b } ⇒ 4k = 8 ⇒ k = 2, b = −3.
- **Спосіб 3 (крокування):** від (2; 1) до (6; 9) — 4 кроки по x, 8 по y ⇒ 2 на крок. Назад від x = 2 до x = 0 — два кроки вниз по 2: b = 1 − 4 = −3.

## 5. Взаємне розташування прямих

| Умова | Прямі |
|---|---|
| k₁ ≠ k₂ | перетинаються (в одній точці) |
| k₁ = k₂, b₁ ≠ b₂ | паралельні |
| k₁ = k₂, b₁ = b₂ | збігаються |
| k₁·k₂ = −1 | перпендикулярні |

**Чому k₁·k₂ = −1 для перпендикулярних.** Поворот на 90° переводить вектор (1; k) у (−k; 1). Нахил нового вектора 1/(−k) = −1/k. Наприклад, y = 2x і y = −x/2.

**Точка перетину** — розв'язок системи (див. [[Системи рівнянь]]): y = 2x − 3 і y = −x + 6 ⇒ 2x − 3 = −x + 6 ⇒ x = 3, y = 3.

## 6. Пряма пропорційність — окремий випадок

**y = kx** (b = 0) — **пряма пропорційність** (див. [[Відношення і пропорції]]). Графік проходить через початок координат. Ознака: відношення y/x стале. Збільшиш x удвічі — y теж збільшиться вдвічі.

y = kx + b при b ≠ 0 — **не** пропорційність: таксі за 2 км (70 грн) не вдвічі дешевше, ніж за 4 км (100 грн).

## 7. Обернена до лінійної

y = kx + b ⇒ x = (y − b)/k. Обернена f⁻¹(x) = (x − b)/k — теж лінійна, з нахилом 1/k. Графіки симетричні відносно y = x.

Цельсій → Фаренгейт: F = 1,8C + 32; обернена: C = (F − 32)/1,8.

## 8. Кусково-лінійні функції

Багато реальних тарифів складаються з кількох лінійних шматків:
- |x| = x при x ≥ 0 і −x при x < 0 (див. [[Модуль числа]]);
- податок, що зростає за шкалою;
- тариф «перші 100 кВт·год по 2,64 грн, решта по 4,32».

## 9. Лінійні моделі і їхні межі

Лінійна модель працює, поки **швидкість зміни стала**. Ріст дитини (≈ 6 см/рік) — лінійний лише кілька років. Населення, відсотки на вклад — **не** лінійні (див. [[Показникова функція]]). У статистиці пряму, що «найкраще» проходить через хмару точок, будують методом найменших квадратів (див. [[Регресія і кореляція]]).

**Лінійна інтерполяція:** якщо при x = 10 маємо y = 50, а при x = 20 — y = 80, то при x = 14 оцінюємо y ≈ 50 + 4·3 = 62. На цьому стоять таблиці, анімація (lerp у програмуванні: `a + (b − a)·t`) і наближені обчислення.

## 10. Типові помилки

| Помилка | Правильно |
|---|---|
| k — це точка перетину з віссю | k — нахил, b — перетин з Oy |
| k = (x₂ − x₁)/(y₂ − y₁) | (y₂ − y₁)/(x₂ − x₁) |
| y = kx + b завжди пропорційність | лише при b = 0 |
| Перпендикулярні: k₂ = −k₁ | k₂ = −1/k₁ |
| Вертикальна пряма x = 3 — лінійна функція | це не функція від x (нахил не визначений) |
| Від'ємний нахил «менш крутий» | крутизна — \|k\| |
