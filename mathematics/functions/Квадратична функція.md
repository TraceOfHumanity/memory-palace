# Квадратична функція

**Квадратична функція** — y = ax² + bx + c, a ≠ 0. Її графік — **парабола**. Це перша функція, яка має **найбільше або найменше значення**: тому вона з'являється скрізь, де щось оптимізують, — максимальна площа при заданому периметрі, максимальний прибуток, найвища точка польоту м'яча. Політ кинутого тіла, форма антени-тарілки, гальмівний шлях, площа квадрата від сторони — усе це параболи.

Пов'язані нотатки: [[Функції]], [[Квадратні рівняння]], [[Квадратні нерівності і метод інтервалів]], [[Лінійна функція]], [[Конічні перерізи]], [[Похідна]], [[Математика — зміст]].

## 1. Базова парабола y = x²

| x | −3 | −2 | −1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| y | 9 | 4 | 1 | 0 | 1 | 4 | 9 |

```
 y
 9 *           *
   \           /
 4  *         *
     \       /
 1    *     *
       \___/
 ───────*────────► x
        0
```

- Вершина (0; 0) — найменше значення.
- Симетрична відносно осі Oy (функція парна).
- **Прирости:** від x = 0 до 1, 2, 3 значення зростають на 1, 3, 5, 7… — непарні числа. Друга різниця стала (2). Це «відбиток пальця» квадратичної функції, як стала перша різниця — у лінійної.

**Чому вона «прискорюється»:** приріст (x + 1)² − x² = 2x + 1 сам зростає лінійно. Швидкість зміни параболи — лінійна функція (у [[Похідна|похідних]]: (x²)′ = 2x).

## 2. Кілька способів зрозуміти параболу

| Модель | Що таке y = ax² + bx + c |
|---|---|
| **Площа** | y = x² — площа квадрата зі стороною x |
| **Політ тіла** | h = h₀ + v₀t − 4,9t² — висота кинутого м'яча |
| **Зсунута базова парабола** | y = a(x − m)² + n — парабола x², розтягнута в a разів і перенесена у вершину (m; n) |
| **Добуток двох лінійних** | y = a(x − x₁)(x − x₂) — нулі видно одразу |
| **Стала друга різниця** | прирости y зростають на сталу величину 2a |
| **Геометричне місце точок** | точки, рівновіддалені від точки (фокуса) і прямої (директриси) — див. [[Конічні перерізи]] |

## 3. Три форми запису

| Форма | Запис | Що видно одразу |
|---|---|---|
| **Загальна** | y = ax² + bx + c | перетин з Oy: (0; c) |
| **Вершинна (канонічна)** | y = a(x − m)² + n | вершина (m; n), вісь симетрії x = m |
| **Розкладена** | y = a(x − x₁)(x − x₂) | нулі x₁, x₂ |

Перехід від загальної до вершинної — **виділення повного квадрата** (див. [[Формули скороченого множення і біном Ньютона]]):

y = 2x² − 8x + 6 = 2(x² − 4x) + 6 = 2((x − 2)² − 4) + 6 = 2(x − 2)² − 2.

Вершина (2; −2). Розкладена: 2(x − 1)(x − 3).

## 4. Роль кожного коефіцієнта

### 4.1. a — напрямок і «ширина»

- a > 0 — гілки вгору, вершина — **мінімум**.
- a < 0 — гілки вниз, вершина — **максимум**.
- |a| > 1 — парабола вужча (розтягнута вертикально), |a| < 1 — ширша.

### 4.2. Вершина — три способи знайти

Для y = x² − 6x + 5:

1. **Формула:** m = −b/(2a) = 3; n = y(3) = 9 − 18 + 5 = −4.
2. **Повний квадрат:** (x − 3)² − 4.
3. **Середина між нулями:** нулі 1 і 5 ⇒ вісь симетрії x = 3 (парабола симетрична, отже вершина посередині).

Звідки m = −b/(2a): з вершинної форми a(x − m)² + n = ax² − 2amx + am² + n. Прирівнюємо коефіцієнт при x: −2am = b ⇒ m = −b/(2a). Те саме — середина коренів (−b ± √D)/(2a).

**Ордината вершини:** n = −D/(4a). Звідси знову видно: якщо a > 0 і D < 0, то n > 0 — парабола вся над віссю.

### 4.3. c — перетин з віссю Oy

y(0) = c.

### 4.4. b — нахил у точці перетину з Oy

Менш очевидно: b — швидкість зміни функції при x = 0 (нахил дотичної в точці (0; c)). При b > 0 парабола в цій точці «йде вгору».

## 5. Алгоритм побудови

1. Напрямок гілок (знак a).
2. Вершина (m; n).
3. Перетин з Oy: (0; c) і симетрична їй точка (2m; c).
4. Нулі (якщо D ≥ 0).
5. Ще пара точок за потреби.

**Приклад:** y = −x² + 2x + 3.
- a = −1 — вниз.
- m = 1, n = 4 — вершина (1; 4), максимум.
- (0; 3) і (2; 3).
- Нулі: −x² + 2x + 3 = 0 ⇒ x = −1, 3.

## 6. Властивості (для a > 0)

| Властивість | Значення |
|---|---|
| D(f) | ℝ |
| E(f) | [n; +∞) |
| Спадає | (−∞; m] |
| Зростає | [m; +∞) |
| Найменше значення | n при x = m |
| Парність | парна лише якщо b = 0 |
| Нулі | залежно від D |

Для a < 0 — все дзеркально: E = (−∞; n], найбільше значення n.

## 7. Перетворення графіка

y = a(x − m)² + n отримуємо з y = x²:
1. розтягнути вертикально в |a| разів (і відобразити, якщо a < 0);
2. зсунути на m праворуч;
3. зсунути на n угору.

**Чому зсув «праворуч» при мінусі:** у y = (x − 3)² значення 0 досягається при x = 3 — те, що в базовій параболі було в нулі, тепер у точці 3.

## 8. Оптимізація

### 8.1. Найбільша площа

60 м сітки на прямокутну ділянку. Сторони x і 30 − x; площа S = x(30 − x) = −x² + 30x. Вершина m = 15 ⇒ квадрат 15×15, S = 225 м².

**Три способи:**
1. **Вершина параболи:** m = −30/(−2) = 15.
2. **Симетрія нулів:** S = 0 при x = 0 і x = 30 ⇒ максимум посередині.
3. **Нерівність між середніми:** x(30 − x) ≤ ((x + 30 − x)/2)² = 225, рівність при x = 15 (див. [[Формули скороченого множення і біном Ньютона]]).

### 8.2. Найбільший прибуток

Кафе продає 200 чашок кави по 40 грн. Кожне підвищення ціни на 1 грн зменшує продаж на 4 чашки. Дохід R(p) = (40 + p)(200 − 4p) = −4p² + 40p + 8000. Вершина p = 5 ⇒ ціна 45 грн, дохід 8100 грн.

### 8.3. Політ м'яча

h = 1,5 + 14t − 4,9t². Найвища точка: t = 14/9,8 ≈ 1,43 с, h ≈ 11,5 м. Час польоту — додатний корінь h = 0: t ≈ 2,96 с.

## 9. Парабола в природі й техніці

- **Траєкторія** кинутого тіла без опору повітря — парабола (Галілей).
- **Параболічні антени й фари:** промені, паралельні осі, після відбиття збираються у фокусі (і навпаки — лампа у фокусі дає паралельний пучок).
- **Гальмівний шлях** пропорційний квадрату швидкості: удвічі швидше — учетверо довше гальмувати.
- **Енергія** руху E = mv²/2.

## 10. Типові помилки

| Помилка | Правильно |
|---|---|
| y = (x − 3)² — зсув ліворуч | праворуч на 3 |
| вершина x = b/(2a) | x = −b/(2a) |
| y = −x² має мінімум | максимум (гілки вниз) |
| −3² = 9 при обчисленні y(−3) для y = −x² | y(−3) = −9 |
| Парабола y = x² + 4 перетинає Ox | D < 0 — не перетинає |
| Найбільше значення y = x² − 4x — у вершині | при a > 0 у вершині найменше; найбільшого немає |
| a = 0 — «пласка парабола» | при a = 0 функція лінійна |
