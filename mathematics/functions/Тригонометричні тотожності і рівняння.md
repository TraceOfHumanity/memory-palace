# Тригонометричні тотожності і рівняння

Тригонометричних формул у шкільних довідниках десятки, але запам'ятовувати їх майже не треба. Майже всі виводяться з **двох фактів**: **sin²α + cos²α = 1** (Піфагор на одиничному колі) і **формули косинуса різниці** cos(α − β) = cos α cos β + sin α sin β. Ще простіше — з формули Ейлера e^(iα) = cos α + i sin α: тоді всі формули додавання — це правило множення степенів.

Пов'язані нотатки: [[Тригонометрія — одиничне коло і радіани]], [[Тригонометричні функції]], [[Комплексні числа]], [[Формули скороченого множення і біном Ньютона]], [[Квадратні рівняння]], [[Математика — зміст]].

## 1. Карта формул

```
          sin² + cos² = 1          cos(α − β)
                │                     │
     1 + tg² = 1/cos²       ┌─────────┼─────────┐
                         cos(α+β)  sin(α±β)  tg(α±β)
                            │         │
                     подвійний кут (β = α)
                            │
                  пониження степеня, половинний кут
                            │
                  сума ↔ добуток
```

## 2. Формули зведення

Як знайти sin(π − α), cos(3π/2 + α) тощо **без таблиці**:

1. **Чи змінюється назва функції?** Якщо кут відкладено від **вертикальної** осі (π/2, 3π/2) — sin ↔ cos, tg ↔ ctg. Якщо від **горизонтальної** (π, 2π) — назва та сама. («Киваємо» головою вгору-вниз біля π/2 — «так, міняй»; вліво-вправо біля π — «ні».)
2. **Який знак?** Вважаючи α маленьким гострим кутом, визначаємо чверть і знак **вихідної** функції.

- sin(π − α): горизонтальна вісь — назва та сама; π − α у II чверті, sin > 0 ⇒ **sin α**.
- cos(π/2 + α): вертикальна — назва змінюється; π/2 + α у II чверті, cos < 0 ⇒ **−sin α**.
- tg(3π/2 − α): вертикальна; III чверть, tg > 0 ⇒ **ctg α**.

**Чому це працює:** усі такі кути отримуємо з α відображеннями й поворотами одиничного кола на чверть оберту. Поворот на 90° міняє координати місцями (x, y) → (−y, x) — тому sin і cos міняються.

## 3. Формули додавання

$$\cos(\alpha-\beta)=\cos\alpha\cos\beta+\sin\alpha\sin\beta$$

**Доведення через скалярний добуток.** Точки одиничного кола A = (cos α; sin α), B = (cos β; sin β). Кут між векторами OA і OB дорівнює α − β. Скалярний добуток: OA·OB = |OA||OB|cos(α − β) = cos(α − β). А в координатах: cos α cos β + sin α sin β.

Решта — заміни:
- cos(α + β) = cos α cos β − sin α sin β (β → −β).
- sin(α + β) = sin α cos β + cos α sin β (через sin x = cos(π/2 − x)).
- sin(α − β) = sin α cos β − cos α sin β.
- tg(α + β) = (tg α + tg β)/(1 − tg α tg β).

**Доведення через Ейлера (найкоротше).** e^(i(α+β)) = e^(iα)·e^(iβ):
cos(α + β) + i sin(α + β) = (cos α + i sin α)(cos β + i sin β) = (cos α cos β − sin α sin β) + i(sin α cos β + cos α sin β).
Порівнюємо дійсні й уявні частини — отримуємо обидві формули одразу.

**Приклад:** sin 75° = sin(45° + 30°) = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4.

## 4. Подвійний і половинний кут

Підставимо β = α:

| Формула | |
|---|---|
| sin 2α = 2 sin α cos α | |
| cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α | три форми через sin²+cos² = 1 |
| tg 2α = 2tg α/(1 − tg²α) | |

**Пониження степеня** (з cos 2α):

cos²α = (1 + cos 2α)/2, sin²α = (1 − cos 2α)/2.

Звідси **половинний кут:** cos²(α/2) = (1 + cos α)/2.

**Наочно:** sin²x коливається між 0 і 1 з **удвічі меншим** періодом навколо середнього 1/2 — це і є (1 − cos 2x)/2.

## 5. Сума ↔ добуток

$$\sin\alpha+\sin\beta=2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$$

$$\cos\alpha+\cos\beta=2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$$

**Звідки:** додаємо sin(u + v) + sin(u − v) = 2sin u cos v і позначаємо u + v = α, u − v = β.

**Фізичний сенс — биття:** дві близькі частоти sin(442·2πt) + sin(440·2πt) = 2sin(441·2πt)·cos(1·2πt). Чуємо тон 441 Гц, гучність якого «пульсує» з частотою 2 рази на секунду.

## 6. Найпростіші рівняння

### 6.1. sin x = a

- |a| > 1 — розв'язків немає.
- |a| ≤ 1: **x = (−1)ᵏ arcsin a + πk**, або двома серіями: x = arcsin a + 2πk і x = π − arcsin a + 2πk.

**Чому дві серії:** на одиничному колі горизонтальна пряма y = a перетинає коло у **двох** точках, симетричних відносно Oy: кути t і π − t. Плюс повні оберти.

```
          y
      .-~~│~~-.
 π−t *────┼────* t      y = a
    |     │     |
    ──────┼──────── x
     \    │    /
      `-..│..-'
```

sin x = 1/2 ⇒ x = π/6 + 2πk або x = 5π/6 + 2πk.

### 6.2. cos x = a

**x = ±arccos a + 2πk.** Вертикальна пряма x = a перетинає коло в точках t і −t (симетричних відносно Ox).

cos x = −√2/2 ⇒ x = ±3π/4 + 2πk.

### 6.3. tg x = a

**x = arctg a + πk** — одна серія з кроком π (бо період тангенса π).

### 6.4. Окремі випадки (запам'ятати «на око»)

| Рівняння | Розв'язок |
|---|---|
| sin x = 0 | x = πk |
| sin x = 1 | x = π/2 + 2πk |
| sin x = −1 | x = −π/2 + 2πk |
| cos x = 0 | x = π/2 + πk |
| cos x = 1 | x = 2πk |
| cos x = −1 | x = π + 2πk |

## 7. Методи розв'язання складніших рівнянь

### 7.1. Заміна → квадратне рівняння

2sin²x − 3sin x + 1 = 0. t = sin x ∈ [−1; 1]: 2t² − 3t + 1 = 0 ⇒ t = 1 або 1/2.
x = π/2 + 2πk; x = π/6 + 2πk; x = 5π/6 + 2πk.

### 7.2. Звести до однієї функції через sin² + cos² = 1

2cos²x + sin x − 1 = 0 ⇒ 2(1 − sin²x) + sin x − 1 = 0 ⇒ 2sin²x − sin x − 1 = 0 ⇒ sin x = 1 або −1/2.

### 7.3. Розкладання на множники

sin 2x = sin x ⇒ 2sin x cos x − sin x = 0 ⇒ sin x(2cos x − 1) = 0 ⇒ x = πk або x = ±π/3 + 2πk.

**Не ділити на sin x** — загубиться серія x = πk.

### 7.4. Однорідні рівняння

sin x = √3·cos x. cos x = 0 не підходить (тоді й sin x = 0, а разом вони не бувають нулями). Ділимо на cos x: tg x = √3 ⇒ x = π/3 + πk.

### 7.5. Ключовий приклад трьома способами: sin x + cos x = 1

**Спосіб 1 (допоміжний кут):** sin x + cos x = √2 sin(x + π/4) = 1 ⇒ sin(x + π/4) = √2/2 ⇒ x + π/4 = π/4 + 2πk або 3π/4 + 2πk ⇒ **x = 2πk або x = π/2 + 2πk**.

**Спосіб 2 (піднесення до квадрата):** 1 + 2sin x cos x = 1 ⇒ sin 2x = 0 ⇒ x = πk/2. Перевірка: x = 0 ✓, π/2 ✓, π: −1 ✗, 3π/2: −1 ✗. Ті самі серії, але треба відсіювати сторонні.

**Спосіб 3 (одиничне коло):** шукаємо точки (cos x; sin x) на колі, для яких x + y = 1. Пряма x + y = 1 перетинає коло в (1; 0) і (0; 1) — кути 0 і π/2.

## 8. Тригонометричні нерівності — коротко

sin x > 1/2: на колі — дуга вище прямої y = 1/2, від π/6 до 5π/6. Відповідь: π/6 + 2πk < x < 5π/6 + 2πk.

## 9. Типові помилки

| Помилка | Правильно |
|---|---|
| sin(α + β) = sin α + sin β | sin α cos β + cos α sin β |
| sin 2α = 2 sin α | 2 sin α cos α |
| cos 2α = 2cos α | 2cos²α − 1 |
| sin x = 1/2 ⇒ лише π/6 + 2πk | ще 5π/6 + 2πk |
| cos x = a ⇒ x = arccos a + πk | ±arccos a + 2πk |
| sin x = 2 ⇒ x = arcsin 2 | розв'язків немає |
| Поділили на sin x | загубили корені sin x = 0 |
| Знак у формулі зведення — за результатом | за знаком **вихідної** функції в тій чверті |
