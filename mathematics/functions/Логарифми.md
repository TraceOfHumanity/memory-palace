# Логарифми

**Логарифм** числа b за основою a — це **показник степеня**, до якого треба піднести a, щоб отримати b:

$$\log_a b = c \iff a^c = b\qquad (a>0,\ a\ne1,\ b>0)$$

log₂8 = 3, бо 2³ = 8. log₁₀1000 = 3. log₅(1/25) = −2. Логарифм відповідає на запитання **«скільки разів треба помножити a на себе, щоб вийшло b?»** або **«скільки подвоєнь, подесятерень… між 1 і b?»**.

Логарифм винайшли на початку XVII століття (Непер, Бюргі), щоб **замінити множення додаванням**: астрономи й мореплавці множили багатозначні числа, і логарифмічні таблиці скоротили цю роботу в рази. Лапласу приписують слова, що логарифми «подвоїли життя астрономів».

Пов'язані нотатки: [[Показникова функція]], [[Степені з цілим показником]], [[Ряди і число e]], [[Системи числення]], [[Складність алгоритмів]], [[Функції]], [[Математика — зміст]].

## 1. Кілька способів зрозуміти логарифм

| Модель | Що означає log₂32 = 5 |
|---|---|
| **Обернена дія до степеня** | 2 в якому степені дає 32? У п'ятому |
| **Лічба множень** | 1 → 2 → 4 → 8 → 16 → 32 — п'ять подвоєнь |
| **Кількість цифр** | log₁₀ числа ≈ кількість цифр мінус 1: log₁₀5000 ≈ 3,7 — число чотиризначне |
| **Глибина дерева / ділення навпіл** | 32 елементи можна ділити навпіл 5 разів до одного — двійковий пошук робить 5 кроків |
| **Шкала порядків** | децибели, бали землетрусу, pH: кожна одиниця шкали — множник |
| **Обернена функція** | y = log₂x — дзеркальне відображення y = 2ˣ відносно y = x |
| **Час росту** | вклад подвоюється щороку — за скільки років стане в 32 рази більшим? За log₂32 = 5 |

**Головна інтуїція:** логарифм перетворює **множення на додавання** і **степені на множення**. Число 1 000 000 «велике», але його log₁₀ лише 6. Логарифм «стискає» величезні діапазони.

## 2. Основні значення й тотожності

- **logₐ1 = 0**, бо a⁰ = 1.
- **logₐa = 1**, бо a¹ = a.
- **logₐaᶜ = c** — логарифм «знімає» степінь.
- **a^(logₐb) = b** — основна логарифмічна тотожність: степінь «знімає» логарифм.
- Позначення: **lg b = log₁₀b** (десятковий), **ln b = log_e b** (натуральний, e ≈ 2,718), часто **log₂** в інформатиці.

**Чому b > 0:** aᶜ > 0 при будь-якому c, тож від'ємне число чи нуль не можна отримати піднесенням додатної основи до степеня. log₂(−8) і log₂0 не існують.

## 3. Властивості — з виведенням

Нехай logₐx = m, logₐy = n, тобто x = aᵐ, y = aⁿ.

| Властивість | Формула | Чому |
|---|---|---|
| **Логарифм добутку** | logₐ(xy) = logₐx + logₐy | xy = aᵐaⁿ = aᵐ⁺ⁿ |
| **Логарифм частки** | logₐ(x/y) = logₐx − logₐy | x/y = aᵐ⁻ⁿ |
| **Логарифм степеня** | logₐ(xᵏ) = k·logₐx | xᵏ = (aᵐ)ᵏ = aᵏᵐ |
| **Перехід до нової основи** | logₐb = log_c b / log_c a | нехай logₐb = t: aᵗ = b; логарифмуємо за основою c: t·log_c a = log_c b |
| **Обернення** | logₐb = 1/log_b a | частковий випадок попередньої з c = b |
| **Степінь основи** | log_(aᵏ) b = (1/k)·logₐb | з переходу до нової основи |

Усі властивості логарифмів — це закони степенів (див. [[Степені з цілим показником]]), прочитані «з боку показника».

**Приклади:**
- lg 2 + lg 5 = lg 10 = 1.
- log₃54 − log₃2 = log₃27 = 3.
- log₂8¹⁰ = 10·3 = 30.
- log₄8 = log₂8/log₂4 = 3/2.
- log₂3·log₃8 = log₂8 = 3 («ланцюжок» — проміжні основи скорочуються).

**Чого немає:** logₐ(x + y) ≠ logₐx + logₐy. logₐx·logₐy ≠ logₐ(xy). (logₐx)² ≠ logₐ(x²).

## 4. Графік і властивості y = logₐx

```
 y
 │                 ___-- y = log₂x
 2 ─ ─ ─ ─ ─ ─ ─ ─*'
 1 ─ ─ ─ ─ _*'
 ┼────────*────┼───┼──► x
 │      / 1    2   4
 │     |
 │     |  ← асимптота x = 0
```

| Властивість | a > 1 | 0 < a < 1 |
|---|---|---|
| D | (0; +∞) | (0; +∞) |
| E | ℝ | ℝ |
| Монотонність | зростає | спадає |
| Точка (1; 0) | так | так |
| Асимптота | x = 0 (вертикальна) | x = 0 |
| Знак | > 0 при x > 1, < 0 при 0 < x < 1 | навпаки |

**Логарифм зростає повільно, але необмежено.** log₂1 000 000 ≈ 20, log₂(10⁹) ≈ 30. Щоб log₂ дорівнював 100, потрібне число з 31 цифрою. Але досягти можна будь-якого значення.

**Порівняння швидкостей:** log x ≪ √x ≪ x ≪ x² ≪ 2ˣ при великих x. Це основа аналізу алгоритмів: O(log n) (двійковий пошук) — неймовірно швидко; O(n log n) (хороші сортування) — майже лінійно (див. [[Складність алгоритмів]]).

## 5. Ключовий приклад кількома способами: обчисліть log₈32

1. **Через степені 2:** 8 = 2³, 32 = 2⁵. Шукаємо c: (2³)ᶜ = 2⁵ ⇒ 3c = 5 ⇒ c = 5/3.
2. **Перехід до основи 2:** log₂32/log₂8 = 5/3.
3. **Через корені:** 8^(1/3) = 2, отже 32 = 2⁵ = (8^(1/3))⁵ = 8^(5/3).
4. **Наближено, десятковими логарифмами:** lg 32/lg 8 ≈ 1,505/0,903 ≈ 1,667.

## 6. Логарифмічні шкали

| Шкала | Формула | Що означає «+1» |
|---|---|---|
| **Децибели** | L = 10·lg(I/I₀) | +10 дБ — інтенсивність у 10 разів більша |
| **pH** | pH = −lg[H⁺] | на 1 менше — у 10 разів кисліше |
| **Магнітуда землетрусу** | M ∝ lg(амплітуди) | +1 — амплітуда в 10 разів більша, енергія ≈ в 32 рази |
| **Зоряна величина** | m = −2,5·lg(блиск) | +5 — у 100 разів тьмяніше |
| **Музика (октави)** | 12·log₂(f/f₀) півтонів | +12 півтонів — частота вдвічі більша |
| **Біти інформації** | log₂N | скільки двійкових питань, щоб вибрати 1 з N |

Людські відчуття (гучність, яскравість) приблизно логарифмічні: подвоєння сили звуку ми чуємо як «трохи гучніше».

## 7. Логарифмічні рівняння

### 7.1. Найпростіше: logₐf(x) = c ⇔ f(x) = aᶜ (і f(x) > 0 автоматично)

log₂(x − 1) = 3 ⇒ x − 1 = 8 ⇒ x = 9.

### 7.2. Однакові основи: logₐf = logₐg ⇔ f = g, **f > 0, g > 0**

log₃(2x − 1) = log₃(x + 4) ⇒ x = 5; перевірка ОДЗ: 9 > 0, 9 > 0 ✓.

### 7.3. Сума логарифмів — обережно з ОДЗ

lg x + lg(x − 3) = 1 ⇒ ОДЗ: x > 3. lg(x(x − 3)) = 1 ⇒ x² − 3x − 10 = 0 ⇒ x = 5 або x = −2. x = −2 поза ОДЗ. **Відповідь: 5.**

**Чому з'являється сторонній корінь:** перехід lg x + lg(x − 3) → lg(x(x − 3)) **розширює** область: добуток x(x − 3) додатний і тоді, коли обидва множники від'ємні.

### 7.4. Заміна

log₂²x − 3log₂x + 2 = 0: t = log₂x ⇒ t = 1, 2 ⇒ x = 2, 4.

### 7.5. Логарифмування показникових рівнянь

3ˣ = 2ˣ⁺¹ ⇒ x·ln3 = (x + 1)·ln2 ⇒ x = ln2/(ln3 − ln2) = log_(3/2)2 ≈ 1,71.

## 8. Логарифмічні нерівності

- a > 1: logₐf > logₐg ⇔ f > g > 0.
- 0 < a < 1: logₐf > logₐg ⇔ 0 < f < g (знак змінюється).

log₂(x − 1) < 3 ⇒ 0 < x − 1 < 8 ⇒ (1; 9).
log_(1/2)x > −2 ⇒ 0 < x < 4.

**Не забувати** умову додатності аргументу — вона дає ліву межу.

## 9. Логарифм у моделях

- **Час подвоєння:** вклад під r% подвоюється за t = ln2/ln(1 + r) ≈ 0,693/r ≈ 70/r% (правило 70–72).
- **Радіовуглецеве датування:** t = T·log₂(N₀/N). Якщо лишилося 25% вуглецю-14 (T ≈ 5730 років) — вік ≈ 11 460 років.
- **Кількість цифр числа:** у 2¹⁰⁰ цифр ⌊100·lg2⌋ + 1 = ⌊30,1⌋ + 1 = 31.
- **Скільки кроків двійкового пошуку** в масиві з мільйона: ⌈log₂10⁶⌉ = 20.

## 10. Типові помилки

| Помилка | Правильно |
|---|---|
| log₂(x + y) = log₂x + log₂y | логарифм суми не розкладається |
| log₂8/log₂2 = log₂4 | = 3/1 = 3 (це перехід до основи, а не логарифм частки) |
| log₂(−4) = −2 | не існує |
| logₐ1 = 1 | 0 |
| lg 100 = 10 | 2 |
| Забули ОДЗ і залишили x = −2 | аргумент кожного логарифма > 0 |
| log_(1/2)x > 1 ⇒ x > 1/2 | 0 < x < 1/2 |
| (log x)² = 2 log x | 2 log x = log(x²) |
| ln e² = e | 2 |
