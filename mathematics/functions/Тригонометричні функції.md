# Тригонометричні функції

Коли кут на одиничному колі може бути будь-яким дійсним числом (див. [[Тригонометрія — одиничне коло і радіани]]), синус і косинус стають **функціями числа**: y = sin x, y = cos x, y = tg x. Аргумент x — кут у радіанах, або просто час, або відстань. Це головні функції для опису **періодичних процесів**: усе, що повторюється, можна розкласти на суму синусоїд.

Пов'язані нотатки: [[Тригонометрія — одиничне коло і радіани]], [[Тригонометричні тотожності і рівняння]], [[Функції]], [[Графіки — основи]], [[Похідна]], [[Комплексні числа]], [[Математика — зміст]].

## 1. Як з кола народжується синусоїда

Точка рівномірно біжить одиничним колом. Запишемо її **висоту** (ординату) як функцію пройденого кута x і «розгорнемо» в часі:

```
 коло                     графік y = sin x
   .-~-.          1 ┤     .-~-.
  /  ·  \           │   /       \
 |   ·───|── ─ ─ ─ ─┼──*─ ─ ─ ─ ─*─ ─ ─ ─ ─ *── x
  \     /           │  0    π/2   π\       / 2π
   `-.-'         −1 ┤                `-~-'
                                       3π/2
```

- x = 0: точка (1; 0), висота 0.
- x = π/2: верхня точка, висота 1.
- x = π: (−1; 0), висота 0.
- x = 3π/2: нижня точка, −1.
- x = 2π: повний оберт, усе повторюється.

**Косинус** — те саме для **абсциси** точки. Його графік — та сама хвиля, зсунута на π/2 ліворуч: cos x = sin(x + π/2). Косинус «випереджає» синус на чверть оберту.

## 2. Кілька способів думати про y = sin x

| Модель | Що таке sin x |
|---|---|
| **Висота точки на колі** | ордината після повороту на x |
| **Тінь колеса** | тінь точки на ободі на вертикальній стіні |
| **Коливання** | відхилення маятника, вантажу на пружині |
| **Хвиля** | профіль хвилі на воді, звукового тиску |
| **Рівняння «прискорення протилежне зміщенню»** | y″ = −y — розв'язки sin і cos (див. [[Похідна]]) |
| **Проєкція обертання** | Re/Im обертального множника e^(ix) (див. [[Комплексні числа]]) |

## 3. Властивості

| | y = sin x | y = cos x | y = tg x |
|---|---|---|---|
| D | ℝ | ℝ | x ≠ π/2 + πk |
| E | [−1; 1] | [−1; 1] | ℝ |
| Період | 2π | 2π | π |
| Парність | непарна | парна | непарна |
| Нулі | x = πk | x = π/2 + πk | x = πk |
| Максимум 1 | x = π/2 + 2πk | x = 2πk | — |
| Мінімум −1 | x = −π/2 + 2πk | x = π + 2πk | — |
| Зростає | [−π/2 + 2πk; π/2 + 2πk] | [−π + 2πk; 2πk] | на кожному (−π/2 + πk; π/2 + πk) |

**Чому sin — непарна, cos — парна.** Кути x і −x симетричні відносно осі Ox: ординати протилежні, абсциси однакові.

**Чому період tg — π.** Пів оберту переводить точку в протилежну, обидві координати змінюють знак, а їхнє відношення — ні.

## 4. Графік тангенса

```
 y     │        │        │
       │       /│       /
       │      / │      /
 ──────┼─────*──┼─────*──┼─── x
      /│   0    │π/2  π  │
     / │        │        │
    /  │        │        │
   −π/2       асимптоти x = π/2 + πk
```

Біля x = π/2 косинус прямує до нуля, а синус до 1 — частка необмежено зростає. Вертикальні асимптоти.

## 5. Загальна синусоїда y = A·sin(ωx + φ) + B

| Параметр | Назва | Що робить з графіком |
|---|---|---|
| **A** | амплітуда | розтягує по вертикалі: значення від B − \|A\| до B + \|A\| |
| **ω** | кутова частота | стискає по горизонталі: **період T = 2π/ω** |
| **φ** | початкова фаза | зсуває по горизонталі на −φ/ω |
| **B** | вертикальний зсув | зсуває вгору — «середня лінія» y = B |

**Приклад:** y = 3sin(2x − π/3) + 1.
- Амплітуда 3, середня лінія y = 1, значення від −2 до 4.
- Період 2π/2 = π.
- 2x − π/3 = 2(x − π/6) — зсув на π/6 праворуч.

**Ключовий приклад кількома способами: період y = sin(3x).**
1. **Формула:** T = 2π/3.
2. **Умова повторення:** sin(3(x + T)) = sin(3x + 3T) — повториться, коли 3T = 2π.
3. **Інтуїція:** аргумент 3x «біжить» утричі швидше, тож повний оберт — утричі швидше.

## 6. Обернені тригонометричні функції

Синус не ін'єктивний — щоб обернути, звужуємо область:

| Функція | Звуження | Обернена | D | E |
|---|---|---|---|---|
| sin x | [−π/2; π/2] | arcsin x | [−1; 1] | [−π/2; π/2] |
| cos x | [0; π] | arccos x | [−1; 1] | [0; π] |
| tg x | (−π/2; π/2) | arctg x | ℝ | (−π/2; π/2) |

**arcsin a** — кут з [−π/2; π/2], синус якого a. arcsin(1/2) = π/6; arccos(−1/2) = 2π/3; arctg 1 = π/4.

**arcsin(sin x) ≠ x** у загальному випадку: arcsin(sin(5π/6)) = π/6.

## 7. Звідки синусоїди в природі

- **Простий гармонічний рух:** x(t) = A·cos(ωt + φ) — маятник з малим відхиленням, вантаж на пружині. Період маятника T = 2π√(l/g).
- **Змінний струм:** напруга в розетці U = 311·sin(100πt) В — 50 Гц, діюче значення 220 В.
- **Звук:** нота ля 440 Гц — sin(2π·440·t). Тембр — суміш гармонік (ряд Фур'є).
- **Тривалість світлового дня** протягом року — приблизно синусоїда з періодом 365 днів.
- **Припливи** — сума кількох синусоїд (Місяць і Сонце).

**Ряд Фур'є:** будь-який «розумний» періодичний сигнал — сума синусоїд з кратними частотами. На цьому стоять MP3, JPEG, аналіз звуку.

## 8. Типові помилки

| Помилка | Правильно |
|---|---|
| Період sin 2x — 4π | π (стискання) |
| y = sin(x − π/4) — зсув ліворуч | праворуч на π/4 |
| y = sin(2x + π) зсунута на π | на π/2 (зсув = −φ/ω) |
| sin x ∈ [0; 1] | [−1; 1] |
| arcsin 2 = … | не існує (\|a\| ≤ 1) |
| arccos(−1/2) = −π/3 | 2π/3 (E arccos = [0; π]) |
| tg x має період 2π | π |
| cos — непарна | парна |
