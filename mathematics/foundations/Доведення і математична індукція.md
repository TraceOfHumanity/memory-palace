# Доведення і математична індукція

**Доведення** — ланцюжок логічних кроків, який показує, що твердження істинне **завжди**, а не лише в перевірених прикладах. Саме доведення відрізняє математику від інших наук: у фізиці теорію підтверджують експериментом і можуть спростувати новим, а доведена теорема лишається істинною назавжди.

Пов'язані нотатки: [[Логіка і висловлення]], [[Основи]], [[Арифметичні дії та їхні властивості]], [[Комбінаторика і рекурентності]], [[Теорія чисел і модульна арифметика]].

## 1. Чому приклади не доводять

Розглянемо твердження: «число n² + n + 41 просте для кожного натурального n». Перевіримо: n = 1 → 43, n = 2 → 47, n = 3 → 53, … Аж до n = 39 усі значення прості. Але n = 40 дає 40² + 40 + 41 = 1681 = 41². Сорок перших прикладів «підтверджували» хибне твердження.

Ще приклад: точки на колі з'єднують усіма хордами і рахують, на скільки частин розпадається круг. Для 1, 2, 3, 4, 5 точок виходить 1, 2, 4, 8, 16 — здається, що далі буде 32. Але для 6 точок частин **31**.

Висновки:
- щоб **спростувати** загальне твердження, достатньо **одного контрприкладу**;
- щоб **довести** його, потрібне міркування, яке працює для **всіх** випадків одразу.

## 2. Будова теореми

- **Означення** — домовленість, що означає слово. «Парне число — ціле число виду 2k, де k ціле.»
- **Аксіома** — твердження, яке приймають без доведення як вихідне. «Через дві різні точки проходить рівно одна пряма.»
- **Теорема** — твердження, доведене з аксіом, означень і вже доведених теорем.
- **Лема** — допоміжна теорема для доведення іншої.
- **Наслідок** — те, що легко випливає з теореми.

Більшість теорем мають вигляд **«якщо A, то B»**: A — **умова** (що дано), B — **висновок** (що треба довести). Доведення починається з «нехай A» і закінчується «отже, B». Кінець доведення позначають ∎ або «що й треба було довести» (ч.т.д.).

**Обернена теорема** (B → A) — окреме твердження, її треба доводити окремо, і вона може бути хибною.

## 3. Пряме доведення

Беремо умову і за допомогою означень та відомих фактів крок за кроком доходимо висновку.

**Теорема.** Сума двох парних чисел парна.
**Доведення.** Нехай a і b парні. За означенням a = 2m, b = 2n, де m, n цілі. Тоді a + b = 2m + 2n = 2(m + n). Число m + n ціле, тому a + b має вигляд 2·(ціле), тобто парне. ∎

**Теорема.** Квадрат непарного числа непарний.
**Доведення.** Нехай n непарне: n = 2k + 1. Тоді n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1 — вигляд «2·(ціле) + 1», тобто непарне. ∎

**Ключова техніка:** **розгорнути означення**. Майже кожне шкільне доведення починається з того, що слово («парне», «ділиться», «раціональне») замінюють його означенням у вигляді рівності.

## 4. Доведення контрапозицією

Замість A → B доводимо рівносильне **¬B → ¬A** (див. [[Логіка і висловлення]]). Це зручно, коли заперечення висновку дає більше інформації, ніж умова.

**Теорема.** Якщо n² парне, то n парне.
**Пряме доведення важке:** з n² = 2k не видно, як отримати n.
**Контрапозиція:** якщо n непарне, то n² непарне. А це ми щойно довели в розділі 3. ∎

## 5. Доведення від супротивного

Припускаємо, що твердження **хибне**, і логічними кроками доходимо **суперечності** — чогось неможливого (наприклад, A ∧ ¬A). Отже, припущення було хибним, і твердження істинне.

### Класика: √2 — ірраціональне число

**Теорема.** √2 не можна записати як дріб p/q з цілими p, q.

**Доведення.**
1. Припустимо супротивне: √2 = p/q, і дріб **нескоротний** (p і q не мають спільних дільників, крім 1). Будь-який дріб можна скоротити до такого вигляду.
2. Піднесемо до квадрата: 2 = p²/q², тобто **p² = 2q²**.
3. Отже p² парне. За теоремою з розділу 4 тоді **p парне**: p = 2k.
4. Підставимо: (2k)² = 2q² → 4k² = 2q² → **q² = 2k²**.
5. Отже q² парне, і тоді **q парне**.
6. Але тоді p і q обидва парні, тобто мають спільний дільник 2. Це **суперечить** кроку 1, де дріб нескоротний.
7. Отже, припущення хибне, і √2 ірраціональне. ∎

Той самий метод доводить ірраціональність √3, √5 і взагалі √n, якщо n не повний квадрат.

### Нескінченність простих чисел (Евклід, ≈ 300 р. до н. е.)

**Теорема.** Простих чисел нескінченно багато.
**Доведення.** Припустимо, що їх скінченно: p₁, p₂, …, pₙ. Розглянемо N = p₁·p₂·…·pₙ + 1. N більше за 1, тому має простий дільник. Але N при діленні на кожне pᵢ дає остачу 1, тобто не ділиться на жодне з них. Отже, існує просте число поза списком — суперечність. ∎

Зауваження: N саме не обов'язково просте (2·3·5·7·11·13 + 1 = 30031 = 59·509), але його простий дільник обов'язково новий.

## 6. Інші методи

| Метод | Ідея | Приклад |

| Перебір випадків | розбити на випадки, що охоплюють усе, і довести кожен | n² + n парне: n парне або непарне — в обох випадках добуток n(n + 1) парний |
| Конструктивне доведення існування | показати об'єкт явно | «існує ірраціональне x, що x² раціональне»: x = √2 |
| Неконструктивне існування | довести, що об'єкт є, не будуючи його | принцип Діріхле: серед 13 людей двоє народилися в одному місяці |

| Математична індукція | доведення для всіх натуральних n | розділ 7 |

## 7. Математична індукція

### Ідея: доміно

Уявімо нескінченний ряд доміно. Щоб упали **всі**, достатньо двох фактів:
1. **упаде перше**;
2. **кожне, падаючи, валить наступне**.

Тоді впаде перше, воно повалить друге, друге — третє, і так без кінця.

### Схема

Щоб довести твердження P(n) для всіх натуральних n ≥ n₀:

1. **База індукції.** Перевірити P(n₀) (зазвичай n₀ = 1).
2. **Індукційне припущення.** Припустити, що P(k) істинне для деякого k ≥ n₀.
3. **Індукційний крок.** Довести, що тоді істинне P(k + 1).
4. **Висновок.** За принципом математичної індукції P(n) істинне для всіх n ≥ n₀.

Крок 3 — це доведення **імплікації** P(k) → P(k + 1), а не доведення P(k). Ми не припускаємо те, що доводимо: ми доводимо, що з кожного «доміно» випливає наступне.

### Приклад 1. Сума перших n натуральних чисел

**Теорема.** 1 + 2 + … + n = n(n + 1)/2.

- **База:** n = 1: ліва частина 1, права 1·2/2 = 1. ✓
- **Припущення:** 1 + 2 + … + k = k(k + 1)/2.
- **Крок:** 1 + 2 + … + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k/2 + 1) = (k + 1)(k + 2)/2. Це і є формула для n = k + 1. ✓
- ∎

Перевірка: 1 + … + 100 = 100·101/2 = 5050 — так рахував маленький Гаусс, складаючи пари 1 + 100, 2 + 99, …

### Приклад 2. Сума непарних чисел

**Теорема.** 1 + 3 + 5 + … + (2n − 1) = n².
- База: 1 = 1². ✓
- Крок: якщо 1 + … + (2k − 1) = k², то додамо наступне непарне 2k + 1: k² + 2k + 1 = (k + 1)². ✓ ∎

### Приклад 3. Подільність

**Теорема.** 4ⁿ − 1 ділиться на 3 для всіх n ≥ 1.
- База: 4 − 1 = 3. ✓
- Припущення: 4ᵏ − 1 = 3m.
- Крок: 4ᵏ⁺¹ − 1 = 4·4ᵏ − 1 = 4(4ᵏ − 1) + 3 = 4·3m + 3 = 3(4m + 1). ✓ ∎

**Прийом для подільності:** у кроці виділити вираз з припущення (тут 4ᵏ − 1) і показати, що решта теж ділиться.

### Приклад 4. Нерівність

**Теорема.** 2ⁿ > n для всіх n ≥ 1.
- База: 2 > 1. ✓
- Крок: 2ᵏ⁺¹ = 2·2ᵏ > 2k = k + k ≥ k + 1 (бо k ≥ 1). ✓ ∎

### Коли індукція «доводить» хибне

**Хибна теорема:** «усі коні одного кольору». «Доведення»: база — один кінь одного кольору. Крок: у групі з k + 1 коней приберемо першого — решта k одного кольору; приберемо останнього — теж k одного кольору; отже всі одного кольору.

**Помилка:** крок не працює при переході **від 1 до 2**: дві групи по одному коню не мають спільного коня, тому не можна стверджувати, що їхні кольори збігаються. Мораль: індукційний крок має працювати для **кожного** k, починаючи з бази.

Інша пастка — забути базу. «4ⁿ ділиться на 3»: крок «якщо 4ᵏ = 3m, то 4ᵏ⁺¹ = 4·3m» правильний, але база хибна (4 не ділиться на 3), тому й теорема хибна.

### Різновиди індукції

- **З іншою базою:** n! > 2ⁿ для n ≥ 4 (база n = 4: 24 > 16).
- **Сильна (повна) індукція:** у кроці можна користуватися **всіма** P(n₀), …, P(k), а не лише P(k). Так доводять, що кожне n ≥ 2 розкладається на прості множники: якщо n не просте, то n = a·b з меншими a, b, які вже розкладаються.
- **Індукція в програмуванні:** коректність рекурсії доводять саме індукцією — база рекурсії = база індукції, рекурсивний виклик = індукційне припущення.

## 8. Як писати доведення

1. Чітко сформулювати, **що дано** і **що треба довести**.
2. **Розгорнути означення** всіх слів у формулу.
3. Обрати метод: пряме, контрапозиція, від супротивного, випадки, індукція.
4. Кожен крок обґрунтувати: означенням, аксіомою, відомою теоремою, алгебраїчним перетворенням.
5. Перевірити, що доведено саме висновок, а не обернене твердження.
6. Перевірити крайні випадки: n = 0, n = 1, порожня множина, рівність замість нерівності.

## 9. Кілька способів думати про доведення

**Як обрати метод доведення:**
| Ситуація | Метод |
|---|---|
| Умова легко «розгортається» в рівність | пряме доведення |
| Заперечення висновку дає більше інформації, ніж умова | контрапозиція |
| Треба довести «не існує», «нескінченно», «ірраціональне» | від супротивного |
| Твердження для всіх натуральних n, і випадок n + 1 будується з випадку n | індукція |
| Мало варіантів (парне / непарне, остачі 0, 1, 2) | перебір випадків |
| Твердження «для всіх» сумнівне | шукати контрприклад |

**Індукцію можна уявляти трьома способами:** доміно (кожне падає і валить наступне); драбина (стати на першу сходинку і вміти з будь-якої піднятися на наступну); рекурсія (функція правильна для бази і правильна для n, якщо правильна для n − 1).

**Формулу 1 + 2 + … + n = n(n + 1)/2 можна довести трьома способами:** індукцією (розділ 7); парами Гаусса (записати суму двічі — у прямому й оберненому порядку — і додати: n пар по n + 1); малюнком (сходинки з n стовпчиків, дві такі сходинки складаються в прямокутник n × (n + 1)).

## Типові помилки

1. Вважати приклади доведенням.
2. Доводити обернене твердження замість прямого.
3. У доведенні від супротивного не дійти суперечності, а просто «нічого не знайти».
4. В індукції забути базу або довести крок, що не працює для всіх k.
5. В індукційному кроці використати те, що треба довести (P(k + 1)), замість P(k).
6. Використати «очевидне», яке насправді не доведене.
