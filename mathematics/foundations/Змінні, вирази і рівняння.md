# Змінні, вирази і рівняння

Перехід від арифметики до алгебри: замість конкретних чисел з'являються **букви**. Це дозволяє записати закон, який працює для **всіх** чисел одразу, і знаходити невідоме, не перебираючи варіанти.

Пов'язані нотатки: [[Арифметичні дії та їхні властивості]], [[Логіка і висловлення]], [[Як розв'язувати задачі]], [[Функції]].

## 1. Змінна

**Змінна** — буква, яка позначає число. Залежно від ситуації в неї різні ролі:

| Роль | Приклад | Що означає буква |
|---|---|---|
| Невідоме | x + 3 = 10 | конкретне число, яке треба знайти (7) |
| Загальне число в законі | a + b = b + a | будь-яке число |
| Величина у формулі | S = v·t | величина, що може набувати різних значень |
| Аргумент функції | y = 2x + 1 | вхід, від якого залежить вихід |
| Параметр | y = kx | число, фіксоване в межах задачі, але не задане наперед |

**Для програміста:** змінна в математиці не «комірка, яку перезаписують». У рівнянні x + 3 = 10 буква x — одне й те саме число в кожному місці. Запис x = x + 1 у програмі — присвоєння; у математиці це рівняння без розв'язків.

## 2. Вираз

**Вираз** — запис із чисел, букв, знаків дій і дужок: 3x + 5, (a + b)², 2πr.
- **Значення виразу** — число, яке отримаємо, підставивши значення букв: 3x + 5 при x = 2 дорівнює 11.
- **Область допустимих значень (ОДЗ)** — значення букв, при яких вираз має зміст: 1/(x − 2) не має змісту при x = 2.
- **Тотожно рівні вирази** мають однакові значення при **всіх** допустимих значеннях букв: 2(x + 3) і 2x + 6.
- **Тотожність** — рівність, правильна при всіх значеннях букв: (a + b)² = a² + 2ab + b².
- **Тотожне перетворення** — заміна виразу тотожно рівним (розкриття дужок, зведення подібних, винесення множника).

### Запис словесних умов виразами

| Словами | Вираз |
|---|---|
| число, на 5 більше за x | x + 5 |
| число, у 3 рази менше за x | x/3 |
| сума двох послідовних цілих | n + (n + 1) |
| парне число | 2k |
| двоцифрове число з цифрами a, b | 10a + b |
| a% від числа x | (a/100)·x |
| середнє арифметичне a і b | (a + b)/2 |

## 3. Рівність і рівняння

- **Рівність** — два вирази, з'єднані знаком «=». Вона може бути правильною (2 + 3 = 5), хибною (2 + 3 = 6) або залежати від букв.
- **Рівняння** — рівність з невідомим, у якій треба знайти значення невідомого, що роблять її правильною.
- **Корінь (розв'язок)** рівняння — значення невідомого, яке перетворює рівняння на правильну числову рівність. Рівняння може мати один корінь (x + 3 = 10), кілька (x² = 4: ±2), жодного (x + 1 = x) або безліч (2(x + 1) = 2x + 2).
- **Розв'язати рівняння** — знайти **всі** корені або довести, що їх немає.

### Рівність як терези

Рівняння — це терези в рівновазі. Ліва чаша — лівий вираз, права — правий. Якщо з обома чашами зробити те саме, рівновага збережеться.

```
   x + 3        10
  ───────  =  ──────
      ▲            
```

## 4. Рівносильні перетворення

Два рівняння **рівносильні**, якщо мають **однакові** множини коренів. Розв'язування — ланцюжок рівносильних перетворень до вигляду «x = число».

| Перетворення | Рівносильне? | Пояснення |
|---|---|---|
| Додати або відняти одне й те саме число чи вираз з обох частин | так | терези: поклали однакову вагу на обидві чаші |
| Перенести доданок в іншу частину зі зміною знака | так | це те саме, що відняти його з обох частин |
| Помножити або поділити обидві частини на число ≠ 0 | так | розтягнули обидві чаші однаково |
| Помножити на **0** | **ні** | будь-яке рівняння стане 0 = 0 |
| Поділити на вираз з невідомим | **небезпечно** | можна **загубити корінь**, якщо вираз дорівнює 0 |
| Помножити на вираз з невідомим | **небезпечно** | можна **отримати сторонній корінь** |
| Піднести обидві частини до квадрата | **небезпечно** | можна отримати сторонній корінь: x = 3 → x² = 9 має ще корінь −3 |
| Тотожне перетворення однієї частини | так, якщо не змінюється ОДЗ | скоротити x/x до 1 — змінює ОДЗ |

**Приклад втрати кореня.** x² = 3x. Якщо поділити на x, вийде x = 3 — і корінь x = 0 загублено. Правильно: x² − 3x = 0, x(x − 3) = 0, x = 0 або x = 3.

**Приклад стороннього кореня.** √(x + 2) = x. Піднесемо до квадрата: x + 2 = x², x² − x − 2 = 0, x = 2 або x = −1. Перевірка: √4 = 2 ✓; √1 = 1 ≠ −1 ✗. Корінь −1 сторонній. Після «небезпечних» перетворень **перевірка обов'язкова**.

## 5. Метод розв'язування лінійного рівняння

1. Розкрити дужки.
2. Звести подібні в кожній частині.
3. Перенести доданки з невідомим ліворуч, числа праворуч.
4. Поділити на коефіцієнт при x.
5. Перевірити підстановкою.

**Приклад.** 3(x − 2) + 4 = x + 6.
- 3x − 6 + 4 = x + 6;
- 3x − 2 = x + 6;
- 3x − x = 6 + 2;
- 2x = 8, x = 4.
- Перевірка: 3·2 + 4 = 10, 4 + 6 = 10 ✓.

Три випадки для ax = b:
- a ≠ 0 — єдиний корінь x = b/a;
- a = 0, b = 0 — будь-яке x (0·x = 0);
- a = 0, b ≠ 0 — коренів немає (0·x = 5).

## 6. Формула

**Формула** — рівність, що пов'язує величини: S = a·b, v = s/t, F = 32 + 1,8C. З формули можна **виразити** будь-яку величину через інші — це те саме розв'язування рівняння, тільки відповідь — вираз.

- Із s = v·t: t = s/v, v = s/t.
- Із P = 2(a + b): a = P/2 − b.
- Із F = 32 + 1,8C: C = (F − 32)/1,8. При F = 98,6: C = 37.
- Із S = πr²: r = √(S/π) (r > 0).

**Перевірка розмірностей** допомагає помітити помилку: t = s/v має розмірність м : (м/с) = с ✓; t = v/s дає 1/с — неправильно.

## 7. Кілька способів розв'язати рівняння

Розв'яжемо **5x − 7 = 3x + 9** трьома способами.

1. **Алгебраїчно (терези):** 5x − 3x = 9 + 7, 2x = 16, x = 8.
2. **Обернені операції («розмотування»):** для простих рівнянь виду 3x + 5 = 20 ідемо назад: x помножили на 3 і додали 5, отримали 20. Отже віднімаємо 5 (15) і ділимо на 3 (5).
3. **Графічно:** корінь — абсциса точки перетину прямих y = 5x − 7 і y = 3x + 9. Прямі перетинаються в точці (8; 33).
4. **Підбором і перевіркою:** для задач з цілими відповідями. Спробували x = 5: 18 і 24 — ліва менша; x = 10: 43 і 39 — ліва більша; отже корінь між 5 і 10, x = 8 дає 33 = 33.
5. **Числовими методами (для складних рівнянь):** метод поділу відрізка навпіл, метод Ньютона. Так комп'ютер розв'язує рівняння, які не розв'язуються формулою.

**Способи уявити невідоме:**
- **Коробочка:** x — закрита коробка з якоюсь кількістю цукерок; 3x + 5 = 20 — «три однакові коробки й 5 цукерок разом — 20 цукерок».
- **Відрізок (схема Сінгапурської методики):** невідоме — відрізок, рівні величини — рівні відрізки; задачі на частини розв'язуються малюнком без букв.
- **Функція:** розв'язати f(x) = 0 — знайти, де графік перетинає вісь x.

## Типові помилки

1. Переносити доданок в іншу частину без зміни знака.
2. Ділити на вираз з невідомим і губити корінь.
3. Підносити до квадрата й не перевіряти корені.
4. Плутати вираз і рівняння: вираз спрощують, рівняння розв'язують.
5. Розкривати −(x − 3) як −x − 3 замість −x + 3.
6. Множити на число лише одну частину рівняння або лише один доданок.
7. Забувати ОДЗ (знаменник ≠ 0, підкореневий вираз ≥ 0).
