# Арифметичні дії та їхні властивості

Чотири дії — додавання, віднімання, множення, ділення — і закони, яким вони підкоряються. Ці закони пояснюють, **чому** працюють усі прийоми усного рахунку, розкриття дужок і алгебраїчні перетворення. Алгебра — це по суті арифметика, де закони застосовують до букв.

Пов'язані нотатки: [[Основи]], [[Системи числення]], [[Змінні, вирази і рівняння]], [[Математика — зміст]].

## 1. Зміст чотирьох дій

| Дія | Компоненти | Зміст |
|---|---|---|
| Додавання a + b = c | доданки, сума | об'єднати дві групи; на числовій прямій — крок праворуч на b |
| Віднімання a − b = c | зменшуване, від'ємник, різниця | забрати b з a; або «на скільки a більше за b»; обернене до додавання: c + b = a |
| Множення a · b = c | множники, добуток | **повторне додавання**: 3·4 = 4 + 4 + 4; площа прямокутника 3×4; кількість пар у декартовому добутку |
| Ділення a : b = c | ділене, дільник, частка | обернене до множення: c · b = a. Два змісти: **на скільки частин** (12 цукерок на 3 дітей — по 4) і **скільки разів уміщується** (у 12 скільки разів по 3 — 4) |

**Множення як площа** — найкорисніша модель: 23·14 = прямокутник 23×14, який розрізаємо на (20 + 3)×(10 + 4) = 200 + 80 + 30 + 12 = 322. Так працює множення в стовпчик.

## 2. Закони (властивості) дій

| Закон | Додавання | Множення |
|---|---|---|
| **Переставний** (комутативність) | a + b = b + a | a·b = b·a |
| **Сполучний** (асоціативність) | (a + b) + c = a + (b + c) | (a·b)·c = a·(b·c) |
| **Нейтральний елемент** | a + 0 = a | a·1 = a |
| **Протилежний / обернений** | a + (−a) = 0 | a·(1/a) = 1, a ≠ 0 |
| **Розподільний** (дистрибутивність) | a·(b + c) = a·b + a·c | |

### Чому переставний закон для множення істинний

3·4 — це 3 рядки по 4 точки. Поверніть малюнок на 90°: тепер це 4 рядки по 3. Кількість точок не змінилася, отже 3·4 = 4·3. Аргумент працює для будь-яких натуральних чисел.

```
● ● ● ●        ● ● ●
● ● ● ●   ↔    ● ● ●
● ● ● ●        ● ● ●
               ● ● ●
```

### Розподільний закон — головний

Він єдиний пов'язує **дві** дії. Площа прямокутника a×(b + c) дорівнює сумі площ a×b і a×c.

```
      b       c
  ┌───────┬───────┐
a │  a·b  │  a·c  │
  └───────┴───────┘
```

На ньому тримаються:
- **усний рахунок:** 7·98 = 7·(100 − 2) = 700 − 14 = 686; 25·44 = 25·4·11 = 1100;
- **розкриття дужок:** 3(x + 5) = 3x + 15;
- **винесення спільного множника:** 6x + 9 = 3(2x + 3);
- **зведення подібних:** 3x + 5x = (3 + 5)x = 8x;
- **формули скороченого множення:** (a + b)² = (a + b)(a + b) = a² + 2ab + b².

### Що НЕ виконується

- Віднімання і ділення **не переставні**: 5 − 3 ≠ 3 − 5, 6 : 2 ≠ 2 : 6.
- Віднімання і ділення **не сполучні**: (8 − 4) − 2 = 2, а 8 − (4 − 2) = 6; (8 : 4) : 2 = 1, а 8 : (4 : 2) = 4. Тому для них важливий порядок: виконують **зліва направо**.
- Множення не розподільне відносно множення: 2·(3·4) ≠ (2·3)·(2·4).
- Піднесення до степеня **не розподільне** відносно додавання: (a + b)² ≠ a² + b². Це найчастіша помилка в алгебрі.

**Прийом:** віднімання = додавання протилежного (a − b = a + (−b)), ділення = множення на обернене (a : b = a·(1/b)). Тоді переставляти можна: 8 − 5 + 2 = 8 + (−5) + 2 = 8 + 2 + (−5) = 5.

## 3. Роль 0 і 1

| Властивість | Формула | Пояснення |
|---|---|---|
| 0 — нейтральний для додавання | a + 0 = a | нічого не додали |
| 1 — нейтральна для множення | a·1 = a | взяли один раз |
| Множення на 0 | a·0 = 0 | 0 разів по a — нічого; або 0 = a·(1 − 1) = a − a |
| Добуток дорівнює нулю | a·b = 0 ⇔ a = 0 або b = 0 | основа розв'язування рівнянь (x − 2)(x + 3) = 0 |
| 0 : a | 0 (a ≠ 0) | 0 предметів на a частин — по 0 |
| a : 0 | **не визначено** | див. нижче |
| 0⁰ | зазвичай вважають 1 (у комбінаториці й алгебрі), але в аналізі це невизначеність | |

### Чому на нуль ділити не можна

Ділення визначене як обернене до множення: a : b = c означає c·b = a.
- **6 : 0 = c** означало б c·0 = 6. Але c·0 = 0 для будь-якого c, тож такого c **не існує**.
- **0 : 0 = c** означало б c·0 = 0. Це виконується для **будь-якого** c, тож відповідь не однозначна.

В обох випадках ділення втрачає зміст, тому його не визначають. У JavaScript `6 / 0` дає `Infinity`, а `0 / 0` — `NaN`: це домовленості стандарту чисел з рухомою комою, а не математичні значення.

## 4. Порядок дій

1. Дії в **дужках** (зсередини назовні).
2. **Степені** й корені.
3. **Множення і ділення** — зліва направо, як рівноправні.
4. **Додавання і віднімання** — зліва направо, як рівноправні.

Приклади:
- 2 + 3·4 = 2 + 12 = 14 (не 20).
- 20 − 8 : 2·3 = 20 − 4·3 = 20 − 12 = 8.
- 8 : 2·(2 + 2) = 8 : 2·4 = 4·4 = 16 (зліва направо; записи на кшталт «8 : 2(2 + 2)» неоднозначні, тому в серйозних текстах їх уникають і ставлять дужки).
- −3² = −9, а (−3)² = 9: степінь виконується раніше за унарний мінус.
- 2³² = 2⁹ = 512, якщо читати як 2^(3²): степені вкладаються **справа наліво**.

## 5. Дії з від'ємними числами (коротко)

| Правило | Приклад |
|---|---|
| a − b = a + (−b) | 3 − 7 = 3 + (−7) = −4 |
| −(−a) = a | −(−5) = 5 |
| (+)·(+) = (+), (−)·(−) = (+) | (−3)·(−4) = 12 |
| (+)·(−) = (−) | 3·(−4) = −12 |
| ділення — так само | (−12) : (−4) = 3 |

**Чому мінус на мінус дає плюс.** З розподільного закону: (−3)·(−4 + 4) = (−3)·0 = 0. Розкриємо дужки: (−3)(−4) + (−3)·4 = 0, тобто (−3)(−4) − 12 = 0, отже (−3)(−4) = 12. Правило знаків — не домовленість, а **наслідок** розподільного закону. Інтуїція: множення на −1 — це поворот на числовій прямій на 180°; два повороти повертають у вихідний бік.

## 6. Ділення з остачею

Для цілих a і натурального b існують єдині q (неповна частка) і r (остача), що

$$a = b\cdot q + r,\quad 0\le r<b.$$

- 17 = 5·3 + 2: 17 : 5 = 3 (ост. 2).
- 3 = 5·0 + 3.
- −7 = 3·(−3) + 2: остача завжди невід'ємна в математиці. У JS `-7 % 3` дає `-1` — це інша домовленість (знак за діленим).

Остачі — основа подільності, перевірки парності, годинникової (модульної) арифметики. Див. [[Теорія чисел і модульна арифметика]].

## 7. Прийоми усного рахунку і чому вони працюють

| Прийом | Приклад | Закон |
|---|---|---|
| Групування до круглих | 37 + 48 + 63 = (37 + 63) + 48 = 148 | переставний і сполучний |
| Округлення і поправка | 398 + 257 = 400 + 257 − 2 = 655 | сполучний |
| Розкладання множника | 25·36 = 25·4·9 = 900 | сполучний |
| Множення на 5 | 46·5 = 460 : 2 = 230 | 5 = 10 : 2 |
| Множення на 11 | 43·11 = 430 + 43 = 473 | розподільний |
| Множення на 9, 99 | 56·99 = 5600 − 56 = 5544 | розподільний |
| Близькі до круглого | 49·51 = 50² − 1 = 2499 | (a − b)(a + b) = a² − b² |
| Квадрат числа на 5 | 35²: 3·4 = 12, дописати 25 → 1225 | (10a + 5)² = 100a(a + 1) + 25 |

## 8. Перевірка результату

- **Оберненою дією:** 342 : 18 = 19, перевірка 19·18 = 342.
- **Оцінкою:** 48·21 ≈ 50·20 = 1000, отже 1008 правдоподібно, а 10 080 — ні.
- **Остання цифра:** 37·43 закінчується на 7·3 = 21 → 1.
- **Парність:** сума двох непарних парна, добуток непарних непарний.
- **Дев'ятка:** число при діленні на 9 дає ту саму остачу, що й сума його цифр; перевірка добутку «відкиданням дев'яток».

## 9. Кілька способів думати про дії

**Множення — п'ять моделей:**
1. **Повторне додавання**: 3·4 = 4 + 4 + 4.
2. **Прямокутник (площа)**: 3·4 — прямокутник 3×4. Звідси переставний і розподільний закони та множення в стовпчик.
3. **Масштабування (розтяг)**: множення на 3 розтягує числову пряму втричі; на ½ — стискає вдвічі; на −1 — перевертає. Ця модель пояснює множення дробів і від'ємних чисел, де «повторне додавання» не працює.
4. **Кількість комбінацій**: 3 сорочки і 4 штани — 3·4 = 12 комплектів (декартів добуток).
5. **Дерево вибору**: кожна гілка першого рівня розходиться на 4 гілки другого.

**Віднімання — три моделі:** забрати («було 9, забрали 4»); порівняти («на скільки 9 більше за 4» — відстань між точками на прямій); доповнити («скільки додати до 4, щоб отримати 9»). Третя модель найзручніша для усного рахунку: 1000 − 763 — доповнюємо 763 до 800 (+37), потім до 1000 (+200): 237.

**Ділення — чотири моделі:** розподіл на рівні частини; вміщення («скільки разів»); обернене множення; дріб (a : b = a/b, див. звичайні дроби).

**Від'ємні числа — три моделі:** борг і гроші (−5 — борг 5 гривень; відняти борг = отримати гроші); температура (рух униз і вгору термометром); поворот на прямій (множення на −1 — поворот на 180°).
