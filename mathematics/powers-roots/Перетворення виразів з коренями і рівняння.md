# Перетворення виразів з коренями і рівняння

Як спрощувати вирази з квадратними коренями: виносити й вносити множник, додавати, множити й ділити корені, звільнятися від ірраціональності в знаменнику, працювати з модулем, розв'язувати рівняння й нерівності. Зміст кореня й наближені значення — у [[Квадратний корінь]].

Пов'язані нотатки: [[Квадратний корінь]], [[Степені з цілим показником]], [[Змінні, вирази і рівняння]], [[Корінь n-го степеня і дробові показники]].

## 1. Головна ідея: корінь поводиться як «одиниця виміру»

Вираз 3√2 можна читати як «три штуки √2», так само як 3x — «три штуки x». Тому:
- **подібні** корені (з однаковим підкореневим виразом) додаються як подібні доданки: 3√2 + 5√2 = 8√2;
- **неподібні** не додаються: √2 + √3 — так і лишається (як x + y);
- щоб побачити подібність, корінь **спрощують** — виносять множник.

## 2. Винесення множника з-під кореня

**Ідея:** знайти в підкореневому числі **повний квадрат**-множник і витягти з нього корінь.

$$\sqrt{a^2 b}=a\sqrt{b}\quad(a\ge0)$$

- √50 = √(25·2) = 5√2.
- √72 = √(36·2) = 6√2.
- √300 = √(100·3) = 10√3.
- √(18x³) = √(9x²·2x) = 3x√(2x) (x ≥ 0).

**Три способи знайти квадрат-множник:**
1. **Пробувати найбільші квадрати** 4, 9, 16, 25, 36, 49, 64, 81, 100 — чи ділиться число на них.
2. **Розкласти на прості:** 72 = 2³·3² = (2·3)²·2 → 6√2. Кожна **пара** однакових множників виходить з-під кореня одним множником.
3. **Поступово:** √72 = √(4·18) = 2√18 = 2√(9·2) = 2·3√2 = 6√2.

**Найпростіший вигляд кореня** — коли під коренем не лишилося жодного квадрата-множника (як нескоротний дріб).

## 3. Внесення множника під корінь

Обернена дія: a√b = √(a²b) для a ≥ 0.
- 3√2 = √(9·2) = √18.
- **З від'ємним множником** знак лишається зовні: −2√5 = −√20 (під корінь вноситься лише модуль).

Навіщо: щоб **порівнювати**. 2√7 і 3√3: √28 і √27 → 2√7 > 3√3.

## 4. Дії з коренями

| Дія | Правило | Приклади |
|---|---|---|
| Додавання, віднімання | лише подібних | 3√2 + 5√2 = 8√2; √50 − √18 = 5√2 − 3√2 = 2√2 |
| Множення | √a·√b = √(ab) | √3·√12 = √36 = 6; 2√5·3√2 = 6√10 |
| Ділення | √a : √b = √(a/b) | √75 : √3 = √25 = 5 |
| Квадрат | (√a)² = a; (a√b)² = a²b | (3√2)² = 18 |
| Розкриття дужок | розподільний закон | √2(√8 − 3) = 4 − 3√2 |

### Формули скороченого множення з коренями

- (√a + √b)² = a + 2√(ab) + b: (√3 + √2)² = 5 + 2√6.
- (√a − √b)(√a + √b) = a − b: (√5 − √3)(√5 + √3) = 2.
- (a + √b)(a − √b) = a² − b: (3 + √2)(3 − √2) = 7.

Остання пара — ключ до наступного розділу.

## 5. Звільнення від ірраціональності в знаменнику

Навіщо: дріб 1/√2 незручно рахувати й порівнювати. Помноживши на 1 у вигляді √2/√2, отримуємо √2/2 ≈ 1,414/2 = 0,707 — ділити на 2 легше, ніж на 1,414. Також це дає «стандартний вигляд» відповіді.

**Випадок 1. Знаменник — корінь:** помножити чисельник і знаменник на цей корінь.
- 6/√3 = 6√3/3 = 2√3.
- 5/(2√5) = 5√5/(2·5) = √5/2.

**Випадок 2. Знаменник — сума або різниця з коренем:** помножити на **спряжений** вираз (той самий, але з протилежним знаком між доданками). Добуток спряжених — різниця квадратів, і корені зникають.
- 1/(√2 − 1) = (√2 + 1)/((√2 − 1)(√2 + 1)) = (√2 + 1)/(2 − 1) = **√2 + 1**.
- 4/(3 + √5) = 4(3 − √5)/(9 − 5) = **3 − √5**.
- (√3 + √2)/(√3 − √2) = (√3 + √2)²/(3 − 2) = **5 + 2√6**.

**Чому саме спряжений:** (a + √b)(a − √b) = a² − (√b)² = a² − b — корінь входить у квадраті й зникає.

## 6. Корінь і модуль

$$\sqrt{x^2}=|x|$$

- √((1 − √2)²) = |1 − √2| = √2 − 1, бо 1 − √2 < 0.
- √((x − 3)²) = |x − 3|: при x ≥ 3 це x − 3, при x < 3 — це 3 − x.
- √(x² − 6x + 9) = √((x − 3)²) = |x − 3|.

**Вкладені корені:** √(3 + 2√2) — шукаємо вигляд (a + b)² = a² + 2ab + b² з ab = √2, a² + b² = 3: a = √2, b = 1. Отже √(3 + 2√2) = √2 + 1. Перевірка: (√2 + 1)² = 3 + 2√2 ✓.

## 7. Рівняння з коренями

### x² = a

| a | Розв'язки |
|---|---|
| a > 0 | x = ±√a |
| a = 0 | x = 0 |
| a < 0 | немає |

(x − 2)² = 9 → x − 2 = ±3 → x = 5 або x = −1.

**Зв'язок з теоремою Піфагора:** катети 5 і 12 → гіпотенуза c, c² = 25 + 144 = 169, c = 13 (беремо лише додатний корінь — довжина).

### √x = a

- a ≥ 0: x = a². √x = 7 → x = 49.
- a < 0: розв'язків немає (корінь невід'ємний).

### Ірраціональні рівняння: підносимо до квадрата і перевіряємо

**√(x + 3) = x − 3.**
1. ОДЗ: x + 3 ≥ 0; права частина має бути ≥ 0: x ≥ 3.
2. Квадрат: x + 3 = x² − 6x + 9 → x² − 7x + 6 = 0 → x = 1 або x = 6.
3. Перевірка: x = 6: √9 = 3 = 6 − 3 ✓. x = 1: √4 = 2 ≠ −2 ✗ — **сторонній** (порушує x ≥ 3).

**Відповідь:** x = 6. Піднесення до квадрата — нерівносильне перетворення (див. [[Змінні, вирази і рівняння]]), тому перевірка обов'язкова.

**Два способи уникнути сторонніх коренів:**
1. Перевірити кожен знайдений корінь підстановкою.
2. Заздалегідь записати умову «права частина ≥ 0» і відкинути корені, що її порушують.

### Нерівності

- √x < 3 ⇔ 0 ≤ x < 9 (не забути x ≥ 0!).
- √x > 3 ⇔ x > 9.
- x² < 9 ⇔ −3 < x < 3, тобто |x| < 3.
- x² > 9 ⇔ x < −3 або x > 3.

## 8. Кілька способів спростити один вираз

**√50 + √32 − √18:**
1. **Винести множники:** 5√2 + 4√2 − 3√2 = **6√2**.
2. **Через розклад на прості:** 50 = 2·5², 32 = 2⁵ = 2·4², 18 = 2·3² → (5 + 4 − 3)√2.
3. **Перевірка наближенням:** 7,071 + 5,657 − 4,243 = 8,485; 6·1,4142 = 8,485 ✓.

## Типові помилки

1. Додавати неподібні корені: √2 + √3 = √5.
2. √(a + b) = √a + √b.
3. Виносити з-під кореня неквадратний множник: √12 = 4√3 (правильно 2√3).
4. Забувати модуль: √((x − 5)²) = x − 5 для всіх x.
5. Не перевіряти корені ірраціонального рівняння.
6. При звільненні від ірраціональності множити лише знаменник.
7. Вважати, що √x < 3 означає x < 9 (забути x ≥ 0).
