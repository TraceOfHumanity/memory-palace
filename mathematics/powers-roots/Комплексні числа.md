# Комплексні числа

Серед дійсних чисел рівняння x² = −1 не має розв'язку: квадрат будь-якого дійсного числа невід'ємний. **Комплексні числа** розширюють числову систему, додаючи **уявну одиницю i** з властивістю **i² = −1**. Це останнє розширення в ланцюжку ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ (див. [[Основи]]), і воно завершує алгебру: у ℂ кожне многочленне рівняння має корінь.

Пов'язані нотатки: [[Квадратний корінь]], [[Корінь n-го степеня і дробові показники]], [[Основи]], [[Ряди і число e]], [[Вектори і матриці]].

## 1. Навіщо їх придумали

Історично комплексні числа з'явилися не через x² = −1, а через **кубічні рівняння** (XVI ст., Кардано, Бомбеллі). Формула для коренів кубічного рівняння x³ = 15x + 4 вимагала обчислити √(−121), хоча відповідь x = 4 — звичайне дійсне число. Математики помітили: якщо сміливо рахувати з «неможливими» коренями за звичайними правилами, уявні частини скорочуються і виходить правильна відповідь. Так «уявні» числа стали робочим інструментом задовго до того, як їх зрозуміли.

Слово «уявні» — історична назва (Декарт, з іронією). Комплексні числа не менш «справжні», ніж від'ємні: від'ємні описують борг і напрямок, комплексні — **повороти** й **коливання**. Без них не обійтися в електротехніці (змінний струм), квантовій механіці, обробці сигналів (перетворення Фур'є), комп'ютерній графіці.

## 2. Що таке комплексне число

$$z=a+bi,\qquad a,b\in\mathbb{R},\ i^2=-1$$

- a = **Re z** — дійсна частина; b = **Im z** — уявна частина (саме b, без i).
- 3 + 4i: Re = 3, Im = 4. −2i: Re = 0, Im = −2. 5 = 5 + 0i — дійсні числа є окремим випадком.
- Два комплексні числа рівні, коли рівні їхні дійсні й уявні частини окремо.
- **Порівнювати** комплексні числа на «більше/менше» не можна: на площині немає природного порядку.

## 3. Кілька способів уявити комплексне число

### Спосіб 1. Точка (вектор) на площині

Число a + bi — точка (a; b) на **комплексній площині**: горизонтальна вісь — дійсні числа, вертикальна — уявні. Дійсна пряма — лише одна вісь цієї площини. Комплексні числа — це «числа, які нарешті вийшли з прямої».

```
        Im
         │      • 3 + 4i
       4 ┤     ╱
         │    ╱
         │   ╱  |z| = 5
         │  ╱
         │ ╱
 ────────┼──────────── Re
         0         3
```

### Спосіб 2. Поворот

Множення на −1 — поворот числової прямої на 180°. Яке число, застосоване **двічі**, дає поворот на 180°? Поворот на **90°**. Це і є множення на i: i·i = −1 означає «два повороти на 90° = поворот на 180°».

- 1 → (·i) → i → (·i) → −1 → (·i) → −i → (·i) → 1. Чотири кроки — повний оберт.

Так i перестає бути загадкою: це **поворот на чверть оберту**.

### Спосіб 3. Пара чисел з особливим множенням

Формально: пари (a; b) з додаванням покоординатно і множенням (a; b)·(c; d) = (ac − bd; ad + bc). Тоді (0; 1)·(0; 1) = (−1; 0), тобто i² = −1 — без жодної «уявності».

### Спосіб 4. Матриця повороту і розтягу

Число a + bi діє на площину як матриця ( (a, −b), (b, a) ) — поворот із розтягом (див. [[Вектори і матриці]]). i відповідає матриці повороту на 90°: ( (0, −1), (1, 0) ), і її квадрат — ( (−1, 0), (0, −1) ).

## 4. Арифметика

Рахуємо як з многочленами від i, а i² замінюємо на −1.

| Дія | Формула | Приклад |
|---|---|---|
| Додавання | (a + bi) + (c + di) = (a + c) + (b + d)i | (3 + 2i) + (1 − 5i) = 4 − 3i |
| Віднімання | (a − c) + (b − d)i | (3 + 2i) − (1 − 5i) = 2 + 7i |
| Множення | (ac − bd) + (ad + bc)i | (3 + 2i)(1 − 5i) = 3 − 15i + 2i − 10i² = 13 − 13i |
| Спряжене | z̄ = a − bi | 3 + 2i → 3 − 2i |
| z·z̄ | a² + b² (дійсне!) | (3 + 2i)(3 − 2i) = 9 + 4 = 13 |
| Ділення | помножити чисельник і знаменник на спряжене до знаменника | нижче |

**Ділення.** (1 + 2i)/(3 − i) = (1 + 2i)(3 + i)/((3 − i)(3 + i)) = (3 + i + 6i + 2i²)/10 = (1 + 7i)/10 = **0,1 + 0,7i**.
Це те саме, що звільнення від ірраціональності в знаменнику (див. [[Перетворення виразів з коренями і рівняння]]): спряжене «знищує» уявну частину знаменника, бо z·z̄ — дійсне.

**Геометрія додавання:** додавання — це додавання векторів (правило паралелограма).

### Степені i

| i¹ | i² | i³ | i⁴ | i⁵ | … |
|---|---|---|---|---|---|
| i | −1 | −i | 1 | i | цикл з періодом 4 |

iⁿ визначається остачею n від ділення на 4: i¹⁰⁰ = 1, i²⁰²⁶ = i² = −1 (2026 = 4·506 + 2).

## 5. Модуль і аргумент

- **Модуль** |z| = √(a² + b²) — відстань від 0 до точки (теорема Піфагора). |3 + 4i| = 5.
- **Аргумент** arg z — кут від додатного напрямку дійсної осі до вектора z. arg i = 90°, arg(−1) = 180°, arg(1 + i) = 45°.
- z·z̄ = |z|².

### Тригонометрична форма

$$z=r(\cos\varphi+i\sin\varphi),\quad r=|z|,\ \varphi=\arg z$$

1 + i = √2(cos 45° + i sin 45°).

### Множення — це поворот і розтяг

$$z_1z_2=r_1r_2\big(\cos(\varphi_1+\varphi_2)+i\sin(\varphi_1+\varphi_2)\big)$$

**Модулі множаться, аргументи додаються.** Помножити на i (модуль 1, аргумент 90°) — повернути на 90° без розтягу. Помножити на 2i — повернути на 90° і розтягнути вдвічі. Помножити на 1 + i — повернути на 45° і розтягнути в √2 раза.

Перевірка: (1 + i)² = 1 + 2i + i² = 2i. За формулою: модуль (√2)² = 2, аргумент 45° + 45° = 90° → 2i ✓.

**Формула Муавра:** zⁿ = rⁿ(cos nφ + i sin nφ). (1 + i)⁸ = (√2)⁸·(cos 360° + i sin 360°) = 16.

### Формула Ейлера (на додачу)

$$e^{i\varphi}=\cos\varphi+i\sin\varphi,\qquad e^{i\pi}+1=0$$

Остання рівність пов'язує п'ять найважливіших чисел математики: 0, 1, π, e, i. Пояснення через ряди — у [[Ряди і число e]].

## 6. Квадратні рівняння з від'ємним дискримінантом

x² + 2x + 5 = 0: D = 4 − 20 = −16. √(−16) = 4i. x = (−2 ± 4i)/2 = **−1 ± 2i**.

Перевірка: (−1 + 2i)² + 2(−1 + 2i) + 5 = (1 − 4i − 4) − 2 + 4i + 5 = 0 ✓.

- Корені з від'ємним D завжди **спряжені** (a ± bi), якщо коефіцієнти дійсні.
- Тепер **кожне** квадратне рівняння має два корені (можливо, однакові).

**Основна теорема алгебри** (Гаусс, 1799): кожен многочлен степеня n ≥ 1 з комплексними коефіцієнтами має рівно n комплексних коренів (з урахуванням кратності). Тобто на ℂ розширення числових систем закінчується: нових чисел для розв'язування многочленних рівнянь більше не потрібно.

## 7. Корені з одиниці

Розв'язки zⁿ = 1 — n точок на колі радіуса 1, що утворюють **правильний n-кутник**: аргументи 0°, 360°/n, 2·360°/n, …
- z² = 1: ±1.
- z⁴ = 1: 1, i, −1, −i.
- z³ = 1: 1, −1/2 ± (√3/2)i.

Так алгебраїчне рівняння перетворюється на геометричну фігуру.

## 8. Комплексні числа в програмуванні

- У Python вбудовані: `(3+2j)*(1-5j)` → `(13-13j)`, `abs(3+4j)` → `5.0`, `cmath.phase(1j)` → `π/2`.
- У JS немає вбудованого типу; пару (re, im) реалізують вручну або бібліотекою `complex.js`.
- **Фрактал Мандельброта** — множина c, для яких послідовність z → z² + c не тікає в нескінченність. Уся його краса — це комплексне множення.
- **Перетворення Фур'є** розкладає сигнал на «обертові» складові e^(iωt) — основа стиснення звуку (MP3), зображень (JPEG), обробки радіосигналів.

## Типові помилки

1. Вважати Im(3 + 4i) = 4i (правильно 4).
2. √(−4)·√(−9) = √36 = 6 ✗. Правильно 2i·3i = 6i² = −6. Правило √a·√b = √(ab) працює лише для a, b ≥ 0.
3. Ділити, не множачи на спряжене.
4. Порівнювати комплексні числа на «більше/менше».
5. i³ = i (правильно −i).
6. |a + bi| = a + b (правильно √(a² + b²)).
