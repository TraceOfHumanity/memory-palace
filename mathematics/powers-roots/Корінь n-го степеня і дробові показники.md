# Корінь n-го степеня і дробові показники

Квадратний корінь відповідає на питання «яке число в квадраті дає a». **Корінь n-го степеня** — на питання «яке число в n-му степені дає a». А **дробовий показник** показує, що корені — це ті самі степені: ⁿ√a = a^(1/n). Так усі правила степенів і коренів зливаються в одну систему.

Пов'язані нотатки: [[Степені з цілим показником]], [[Квадратний корінь]], [[Перетворення виразів з коренями і рівняння]], [[Комплексні числа]].

---

## 1. Кубічний корінь

**∛a** — число, куб якого дорівнює a: (∛a)³ = a.
- ∛8 = 2, ∛27 = 3, ∛1000 = 10, ∛0,001 = 0,1.
- **Геометрично:** ребро куба з об'ємом a. Куб об'ємом 64 см³ має ребро 4 см.
- **З від'ємного числа можна:** ∛(−8) = −2, бо (−2)³ = −8. Непарний степінь зберігає знак, тому кожне дійсне число має рівно один дійсний кубічний корінь.

**Куби, які варто знати:** 1, 8, 27, 64, 125, 216, 343, 512, 729, 1000.

## 2. Корінь n-го степеня

**ⁿ√a** — число, n-й степінь якого дорівнює a. n — **показник кореня**.

| n | Яке a допустиме | Скільки дійсних коренів має xⁿ = a | ⁿ√a |
|---|---|---|---|
| парний (2, 4, 6…) | a ≥ 0 | a > 0: два (±); a = 0: один; a < 0: жодного | **невід'ємний** з них |
| непарний (3, 5…) | будь-яке | рівно один | той самий знак, що й a |

- ⁴√16 = 2 (не −2, хоч (−2)⁴ = 16 — арифметичний корінь невід'ємний).
- ⁴√(−16) — не існує серед дійсних.
- ⁵√(−32) = −2.
- ⁿ√(aⁿ) = **|a|** для парного n і **a** для непарного: ⁴√((−3)⁴) = 3, ∛((−3)³) = −3.

## 3. Властивості коренів

Для a, b ≥ 0 (для непарних n — для будь-яких a, b):

| Властивість | Формула | Приклад |
|---|---|---|
| Корінь з добутку | ⁿ√(ab) = ⁿ√a·ⁿ√b | ∛(8·27) = 2·3 = 6 |
| Корінь з частки | ⁿ√(a/b) = ⁿ√a/ⁿ√b | ∛(8/125) = 2/5 |
| Корінь зі степеня | ⁿ√(aᵐ) = (ⁿ√a)ᵐ | ∛(8²) = (∛8)² = 4 |
| Корінь з кореня | ᵐ√(ⁿ√a) = ᵐⁿ√a | √(∛64) = ⁶√64 = 2 |
| Скорочення показників | ⁿᵏ√(aᵐᵏ) = ⁿ√(aᵐ) | ⁶√(a⁴) = ∛(a²) |

Винесення множника працює так само, як для квадратного кореня, лише шукаємо **n-ті** степені: ∛54 = ∛(27·2) = 3∛2; ⁴√48 = ⁴√(16·3) = 2·⁴√3.

## 4. Дробовий показник: звідки він береться

Як визначити 8^(1/3)? Вимагатимемо, щоб правило (aᵐ)ⁿ = aᵐⁿ працювало й тут:

$$\left(8^{1/3}\right)^3=8^{\frac13\cdot3}=8^1=8$$

Отже 8^(1/3) — число, куб якого дорівнює 8, тобто ∛8 = 2. Так само a^(1/2) = √a. **Дробовий показник — не нове поняття, а інший запис кореня**, обраний так, щоб усі закони степенів лишалися правильними.

$$a^{\frac{m}{n}}=\sqrt[n]{a^m}=\left(\sqrt[n]{a}\right)^m,\qquad a>0$$

- **Знаменник** показника — показник кореня, **чисельник** — степінь.
- 8^(2/3) = (∛8)² = 4. Зручніше спершу добувати корінь (менші числа): 27^(4/3) = (∛27)⁴ = 81.
- a^(−m/n) = 1/a^(m/n): 16^(−3/4) = 1/(⁴√16)³ = 1/8.
- 4^(1,5) = 4^(3/2) = (√4)³ = 8.

**Чому основа має бути додатною.** (−8)^(1/3) = −2 здається логічним, але (−8)^(2/6) мало б дорівнювати тому самому (2/6 = 1/3), а ⁶√((−8)²) = ⁶√64 = 2. Щоб не було суперечностей, дробові степені визначають лише для **a > 0** (і 0^(m/n) = 0 при m/n > 0). У JS `Math.pow(-8, 1/3)` дає `NaN`, а `Math.cbrt(-8)` — `-2`.

## 5. Усі закони степенів — тепер з будь-якими раціональними показниками

Для a, b > 0 і раціональних p, q:

| Закон | Приклад з дробами |
|---|---|
| aᵖ·a^q = a^(p+q) | 2^(1/2)·2^(1/3) = 2^(5/6) = ⁶√32 |
| aᵖ : a^q = a^(p−q) | 5^(3/4) : 5^(1/4) = 5^(1/2) = √5 |
| (aᵖ)^q = a^(pq) | (9^(1/4))² = 9^(1/2) = 3 |
| (ab)ᵖ = aᵖbᵖ | (8x³)^(1/3) = 2x |
| a⁰ = 1, a⁻ᵖ = 1/aᵖ | 27^(−1/3) = 1/3 |

**Добуток коренів з різними показниками:** √2·∛2 = 2^(1/2)·2^(1/3) = 2^(5/6) = ⁶√32. Без дробових показників це незрозуміло, з ними — просте додавання дробів.

## 6. Ірраціональні показники

Що таке 2^√2? √2 = 1,41421…; беремо раціональні наближення: 2^1,4 ≈ 2,639, 2^1,41 ≈ 2,657, 2^1,414 ≈ 2,665, 2^1,4142 ≈ 2,6651… Ці числа прямують до одного значення **2^√2 ≈ 2,6651**. Так степінь визначається для будь-якого дійсного показника — і з'являється **показникова функція** y = aˣ (див. [[Найважливіші графіки]]).

## 7. Порівняння коренів різних степенів

Зводимо до **спільного показника кореня**: √3 і ∛5. НСК(2, 3) = 6: √3 = ⁶√27, ∛5 = ⁶√25. 27 > 25, отже **√3 > ∛5**.

Або підносимо до степеня НСК: (√3)⁶ = 27, (∛5)⁶ = 25.

## 8. Кілька способів думати про ⁿ√a і a^(m/n)

| Модель | ∛8 = 2 | 8^(2/3) = 4 |
|---|---|---|
| Обернена дія | яке число в кубі дає 8 | корінь з 8², або (∛8)² |
| Геометрія | ребро куба з об'ємом 8 | площа грані цього куба |
| «Частина множень» | 8 — це три множення на 2 з 1; одна третина шляху — одне множення | дві третини шляху — два множення: 1 → 2 → 4 |
| Логарифмічна шкала | точка на третині відстані від 1 до 8 | на двох третинах |

Модель «частини множень» найглибша: 8 = 2·2·2 — три однакові кроки множення від 1. a^(1/3) — один такий крок, a^(2/3) — два. Дробовий показник ділить «шлях множення» на рівні частини, так само як дріб ділить відрізок.

## 9. Застосування

- **Середнє геометричне** n чисел: ⁿ√(a₁·…·aₙ). Середній річний ріст, якщо за 3 роки капітал зріс у 1,331 раза: ∛1,331 = 1,1 → 10% на рік (див. [[Зміна у відсотках і складні відсотки]]).
- **Музика:** у рівномірній темперації півтон — множник частоти ¹²√2 ≈ 1,0595 (12 півтонів = октава = ×2).
- **Закон Кеплера:** період обертання планети T пропорційний a^(3/2), де a — радіус орбіти.
- **Масштабування:** якщо об'єм кулі збільшився у 8 разів, радіус — у ∛8 = 2 рази.

## Типові помилки

1. ⁴√16 = ±2 (правильно 2).
2. Вважати, що ∛(−8) не існує.
3. a^(1/n) = 1/aⁿ або a^(1/n) = a/n.
4. 8^(2/3) = (8²)/3.
5. √a + ∛a = ⁵√a.
6. Застосовувати дробові степені до від'ємних основ.
7. ⁿ√(aⁿ) = a для парного n і від'ємного a (правильно |a|).
