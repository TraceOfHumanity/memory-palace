# Кути

**Кут** — фігура з двох променів зі спільним початком. Промені — **сторони** кута, спільний початок — **вершина**. Позначення: ∠AOB (вершина посередині), ∠O або ∠α. Кут вимірює **«наскільки повернутий» один промінь відносно іншого** — це міра обертання, а не довжина.

Пов'язані нотатки: [[Основи геометрії — аксіоми]], [[Паралельні прямі]], [[Трикутник]], [[Тригонометрія — одиничне коло і радіани]], [[Довжина кола і число π]], [[Математика — зміст]].

## 1. Кілька способів зрозуміти кут

| Модель | Що таке кут 90° |
|---|---|
| **Поворот** | чверть повного оберту: стрілка годинника з 12 до 3 |
| **Розхил двох променів** | «наскільки розкриті» ножиці |
| **Частина круга** | сектор, що становить 1/4 круга |
| **Напрямок** | зміна курсу корабля з півночі на схід |
| **Нахил** | кут між дорогою і горизонтом |
| **Дуга** | довжина дуги одиничного кола — π/2 (радіанна міра) |

Найкорисніша модель — **поворот**: вона пояснює, чому кути додаються, чому повний кут 360°, і як визначити кути понад 180° чи від'ємні.

## 2. Вимірювання

- **Градус** — 1/360 повного оберту. Мінута — 1/60 градуса, секунда — 1/60 мінути: 23°15′30″.
- **Чому 360:** вавилоняни рахували в шістдесятковій системі, а 360 ≈ кількість днів у році й ділиться на 2, 3, 4, 5, 6, 8, 9, 10, 12…
- **Радіан** — кут, що спирається на дугу довжиною в радіус: 360° = 2π рад (див. [[Тригонометрія — одиничне коло і радіани]]).
- **Транспортир** — півколо з поділками: центр — у вершину, нуль — на одну сторону.

**Аксіома вимірювання кутів:** якщо промінь OC проходить між сторонами кута AOB, то ∠AOB = ∠AOC + ∠COB.

## 3. Види кутів

| Вид | Міра | Картинка |
|---|---|---|
| Нульовий | 0° | промені збігаються |
| Гострий | 0° < α < 90° | `∠` вузький |
| Прямий | 90° | `∟` |
| Тупий | 90° < α < 180° | розкритий |
| Розгорнутий | 180° | промені — одна пряма |
| Повний | 360° | повний оберт |

## 4. Пари кутів

### 4.1. Суміжні кути

Одна сторона спільна, дві інші утворюють пряму.

```
            C
           /
          /  β
   α     /
 A──────O──────── B
```

**∠AOC + ∠COB = 180°** — разом вони утворюють розгорнутий кут.

### 4.2. Вертикальні кути

Сторони одного — продовження сторін іншого (утворюються при перетині двох прямих).

```
      \   /
     α \ / β
  ──────X──────
     β / \ α
      /   \
```

**Вертикальні кути рівні.**

*Доведення:* α + β = 180° (суміжні) і β + α′ = 180° (суміжні, де α′ — вертикальний до α). Отже α = 180° − β = α′. ∎

*Інтуїція поворотом:* поверніть картинку на 180° навколо точки перетину — кожен кут перейде у свій вертикальний.

### 4.3. Інші пари

- **Доповняльні:** сума 90° (кути гострого кута прямокутного трикутника).
- **Кути з відповідно паралельними сторонами** — рівні або в сумі 180° (див. [[Паралельні прямі]]).
- **Кути з відповідно перпендикулярними сторонами** — так само рівні або в сумі 180°.

## 5. Бісектриса

**Бісектриса** кута — промінь з вершини, що ділить кут навпіл.

**Властивість:** кожна точка бісектриси **рівновіддалена від сторін** кута. І навпаки: точка всередині кута, рівновіддалена від сторін, лежить на бісектрисі. (Доведення — через рівність прямокутних трикутників, див. [[Рівність трикутників]].)

**Кут між бісектрисами суміжних кутів — 90°:** (α + β)/2 = 180°/2.

## 6. Перпендикулярні прямі

Прямі **перпендикулярні** (a ⊥ b), якщо при перетині утворюють прямий кут (тоді всі чотири кути прямі).

- Через точку прямої можна провести **одну** перпендикулярну пряму.
- З точки поза прямою можна опустити **один** перпендикуляр. Його довжина — **відстань від точки до прямої**; вона менша за будь-яку похилу (катет менший за гіпотенузу).

## 7. Ключовий приклад трьома способами

**Задача.** Дві прямі перетинаються, один з кутів на 40° більший за інший. Знайдіть усі кути.

1. **Рівняння:** суміжні x і x + 40: 2x + 40 = 180 ⇒ x = 70. Кути 70°, 110°, 70°, 110°.
2. **Вирівнювання:** якщо забрати «зайві» 40°, залишиться 140° на два рівні кути — по 70°.
3. **Середнє і відхилення:** середнє суміжних — 90°, відхилення 20° ⇒ 70° і 110°.

## 8. Кути на годиннику та в навігації

- **Годинник:** хвилинна стрілка проходить 6° за хвилину, годинна — 0,5° за хвилину (30° за годину). О 3:00 кут 90°; о 3:30 — |30·3 + 0,5·30 − 6·30| = |105 − 180| = 75°.
- **Азимут** — кут від напрямку на північ за годинниковою стрілкою: схід 90°, південь 180°, захід 270°.
- **Кут підйому** дороги часто подають у відсотках: 10% — 10 м підйому на 100 м по горизонталі, тобто tg α = 0,1, α ≈ 5,7°.

## 9. Типові помилки

| Помилка | Правильно |
|---|---|
| ∠AOB: вершина — A | вершина — середня літера O |
| Кут залежить від довжини сторін | лише від розхилу променів |
| Вертикальні кути в сумі 180° | вертикальні рівні; суміжні в сумі 180° |
| Будь-які два кути зі спільною стороною — суміжні | ще треба, щоб інші сторони утворили пряму |
| Відстань від точки до прямої — будь-який відрізок | лише перпендикуляр |
| О 3:30 стрілки утворюють 90° | 75° — годинна стрілка теж рухається |
