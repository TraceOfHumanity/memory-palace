# Координати на площині

**Метод координат** перетворює геометрію на алгебру: точка стає парою чисел (x; y), пряма — лінійним рівнянням, коло — квадратним. Це відкриття Декарта і Ферма (XVII ст.) — **аналітична геометрія**. Тепер, щоб довести геометричне твердження, можна просто порахувати. Задачі, що вимагали хитрих додаткових побудов, розв'язуються механічно. Так працюють комп'ютерна графіка, GPS, карти, ігри.

Пов'язані нотатки: [[Графіки — основи]], [[Лінійна функція]], [[Теорема Піфагора]], [[Коло і круг]], [[Вектори на площині]], [[Геометричні перетворення]], [[Конічні перерізи]], [[Математика — зміст]].

## 1. Основні формули

| Що | Формула | Звідки |
|---|---|---|
| **Відстань** між A(x₁; y₁) і B(x₂; y₂) | √((x₂ − x₁)² + (y₂ − y₁)²) | Піфагор: Δx і Δy — катети |
| **Середина** відрізка | ((x₁ + x₂)/2; (y₁ + y₂)/2) | середнє арифметичне координат |
| **Поділ у відношенні** m : n від A | ((nx₁ + mx₂)/(m + n); (ny₁ + my₂)/(m + n)) | зважене середнє |
| **Центроїд** трикутника | ((x₁ + x₂ + x₃)/3; (y₁ + y₂ + y₃)/3) | див. [[Чудові точки трикутника]] |
| **Площа** трикутника | ½\|(x₂ − x₁)(y₃ − y₁) − (x₃ − x₁)(y₂ − y₁)\| | визначник (див. [[Площі фігур]]) |

## 2. Пряма

### 2.1. Форми рівняння

| Форма | Запис | Що видно |
|---|---|---|
| з кутовим коефіцієнтом | y = kx + b | нахил і перетин з Oy |
| загальна | Ax + By + C = 0 | охоплює і вертикальні прямі (B = 0) |
| через точку і нахил | y − y₀ = k(x − x₀) | зручно складати |
| через дві точки | (y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁) | — |
| у відрізках | x/a + y/b = 1 | перетини з осями (a; 0), (0; b) |

**Нормальний вектор:** у прямої Ax + By + C = 0 вектор (A; B) **перпендикулярний** до неї. *Чому:* для двох точок прямої A(x₂ − x₁) + B(y₂ − y₁) = 0 — скалярний добуток (A; B) на напрямний вектор дорівнює нулю.

### 2.2. Паралельність і перпендикулярність

- паралельні: k₁ = k₂ (або (A₁; B₁) ∥ (A₂; B₂));
- перпендикулярні: k₁k₂ = −1 (або A₁A₂ + B₁B₂ = 0).

### 2.3. Відстань від точки до прямої

$$d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$$

**Звідки:** проєктуємо вектор від будь-якої точки прямої до (x₀; y₀) на одиничний нормальний вектор (A; B)/√(A² + B²).

## 3. Коло

**Коло з центром (a; b) і радіусом r** — точки на відстані r від центра. За формулою відстані:

$$(x-a)^2+(y-b)^2=r^2$$

**Загальне рівняння** x² + y² + Dx + Ey + F = 0 зводиться до канонічного виділенням повних квадратів:
x² + y² − 6x + 4y − 3 = 0 ⇒ (x − 3)² + (y + 2)² = 16 — центр (3; −2), r = 4.

Якщо після виділення праворуч від'ємне число — це не коло (порожня множина); нуль — точка.

**Перетин прямої й кола** — система лінійного і квадратного рівнянь; кількість розв'язків (0, 1, 2) = знак дискримінанта.

## 4. Метод координат для доведень

### 4.1. Алгоритм

1. Вдало розташувати осі (центр у вершині, вісь вздовж сторони, використати симетрію).
2. Записати координати точок через параметри.
3. Перевести твердження в рівність і перевірити алгебраїчно.

### 4.2. Ключовий приклад кількома способами

**Теорема.** Медіана прямокутного трикутника до гіпотенузи дорівнює половині гіпотенузи.

**Спосіб 1 (координати).** C(0; 0), A(2a; 0), B(0; 2b). Середина гіпотенузи M(a; b). CM = √(a² + b²), AB = √(4a² + 4b²) = 2√(a² + b²) ⇒ CM = AB/2 ∎. (Множник 2 у координатах — щоб уникнути дробів.)

**Спосіб 2 (прямокутник).** Добудуємо трикутник до прямокутника; діагоналі прямокутника рівні й діляться навпіл.

**Спосіб 3 (описане коло).** Прямий кут спирається на діаметр ⇒ середина гіпотенузи — центр описаного кола ⇒ MA = MB = MC = R.

### 4.3. Ще приклад: паралелограм

Довести: сума квадратів діагоналей паралелограма = сума квадратів сторін. A(0; 0), B(a; 0), D(b; c), C(a + b; c). AC² + BD² = (a + b)² + c² + (b − a)² + c² = 2a² + 2b² + 2c² = 2(AB² + AD²) ✓.

## 5. Інші системи координат

- **Полярні:** точка задається відстанню r від початку і кутом φ: x = r cos φ, y = r sin φ. Коло — r = const, спіраль Архімеда — r = aφ. Зручні для обертань і радарів.
- **Географічні:** широта і довгота — «полярні координати на сфері».
- **Екранні:** у комп'ютерній графіці вісь y спрямована вниз.
- **Простір:** (x; y; z) (див. [[Координати і вектори в просторі]]).

## 6. Типові помилки

| Помилка | Правильно |
|---|---|
| Відстань = (x₂ − x₁) + (y₂ − y₁) | корінь із суми квадратів |
| Середина = ((x₂ − x₁)/2; …) | півсума, не піврізниця |
| (x + 3)² + (y − 1)² = 9: центр (3; −1) | центр (−3; 1) |
| Радіус кола x² + y² = 9 дорівнює 9 | 3 |
| Перпендикулярні: k₂ = −k₁ | k₂ = −1/k₁ |
| Відстань до прямої — без модуля | модуль у чисельнику |
| Не можна записати вертикальну пряму | x = a (загальна форма, B = 0) |
