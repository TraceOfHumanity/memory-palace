# Координати і вектори в просторі

У просторі точку задають **трьома** числами (x; y; z): довжина, ширина, висота. Усі формули площини переносяться майже без змін — додається третя координата. Але з'являються й нові об'єкти: **рівняння площини** і **векторний добуток**. Метод координат у просторі — найпотужніший інструмент стереометрії: задачі про кути й відстані, що вимагають хитрих побудов, розв'язуються обчисленням. Так працюють 3D-графіка, CAD-програми, фізичні рушії ігор, GPS.

## 1. Система координат

Три взаємно перпендикулярні осі Ox, Oy, Oz зі спільним початком. **Права система:** якщо пальці правої руки повертають від Ox до Oy, великий палець показує Oz.

Кімната як модель: кут кімнати — початок, два ребра підлоги — Ox і Oy, вертикальне ребро — Oz.

## 2. Формули — як на площині, плюс z

| Що | Формула |
|---|---|
| відстань | √((x₂ − x₁)² + (y₂ − y₁)² + (z₂ − z₁)²) |
| середина | ((x₁ + x₂)/2; (y₁ + y₂)/2; (z₁ + z₂)/2) |
| вектор AB⃗ | (x₂ − x₁; y₂ − y₁; z₂ − z₁) |
| довжина | \|a⃗\| = √(a₁² + a₂² + a₃²) |
| скалярний добуток | a⃗·b⃗ = a₁b₁ + a₂b₂ + a₃b₃ = \|a⃗\|\|b⃗\|cos φ |
| сфера | (x − a)² + (y − b)² + (z − c)² = R² |

**Чому відстань — «тричі Піфагор».** Від A до B: спершу зміщення по x і y дає діагональ основи √(Δx² + Δy²), потім по z — ще один прямокутний трикутник: √(Δx² + Δy² + Δz²). Це діагональ прямокутного паралелепіпеда.

## 3. Рівняння площини

$$Ax+By+Cz+D=0$$

Вектор **n⃗ = (A; B; C)** — **нормаль**, перпендикулярна до площини. *Чому:* для будь-яких двох точок площини A(x₂ − x₁) + B(y₂ − y₁) + C(z₂ − z₁) = 0 — нормаль перпендикулярна до будь-якого вектора в площині.

**Як скласти:**
- через точку M₀ з нормаллю n⃗: A(x − x₀) + B(y − y₀) + C(z − z₀) = 0;
- через три точки: знайти нормаль як векторний добуток двох векторів площини (або розв'язати систему).

**Окремі випадки:** z = 0 — площина Oxy; x = 3 — площина, паралельна Oyz; x/a + y/b + z/c = 1 — площина з відрізками a, b, c на осях.

**Відстань від точки до площини:**

$$d=\frac{|Ax_0+By_0+Cz_0+D|}{\sqrt{A^2+B^2+C^2}}$$

## 4. Пряма в просторі

Пряма задається точкою M₀ і **напрямним вектором** s⃗ = (p; q; r):

(x; y; z) = (x₀; y₀; z₀) + t(p; q; r) — **параметричне рівняння** (t — «час», точка рухається вздовж прямої).

Канонічна форма: (x − x₀)/p = (y − y₀)/q = (z − z₀)/r.

## 5. Векторний добуток

$$\vec a\times\vec b=(a_2b_3-a_3b_2;\ a_3b_1-a_1b_3;\ a_1b_2-a_2b_1)$$

- результат — **вектор, перпендикулярний** до обох;
- довжина = **площа паралелограма**, натягнутого на a⃗ і b⃗: |a⃗||b⃗|sin φ;
- напрямок — за правилом правої руки;
- a⃗ × b⃗ = −b⃗ × a⃗ (порядок важливий!).

**Мішаний добуток** (a⃗ × b⃗)·c⃗ — об'єм паралелепіпеда (зі знаком); дорівнює визначнику 3×3 з координат (див. [[Вектори і матриці]]). Нуль — вектори компланарні.

## 6. Кути

| Кут | Формула |
|---|---|
| між прямими (напрямні s⃗₁, s⃗₂) | cos φ = \|s⃗₁·s⃗₂\|/(\|s⃗₁\|\|s⃗₂\|) |
| між прямою і площиною | sin φ = \|s⃗·n⃗\|/(\|s⃗\|\|n⃗\|) |
| між площинами | cos φ = \|n⃗₁·n⃗₂\|/(\|n⃗₁\|\|n⃗₂\|) |

**Чому між прямою і площиною — синус:** кут з нормаллю доповнює кут з площиною до 90°.

## 7. Ключовий приклад кількома способами

**Задача.** Куб ABCDA₁B₁C₁D₁ з ребром 1. Знайдіть кут між діагоналлю куба AC₁ і діагоналлю грані BD.

**Спосіб 1 (координати).** A(0; 0; 0), C₁(1; 1; 1), B(1; 0; 0), D(0; 1; 0). AC₁⃗ = (1; 1; 1), BD⃗ = (−1; 1; 0). Скалярний добуток −1 + 1 + 0 = 0 ⇒ **90°**.

**Спосіб 2 (теорема про три перпендикуляри).** Проєкція AC₁ на основу — AC. У квадраті AC ⊥ BD. За теоремою про три перпендикуляри BD ⊥ AC₁.

**Спосіб 3 (симетрія).** Площина ACC₁A₁ — площина симетрії куба, що переводить B у D. Отже BD перпендикулярна до цієї площини, а AC₁ у ній лежить.

## 8. Застосування

- **3D-графіка:** вершини моделі — вектори; повороти — матриці 3×3; освітлення — скалярний добуток нормалі й напрямку на світло; видимість грані — знак скалярного добутку нормалі й напрямку на камеру.
- **Фізика:** момент сили M⃗ = r⃗ × F⃗; сила Лоренца F⃗ = qv⃗ × B⃗.
- **GPS:** приймач розв'язує систему рівнянь сфер (відстані до супутників) — перетин чотирьох сфер дає точку.

## 9. Типові помилки

| Помилка | Правильно |
|---|---|
| Відстань без z | три доданки під коренем |
| Нормаль площини 2x − y + 3z = 5 — (2; −1; 5) | (2; −1; 3) |
| a⃗ × b⃗ = b⃗ × a⃗ | = −b⃗ × a⃗ |
| Векторний добуток — число | вектор (скалярний — число) |
| Кут між прямою і площиною — через cos з нормаллю | sin |
| Площина x = 3 — пряма | у просторі це площина |
| Векторний добуток на площині | визначений лише в 3D |
