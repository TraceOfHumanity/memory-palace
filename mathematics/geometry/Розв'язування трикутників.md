# Розв'язування трикутників

**Розв'язати трикутник** — за трьома відомими елементами (хоча б один з яких — сторона) знайти решту сторін і кутів. Для прямокутного трикутника вистачає Піфагора і означень sin, cos, tg. Для довільного є два інструменти: **теорема косинусів** (узагальнений Піфагор) і **теорема синусів**. На них стоять геодезія, навігація, GPS, астрономія — скрізь, де відстань не виміряти рулеткою, але можна виміряти кути.

Пов'язані нотатки: [[Тригонометрія — одиничне коло і радіани]], [[Теорема Піфагора]], [[Трикутник]], [[Рівність трикутників]], [[Коло і круг]], [[Площі фігур]], [[Вектори на площині]], [[Математика — зміст]].

## 1. Прямокутний трикутник

| Відомо | Знаходимо |
|---|---|
| два катети a, b | c = √(a² + b²), tg α = a/b |
| катет a і гіпотенуза c | b = √(c² − a²), sin α = a/c |
| гіпотенуза c і кут α | a = c·sin α, b = c·cos α |
| катет b і прилеглий кут α | a = b·tg α, c = b/cos α |

**Мнемоніка:** протилежний катет = гіпотенуза × синус; прилеглий = гіпотенуза × косинус.

## 2. Теорема косинусів

$$c^2=a^2+b^2-2ab\cos\gamma$$

**Сенс:** це Піфагор з **поправкою**. При γ = 90° cos γ = 0 — звичайний Піфагор. Якщо γ гострий (cos > 0), c² **менше** за a² + b²; якщо тупий — **більше**. Поправка 2ab·cos γ показує, наскільки кут «відхиляється» від прямого.

### 2.1. Три доведення

**Спосіб 1 (висота).** Опустимо висоту h з B на AC. Відрізок CH = a·cos γ, AH = b − a·cos γ. Піфагор у ΔABH: c² = h² + (b − a cos γ)², а h² = a² − a²cos²γ. Разом: c² = a² − a²cos²γ + b² − 2ab cos γ + a²cos²γ = a² + b² − 2ab cos γ.

**Спосіб 2 (вектори).** c⃗ = a⃗ − b⃗ (вектори зі спільним початком у C). |c⃗|² = |a⃗|² + |b⃗|² − 2a⃗·b⃗ = a² + b² − 2ab cos γ (див. [[Вектори на площині]]).

**Спосіб 3 (координати).** C = (0; 0), A = (b; 0), B = (a cos γ; a sin γ). AB² = (a cos γ − b)² + a²sin²γ = a² + b² − 2ab cos γ.

### 2.2. Коли застосовувати

- Відомі **дві сторони і кут між ними** → третя сторона.
- Відомі **три сторони** → кути: cos γ = (a² + b² − c²)/(2ab).
- **Вид трикутника** за знаком a² + b² − c² (c — найбільша сторона).

## 3. Теорема синусів

$$\frac{a}{\sin\alpha}=\frac{b}{\sin\beta}=\frac{c}{\sin\gamma}=2R$$

**Сенс:** **сторони пропорційні синусам протилежних кутів**; коефіцієнт — діаметр описаного кола.

### 3.1. Два доведення

**Спосіб 1 (висота).** Висота з C: h = b·sin α = a·sin β ⇒ a/sin α = b/sin β.

**Спосіб 2 (описане коло).** Проведемо діаметр BD = 2R. Вписані кути BAC і BDC спираються на одну дугу ⇒ ∠BDC = α. ΔBCD прямокутний (спирається на діаметр) ⇒ a = 2R·sin α. Це доводить ще й, що відношення дорівнює 2R.

### 3.2. Коли застосовувати

- Відомі **сторона і два кути** → інші сторони.
- Відомі **дві сторони і кут проти однієї з них** → кут проти іншої (обережно: може бути 0, 1 або 2 розв'язки — неоднозначний випадок ССК, див. [[Рівність трикутників]]).
- Пов'язати сторону з **радіусом описаного кола**.

## 4. Чотири типові задачі

| Дано | Метод | Скільки розв'язків |
|---|---|---|
| **ССС** — три сторони | косинусів для двох кутів, третій = 180° − … | 1 (якщо існує) |
| **СКС** — дві сторони і кут між ними | косинусів для третьої сторони, далі синусів/косинусів | 1 |
| **КСК / ККС** — сторона і два кути | третій кут = 180° − …, далі синусів | 1 |
| **ССК** — дві сторони і кут не між ними | синусів | 0, 1 або 2 |

**Порада:** шукаючи кут через синус, пам'ятайте: sin α = sin(180° − α). Синус не розрізняє гострий і тупий кут. **Кут через косинус визначається однозначно**, тому для кутів надійніша теорема косинусів.

## 5. Ключовий приклад кількома способами

**Задача.** a = 5, b = 8, γ = 60°. Знайдіть c і площу.

**c — теорема косинусів:** c² = 25 + 64 − 2·5·8·½ = 49 ⇒ **c = 7**.

**Перевірка координатами:** C = (0; 0), A = (8; 0), B = (2,5; 2,5√3). AB² = 5,5² + 18,75 = 30,25 + 18,75 = 49 ✓.

**Площа — три способи:**
1. ½ab sin γ = ½·40·(√3/2) = 10√3.
2. Герон: p = 10, S = √(10·5·2·3) = √300 = 10√3.
3. Координати: основа 8, висота (y точки B) 2,5√3 ⇒ ½·8·2,5√3 = 10√3.

## 6. Інші корисні формули

- **Площа:** S = ½ab sin γ; через R: S = abc/(4R).
- **Медіана:** mc² = (2a² + 2b² − c²)/4 (з теореми косинусів двічі або з формули діагоналей паралелограма).
- **Бісектриса:** lc = 2ab·cos(γ/2)/(a + b).
- **Тангенсів, проєкцій:** c = a cos β + b cos α (сторона = сума проєкцій двох інших).

## 7. Застосування

### 7.1. Висота недоступного об'єкта

З точки A вершина гори видна під кутом 30°, з точки B, на 1 км ближче, — під 45°. Висота: з ΔABP (P — вершина): ∠APB = 15°, за теоремою синусів BP = 1·sin 30°/sin 15° ≈ 1,932 км; висота h = BP·sin 45° ≈ 1,366 км.

### 7.2. Тріангуляція

Щоб знайти відстань до корабля з берега, вимірюють базу AB і два кути — далі теорема синусів. Так у XVIII–XIX ст. виміряли меридіан (дуга Струве, частина її — в Україні, пам'ятка ЮНЕСКО) і склали точні карти.

### 7.3. Сила і швидкість

Сума двох сил 30 Н і 40 Н під кутом 60°: |F|² = 900 + 1600 + 2·30·40·cos 60° = 3700 ⇒ |F| ≈ 60,8 Н. (Тут знак «+», бо кут між векторами, а не кут трикутника, — трикутник має кут 120°.)

## 8. Типові помилки

| Помилка | Правильно |
|---|---|
| c² = a² + b² + 2ab cos γ | мінус |
| Кут γ у формулі — між будь-якими сторонами | γ — між a і b, проти c |
| Знайшли кут через синус і не перевірили тупий варіант | sin α = sin(180° − α) |
| Теорема синусів: a/sin β | сторона ділиться на синус **протилежного** кута |
| Калькулятор у радіанах | перевірити режим DEG |
| a/sin α = R | = 2R |
| Плутати кут між векторами і кут трикутника при додаванні сил | вони доповнюють один одного до 180° |
