# Теорема Піфагора

**У прямокутному трикутнику квадрат гіпотенузи дорівнює сумі квадратів катетів:**

$$c^2=a^2+b^2$$

Геометрично: **площа квадрата, побудованого на гіпотенузі, дорівнює сумі площ квадратів на катетах.** Це, мабуть, найвідоміша теорема математики. Її знали вавилоняни за 1000 років до Піфагора (табличка Plimpton 322 містить піфагорові трійки), єгиптяни й китайці; відомо понад 370 різних доведень. Теорема — міст між **геометрією** (кути, форма) і **алгеброю** (числа, квадрати): з неї виростають формула відстані, рівняння кола, норма вектора, тригонометрична тотожність sin² + cos² = 1.

Пов'язані нотатки: [[Трикутник]], [[Подібність трикутників]], [[Площі фігур]], [[Квадратний корінь]], [[Координати на площині]], [[Розв'язування трикутників]], [[Тригонометрія — одиничне коло і радіани]], [[Математика — зміст]].

## 1. Кілька способів зрозуміти твердження

| Погляд | Що каже теорема |
|---|---|
| **Площі** | квадрат на гіпотенузі = два квадрати на катетах разом |
| **Відстань** | відстань по діагоналі = √(Δx² + Δy²) — «шлях навпростець» |
| **Будь-які подібні фігури** | півкола, рівносторонні трикутники, будь-які подібні фігури на сторонах: площа на гіпотенузі = сума площ на катетах |
| **Перевірка прямого кута** | якщо c² = a² + b², кут прямий (обернена теорема) — «єгипетський трикутник» 3-4-5 |
| **Тригонометрія** | cos²α + sin²α = 1 — та сама теорема для гіпотенузи 1 |
| **Вектори** | \|a + b\|² = \|a\|² + \|b\|², якщо a ⊥ b |

## 2. Доведення — п'ять способів

### 2.1. Перекомпонування (китайське, «Чжоу бі»)

Великий квадрат зі стороною a + b можна заповнити **двома способами**:

```
  Спосіб А                       Спосіб Б
 ┌────────┬───┐                ┌──────────────┐
 │        │   │                │ ◣          ◢ │
 │   a²   │ab │                │    ┌────┐    │
 │        │   │                │    │ c² │    │  (квадрат c²
 ├────────┼───┤                │    └────┘    │   повернутий)
 │   ab   │b² │                │ ◥          ◤ │
 └────────┴───┘                └──────────────┘
 a² + b² + 4 трикутники        c² + 4 трикутники
```

- **А:** квадрат a², квадрат b² і чотири трикутники (два прямокутники ab, кожен розрізаний діагоналлю).
- **Б:** ті самі чотири трикутники в кутах, а посередині — квадрат зі стороною c.

Великий квадрат той самий, трикутники ті самі ⇒ **a² + b² = c²**. Доведення без слів.

### 2.2. Алгебраїчне (з тієї самої картинки Б)

(a + b)² = c² + 4·(ab/2) ⇒ a² + 2ab + b² = c² + 2ab ⇒ a² + b² = c².

### 2.3. Через подібність (найкоротше «серйозне»)

Опустимо висоту CH на гіпотенузу. Вона розбиває трикутник на два, **подібні до вихідного** (по одному спільному гострому куту і прямому куту).

```
           C
          /|\
       b / | \ a
        /  |h \
       /___|___\
      A  q  H  p  B
         └── c ──┘
```

- ΔACH ~ ΔABC ⇒ b/c = q/b ⇒ **b² = cq**.
- ΔBCH ~ ΔBAC ⇒ a/c = p/a ⇒ **a² = cp**.
- Додаємо: a² + b² = c(p + q) = c·c = c². ∎

**Бонус:** звідси ж **h² = pq** (висота — середнє геометричне проєкцій).

### 2.4. Евклідове (І книга «Начал», твердження 47)

Висота з прямого кута продовжується і ділить квадрат на гіпотенузі на два прямокутники. Кожен прямокутник **рівновеликий** квадрату на відповідному катеті (доводиться через рівні трикутники і те, що зсув вершини паралельно основі не змінює площі). Це те саме, що a² = cp і b² = cq, тільки мовою площ.

### 2.5. Президентське (Гарфілд, 1876)

Трапеція з основами a і b та висотою a + b складається з трьох прямокутних трикутників: двох з катетами a, b і одного з катетами c, c.
(a + b)(a + b)/2 = 2·ab/2 + c²/2 ⇒ a² + 2ab + b² = 2ab + c² ⇒ a² + b² = c².

(Джеймс Гарфілд — пізніше 20-й президент США.)

## 3. Обернена теорема

**Якщо c² = a² + b², то трикутник прямокутний** (кут проти c прямий).

*Доведення:* побудуємо прямокутний трикутник з катетами a і b. Його гіпотенуза за Піфагором дорівнює √(a² + b²) = c. Трикутники рівні за ССС ⇒ кут у даного теж прямий.

**Практика:** єгипетські землеміри (за переказом) робили мотузку з 12 рівними вузлами і натягували її трикутником 3-4-5, щоб отримати прямий кут. Будівельники досі перевіряють прямі кути фундаменту «правилом 3-4-5» (або 6-8-10).

**Узагальнення (через теорему косинусів):** якщо c² < a² + b² — кут проти c гострий; якщо c² > a² + b² — тупий (див. [[Розв'язування трикутників]]).

## 4. Піфагорові трійки

**Піфагорова трійка** — натуральні a, b, c з a² + b² = c².

| Трійка | Кратні |
|---|---|
| 3, 4, 5 | 6-8-10, 9-12-15, 30-40-50 |
| 5, 12, 13 | 10-24-26 |
| 8, 15, 17 | |
| 7, 24, 25 | |
| 20, 21, 29 | |
| 9, 40, 41 | |

**Формула Евкліда:** для m > n > 0: **a = m² − n², b = 2mn, c = m² + n²** дає трійку. Перевірка: (m² − n²)² + (2mn)² = m⁴ + 2m²n² + n⁴ = (m² + n²)². m = 2, n = 1 ⇒ 3, 4, 5; m = 3, n = 2 ⇒ 5, 12, 13.

**Велика теорема Ферма:** для n > 2 рівняння aⁿ + bⁿ = cⁿ не має розв'язків у натуральних числах. Ферма записав це на полях книги в 1637 р. («я знайшов чудове доведення, але поле замале»); довів Ендрю Вайлз у 1994 р.

## 5. Наслідки й застосування

- **Діагональ квадрата:** d = a√2. **Діагональ прямокутника:** d = √(a² + b²).
- **Висота рівностороннього трикутника:** h = a√3/2.
- **Відстань між точками:** d = √((x₂ − x₁)² + (y₂ − y₁)²) (див. [[Координати на площині]]).
- **Рівняння кола:** x² + y² = r².
- **Просторова діагональ** прямокутного паралелепіпеда: d = √(a² + b² + c²) — Піфагор двічі.
- **Ірраціональність √2:** діагональ одиничного квадрата не виражається дробом — це відкриття (приписують Гіппасу) стало кризою піфагорійської філософії «усе є число» (див. [[Квадратний корінь]]).
- **Спіраль Теодора:** прямокутні трикутники з катетами 1 і √n дають гіпотенузи √2, √3, √4, … — побудова коренів циркулем і лінійкою.

## 6. Ключовий приклад кількома способами

**Задача.** Драбина довжиною 5 м стоїть біля стіни, нижній кінець на 3 м від стіни. На якій висоті верхній кінець?

1. **Піфагор:** h = √(25 − 9) = 4 м.
2. **Впізнати трійку:** 3, ?, 5 — це 3-4-5 ⇒ 4 м без обчислень.
3. **Тригонометрія:** cos α = 3/5 ⇒ sin α = 4/5 ⇒ h = 5·4/5 = 4 м.

## 7. Типові помилки

| Помилка | Правильно |
|---|---|
| c = a + b | c² = a² + b², c < a + b |
| √(a² + b²) = a + b | ні: √(9 + 16) = 5 ≠ 7 |
| Застосовувати до не прямокутного трикутника | лише прямокутний (інакше — теорема косинусів) |
| Шукати катет як √(a² + c²) | катет: √(c² − a²) |
| Гіпотенуза — будь-яка сторона | сторона проти прямого кута, найбільша |
| 3, 4, 5 — «єдина» трійка | трійок нескінченно багато |
