# Вектори на площині

**Вектор** — напрямлений відрізок: величина, що має **довжину і напрямок**. Швидкість, сила, переміщення, вітер — вектори; маса, температура, час — ні (це **скаляри**, просто числа). Вектор AB⃗ — «стрілка від A до B». Два вектори **рівні**, якщо мають однакову довжину і напрямок, хоч би де вони починалися: вектор — це «зсув», а не конкретний відрізок.

Векторна алгебра — найкоротший шлях від геометрії до обчислень: доведення про середини, медіани, паралельність і перпендикулярність стають рядком формул.

## 1. Кілька способів думати про вектор

| Модель | Що таке вектор (3; 2) |
|---|---|
| **Стрілка** | відрізок з початком і кінцем, «3 праворуч, 2 вгору» |
| **Переміщення / зсув** | інструкція «перемісти все на 3 праворуч і на 2 вгору» (паралельне перенесення) |

| **Комплексне число** | 3 + 2i (див. [[Комплексні числа]]) |

## 2. Координати і довжина

AB⃗ = (x_B − x_A; y_B − y_A). Довжина (модуль): **|a⃗| = √(a₁² + a₂²)** — Піфагор.

**Нульовий вектор** 0⃗ = (0; 0) — довжина 0, напрямок не визначений. **Одиничний** — довжина 1; щоб отримати одиничний у напрямку a⃗: a⃗/|a⃗|.

## 3. Дії з векторами

### 3.1. Додавання — два правила

**Правило трикутника:** кінець першого — початок другого; сума — від початку першого до кінця другого. AB⃗ + BC⃗ = AC⃗. *Сенс:* два переміщення поспіль.

**Правило паралелограма:** обидва з однієї точки; сума — діагональ паралелограма. *Сенс:* дві сили, прикладені до тіла одночасно.

```
 трикутник:              паралелограм:
        C                    ______
       ↗                    /     ↗/
  b⃗  /                 b⃗ /  a⃗+b⃗ /
     /                    /   ↗   /
 A ——→ B                 •———→———
    a⃗    (a⃗ + b⃗ = AC⃗)        a⃗
```

У координатах: (a₁; a₂) + (b₁; b₂) = (a₁ + b₁; a₂ + b₂).

**Віднімання:** a⃗ − b⃗ — вектор, який треба додати до b⃗, щоб отримати a⃗. З однієї точки: від кінця b⃗ до кінця a⃗.

### 3.2. Множення на число

k·a⃗ — вектор у k разів довший; при k < 0 — протилежного напрямку. (ka₁; ka₂).

**Колінеарні** вектори (на паралельних прямих або одній прямій): b⃗ = k·a⃗ ⇔ a₁/b₁ = a₂/b₂ ⇔ a₁b₂ − a₂b₁ = 0.

### 3.3. Розклад за базисом

Будь-який вектор площини — **лінійна комбінація** двох неколінеарних: c⃗ = x·a⃗ + y·b⃗, і коефіцієнти єдині. Координати — це коефіцієнти розкладу за i⃗ = (1; 0), j⃗ = (0; 1).

## 4. Скалярний добуток

$$\vec a\cdot\vec b=|\vec a|\,|\vec b|\cos\varphi=a_1b_1+a_2b_2$$

Результат — **число**, а не вектор.

### 4.1. Сенс — три погляди

1. **Проєкція:** a⃗·b⃗ = |a⃗| × (проєкція b⃗ на напрямок a⃗). «Наскільки b⃗ дивиться в той самий бік, що й a⃗».
2. **Робота сили:** A = F⃗·s⃗ = |F||s|cos φ — лише складова сили вздовж руху виконує роботу.
3. **Схожість напрямків:** cos φ = a⃗·b⃗/(|a⃗||b⃗|). +1 — однаковий напрямок, 0 — перпендикулярні, −1 — протилежні. Так у машинному навчанні міряють «косинусну схожість» текстів.

### 4.2. Чому дві формули рівні

Теорема косинусів для трикутника зі сторонами a⃗, b⃗, a⃗ − b⃗: |a⃗ − b⃗|² = |a⃗|² + |b⃗|² − 2|a⃗||b⃗|cos φ. У координатах ліва частина: (a₁ − b₁)² + (a₂ − b₂)² = |a⃗|² + |b⃗|² − 2(a₁b₁ + a₂b₂). Порівнюємо — отримуємо рівність.

### 4.3. Застосування

- **Перпендикулярність:** a⃗ ⊥ b⃗ ⇔ a⃗·b⃗ = 0. (3; 4) ⊥ (−4; 3).
- **Кут між векторами:** cos φ = (a₁b₁ + a₂b₂)/(|a⃗||b⃗|).
- **Довжина:** |a⃗|² = a⃗·a⃗.
- **Проєкція:** proj = (a⃗·b⃗)/|b⃗|.

## 5. Векторний метод доведень

### 5.1. Корисні факти

- **Середина M відрізка AB:** OM⃗ = (OA⃗ + OB⃗)/2.
- **Точка, що ділить AB у відношенні m : n:** OP⃗ = (n·OA⃗ + m·OB⃗)/(m + n).
- **Центроїд:** OG⃗ = (OA⃗ + OB⃗ + OC⃗)/3.
- **Три точки на одній прямій** ⇔ AB⃗ і AC⃗ колінеарні.

### 5.2. Ключовий приклад кількома способами

**Теорема.** Діагоналі ромба перпендикулярні.

**Спосіб 1 (вектори).** Сторони a⃗ і b⃗, |a⃗| = |b⃗|. Діагоналі a⃗ + b⃗ і a⃗ − b⃗. (a⃗ + b⃗)·(a⃗ − b⃗) = |a⃗|² − |b⃗|² = 0 ⇒ перпендикулярні ∎. (Це різниця квадратів!)

**Спосіб 2 (рівність трикутників).** ΔABO = ΔADO за ССС ⇒ суміжні кути при O рівні ⇒ 90°.

**Спосіб 3 (симетрія).** A і C рівновіддалені від B і від D ⇒ BD — серединний перпендикуляр до AC.

### 5.3. Ще приклад — середня лінія

M, N — середини AB і BC. MN⃗ = BN⃗ − BM⃗ = ½BC⃗ − ½BA⃗ = ½AC⃗. Отже MN ∥ AC і MN = AC/2 — одним рядком.

## 6. Застосування у фізиці й техніці

- **Сили:** рівнодійна — векторна сума. Тіло в рівновазі, якщо сума сил — нульовий вектор.
- **Швидкість човна на річці:** v⃗ = v⃗_човна + v⃗_течії.
- **Літак у вітер:** курс і шляхова швидкість — сума вектора швидкості літака і вітру.
- **Комп'ютерна графіка:** нормалі, освітлення (яскравість ∝ cos кута між нормаллю і напрямком на світло = скалярний добуток).

## 7. Типові помилки

| Помилка | Правильно |
|---|---|
| \|a⃗ + b⃗\| = \|a⃗\| + \|b⃗\| | ≤; рівність лише при однаковому напрямку |
| AB⃗ = BA⃗ | BA⃗ = −AB⃗ |
| Скалярний добуток — вектор | число |
| a⃗·b⃗ = a₁b₂ + a₂b₁ | a₁b₁ + a₂b₂ |
| Координати AB⃗ = A − B | B − A (кінець мінус початок) |
| a⃗·b⃗ = 0 ⇒ один з векторів нульовий | можуть бути перпендикулярні |
| Колінеарні = однаково напрямлені | можуть бути протилежні |
