# Трикутник

**Трикутник** — фігура з трьох точок, що не лежать на одній прямій (вершин), і трьох відрізків, що їх сполучають (сторін). Це найпростіший многокутник і **«атом» геометрії**: будь-який многокутник розрізається на трикутники, а більшість задач про фігури зводиться до задач про трикутники. Трикутник — **жорстка** фігура: три сторони однозначно задають форму. Тому мости, вежі, крани й дахи будують з трикутників (ферми), а чотирикутна рама без діагоналі складається, як паралелограм.

Пов'язані нотатки: [[Паралельні прямі]], [[Рівність трикутників]], [[Чудові точки трикутника]], [[Теорема Піфагора]], [[Подібність трикутників]], [[Площі фігур]], [[Розв'язування трикутників]], [[Математика — зміст]].

## 1. Позначення

Вершини A, B, C; сторони, протилежні їм, — **a = BC, b = CA, c = AB**; кути **α = ∠A, β = ∠B, γ = ∠C**. Периметр P = a + b + c, півпериметр p = P/2.

```
            B
           /\
       c  /  \  a
         /    \
        /______\
       A    b   C
```

## 2. Види трикутників

**За кутами:**

| Вид | Кути | Ознака через сторони (c — найбільша) |
|---|---|---|
| Гострокутний | усі < 90° | c² < a² + b² |
| Прямокутний | один = 90° | c² = a² + b² |
| Тупокутний | один > 90° | c² > a² + b² |

**За сторонами:**

| Вид | Сторони | Кути |
|---|---|---|
| Різносторонній | усі різні | усі різні |
| Рівнобедрений | дві рівні (бічні), третя — основа | кути при основі рівні |
| Рівносторонній | усі рівні | усі по 60° |

## 3. Сума кутів і зовнішній кут

**α + β + γ = 180°** — наслідок аксіоми паралельних (доведення трьома способами — у [[Паралельні прямі]]).

**Наслідки:**
- У трикутнику не більше одного прямого чи тупого кута.
- Гострі кути прямокутного трикутника в сумі 90°.
- Кожен кут рівностороннього — 60°.

**Зовнішній кут** — суміжний з внутрішнім. **Зовнішній кут дорівнює сумі двох внутрішніх, не суміжних з ним:** δ = 180° − γ = α + β.

Тому зовнішній кут **більший** за кожен внутрішній, не суміжний з ним — цей факт використовують в ознаці паралельності.

## 4. Нерівність трикутника

**Кожна сторона менша за суму двох інших:** a < b + c, b < a + c, c < a + b.

**Чому — три пояснення:**
1. **Найкоротший шлях:** пряма AB — найкоротша дорога з A в B; шлях через C довший.
2. **Шарнірна модель:** з паличок 2, 3 і 10 трикутник не складеш — дві короткі не дотягнуться одна до одної.
3. **Модуль:** це та сама нерівність |x + y| ≤ |x| + |y| (див. [[Модуль числа]]), для векторів.

**Наслідок:** сторона більша за **різницю** двох інших: |b − c| < a < b + c.

**Перевірка на практиці:** досить перевірити, що **найбільша сторона менша за суму двох менших**. Для 4, 7, 10: 10 < 11 ✓. Для 3, 5, 9: 9 > 8 ✗.

**Рівність** a = b + c можлива лише для «виродженого» трикутника — точок на одній прямій.

## 5. Співвідношення сторін і кутів

**Проти більшої сторони лежить більший кут, і навпаки.**

*Пояснення:* якщо AC > AB, відкладемо на AC відрізок AD = AB. Трикутник ABD рівнобедрений, ∠ABD = ∠ADB. Але ∠ADB — зовнішній для трикутника BDC, тож більший за ∠C. Отже ∠B > ∠ABD = ∠ADB > ∠C.

**Наслідки:**
- У прямокутному трикутнику гіпотенуза — найбільша сторона (проти найбільшого кута 90°).
- Проти рівних сторін — рівні кути (рівнобедрений трикутник).

## 6. Рівнобедрений трикутник

- **Кути при основі рівні.** І навпаки: якщо два кути рівні, трикутник рівнобедрений.
- **Медіана, проведена до основи, є бісектрисою і висотою** (і лежить на осі симетрії).
- Рівнобедрений трикутник **симетричний** відносно цієї прямої.

**Доведення через симетрію:** перегнемо трикутник по бісектрисі кута при вершині. Бічні сторони рівні й лежать під однаковими кутами до бісектриси — вони сумістяться. Отже сумістяться й кути при основі.

## 7. Основні лінії трикутника — коротко

| Лінія | Що це | Детальніше |
|---|---|---|
| **Медіана** | з вершини до середини протилежної сторони | [[Чудові точки трикутника]] |
| **Бісектриса** | ділить кут навпіл | [[Чудові точки трикутника]] |
| **Висота** | перпендикуляр з вершини на пряму протилежної сторони | [[Чудові точки трикутника]] |
| **Середня лінія** | з'єднує середини двох сторін; паралельна третій і дорівнює її половині | [[Подібність трикутників]] |

**Середня лінія — три способи довести, що MN = AC/2 і MN ∥ AC:**
1. **Подібність:** трикутник MBN подібний ABC з коефіцієнтом 1/2.
2. **Добудова до паралелограма:** продовжимо MN на свою довжину — вийде паралелограм.
3. **Вектори:** MN = BN − BM = (BC − BA)/2 = AC/2.

## 8. Ключовий приклад кількома способами

**Задача.** У трикутнику ∠A = 50°, ∠B = 70°. Яка сторона найбільша і яка найменша?

1. **Співвідношення кут — сторона:** ∠C = 60°. Найбільший кут B ⇒ найбільша сторона AC. Найменший кут A ⇒ найменша BC.
2. **Теорема синусів** (див. [[Розв'язування трикутників]]): a : b : c = sin 50° : sin 70° : sin 60° ≈ 0,766 : 0,940 : 0,866.
3. **Побудова:** накреслимо AB = 10, кути 50° і 70° — і виміряємо.

## 9. Скільки трикутників існує

- З трьома сторонами 3, 4, 5 — один (з точністю до рівності): трикутник жорсткий.
- З цілими сторонами і периметром 12: (2, 5, 5), (3, 4, 5), (4, 4, 4) — три.
- Трикутник однозначно задають: **три сторони**; дві сторони й кут між ними; сторона і два кути (див. [[Рівність трикутників]]).

## 10. Типові помилки

| Помилка | Правильно |
|---|---|
| Трикутник зі сторонами 2, 3, 5 існує | вироджений: 5 = 2 + 3 |
| Перевіряти лише одну нерівність з довільною стороною | перевірити найбільшу проти суми двох інших |
| Зовнішній кут = 180° − сума двох інших | = сума двох внутрішніх не суміжних |
| Проти більшого кута — менша сторона | більша |
| Рівнобедрений — «два рівні кути при вершині» | рівні кути при **основі** |
| Висота завжди всередині трикутника | у тупокутному — зовні |
