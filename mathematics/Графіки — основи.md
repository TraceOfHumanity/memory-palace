# Графіки: основи (що це, як будується, як читається)

Числові приклади перевірені обчисленням.

---

## 1. Навіщо графік
Формула каже, **як рахувати**. Графік показує **всю поведінку одразу**: де функція росте, падає, перетинає нуль, має мінімум, «вибухає». Око бачить форму за мить, тоді як у таблиці треба читати числа. Графік — це **картинка рівняння**.

## 2. Координатна площина
- Два числові прямі, що перетинаються під прямим кутом у точці **O (0; 0)** — початку координат. Горизонтальна — вісь **x** (абсцис), вертикальна — вісь **y** (ординат). Ідея Декарта (XVII ст.): будь-яку точку площини можна задати двома числами.
- **Точка** записується парою (x; y): спершу «скільки вздовж x» (вправо +, вліво −), потім «скільки вздовж y» (вгору +, вниз −). **Порядок важливий:** (2; 3) ≠ (3; 2).
- Чотири чверті: I (+; +), II (−; +), III (−; −), IV (+; −). Точки на осях не належать жодній чверті.
- Одиничний відрізок (масштаб) — скільки пікселів/сантиметрів — «1». Може бути різним по осях, але тоді форма спотворюється.

**Для програміста:** екранна система координат має вісь y, спрямовану **вниз**. Перехід: `screenX = originX + x·unit`, `screenY = originY − y·unit` (мінус перевертає вісь).

## 3. Що таке графік функції
**Графік функції f — це множина всіх точок (x; f(x))**, де x пробігає область визначення.
- Точка **лежить на графіку ⇔ її координати задовольняють рівняння**. Приклад: y = 2x + 1. Точка (2; 5): 2·2 + 1 = 5 ✓ — належить. Точка (1; 4): 2·1 + 1 = 3 ≠ 4 — не належить.
- Отже графік — це «картинка всіх розв'язків» рівняння y = f(x). Кожна точка графіка — одна пара (вхід; вихід).
- Тест вертикальної прямої: крива є графіком функції ⇔ кожна вертикальна пряма перетинає її не більше ніж в одній точці.

## 4. Як будувати графік — по точках
1. Знайти область визначення (де можна рахувати).
2. Скласти таблицю: вибрати кілька x, обчислити y.
3. Нанести точки.
4. З'єднати плавною лінією (якщо функція неперервна).
5. Перевірити «особливі» місця: нулі, вершину, асимптоти, поведінку на краях.

Приклад y = x² − 4x + 3:
| x | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| y | 3 | 0 | −1 | 0 | 3 |
Видно: нулі x = 1 та x = 3, вершина (2; −1), симетрія відносно x = 2.

**Пастка:** мало точок — можна не побачити важливого (мінімум між двома вибраними x). Тому краще знати **тип** графіка заздалегідь і брати **характерні точки** (вершина, нулі, перетин з осями), а не випадкові.

## 5. Читання графіка (що з нього можна дізнатися)
- **Значення функції:** f(2) — підняти вертикаль від x = 2 до кривої, прочитати y.
- **Обернене питання:** для яких x функція дорівнює k? — провести горизонталь y = k, дивитись перетини.
- **Нулі:** перетини з віссю x (f(x) = 0).
- **Перетин з віссю y:** точка (0; f(0)) — рівно одна, якщо 0 ∈ D.
- **Знак:** де крива вище осі x — f > 0, нижче — f < 0.
- **Зростання/спадання:** йдемо зліва направо — вгору чи вниз.
- **Екстремуми:** вершини та западини.
- **Область визначення:** які x «займає» графік (проєкція на вісь x). **Область значень:** які y (проєкція на вісь y).
- **Симетрія:** осі y (парна) чи початку координат (непарна).

## 6. Нахил (швидкість зміни)
Для прямої: **k = Δy/Δx** — на скільки зростає y при збільшенні x на 1. y = 2x + 1: x +1 → y +2; нахил 2.
- k > 0 — зростає, k < 0 — спадає, k = 0 — горизонталь.
- Вертикальна пряма x = a — **не** функція (нахил «нескінченний»).
- Для кривих нахил змінюється від точки до точки — це ідея **похідної**.

## 7. Перетин графіків = розв'язок рівняння
Точка перетину f(x) = g(x) — спільний розв'язок. Приклад: y = x² та y = x + 2. Рівняння x² = x + 2 → x² − x − 2 = 0 → x = −1 та x = 2. Перевірка: (−1)² = 1 = −1 + 2 ✓; 2² = 4 = 2 + 2 ✓. Дві точки перетину: (−1; 1) і (2; 4).
- **Нерівність** f(x) > g(x): де графік f **вищий** за графік g.
- Графічний метод наочний, але наближений; точність дає алгебра.

## 8. Масштаб і спотворення
- Різні одиниці на осях дають різну «крутизну» — один і той самий графік може виглядати полого чи стрімко. Завжди дивіться на підписи осей.
- **Логарифмічна шкала:** кожна позначка — множення на 10, зручно для величин, що змінюються на порядки.
- **Обрізана вісь** y (починається не з 0) перебільшує різницю — маніпуляція в діаграмах.

## 9. Особливості, на які треба звертати увагу
- **Розрив / асимптота:** y = 1/x при x → 0 прямує до ±∞. Вертикальна асимптота x = 0, горизонтальна y = 0.
- **Виколота точка:** функція не визначена в точці, але поряд все гладко.
- **Злам:** |x| у нулі різко змінює напрям.
- **Періодичність:** шматок повторюється (sin).
- **Поведінка на нескінченності:** куди прямує графік.

## 10. Швидкий ескіз: алгоритм
1. Тип (пряма? парабола? гіпербола?) за виглядом формули.
2. Область визначення.
3. Перетини: з віссю y (x = 0), з віссю x (y = 0).
4. Симетрія/парність.
5. Особливі точки: вершина, асимптоти, екстремуми.
6. Поведінка на краях.
7. Кілька контрольних точок → плавна лінія.

## Для програміста
- Побудова графіка = **дискретизація**: `xs = linspace(a, b, N); ys = xs.map(f); polyline`. Більше N — гладша лінія, але більше обчислень.
- Не з'єднуйте точки **через розрив**: для 1/x розбийте на дві гілки (або вставте NaN), інакше з'явиться фальшива вертикальна лінія.
- Для швидко змінних функцій потрібна **адаптивна** дискретизація.
- Підписи, шкала, автоматичний вибір меж (`min/max` за ys).
- Бібліотеки: matplotlib/plotly (Python), Chart.js/D3/Canvas (JS). Візуалізація залежності — найкращий спосіб налагодити математичну модель.

## Типові помилки
1. Переплутати порядок координат (x; y).
2. З'єднувати точки ламаною там, де функція має бути гладкою (або навпаки — через розрив).
3. Брати занадто мало точок і пропускати вершину чи нулі.
4. Ігнорувати область визначення.
5. Читати нахил, не враховуючи різний масштаб осей.
6. Вважати, що точка належить графіку, не підставивши її координати.
7. Плутати нулі функції (перетин з віссю x) та перетин з віссю y.
