# Цілі числа

**Цілі числа** ℤ = {…, −3, −2, −1, 0, 1, 2, 3, …} — натуральні числа, нуль і числа, протилежні натуральним. Вони з'явилися, щоб віднімання завжди мало результат: 3 − 5 у натуральних числах неможливе, а в цілих дорівнює −2. Позначення ℤ — від німецького *Zahlen* («числа»).

Пов'язані нотатки: [[Основи]], [[Арифметичні дії та їхні властивості]], [[Подільність, прості числа, НСД і НСК]], [[Модуль числа]], [[Математика — зміст]].

## 1. Числова пряма

```
 ──┼────┼────┼────┼────┼────┼────┼──►
  −3   −2   −1    0    1    2    3
```

- **Нуль** ділить пряму на дві частини: праворуч — **додатні** числа, ліворуч — **від'ємні**. Сам нуль ні додатний, ні від'ємний.
- **Протилежні числа** — на однаковій відстані від нуля по різні боки: 3 і −3. Сума протилежних дорівнює 0. Протилежне до a позначають −a; −(−a) = a. Протилежне до 0 — сам 0.
- **Модуль** |a| — відстань від числа до нуля: |−5| = 5, |5| = 5, |0| = 0. Модуль ніколи не від'ємний. Докладно: [[Модуль числа]].
- **Порівняння:** з двох чисел більше те, що на прямій **праворуч**. −2 > −7, бо −2 праворуч. Будь-яке додатне більше за будь-яке від'ємне. З двох від'ємних більше те, в якого **менший модуль**: −3 > −10.

## 2. Кілька способів думати про від'ємні числа

| Модель | Що означає −5 | Що означає «відняти» | Що означає «помножити на −1» |
|---|---|---|---|
| **Гроші й борг** | борг 5 грн | забрати; забрати борг = отримати гроші | «перевернути» баланс |
| **Термометр** | 5° нижче нуля | похолоднішало | — |
| **Рух на прямій** | точка на 5 кроків ліворуч від 0 | крок ліворуч | розворот на 180° |
| **Висота над рівнем моря** | 5 м під водою | спуститися | — |
| **Поверхи** | 5-й підземний поверх | спуск ліфта | — |
| **Фішки двох кольорів** | 5 червоних фішок (червона = −1, синя = +1, пара червона + синя = 0) | прибрати фішки (якщо їх немає — додати нульові пари) | поміняти кольори |

**Фішки** — найкорисніша модель для правил знаків. Обчислимо 3 − (−2): маємо 3 сині фішки, треба прибрати 2 червоні. Червоних немає, тому додаємо дві нульові пари (2 сині + 2 червоні — значення не змінилося). Тепер прибираємо 2 червоні: лишилося 5 синіх. Отже **3 − (−2) = 5**.

## 3. Додавання

| Випадок | Правило | Приклад |
|---|---|---|
| Однакові знаки | додати модулі, знак спільний | (−3) + (−5) = −8 |
| Різні знаки | від більшого модуля відняти менший, знак — числа з більшим модулем | (−8) + 5 = −3; 8 + (−5) = 3 |
| Протилежні числа | сума 0 | (−7) + 7 = 0 |

**На прямій:** додати додатне — іти праворуч, додати від'ємне — іти ліворуч. (−3) + 5: стоїмо на −3, робимо 5 кроків праворуч, опиняємося на 2.

## 4. Віднімання

**Головне правило: відняти число — те саме, що додати протилежне.**

$$a-b=a+(-b)$$

- 3 − 7 = 3 + (−7) = −4.
- −2 − 5 = −2 + (−5) = −7.
- 4 − (−6) = 4 + 6 = 10.
- −3 − (−8) = −3 + 8 = 5.

**Три способи пояснити, чому 4 − (−6) = 10:**
1. **Борг:** мені списали борг 6 грн — мій баланс зріс на 6.
2. **Відстань:** різниця a − b — це «наскільки a правіше за b». Від −6 до 4 — 10 кроків.
3. **Перевірка оберненою дією:** 10 + (−6) = 4 ✓.

**Різниця як відстань:** a − b > 0, якщо a правіше за b. Відстань між точками a і b дорівнює |a − b|: між −3 і 5 відстань |−3 − 5| = 8.

## 5. Множення і ділення

| Знаки множників | Знак результату |
|---|---|
| (+)·(+) | + |
| (−)·(−) | + |
| (+)·(−) | − |
| (−)·(+) | − |

Те саме для ділення. Модуль результату — добуток (частка) модулів.

- (−4)·3 = −12; (−4)·(−3) = 12; 12 : (−4) = −3; (−12) : (−4) = 3.
- **Знак добутку кількох множників:** парна кількість мінусів — плюс, непарна — мінус. (−1)·(−2)·(−3) = −6; (−1)⁴ = 1; (−1)⁵ = −1.
- Степінь від'ємного числа: парний показник — додатний результат, непарний — від'ємний: (−2)³ = −8, (−2)⁴ = 16.

### Чому мінус на мінус дає плюс — чотири пояснення

1. **Закономірність.** (−3)·3 = −9, (−3)·2 = −6, (−3)·1 = −3, (−3)·0 = 0. Кожного разу результат **зростає на 3**. Продовжуємо: (−3)·(−1) = 3, (−3)·(−2) = 6.
2. **Розподільний закон.** (−3)·(−2 + 2) = (−3)·0 = 0. Розкриваємо: (−3)(−2) + (−3)·2 = 0, тобто (−3)(−2) − 6 = 0, отже (−3)(−2) = 6. Правило знаків — **наслідок** законів арифметики, а не домовленість.
3. **Поворот.** Множення на −1 — поворот числової прямої на 180° навколо нуля. Два повороти повертають у вихідне положення.
4. **Плівка назад.** Резервуар наповнюється на 3 л/хв (+3). «Через 2 хв» — це +2. Якщо воду **зливають** (−3) і ми прокрутимо плівку на 2 хв **назад** (−2), то бачимо, що 2 хв тому води було **більше** на 6 л: (−3)·(−2) = +6.

## 6. Порядок дій і дужки

- Мінус перед дужками змінює знаки **всіх** доданків у дужках: −(a − b + c) = −a + b − c.
- Плюс перед дужками нічого не змінює: +(a − b) = a − b.
- **Алгебраїчна сума:** вираз 5 − 8 + 3 − 2 можна розглядати як суму 5 + (−8) + 3 + (−2) і групувати як зручно: (5 + 3) + (−8 − 2) = 8 − 10 = −2.
- −3² = −9, а (−3)² = 9.

## 7. Ділення з остачею для від'ємних

У математиці остача завжди невід'ємна: a = b·q + r, 0 ≤ r < |b|.
- −17 : 5: −17 = 5·(−4) + 3, тобто q = −4, r = 3.
- У мовах програмування `%` поводиться по-різному: у JavaScript і C `-17 % 5 === -2` (знак діленого), у Python `-17 % 5 == 3` (математична остача).
- Математичну остачу в JS отримують так: `((a % b) + b) % b`.

## 8. Цілі числа в комп'ютері

- Цілі числа зберігаються у **доповняльному коді** з фіксованою кількістю бітів: 32-бітне знакове ціле має діапазон від −2 147 483 648 до 2 147 483 647 (див. [[Системи числення]]).
- Вихід за діапазон — **переповнення**: у 32-бітній арифметиці 2 147 483 647 + 1 перетворюється на −2 147 483 648.
- У JavaScript звичайні числа — дробові (*double*), точно зберігають цілі до 2⁵³ − 1 = 9 007 199 254 740 991 (`Number.MAX_SAFE_INTEGER`). Для більших — `BigInt`: `2n ** 64n`.

## Типові помилки

1. Порівнювати від'ємні числа за модулем: −10 > −3 — **неправильно**.
2. −3 − 5 = −2 замість −8 (ліворуч від −3 ще на 5 кроків).
3. 4 − (−6) = −2 замість 10.
4. (−2)² = −4 замість 4; −2² = 4 замість −4.
5. Змінювати знак лише першого доданка в дужках після мінуса.
6. Вважати 0 додатним чи від'ємним.
