# Системи лінійних рівнянь: метод Гауса, ранг, структура розв'язків

Числа перевірені обчисленням (numpy).

## 1. Система як матриця
```
x +  y + z = 6
2x − y + z = 3
x + 2y − z = 2
```
Розширена матриця [A | b]:
```
| 1  1  1 | 6 |
| 2 −1  1 | 3 |
| 1  2 −1 | 2 |
```
Розв'язок: (x, y, z) = (1, 2, 3). Перевірка: 1+2+3 = 6; 2−2+3 = 3; 1+4−3 = 2 ✓. det A = 7 ≠ 0.

## 2. Елементарні перетворення рядків
Не змінюють множину розв'язків:
1. Поміняти два рядки.
2. Помножити рядок на ненульове число.
3. Додати до рядка інший, помножений на число.
Це саме те, що ми робимо зі школи: додати/відняти рівняння.

## 3. Метод Гауса (прямий і зворотний хід)
**Прямий хід:** привести до **східчастого вигляду** — нулі під головною діагоналлю. 1) за допомогою першого рядка занулити перший стовпець нижче; 2) те саме для другого стовпця тощо.
**Зворотний хід:** з останнього рівняння знаходимо останню змінну, підставляємо вгору.
Приклад: R₂ − 2R₁: (0, −3, −1 | −9); R₃ − R₁: (0, 1, −2 | −4). Потім R₃ + R₂/3: (0, 0, −7/3 | −7) → z = 3; з −3y − z = −9 → y = 2; x = 6 − 2 − 3 = 1 ✓.
Складність O(n³). Це основа `np.linalg.solve` (LU-розклад).
**Жордан–Гаус:** продовжити до одиничної матриці ліворуч — відповідь одразу праворуч.
Вибір головного елемента (pivoting) — для числової стійкості.

## 4. Ранг матриці
**Ранг** = кількість ненульових рядків у східчастому вигляді = максимальна кількість лінійно незалежних рядків (або стовпців — збігаються!). Розмірність образу.
- A = [[1,2,3],[4,5,6],[7,8,9]]: ранг 2 (третій рядок = 2·другий − перший), det = 0.
- [[1,2,3],[2,4,6],[1,0,1]]: другий рядок = 2·перший → ранг 2.
- Ранг ≤ min(m, n). «Повний ранг» — максимально можливий.
- Для квадратної n×n: ранг n ⇔ det ≠ 0 ⇔ матриця оборотна.

## 5. Скільки розв'язків: теорема Кронекера–Капеллі
Система Ax = b сумісна ⇔ rank A = rank [A | b].
- rank A = rank [A|b] = n (кількість змінних): **єдиний розв'язок**.
- rank A = rank [A|b] < n: **безліч** розв'язків, n − rank вільних параметрів.
- rank A < rank [A|b]: **немає** розв'язків (суперечність 0 = 1 у східчастому вигляді).
Приклад: x + y = 2, 2x + 2y = 4 → один рядок кратний другому, безліч розв'язків (пряма). x + y = 2, 2x + 2y = 5 → немає.

## 6. Однорідні системи і нуль-простір
Ax = 0 завжди має розв'язок x = 0. Всі розв'язки утворюють **нуль-простір** (ядро) — підпростір розмірності n − rank. **Теорема про ранг і нульність:** rank + nullity = n.
Загальний розв'язок Ax = b: частинний розв'язок + будь-який з нуль-простору (як «пряма в просторі»).

## 7. Простори, пов'язані з матрицею
- **Простір стовпців** C(A): усі можливі виходи Ax (образ), розмірність = ранг.
- **Простір рядків**, **нуль-простір** N(A), ліве ядро. Ортогональні пари: N(A) ⟂ рядки A.
- Лінійна незалежність стовпців ⇔ нуль-простір тривіальний.
Геометрія: матриця 3×3 рангу 2 «розплющує» простір у площину, рангу 1 — у пряму.

## 8. Обернена матриця за Гаусом
Записуємо [A | I] і перетворюємо рядками до [I | A⁻¹]. Якщо до одиничної не зводиться (з'явився нульовий рядок) — оберненої немає.

## 9. Визначник у 3×3 та правило Крамера
det A розкладаємо за рядком (мінори) або методом Гауса (добуток діагоналі зі знаком від перестановок рядків). Крамер: xᵢ = det(Aᵢ)/det(A) (заміна i-го стовпця на b). Зручно для 2×2/3×3, непрактично для великих — Гаус швидший.

## Для програміста
- `np.linalg.solve(A, b)` (LU), `np.linalg.matrix_rank`, `np.linalg.lstsq` (перевизначені системи), `scipy.linalg.null_space`.
- Перевизначена система (рівнянь більше, ніж невідомих) — найменші квадрати (регресія!).
- Числова стійкість: майже вироджені матриці (велике число обумовленості) дають нестабільні розв'язки; перевіряйте cond(A).
- Розріджені системи — ітераційні методи (CG).

## Типові помилки
1. Множити рядок на 0 (втрата інформації).
2. Арифметичні помилки під час віднімання рядків — перевірте підстановкою.
3. Плутати ранг рядків і стовпців (вони рівні).
4. Вважати det = 0 «розв'язків нема»: може бути безліч.
5. Обернена для великої системи замість solve.
