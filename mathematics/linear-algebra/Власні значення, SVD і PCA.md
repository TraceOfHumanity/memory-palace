# Власні значення, SVD і PCA (поглиблення)

Числа перевірені обчисленням (numpy).

## 1. Нагадування: власні вектори
A·v = λ·v: напрямок v не змінюється, лише розтягується в λ разів. A = [[2, 1], [1, 2]]: v = (1, 1), λ = 3; v = (1, −1), λ = 1. Знаходимо з det(A − λI) = 0.
- Слід (trace) A = Σ λ; det A = Π λ. (2 + 2 = 4 = 3 + 1; 4 − 1 = 3 = 3·1 ✓.)
- Симетрична матриця: власні числа дійсні, власні вектори **ортогональні** (спектральна теорема): A = QΛQᵀ.

## 2. Діагоналізація
Якщо n незалежних власних векторів: A = PDP⁻¹, D = diag(λ). Тоді Aᵏ = PDᵏP⁻¹ — степінь за O(1) множень діагоналі. Приклад: Фібоначчі через [[1,1],[1,0]]ᵏ. Також розв'язок диференціальних рівнянь і ланцюгів Маркова (стаціонарний розподіл = власний вектор λ = 1).

## 3. Сингулярний розклад SVD
Для **будь-якої** матриці A (m×n): **A = U·Σ·Vᵀ**, де U, V — ортогональні, Σ — діагональна з **сингулярними числами** σ₁ ≥ σ₂ ≥ … ≥ 0.
Геометрія: будь-яке лінійне перетворення = поворот (Vᵀ) → розтяг уздовж осей (Σ) → поворот (U). Образ одиничного кола — еліпс з півосями σᵢ.
Приклад: [[3, 0],[4, 5]] має σ = 6,708 та 2,236. Для симетричної додатної [[2,1],[1,2]]: σ = 3, 1 (= λ).
Зв'язок: σᵢ² — власні числа AᵀA. Ранг = кількість ненульових σ.
Число обумовленості cond = σ₁/σ_min — чутливість розв'язку до похибок.

## 4. Наближення малого рангу
Залишивши k найбільших σ: A ≈ Σᵢ₌₁ᵏ σᵢuᵢvᵢᵀ — найкраще наближення рангу k (теорема Екарта–Янга). Застосування:
- **Стиснення зображень:** матриця пікселів ≈ сума k «шарів».
- Прибирання шуму, рекомендаційні системи (матриця користувач×фільм), латентний семантичний аналіз.

## 5. PCA (метод головних компонент)
Задача: у даних багато ознак, багато з яких корелюють. Знайти **нові осі**, уздовж яких дані мають найбільший розкид.
Алгоритм:
1. Центрувати дані (відняти середнє по кожній ознаці).
2. Обчислити матрицю коваріації Σ = XᵀX/(n − 1).
3. Знайти власні вектори й числа Σ (або SVD центрованої X).
4. Власні вектори = **головні компоненти** (напрямки); власні числа = дисперсія вздовж них.
5. Проєктувати дані на перші k компонент.
Приклад: X = [(2,3),(3,3),(4,5),(5,5),(6,7)]. Σ = [[2,5; 2,5],[2,5; 2,8]]; власні числа 5,154 та 0,146; перша компонента (0,686; 0,728) — діагональ, пояснює 5,154/(5,154 + 0,146) ≈ 97,3 % дисперсії. Двовимірні дані майже лежать на прямій → одного виміру досить.
**Частка поясненої дисперсії** λᵢ/Σλ вибирає k.

## 6. Чому PCA = власні вектори коваріації
Дисперсія даних уздовж одиничного напряму w дорівнює wᵀΣw. Максимум цієї форми на |w| = 1 досягається на власному векторі з найбільшим λ (множники Лагранжа), і значення дорівнює λ. Наступна компонента — найбільша дисперсія в ортогональному доповненні, і так далі.

## 7. Застосування
- Зменшення розмірності (візуалізація 100-вимірних даних у 2D), стиснення, видалення шуму.
- Розпізнавання облич (eigenfaces), геометрія хмар точок (орієнтація об'єкта).
- PageRank — власний вектор матриці переходів (λ = 1).
- Спектральна кластеризація — власні вектори матриці графа.

## Для програміста
- `np.linalg.eigh(S)` (симетрична), `np.linalg.svd`, `sklearn.decomposition.PCA(n_components=2)`.
- Масштабуйте ознаки перед PCA (різні одиниці спотворять).
- PCA лінійний; для складних форм — t-SNE, UMAP, автокодувальники.
- Усічений SVD для великих розріджених матриць (`scipy.sparse.linalg.svds`).

## Типові помилки
1. Забути центрувати дані.
2. Застосувати PCA без масштабування.
3. Інтерпретувати компоненти як «реальні» причини.
4. Плутати власні числа (квадратних) і сингулярні (будь-яких матриць).
5. Очікувати, що PCA збереже класифікаційно важливі напрямки (шукає розкид, а не ознаку класу).
