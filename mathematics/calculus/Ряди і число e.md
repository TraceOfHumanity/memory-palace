# Ряди, нескінченні суми та число e

Числа перевірені обчисленням.

## 1. Нескінченна сума — як це можливо?
Парадокс Зенона: 1 + 1/2 + 1/4 + 1/8 + … = 2. Часткові суми (1; 1,5; 1,75; …) наближаються до 2, відстань до 2 щоразу зменшується вдвічі. **Сума ряду = границя часткових сум.** Числово: 40 членів → 1,9999999999982.

## 2. Геометричний ряд
a + aq + aq² + … = a/(1 − q) при |q| < 1. Виведення: S = a + qS → S(1 − q) = a. При |q| ≥ 1 — розбігається.
Приклад: 0,999… = 9/10 + 9/100 + … = (9/10)/(1 − 1/10) = 1.

## 3. Збіжність і розбіжність
- Необхідна умова: члени → 0. Але **не достатня**: гармонічний ряд 1 + 1/2 + 1/3 + … **розбігається** (повільно: сума перших 1000 членів ≈ 7,485, росте як ln n).
- Ряд 1/n² збігається (= π²/6 ≈ 1,645).
- Ознаки: порівняння, Даламбера (відношення сусідніх членів), інтегральна.

## 4. Число e
e = lim (1 + 1/n)ⁿ ≈ 2,718281828. Інший вигляд: **e = Σ 1/n! = 1 + 1 + 1/2 + 1/6 + 1/24 + …**. Сума перших 11 членів: 2,7182818011 (практично e).
Змістом: складні відсотки. 100 грн під 100 % річних: щорічно → 200; щомісяця → 261; щодня → 271,5; безперервно → 271,83 (100e).
e — основа, при якій (eˣ)′ = eˣ; ln x = logₑ x.

## 5. Ряд Тейлора: функція як нескінченний многочлен
Біля точки a: f(x) = f(a) + f′(a)(x − a) + f″(a)(x − a)²/2! + f‴(a)(x − a)³/3! + …
- eˣ = 1 + x + x²/2! + x³/3! + …
- sin x = x − x³/3! + x⁵/5! − …
- cos x = 1 − x²/2! + x⁴/4! − …
- 1/(1 − x) = 1 + x + x² + … (|x| < 1)
Приклад: sin 0,5 ≈ 0,5 − 0,125/6 = 0,47917 (точно 0,479426) — двох членів вистачає.
Саме так калькулятори й комп'ютери обчислюють sin, exp, ln: многочлен наближає, а многочлени рахувати легко.

## 6. Формула Ейлера (на додачу)
e^{iπ} + 1 = 0 — з ряду Тейлора eˣ, sin, cos при x → iθ: e^{iθ} = cos θ + i sin θ.

## Для програміста
- Обчислення функцій: ряд Тейлора, CORDIC; обмежити кількість членів за допустимою похибкою.
- Float: сума багатьох малих чисел губить точність — алгоритм Кагана (компенсоване сумування).
- Геометричний ряд — складність рекурсій (n + n/2 + n/4 + … = 2n).
- Збіжність ітераційних методів.

## Типові помилки
1. «Члени → 0, тож ряд збігається» (гармонічний — ні).
2. Геометрична формула при |q| ≥ 1.
3. Ряд Тейлора поза радіусом збіжності.
4. Плутати 0,999… «майже 1» і = 1 (рівно 1).
