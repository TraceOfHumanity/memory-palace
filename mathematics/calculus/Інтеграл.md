# Інтеграл

Числа перевірені обчисленням (Python).

## 1. Ідея: площа під кривою, як нескінченна сума
Як знайти площу фігури під графіком f на [a, b]? Розріжемо на n тонких смужок-прямокутників шириною Δx = (b − a)/n, висотою f(xᵢ). Сума площ — **сума Рімана**. Чим більше n, тим точніше; границя — **визначений інтеграл**:
`∫ₐᵇ f(x) dx = lim_{n→∞} Σ f(xᵢ)Δx`.
Приклад: ∫₀¹ x² dx. Ліва сума при n = 100: 0,32835; права: 0,33835; точне значення 1/3 ≈ 0,3333 між ними.
Знак ∫ — витягнута літера S (summa); dx — «ширина крихітної смужки».
Площа **зі знаком**: під віссю x — від'ємна.

## 2. Фізичний зміст
Якщо v(t) — швидкість, то ∫ v dt — пройдений шлях. Інтеграл накопичує: перетворює «швидкість зміни» у «загальну зміну». Тож інтеграл — обернена дія до похідної.

## 3. Основна теорема аналізу (зв'язок з похідною)
Якщо F′ = f (F — **первісна**), то `∫ₐᵇ f(x) dx = F(b) − F(a)`.
- Не треба рахувати нескінченні суми — достатньо знайти первісну!
- Чому: F(b) − F(a) — сумарна зміна F, яка складається з крихітних змін F′dx = f dx. Це «телескопічна сума».
- Приклад: ∫₀¹ x² dx = [x³/3]₀¹ = 1/3. ∫₀^π sin x dx = [−cos x]₀^π = 1 − (−1) = 2.

## 4. Невизначений інтеграл (первісна)
∫ f(x) dx = F(x) + C. Константа C, бо похідна сталої = 0. Первісних безліч, відрізняються на константу.

## 5. Таблиця
| f | ∫ f dx |
|---|---|
| xⁿ (n ≠ −1) | xⁿ⁺¹/(n+1) + C |
| 1/x | ln\|x\| + C |
| eˣ | eˣ + C |
| aˣ | aˣ/ln a + C |
| sin x | −cos x + C |
| cos x | sin x + C |
| 1/(1+x²) | arctg x + C |
Лінійність: ∫(af + bg) = a∫f + b∫g.

## 6. Методи
- **Заміна змінної (підстановка):** ∫ f(g(x))g′(x)dx = ∫ f(u)du, u = g(x). Це ланцюгове правило навпаки. Приклад ∫ 2x·cos(x²) dx = sin(x²) + C.
- **По частинах:** ∫ u dv = uv − ∫ v du. Це правило добутку навпаки. Приклад ∫ x eˣ dx = x eˣ − eˣ + C.

## 7. Застосування
- **Площа між кривими:** ∫ (верхня − нижня) dx. y = x і y = x²: перетини 0 і 1, площа = ∫₀¹ (x − x²)dx = 1/2 − 1/3 = 1/6.
- **Середнє значення функції:** (1/(b − a))∫ f dx.
- **Об'єми тіл обертання, довжина кривої, робота, маса, заряд.**
- **Ймовірність:** площа під кривою щільності (нормальний розподіл).

## 8. Числове інтегрування (коли первісну не знайти)
- Прямокутники (ліві/праві/середні).
- **Трапеції:** (Δx/2)(f₀ + 2f₁ + … + fₙ).
- **Симпсон:** точніший (параболи).
- Монте-Карло: випадкові точки; частка під кривою × площа прямокутника.
Часто ∫ eˣ² не виражається елементарно — тільки числово.

## Для програміста
- `sum += f(x) * dx` — цикл по смужках; accumulate; інтегрування сигналів, фізика (позиція += швидкість·dt — це інтеграл за методом Ейлера!).
- Накопичувальні суми (prefix sums) — дискретний аналог.
- Ймовірнісне Монте-Карло.

## Типові помилки
1. Забути +C у невизначеному.
2. Забути, що площа під віссю від'ємна.
3. ∫ 1/x = ln|x|, не x⁰/0.
4. Не міняти межі при заміні змінної у визначеному інтегралі.
5. Плутати інтеграл як площу та як первісну (зв'язок дає теорема).
