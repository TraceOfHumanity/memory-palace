# Застосування похідної: екстремуми й оптимізація

Числа перевірені обчисленням.

## 1. Екстремуми
**Локальний максимум/мінімум** — точка, значення в якій найбільше/найменше серед сусідніх. Необхідна умова (теорема Ферма): у внутрішньому екстремумі f′ = 0 (або f′ не існує). Достатня: f′ змінює знак (+ → − максимум; − → + мінімум) або f″(x₀) ≠ 0 (f″ > 0 → мінімум, f″ < 0 → максимум).
Глобальні на відрізку [a, b]: порівняти значення в критичних точках **і на кінцях**.

## 2. Алгоритм знаходження найбільшого/найменшого
1. Область визначення та відрізок.
2. f′(x) = 0 та точки, де f′ не існує.
3. Обчислити f у цих точках та на кінцях.
4. Вибрати найбільше/найменше.
Приклад f = x³ − 3x на [−2, 2]: f(−2) = −2, f(−1) = 2, f(1) = −2, f(2) = 2 → max = 2, min = −2.

## 3. Оптимізація (задачі «знайти найкраще»)
План: 1) змінна, 2) функція мети, 3) зв'язок (обмеження) → одна змінна, 4) знайти екстремум, 5) відповісти.
- **Огорожа:** 100 м сітки, прямокутна ділянка максимальної площі. Сторони x і 50 − x: S = x(50 − x), S′ = 50 − 2x = 0 → x = 25. Квадрат 25×25: S = 625 м².
- **Сума x + 1/x при x > 0:** f′ = 1 − 1/x² = 0 → x = 1, мінімум 2.
- Банка: мінімум матеріалу при заданому об'ємі, тощо.

## 4. Опуклість і перегин
f″ > 0 — графік над дотичною (опукла вниз, «чаша»), f″ < 0 — «шапка». Перегин — зміна знаку f″.

## 5. Правило Лопіталя
Невизначеність 0/0 або ∞/∞: lim f/g = lim f′/g′ (якщо існує). Приклад: lim_{x→0} sin x / x = lim cos x / 1 = 1.

## 6. Метод Ньютона (розв'язок f(x) = 0)
x_{n+1} = x_n − f(x_n)/f′(x_n) — дотична до осі x. Приклад √2: f = x² − 2; x₀ = 1 → 1,5 → 1,41667 → 1,41422 — подвоєння точних цифр за крок.

## 7. Лінійне наближення та диференціал
f(x + Δx) ≈ f(x) + f′(x)Δx. √4,1 ≈ 2 + (1/4)·0,1 = 2,025 (точно 2,02485).

## Для програміста
- Градієнтний спуск — пошук мінімуму; learning rate = розмір кроку; локальні мінімуми, сідлові точки.
- Оптимізація продуктивності: де функція «вартості» має мінімум.
- Метод Ньютона — швидке обчислення коренів, у т.ч. всередині `sqrt`.

## Типові помилки
1. Ігнорувати кінці відрізка.
2. Вважати кожну критичну точку екстремумом.
3. Не враховувати обмеження (x > 0).
4. Не перевіряти, що знайдений екстремум — саме той тип (max/min).
