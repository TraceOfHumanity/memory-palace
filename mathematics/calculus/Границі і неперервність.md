# Границі та неперервність

Числа перевірені обчисленням (Python).

## 1. Навіщо границі
Усе «динамічне» в математиці — миттєва швидкість, нахил кривої, площа під кривою — потребує поводження з **нескінченно малим**. Границя — акуратний спосіб це зробити без парадоксів: не «ділимо на нуль», а питаємо, **до чого наближається** значення.

## 2. Інтуїція
`lim_{x→a} f(x) = L` означає: **коли x наближається до a (але не дорівнює a), f(x) наближається до L**, скільки завгодно близько.
- Важливо: границя не залежить від значення **в самій точці** a (функція там може бути навіть не визначена), лише від поведінки **поряд**.
- Приклад: f(x) = (x² − 1)/(x − 1). При x = 1 — 0/0, не визначено. Але для x ≠ 1: f(x) = (x − 1)(x + 1)/(x − 1) = x + 1. Тому lim_{x→1} f = 2. Числова перевірка: x = 1,0001 → f = 2,0001.
- Таблиця: x = 0,9; 0,99; 0,999 → f = 1,9; 1,99; 1,999 → прямує до 2.
- Це не «ділення на нуль»: ми дивимось, що відбувається біля нуля у знаменнику.

## 3. Односторонні границі
lim_{x→a⁻} (зліва), lim_{x→a⁺} (справа). Границя існує ⇔ обидві односторонні існують і рівні.
- sign(x) у 0: зліва −1, справа +1 → границі немає.
- 1/x при x → 0⁺ → +∞, при x → 0⁻ → −∞.

## 4. Точне означення (ε–δ) — «гра»
Для будь-якого ε > 0 (допуск на відповідь) існує δ > 0 (допуск на вхід) таке, що якщо 0 < |x − a| < δ, то |f(x) − L| < ε.
Це «гра»: суперник називає як завгодно малу точність ε, ви знаходите δ, яке її забезпечує. Приклад: lim_{x→2} 3x = 6: |3x − 6| = 3|x − 2| < ε, візьмемо δ = ε/3.
Для програміста: «вибрати крок h так, щоб похибка була менша за tolerance».

## 5. Правила (границя суми, добутку, частки)
Якщо lim f = A, lim g = B, то: lim (f ± g) = A ± B; lim (f·g) = A·B; lim (f/g) = A/B (B ≠ 0); lim c·f = c·A; lim f(g(x)) для неперервних.
Для многочленів — просто підстановка.

## 6. Невизначеності і як їх розкривати
- **0/0:** розкласти на множники й скоротити (приклад вище); домножити на спряжене (√x − 1)/(x − 1) → 1/2; використати відомі границі.
- **∞/∞:** розділити чисельник і знаменник на найвищий степінь x. (3x² + 1)/(x² − 5) → 3 при x → ∞.
- **∞ − ∞**, **0·∞**: звести до дробу.
- **1^∞:** друга чудова границя.

## 7. Чудові границі
- `lim_{x→0} sin x / x = 1` (x в радіанах). Числово: x = 10⁻⁴ → 0,99999999983. Геометрично: для малого кута синус майже дорівнює дузі.
- `lim_{n→∞} (1 + 1/n)ⁿ = e ≈ 2,71828`. Числово: n = 10⁶ → 2,7182805. Це складні відсотки при безперервному нарахуванні.

## 8. Границі на нескінченності
lim_{x→∞} 1/x = 0 (горизонтальна асимптота y = 0). lim 2ˣ → ∞. Ріст: ln x ≪ √x ≪ x ≪ x² ≪ 2ˣ.

## 9. Неперервність
f **неперервна** в точці a, якщо: 1) f(a) визначена; 2) існує lim_{x→a} f(x); 3) вони рівні. Інтуїція: графік можна намалювати «не відриваючи руки».
Типи розривів: **усувний** (виколота точка), **стрибок** (односторонні границі різні), **нескінченний** (асимптота 1/x).
- Многочлени, sin, cos, eˣ — неперервні всюди; дроби — де знаменник ≠ 0; √x — на [0; ∞).
- **Теорема про проміжне значення:** неперервна на [a, b] функція набуває всіх значень між f(a) і f(b). Наслідок: якщо f(a) < 0 < f(b), на (a, b) є нуль → **метод бісекції** (бінарний пошук кореня).
- **Теорема Веєрштрасса:** неперервна на відрізку функція має найбільше й найменше значення.

## Для програміста
- Числова границя: обчислювати f(a ± h) з малим h; але не надто малим (втрата точності float: (1+1e-16) = 1!). Типова помилка: катастрофічне віднімання.
- Бісекція: `while hi - lo > eps: mid; if f(lo)*f(mid) <= 0: hi = mid else lo = mid`. Збіжність гарантована неперервністю.
- Збіжність алгоритмів (ітерації наближаються до границі).

## Типові помилки
1. «lim = f(a)» завжди — не завжди (розрив).
2. Підставити a і отримати 0/0 — «границі не існує» (ні, треба розкрити невизначеність).
3. Вважати ∞ числом: ∞ − ∞ ≠ 0.
4. sin x / x → 1 лише в радіанах.
5. Плутати «границя дорівнює ∞» з «існує» — це поведінка зростання, а не число.
