# Похідна

Числа перевірені обчисленням (Python).

## 1. Ідея: миттєва швидкість і нахил дотичної
- Середня швидкість на проміжку: Δs/Δt (нахил **січної** через дві точки графіка).
- Миттєва швидкість — що буде, якщо проміжок стискати до нуля: **нахил дотичної**.
- **Похідна** f′(a) — миттєва швидкість зміни f у точці a = нахил дотичної до графіка в (a; f(a)).

## 2. Означення
`f′(a) = lim_{h→0} (f(a + h) − f(a)) / h`
- Приклад f(x) = x² у a = 3: ((3 + h)² − 9)/h = (6h + h²)/h = 6 + h → 6. Числово h = 0,001: 6,001.
- Різницеве відношення — нахил січної; границя — нахил дотичної.
- Позначення: f′(x), dy/dx, df/dx (Лейбніц: «крихітна зміна y на крихітну зміну x»).
- Одиниці: [f]/[x] (м/с, грн/кг).

## 3. Геометрія та рівняння дотичної
Дотична в x = a: `y = f(a) + f′(a)(x − a)`. Це **лінійне наближення**: поблизу a функція майже пряма (локальна лінійність).
Приклад: f = x², a = 3: y = 9 + 6(x − 3) = 6x − 9.

## 4. Існування похідної
Не існує в точках розриву, зламу (|x| у 0: зліва −1, справа +1) і вертикальної дотичної. **Диференційовна ⇒ неперервна**, але не навпаки.

## 5. Таблиця похідних
| f(x) | f′(x) |
|---|---|
| c | 0 |
| xⁿ | n·xⁿ⁻¹ |
| √x | 1/(2√x) |
| 1/x | −1/x² |
| eˣ | eˣ |
| aˣ | aˣ ln a |
| ln x | 1/x |
| sin x | cos x |
| cos x | −sin x |
| tg x | 1/cos²x |

**Звідки xⁿ:** (x + h)ⁿ = xⁿ + n·xⁿ⁻¹h + …; усі старші члени мають h² і зникають у границі.
**Чому (eˣ)′ = eˣ:** e — число, при якому нахил eˣ в нулі дорівнює 1, а далі «швидкість росту пропорційна поточному значенню».

## 6. Правила
- **Лінійність:** (af + bg)′ = af′ + bg′.
- **Добуток:** (fg)′ = f′g + fg′.
- **Частка:** (f/g)′ = (f′g − fg′)/g².
- **Складена (ланцюгове правило):** (f(g(x)))′ = f′(g(x))·g′(x). Зовнішня × внутрішня.
  Приклад: (sin x²)′ = cos(x²)·2x; при x = 2: 4·cos 4 ≈ −2,6146.
- **Обернена функція:** (f⁻¹)′(y) = 1/f′(x). Звідси (ln x)′ = 1/x.
Приклад добутку: (x² sin x)′ = 2x sin x + x² cos x.
Приклад частки: (x/(x+1))′ = 1/(x+1)².

## 7. Похідна і поведінка функції
- f′ > 0 → зростає; f′ < 0 → спадає; f′ = 0 → **критична точка** (кандидат на екстремум).
- **Друга похідна** f″ (похідна похідної) — «прискорення»: f″ > 0 — опукла вниз («чаша»), f″ < 0 — вгору. Зміна знаку f″ — точка перегину.
- Приклад: f = x³ − 3x; f′ = 3x² − 3 = 0 → x = ±1; f(−1) = 2 (максимум), f(1) = −2 (мінімум).

## 8. Фізичний зміст
s(t) — шлях; v = s′; a = v′ = s″. Швидкість зміни ціни, температури, населення.

## Для програміста
- **Градієнтний спуск:** x ← x − η·f′(x) (крок проти похідної до мінімуму). Основа навчання нейромереж.
- **Числова похідна:** (f(x + h) − f(x − h))/(2h) (центральна різниця точніша). h ≈ 10⁻⁵…10⁻⁶ для double.
- **Автоматичне диференціювання** (autodiff) — ланцюгове правило, застосоване алгоритмічно (PyTorch, TensorFlow).
- Швидкість зміни в симуляціях: dx/dt, метод Ейлера x += v·dt.

## Типові помилки
1. (fg)′ = f′g′ (ні! правило добутку).
2. Забути внутрішню похідну в ланцюговому правилі: (sin 2x)′ = 2cos 2x, не cos 2x.
3. (xⁿ)′ = n·xⁿ⁻¹ — для eˣ це не діє (eˣ — не степінь від x).
4. f′(a) = 0 ⇒ екстремум — не завжди (x³ у 0 — перегин).
5. Не перевіряти область визначення.
