# Найважливіші графіки (які треба знати напам'ять)

Це «алфавіт» графіків: майже будь-яка складна залежність складається з цих. Для кожного — форма, ключові точки, область визначення D / значень E, парність, поведінка.
Числові приклади перевірені обчисленням.

---

## 1. Пряма y = kx + b
- Форма: пряма лінія. k — нахил (Δy/Δx), b — перетин з віссю y (точка (0; b)).
- Нуль: x = −b/k (k ≠ 0). D = ℝ, E = ℝ (при k ≠ 0).
- k > 0 зростає, k < 0 спадає, k = 0 — горизонталь y = b.
- Дві прямі паралельні, якщо k однакові; перпендикулярні, якщо k₁·k₂ = −1.
- y = x — діагональ (1-ша і 3-тя чверті), на ній лежать точки (a; a); відносно неї дзеркальні графіки взаємно обернених функцій.
- Приклад: y = 2x + 1: (0; 1), (1; 3), (2; 5).

## 2. Парабола y = x²
- Форма: чаша, вершина (0; 0), відкрита вгору. D = ℝ, E = [0; +∞). **Парна** (симетрія відносно осі y).
- Точки: (±1; 1), (±2; 4), (±3; 9). Росте швидше за пряму: «чим далі, тим крутіше».
- Спадає на (−∞; 0], зростає на [0; +∞).
- Загальна: y = ax² + bx + c. Вершина x₀ = −b/(2a). a > 0 — гілки вгору, a < 0 — вниз; |a| більше — вужча.
- Приклад: y = x² − 4x + 3: x₀ = 2, y₀ = −1, нулі 1 і 3, перетин з віссю y — (0; 3).
- Дискримінант D: D > 0 — два перетини з віссю x, D = 0 — дотик у вершині, D < 0 — не перетинає.

## 3. Кубічна парабола y = x³
- Форма: «S»-подібна, проходить через початок координат. D = ℝ, E = ℝ. **Непарна** (симетрія відносно початку).
- Точки: (±1; ±1), (±2; ±8). Біля 0 дуже пласка, далі стрімка. Завжди зростає, екстремумів немає (у початку — точка перегину).

## 4. Гіпербола y = 1/x
- Дві гілки (у 1-й та 3-й чвертях). D: x ≠ 0, E: y ≠ 0. **Непарна.**
- Асимптоти: вертикальна x = 0, горизонтальна y = 0 — крива до них наближається, але не торкається.
- Точки: (1; 1), (2; 0,5), (0,1; 10), (0,01; 100), (−1; −1).
- Обернена пропорційність: «чим більше x, тим менше y». xy = 1 — стала.
- Спадає на кожній гілці окремо (не на всій області визначення).
- Споріднена y = 1/x²: парна, обидві гілки вгору, y > 0.

## 5. Квадратний корінь y = √x
- «Половина» параболи, повернутої набік. D = [0; +∞), E = [0; +∞). Починається в (0; 0).
- Точки: (0; 0), (1; 1), (4; 2), (9; 3). Росте повільно (спочатку круто, потім положисто).
- Обернена до y = x² на [0; +∞): графіки дзеркальні відносно y = x.
- Кубічний корінь ∛x: визначений для всіх x (непарна, «S» на боці).

## 6. Модуль y = |x|
- «V»-подібна, вершина в початку, кути 45°. D = ℝ, E = [0; +∞). **Парна.**
- Кусково-лінійна: y = x при x ≥ 0 і y = −x при x < 0. У нулі — злам (гладкості немає).
- y = |x − a| + b — V із вершиною (a; b). Відстань на числовій прямій: |x − a|.

## 7. Показникова y = aˣ (a > 0, a ≠ 1)
- a > 1: швидке зростання, a < 1 — спадання. D = ℝ, E = (0; +∞): **завжди над віссю x**.
- Усі проходять через (0; 1). Для 2ˣ: (−1; 0,5), (0; 1), (1; 2), (2; 4), (3; 8).
- Горизонтальна асимптота y = 0 (при x → −∞ для a > 1).
- Особлива: y = eˣ (e ≈ 2,718): нахил дотичної в (0; 1) дорівнює 1; eˣ збігається зі своєю швидкістю зростання.
- Прикладами є складні відсотки, зростання популяцій, радіоактивний розпад (a < 1).

## 8. Логарифм y = logₐ x
- Обернена до aˣ: дзеркало відносно y = x. D = (0; +∞), E = ℝ. **Завжди праворуч від осі y**, вісь y — вертикальна асимптота.
- Усі проходять через (1; 0). Для log₂: (1/2; −1), (1; 0), (2; 1), (4; 2), (8; 3).
- Росте дуже повільно (a > 1): щоб підняти на 1, треба помножити x на a.
- Прикладами є децибели, pH, складність алгоритмів O(log n) (бінарний пошук).

## 9. Синус та косинус y = sin x, y = cos x
- Хвилі, періодичні (T = 2π ≈ 6,28). D = ℝ, E = [−1; 1].
- sin: проходить (0; 0), максимум (π/2; 1), нуль (π; 0), мінімум (3π/2; −1). **Непарний.**
- cos: починається з максимуму (0; 1), нуль у π/2. **Парний.** cos x = sin(x + π/2): зсунутий синус.
- Амплітуда A, період T = 2π/ω: y = A·sin(ωx + φ).
- Прикладами є коливання, звук, змінний струм, обертання.

## 10. Тангенс y = tg x
- Періодичний (T = π), **вертикальні асимптоти** x = π/2 + πk, область значень ℝ. Непарний. Між асимптотами зростає від −∞ до +∞.
- tg x = sin x / cos x: вертикальна асимптота там, де cos x = 0.

## 11. Коло x² + y² = r² (не функція)
- Радіус r, центр (0; 0). Два значення y для одного x → не функція. Верхнє півколо y = √(r² − x²).
- (x − a)² + (y − b)² = r² — коло з центром (a; b).
- Еліпс x²/a² + y²/b² = 1 — витягнуте коло.

## 12. Кусково-задані та сходинки
- **Підлога** ⌊x⌋: сходинки, на кожному [n; n+1) значення n. ⌊2,7⌋ = 2, ⌊−1,5⌋ = −2 (!). Розриви в цілих.
- **Знак** sign x: −1, 0, 1.
- Кусково-лінійні — податкові шкали, тарифи. У програмуванні — `if/else`.

## Як пізнавати графік за виглядом формули
- Змінна лише в 1-му степені → пряма.
- x² (найвищий степінь 2) → парабола; x³ → кубічна.
- x у знаменнику → гіпербола (є розрив).
- x під коренем → «півпарабола», обмежена область.
- x у **показнику** → експонента (швидке зростання/спадання).
- Модуль → «V» та кути.
- sin/cos → хвиля.

## Швидкі правила порівняння росту (на нескінченності)
logx ≪ √x ≪ x ≪ x² ≪ x³ ≪ 2ˣ ≪ x! . Показникова зрештою обганяє будь-який степінь. Для програміста це асимптотика складності: O(log n), O(√n), O(n), O(n²), O(2ⁿ).

## Перетворення (з будь-якого графіка отримуємо родину)
f(x − a) — вправо на a; f(x) + b — вгору на b; −f(x) — відбиття відносно осі x; f(−x) — відносно осі y; k·f(x) — розтяг по y; f(kx) — стиск по x; |f(x)| — від'ємні частини відбиваються вгору. Приклад: y = (x − 2)² + 1 — парабола з вершиною (2; 1).

## Типові помилки
1. Малювати y = x² «гострою» біля нуля (вона гладка, дно закруглене).
2. Забувати асимптоти 1/x, tg x і з'єднувати гілки.
3. Вважати, що log та √ визначені для від'ємних x.
4. Забувати, що aˣ завжди додатна і ніколи не торкається осі x.
5. Плутати парність: x² парна, x³ непарна; sin непарний, cos парний.
6. Думати, що експонента «колись» перетне вісь — не перетне.
7. Плутати зсув f(x − a) (вправо) та f(x + a) (вліво).
