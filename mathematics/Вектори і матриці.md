# Вектори і матриці

Усі числові приклади нижче перевірені в numpy 2.0.2 (`np.linalg`, `@`, `np.cross`).

---

## Частина I. Вектори

### 1. Що таке вектор — три погляди на одне й те саме
1. **Геометричний:** напрямлений відрізок = «скільки пройти і в який бік». Має довжину й напрямок. Початок не важливий: стрілку можна переносити паралельно, вона залишається тим самим вектором.
2. **Числовий (для програміста):** впорядкований список чисел `(x; y)` або `(x; y; z)`. Це просто масив `[3, 1]`.
3. **Абстрактний:** будь-що, що можна **додавати** і **множити на число**, і ці операції поводяться «як треба» (аксіоми векторного простору). Стрілки, списки, багаточлени, звукові сигнали, пікселі зображення — усе це вектори.

Різниця між **точкою** і **вектором**: точка — це місце, вектор — це зсув. Точка + вектор = точка. Точка − точка = вектор. Вектор + вектор = вектор. Точка + точка — не має змісту. У графіці це різниця між `w = 1` (точка) і `w = 0` (вектор) в однорідних координатах.

Вектор a = (3; 1) означає: «3 вправо, 1 вгору». Координати — це розклад зсуву за осями.

### 2. Додавання векторів
`a + b = (a₁ + b₁; a₂ + b₂)` — додаємо покоординатно.
- Приклад: (3; 1) + (1; 3) = (4; 4).
- Геометрично два рівнозначні способи: **«ланцюжок»** (початок b у кінець a) і **правило паралелограма** (обидва з одного початку, сума — діагональ).
- Властивості: a + b = b + a; (a + b) + c = a + (b + c); a + 0 = a; a + (−a) = 0.
- **Чому покоординатно?** Бо «3 вправо, 1 вгору» і потім «1 вправо, 3 вгору» — разом 4 вправо, 4 вгору. Рух по осях незалежний.
- Різниця a − b — вектор **від кінця b до кінця a** (коли обидва відкладені з одного початку). Корисно: напрямок «від ворога до гравця» = гравець − ворог.

### 3. Множення на число (скаляр)
`k·a = (k·a₁; k·a₂)`. k > 1 розтягує, 0 < k < 1 стискає, k < 0 розвертає в протилежний бік, k = 0 дає нульовий вектор.
- 2·(3; 1) = (6; 2); −(3; 1) = (−3; −1).
- Розподільність: k(a + b) = ka + kb; (k + m)a = ka + ma. Це ті самі закони, що й для чисел (див. розподільний закон).

### 4. Довжина (норма)
`|a| = √(a₁² + a₂²)` — теорема Піфагора. Для (3; 1): √10 ≈ 3,162. У 3D: √(x² + y² + z²), узагальнення Піфагора (два прямокутні трикутники поспіль).
- `|k·a| = |k|·|a|`.
- **Одиничний вектор** (довжина 1): `â = a / |a|` — це **нормалізація**. Дає чистий напрямок. Нормалізувати нульовий вектор не можна (ділення на нуль!).
- Відстань між точками A і B = |B − A|.

### 5. Скалярний добуток (dot product)
**Алгебраїчно:** `a·b = a₁b₁ + a₂b₂ (+ a₃b₃)`. Результат — **число**, не вектор.
**Геометрично:** `a·b = |a|·|b|·cos φ`, φ — кут між векторами.
- (3; 1)·(1; 3) = 3 + 3 = 6. |a| = |b| = √10, тому cos φ = 6/10 = 0,6, φ ≈ 53,13°.

**Чому ці дві формули однакові (доведення через теорему косинусів).** Трикутник зі сторонами a, b, a−b. Теорема косинусів: |a−b|² = |a|² + |b|² − 2|a||b|cos φ. Але |a−b|² = (a₁−b₁)² + (a₂−b₂)² = |a|² + |b|² − 2(a₁b₁ + a₂b₂). Порівнюємо: a₁b₁ + a₂b₂ = |a||b|cos φ. ∎

**Що воно означає:**
- a·b > 0 — вектори «дивляться в один бік» (кут гострий); a·b = 0 — **перпендикулярні**; a·b < 0 — у протилежні боки (кут тупий).
- a·a = |a|² — довжина в квадраті.
- **Проєкція** b на напрямок a: `proj = (a·b / a·a)·a`. Скалярна довжина проєкції = |b|cos φ. Приклад: проєкція (3; 1) на (1; 3): 6/10·(1; 3) = (0,6; 1,8).
- Кут: `φ = arccos(a·b / (|a||b|))`.
- Властивості: a·b = b·a; a·(b + c) = a·b + a·c; (ka)·b = k(a·b).

**Для програміста:** `dot(forward, toTarget) > 0` — ціль попереду; `dot(normal, lightDir)` — яскравість освітлення (закон Ламберта); `dot(a, b) / (|a||b|)` — косинусна подібність (пошук, рекомендації, ембединги); робота = сила · переміщення.

### 6. Векторний добуток (cross product, тільки 3D)
`a × b` = вектор, **перпендикулярний** обом, довжина = |a||b|sin φ = площа паралелограма на a і b. Напрямок — за правилом правої руки.
- Формула: `(a₂b₃ − a₃b₂; a₃b₁ − a₁b₃; a₁b₂ − a₂b₁)`.
- (1; 0; 0) × (0; 1; 0) = (0; 0; 1) ✓. (1; 2; 3) × (4; 5; 6) = (−3; 6; −3) ✓.
- a × b = −(b × a) (антикомутативність!). a × a = 0.
- Застосування: нормаль до трикутника (graphics), момент сили, орієнтація (знак).
- У 2D є «псевдо-добуток» a₁b₂ − a₂b₁ = площа зі знаком = визначник матриці з колонок a і b.

### 7. Лінійна комбінація, span, базис
- **Лінійна комбінація:** `c₁v₁ + c₂v₂ + …` — «скільки взяти кожного вектора».
- **Span** — усі точки, які можна отримати. Один ненульовий вектор → пряма; два неколінеарні в 2D → вся площина; два колінеарні → знову лише пряма.
- **Лінійна незалежність:** жоден вектор не виражається через решту. Для двох векторів — не лежать на одній прямій.
- **Базис** — набір незалежних векторів, що породжують весь простір. Кожен вектор записується **єдиним** способом.
- **Стандартний базис:** î = (1; 0), ĵ = (0; 1). Запис (3; 2) — це насправді `3·î + 2·ĵ`. **Координати — це «рецепт» у заданому базисі.** Інший базис — інші координати для тієї самої стрілки.
- Розмірність = кількість векторів базису (2 для площини, 3 для простору).

## Частина II. Матриці

### 8. Що таке матриця — головна ідея
Формально: прямокутна таблиця чисел, m рядків × n стовпців.
```
A = | 2  1 |
    | 1  2 |
```
Але справжній зміст: **матриця — це лінійне перетворення** простору (поворот, розтяг, дзеркало, зсув (shear), проєкція), записане числами.

**Лінійне** означає: початок координат залишається на місці, прямі лишаються прямими, паралельні — паралельними, сітка — рівномірною. Формально: `A(u + v) = Au + Av`, `A(ku) = k·Au`.

**Ключ:** лінійне перетворення повністю визначається тим, куди воно переводить базисні вектори. Бо (x; y) = x·î + y·ĵ, а отже A(x; y) = x·A(î) + y·A(ĵ).
**Стовпці матриці = образи î та ĵ.**
Для A = [[2, 1], [1, 2]]: î → (2; 1) (перший стовпець), ĵ → (1; 2) (другий). Одиничний квадрат перетворюється на паралелограм.

### 9. Матриця × вектор — два способи обчислення
Приклад: A = [[2, 1], [1, 2]], v = (1; 2). Відповідь (4; 5).
1. **По рядках (скалярні добутки):** кожен елемент результату = (рядок A)·v: 2·1 + 1·2 = 4; 1·1 + 2·2 = 5.
2. **По стовпцях (лінійна комбінація, суть!):** `1·(2; 1) + 2·(1; 2) = (2; 1) + (2; 4) = (4; 5)`. Результат — комбінація стовпців з коефіцієнтами з v.
Перший зручний для рахування, другий — для розуміння.

**Форми:** (m × n) · (n × 1) → (m × 1). Кількість стовпців матриці = довжині вектора.

### 10. Стандартні перетворення (2D)
| Перетворення | Матриця | Пояснення |
|---|---|---|
| Масштаб | [[sx, 0], [0, sy]] | розтяг осей |
| Поворот на θ (проти год.) | [[cos θ, −sin θ], [sin θ, cos θ]] | î → (cos θ; sin θ), ĵ → (−sin θ; cos θ) |
| Дзеркало відносно осі x | [[1, 0], [0, −1]] | y → −y |
| Зсув (shear) | [[1, k], [0, 1]] | ĵ → (k; 1) |
| Проєкція на вісь x | [[1, 0], [0, 0]] | колапс: втрата виміру |
| Одинична (identity) | [[1, 0], [0, 1]] | нічого не змінює |

- Поворот на 90°: [[0, −1], [1, 0]]; (2; 1) → (−1; 2) ✓.
- Поворот на 45°: [[c, −c], [c, c]], c = √2/2 ≈ 0,7071; (1; 0) → (0,707; 0,707) ✓.
- **Звідки формула повороту:** î повертається в точку одиничного кола (cos θ; sin θ) — це перший стовпець; ĵ (на 90° попереду) → (cos(θ+90°); sin(θ+90°)) = (−sin θ; cos θ) — другий стовпець.

### 11. Добуток матриць = композиція перетворень
`(AB)v = A(Bv)`: спершу B, потім A — **порядок справа наліво**.
**Правило обчислення:** елемент (i, j) результату = (рядок i матриці A)·(стовпець j матриці B).

Приклад: A = [[1, 2], [3, 4]], B = [[0, 1], [1, 0]] (B міняє місцями координати).
- AB = [[2, 1], [4, 3]] — B переставляє **стовпці** A.
- BA = [[3, 4], [1, 2]] — B переставляє **рядки** A.
- **AB ≠ BA** — множення матриць **не комутативне**. Приклад з життя: «повернути, потім розтягнути» ≠ «розтягнути, потім повернути». Одягти шкарпетки і взути взуття — не те саме, що навпаки.
- Асоціативність є: (AB)C = A(BC). Розподільність: A(B + C) = AB + AC.
- **Розміри:** (m × n)·(n × k) = (m × k). Внутрішні розміри мають збігатися. (2×3)·(3×2): [[1,2,3],[4,5,6]]·[[1,0],[0,1],[1,1]] = [[4,5],[10,11]] ✓.
- **Чому правило таке дивне?** Бо його виводять із вимоги «(AB)v = A(Bv)» — таблиця множення лише стенографія композиції.
- Складність: наївне множення n×n — O(n³).
- Піднесення до степеня: A² = A·A. Для поворотів Rθ² = R(2θ) (R45² = R90 ✓).

### 12. Транспонування
Aᵀ — дзеркало відносно головної діагоналі: (Aᵀ)ᵢⱼ = Aⱼᵢ. [[1, 2], [3, 4]]ᵀ = [[1, 3], [2, 4]]. Властивість: (AB)ᵀ = BᵀAᵀ (порядок змінюється, як при знятті взуття). Для векторів: a·b = aᵀb.
Симетрична матриця: A = Aᵀ. Ортогональна: AᵀA = I (повороти, дзеркала зберігають довжини й кути; обернена = транспонована).

### 13. Визначник (determinant)
Для 2×2: `det [[a, b], [c, d]] = ad − bc`.
**Зміст:** коефіцієнт зміни площі (у 3D — об'єму). Одиничний квадрат (площа 1) → паралелограм площею |det|.
- A = [[2, 1], [1, 2]]: det = 4 − 1 = 3 → площа ×3.
- Зсув [[1, 1], [0, 1]]: det = 1 (площа не змінюється, лише скошується).
- Поворот: det = 1. Дзеркало: det = −1 (**знак мінус — орієнтація розвернулася**, «лівий» стає «правим»).
- [[1, 2], [2, 4]]: det = 0 — стовпці колінеарні, площина «складається» в пряму. Інформація втрачена назавжди.
- **det = 0 ⇔ матриця вироджена ⇔ немає оберненої.**
- det(AB) = det(A)·det(B) (коефіцієнти площ перемножуються).
- **Доведення формули ad − bc:** площа паралелограма на (a; c) і (b; d) = площа прямокутника (a+b)(c+d) мінус два трикутники і дві пари прямокутників → ad − bc. (На картинці: великий прямокутник мінус 2 трикутники ½ac, 2 трикутники ½bd, 2 прямокутники bc.)
- Для 3×3: розклад за першим рядком (мінори), або як об'єм паралелепіпеда = a·(b × c).

### 14. Обернена матриця
A⁻¹ — перетворення, що скасовує A: A⁻¹A = AA⁻¹ = I.
- Для 2×2: `A⁻¹ = (1/det)·[[d, −b], [−c, a]]`.
- A = [[2, 1], [1, 2]]: A⁻¹ = (1/3)·[[2, −1], [−1, 2]] ✓.
- A = [[1, 2], [3, 4]]: det = −2, A⁻¹ = [[−2; 1]; [1,5; −0,5]] (рядки (−2; 1) і (1,5; −0,5)) ✓.
- Існує лише при det ≠ 0 (не можна «розплющити» пряму назад у площину).
- (AB)⁻¹ = B⁻¹A⁻¹ (знімаємо у зворотному порядку).
- Поворот: R(θ)⁻¹ = R(−θ) = R(θ)ᵀ.

### 15. Системи лінійних рівнянь = Ax = b
```
2x + y = 5
x + 3y = 5
```
Записуємо: A = [[2, 1], [1, 3]], x = (x; y), b = (5; 5). Питання: **який вектор x після перетворення A стає b?**
- Розв'язок: x = A⁻¹b. det = 5. Відповідь (2; 1) (перевірка: 4+1 = 5 ✓, 2+3 = 5 ✓).
- **Погляд по стовпцях:** знайти коефіцієнти, з якими стовпці (2; 1) і (1; 3) дають b: 2·(2; 1) + 1·(1; 3) = (5; 5) ✓.
- **Погляд по рядках:** два рівняння = дві прямі, розв'язок — точка перетину.
- det = 0: або прямі паралельні (немає розв'язків), або збігаються (безліч).
- Практично обернену матрицю не рахують — застосовують **метод Гауса** (елементарні перетворення рядків) або `np.linalg.solve`. Складність O(n³).
- Правило Крамера (2×2): x = det(Aₓ)/det(A), де в Aₓ перший стовпець замінено на b: x = (5·3 − 1·5)/5 = 2; y = (2·5 − 5·1)/5 = 1 ✓.

### 16. Власні вектори і власні числа
Більшість векторів після A **змінюють напрямок**. Але деякі лише розтягуються: `A·v = λ·v`. Такий v — **власний вектор**, λ — **власне число**.
A = [[2, 1], [1, 2]]:
- v = (1; 1) → A v = (3; 3) = 3·v → λ = 3.
- v = (1; −1) → A v = (1; −1) = 1·v → λ = 1.
- Знаходження: det(A − λI) = 0 → (2−λ)² − 1 = 0 → λ = 1 або 3 ✓.
- Сенс: «осі» перетворення; у власному базисі матриця діагональна (просто розтяги по осях). Звідси швидке піднесення до степеня: A¹⁰ = P·D¹⁰·P⁻¹.
- Застосування: PCA (головні компоненти даних), PageRank, стійкість систем, числа Фібоначчі (матриця [[1, 1], [1, 0]]).
- Поворот на кут ≠ 0°, 180° не має дійсних власних векторів (напрямок завжди змінюється; власні числа комплексні).

### 17. Однорідні координати (graphics)
Зсув (translation) **не лінійний** (початок зсувається). Трюк: додати координату w = 1: (x; y) → (x; y; 1), і зсув стає матрицею 3×3: [[1, 0, tx], [0, 1, ty], [0, 0, 1]]. Тоді поворот, масштаб і зсув комбінуються множенням матриць. У 3D — матриці 4×4. Типовий ланцюг: `MVP = Projection · View · Model`, застосовується до вершини справа наліво.

## Частина III. Для програміста

- **numpy:** `a @ b` (скалярний добуток/добуток матриць), `A @ v`, `A.T`, `np.linalg.inv(A)`, `np.linalg.solve(A, b)` (краще за inv), `np.linalg.det(A)`, `np.linalg.eig(A)`, `np.cross`, `np.linalg.norm`. **Пастка:** `A * B` — **поелементний** добуток, а не матричний.
- **Нейромережі:** шар = `y = W x + b` (матриця ваг × вектор входів). Пакет входів — матриця; навчання — це здебільшого множення матриць (GPU створені під них).
- **Графіка/ігри:** поворот і положення об'єктів, камера, проєкція (MVP), нормалі (cross), освітлення (dot), колізії (проєкції).
- **Пошук/ML:** текст → вектор (ембединг), схожість = косинус кута (dot / довжини).
- **Дані:** таблиця (рядки — об'єкти, стовпці — ознаки) = матриця. PCA, регресія (нормальні рівняння (XᵀX)β = Xᵀy).
- **Пам'ять:** row-major (C, numpy) vs column-major (Fortran, OpenGL, MATLAB) — порядок зберігання впливає на швидкість і на те, чи треба транспонувати.
- Числова точність: float дають cos(90°) ≈ 6e-17 замість 0 — порівнюйте з допуском `abs(x) < 1e-9`.

## Типові помилки
1. Вважати AB = BA (множення матриць не комутативне).
2. Множити матриці з неузгодженими розмірами ((2×3)·(2×3) неможливо).
3. Плутати порядок застосування: у AB спершу діє **B**.
4. Плутати скалярний добуток (число) з векторним (вектор) та поелементним `*`.
5. Ділити на матрицю: «A/B» не існує, є лише A·B⁻¹ або B⁻¹·A (різні!).
6. Забувати, що обернена існує лише при det ≠ 0.
7. (A + B)² ≠ A² + 2AB + B² (бо AB ≠ BA); (AB)ᵀ = BᵀAᵀ, а не AᵀBᵀ.
8. Вважати, що нульовий добуток означає нульовий множник: AB = 0 можливе при A ≠ 0 і B ≠ 0.
9. Нормалізувати нульовий вектор.
10. Додавати точку до точки; плутати точку з вектором.

## Алгоритм мислення
1. Вектор — зсув/список чисел; будь-який вектор = комбінація базисних.
2. Матриця — перетворення; **стовпці = куди йдуть î і ĵ**.
3. Матриця × вектор = комбінація стовпців.
4. Матриця × матриця = «спочатку права, потім ліва».
5. Визначник — у скільки разів змінюється площа; 0 → втрата виміру, обернена не існує.
6. Ax = b: «який вектор переходить у b?»; розв'язуємо Гаусом/solve.
7. Власні вектори — напрямки, що лишаються на місці.
8. Перевірка: розміри, порядок, підстановка відповіді.
