# Розподіли ймовірностей

Числа перевірені обчисленням (Python, math.erf).

## 1. Випадкова величина і розподіл
**Випадкова величина** X — число, що залежить від випадку (результат кидка, час очікування, зріст). **Розподіл** показує, з якою ймовірністю X набуває значень.
- **Дискретна** (рахуємо): P(X = k), сума всіх ймовірностей = 1 (таблиця / стовпчикова діаграма).
- **Неперервна** (вимірюємо): **щільність** f(x); імовірність потрапити у проміжок = площа під кривою f на ньому (інтеграл!). P(X = точне число) = 0. Повна площа = 1.
- **Функція розподілу** F(x) = P(X ≤ x) — накопичена ймовірність, зростає від 0 до 1.
- Сподівання E[X] = Σ x·P(x) (або ∫x f dx) — «центр мас». Дисперсія Var = E[(X − E X)²]; σ = √Var.

## 2. Рівномірний
Усі значення рівноймовірні. Дискретний: кубик, P(k) = 1/6, E = 3,5. Неперервний на [a, b]: f = 1/(b − a), E = (a + b)/2. Генератори випадкових чисел random() ∈ [0, 1).

## 3. Бернуллі та біноміальний
- **Бернуллі(p):** одне випробування «успіх/невдача», P(1) = p. E = p, Var = p(1 − p).
- **Біноміальний B(n, p):** кількість успіхів у n незалежних випробуваннях. `P(X = k) = C(n, k)·pᵏ·(1 − p)ⁿ⁻ᵏ`. E = np, Var = np(1 − p).
- Приклад: 10 підкидань монети, рівно 5 орлів: C(10, 5)/2¹⁰ = 252/1024 ≈ 0,246. Не більше 3 орлів: (1 + 10 + 45 + 120)/1024 ≈ 0,172.
- Приклад: 20 тестів із 5 % шансу збою — хоча б один збій = 1 − 0,95²⁰ ≈ 0,642 (64 %).

## 4. Геометричний
Кількість спроб до першого успіху: P(X = k) = (1 − p)ᵏ⁻¹p. E = 1/p. Кубик до першої шістки: в середньому 6 кидків.

## 5. Пуассон
Кількість рідкісних подій за фіксований проміжок (запити за секунду, помилки на сторінку): `P(X = k) = λᵏe^{−λ}/k!`, E = Var = λ.
Приклад λ = 3: P(0) = e⁻³ ≈ 0,0498; P(1) ≈ 0,149; P(2) ≈ 0,224. Граничний випадок біноміального при великому n, малому p, np = λ.

## 6. Нормальний (Гаусса)
Колокол: `f(x) = (1/(σ√(2π)))·e^{−(x − μ)²/(2σ²)}`. Параметри: μ — центр, σ — розкид. Симетричний.
- **Правило 68–95–99,7:** у межах μ ± σ — 68,3 %; μ ± 2σ — 95,4 %; μ ± 3σ — 99,7 %. μ ± 1,96σ — рівно 95 %.
- **Стандартизація:** z = (x − μ)/σ — скільки σ від центра. Тоді z ~ N(0, 1). Дає порівнювати різні шкали.
- Приклад: IQ (μ = 100, σ = 15): x = 130 → z = 2; вище лише ≈ 2,3 %.
- Чому нормальний скрізь? **Центральна гранична теорема**: сума багатьох незалежних малих внесків ≈ нормальна.

## 7. Експоненційний
Час між рідкісними подіями (Пуассонівський потік): f(x) = λe^{−λx}, E = 1/λ. «Не має пам'яті»: чекали вже довго — очікування не скорочується. Час життя, інтервали між запитами.

## 8. Інші важливі
- **Хі-квадрат, t-Стьюдента, F** — для статистичних тестів.
- **Степеневі (Парето, Ципфа)** — «важкі хвости»: розмір міст, частота слів, доходи. Нормальний тут не підходить: рідкісні величезні значення трапляються.
- **Логнормальний:** log X нормальний (ціни, розміри файлів).

## 9. Закон великих чисел
Середнє n незалежних спостережень → E[X] при n → ∞. Підкидаємо монету 10 разів — частка орлів може бути 0,3; тисячу — близько 0,5. Основа: симуляції Монте-Карло, страхування, A/B-тести.

## Для програміста
- `random.gauss`, `np.random.normal/binomial/poisson`. Монте-Карло: моделювання багаторазовим розігруванням.
- Моделі: час відповіді (логнормальний/експоненційний), кількість запитів (Пуассон), помилки (біноміальний).
- Не припускайте нормальність без перевірки (гістограма, Q–Q).
- Перцентилі p95/p99 важливіші за середнє для затримок.

## Типові помилки
1. Плутати щільність і ймовірність: f(x) — не ймовірність (може бути > 1).
2. Додавати стандартні відхилення замість дисперсій: Var(X + Y) = Var X + Var Y (незалежні).
3. Застосовувати нормальний розподіл до «важкохвостих» даних.
4. Плутати «незалежні» й «взаємовиключні».
5. Хибна думка гравця: після серії орлів «має випасти решка».
