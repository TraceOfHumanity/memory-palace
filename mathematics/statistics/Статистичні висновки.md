# Статистичні висновки: вибірка, ЦГТ, довірчі інтервали, перевірка гіпотез

Числа перевірені обчисленням.

## 1. Генеральна сукупність і вибірка
Хочемо знати щось про **всю** сукупність (усі користувачі, вся виробнича партія), але можемо виміряти лише **вибірку**. Висновок про ціле за вибіркою — ідея статистики. Вибірка має бути **репрезентативною** (випадкова), інакше зсув (survivorship bias, самовідбір).
- Параметр сукупності: μ, σ; оцінка за вибіркою: x̄, s.

## 2. Вибіркові характеристики
- Середнє x̄ = Σxᵢ/n. Медіана, мода.
- Дисперсія: s² = Σ(xᵢ − x̄)²/(n − 1) — **ділимо на n − 1** (поправка Бесселя), бо x̄ вже «використало» один ступінь свободи, і ділення на n занижує. Приклад 1, 2, 3, 4, 5: x̄ = 3; ділення на n → 2; на n − 1 → 2,5; s ≈ 1,58.
- Перцентилі (p95 — 95 % значень менші). Для часу відповіді важливіші за середнє.
- Стандартна похибка середнього **SE = s/√n** — наскільки «гуляє» x̄ від вибірки до вибірки.

## 3. Центральна гранична теорема (ЦГТ)
Яким би не був розподіл X (зі скінченними μ та σ), **середнє x̄ великої вибірки приблизно нормальне**: x̄ ~ N(μ, σ²/n). Розкид середнього зменшується як 1/√n: щоб удвічі зменшити похибку, потрібна вчетверо більша вибірка.
Чому: у сумі багатьох випадкових внесків відхилення «гасять» одне одного. Саме ЦГТ пояснює нормальний розподіл у природі й обґрунтовує більшість статистичних тестів.

## 4. Довірчий інтервал
Діапазон, у якому, ймовірно, лежить справжнє μ: **x̄ ± z·SE**. Для 95 %: z = 1,96.
Приклад: x̄ = 50, s = 10, n = 100 → SE = 1 → 95 % ДІ: 50 ± 1,96 = [48,04; 51,96].
**Правильне тлумачення:** якщо повторювати експеримент багато разів, 95 % побудованих інтервалів накриють справжнє μ. НЕ «μ з 95 % ймовірністю в цьому інтервалі» (μ — фіксоване). Ширший інтервал — вища впевненість; більша вибірка — вужчий.
Для малих n замість 1,96 беруть квантиль t-розподілу (ширший).

## 5. Перевірка гіпотез
1. **Нульова гіпотеза H₀** — «нічого особливого» (монета чесна, нова версія не краща).
2. **Альтернатива H₁.**
3. Обчислюємо **статистику** (наскільки дані віддалені від H₀).
4. **p-значення:** імовірність отримати такі чи ще екстремальніші дані, **якщо H₀ правдива**.
5. Якщо p < α (зазвичай 0,05) — відхиляємо H₀ («статистично значущо»).
Приклад: монета, 100 підкидань, 60 орлів. Під H₀: μ = 50, σ = √(100·0,25) = 5. z = (60 − 50)/5 = 2 → двостороннє p ≈ 0,0455 < 0,05 → відхиляємо H₀ (хоча й на межі).
- **Помилка I роду** (хибна тривога, α): відхилили правдиву H₀. **II роду** (пропуск, β): не відхилили хибну. Потужність = 1 − β.
- Тести: z/t (середні), хі-квадрат (частоти, незалежність), ANOVA.

## 6. Чого p-значення НЕ означає
- p — не ймовірність, що H₀ правдива.
- Мале p не означає великий ефект: при величезній вибірці зникомо малий ефект «значущий» — дивіться **розмір ефекту** та довірчий інтервал.
- Багатократні перевірки: ризик хибної значущості росте. 20 тестів при α = 0,05 дають «значущий» результат випадково з імовірністю 1 − 0,95²⁰ ≈ 64 %! Поправка Бонферроні (α/m).
- **p-hacking** — підбір тестів, доки не вийде p < 0,05: недопустимо.

## 7. A/B-тестування
Дві версії (A, B) показуємо різним випадковим групам, порівнюємо метрику (конверсія). Перевірка гіпотези про різницю часток. Правила: заздалегідь заданий розмір вибірки (не «підглядати»), одночасне виконання, одна зміна за раз, перевірка на систематичні зсуви.

## Для програміста
- Бенчмарки: кілька замірів, середнє ± SE, медіана і p95; порівнювати версії з урахуванням шуму (t-тест).
- A/B у продуктах; флейкі-тести як «шум»; моніторинг аномалій (відхилення > 3σ).
- `scipy.stats.ttest_ind`, bootstrap (перевибірка з поверненням) — коли формул немає.

## Типові помилки
1. s² з діленням на n замість n − 1 для вибірки.
2. Довірчий інтервал: «95 % ймовірність, що μ у ньому».
3. p-значення = ймовірність правдивості H₀.
4. Не відрізняти статистичну значущість від практичної.
5. Підглядати в A/B-тест і зупиняти за «хорошим» p.
6. Нерепрезентативна вибірка.
