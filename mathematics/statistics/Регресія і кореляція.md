# Кореляція та лінійна регресія

Числа перевірені обчисленням (numpy).

## 1. Зв'язок двох змінних
Діаграма розсіювання: точки (xᵢ, yᵢ). Питання: чи залежить y від x і як? Бувають зростаючий, спадний, відсутній зв'язок.

## 2. Коваріація та кореляція
- **Коваріація** cov(X, Y) = E[(X − μₓ)(Y − μᵧ)] — чи рухаються разом (+), протилежно (−).
- **Кореляція Пірсона** r = cov/(σₓσᵧ) ∈ [−1; 1] — безрозмірна. r = 1 — точна зростаюча пряма; −1 — спадна; 0 — немає **лінійного** зв'язку.
- Приклад: x = 1,2,3,4,5; y = 2,3,5,4,6 → r = 0,9, r² = 0,81.
- **r² (коефіцієнт детермінації)** — частка варіації y, пояснена x (тут 81 %).
- Кореляція Спірмена — за рангами (стійкіша до викидів і нелінійної монотонності).

## 3. Кореляція ≠ причинність
- Морозиво та потопання корелюють — обидва залежать від літньої спеки (прихована змінна).
- Може бути зворотна причинність, випадковий збіг.
- Причинність встановлюють контрольованим експериментом (A/B), а не одними кореляціями.
- r = 0 не означає незалежності: y = x² на симетричному проміжку має r = 0, але залежність повна (нелінійна).

## 4. Лінійна регресія: пряма найкращого наближення
Модель y ≈ a + b·x. Критерій — **метод найменших квадратів**: мінімізувати суму квадратів помилок (залишків) Σ(yᵢ − a − bxᵢ)².
- Нахил: **b = cov(x, y)/Var(x) = r·(sᵧ/sₓ)**; зсув: **a = ȳ − b·x̄** (пряма проходить через точку середніх).
- Приклад: x̄ = 3, ȳ = 4; b = 0,9, a = 4 − 0,9·3 = 1,3 → **y = 1,3 + 0,9x**. Прогноз x = 6: 1,3 + 5,4 = 6,7.
- Інтерпретація b: на скільки в середньому змінюється y при збільшенні x на 1.
- Чому квадрати? Гладка функція (диференціюється), штрафує великі помилки, дає зручні формули, відповідає нормально розподіленій похибці.
- Виведення: прирівняти часткові похідні суми квадратів до нуля — **нормальні рівняння**.

## 5. Матричний вигляд
y ≈ Xβ. Мінімізуємо |y − Xβ|² → **(XᵀX)β = Xᵀy** → β = (XᵀX)⁻¹Xᵀy. Це проєкція вектора y на простір стовпців X (геометрія лінійної алгебри!). Залишок перпендикулярний до цього простору.
Багато змінних: y ≈ β₀ + β₁x₁ + … + βₖxₖ.

## 6. Залишки та перевірка моделі
- Залишок eᵢ = yᵢ − ŷᵢ. Мають бути «випадковими» без структури: малюйте залишки проти x.
- **R²** = 1 − (сума квадратів залишків)/(повна варіація) — частка поясненого.
- Підозрілі: викиди (один різкий викид «тягне» пряму), гетероскедастичність (розкид росте з x), нелінійність (залишки виписують криву).
- Екстраполяція (прогноз поза діапазоном даних) — ненадійна.

## 7. Перенавчання
Занадто складна модель (многочлен високого степеня) ідеально лягає на навчальні точки, але погано передбачає нові. Тому дані ділять на навчальну/тестову вибірки, використовують крос-валідацію та регуляризацію (Ridge/Lasso — штраф за великі коефіцієнти).

## 8. Нелінійні залежності
Перетворення: y = aeᵇˣ → ln y = ln a + bx (лінійна в логарифмі). Степенева y = axᵇ → логарифмічні шкали. Многочленна регресія: додаємо x², x³ як нові ознаки.

## Для програміста
- `np.polyfit(x, y, 1)`, `sklearn.linear_model.LinearRegression`, `np.linalg.lstsq`.
- Лінійна регресія — найпростіша модель ML; градієнтний спуск мінімізує ту саму суму квадратів.
- Прогноз навантаження, оцінка часу виконання від розміру даних, калібровка датчиків.
- Нормалізуйте ознаки; перевіряйте залишки.

## Типові помилки
1. Кореляція = причинність.
2. Екстраполяція далеко за межі даних.
3. Ігнорувати викиди й діаграму розсіювання (квартет Анскомба: однакові r, зовсім різні дані).
4. r ≈ 0 ⇒ «немає зв'язку» (нелінійний залишився непоміченим).
5. Занадто складна модель (перенавчання).
