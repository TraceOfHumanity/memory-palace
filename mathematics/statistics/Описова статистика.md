# Описова статистика

**Описова статистика** стискає купу чисел у кілька показників, які можна охопити поглядом: «типове» значення (середнє, медіана, мода), «розкид» (розмах, дисперсія, стандартне відхилення) і форму (графіки). Сто оцінок класу важко зрозуміти, але «середнє 8,2, половина отримала не менше 8, розкид ±1,5» — уже картина. Важливо пам'ятати: кожен показник щось **приховує**, і вибір показника може дуже змінити враження.

Пов'язані нотатки: [[Ймовірність]], [[Математичне сподівання і дисперсія]], [[Розподіли ймовірностей]], [[Регресія і кореляція]], [[Відсотки]], [[Модуль числа]], [[Математика — зміст]].

## 1. Центр: середнє, медіана, мода

| Показник | Як знайти | Приклад: 2, 3, 3, 5, 7, 10, 40 |
|---|---|---|
| **Середнє арифметичне** x̄ | сума / кількість | 70/7 = 10 |
| **Медіана** | середнє значення впорядкованого ряду (для парної кількості — півсума двох середніх) | 5 |
| **Мода** | найчастіше значення | 3 |

### 1.1. Кілька способів зрозуміти середнє

1. **Розподіл порівну:** якби всі отримали однаково, скільки отримав би кожен.
2. **Точка рівноваги:** покладіть однакові вантажі на лінійку в точках значень — вона врівноважиться в x̄. Сума відхилень від середнього дорівнює нулю: Σ(xᵢ − x̄) = 0.
3. **Найкраща оцінка в сенсі квадратів:** x̄ — число, для якого сума квадратів відхилень Σ(xᵢ − c)² найменша. (А медіана мінімізує суму модулів Σ|xᵢ − c| — див. [[Модуль числа]].)

### 1.2. Середнє vs медіана — стійкість до викидів

У прикладі одне значення 40 «тягне» середнє до 10, хоча 5 з 7 чисел менші за 10. Медіана (5) не реагує на викид.

**Зарплати:** у компанії 9 людей отримують по 20 000 грн, директор — 500 000. Середнє 68 000, медіана 20 000. Що «типово»? Медіана. Тому для доходів, цін на житло подають медіану.

**Правило:** якщо розподіл скошений (довгий «хвіст» в один бік), середнє зсувається в бік хвоста: середнє > медіани для правого хвоста (доходи), середнє < медіани для лівого.

### 1.3. Інші середні

- **Зважене:** Σwᵢxᵢ / Σwᵢ — оцінка за семестр з різними вагами контрольних і поточних.
- **Геометричне:** ⁿ√(x₁x₂…xₙ) — для темпів росту (див. [[Зміна у відсотках і складні відсотки]]): +10% і −10% дають середнє зростання √(1,1·0,9) − 1 ≈ −0,5%, а не 0%.
- **Гармонічне:** n/(1/x₁ + … + 1/xₙ) — середня швидкість на однакових відрізках шляху (див. [[Текстові задачі]]).
- **Нерівність:** гармонічне ≤ геометричне ≤ арифметичне.

## 2. Розкид

| Показник | Формула | Сенс |
|---|---|---|
| **Розмах** | max − min | найпростіший, чутливий до викидів |
| **Середнє абсолютне відхилення** | Σ\|xᵢ − x̄\|/n | «у середньому на скільки відхиляються» |
| **Дисперсія** | σ² = Σ(xᵢ − x̄)²/n | середній квадрат відхилення |
| **Стандартне відхилення** | σ = √(дисперсія) | у тих самих одиницях, що й дані |
| **Міжквартильний розмах** | Q₃ − Q₁ | розкид середньої половини; стійкий до викидів |

**Чому квадрати, а не модулі.** Відхилення в обидва боки не мають знищувати одне одного; квадрат і модуль обидва це роблять. Квадрати зручніші алгебраїчно: дисперсія суми незалежних величин — сума дисперсій (див. [[Математичне сподівання і дисперсія]]), і зв'язок з Піфагором — σ — це «відстань» від даних до середнього.

**Обчислювальна формула:** σ² = (Σxᵢ²)/n − x̄² («середнє квадратів мінус квадрат середнього»).

**Вибіркова дисперсія:** якщо дані — вибірка з більшої сукупності, ділять на **n − 1**, а не на n (поправка Бесселя), бо середнє вибірки «підлаштоване» під неї і відхилення від нього систематично менші.

### 2.1. Приклад

Дані 2, 4, 4, 4, 5, 5, 7, 9: x̄ = 40/8 = 5. Відхилення: −3, −1, −1, −1, 0, 0, 2, 4. Квадрати: 9, 1, 1, 1, 0, 0, 4, 16 — сума 32. σ² = 4, **σ = 2**.

Перевірка другою формулою: Σx² = 4 + 16·3 + 25·2 + 49 + 81 = 232; 232/8 − 25 = 29 − 25 = 4 ✓.

## 3. Квартилі, перцентилі, «ящик з вусами»

- **Q₁** — медіана нижньої половини, **Q₃** — верхньої. Між ними — середні 50% даних.
- **Перцентиль p** — значення, нижче від якого p% даних. Медіана = 50-й перцентиль. «Дитина на 90-му перцентилі зросту» — вища за 90% однолітків.
- **Ящик з вусами (box plot):** ящик від Q₁ до Q₃ з рискою медіани, вуса до min/max (або до 1,5·IQR), окремі точки — викиди.

```
   min    Q₁   медіана  Q₃         max   викид
    ├──────[──────|──────]──────────┤       •
```

## 4. Графіки

| Графік | Для чого |
|---|---|
| **Стовпчикова діаграма** | порівняти категорії |
| **Гістограма** | форма розподілу числових даних (стовпчики суміжних інтервалів) |
| **Кругова** | частки цілого (лише для кількох категорій) |
| **Лінійний графік** | зміна в часі |
| **Діаграма розсіювання** | зв'язок двох величин (див. [[Регресія і кореляція]]) |
| **Box plot** | порівняти розподіли кількох груп |

**Маніпуляції графіками:** вісь y не з нуля (перебільшує різницю), різні масштаби, 3D-ефекти в кругових діаграмах, вибір зручного часового відрізка. Завжди дивіться на осі.

## 5. Стандартизація: z-оцінка

z = (x − x̄)/σ — **на скільки стандартних відхилень** значення від середнього. Дає змогу порівнювати непорівнянне: 85 балів з математики (x̄ = 70, σ = 10, z = 1,5) — кращий результат, ніж 90 з історії (x̄ = 80, σ = 10, z = 1).

**Правило 68–95–99,7** (для нормального розподілу): у межах ±1σ від середнього ≈ 68% даних, ±2σ — 95%, ±3σ — 99,7% (див. [[Розподіли ймовірностей]]).

## 6. Ключовий приклад кількома способами

**Задача.** Оцінки: 7, 8, 8, 9, 10, 6, 8, 12. Знайдіть середнє і поясніть, що краще описує «типову» оцінку.

1. **Пряма сума:** 68/8 = **8,5**.
2. **Відхилення від «зручного» числа:** візьмемо 8: відхилення −1, 0, 0, 1, 2, −2, 0, 4 — сума 4, середнє відхилення 0,5 ⇒ x̄ = 8,5. (Так рахують у голові.)
3. **Частоти:** 6·1 + 7·1 + 8·3 + 9·1 + 10·1 + 12·1 = 68.

Медіана: впорядковані 6, 7, 8, **8, 8**, 9, 10, 12 ⇒ 8; мода 8. Середнє 8,5 трохи підтягнуте «12». Обидва показники розумні, але медіана й мода краще відповідають на «що отримав типовий учень».

## 7. Типові помилки

| Помилка | Правильно |
|---|---|
| Медіана без упорядкування | спочатку впорядкувати |
| Середнє завжди «типове» | при викидах і скошеності — медіана |
| Середнє відсотків = відсоток від суми | зважити за розміром груп |
| σ і σ² — одне й те саме | σ — корінь з дисперсії |
| Середнє темпів зростання — арифметичне | геометричне |
| Висновок з графіка без погляду на осі | перевіряти масштаб і початок осі |
| Мода завжди одна | може бути кілька або жодної |
