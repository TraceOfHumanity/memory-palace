# Теорія графів

Числові приклади перевірені обчисленням (Python).

## 1. Що таке граф
**Граф** G = (V, E): множина **вершин** V (об'єктів) і **ребер** E (зв'язків між ними). Модель «що з чим пов'язано»: міста й дороги, користувачі й дружба, сторінки й посилання, залежності пакетів, стани програми й переходи.
- **Неорієнтований** (ребро — двосторонній зв'язок), **орієнтований** (орграф: дуга A→B).
- **Зважений** — кожному ребру число (довжина, ціна, час).
- **Степінь** вершини — кількість ребер при ній (орграф: вхідний / вихідний).
- **Шлях**: послідовність вершин, сусідні з'єднані ребрами. **Цикл** — шлях, що повертається в початок. **Зв'язний** граф — між будь-якими двома вершинами є шлях.
- **Простий** граф: без петель і кратних ребер.

## 2. Лема про рукостискання
Сума степенів усіх вершин = 2·|E| (кожне ребро має два кінці). Наслідок: кількість вершин непарного степеня — парна. Приклад: граф A–B, A–C, B–D, C–D, C–E, D–E має 6 ребер; степені 2, 2, 3, 3, 2 → сума 12 = 2·6 ✓.

## 3. Подання в пам'яті
- **Матриця суміжності** n×n: a[i][j] = 1, якщо ребро є. Перевірка ребра O(1), пам'ять O(n²) — для щільних графів.
- **Список суміжності**: для кожної вершини — список сусідів. Пам'ять O(V + E) — для розріджених (більшість реальних).
- **Список ребер**: зручно для сортування ребер (Крускал).

## 4. Обхід у ширину (BFS)
Черга: беремо вершину, додаємо всіх невідвіданих сусідів. Відвідує за зростанням відстані (у ребрах). **Знаходить найкоротший шлях у незваженому графі.** Складність O(V + E).
Приклад: граф вище від A: відстані A=0, B=1, C=1, D=2, E=2.
```
queue=[s]; dist[s]=0
while queue: u=pop_front; for v in adj[u]: if v not in dist: dist[v]=dist[u]+1; push(v)
```

## 5. Обхід у глибину (DFS)
Стек (або рекурсія): ідемо вглиб, поки можна, потім повертаємось. Застосування: пошук циклів, компонент зв'язності, топологічне сортування, лабіринти. O(V + E).

## 6. Найкоротші шляхи у зважених графах
- **Дейкстра** (ваги ≥ 0): жадібно беремо вершину з найменшою відстанню, «послаблюємо» ребра. З пріоритетною чергою O((V + E) log V).
  Приклад: ваги A–B 4, A–C 1, B–C 2, B–D 5, C–D 8, C–E 10, D–E 2. Від A: C = 1, B = 3 (через C), D = 8 (через B), E = 10.
- **Беллман–Форд** — допускає від'ємні ваги, O(VE).
- **Флойд–Воршелл** — усі пари, O(V³).
- **A*** — Дейкстра з евристикою (ігри, навігація).

## 7. Дерева
**Дерево** — зв'язний граф без циклів. Властивості (еквівалентні): n вершин → рівно n − 1 ребер; між двома вершинами єдиний шлях; видалення будь-якого ребра розриває зв'язність. Корінь, листки, глибина, висота. Двійкове дерево, дерево пошуку, трі, файлова система, DOM.
**Кістяк (мінімальне остовне дерево)** — підмножина ребер, що з'єднує всі вершини з мінімальною сумою ваг: алгоритми Крускала, Пріма.

## 8. Ейлерові та гамільтонові шляхи
- **Ейлерів цикл** проходить кожне **ребро** рівно один раз: існує ⇔ граф зв'язний і всі степені парні (Ейлер, мости Кенігсберга, 1736). Ейлерів шлях (не цикл) — рівно дві непарні вершини.
- **Гамільтонів цикл** проходить кожну **вершину** один раз: загального простого критерію немає, задача NP-повна (комівояжер).

## 9. Планарність і розфарбування
- Граф **планарний**, якщо його можна намалювати без перетину ребер. Формула Ейлера: V − E + F = 2.
- **Розфарбування**: вершини фарбують так, щоб сусіди мали різні кольори; хроматичне число. Теорема про 4 фарби для планарних. Застосування: розклад (конфлікти), розподіл регістрів, карти.
- **Дводольний** граф: два класи, ребра лише між ними ⇔ без непарних циклів (2-розфарбовуваний).

## 10. Топологічне сортування
Для орієнтованого ациклічного графа (DAG): порядок вершин, де кожна залежність стоїть раніше залежного. Застосування: збірка пакетів, порядок виконання задач (make, npm).

## Для програміста
- Мережі, соцграфи, веб (PageRank), маршрутизація, карти (Дейкстра/A*), залежності, потоки даних, графи станів, git (DAG комітів).
- Вибір структури: розріджений — список суміжності; щільний — матриця.
- Не забудьте множину відвіданих — інакше нескінченний цикл.

## Типові помилки
1. Забути відмітку «відвідано» (цикл у циклічному графі).
2. Застосувати Дейкстру до від'ємних ваг.
3. Плутати Ейлерів (ребра) і Гамільтонів (вершини) шляхи.
4. BFS на зваженому графі як «найкоротший» — працює лише за кількістю ребер.
5. Матриця суміжності для величезного розрідженого графа (n² пам'яті).
