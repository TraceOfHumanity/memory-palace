# Булева алгебра та логічні схеми

## 1. Булева алгебра
Дві величини: 0 (хибність) та 1 (істина). Операції:
- **NOT** (¬x): інверсія. **AND** (x ∧ y, x·y): 1, лише якщо обидва 1. **OR** (x ∨ y, x + y): 1, якщо хоч один 1.
- **XOR** (x ⊕ y): 1, якщо входи різні; x ⊕ x = 0; x ⊕ 0 = x. **NAND**, **NOR** — «НЕ-І», «НЕ-АБО».
Таблиця істинності AND: 00→0, 01→0, 10→0, 11→1; OR: 00→0, інші 1; XOR: 01→1, 10→1.
Зв'язок з множинами (∩, ∪, доповнення) та логікою (і, або, не): один формалізм.

## 2. Закони
- Комутативність, асоціативність: x ∧ y = y ∧ x.
- **Дистрибутивність:** x ∧ (y ∨ z) = (x ∧ y) ∨ (x ∧ z); x ∨ (y ∧ z) = (x ∨ y) ∧ (x ∨ z) (у булевій алгебрі ОБИДВА закони!).
- **Закони де Моргана:** ¬(x ∧ y) = ¬x ∨ ¬y; ¬(x ∨ y) = ¬x ∧ ¬y. Корисно спрощувати умови `if`.
- Ідемпотентність: x ∧ x = x. Поглинання: x ∨ (x ∧ y) = x. Подвійне заперечення ¬¬x = x. x ∨ ¬x = 1, x ∧ ¬x = 0.
- Доведення — таблицею істинності (перебір усіх 2ⁿ входів).

## 3. Нормальні форми
- **ДНФ** — диз'юнкція кон'юнкцій (OR з AND). **КНФ** — кон'юнкція диз'юнкцій (AND з OR).
- Будь-яка булева функція записується в ДНФ: беремо рядки таблиці з виходом 1, для кожного — кон'юнкція (x або ¬x), їх об'єднуємо OR.
- Функціональна повнота: {AND, OR, NOT} повна; **NAND сама** повна — з неї збирають будь-яку схему.

## 4. Логічні вентилі та схеми
Вентиль — фізична реалізація операції (транзистори). З вентилів складають:
- **Півсуматор:** сума біта = x ⊕ y, перенос = x ∧ y.
- **Повний суматор:** сума = x ⊕ y ⊕ cᵢₙ; перенос = (x ∧ y) ∨ (cᵢₙ ∧ (x ⊕ y)).
- Ланцюг суматорів дає складання n-бітних чисел → АЛП процесора. 1 + 1 у двійковій = 10: сума 0, перенос 1.
- Мультиплексор, декодер, тригер (пам'ять) — основа комп'ютера.

## 5. Спрощення (мінімізація)
Карти Карно: групування сусідніх одиниць зменшує формулу. Приклад: f = x̄y + xy = y (бо x̄ ∨ x = 1). Менше вентилів — швидша й дешевша схема.

## 6. Бітові операції в коді
`&` AND, `|` OR, `^` XOR, `~` NOT, `<<`, `>>` зсуви. Прийоми:
- Перевірка біта: `(n >> k) & 1`. Встановити: `n | (1 << k)`. Скинути: `n & ~(1 << k)`. Інвертувати: `n ^ (1 << k)`.
- Парність: `n & 1`. Степінь двійки: `n & (n − 1) == 0`.
- Обмін без тимчасової змінної: a ^= b; b ^= a; a ^= b.
- Маски прав доступу, прапорці, bitset, хеші, шифри (XOR), CRC.

## 7. SAT і складність
Задача виконуваності (SAT): чи існують значення змінних, що робить формулу істинною? NP-повна (Кук–Левін). Відіграє роль у верифікації та планувальниках.

## Для програміста
- Спрощення умов (де Морган), короткозамкнене обчислення `&&`, `||`; тернарні й нульові значення (truthy/falsy).
- `x ^ x == 0`; пошук єдиного елемента без пари — XOR усіх.
- Маски в мережах (підмережі), права в Unix (rwx = 111).

## Типові помилки
1. Плутати `&` (бітове) та `&&` (логічне).
2. Невірне заперечення складної умови: ¬(A ∧ B) ≠ ¬A ∧ ¬B.
3. Пріоритет операцій (у C `==` вище за `&`): ставте дужки.
4. Припускати, що OR = «або одне, або інше» (виключне — XOR).
