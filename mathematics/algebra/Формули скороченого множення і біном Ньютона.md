# Формули скороченого множення і біном Ньютона

**Формули скороченого множення** — це кілька добутків, які трапляються так часто, що їх варто знати готовими: квадрат суми, різниця квадратів, куб суми тощо. Їх не треба зубрити як заклинання: кожна виходить звичайним множенням дужок за пів хвилини, а для більшості є наочна картинка з площами чи об'ємами. **Біном Ньютона** — загальне правило для (a + b)ⁿ з будь-яким n, і він пояснює, звідки беруться коефіцієнти всіх цих формул.

Пов'язані нотатки: [[Многочлени]], [[Розкладання на множники]], [[Комбінаторика і рекурентності]], [[Степені з цілим показником]], [[Математика — зміст]].

## 1. Сім формул

| Назва | Формула |
|---|---|
| Квадрат суми | (a + b)² = a² + 2ab + b² |
| Квадрат різниці | (a − b)² = a² − 2ab + b² |
| Різниця квадратів | a² − b² = (a − b)(a + b) |
| Куб суми | (a + b)³ = a³ + 3a²b + 3ab² + b³ |
| Куб різниці | (a − b)³ = a³ − 3a²b + 3ab² − b³ |
| Сума кубів | a³ + b³ = (a + b)(a² − ab + b²) |
| Різниця кубів | a³ − b³ = (a − b)(a² + ab + b²) |

Читати їх можна в обидва боки. **Зліва направо** — швидке множення. **Справа наліво** — розкладання на множники (див. [[Розкладання на множники]]).

## 2. Квадрат суми — чотири способи побачити

### 2.1. Множення дужок

(a + b)² = (a + b)(a + b) = a² + ab + ba + b² = a² + 2ab + b². Доданок ab з'являється **двічі**: a з першої дужки на b з другої і b з першої на a з другої.

### 2.2. Площа квадрата

Квадрат зі стороною a + b розрізаємо на чотири частини:

```
      a        b
  ┌────────┬────┐
a │   a²   │ ab │
  │        │    │
  ├────────┼────┤
b │   ab   │ b² │
  └────────┴────┘
```

Великий квадрат a², маленький b² і **два однакові прямокутники** ab. Звідси й «подвоєний добуток». Картинка одразу показує, чому (a + b)² ≠ a² + b²: два прямокутники ab нікуди не зникають.

### 2.3. Числа

(10 + 3)² = 100 + 60 + 9 = 169 = 13². Так рахують у голові: 51² = 2500 + 100 + 1 = 2601; 99² = (100 − 1)² = 10 000 − 200 + 1 = 9801.

### 2.4. «Квадрат першого, подвоєний добуток, квадрат другого»

Словесне правило корисне, коли «перше» і «друге» — складні вирази: (3x + 2y)² = (3x)² + 2·3x·2y + (2y)² = 9x² + 12xy + 4y².

**Квадрат різниці** — той самий квадрат суми з b, заміненим на −b: (a − b)² = a² + 2a(−b) + (−b)² = a² − 2ab + b². На картинці: з квадрата a² вирізаємо дві смужки шириною b, але кут b² вирізали двічі — повертаємо один.

## 3. Різниця квадратів — три способи

### 3.1. Множення

(a − b)(a + b) = a² + ab − ab − b² = a² − b². Перехресні члени знищують один одного.

### 3.2. Площа

З квадрата a×a вирізали кут b×b. Решту (фігура «Г») розрізаємо на два прямокутники і переставляємо в один довгий прямокутник зі сторонами (a + b) і (a − b).

```
 ┌──────┬───┐          ┌──────────┬───┐
 │      │   │          │          │   │
 │  1   │ 2 │   →      │    1     │ 2 │  висота a − b
 ├──────┴───┤          └──────────┴───┘
 │  (b×b    │           ширина a + b
 │  вирізано)
```

### 3.3. Середнє і відхилення

Два числа, симетричні відносно середнього m: (m − d)(m + d) = m² − d². Звідси швидке множення: 47·53 = 50² − 3² = 2491; 98·102 = 10 000 − 4 = 9996.

**Чому добуток чисел із фіксованою сумою найбільший, коли вони рівні:** при сумі 2m добуток (m − d)(m + d) = m² − d², і він максимальний при d = 0. Тому з усіх прямокутників з однаковим периметром найбільшу площу має квадрат.

## 4. Куби

### 4.1. Куб суми

(a + b)³ = (a + b)²(a + b) = (a² + 2ab + b²)(a + b) = a³ + 3a²b + 3ab² + b³.

**Об'ємна картинка.** Куб з ребром a + b розрізається площинами на 8 частин: куб a³, куб b³, **три** бруски a×a×b і **три** бруски a×b×b. Звідси коефіцієнти 1, 3, 3, 1.

**Перевірка числом:** 11³ = 1331 — рядок 1, 3, 3, 1 трикутника Паскаля (див. нижче).

### 4.2. Сума й різниця кубів

a³ − b³ = (a − b)(a² + ab + b²). Перевірка множенням: a³ + a²b + ab² − a²b − ab² − b³ = a³ − b³.

**Звідки береться друга дужка.** Поділимо a³ − b³ на (a − b) за [[Многочлени|теоремою Безу]]: при a = b вираз дорівнює нулю, отже (a − b) — множник. Частка a² + ab + b² — це «геометрична сума»: так само aⁿ − bⁿ = (a − b)(aⁿ⁻¹ + aⁿ⁻²b + … + bⁿ⁻¹).

**Неповний квадрат.** Вираз a² ± ab + b² називають неповним квадратом (у справжньому квадраті стоїть 2ab). Він **ніколи не розкладається далі** на дійсні множники і (якщо a, b не обидва нулі) завжди додатний.

**Знаки:** «СОП» — у сумі кубів знаки дужок: **С**падкує знак, **О**протилежний, **П**люс. a³ + b³ = (a **+** b)(a² **−** ab **+** b²).

## 5. Біном Ньютона

### 5.1. Звідки коефіцієнти

Розкриємо (a + b)ⁿ = (a + b)(a + b)…(a + b) — n дужок. Кожен доданок результату утворюється вибором з **кожної** дужки або a, або b. Доданок aⁿ⁻ᵏbᵏ отримуємо стільки разів, скільки є способів вибрати k дужок, з яких беремо b. Це число комбінацій C(n, k) (див. [[Комбінаторика і рекурентності]]).

$$(a+b)^n=\sum_{k=0}^{n}C_n^k\,a^{n-k}b^k,\qquad C_n^k=\frac{n!}{k!\,(n-k)!}$$

### 5.2. Трикутник Паскаля

Кожне число — сума двох над ним.

```
n=0:            1
n=1:          1   1
n=2:        1   2   1
n=3:      1   3   3   1
n=4:    1   4   6   4   1
n=5:  1   5  10  10   5   1
n=6: 1  6  15  20  15   6  1
```

**Чому сума двох над ним.** (a + b)ⁿ⁺¹ = (a + b)ⁿ·(a + b). Член aⁿ⁺¹⁻ᵏbᵏ отримуємо двома шляхами: з члена aⁿ⁻ᵏbᵏ, помноженого на a, і з члена aⁿ⁻ᵏ⁺¹bᵏ⁻¹, помноженого на b. Тому C(n+1, k) = C(n, k) + C(n, k−1).

(a + b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴.

### 5.3. Властивості, які видно з трикутника

- **Симетрія:** C(n, k) = C(n, n − k) — вибрати k дужок для b те саме, що вибрати n − k дужок для a.
- **Сума рядка = 2ⁿ:** підставимо a = b = 1. Також це кількість усіх підмножин множини з n елементів (див. [[Основи]]).
- **Знакозмінна сума = 0** (n ≥ 1): підставимо a = 1, b = −1.
- **Степені 11:** 11² = 121, 11³ = 1331, 11⁴ = 14641 — рядки трикутника, поки немає переносів.
- **Загальний член** (k + 1)-й: Tₖ₊₁ = C(n, k)aⁿ⁻ᵏbᵏ. Наприклад, коефіцієнт при x³ у (2x + 1)⁵: k = 2, C(5, 2)·2³ = 10·8 = 80.

### 5.4. Наближення

(1 + x)ⁿ ≈ 1 + nx для малих x — перші два члени бінома. 1,02¹⁰ ≈ 1,2 (точно 1,219). Звідси правило «маленькі відсоткові зміни додаються» (див. [[Зміна у відсотках і складні відсотки]]).

## 6. Ключовий приклад кількома способами: 103²

1. **Квадрат суми:** (100 + 3)² = 10 000 + 600 + 9 = 10 609.
2. **Різниця квадратів:** 103² = (103 − 3)(103 + 3) + 3² = 100·106 + 9 = 10 609.
3. **Таблиця площ:** клітинки 10 000, 300, 300, 9.
4. **Стовпчиком** — звичайне множення 103 × 103.

## 7. Застосування

- **Усний рахунок:** 65² = 4225 (для чисел на 5: n5² = n(n + 1)·100 + 25, бо (10n + 5)² = 100n² + 100n + 25).
- **Виділення повного квадрата:** x² + 6x + 1 = (x + 3)² − 8. Це основа формули коренів квадратного рівняння (див. [[Квадратні рівняння]]).
- **Звільнення від ірраціональності:** 1/(√5 − √3) — множимо на (√5 + √3), бо (√5 − √3)(√5 + √3) = 2 (див. [[Перетворення виразів з коренями і рівняння]]).
- **Комплексні числа:** (a + bi)(a − bi) = a² + b² — та сама різниця квадратів (див. [[Комплексні числа]]).
- **Нерівність між середніми:** (a − b)² ≥ 0 ⇒ a² + b² ≥ 2ab ⇒ (a + b)/2 ≥ √(ab) для a, b ≥ 0.

## 8. Типові помилки

| Помилка | Правильно |
|---|---|
| (a + b)² = a² + b² | + 2ab |
| (a − b)² = a² − b² | a² − 2ab + b² |
| (2x + 3)² = 4x² + 6x + 9 | 4x² + **12**x + 9 (2·2x·3) |
| (3x)² = 3x² | 9x² |
| a³ + b³ = (a + b)³ | (a + b)(a² − ab + b²) |
| a³ − b³ = (a − b)(a² − ab + b²) | у різниці кубів у дужці **+ab** |
| a² + b² = (a + b)(a − b) | сума квадратів у дійсних числах не розкладається |
| (a + b)⁴ = a⁴ + 4a³b + 4a²b² + 4ab³ + b⁴ | середній коефіцієнт 6 |
| (−a − b)² = −(a + b)² | (−a − b)² = (a + b)² |
