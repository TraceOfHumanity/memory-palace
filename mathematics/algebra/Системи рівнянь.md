# Системи рівнянь

**Система рівнянь** — кілька рівнянь, які мають виконуватися **одночасно**. Розв'язок системи з двома змінними — **пара чисел** (x; y), яка перетворює на правильну рівність кожне рівняння.

{ x + y = 10, x − y = 4 } має розв'язок (7; 3): 7 + 3 = 10 і 7 − 3 = 4.

Одне рівняння з двома невідомими має безліч розв'язків: x + y = 10 задовольняють (0; 10), (1; 9), (2,5; 7,5)… Друге рівняння — додаткова умова, яка з цієї безлічі вибирає потрібну пару. Загальне правило: **скільки невідомих, стільки потрібно незалежних рівнянь**.

## 1. Кілька способів думати про систему

| Модель | Що означає { x + y = 10, x − y = 4 } |
|---|---|
| **Дві умови загадки** | «Сума двох чисел 10, різниця 4. Що це за числа?» |
| **Перетин графіків** | кожне рівняння — пряма; розв'язок — точка, що лежить на обох |
| **Ваги / баланс** | дві різні зважувки однакових предметів |
| **Перетин множин** | множина розв'язків першого ∩ множина розв'язків другого |
| **Матриця** | (1, 1; 1, −1)·(x; y) = (10; 4) — «яким вектором треба подіяти, щоб отримати (10; 4)» |
| **Середнє й відхилення** | числа симетричні відносно середнього 5 на відстань 2: 5 ± 2 |

Остання модель розв'язує цю систему в голові: сума 10 ⇒ середнє 5; різниця 4 ⇒ кожне на 2 від середнього ⇒ 7 і 3.

## 2. Лінійні системи 2×2: чотири методи

Ключовий приклад:

$$\begin{cases}2x+3y=13\\ 5x-y=7\end{cases}$$

### 2.1. Підстановка

Виразити одну змінну з одного рівняння і підставити в інше.

З другого: y = 5x − 7. У перше: 2x + 3(5x − 7) = 13 ⇒ 17x = 34 ⇒ **x = 2**, y = 10 − 7 = **3**.

**Коли зручно:** якщо якась змінна має коефіцієнт ±1.

### 2.2. Додавання (алгебраїчне додавання)

Помножити рівняння на такі числа, щоб коефіцієнти при одній змінній стали протилежними, і скласти.

Друге помножимо на 3: 15x − 3y = 21. Додамо до першого: 17x = 34 ⇒ x = 2.

**Чому можна додавати рівняння:** якщо A = B і C = D, то A + C = B + D — до рівних додаємо рівні. Це «терези»: на обидві шальки поклали однакову вагу.

**Коли зручно:** коли коефіцієнти «майже протилежні» або в обох рівняннях великі.

### 2.3. Графічний

Побудувати дві прямі: y = (13 − 2x)/3 і y = 5x − 7. Точка перетину (2; 3).

```
 y
 │        /  y = 5x − 7
 │       /
 3 ─ ─ ─*
 │    / │ \___
 │   /  │     \___ 2x + 3y = 13
 ┼──/───┼──────────► x
   /    2
```

**Коли зручно:** щоб побачити, чи є розв'язок і скільки їх; точність — низька.

### 2.4. Формули Крамера (визначники)

Для { a₁x + b₁y = c₁, a₂x + b₂y = c₂ }:

$$\Delta=a_1b_2-a_2b_1,\quad x=\frac{c_1b_2-c_2b_1}{\Delta},\quad y=\frac{a_1c_2-a_2c_1}{\Delta}$$

Δ = 2·(−1) − 5·3 = −17; x = (13·(−1) − 7·3)/(−17) = −34/(−17) = 2; y = (2·7 − 5·13)/(−17) = −51/(−17) = 3.

**Звідки:** це результат методу додавання в загальному вигляді. Δ — площа паралелограма, натягнутого на стовпці коефіцієнтів; якщо Δ = 0, прямі паралельні (див. [[Вектори і матриці]]).

## 3. Скільки розв'язків — три випадки

| Випадок | Прямі | Ознака | Приклад |
|---|---|---|---|
| один розв'язок | перетинаються | a₁/a₂ ≠ b₁/b₂ (Δ ≠ 0) | { x + y = 3, x − y = 1 } |
| немає розв'язків | паралельні | a₁/a₂ = b₁/b₂ ≠ c₁/c₂ | { x + y = 3, 2x + 2y = 7 } — 3 ≠ 3,5 |
| безліч | збігаються | a₁/a₂ = b₁/b₂ = c₁/c₂ | { x + y = 3, 2x + 2y = 6 } |

**Що відбувається при розв'язуванні:** у другому випадку виходить 0 = 1 (суперечність), у третьому 0 = 0 (друге рівняння — копія першого, нової інформації немає).

## 4. Системи з трьома змінними

{ x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2 }.

**Метод Гауса** — послідовно виключати змінні:
1. Від другого відняти подвоєне перше: −3y − z = −9.
2. Від третього відняти перше: y − 2z = −4.
3. З нових двох: y = 2z − 4 ⇒ −3(2z − 4) − z = −9 ⇒ −7z = −21 ⇒ z = 3, y = 2.
4. x = 6 − 2 − 3 = 1.

Розв'язок (1; 2; 3). Геометрично кожне рівняння — площина в просторі, розв'язок — точка перетину трьох площин. Детально про метод для будь-якої кількості змінних — [[Метод Гауса і ранг]].

## 5. Нелінійні системи

### 5.1. Підстановка

{ x + y = 5, x² + y² = 13 }: y = 5 − x ⇒ x² + (5 − x)² = 13 ⇒ 2x² − 10x + 12 = 0 ⇒ x = 2 або 3. Розв'язки (2; 3), (3; 2).

**Геометрично:** пряма перетинає коло радіуса √13 у двох точках.

### 5.2. Симетричні системи — заміна u = x + y, v = xy

У тій самій системі: x² + y² = u² − 2v ⇒ 25 − 2v = 13 ⇒ v = 6. Числа з сумою 5 і добутком 6 — корені t² − 5t + 6 = 0 (теорема Вієта, див. [[Квадратні рівняння]]): 2 і 3.

### 5.3. Додавання й множення рівнянь

{ x² + y² = 25, x² − y² = 7 }: додаємо: 2x² = 32 ⇒ x = ±4; y² = 9 ⇒ y = ±3. Чотири розв'язки: (±4; ±3) — точки перетину кола з гіперболою.

{ xy = 6, x/y = 3/2 }: перемножимо: x² = 9 ⇒ x = ±3, y = 6/x = ±2: (3; 2), (−3; −2).

### 5.4. Однорідні рівняння

{ x² − 3xy + 2y² = 0, x + y = 6 }: перше ділимо на y² (y ≠ 0): t² − 3t + 2 = 0, t = x/y = 1 або 2 ⇒ x = y або x = 2y. З другим: (3; 3) і (4; 2).

## 6. Системи нерівностей з двома змінними

Розв'язок нерівності y ≥ 2x − 1 — **півплощина** над прямою. Система нерівностей — перетин півплощин, зазвичай багатокутник. Так ставлять задачі **лінійного програмування**: знайти найбільший прибуток при обмеженнях на ресурси. Оптимум завжди в одній з вершин багатокутника.

## 7. Складання систем — задачі

- **Ціни:** 2 кави і 3 круасани — 190 грн; 3 кави і 1 круасан — 145 грн. { 2k + 3c = 190, 3k + c = 145 } ⇒ k = 35, c = 40.
- **Суміші:** скільки літрів 20%-ого і 50%-ого розчину змішати, щоб отримати 12 л 30%-ого? { a + b = 12, 0,2a + 0,5b = 3,6 } ⇒ a = 8, b = 4.
- **Рух по річці:** за течією 36 км за 2 год, проти — за 3 год. { v + u = 18, v − u = 12 } ⇒ v = 15, u = 3.
- **Двозначне число:** сума цифр 11, а якщо переставити цифри, число збільшиться на 27. { a + b = 11, (10b + a) − (10a + b) = 27 } ⇒ b − a = 3 ⇒ 47.

Більше — у [[Текстові задачі]].

## 8. Типові помилки

| Помилка | Правильно |
|---|---|
| Знайшли x і зупинилися | відповідь — пара (x; y) |
| Підставили в те саме рівняння, з якого виражали | підставляти в **інше** |
| Помножили на 3 лише ліву частину | множити обидві частини |
| Віднімали рівняння і забули змінити знаки | (A − C) = (B − D) почленно |
| 0 = 0 ⇒ «розв'язків немає» | безліч розв'язків |
| Нелінійна система: загубили розв'язки з від'ємними x | x² = 16 ⇒ x = ±4 |
| Поділили на y, не перевіривши y = 0 | розглянути y = 0 окремо |
| Записали (3; 2) замість (2; 3) | порядок (x; y) важливий |
