# Раціональні та ірраціональні рівняння

**Раціональне (дробово-раціональне) рівняння** містить змінну в знаменнику: 3/(x − 1) = x + 1, 1/x + 1/(x + 2) = 3/4. **Ірраціональне рівняння** містить змінну під знаком кореня: √(x + 3) = x − 3.

Обидва типи розв'язують однаково: **позбуваються «незручної» операції** (знаменника — множенням, кореня — піднесенням до степеня) і отримують многочленне рівняння. Але ці дії **не завжди рівносильні**: вони можуть додати «зайві» корені. Тому головне в темі — розуміти, звідки беруться сторонні корені і як їх відсіяти.

Пов'язані нотатки: [[Алгебраїчні дроби]], [[Квадратні рівняння]], [[Перетворення виразів з коренями і рівняння]], [[Квадратний корінь]], [[Модуль числа]], [[Математика — зміст]].

## 1. Звідки беруться сторонні корені

### 1.1. Множення на вираз, що може бути нулем

x/(x − 2) = 2/(x − 2). Множимо на (x − 2): x = 2. Але при x = 2 знаменник нульовий — вихідне рівняння не має змісту. **Коренів немає.**

Множення на (x − 2) «дозволило» значення, при якому ми фактично множили на нуль. А множення на нуль робить правильною будь-яку рівність: 5·0 = 7·0.

### 1.2. Піднесення до квадрата

√x = −2. Підносимо до квадрата: x = 4. Перевірка: √4 = 2 ≠ −2. **Коренів немає.**

**Чому:** з a = b випливає a² = b², але **не навпаки**: (−2)² = 2², хоча −2 ≠ 2. Рівняння a² = b² рівносильне сукупності a = b **або a = −b**. Піднісши до квадрата √x = −2, ми розв'язали заразом і рівняння √x = 2, і саме його корінь отримали.

### 1.3. Три способи захиститися

| Спосіб | Що робимо | Коли зручно |
|---|---|---|
| **Перевірка підстановкою** | кожен знайдений корінь підставляємо у вихідне рівняння | коренів мало, вони «гарні» |
| **ОДЗ** | заздалегідь записуємо, де рівняння має зміст (знаменники ≠ 0, підкореневі ≥ 0) | раціональні рівняння |
| **Рівносильні переходи з умовами** | √f = g ⇔ { f = g², g ≥ 0 } | ірраціональні рівняння з «поганими» коренями |

## 2. Раціональні рівняння

### 2.1. Алгоритм

1. Знайти ОДЗ: усі знаменники ≠ 0.
2. Перенести все в один бік, звести до спільного знаменника: P(x)/Q(x) = 0.
3. **Дріб дорівнює нулю ⇔ чисельник = 0, знаменник ≠ 0.**
4. Розв'язати P(x) = 0, відкинути корені поза ОДЗ.

**Чому в п. 3 саме так:** a/b = 0 означає a = 0·b = 0; а b ≠ 0, бо інакше дріб не існує.

### 2.2. Ключовий приклад трьома способами

$$\frac{x}{x-3}-\frac{6}{x+3}=\frac{18}{x^2-9}$$

ОДЗ: x ≠ ±3.

**Спосіб 1. Помножити на спільний знаменник (x − 3)(x + 3):**
x(x + 3) − 6(x − 3) = 18 ⇒ x² + 3x − 6x + 18 = 18 ⇒ x² − 3x = 0 ⇒ x = 0 або x = 3.
x = 3 поза ОДЗ. **Відповідь: x = 0.**

**Спосіб 2. Все в один бік, один дріб:**
(x(x + 3) − 6(x − 3) − 18)/(x² − 9) = 0 ⇒ (x² − 3x)/(x² − 9) = 0 ⇒ x(x − 3)/((x − 3)(x + 3)) = 0.
Чисельник нуль при x = 0 і x = 3, але при x = 3 нуль і знаменник. Відповідь x = 0.

**Спосіб 3. Графічно.** Ліва частина мінус права — функція x/(x + 3) з «дірою» в x = 3 (після скорочення). Вона дорівнює нулю лише в x = 0.

### 2.3. Пропорція

a/b = c/d ⇔ ad = bc (при b, d ≠ 0). (x + 1)/(x − 2) = 3/2 ⇒ 2x + 2 = 3x − 6 ⇒ x = 8.

### 2.4. Заміна змінної

(x² + 1)/x + x/(x² + 1) = 5/2. Нехай t = (x² + 1)/x. Тоді t + 1/t = 5/2 ⇒ 2t² − 5t + 2 = 0 ⇒ t = 2 або 1/2.
- (x² + 1)/x = 2 ⇒ x² − 2x + 1 = 0 ⇒ x = 1.
- (x² + 1)/x = 1/2 ⇒ 2x² − x + 2 = 0, D < 0.

Відповідь: x = 1.

**Симетрична заміна:** x + 1/x = t ⇒ x² + 1/x² = t² − 2.

## 3. Ірраціональні рівняння

### 3.1. Основна схема: √f(x) = g(x)

$$\sqrt{f(x)}=g(x)\iff\begin{cases}f(x)=g(x)^2\\ g(x)\ge0\end{cases}$$

Умова f(x) ≥ 0 автоматично виконана, бо f = g² ≥ 0. Умова g ≥ 0 — обов'язкова, бо арифметичний корінь невід'ємний.

### 3.2. Ключовий приклад трьома способами: √(x + 3) = x − 3

**Спосіб 1. Піднесення до квадрата + перевірка:**
x + 3 = x² − 6x + 9 ⇒ x² − 7x + 6 = 0 ⇒ x = 1 або x = 6.
Перевірка: x = 1: √4 = 2, а 1 − 3 = −2 — не підходить. x = 6: √9 = 3 = 6 − 3 ✓. **Відповідь: x = 6.**

**Спосіб 2. Рівносильний перехід:** умова x − 3 ≥ 0 ⇒ x ≥ 3. З коренів 1 і 6 лишається 6. Перевірка не потрібна.

**Спосіб 3. Графіки.** y = √(x + 3) — півпарабола, що виходить з (−3; 0) вгору. y = x − 3 — пряма. Вони перетинаються один раз, при x = 6. «Сторонній» корінь x = 1 — це точка перетину прямої з **нижньою** половиною параболи y = −√(x + 3), яку додало піднесення до квадрата.

```
 y
 3 ─ ─ ─ ─ ─ ─ ─ ─ *   y = √(x + 3)
 │        ___----/
 │  __---       /
 *--───────────/──────► x
−3     │      / 6
 −2 ─ ─*─ ─ ─/    ← x = 1 на нижній гілці −√(x + 3)
       1    /  y = x − 3
```

### 3.3. Дві корені: √f = √g

⇔ { f = g, f ≥ 0 } (або g ≥ 0 — досить однієї умови, бо f = g).

√(2x − 1) = √(x + 4) ⇒ 2x − 1 = x + 4 ⇒ x = 5; 2·5 − 1 = 9 ≥ 0 ✓.

### 3.4. Кілька коренів — ізолювати й підносити двічі

√(x + 5) − √x = 1 ⇒ √(x + 5) = 1 + √x ⇒ x + 5 = 1 + 2√x + x ⇒ √x = 2 ⇒ x = 4. Перевірка: 3 − 2 = 1 ✓.

**Порада:** перед піднесенням до квадрата лишіть корінь **сам по собі** з одного боку — тоді після піднесення він зникне.

### 3.5. Заміна

x − 5√x + 6 = 0: t = √x ≥ 0 ⇒ t² − 5t + 6 = 0 ⇒ t = 2, 3 ⇒ x = 4, 9.

√(x² + 3x + 7) + x² + 3x = 13: t = √(x² + 3x + 7) ≥ 0 ⇒ t + t² − 7 = 13 ⇒ t² + t − 20 = 0 ⇒ t = 4 (t = −5 відкидаємо) ⇒ x² + 3x + 7 = 16 ⇒ x = (−3 ± 3√5)/2.

### 3.6. Корінь кубічний

∛(x − 2) = 3 ⇒ x − 2 = 27 ⇒ x = 29. **Сторонніх коренів не виникає:** куб — взаємно однозначна функція, з a³ = b³ випливає a = b (див. [[Корінь n-го степеня і дробові показники]]).

### 3.7. Оцінка замість перетворень

√(x − 4) + √(4 − x) = 0: обидва корені існують лише при x = 4. Перевірка: 0 + 0 = 0 ✓.

√(x + 1) + √(x + 6) = −1: ліва частина ≥ 0 — коренів немає. Іноді досить подивитися на область значень.

## 4. Ірраціональні нерівності — коротко

√f < g ⇔ { f ≥ 0, g > 0, f < g² }.

√f > g ⇔ { g < 0, f ≥ 0 } або { g ≥ 0, f > g² }.

**Приклад:** √(x + 2) > x. Випадок x < 0: x + 2 ≥ 0 ⇒ [−2; 0). Випадок x ≥ 0: x + 2 > x² ⇒ −1 < x < 2 ⇒ [0; 2). Разом: [−2; 2).

## 5. Типові помилки

| Помилка | Правильно |
|---|---|
| Не виписали ОДЗ і залишили корінь, при якому знаменник 0 | перевіряти ОДЗ |
| (x² − 4)/(x − 2) = 0 ⇒ x = ±2 | лише x = −2 |
| Піднесли до квадрата без перевірки | перевірити або умова g ≥ 0 |
| (√x + 1)² = x + 1 | x + 2√x + 1 |
| √(x² ) = x | \|x\| |
| √(a + b) = √a + √b | неправильно: √(9 + 16) = 5 ≠ 7 |
| Підносили до квадрата суму коренів, не ізолювавши | спочатку перенести один корінь |
| Перевірили у вже перетвореному рівнянні | перевіряти у **вихідному** |
