# Квадратні рівняння

**Квадратне рівняння** — рівняння вигляду **ax² + bx + c = 0**, де a ≠ 0. Числа a, b, c — коефіцієнти: a — старший, b — другий (середній), c — вільний член. Якщо a = 0, квадрата немає, і рівняння лінійне.

Квадратні рівняння люди розв'язували ще у Вавилоні 4000 років тому — задачі «знайди сторони поля, якщо відомі площа і різниця сторін». Тоді не було ні формул, ні навіть від'ємних чисел, а розв'язували їх геометрично — **добудовуючи квадрат**. Сучасна формула коренів — це той самий прийом, записаний буквами.

Пов'язані нотатки: [[Розкладання на множники]], [[Формули скороченого множення і біном Ньютона]], [[Квадратний корінь]], [[Комплексні числа]], [[Квадратні нерівності і метод інтервалів]], [[Раціональні та ірраціональні рівняння]], [[Найважливіші графіки]], [[Математика — зміст]].

## 1. Кілька способів зрозуміти квадратне рівняння

| Модель | Що означає x² + 6x = 16 |
|---|---|
| **Площі** | квадрат зі стороною x і два прямокутники 3×x разом мають площу 16 |
| **Графік** | де парабола y = x² + 6x − 16 перетинає вісь Ox |
| **Два числа** | знайти числа з сумою −6 і добутком −16 (теорема Вієта) |
| **Симетрія** | корені симетричні відносно вершини параболи x = −3: це −3 ± d |
| **Добуток дорівнює нулю** | (x − 2)(x + 8) = 0 — один з множників нуль |

Кожна модель дає свій метод розв'язання. Нижче — всі вони на одному прикладі.

## 2. Ключовий приклад шістьма способами: x² + 6x − 16 = 0

### 2.1. Добудова квадрата геометрично (як у аль-Хорезмі)

Ліва частина x² + 6x — це квадрат x×x і прямокутник 6×x. Розріжемо прямокутник на два 3×x і прикладемо до двох сторін квадрата. Вийде «майже квадрат» зі стороною x + 3, в якого бракує кута 3×3 = 9.

```
      x       3
  ┌───────┬─────┐
x │  x²   │ 3x  │
  ├───────┼─────┤
3 │  3x   │  9  │ ← бракує
  └───────┴─────┘
```

Додаємо 9 до обох частин: x² + 6x + 9 = 16 + 9 = 25. Ліворуч — повний квадрат (x + 3)². Отже сторона x + 3 = 5, x = 2. Геометрично від'ємна сторона не має сенсу, але алгебраїчно x + 3 = −5 теж підходить ⇒ x = −8.

### 2.2. Виділення повного квадрата алгебраїчно

x² + 6x − 16 = (x + 3)² − 9 − 16 = (x + 3)² − 25 = 0 ⇒ (x + 3)² = 25 ⇒ x + 3 = ±5 ⇒ **x = 2 або x = −8**.

### 2.3. Формула коренів

a = 1, b = 6, c = −16. D = b² − 4ac = 36 + 64 = 100. x = (−6 ± 10)/2 ⇒ 2 і −8.

### 2.4. Теорема Вієта (підбір)

Шукаємо два числа з сумою −b/a = −6 і добутком c/a = −16: це 2 і −8.

### 2.5. Розкладання на множники

x² + 6x − 16 = (x − 2)(x + 8) = 0 ⇒ x = 2 або x = −8.

### 2.6. Графік

Парабола y = x² + 6x − 16 має вершину в x = −3 (y = −25) і перетинає вісь Ox на відстані 5 від вершини в обидва боки: −3 ± 5.

```
  y
    \                 /
     \               /
 ─────*─────────────*────► x
     −8 \         / 2
          \     /
           \___/
          (−3; −25)
```

**Коли який метод:** Вієта — коли a = 1 і корені цілі (за 10 секунд). Формула — завжди. Повний квадрат — коли b парне або треба знайти вершину. Графік — коли треба зрозуміти, скільки коренів і як вони розташовані.

## 3. Виведення формули коренів

Повторимо 2.2 для загального рівняння ax² + bx + c = 0.

1. Поділимо на a: x² + (b/a)x + c/a = 0.
2. Половина коефіцієнта при x: b/(2a). Додамо й віднімемо її квадрат:
   (x + b/(2a))² − b²/(4a²) + c/a = 0.
3. Перенесемо: (x + b/(2a))² = (b² − 4ac)/(4a²).
4. Позначимо **D = b² − 4ac** (дискримінант, від лат. *discriminare* — «розрізняти»).
5. Якщо D ≥ 0: x + b/(2a) = ±√D/(2a).

$$x_{1,2}=\frac{-b\pm\sqrt{D}}{2a},\qquad D=b^2-4ac$$

**Сенс частин формули:**
- −b/(2a) — **вісь симетрії** параболи, «центр» між коренями.
- ±√D/(2a) — **відстань** від центру до кожного кореня.
- Тобто корені — це «центр ± відхилення». Саме це ми бачили на графіку: −3 ± 5.

## 4. Дискримінант — скільки коренів

| D | Коренів | Графік | Чому |
|---|---|---|---|
| D > 0 | 2 різні | парабола перетинає вісь двічі | √D — додатне число, ± дає два різні значення |
| D = 0 | 1 (два однакові) | парабола торкається осі вершиною | ±0 — те саме |
| D < 0 | дійсних немає | парабола не дістає осі | квадрат (x + b/(2a))² не може бути від'ємним |

При D < 0 корені існують серед **комплексних чисел**: x² + 4 = 0 ⇒ x = ±2i (див. [[Комплексні числа]]).

### 4.1. Скорочена формула (для парного b)

Якщо b = 2k: D/4 = k² − ac, x = (−k ± √(D/4))/a. Для x² − 10x + 21: k = −5, D/4 = 25 − 21 = 4, x = 5 ± 2 ⇒ 3 і 7. Менше арифметики.

## 5. Неповні квадратні рівняння

Коли b = 0 або c = 0, формула не потрібна.

| Вигляд | Метод | Приклад |
|---|---|---|
| ax² = 0 | x = 0 | 5x² = 0 ⇒ x = 0 |
| ax² + c = 0 | x² = −c/a; корені ±√(−c/a), якщо −c/a ≥ 0 | 2x² − 18 = 0 ⇒ x = ±3; x² + 9 = 0 — коренів немає |
| ax² + bx = 0 | винести x: x(ax + b) = 0 ⇒ x = 0 або x = −b/a | 3x² − 12x = 0 ⇒ x = 0 або 4 |

**Помилка:** x² = 9 ⇒ x = 3. Загублено x = −3. Правильно: x = ±3, бо (−3)² = 9.

## 6. Теорема Вієта

Для ax² + bx + c = 0 з коренями x₁, x₂:

$$x_1+x_2=-\frac{b}{a},\qquad x_1x_2=\frac{c}{a}$$

**Чому (спосіб 1):** a(x − x₁)(x − x₂) = a(x² − (x₁ + x₂)x + x₁x₂) = ax² − a(x₁ + x₂)x + ax₁x₂. Прирівнюємо коефіцієнти з ax² + bx + c.

**Чому (спосіб 2):** додаємо й множимо формули коренів: (−b + √D)/(2a) + (−b − √D)/(2a) = −b/a; добуток — різниця квадратів (b² − D)/(4a²) = 4ac/(4a²) = c/a.

**Застосування:**
- **Підбір коренів:** x² − 7x + 12: сума 7, добуток 12 ⇒ 3 і 4.
- **Перевірка:** знайшли корені — перевірте суму й добуток.
- **Знаки коренів без розв'язання:** якщо c/a < 0, корені різних знаків. Якщо c/a > 0 і −b/a > 0 — обидва додатні.
- **Симетричні вирази:** x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂; 1/x₁ + 1/x₂ = (x₁ + x₂)/(x₁x₂).
- **Скласти рівняння за коренями:** корені 3 і −5 ⇒ x² + 2x − 15 = 0.

**Обернена теорема:** якщо m + n = −p і mn = q, то m, n — корені x² + px + q = 0.

### 6.1. Метод «перекидання»

Для 6x² − 7x − 3 = 0 «перекинемо» a на c: y² − 7y − 18 = 0 ⇒ y = 9, −2 (Вієта). Корені вихідного — y/a: 9/6 = 3/2 і −2/6 = −1/3. Працює, бо підстановка y = ax перетворює рівняння на y² + by + ac = 0.

## 7. Рівняння, що зводяться до квадратних

- **Біквадратні:** x⁴ − 13x² + 36 = 0. Заміна t = x² ≥ 0: t² − 13t + 36 = 0 ⇒ t = 4, 9 ⇒ x = ±2, ±3.
- **Заміна виразу:** (x² + x)² − 8(x² + x) + 12 = 0. t = x² + x: t = 2 або 6 ⇒ x² + x − 2 = 0 або x² + x − 6 = 0 ⇒ x ∈ {−3, −2, 1, 2}.
- **З дробами** — див. [[Раціональні та ірраціональні рівняння]].
- **З модулем:** x² − 5|x| + 6 = 0. t = |x|: t = 2, 3 ⇒ x = ±2, ±3.

## 8. Квадратні рівняння в житті

- **Падіння тіла:** h = h₀ − 4,9t². З 20 м: 4,9t² = 20 ⇒ t ≈ 2,02 с.
- **Кинутий вгору м'яч:** h = 1,5 + 12t − 4,9t². Коли h = 0? 4,9t² − 12t − 1,5 = 0 ⇒ t ≈ 2,57 с.
- **Площі:** ділянка 120 м², довжина на 2 м більша за ширину: x(x + 2) = 120 ⇒ x = 10.
- **Золотий переріз:** x² = x + 1 ⇒ x = (1 + √5)/2 ≈ 1,618.
- **Прибуток:** P(q) = −2q² + 80q − 600 — коли P = 0 (точки беззбитковості) і де максимум (вершина q = 20).

## 9. Типові помилки

| Помилка | Правильно |
|---|---|
| x² = 16 ⇒ x = 4 | x = ±4 |
| D = b² − 4ac при b = −6: D = −36 − … | (−6)² = 36 |
| x = −b ± √D/2a | весь чисельник ділиться на 2a: (−b ± √D)/(2a) |
| 3x² = 12x ⇒ ділимо на x ⇒ x = 4 | загубили x = 0 |
| Вієта: x₁ + x₂ = b | −b/a |
| Вієта при D < 0 «дає корені» | спочатку перевірити, що корені існують |
| Не звели до вигляду … = 0 перед формулою | спочатку все в один бік |
| Біквадратне: t = −4 ⇒ x = ±2 | t = x² ≥ 0, від'ємне t відкинути |
