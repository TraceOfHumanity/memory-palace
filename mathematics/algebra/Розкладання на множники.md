# Розкладання на множники

**Розкласти многочлен на множники** — записати його як добуток простіших многочленів: x² − 5x + 6 = (x − 2)(x − 3). Це дія, обернена до множення: розкрити дужки легко, а знайти, з яких дужок вийшов вираз, — мистецтво. Так само з числами: помножити 7·13 легко, а здогадатися, що 91 = 7·13, складніше (див. [[Подільність, прості числа, НСД і НСК]]).

**Навіщо:** добуток дорівнює нулю, лише коли один з множників дорівнює нулю. Тому розклад одразу дає корені рівняння, знаки виразу, скорочення дробів і спрощення обчислень.

Пов'язані нотатки: [[Многочлени]], [[Формули скороченого множення і біном Ньютона]], [[Алгебраїчні дроби]], [[Квадратні рівняння]], [[Математика — зміст]].

## 1. Кілька способів зрозуміти розкладання

| Модель | Що означає розкласти x² + 5x + 6 |
|---|---|
| **Як з числами** | знайти «прості множники» многочлена, як 60 = 2²·3·5 |
| **Прямокутник з плиток** | скласти з 1 квадрата x², 5 смужок x і 6 квадратиків прямокутник; його сторони (x + 2) і (x + 3) — множники |
| **Корені** | знайти числа, при яких вираз дорівнює нулю (−2 і −3); кожен корінь a дає множник (x − a) |
| **Обернене множення** | підібрати дужки, які при розкритті дають цей вираз |
| **Графік** | точки перетину параболи з віссю Ox — корені, а отже множники |

**Прямокутник з плиток** для x² + 5x + 6:

```
        x     1  1  1
     ┌──────┬──┬──┬──┐
  x  │  x²  │x │x │x │
     ├──────┼──┼──┼──┤
  1  │  x   │1 │1 │1 │
     ├──────┼──┼──┼──┤
  1  │  x   │1 │1 │1 │
     └──────┴──┴──┴──┘
   сторони: (x + 3) і (x + 2)
```

Розклад існує, коли плитки вдається скласти в прямокутник без дірок. Для x² + x + 1 не вийде ніяк — і справді, цей тричлен на дійсні множники не розкладається.

## 2. Методи (у порядку, в якому їх варто пробувати)

### 2.1. Винесення спільного множника

Розподільний закон справа наліво: ab + ac = a(b + c). Виносимо НСД коефіцієнтів і найменші степені спільних змінних.

12x³y − 18x²y² = 6x²y(2x − 3y).

**Перевірка:** розкрити дужки. Спільним множником може бути і многочлен: x(a − b) + 3(a − b) = (a − b)(x + 3). Увага до знаків: 5(x − 2) − y(2 − x) = 5(x − 2) + y(x − 2) = (x − 2)(5 + y).

### 2.2. Формули скороченого множення

| Бачимо | Розкладаємо |
|---|---|
| a² − b² | (a − b)(a + b) |
| a² ± 2ab + b² | (a ± b)² |
| a³ − b³ | (a − b)(a² + ab + b²) |
| a³ + b³ | (a + b)(a² − ab + b²) |

**Як впізнати квадрат тричлена:** крайні члени — квадрати (4x² = (2x)², 9 = 3²), середній — подвоєний добуток їхніх «коренів»: 2·2x·3 = 12x. Тоді 4x² − 12x + 9 = (2x − 3)².

### 2.3. Групування

Розбити члени на групи, в кожній винести спільне, і сподіватися, що в дужках вийде однакове.

x³ − 2x² + 3x − 6 = x²(x − 2) + 3(x − 2) = (x − 2)(x² + 3).

Іноді групують інакше: a² − b² + a − b = (a − b)(a + b) + (a − b) = (a − b)(a + b + 1).

### 2.4. Квадратний тричлен ax² + bx + c

**Спосіб 1 — підбір (теорема Вієта).** Для x² + px + q шукаємо два числа з **добутком q** і **сумою p**. Для x² − 5x + 6: добуток 6, сума −5 ⇒ −2 і −3 ⇒ (x − 2)(x − 3).

**Чому:** (x + m)(x + n) = x² + (m + n)x + mn.

**Спосіб 2 — через корені.** Якщо x₁, x₂ — корені ax² + bx + c = 0 (див. [[Квадратні рівняння]]), то **ax² + bx + c = a(x − x₁)(x − x₂)**. Для 2x² − 7x + 3: D = 49 − 24 = 25, x = (7 ± 5)/4 ⇒ 3 і 1/2 ⇒ 2(x − 3)(x − 1/2) = (x − 3)(2x − 1).

**Спосіб 3 — розщеплення середнього члена (метод «ac»).** Для 2x² − 7x + 3: шукаємо два числа з добутком a·c = 6 і сумою −7 ⇒ −1 і −6. Розщеплюємо: 2x² − x − 6x + 3 = x(2x − 1) − 3(2x − 1) = (2x − 1)(x − 3).

**Спосіб 4 — виділення повного квадрата і різниця квадратів.** x² + 6x + 5 = (x + 3)² − 4 = (x + 3 − 2)(x + 3 + 2) = (x + 1)(x + 5).

**Коли не розкладається:** якщо дискримінант D = b² − 4ac < 0, дійсних коренів немає, і тричлен лишається «простим» (як просте число).

### 2.5. Корені й теорема Безу для вищих степенів

Якщо P(a) = 0, то P(x) = (x − a)·Q(x). Підбираємо цілий корінь серед дільників вільного члена, ділимо схемою Горнера (див. [[Многочлени]]).

x³ − 7x + 6: P(1) = 0 ⇒ (x − 1)(x² + x − 6) = (x − 1)(x − 2)(x + 3).

### 2.6. Штучні прийоми

- **Додати й відняти:** x⁴ + 4 = x⁴ + 4x² + 4 − 4x² = (x² + 2)² − (2x)² = (x² − 2x + 2)(x² + 2x + 2) (тотожність Софі Жермен).
- **Заміна:** x⁴ − 5x² + 4: t = x² ⇒ t² − 5t + 4 = (t − 1)(t − 4) ⇒ (x − 1)(x + 1)(x − 2)(x + 2).
- **Розщеплення члена:** x³ + 3x² − 4 = x³ − x² + 4x² − 4 = x²(x − 1) + 4(x − 1)(x + 1) = (x − 1)(x² + 4x + 4) = (x − 1)(x + 2)².

## 3. Алгоритм «до кінця»

1. Винести спільний множник.
2. Порахувати члени: два — шукати різницю квадратів / кубів; три — квадрат тричлена або підбір; чотири й більше — групування.
3. Пошукати цілі корені (теорема Безу).
4. Перевірити, чи кожен множник ще розкладається.
5. Перевірити множенням або підстановкою числа.

**Приклад повного розкладу:** 2x⁴ − 32 = 2(x⁴ − 16) = 2(x² − 4)(x² + 4) = 2(x − 2)(x + 2)(x² + 4). Множник x² + 4 далі не розкладається на дійсні.

## 4. Ключовий приклад кількома способами: x² − 2x − 15

1. **Вієта:** добуток −15, сума −2 ⇒ −5 і 3 ⇒ (x − 5)(x + 3).
2. **Повний квадрат:** (x − 1)² − 16 = (x − 1 − 4)(x − 1 + 4) = (x − 5)(x + 3).
3. **Корені:** D = 4 + 60 = 64, x = (2 ± 8)/2 = 5 і −3.
4. **Метод «ac»:** −5x + 3x: x² − 5x + 3x − 15 = x(x − 5) + 3(x − 5).
5. **Перевірка числом:** x = 10: 100 − 20 − 15 = 65 = 5·13 ✓.

## 5. Навіщо це потрібно — приклади

- **Рівняння:** x³ − 4x = 0 ⇒ x(x − 2)(x + 2) = 0 ⇒ x = 0, ±2. Без розкладу кубічне рівняння загалом складне.
- **Нерівності:** знак (x − 1)(x + 3) видно з таблиці знаків множників (метод інтервалів, див. [[Квадратні рівняння]]).
- **Дроби:** (x² − 9)/(x² + 3x) = (x − 3)(x + 3)/(x(x + 3)) = (x − 3)/x (див. [[Алгебраїчні дроби]]).
- **Усний рахунок:** 37² − 13² = 24·50 = 1200.
- **Теорія чисел:** n³ − n = (n − 1)n(n + 1) — добуток трьох послідовних чисел, отже ділиться на 6.

## 6. Типові помилки

| Помилка | Правильно |
|---|---|
| x² + 9 = (x + 3)(x − 3) | x² − 9 = (x + 3)(x − 3); x² + 9 не розкладається |
| x² + 4x + 4 = (x + 4)² | (x + 2)² |
| 6x² − 3x = 3x(2x) | 3x(2x − 1): «1» на місці винесеного члена |
| Зупинитися на (x² − 1)(x² + 1) | x² − 1 розкладається далі |
| 2x² − 7x + 3 = (x − 3)(x − 1/2) | загубили старший коефіцієнт 2 |
| −x² + 4 = −(x² + 4) | −x² + 4 = −(x² − 4) = (2 − x)(2 + x): при винесенні −1 змінюється знак кожного члена |
| a − b і b − a — один множник | b − a = −(a − b) |
