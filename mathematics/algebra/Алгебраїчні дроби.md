# Алгебраїчні дроби

**Алгебраїчний (раціональний) дріб** — дріб, у чисельнику й знаменнику якого стоять многочлени: (x + 1)/(x − 2), 3/a², (x² − 9)/(x² + 3x). Усі правила — ті самі, що для звичайних дробів (див. [[Звичайні дроби]] і [[Дії зі звичайними дробами]]), бо змінна — це просто «будь-яке число». Нове лише одне: **знаменник не може дорівнювати нулю**, і тепер за цим треба стежити, бо знаменник залежить від x.

Пов'язані нотатки: [[Дії зі звичайними дробами]], [[Многочлени]], [[Розкладання на множники]], [[Раціональні та ірраціональні рівняння]], [[Математика — зміст]].

---

## 1. Область допустимих значень (ОДЗ)

**ОДЗ** — усі значення змінних, при яких вираз має зміст. Для дробу — усі x, крім нулів знаменника.

(x + 1)/(x² − 4): x² − 4 ≠ 0 ⇒ x ≠ ±2.

**Чому на нуль ділити не можна.** Ділення — обернене до множення: 6 : 2 = 3, бо 3·2 = 6. Якщо 5 : 0 = c, то c·0 = 5 — такого c немає. Якщо 0 : 0 = c, то c·0 = 0 — підходить будь-яке c, відповідь невизначена. В обох випадках однозначного результату немає.

## 2. Кілька способів думати про алгебраїчний дріб

| Модель | Що таке (x + 1)/(x − 2) |
|---|---|
| **Шаблон звичайних дробів** | при x = 5 це 6/3 = 2, при x = 3 це 4/1 — «дріб, що змінюється» |
| **Ділення** | результат ділення многочлена x + 1 на x − 2; ділення кутом дає 1 + 3/(x − 2) |
| **Функція** | правило x ↦ (x + 1)/(x − 2); графік — гіпербола з «дірою» в x = 2 |
| **Відношення величин** | швидкість = шлях/час, ціна = вартість/кількість |

**Перевірка числом** — головний інструмент теми: будь-яке перетворення можна перевірити, підставивши зручне число (не з ОДЗ-заборонених) у вихідний і в кінцевий вираз.

## 3. Основна властивість і скорочення

**Чисельник і знаменник можна помножити або поділити на один і той самий ненульовий вираз:** A/B = (A·C)/(B·C), C ≠ 0.

**Скорочувати можна лише множники, а не доданки.** Тому спочатку — розкласти на множники (див. [[Розкладання на множники]]).

(x² − 9)/(x² + 3x) = ((x − 3)(x + 3))/(x(x + 3)) = (x − 3)/x, при x ≠ 0, x ≠ −3.

**Чому після скорочення ОДЗ «пам'ятає» x ≠ −3.** Вихідний вираз при x = −3 не існує (0/0), а скорочений (x − 3)/x існує і дорівнює 2. Вирази рівні лише там, де обидва визначені. На графіку y = (x² − 9)/(x² + 3x) — це гіпербола y = (x − 3)/x з **виколотою точкою** при x = −3.

**Класична помилка:** (x + 3)/3 ≠ x, (x² + y²)/(x + y) ≠ x + y. Скорочувати доданки — те саме, що сказати (2 + 3)/3 = 2, а насправді 5/3.

**Знаки:** (a − b)/(b − a) = −1, бо b − a = −(a − b). Мінус можна переносити між чисельником, знаменником і перед дробом: −a/b = (−a)/b = a/(−b).

## 4. Додавання й віднімання

### 4.1. Однакові знаменники

A/C + B/C = (A + B)/C. Обережно з мінусом перед дробом: він стосується **всього** чисельника.

(3x + 1)/(x − 2) − (x − 5)/(x − 2) = (3x + 1 − x + 5)/(x − 2) = (2x + 6)/(x − 2).

### 4.2. Різні знаменники — спільний знаменник

1. Розкласти знаменники на множники.
2. Спільний знаменник — **НСК**: кожен множник у найбільшому степені, в якому він трапляється.
3. Додаткові множники — те, чого бракує кожному знаменнику.
4. Скласти чисельники, звести подібні, за можливості скоротити.

**Приклад:** 1/(x² − 4) + 1/(x² + 2x).
- x² − 4 = (x − 2)(x + 2); x² + 2x = x(x + 2).
- Спільний знаменник x(x − 2)(x + 2).
- Додаткові множники: x і (x − 2).
- (x + x − 2)/(x(x − 2)(x + 2)) = (2x − 2)/(x(x − 2)(x + 2)) = 2(x − 1)/(x(x² − 4)).

### 4.3. Ключовий приклад трьома способами: 1/x − 1/(x + 1)

**Спосіб 1. Спільний знаменник:** ((x + 1) − x)/(x(x + 1)) = 1/(x(x + 1)).

**Спосіб 2. Хрест-навхрест:** a/b − c/d = (ad − bc)/(bd): (1·(x + 1) − 1·x)/(x(x + 1)) = 1/(x(x + 1)).

**Спосіб 3. Читаємо справа наліво — «телескоп».** 1/(x(x + 1)) = 1/x − 1/(x + 1). Ця рівність дає змогу додати 1/(1·2) + 1/(2·3) + … + 1/(99·100) = (1 − 1/2) + (1/2 − 1/3) + … + (1/99 − 1/100) = 1 − 1/100 = 99/100. Проміжні члени взаємно знищуються, як секції складаної підзорної труби.

**Перевірка числом:** x = 1: 1 − 1/2 = 1/2 і 1/(1·2) = 1/2 ✓.

## 5. Множення, ділення, степінь

- **Множення:** (A/B)·(C/D) = (AC)/(BD). Спершу розкласти все на множники й скоротити хрест-навхрест, потім перемножувати.
- **Ділення:** (A/B) : (C/D) = (A/B)·(D/C) — множення на обернений дріб (див. [[Дії зі звичайними дробами]], де пояснено, чому). Додаткова умова: C ≠ 0.
- **Степінь:** (A/B)ⁿ = Aⁿ/Bⁿ.

**Приклад:** (x² − 1)/(x + 3) : (x − 1)/(x² + 3x) = ((x − 1)(x + 1))/(x + 3) · (x(x + 3))/(x − 1) = x(x + 1).

## 6. Багатоповерхові дроби

(1 + 1/x)/(1 − 1/x²).

**Спосіб 1 — спростити окремо:** чисельник (x + 1)/x, знаменник (x² − 1)/x² ⇒ (x + 1)/x · x²/((x − 1)(x + 1)) = x/(x − 1).

**Спосіб 2 — помножити «поверхи» на спільний знаменник усіх маленьких дробів** (x²): (x² + x)/(x² − 1) = x(x + 1)/((x − 1)(x + 1)) = x/(x − 1). Зазвичай швидше.

## 7. Виділення цілої частини

Як 17/5 = 3 + 2/5, так і (x² + 1)/(x − 1) = x + 1 + 2/(x − 1) (ділення кутом, див. [[Многочлени]]).

**Навіщо:**
- **Графік:** y = (2x + 1)/(x − 1) = 2 + 3/(x − 1) — гіпербола y = 3/x, зсунута на 1 праворуч і на 2 вгору.
- **Цілі значення:** (2x + 1)/(x − 1) ціле ⇔ 3/(x − 1) ціле ⇔ x − 1 ∈ {±1, ±3} ⇔ x ∈ {−2, 0, 2, 4}.
- **Поведінка на нескінченності:** при великих x дріб ≈ 2.

## 8. Розклад на найпростіші дроби

Іноді треба навпаки — розкласти один дріб на суму простих:

(5x − 1)/((x − 1)(x + 1)) = A/(x − 1) + B/(x + 1).

Множимо на знаменник: 5x − 1 = A(x + 1) + B(x − 1). При x = 1: 4 = 2A ⇒ A = 2. При x = −1: −6 = −2B ⇒ B = 3.

Ця техніка потрібна для інтегрування (див. [[Інтеграл]]) і сум рядів.

## 9. Типові помилки

| Помилка | Правильно |
|---|---|
| (x + 5)/5 = x | скорочують лише множники |
| (x² − 4)/(x − 2) = x + 2 «для всіх x» | лише при x ≠ 2 |
| 1/a + 1/b = 1/(a + b) | (a + b)/(ab) |
| −(x − 3)/(x + 1) = (−x − 3)/(x + 1) | (−x + 3)/(x + 1) |
| A/B : C/D = AC/BD | AD/(BC) |
| Спільний знаменник — завжди добуток | НСК, інакше вираз роздувається |
| Загубили ОДЗ і знайшли «корінь», при якому знаменник 0 | перевіряти ОДЗ |
