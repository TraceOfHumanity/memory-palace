# Прогресії

**Числова послідовність** — числа, записані по порядку й пронумеровані: a₁, a₂, a₃, … Номер n — натуральне число, aₙ — n-й член. Формально послідовність — це функція з натуральних чисел у дійсні (див. [[Функції]]).

Дві найважливіші послідовності шкільної математики:
- **арифметична прогресія** — кожен наступний член отримуємо **додаванням** одного й того самого числа: 3, 7, 11, 15, … (+4);
- **геометрична прогресія** — кожен наступний член отримуємо **множенням** на одне й те саме число: 3, 6, 12, 24, … (·2).

Це дві моделі зростання: **лінійне** (зарплата, що зростає на сталу суму) і **експоненційне** (вклад під відсотки, розмноження бактерій, поширення чуток).

Пов'язані нотатки: [[Доведення і математична індукція]], [[Зміна у відсотках і складні відсотки]], [[Степені з цілим показником]], [[Ряди і число e]], [[Комбінаторика і рекурентності]], [[Математика — зміст]].

## 1. Способи задати послідовність

| Спосіб | Приклад | Плюс | Мінус |
|---|---|---|---|
| **Формула n-го члена** | aₙ = 4n − 1 | будь-який член одразу: a₁₀₀ = 399 | не завжди відома |
| **Рекурентна формула** | a₁ = 3, aₙ₊₁ = aₙ + 4 | природно описує процес «крок за кроком» | щоб знайти a₁₀₀, треба 99 кроків |
| **Перелік** | 3, 7, 11, 15, … | наочно | не визначає послідовність однозначно |
| **Опис словами** | «прості числа за зростанням» | — | формули може не бути |

## 2. Арифметична прогресія

### 2.1. Означення і формула n-го члена

aₙ₊₁ = aₙ + d. Число **d** — **різниця** прогресії: d = a₂ − a₁.

$$a_n=a_1+(n-1)d$$

**Чому n − 1:** від першого члена до n-го — n − 1 кроків. Від a₁ до a₁ — нуль кроків, до a₂ — один. Як стовпчики паркану: між 10 стовпчиками 9 прогонів.

### 2.2. Кілька способів думати

| Модель | Що таке арифметична прогресія |
|---|---|
| **Сходи** | кожна сходинка на однакову висоту d вища |
| **Лінійна функція** | точки (n; aₙ) лежать на прямій з кутовим коефіцієнтом d: aₙ = dn + (a₁ − d) |
| **Рівномірний рух** | положення через кожну секунду при сталій швидкості |
| **Скарбничка** | щотижня кладемо однакову суму |

### 2.3. Характеристична властивість

**Кожен член (крім першого) — середнє арифметичне сусідів:** aₙ = (aₙ₋₁ + aₙ₊₁)/2.

**Чому:** aₙ₋₁ = aₙ − d, aₙ₊₁ = aₙ + d, сума 2aₙ. Звідси ж: aₘ + aₖ = aₚ + a_q, якщо m + k = p + q. Члени, рівновіддалені від кінців, мають однакову суму.

### 2.4. Сума n перших членів — три способи

**Спосіб 1. Гаусс.** За легендою, маленький Гаусс мав скласти 1 + 2 + … + 100. Він записав суму двічі, другий раз задом наперед:

```
S =   1 +  2 +  3 + … + 99 + 100
S = 100 + 99 + 98 + … +  2 +   1
2S = 101 + 101 + 101 + … + 101   (100 разів)
```

2S = 100·101 ⇒ S = 5050. Те саме для будь-якої арифметичної прогресії:

$$S_n=\frac{(a_1+a_n)\,n}{2}=\frac{2a_1+(n-1)d}{2}\cdot n$$

**Спосіб 2. Середнє × кількість.** Члени симетричні відносно середнього (a₁ + aₙ)/2. Сума = середнє значення × кількість.

**Спосіб 3. Площа сходинок.** Сходинки висотою 1, 2, …, n утворюють «трикутник» з n(n + 1)/2 клітинок: два такі трикутники складаються у прямокутник n×(n + 1).

```
■
■ ■
■ ■ ■
■ ■ ■ ■     + такий самий перевернутий = прямокутник 4×5
```

**Наслідки:**
- 1 + 2 + … + n = n(n + 1)/2 (трикутні числа).
- 1 + 3 + 5 + … + (2n − 1) = n² — сума перших непарних чисел є квадратом. Картинка: кожне непарне число — «кутик», що добудовує квадрат (k − 1)×(k − 1) до k×k.

## 3. Геометрична прогресія

### 3.1. Означення і формула n-го члена

bₙ₊₁ = bₙ·q, b₁ ≠ 0, q ≠ 0. Число **q** — **знаменник**: q = b₂/b₁.

$$b_n=b_1\cdot q^{\,n-1}$$

n − 1 множень на q від першого до n-го члена.

### 3.2. Кілька способів думати

| Модель | Що таке геометрична прогресія |
|---|---|
| **Складні відсотки** | вклад 1000 грн під 10% річних: 1000, 1100, 1210, … (q = 1,1) |
| **Розмноження** | бактерія ділиться щогодини: 1, 2, 4, 8, … (q = 2) |
| **Розпад** | половина речовини розпадається за період: 100, 50, 25, … (q = 1/2) |
| **Показникова функція** | точки (n; bₙ) лежать на кривій y = b₁·qⁿ⁻¹ (див. [[Найважливіші графіки]]) |
| **Масштабування** | кожна наступна фігура — зменшена копія попередньої (фрактали) |

**Поведінка залежно від q:**
- q > 1 — швидке зростання (якщо b₁ > 0);
- 0 < q < 1 — спадання до нуля;
- q < 0 — знаки чергуються: 1, −2, 4, −8, …;
- q = 1 — стала послідовність.

### 3.3. Характеристична властивість

**Кожен член — середнє геометричне сусідів (за модулем):** bₙ² = bₙ₋₁·bₙ₊₁.

### 3.4. Сума n перших членів

**Прийом «помнож і відніми»:**

S = b₁ + b₁q + b₁q² + … + b₁qⁿ⁻¹
qS = b₁q + b₁q² + … + b₁qⁿ⁻¹ + b₁qⁿ

Віднімаємо: S − qS = b₁ − b₁qⁿ. Усі середні члени знищилися.

$$S_n=\frac{b_1(q^n-1)}{q-1}=\frac{b_1(1-q^n)}{1-q},\quad q\ne1$$

**Приклад-легенда про шахи.** Винахідник шахів попросив 1 зернину на першу клітинку, 2 на другу, 4 на третю… Усього 1 + 2 + … + 2⁶³ = 2⁶⁴ − 1 ≈ 1,8·10¹⁹ зерен — більше, ніж вирощено пшениці за всю історію людства. Так виглядає експоненційне зростання.

**Двійкова картинка:** 1 + 2 + 4 + … + 2ⁿ⁻¹ = 2ⁿ − 1, бо у двійковій системі це число 111…1 (n одиниць), а додавши 1, отримаємо 1000…0 = 2ⁿ (див. [[Системи числення]]).

### 3.5. Нескінченно спадна геометрична прогресія

Якщо |q| < 1, то qⁿ → 0, і сума всіх членів скінченна:

$$S=\frac{b_1}{1-q}$$

**Квадрат, що ділиться навпіл:** 1/2 + 1/4 + 1/8 + … = 1. Візьміть квадрат площі 1, зафарбуйте половину, потім половину того, що лишилося, і так далі — зафарбованим стане весь квадрат.

```
┌───────┬───┬─┐
│       │   │ │
│  1/2  │1/4├─┤
│       │   │…│
│       ├───┴─┤
│       │ 1/8 │
└───────┴─────┘
```

**Апорія Зенона** про Ахілла й черепаху: Ахілл пробігає відстань до черепахи, але вона встигає відповзти; він пробігає і цю відстань… Нескінченно багато кроків — але їхня сумарна тривалість — сума спадної прогресії — скінченна, і Ахілл наздоганяє черепаху.

**Періодичні дроби:** 0,(3) = 3/10 + 3/100 + … = (3/10)/(1 − 1/10) = 1/3. І 0,(9) = (9/10)/(9/10) = 1 — так, 0,999… = 1 (див. [[Десяткові дроби й округлення]]).

## 4. Порівняння двох прогресій

| | Арифметична | Геометрична |
|---|---|---|
| Крок | + d | · q |
| n-й член | a₁ + (n − 1)d | b₁qⁿ⁻¹ |
| Середній член | середнє арифметичне | середнє геометричне |
| Сума | (a₁ + aₙ)n/2 | b₁(qⁿ − 1)/(q − 1) |
| Графік | точки на прямій | точки на показниковій кривій |
| Зростання | лінійне | експоненційне |
| Приклад | зарплата +1000 грн щороку | зарплата +10% щороку |

**Хто переможе:** 1000 + 1000n проти 1,1ⁿ·1000. Спочатку арифметична попереду, але геометрична з q > 1 **завжди** зрештою обганяє будь-яку арифметичну.

## 5. Ключовий приклад кількома способами

**Задача:** a₃ = 7, a₈ = 22. Знайдіть a₁, d і S₁₀.

**Спосіб 1. Система:** { a₁ + 2d = 7, a₁ + 7d = 22 } ⇒ 5d = 15 ⇒ d = 3, a₁ = 1.

**Спосіб 2. Кроки:** від a₃ до a₈ — 5 кроків, приріст 22 − 7 = 15 ⇒ d = 3. Назад від a₃ на два кроки: a₁ = 7 − 6 = 1.

**Спосіб 3. Пряма:** точки (3; 7) і (8; 22) лежать на прямій з нахилом 15/5 = 3.

S₁₀: a₁₀ = 1 + 27 = 28; S₁₀ = (1 + 28)·10/2 = 145.

## 6. Інші послідовності — для кругозору

- **Фібоначчі:** 1, 1, 2, 3, 5, 8, 13, … (Fₙ₊₁ = Fₙ + Fₙ₋₁). Відношення сусідніх → золотий переріз 1,618… Див. [[Комбінаторика і рекурентності]].
- **Квадрати й куби:** 1² + 2² + … + n² = n(n + 1)(2n + 1)/6; 1³ + … + n³ = (n(n + 1)/2)².
- **Гармонічний ряд** 1 + 1/2 + 1/3 + … — **розбіжний**, хоча члени прямують до нуля (див. [[Ряди і число e]]).

## 7. Типові помилки

| Помилка | Правильно |
|---|---|
| aₙ = a₁ + nd | a₁ + (n − 1)d |
| bₙ = b₁qⁿ | b₁qⁿ⁻¹ |
| d = a₁ − a₂ | d = a₂ − a₁ |
| Сума спадної прогресії при q = 2 | формула S = b₁/(1 − q) лише при \|q\| < 1 |
| 2, 4, 8, 14 — геометрична | перевірити відношення: 2, 2, 1,75 — ні |
| Кількість членів від a₅ до a₁₂ — 7 | 8 (12 − 5 + 1) |
| Забули, що q може бути від'ємним: b₃ = 4, b₅ = 16 ⇒ q = 2 | q = ±2 |
