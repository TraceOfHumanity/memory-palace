# Модуль числа

**Модуль** (абсолютна величина) числа a, позначення |a|, — це **відстань від точки a до нуля** на числовій прямій. Відстань не буває від'ємною, тому |a| ≥ 0 завжди: |5| = 5, |−5| = 5, |0| = 0. Модуль «забуває» знак числа й лишає тільки його величину.

Пов'язані нотатки: [[Цілі числа]], [[Змінні, вирази і рівняння]], [[Квадратний корінь]], [[Комплексні числа]], [[Лінійні рівняння і нерівності]], [[Графіки — основи]], [[Математика — зміст]].

## 1. Чотири рівносильні означення

Одне й те саме поняття можна записати чотирма способами. Кожен корисний у своїх задачах.

| Означення | Запис | Коли зручне |
|---|---|---|
| **Геометричне** | \|a\| — відстань від a до 0 | рівняння й нерівності з \|x − c\|, задачі «на відстань» |
| **Алгебраїчне (за знаком)** | \|a\| = a, якщо a ≥ 0; \|a\| = −a, якщо a < 0 | розкриття модуля, метод інтервалів |
| **Через корінь** | \|a\| = √(a²) | перетворення виразів з коренями |
| **Через максимум** | \|a\| = max(a, −a) | доведення нерівностей, програмування |

**Чому «−a» в другому рядку не помилка.** Якщо a від'ємне, наприклад a = −7, то −a = −(−7) = 7 — додатне. Мінус перед від'ємним числом робить його додатним. Тому запис «|a| = −a при a < 0» означає саме «прибрати мінус». Це найчастіше джерело плутанини: здається, що модуль раптом став від'ємним, але −a тут додатне число.

**Чому √(a²) = |a|, а не a.** Піднесення до квадрата знищує знак: (−3)² = 9 = 3². Арифметичний корінь повертає **невід'ємне** число: √9 = 3. Отже √((−3)²) = 3 = |−3|. Якщо написати √(a²) = a, то при a = −3 вийде 3 = −3 — неправда.

**Чому max(a, −a).** З двох чисел a і −a одне невід'ємне, а друге недодатне. Більше з них — невід'ємне, тобто якраз величина без знака.

## 2. Кілька способів зрозуміти модуль

| Модель | Що таке \|a\| | Що таке \|a − b\| |
|---|---|---|
| **Відстань на прямій** | скільки кроків від a до 0 | скільки кроків від a до b |
| **Гроші** | розмір суми, байдуже — дохід чи борг | наскільки дві суми відрізняються |
| **Термометр** | наскільки далеко від нуля температура | на скільки градусів відрізняються дві температури |
| **Похибка** | — | наскільки вимір a відхилився від справжнього b |
| **Довжина стрілки** | довжина вектора на прямій без напрямку | довжина стрілки від b до a |
| **«Дзеркало»** | відображення від'ємної півосі на додатну | — |

Найважливіша ідея всієї теми: **|a − b| — відстань між точками a і b**. Різниця a − b показує, на скільки a правіше за b. Якщо a лівіше, різниця від'ємна, але відстань однакова. Модуль прибирає «напрямок». Між −3 і 5 відстань |−3 − 5| = |−8| = 8, і так само |5 − (−3)| = 8.

Звідси переклад з мови модулів на мову відстаней:

| Запис | Читаємо як |
|---|---|
| \|x\| = 4 | x на відстані 4 від нуля |
| \|x − 2\| = 4 | x на відстані 4 від точки 2 |
| \|x + 2\| = 4 | x на відстані 4 від точки −2 (бо x + 2 = x − (−2)) |
| \|x − 2\| < 4 | x ближче ніж на 4 до точки 2 |
| \|x − 2\| > 4 | x далі ніж на 4 від точки 2 |
| \|x − 1\| = \|x − 7\| | x однаково далеко від 1 і 7 |
| \|x − 1\| + \|x − 7\| | сума відстаней від x до 1 і до 7 |

## 3. Властивості з поясненнями

1. **|a| ≥ 0**, і **|a| = 0 тільки при a = 0.** Відстань невід'ємна; нульова лише тоді, коли точка збігається з нулем.
2. **|−a| = |a|.** Точки a і −a симетричні відносно нуля, тож однаково віддалені від нього.
3. **|a|² = a².** Обидва боки — квадрат величини числа, знак при піднесенні до квадрата зникає. Ця властивість дає змогу позбутися модуля, піднісши обидві частини до квадрата.
4. **|ab| = |a|·|b|.** Добуток модулів дорівнює модулю добутку. Чому: за правилом знаків добуток має модуль, що дорівнює добутку модулів, а знак визначається окремо. Модуль знак відкидає.
5. **|a / b| = |a| / |b|** при b ≠ 0 — з тієї самої причини.
6. **−|a| ≤ a ≤ |a|.** Число не більше за свою величину і не менше за мінус свою величину.
7. **Нерівність трикутника: |a + b| ≤ |a| + |b|.**
   - *Чому:* якщо a і b одного знака, вони «тягнуть в один бік», і |a + b| = |a| + |b|. Якщо знаки різні, вони частково гасять одне одного, і сума менша.
   - *Доведення:* з властивості 6 маємо −|a| ≤ a ≤ |a| і −|b| ≤ b ≤ |b|. Додаємо: −(|a| + |b|) ≤ a + b ≤ |a| + |b|, а це й означає |a + b| ≤ |a| + |b|.
   - *Чому «трикутника»:* для векторів на площині це твердження «сторона трикутника не довша за суму двох інших».
   - Рівність — тоді й лише тоді, коли ab ≥ 0.
8. **|a − b| ≥ ||a| − |b||.** Обернена нерівність трикутника: різниця величин не більша за відстань між числами.
9. **|a| ≤ c ⇔ −c ≤ a ≤ c**, **|a| ≥ c ⇔ a ≤ −c або a ≥ c** (для c ≥ 0). Це геометричне означення, записане нерівностями. На ньому стоять усі нерівності з модулем.

**Чого немає:** |a + b| ≠ |a| + |b| у загальному випадку: |3 + (−5)| = 2, а |3| + |−5| = 8. Модуль «проходить» крізь множення й ділення, але **не крізь додавання**.

## 4. Розкриття модуля у виразах

Щоб прибрати модуль з виразу, треба знати **знак** того, що всередині.

- Якщо вираз під модулем ≥ 0 — модуль просто знімаємо: |x − 3| = x − 3 при x ≥ 3.
- Якщо вираз < 0 — знімаємо і змінюємо знак усього виразу: |x − 3| = −(x − 3) = 3 − x при x < 3.

**Приклад.** Спростіть |x − 5| + |x + 1| при 0 < x < 2.
- x − 5 < 0, бо x < 2 < 5. Тому |x − 5| = 5 − x.
- x + 1 > 0, бо x > 0. Тому |x + 1| = x + 1.
- Сума: 5 − x + x + 1 = 6.

**Приклад з коренем.** √(x² − 6x + 9) = √((x − 3)²) = |x − 3|. Типова помилка — написати «x − 3» і загубити модуль.

**Порівняння чисел з коренями.** |√5 − 3| = 3 − √5, бо √5 ≈ 2,24 < 3.

## 5. Рівняння з модулем

### 5.1. Найпростіше: |x| = a

- a > 0: два корені x = a і x = −a (дві точки на відстані a від нуля).
- a = 0: один корінь x = 0.
- a < 0: коренів немає (відстань не буває від'ємною).

### 5.2. |f(x)| = a, де a > 0

Розпадається на два рівняння: **f(x) = a або f(x) = −a**.

|2x − 3| = 7 ⇒ 2x − 3 = 7 або 2x − 3 = −7 ⇒ x = 5 або x = −2.

**Геометрично:** |2x − 3| = 2·|x − 1,5| = 7 ⇒ |x − 1,5| = 3,5 — точки на відстані 3,5 від 1,5: 1,5 ± 3,5, тобто 5 і −2.

### 5.3. |f(x)| = |g(x)|

Два числа з однаковими модулями або рівні, або протилежні: **f = g або f = −g**. Інший спосіб — піднести до квадрата: f² = g² ⇔ (f − g)(f + g) = 0 — те саме.

|x − 1| = |x − 7|: x − 1 = x − 7 (неможливо) або x − 1 = −(x − 7) ⇒ x = 4. Геометрично — середина відрізка [1; 7], відповідь очевидна з малюнка.

### 5.4. |f(x)| = g(x) з виразом справа

Модуль невід'ємний, тому **потрібна умова g(x) ≥ 0**. Розв'язуємо f = g або f = −g, а потім **відкидаємо** корені, де g < 0.

|x − 2| = 2x − 1:
- x − 2 = 2x − 1 ⇒ x = −1. Перевірка умови: 2·(−1) − 1 = −3 < 0 — відкидаємо.
- x − 2 = −(2x − 1) ⇒ 3x = 3 ⇒ x = 1. Умова: 2·1 − 1 = 1 ≥ 0 — підходить.
- Відповідь: x = 1.

### 5.5. Кілька модулів — метод інтервалів

1. Знайти **нулі** кожного підмодульного виразу.
2. Ці точки ділять пряму на проміжки. На кожному проміжку знак кожного виразу сталий.
3. На кожному проміжку розкрити модулі за знаками й розв'язати звичайне рівняння.
4. Перевірити, чи корінь лежить у своєму проміжку.

### 5.6. Ключовий приклад трьома способами: |x − 1| + |x + 2| = 5

**Спосіб 1. Метод інтервалів.** Нулі: x = 1 і x = −2.

| Проміжок | x − 1 | x + 2 | Рівняння | Розв'язок | У проміжку? |
|---|---|---|---|---|---|
| x < −2 | − | − | (1 − x) + (−x − 2) = 5 ⇒ −2x − 1 = 5 | x = −3 | так |
| −2 ≤ x < 1 | − | + | (1 − x) + (x + 2) = 5 ⇒ 3 = 5 | немає | — |
| x ≥ 1 | + | + | (x − 1) + (x + 2) = 5 ⇒ 2x + 1 = 5 | x = 2 | так |

Відповідь: x = −3 і x = 2.

**Спосіб 2. Відстані.** |x − 1| + |x + 2| — сума відстаней від x до точок 1 і −2. Відстань між самими точками 1 і −2 дорівнює 3.
- Будь-яка точка **між** ними має суму відстаней рівно 3, бо дві відстані складаються в весь відрізок. Тож між точками розв'язків немає: 3 ≠ 5.
- Точка **зовні** має суму 3 + 2·(відстань до ближчого кінця). Щоб вийшло 5, треба відійти на 1 від ближчого кінця: x = 1 + 1 = 2 або x = −2 − 1 = −3.

**Спосіб 3. Графік.** Графік y = |x − 1| + |x + 2| — «корито»: на [−2; 1] горизонтальне дно на висоті 3, зліва й справа — прямі з кутовими коефіцієнтами −2 і 2. Пряма y = 5 перетинає його у двох точках: x = −3 і x = 2.

```
 y
 5 ─*─────────────*─── y = 5
     \           /
 3    \_________/
  ─────┼────┼───┼────► x
      −2    0   1
```

**Порівняння способів:** метод інтервалів працює завжди, але вимагає акуратності. Відстані дають відповідь у голові, коли коефіцієнти при x дорівнюють 1. Графік показує, скільки розв'язків, ще до обчислень.

## 6. Нерівності з модулем

### 6.1. Основні типи (c > 0)

| Нерівність | Геометрично | Рівносильна | Відповідь |
|---|---|---|---|
| \|x\| < c | ближче за c до нуля | −c < x < c | (−c; c) |
| \|x\| > c | далі за c від нуля | x < −c або x > c | (−∞; −c) ∪ (c; +∞) |
| \|x − m\| < r | ближче за r до m | m − r < x < m + r | (m − r; m + r) |
| \|x − m\| ≥ r | не ближче за r до m | x ≤ m − r або x ≥ m + r | (−∞; m − r] ∪ [m + r; +∞) |

**Як запам'ятати:** «менше» — **всередині** (один проміжок, подвійна нерівність), «більше» — **зовні** (два промені, «або»).

**Окремі випадки:** |x| < 0 — розв'язків немає; |x| ≤ 0 ⇔ x = 0; |x| ≥ 0 — будь-яке x; |x| > −3 — будь-яке x.

### 6.2. Приклад: |2x − 5| ≤ 3

**Спосіб 1 (подвійна нерівність):** −3 ≤ 2x − 5 ≤ 3 ⇒ 2 ≤ 2x ≤ 8 ⇒ 1 ≤ x ≤ 4.

**Спосіб 2 (відстані):** |2x − 5| = 2·|x − 2,5| ≤ 3 ⇒ |x − 2,5| ≤ 1,5 — точки не далі ніж 1,5 від 2,5: [1; 4].

**Спосіб 3 (квадрати):** обидві частини невід'ємні, тож (2x − 5)² ≤ 9 ⇔ (2x − 5 − 3)(2x − 5 + 3) ≤ 0 ⇔ (2x − 8)(2x − 2) ≤ 0 ⇒ [1; 4].

### 6.3. «Окіл» — мова аналізу

Запис |x − a| < ε читають «x лежить в ε-околі точки a»: x відрізняється від a менше ніж на ε. Саме так у [[Границі і неперервність]] формулюють «x наближається до a»: для будь-якої малої ε відстань |f(x) − L| < ε.

### 6.4. Похибка

Якщо довжина l = 25 ± 0,3 см, це означає |l − 25| ≤ 0,3, тобто 24,7 ≤ l ≤ 25,3. Абсолютна похибка — |наближене − точне|, відносна — |наближене − точне| / |точне|.

## 7. Графіки з модулем

### 7.1. y = |x|

«Галочка» з вершиною в (0; 0): праворуч пряма y = x, ліворуч y = −x. Кут між гілками прямий.

```
 y
  \       /
   \     /
    \   /
     \ /
  ────*────► x
      0
```

### 7.2. Перетворення

| Графік | Як отримати з графіка y = f(x) | Чому |
|---|---|---|
| y = \|x − a\| + b | галочку зсунути на a праворуч і на b угору | заміна x на x − a зсуває вправо |
| y = \|f(x)\| | частину під віссю Ox **дзеркально відобразити вгору** | від'ємні значення стають додатними |
| y = f(\|x\|) | праву половину залишити, ліву **стерти й замінити дзеркальною копією правої** | f(\|−x\|) = f(\|x\|) — функція стає парною |
| y = k\|x\| | галочка крутіша при k > 1, положистіша при 0 < k < 1 | множення значень |

**Приклад:** y = |x² − 4|. Парабола y = x² − 4 між −2 і 2 лежить під віссю; цей шматок «перевертаємо» догори — виходить «пташка» з горбом висоти 4 в нулі.

### 7.3. Графічний розв'язок

Рівняння |f(x)| = a має стільки розв'язків, скільки разів горизонтальна пряма y = a перетинає графік y = |f(x)|. Так зручно розв'язувати задачі «при яких a рівняння має рівно 3 розв'язки». Для |x² − 4| = a: при a = 4 пряма торкається горба, розв'язків рівно 3; при 0 < a < 4 — чотири; при a > 4 — два.

## 8. Де модуль трапляється далі

- **Комплексні числа:** |a + bi| = √(a² + b²) — відстань від точки до початку координат на площині. Див. [[Комплексні числа]].
- **Вектори:** довжина (норма) вектора |v| = √(v₁² + v₂² + …) — той самий модуль у кількох вимірах. Див. [[Вектори і матриці]].
- **Відстань на площині** між точками — √((x₁ − x₂)² + (y₁ − y₂)²); на прямій вона спрощується до |x₁ − x₂|.
- **Програмування:** `Math.abs(x)`, `abs(x)`. Перевірка «майже рівні» для дробових чисел: `Math.abs(a - b) < 1e-9`.
- **Статистика:** середнє абсолютне відхилення — середнє |xᵢ − x̄|.

## 9. Типові помилки

| Помилка | Правильно |
|---|---|
| \|−x\| = x | \|−x\| = \|x\|; дорівнює x лише при x ≥ 0 |
| √(x²) = x | √(x²) = \|x\| |
| \|a + b\| = \|a\| + \|b\| | ≤; рівність лише при однакових знаках |
| \|x\| = −3 ⇒ x = ±3 | розв'язків немає |
| \|x − 2\| = 2x − 1: обидва корені без перевірки | перевірити умову 2x − 1 ≥ 0 |
| \|x\| > 3 ⇒ −3 > x > 3 | x < −3 **або** x > 3 (двох умов разом не буває) |
| \|x + 2\| — відстань до 2 | відстань до **−2** |
| Метод інтервалів: корінь поза своїм проміжком лишили | корінь проміжку має належати проміжку |
| «−a при a < 0 — від'ємне» | −a при a < 0 додатне |
