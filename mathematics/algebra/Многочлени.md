# Многочлени

**Многочлен** — це сума одночленів, тобто вираз, складений із чисел і змінних лише за допомогою додавання, віднімання, множення та піднесення до натурального степеня: 3x² − 5x + 2, a³ + b³, 7, x. Ділення на змінну, корені зі змінної й від'ємні степені змінної в многочлен не входять.

Многочлени — це «числа алгебри». З ними роблять усе те саме, що з числами: додають, множать, ділять з остачею, розкладають на множники. Більшість правил алгебри — це правила арифметики, записані для будь-якого числа одразу.

Пов'язані нотатки: [[Змінні, вирази і рівняння]], [[Арифметичні дії та їхні властивості]], [[Степені з цілим показником]], [[Формули скороченого множення і біном Ньютона]], [[Розкладання на множники]], [[Алгебраїчні дроби]], [[Математика — зміст]].

## 1. Словник

| Термін | Що означає | Приклад |
|---|---|---|
| **Одночлен** | добуток числа й степенів змінних | −5x²y, 7, a |
| **Коефіцієнт** | числовий множник одночлена | у −5x²y це −5 |
| **Степінь одночлена** | сума показників усіх змінних | −5x²y має степінь 2 + 1 = 3 |
| **Подібні одночлени** | однакова буквена частина | 3x²y і −8x²y; але не x²y і xy² |
| **Многочлен** | сума одночленів | 4x³ − x + 9 |
| **Стандартний вигляд** | подібні зведено, члени впорядковано за спаданням степеня | 4x³ + 0x² − x + 9 |
| **Степінь многочлена** | найбільший степінь його членів | 4x³ − x + 9 має степінь 3 |
| **Старший коефіцієнт** | коефіцієнт при найвищому степені | 4 |
| **Вільний член** | член без змінної | 9 |
| **Двочлен, тричлен** | многочлен з 2 і 3 членів | x + 1; x² + x + 1 |

Многочлен степеня 1 — **лінійний** (ax + b), степеня 2 — **квадратний** (ax² + bx + c), 3 — **кубічний**.

## 2. Кілька способів думати про многочлен

| Модель | Що таке 3x² + 2x + 1 | Що дає |
|---|---|---|
| **Рецепт обчислення** | «візьми число, піднеси до квадрата, помнож на 3, додай подвоєне число й 1» | значення при будь-якому x |
| **Число в системі з основою x** | як 321 = 3·10² + 2·10 + 1, тільки замість 10 стоїть x | додавання й множення «стовпчиком», ділення кутом |
| **Площі (алгебраїчні плитки)** | 3 великі квадрати x×x, 2 смужки x×1, 1 маленький квадратик | множення як площа прямокутника, розкладання як складання прямокутника |
| **Список коефіцієнтів** | (3, 2, 1) | комп'ютерне представлення, схема Горнера |
| **Функція** | правило x ↦ 3x² + 2x + 1, графік — парабола | корені, знаки, поведінка |

**Многочлен як число.** При x = 10 многочлен 3x² + 2x + 1 дорівнює 321. Множення (x + 2)(x + 3) = x² + 5x + 6 при x = 10 дає 12·13 = 156. Саме тому множення многочленів стовпчиком виглядає як множення чисел стовпчиком — тільки без переносів, бо «цифри» (коефіцієнти) можуть бути будь-якими.

## 3. Одночлени

**Множення:** коефіцієнти множимо, степені однакових змінних додаємо (див. [[Степені з цілим показником]]).

(−3x²y)·(4xy³) = (−3·4)·x²⁺¹·y¹⁺³ = −12x³y⁴.

**Піднесення до степеня:** кожен множник підносимо до степеня.

(−2a³b)⁴ = (−2)⁴·a¹²·b⁴ = 16a¹²b⁴.

**Додавання** можливе лише для подібних: 3x²y + 5x²y = 8x²y — як «3 яблука + 5 яблук». А 3x² + 5x не додаються, як не додаються яблука з грушами.

## 4. Додавання й віднімання многочленів

Розкрити дужки й звести подібні.

(3x² − 2x + 5) − (x² − 7x − 1) = 3x² − 2x + 5 − x² + 7x + 1 = 2x² + 5x + 6.

**Мінус перед дужками змінює знак кожного члена** — це розподільний закон з множником −1: −(a − b + c) = −a + b − c.

**Стовпчиком** (як числа):

```
  3x² − 2x + 5
− ( x² − 7x − 1)
  ─────────────
  2x² + 5x + 6
```

## 5. Множення

### 5.1. Одночлен на многочлен — розподільний закон

2x(3x² − x + 4) = 6x³ − 2x² + 8x.

### 5.2. Многочлен на многочлен — «кожен з кожним»

**(a + b)(c + d) = ac + ad + bc + bd.** Кожен член першої дужки множимо на кожен член другої. Якщо в дужках m і n членів, до зведення подібних буде m·n доданків.

**Чому:** двічі застосовуємо розподільний закон: (a + b)(c + d) = a(c + d) + b(c + d) = ac + ad + bc + bd.

### 5.3. Ключовий приклад трьома способами: (2x + 3)(x − 4)

**Спосіб 1. Розподільний закон:** 2x·x + 2x·(−4) + 3·x + 3·(−4) = 2x² − 8x + 3x − 12 = 2x² − 5x − 12.

**Спосіб 2. Таблиця (сітка площ).** Прямокутник зі сторонами (2x + 3) і (x − 4) розбиваємо на клітинки:

| × | x | −4 |
|---|---|---|
| **2x** | 2x² | −8x |
| **3** | 3x | −12 |

Сума клітинок: 2x² − 5x − 12. Подібні члени лежать на діагоналі — так їх не загубиш.

**Спосіб 3. Перевірка числом.** При x = 10: (23)(6) = 138, і 2·100 − 50 − 12 = 138 ✓. Підстановка числа — найшвидший спосіб упіймати помилку в перетвореннях.

### 5.4. Стовпчиком для довших многочленів

(x² + 2x − 1)(x − 3):

```
          x² + 2x − 1
        ×      x − 3
  ─────────────────────
       −3x² − 6x + 3
  x³ + 2x² −  x
  ─────────────────────
  x³ −  x² − 7x + 3
```

### 5.5. Корисні спостереження

- **Степінь добутку** = сума степенів множників (старші члени множаться).
- **Вільний член добутку** = добуток вільних членів: (2x + 3)(x − 4) → 3·(−4) = −12.
- **Сума коефіцієнтів** многочлена = його значення при x = 1. Для добутку: P(1)·Q(1). Для 2x² − 5x − 12: 2 − 5 − 12 = −15 = 5·(−3) ✓.

## 6. Ділення многочленів

### 6.1. Ділення з остачею — як у числах

Для чисел: 17 = 5·3 + 2, остача менша за дільник. Для многочленів: **P(x) = D(x)·Q(x) + R(x)**, де степінь остачі R менший за степінь дільника D.

### 6.2. Ділення кутом: (2x³ − 3x² + 4x − 5) : (x − 2)

Кожен крок — як у шкільному діленні кутом: ділимо старший член на старший член дільника, множимо, віднімаємо, зносимо наступний член.

```
 2x³ − 3x² + 4x − 5 │ x − 2
−(2x³ − 4x²)        │──────────────
 ──────────         │ 2x² + x + 6
        x² + 4x     │
      −(x² − 2x)    │
       ─────────    │
              6x − 5
            −(6x − 12)
             ────────
                   7
```

Частка 2x² + x + 6, остача 7: 2x³ − 3x² + 4x − 5 = (x − 2)(2x² + x + 6) + 7.

### 6.3. Теорема Безу

**Остача від ділення P(x) на (x − a) дорівнює P(a).**

**Чому:** P(x) = (x − a)·Q(x) + R, де R — число (степінь менший за 1). Підставимо x = a: перший доданок перетворюється на нуль, лишається P(a) = R.

Перевірка на прикладі: P(2) = 16 − 12 + 8 − 5 = 7 ✓.

**Наслідок (дуже важливий):** **a — корінь многочлена ⇔ P ділиться на (x − a) без остачі.** Знайшовши один корінь, можна поділити й понизити степінь — так розв'язують кубічні рівняння.

**Цілі корені:** якщо всі коефіцієнти цілі й старший коефіцієнт 1, то цілий корінь — дільник вільного члена. Бо P(a) = 0 ⇒ вільний член = −a·(…ціле…). Для x³ − 6x² + 11x − 6 кандидати ±1, ±2, ±3, ±6; P(1) = 0.

### 6.4. Схема Горнера — швидке ділення на (x − a)

Записуємо коефіцієнти в рядок; перший зносимо; далі «помнож на a, додай наступний».

Ділимо 2x³ − 3x² + 4x − 5 на x − 2 (a = 2):

| | 2 | −3 | 4 | −5 |
|---|---|---|---|---|
| a = 2 | 2 | 2·2 − 3 = 1 | 1·2 + 4 = 6 | 6·2 − 5 = **7** |

Нижній рядок: коефіцієнти частки 2, 1, 6 (тобто 2x² + x + 6) і остача 7.

**Звідки схема.** Запишемо многочлен «матрьошкою»: 2x³ − 3x² + 4x − 5 = ((2x − 3)x + 4)x − 5. Обчислення значення при x = 2 зсередини назовні — це рівно ті самі кроки «помнож і додай». Тому схема Горнера одночасно обчислює P(a) і дає частку. Це також найшвидший спосіб обчислювати многочлен у програмі: n множень замість ~n²/2.

## 7. Тотожності й рівність многочленів

Два многочлени **тотожно рівні** (рівні при всіх x), якщо після зведення до стандартного вигляду в них однакові коефіцієнти при однакових степенях. Звідси **метод невизначених коефіцієнтів**: щоб знайти a, b з умови x² + ax + 6 ≡ (x + 2)(x + b), розкриваємо праворуч x² + (2 + b)x + 2b і прирівнюємо: 2b = 6, 2 + b = a ⇒ b = 3, a = 5.

**Чому коефіцієнти мусять збігатися:** різниця двох таких многочленів має безліч коренів, а ненульовий многочлен степеня n має не більше n коренів. Отже різниця — нульовий многочлен.

## 8. Типові помилки

| Помилка | Правильно |
|---|---|
| 3x² + 2x = 5x³ | не подібні — не додаються |
| x²·x³ = x⁶ | x⁵ (показники додаються) |
| (x²)³ = x⁵ | x⁶ (показники множаться) |
| −(2x − 5) = −2x − 5 | −2x + 5 |
| (x + 3)(x + 4) = x² + 12 | x² + 7x + 12 (забули «перехресні» члени) |
| (−2x)² = −4x² | 4x² |
| −2x² при x = −3 дорівнює 36 | −18: степінь лише на x, мінус залишається |
| Степінь 3x²y⁴ — 4 | 6 (сума показників) |
| Ділення кутом: забули член 0·x² | пропущені степені записувати з нулем |
