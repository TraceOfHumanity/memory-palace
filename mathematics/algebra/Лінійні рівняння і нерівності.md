# Лінійні рівняння і нерівності

**Лінійне рівняння** з однією змінною зводиться до вигляду **ax = b** (або ax + b = 0). «Лінійне», бо графік y = ax + b — пряма лінія. Це найпростіший і найважливіший тип рівнянь: майже кожне складніше рівняння розв'язують, зводячи його крок за кроком до лінійних.

**Лінійна нерівність** — те саме зі знаком <, >, ≤, ≥ замість =. Розв'язок — уже не одне число, а цілий проміжок.

## 1. Що означає «розв'язати рівняння»

Рівняння — це **питання**: «при яких x ліва частина дорівнює правій?» **Корінь** — число, яке робить рівність правильною. Розв'язати — знайти **всі** корені або довести, що їх немає.

3x + 5 = 20: при x = 5 маємо 15 + 5 = 20 ✓ — корінь. При x = 4: 17 ≠ 20.

## 2. Кілька способів думати про розв'язування

| Модель | Як виглядає 3x + 5 = 20 | Що таке «крок розв'язання» |
|---|---|---|
| **Терези** | на лівій шальці 3 однакові коробки і 5 гир, на правій 20 гир; терези в рівновазі | з обох шальок прибрати або додати однакове — рівновага не порушиться |
| **Обернені дії («розмотування»)** | з x зробили: «помножили на 3», «додали 5», вийшло 20 | іти назад: 20 − 5 = 15, 15 : 3 = 5 |
| **Стрілковий ланцюжок** | x —(·3)→ 3x —(+5)→ 20 | обернути кожну стрілку: 20 —(−5)→ 15 —(:3)→ 5 |
| **Смужкова модель** | смужка з трьох однакових частин і шматка 5 має довжину 20 | прибрати шматок 5, поділити решту 15 на 3 частини |
| **Графік** | де пряма y = 3x + 5 перетинає горизонталь y = 20 | x-координата точки перетину |
| **Підбір і уточнення** | спробувати x = 4 (17 — мало), x = 6 (23 — багато) | звужувати, поки не влучимо |

**Терези** пояснюють, чому розв'язання правильне. **Обернені дії** — найшвидший спосіб для рівнянь, де x трапляється один раз. **Графік** показує, скільки буває коренів.

## 3. Рівносильні перетворення

Рівняння **рівносильні**, якщо мають однакові корені. Ці дії дають рівносильне рівняння:

1. **Додати (відняти) одне й те саме** до обох частин. На практиці — **перенести доданок в іншу частину з протилежним знаком**: 3x + 5 = 20 ⇔ 3x = 20 − 5.
2. **Помножити (поділити) обидві частини на одне й те саме ненульове число.**
3. **Замінити вираз тотожно рівним**: розкрити дужки, звести подібні.

**Чому не можна множити на нуль:** 0 = 0 правильне при будь-якому x — усі корені «злипаються», інформація втрачається.

**Чому обережно з діленням на вираз зі змінною:** x² = 3x; поділимо на x ⇒ x = 3. Але загубили корінь x = 0! Правильно: x² − 3x = 0 ⇒ x(x − 3) = 0 ⇒ x = 0 або x = 3.

## 4. Рівняння ax = b — три випадки

| Випадок | Розв'язок | Приклад | Графічно |
|---|---|---|---|
| a ≠ 0 | рівно один корінь x = b/a | 4x = 12 ⇒ x = 3 | похила пряма перетинає вісь один раз |
| a = 0, b ≠ 0 | коренів немає | 0·x = 5 | горизонтальна пряма, паралельна осі |
| a = 0, b = 0 | будь-яке x | 0·x = 0 | пряма збігається з віссю |

Другий і третій випадки виникають після спрощення: 2(x + 3) = 2x + 1 ⇒ 6 = 1 — коренів немає. 3(x − 1) + x = 4x − 3 ⇒ 0 = 0 — тотожність, підходить будь-яке x.

## 5. Алгоритм

1. Позбутися знаменників: помножити на НСК знаменників.
2. Розкрити дужки.
3. Члени з x — ліворуч, числа — праворуч.
4. Звести подібні: ax = b.
5. Поділити на a (якщо a ≠ 0).
6. **Перевірити** підстановкою.

### 5.1. Ключовий приклад трьома способами

$$\frac{x-1}{3}-\frac{x+2}{4}=1$$

**Спосіб 1. Помножити на НСК(3, 4) = 12:**
4(x − 1) − 3(x + 2) = 12 ⇒ 4x − 4 − 3x − 6 = 12 ⇒ x − 10 = 12 ⇒ **x = 22**.

**Спосіб 2. Звести до спільного знаменника без множення:**
(4(x − 1) − 3(x + 2))/12 = 1 ⇒ (x − 10)/12 = 1 ⇒ x − 10 = 12 ⇒ x = 22.

**Спосіб 3. Графік / підбір.** Ліва частина — лінійна функція (x − 10)/12. Вона дорівнює 1, коли x − 10 = 12. Навіть без перетворень: при x = 10 ліва частина 0, і кожне збільшення x на 12 додає 1.

**Перевірка:** (22 − 1)/3 − (22 + 2)/4 = 7 − 6 = 1 ✓.

**Типова помилка в способі 1:** −3(x + 2) = −3x **− 6**, а не −3x + 2 чи −3x + 6. Мінус і множник застосовуються до кожного члена дужки.

## 6. Рівняння з параметром

**Параметр** — буква, яка позначає «якесь фіксоване число». Відповідь залежить від нього.

(a − 2)x = a² − 4:
- a ≠ 2: x = (a² − 4)/(a − 2) = a + 2.
- a = 2: 0·x = 0 — будь-яке x.

Такі задачі вчать головного: **не ділити, не перевіривши, що дільник не нуль.**

## 7. Формули — теж рівняння

Виразити змінну з формули — та сама техніка обернених дій.

- v = s/t ⇒ s = vt ⇒ t = s/v.
- F = 1,8C + 32 ⇒ C = (F − 32)/1,8. При F = 98,6: C = 37.
- S = (a + b)h/2 ⇒ h = 2S/(a + b).

## 8. Лінійні нерівності

### 8.1. Що змінюється порівняно з рівняннями

Усі перетворення ті самі, крім одного: **при множенні або діленні на від'ємне число знак нерівності змінюється на протилежний.**

### 8.2. Чому знак перевертається — три пояснення

1. **Числова пряма:** множення на −1 — дзеркальне відображення відносно нуля. 2 < 5: точка 2 лівіше за 5. Після відображення −2 правіше за −5: −2 > −5. Порядок перевертається.
2. **Перенесення доданків:** −2x > 6. Перенесемо: −6 > 2x, тобто 2x < −6, x < −3. Знак не перевертали — просто переставили частини, і результат той самий.
3. **Перевірка числом:** −2x > 6. Візьмемо x = −5: 10 > 6 ✓. Візьмемо x = 0: 0 > 6 ✗. Отже розв'язки — «маленькі» x: x < −3. Якби ми не перевернули знак, отримали б x > −3 — і x = 0 мав би підійти.

### 8.3. Відповідь — проміжок

3x − 7 ≤ 2 ⇒ 3x ≤ 9 ⇒ x ≤ 3. Відповідь: **(−∞; 3]**.

```
 ═══════════════●
 ───────────────┼──────► x
                3
```

Квадратна дужка (зафарбована точка) — кінець входить, кругла (порожня точка) — не входить. Нескінченність завжди з круглою дужкою: це не число, до неї не можна «дійти».

### 8.4. Особливі випадки

- 0·x < 5 — правильна при будь-якому x: (−∞; +∞).
- 0·x > 5 — розв'язків немає: ∅.
- 0·x ≥ 0 — будь-яке x; 0·x > 0 — розв'язків немає.

### 8.5. Подвійні нерівності й системи

**Подвійна:** −3 < 2x + 1 ≤ 7. Віднімаємо 1 від усіх трьох частин: −4 < 2x ≤ 6. Ділимо на 2: −2 < x ≤ 3. Відповідь (−2; 3].

**Система** (усі нерівності одночасно) — **перетин** розв'язків:
{ 2x − 1 > 3, x + 4 ≤ 10 } ⇒ { x > 2, x ≤ 6 } ⇒ (2; 6].

**Сукупність** («або») — **об'єднання**: x < −1 або x > 4 ⇒ (−∞; −1) ∪ (4; +∞).

```
система:     ○═══════════●
          ───┼───────────┼──► x
             2           6
```

Якщо проміжки не перетинаються — система розв'язків не має: { x < 1, x > 5 } ⇒ ∅.

## 9. Лінійні моделі в житті

- **Тарифи:** таксі 40 грн за посадку + 15 грн/км. Ціна C = 40 + 15d. Скільки км за 250 грн? 40 + 15d ≤ 250 ⇒ d ≤ 14.
- **Порівняння тарифів:** план А: 200 грн + 2 грн/хв; план Б: 5 грн/хв. Б вигідніший, поки 5t < 200 + 2t ⇒ t < 66⅔ хв.
- **Точка беззбитковості:** постійні витрати 12 000, собівартість одиниці 30, ціна 50. Прибуток 50n − 30n − 12 000 ≥ 0 ⇒ n ≥ 600.
- **Середній бал:** оцінки 8, 9, 7, x. Щоб середнє було ≥ 8,5: (24 + x)/4 ≥ 8,5 ⇒ x ≥ 10.

Детальніше про складання рівнянь — [[Текстові задачі]].

## 10. Типові помилки

| Помилка | Правильно |
|---|---|
| Перенесли доданок без зміни знака | 3x + 5 = 20 ⇒ 3x = 20 **− 5** |
| 2(x − 3) = 2x − 3 | 2x − 6 |
| Помножили на 12 лише один член | множити **всі** члени обох частин |
| −2x > 6 ⇒ x > −3 | x < −3 |
| 0·x = 5 ⇒ x = 0 | коренів немає |
| Поділили на x і загубили корінь 0 | виносити x за дужки |
| x ≤ 3 ⇒ відповідь (−∞; 3) | (−∞; 3] |
| Система: об'єднали проміжки | система — перетин |
| [−∞; 3] | (−∞; 3] — нескінченність завжди з круглою |
