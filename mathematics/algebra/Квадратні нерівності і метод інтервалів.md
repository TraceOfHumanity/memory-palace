# Квадратні нерівності і метод інтервалів

**Квадратна нерівність** — нерівність вигляду ax² + bx + c > 0 (або <, ≥, ≤), a ≠ 0. На відміну від лінійної, тут не можна просто «перенести і поділити»: знак квадратного тричлена змінюється не один раз, а до двох. Розв'язок — один проміжок, два промені, вся пряма або порожня множина.

**Метод інтервалів** — загальний спосіб розв'язувати нерівності, в яких вираз розкладено на множники або записано дробом: (x − 1)(x + 2)(x − 5) < 0, (x + 3)/(x − 4) ≥ 0. Квадратні нерівності — його окремий випадок.

## 1. Головна ідея: знак змінюється лише в нулях

Многочлен — неперервна функція: його графік можна намалювати не відриваючи олівця. Щоб перейти від додатних значень до від'ємних, графік **мусить перетнути вісь Ox**, тобто пройти через нуль. Тому:

**Між сусідніми коренями многочлен зберігає знак.** Досить знайти корені й перевірити знак на кожному проміжку однією точкою.

Для дробу знак може змінюватися ще й у точках, де знаменник дорівнює нулю (там графік «рветься»).

## 2. Кілька способів розв'язати x² − x − 6 < 0

### 2.1. Парабола

Корені: x² − x − 6 = (x − 3)(x + 2) ⇒ −2 і 3. a = 1 > 0 — гілки вгору. Парабола нижче осі (значення < 0) **між** коренями.

```
  y
   \           /
    \         /
 ────*───────*────► x
    −2\_____/3
       < 0
```

Відповідь: (−2; 3).

### 2.2. Метод інтервалів

Нулі −2 і 3 ділять пряму на три проміжки. Беремо пробну точку в кожному:

| Проміжок | Пробна точка | x − 3 | x + 2 | Добуток |
|---|---|---|---|---|
| (−∞; −2) | −3 | − | − | + |
| (−2; 3) | 0 | − | + | − |
| (3; +∞) | 4 | + | + | + |

```
     +          −          +
 ────────○──────────○────────► x
        −2          3
```

Потрібні «−»: (−2; 3).

### 2.3. Логіка знаків добутку

(x − 3)(x + 2) < 0 ⇔ множники різних знаків:
- x − 3 > 0 і x + 2 < 0 ⇒ x > 3 і x < −2 — неможливо;
- x − 3 < 0 і x + 2 > 0 ⇒ −2 < x < 3.

### 2.4. Повний квадрат і модуль

x² − x − 6 = (x − 1/2)² − 25/4 < 0 ⇔ (x − 1/2)² < 25/4 ⇔ |x − 1/2| < 5/2 ⇔ x ближче ніж на 5/2 до 1/2 ⇒ (−2; 3). Цей спосіб показує, що розв'язок — **окіл центру параболи** (див. [[Модуль числа]]).

## 3. Шість картинок, які треба бачити

Для a > 0 (гілки вгору); для a < 0 варто помножити нерівність на −1 і перевернути знак.

| D | Графік | ax² + bx + c > 0 | ax² + bx + c < 0 |
|---|---|---|---|
| D > 0, корені x₁ < x₂ | перетинає вісь двічі | (−∞; x₁) ∪ (x₂; +∞) — **зовні** | (x₁; x₂) — **між** |
| D = 0, корінь x₀ | торкається осі | усі x, крім x₀ | ∅ |
| D < 0 | вся над віссю | (−∞; +∞) | ∅ |

**Пам'ятка:** при a > 0 «більше нуля» — **за коренями**, «менше нуля» — **між коренями**.

Для нестрогих нерівностей (≥, ≤) корені додаються до відповіді: x² − x − 6 ≤ 0 ⇒ [−2; 3]. При D = 0: x² − 4x + 4 ≤ 0 ⇔ (x − 2)² ≤ 0 ⇔ x = 2 — одна точка. x² − 4x + 4 ≥ 0 — будь-яке x.

## 4. Метод інтервалів у загальному вигляді

### 4.1. Алгоритм

1. Перенести все в один бік: **f(x) ∨ 0** (∨ — один зі знаків <, >, ≤, ≥).
2. Розкласти чисельник і знаменник на множники.
3. Знайти нулі чисельника й знаменника. Нулі знаменника — **завжди виколоті** (порожні точки).
4. Нанести на пряму, визначити знак на кожному проміжку.
5. Вибрати проміжки з потрібним знаком; для нестрогої нерівності додати нулі чисельника.

### 4.2. Швидке правило чергування

Якщо всі множники вигляду (x − a) у **першому** степені, і старший коефіцієнт додатний, на крайньому правому проміжку знак «+», а далі знаки **чергуються** при переході через кожен нуль.

**Чому:** праворуч від усіх нулів кожен множник (x − a) додатний. Переходячи через a ліворуч, лише один множник змінює знак — отже, змінюється знак добутку.

### 4.3. Кратні корені — знак не змінюється

Множник у **парному** степені, наприклад (x − 1)², при переході через 1 знака не змінює: квадрат невід'ємний з обох боків. У непарному степені — змінює.

**Приклад:** (x − 1)²(x + 3) > 0.

```
     −          +          +
 ────────○──────────○────────► x
        −3          1
```

Відповідь: (−3; 1) ∪ (1; +∞). Точка 1 виключена, бо там добуток дорівнює 0, а нерівність строга.

### 4.4. Дробові нерівності

(x + 3)/(x − 4) ≥ 0.

- Нулі чисельника: −3 (входить, бо ≥). Нуль знаменника: 4 (виключений завжди).
- Знаки: праворуч від 4 «+», між −3 і 4 «−», ліворуч від −3 «+».
- Відповідь: (−∞; −3] ∪ (4; +∞).

**Чому не можна просто помножити на знаменник:** знак x − 4 невідомий — при множенні на від'ємне треба перевертати знак нерівності. Метод інтервалів обходить цю проблему. Знак дробу A/B такий самий, як знак добутку A·B, тому (x + 3)/(x − 4) ≥ 0 ⇔ (x + 3)(x − 4) ≥ 0 при x ≠ 4.

**Класична помилка:** 1/x < 1 ⇒ 1 < x. Неправильно: при x = −5 нерівність 1/(−5) < 1 правильна. Правильно: 1/x − 1 < 0 ⇒ (1 − x)/x < 0 ⇒ (−∞; 0) ∪ (1; +∞).

## 5. Нерівності з параметром і застосування

### 5.1. «При яких m нерівність виконується для всіх x»

x² + mx + 4 > 0 для всіх x ⇔ парабола з гілками вгору повністю над віссю ⇔ D < 0 ⇔ m² − 16 < 0 ⇔ −4 < m < 4.

### 5.2. Область визначення

√(6 + x − x²) існує ⇔ 6 + x − x² ≥ 0 ⇔ x² − x − 6 ≤ 0 ⇔ [−2; 3].

### 5.3. Задачі з життя

- **Висота м'яча** h = 20t − 5t². Коли він вище 15 м? 20t − 5t² > 15 ⇔ t² − 4t + 3 < 0 ⇔ 1 < t < 3 — дві секунди.
- **Прибуток** P = −q² + 50q − 400 > 0 ⇔ q² − 50q + 400 < 0 ⇔ 10 < q < 40 — випуск, при якому фірма в плюсі.
- **Гальмівний шлях** s = 0,2v + 0,005v². Щоб s ≤ 40 м: 0,005v² + 0,2v − 40 ≤ 0 ⇒ v ≤ 72,1 км/год.

## 6. Типові помилки

| Помилка | Правильно |
|---|---|
| x² < 9 ⇒ x < ±3 / x < 3 | −3 < x < 3 |
| x² > 9 ⇒ x > ±3 | x < −3 або x > 3 |
| a < 0, а знаки поставили як для a > 0 | спершу помножити на −1 і перевернути знак |
| Помножили на знаменник зі змінною | метод інтервалів |
| Нуль знаменника включили при ≥ | знаменник ≠ 0 — точка завжди виколота |
| Чергували знаки через (x − 1)² | через корінь парної кратності знак не змінюється |
| x² + 1 > 0 «не має розв'язків, бо D < 0» | D < 0 і a > 0 ⇒ виконується для всіх x |
| (x − 2)² > 0 ⇒ усі x | усі x, крім 2 |
