# Відповіді: вектори та матриці

1. a + b = (5; 4); 2a − b = (6 − 2; −2 − 5) = (4; −7); |a| = √(9 + 1) = √10 ≈ 3,16.
2. a·b = 3·2 + (−1)·5 = 1. |a| = √10, |b| = √29. cos φ = 1/(√10·√29) ≈ 0,0587 → φ ≈ 86,6°. (Майже прямий кут: скалярний добуток близький до 0.)
3. 4x + 3·6 = 0 → 4x = −18 → x = −4,5.
4. proj = (a·b / a·a)·a = (1/10)·(3; −1) = (0,3; −0,1).
5. (2;0;1) × (1;3;−1) = (0·(−1) − 1·3 ; 1·1 − 2·(−1) ; 2·3 − 0·1) = (−3; 3; 6). Перевірка: (−3; 3; 6)·(2; 0; 1) = −6 + 0 + 6 = 0 ✓.
6. (5; 4) = 5·î + 4·ĵ. У базисі u, w: c₁(1,1) + c₂(1,−1) = (5,4): c₁ + c₂ = 5, c₁ − c₂ = 4 → c₁ = 4,5, c₂ = 0,5. Тобто (5; 4) = 4,5·u + 0,5·w.
7. По рядках: (1·3 + 2·2; 0·3 + 1·2) = (7; 2). По стовпцях: 3·(1; 0) + 2·(2; 1) = (3; 0) + (4; 2) = (7; 2) ✓.
8. AB = [[2, 1], [4, 3]]; BA = [[3, 4], [1, 2]]. Не збігаються (множення не комутативне). B міняє місцями стовпці (коли справа) або рядки (коли зліва).
9. det = 3·4 − 1·2 = 10. A⁻¹ = (1/10)·[[4, −1], [−2, 3]].
10. A = [[3,1],[1,2]], det = 5, A⁻¹ = (1/5)[[2, −1], [−1, 3]]. x = A⁻¹(7; 4) = (1/5)(14 − 4 ; −7 + 12) = (2; 1). Перевірка: 6 + 1 = 7 ✓; 2 + 2 = 4 ✓.
11. R·(3; 1) = (−1; 3). R² = [[−1, 0], [0, −1]] = −I (поворот на 180°).
12. det = 2·2 − 4·1 = 0 — матриця вироджена, оберненої немає. Вона «розплющує» площину в пряму (стовпці колінеарні).
13. Слід 7, det = 12 − 2 = 10 → λ² − 7λ + 10 = 0 → λ = 5 та 2. Для λ = 5: (A − 5I)v = 0 → −v₁ + v₂ = 0 → v = (1; 1). Для λ = 2: 2v₁ + v₂ = 0 → v = (1; −2). Перевірка: A(1;1) = (5;5) ✓; A(1;−2) = (2;−4) = 2(1;−2) ✓.
14. Приклад:
```js
function normalize([x, y]) {
  const len = Math.hypot(x, y);
  return len < 1e-12 ? [0, 0] : [x / len, y / len];
}
```
Ключове: перевірка len ≈ 0 (допуск, а не == 0), інакше ділення на нуль дасть NaN.
