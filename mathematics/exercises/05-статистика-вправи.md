# Вправи: статистика, розподіли, регресія

Відповіді: `05-статистика-відповіді.md`. Відео: `distributions`, `inference`, `regression`.

## Описова статистика
1. Дані 2, 4, 4, 4, 5, 5, 7, 9. Знайдіть середнє, дисперсію й стандартне відхилення (як для всієї сукупності), а також вибіркову дисперсію s² і s.
2. IQ ~ N(100; 15). Знайдіть z-значення для 130 та 85. Яка частка людей приблизно між 85 і 115?

## Розподіли
3. Монету підкидають 5 разів. Імовірність рівно 2 орлів? Сподівання і дисперсія кількості орлів?
4. Кількість запитів за секунду ~ Пуассон, λ = 2. Імовірність жодного запиту за секунду?
5. Тест хибно спрацьовує у 10 % випадків. Запускаємо 10 незалежних тестів. Імовірність хоча б одного хибного спрацювання?
6. Кубик кидають до першої шістки. Скільки кидків у середньому?

## Висновки
7. x̄ = 80, s = 12, n = 36. Побудуйте 95 % довірчий інтервал (z = 1,96).
8. Монета: 55 орлів зі 100. Чи дають підстави відхилити H₀ «монета чесна» при α = 0,05? Обчисліть z та p приблизно.
9. 20 незалежних тестів при α = 0,05 без реального ефекту. Яка ймовірність хоча б одного «значущого» результату? Що з цим робити?
10. Як зміниться ширина довірчого інтервалу, якщо n збільшити вчетверо?

## Регресія
11. Точки (1; 1), (2; 3), (3; 2), (4; 5). Знайдіть пряму найменших квадратів y = a + bx та коефіцієнт кореляції (приблизно).
12. Нахил регресії b = 0,9, x̄ = 3, ȳ = 4. Знайдіть a і прогноз при x = 6. Чому прогноз при x = 100 ненадійний?
13. Продажі морозива сильно корелюють із кількістю випадків утоплення. Чи означає це, що морозиво спричиняє утоплення? Поясніть.
14. (Код) Напишіть функцію, що рахує вибіркове середнє й вибіркове стандартне відхилення без бібліотек.
