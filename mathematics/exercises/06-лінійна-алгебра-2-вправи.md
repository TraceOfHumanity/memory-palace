# Вправи: метод Гауса, ранг, SVD, PCA

Відповіді: `06-лінійна-алгебра-2-відповіді.md`. Відео: `gauss`, `svdpca`.

1. Розв'яжіть методом Гауса: x + 2y + z = 8; 2x − y + z = 3; x + y − z = 0. Перевірте підстановкою.
2. Скільки розв'язків має система x + y = 2, 2x + 2y = 4? А x + y = 2, 2x + 2y = 5? Що з рангами?
3. Знайдіть ранг матриці [[1, 2], [2, 4], [3, 6]] та [[1, 2, 3], [4, 5, 6], [7, 8, 9]].
4. Знайдіть обернену до [[1, 2], [3, 5]] методом Гауса–Жордана [A | I].
5. Матриця 4×6 має ранг 3. Яка розмірність нуль-простору? Яка розмірність простору стовпців?
6. Знайдіть нуль-простір матриці [[1, 1], [1, 1]].
7. Чи оборотна матриця [[1, 2, 3], [4, 5, 6], [7, 8, 9]]? Чому?
8. Знайдіть сингулярні числа матриці diag(3; −2).
9. Для A = [[2, 1], [1, 2]]: власні числа, діагоналізація A = PDP⁻¹, а також A¹⁰ (запишіть формулою).
10. Дані мають матрицю коваріації з власними числами 5,15 та 0,15. Яка частка дисперсії припадає на першу компоненту? Скільки компонент залишити?
11. Чому перед PCA потрібно центрувати й масштабувати дані? Що буде, якщо ознаки в різних одиницях?
12. (Код) У numpy знайдіть розв'язок системи з п. 1, ранг матриці та сингулярні числа без явного обчислення оберненої матриці.
