1. Розширена [[1,2,1|8],[2,−1,1|3],[1,1,−1|0]]. R₂ − 2R₁ → (0,−5,−1 | −13); R₃ − R₁ → (0,−1,−2 | −8). R₃ − R₂/5 → (0, 0, −2 + 1/5 | −8 + 13/5) = (0, 0, −9/5 | −27/5) → z = 3. З −5y − 3 = −13 → y = 2. x = 8 − 4 − 3 = 1. Відповідь (1; 2; 3). Перевірка: 1 + 4 + 3 = 8 ✓; 2 − 2 + 3 = 3 ✓; 1 + 2 − 3 = 0 ✓.
2. Перша: безліч розв'язків (другий рівняння = 2·перше; rank A = rank [A|b] = 1 < 2). Друга: немає (rank A = 1, rank [A|b] = 2 — суперечність 0 = 1).
3. Перша: ранг 1 (усі рядки кратні (1; 2)). Друга: ранг 2 (третій рядок = 2·другий − перший).
4. [1 2 | 1 0; 3 5 | 0 1]. R₂ − 3R₁ → (0, −1 | −3, 1). R₂·(−1) → (0, 1 | 3, −1). R₁ − 2R₂ → (1, 0 | 1 − 6, 0 + 2) = (1, 0 | −5, 2). Обернена [[−5, 2], [3, −1]]. Перевірка det = 5 − 6 = −1 і формулою (1/(−1))·[[5, −2], [−3, 1]] = [[−5, 2], [3, −1]] ✓.
5. Нуль-простір: 6 − 3 = 3. Простір стовпців: розмірність 3 (= ранг).
6. x + y = 0 → x = −y: нуль-простір = {t·(1; −1)}, пряма розмірності 1 (rank = 1, nullity = 2 − 1).
7. Ні: ранг 2 < 3, det = 0 (третій рядок = 2·другий − перший).
8. σ = 3 та 2 (модулі діагональних елементів; знак поглинається ортогональною матрицею).
9. λ = 3 та 1 (власні вектори (1; 1) та (1; −1)). P = [[1,1],[1,−1]], D = diag(3, 1), A = PDP⁻¹. A¹⁰ = P·diag(3¹⁰, 1)·P⁻¹ = P·diag(59049, 1)·P⁻¹.
10. 5,15/(5,15 + 0,15) = 5,15/5,3 ≈ 97,2 %. Достатньо однієї компоненти.
11. Центрування — бо інакше перша компонента вказуватиме на середнє, а не на напрям розкиду; масштабування — бо ознака з великими числами (зарплата в гривнях проти віку) домінує в дисперсії й «захоплює» всі компоненти.
