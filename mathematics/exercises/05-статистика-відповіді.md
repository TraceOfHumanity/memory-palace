```js
function stats(a) {
  const n = a.length, m = a.reduce((s, x) => s + x, 0) / n;
  const s2 = a.reduce((s, x) => s + (x - m) ** 2, 0) / (n - 1);
  return {mean: m, sd: Math.sqrt(s2)};
}
```
Ділення на n − 1 — вибіркова (незміщена) оцінка дисперсії.
