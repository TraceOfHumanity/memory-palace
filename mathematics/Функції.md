# Функції

Числові приклади перевірені обчисленням (Python).

---

## 1. Що таке функція
**Функція** — правило, яке **кожному** допустимому входу ставить у відповідність **рівно один** вихід. Позначення: `f: X → Y`, `y = f(x)`.
- **x** — аргумент (вхід, незалежна змінна), **y** — значення (вихід, залежна змінна).
- **Область визначення D(f)** (domain) — множина допустимих входів.
- **Область значень E(f)** (range) — множина виходів, які справді трапляються. Не плутати з **кодоменом** Y — «куди дозволено потрапляти».
- Ключ: «рівно один вихід». Одному входу не можуть відповідати два виходи. Різним входам **можуть** відповідати однакові виходи (x² дає 4 і при x = 2, і при x = −2).

**Для програміста:** функція в математиці — це **чиста функція** (pure function): без побічних ефектів, той самий вхід завжди дає той самий вихід. Область визначення — це типи/умови вхідних даних; помилка «ділення на нуль» = вхід поза областю визначення. Область значень — реальні виходи; кодомен — тип результату.

Образ: «машина» — кидаємо x, отримуємо f(x). Без пам'яті й випадковості.

## 2. Чотири способи задати функцію
1. **Формулою:** f(x) = 2x + 1.
2. **Таблицею:** x: −2, −1, 0, 1, 2 → x²: 4, 1, 0, 1, 4.
3. **Графіком:** множина точок (x; f(x)) на площині.
4. **Словесно / алгоритмом (кодом):** «квадрат числа», `function f(x){ return 2*x+1 }`.
Усі чотири — той самий об'єкт у різних «одягах». Вміння перемикатися між ними — основа розуміння.

## 3. Область визначення — як знаходити
Що заборонено:
1. **Ділення на нуль:** f(x) = 1/(x − 2) → x ≠ 2. D = (−∞; 2) ∪ (2; +∞).
2. **Корінь парного степеня з від'ємного:** f(x) = √(x − 1) → x − 1 ≥ 0 → x ≥ 1. D = [1; +∞).
3. **Логарифм від невід'ємного:** log(x) → x > 0.
4. tg x, не визначений при x = π/2 + πk.
Алгоритм: виписати всі обмеження (знаменник ≠ 0, підкореневий ≥ 0, аргумент log > 0), розв'язати разом (перетин).
Приклад: f(x) = √(x − 1)/(x − 3): x ≥ 1 і x ≠ 3 → [1; 3) ∪ (3; +∞).

## 4. Графік і тест вертикальної прямої
- Графік функції = усі точки (x; f(x)).
- **Тест вертикальної прямої:** крива є графіком функції ⇔ кожна вертикальна пряма перетинає її не більше ніж в одній точці (бо кожному x — один y).
- Коло x² + y² = 1 — **не** функція y(x) (дві точки при одному x). Але верхня півколо y = √(1 − x²) — функція.

## 5. Корисні властивості
- **Нулі функції:** x, де f(x) = 0 (графік перетинає вісь x). Розв'язуємо рівняння f(x) = 0.
- **Знакосталість:** де f > 0, де f < 0.
- **Монотонність:** зростає, якщо x₁ < x₂ ⇒ f(x₁) < f(x₂); спадає — навпаки. x² спадає на (−∞; 0], зростає на [0; +∞).
- **Парність:** f(−x) = f(x) — парна, графік симетричний відносно осі y (x², |x|, cos x). f(−x) = −f(x) — непарна, симетрія відносно початку (x³, sin x, 1/x). Інакше — ні та, ні інша: h(x) = x² + x: h(2) = 6, h(−2) = 2 — не збігається ні з h(2), ні з −h(2).
- **Періодичність:** f(x + T) = f(x) (sin x, T = 2π).
- **Обмеженість:** є ліміт зверху/знизу (sin x ∈ [−1; 1]).
- **Екстремуми:** найбільше/найменше значення (локальні та глобальні).

## 6. Ін'єкція, сюр'єкція, бієкція
- **Ін'єкція (один-до-одного):** різним x — різні y. x³ — так; x² — ні (f(2) = f(−2) = 4). Горизонтальний тест: будь-яка горизонтальна пряма перетинає графік не більше одного разу.
- **Сюр'єкція («на»):** кожне значення з кодомену досягається.
- **Бієкція:** і те, і інше. Лише бієкція має обернену функцію.
Для програміста: ін'єкція — «хеш без колізій»; бієкція — оборотне кодування (шифрування без втрати даних).

## 7. Композиція функцій
`(f ∘ g)(x) = f(g(x))` — спершу g, потім f. Порядок справа наліво.
Приклад: f(x) = 2x + 1, g(x) = x².
- (f∘g)(x) = f(x²) = 2x² + 1; при x = 3: 19.
- (g∘f)(x) = (2x + 1)²; при x = 3: 49. Різні! Композиція **не комутативна**.
- Асоціативна: (f∘g)∘h = f∘(g∘h). Тотожна функція id(x) = x — «одиниця» композиції.
- Область визначення: x має бути в D(g), і g(x) має бути в D(f).
Для програміста: конвеєр `pipe`, `map(g).map(f)`, middleware — композиція функцій.

## 8. Обернена функція
`f⁻¹` скасовує f: f⁻¹(f(x)) = x і f(f⁻¹(y)) = y. Існує **тільки** для бієкції (ін'єктивної функції на її області значень).
- Алгоритм: 1) запиши y = f(x); 2) виразь x через y; 3) поміняй позначення x ↔ y.
- f(x) = 2x + 1 → y = 2x + 1 → x = (y − 1)/2 → f⁻¹(x) = (x − 1)/2. Перевірка: f⁻¹(f(5)) = f⁻¹(11) = 5 ✓; f(f⁻¹(7)) = f(3) = 7 ✓.
- x² не оборотна на всій прямій (неін'єктивна), але на [0; +∞) обернена — √x.
- **Графіки f та f⁻¹ симетричні відносно прямої y = x** (бо обернена міняє x і y місцями).
- Пари взаємно обернених: a^x ↔ logₐ x; x² (x ≥ 0) ↔ √x; sin (на [−π/2; π/2]) ↔ arcsin.

## 9. Перетворення графіків (від y = f(x))
| Дія | Результат |
|---|---|
| f(x − a) | зсув вправо на a |
| f(x) + b | зсув вгору на b |
| −f(x) | відбиття відносно осі x |
| f(−x) | відбиття відносно осі y |
| k·f(x), k > 1 | розтяг по вертикалі в k разів |
| f(kx), k > 1 | стиск по горизонталі в k разів |
| \|f(x)\| | відбиття від'ємних частин угору |
Пояснення «контрінтуїтивного»: f(x − a) = те саме значення, яке f мала в точці x − a, тепер — у x; тому графік зсунувся вправо.

## 10. Функція не лише числа
Функція може приймати і повертати що завгодно: рядки, множини, вектори. `length("abc") = 3`; матриця — функція вектор→вектор; ймовірність P — функція подій у [0; 1]. Узагальнення: **відображення**.

## 11. Каталог основних функцій
| Функція | D | E | Форма |
|---|---|---|---|
| y = kx + b | ℝ | ℝ (k ≠ 0) | пряма |
| y = x² | ℝ | [0; ∞) | парабола |
| y = x³ | ℝ | ℝ | кубічна, непарна |
| y = 1/x | x ≠ 0 | y ≠ 0 | гіпербола, непарна |
| y = √x | [0; ∞) | [0; ∞) | піввітка параболи |
| y = \|x\| | ℝ | [0; ∞) | «V» |
| y = aˣ | ℝ | (0; ∞) | експонента |
| y = logₐ x | (0; ∞) | ℝ | логарифм |
| y = sin x, cos x | ℝ | [−1; 1] | хвиля |
(Детальніше — окремі відео: лінійна, квадратична, степеневі, показникова, логарифм, тригонометрія.)

## 12. Функція як залежність у житті
- Шлях від часу s(t) = vt, ціна від кількості, температура від часу.
- Змінна-«причина» → аргумент; «наслідок» → значення.
- **Швидкість зміни** (нахил графіка) — початок похідної (математичний аналіз).

## Для програміста — зведення
- Область визначення = перевірка вхідних даних (guard); поза нею — помилка/NaN.
- Чиста функція vs функція з побічними ефектами: математична = чиста; тому зручно тестувати й комбінувати (мемоізація можлива, бо вхід → той самий вихід).
- Композиція — `compose(f, g)`, `pipe`; обернена функція — `encode`/`decode`.
- Графік = побудова за масивом точок: `for x in linspace: points.push([x, f(x)])`.
- Рекурсія — функція, що викликає саму себе.

## Типові помилки
1. «Функція — це завжди формула» (ні: таблиця, графік, алгоритм теж).
2. Забути область визначення (ділення на 0, корінь з від'ємного).
3. f(a + b) ≠ f(a) + f(b) загалом: (x + y)² ≠ x² + y²; f(x) — це **не** множення f на x.
4. Плутати f⁻¹ (обернена функція) і 1/f (обернене число): f⁻¹(x) ≠ 1/f(x).
5. Плутати порядок композиції: f∘g ≠ g∘f.
6. Зсув f(x − a) — вправо, а не вліво.
7. Вважати, що одне значення має один аргумент (неін'єктивні функції).
8. Вважати коло графіком функції.

## Алгоритм дослідження функції
1. Область визначення (обмеження).
2. Нулі й знакосталість.
3. Парність, періодичність.
4. Монотонність, екстремуми.
5. Область значень.
6. Особливі точки й поведінка на краях; побудова графіка.
7. Чи оборотна (горизонтальний тест)? Якщо так — знайти f⁻¹.
