# Електромагнітні коливання

**Коливальний контур** — конденсатор і котушка, з'єднані в замкнене коло. Якщо зарядити конденсатор і замкнути контур, заряд, струм і напруга почнуть періодично змінюватися: енергія перетікає з електричного поля конденсатора в магнітне поле котушки і назад. Це **електромагнітні коливання** — повний аналог коливань пружинного маятника. Період дає **формула Томсона** T = 2π√(LC). На коливальних контурах побудовані радіоприймачі, передавачі, генератори частоти, металошукачі.

## 1. Як виникають коливання в контурі

Зарядимо конденсатор C до заряду q₀ і замкнемо на котушку L (опір нехтовно малий). Покроково:

1. **t = 0.** Конденсатор заряджений, струму немає. Уся енергія — в **електричному** полі: q₀²/(2C).
2. Конденсатор починає розряджатися через котушку. Струм міг би зрости миттєво, але **самоіндукція** ([[Самоіндукція і енергія магнітного поля]]) гальмує його зростання. Струм наростає поступово.
3. **t = T/4.** Конденсатор розрядився (q = 0), струм **найбільший**. Уся енергія — в **магнітному** полі котушки: LI₀²/2.
4. Струм не може миттєво зникнути — котушка «підтримує» його (самоіндукція). Струм продовжує текти в тому самому напрямку і **перезаряджає** конденсатор з протилежною полярністю.
5. **t = T/2.** Конденсатор заряджений «навпаки», струм нуль. Енергія знову електрична.
6. Процес повторюється у зворотному напрямку; при t = T контур повертається у початковий стан.

Роль котушки — **інертність** струму (як маса тіла не дає зупинитися в рівновазі); роль конденсатора — **пружність** (як пружина повертає тіло).

## 2. Аналогія з пружинним маятником

| Пружинний маятник | Коливальний контур |
|---|---|
| зміщення x | заряд q |
| швидкість v = x′ | сила струму I = q′ |
| маса m | індуктивність L |
| жорсткість k | обернена ємність 1/C |
| потенціальна енергія kx²/2 | енергія конденсатора q²/(2C) |
| кінетична енергія mv²/2 | енергія котушки LI²/2 |
| T = 2π√(m/k) | T = 2π√(LC) |
| тертя | активний опір R |

Аналогія не випадкова: обидві системи описуються **тим самим рівнянням**. Для маятника ma = −kx, тобто x″ = −(k/m)x. Для контуру: напруга на котушці L·I′ дорівнює напрузі на конденсаторі з протилежним знаком −q/C, отже q″ = −q/(LC). Те саме рівняння a = −ω²x з **ω² = 1/(LC)** ([[Механічні коливання]]). Тому все, що ми знаємо про маятник, переноситься на контур без змін.

## 3. Формула Томсона і закони коливань

**ω₀ = 1/√(LC), T = 2π√(LC), ν = 1/(2π√(LC)).**

Закони зміни (від початку розряду):
- заряд: q = q₀ cos ω₀t;
- напруга: u = q/C = U₀ cos ω₀t, U₀ = q₀/C;
- струм: i = q′ = −q₀ω₀ sin ω₀t, амплітуда **I₀ = q₀ω₀**.

Струм **зсунутий за фазою** на чверть періоду (π/2) відносно заряду: коли заряд найбільший, струм нуль, і навпаки — як швидкість і зміщення маятника.

Приклад: L = 1 мГн, C = 10 нФ: T = 2π√(10⁻³ · 10⁻⁸) = 2π · 3,16·10⁻⁶ ≈ 2·10⁻⁵ с, ν ≈ 50 кГц.

Збільшення L або C **сповільнює** коливання (як важче тіло чи м'якша пружина). Радіоприймач налаштовують на станцію, змінюючи ємність конденсатора змінної ємності — частота контуру підлаштовується під частоту хвилі.

## 4. Енергія

Без опору повна енергія стала:

**W = q²/(2C) + LI²/2 = q₀²/(2C) = LI₀²/2 = CU₀²/2.**

З рівності максимальних енергій: I₀ = U₀√(C/L), q₀ = I₀√(LC). Енергії поля конденсатора і поля котушки коливаються з **подвоєною** частотою, у протифазі.

## 5. Згасання і автоколивання

Реальний контур має **активний опір** R — провідники нагріваються (закон Джоуля–Ленца), частина енергії випромінюється. Амплітуда поступово зменшується — **згасальні коливання**, як маятник з тертям. При великому опорі коливань немає зовсім — конденсатор просто розряджається.

Щоб коливання були **незгасальними**, енергію треба поповнювати «в такт». **Автоколивальна система** (генератор на транзисторі) сама керує підкачуванням енергії від джерела постійного струму: транзистор відкривається в потрібні моменти, як механізм годинника штовхає маятник щоразу в потрібній фазі. Так отримують коливання заданої частоти в радіопередавачах, комп'ютерах (тактова частота), кварцових годинниках.

## 6. Резонанс у контурі
Якщо на контур діє зовнішня змінна ЕРС частоти ν, амплітуда струму найбільша при ν = ν₀ = 1/(2π√(LC)) — **електричний резонанс**. Антена приймача отримує сигнали всіх станцій одночасно, але контур «відгукується» лише на ту, частота якої збігається з власною, — так працює **налаштування** радіо ([[Механічні коливання]]: резонанс; [[Змінний струм і трансформатор]]: опори в колі змінного струму).

## 7. Кілька способів зрозуміти

| Модель | Що вона показує |
|---|---|
| Пружинний маятник | Повна аналогія: L ↔ m, 1/C ↔ k, q ↔ x, I ↔ v |
| Перетікання енергії | Електричне поле ↔ магнітне поле, двічі за період |
| Інертність + пружність | Котушка не дає струму зупинитися, конденсатор повертає заряд |
| Одне рівняння | q″ = −q/(LC) — те саме, що x″ = −ω²x |
| Гойдалка з поштовхами | Автоколивання і резонанс — підживлення в такт |

### Ключовий приклад: контур приймача
Контур з котушкою 2 мкГн і конденсатором 20 пФ. Знайдіть частоту коливань. Яка довжина хвилі, на яку налаштований приймач (c = 3·10⁸ м/с)? У скільки разів треба змінити ємність, щоб налаштуватися на вдвічі довшу хвилю?

**Спосіб 1 — формула Томсона.** LC = 2·10⁻⁶ · 2·10⁻¹¹ = 4·10⁻¹⁷ с². √ = 6,32·10⁻⁹ с. T = 2π · 6,32·10⁻⁹ ≈ 3,97·10⁻⁸ с, ν ≈ 25,2 МГц. λ = cT ≈ 11,9 м.

**Спосіб 2 — через ω.** ω₀ = 1/√(LC) ≈ 1,58·10⁸ рад/с, ν = ω₀/2π ≈ 25,2 МГц.

**Спосіб 3 — масштабування.** λ = cT ~ √C. Щоб λ подвоїлась, √C має подвоїтись — ємність збільшити **вчетверо** (до 80 пФ).

**Спосіб 4 — аналогія.** Як подвоїти період маятника? Збільшити масу вчетверо (T ~ √m). Тут «маса» — L, і так само можна збільшити вчетверо L замість C.

## 8. Типові помилки

| Помилка | Як правильно |
|---|---|
| T = 2πLC | T = 2π√(LC) |
| Коли заряд найбільший, струм теж найбільший | Струм у цей момент нуль (зсув на T/4) |
| Конденсатор розряджається миттєво | Самоіндукція котушки уповільнює розряд |
| Після розряду конденсатора струм припиняється | Котушка підтримує струм і перезаряджає конденсатор |
| Енергія конденсатора змінюється з частотою ν | З частотою 2ν |
| Ємність подвоїли — частота зменшилась удвічі | У √2 раза |
| Коливання незгасальні в будь-якому контурі | Опір R спричиняє згасання |
