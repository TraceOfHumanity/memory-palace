# Лінзи і оптичні прилади

**Лінза** — прозоре тіло, обмежене двома сферичними поверхнями. Завдяки заломленню вона збирає (або розсіює) промені і створює **зображення** предметів. Лінзи — серце ока, окулярів, фотоапаратів, мікроскопів, телескопів і проєкторів. Усю геометрію зображень описує одна формула тонкої лінзи 1/d + 1/f = 1/F, яку можна вивести з подібних трикутників.

## 1. Види лінз

- **Збиральні (опуклі)**: посередині товщі, ніж по краях (двоопукла, плоско-опукла). Паралельні промені після лінзи збираються в точці.
- **Розсіювальні (увігнуті)**: посередині тонші. Паралельні промені розходяться, ніби виходячи з точки перед лінзою.

Чому так: лінзу можна уявити набором маленьких призм. Кожна призма відхиляє промінь до своєї основи ([[Заломлення світла]]). У збиральній лінзі основи призм — до центра, тож промені відхиляються до осі. Що далі від центра, то більший кут «призми» — то сильніше відхилення. Саме тому всі паралельні промені сходяться в одній точці.

(Це для скляної лінзи в повітрі. Повітряна «опукла» лінза у воді — розсіювальна!)

## 2. Основні поняття

- **Головна оптична вісь** — пряма через центри сферичних поверхонь.
- **Оптичний центр** O — точка лінзи, через яку промені проходять **без заломлення** (там лінза — як тонка плоскопаралельна пластинка).
- **Головний фокус** F — точка, де збираються промені, паралельні головній осі (для розсіювальної — точка, з якої «виходять» продовження розсіяних променів; фокус **уявний**). У кожної лінзи два фокуси, симетричні відносно неї.
- **Фокусна відстань** F — відстань від центра до фокуса. Для збиральної F > 0, для розсіювальної F < 0.
- **Оптична сила** **D = 1/F**, одиниця **діоптрія** (дптр = 1/м). Лінза з F = 0,5 м — 2 дптр; розсіювальна F = −0,25 м — −4 дптр. Окуляри «+2» і «−3» — саме діоптрії.

Оптичні сили тонких лінз, складених разом, **додаються**: D = D₁ + D₂.

## 3. Побудова зображень

Для будь-якої точки предмета досить двох з трьох «зручних» променів:
1. Промінь **паралельно осі** → після лінзи йде через фокус (для розсіювальної — так, ніби вийшов з переднього фокуса).
2. Промінь **через оптичний центр** → не заломлюється.
3. Промінь **через передній фокус** → після лінзи паралельно осі.

Точка перетину заломлених променів (або їх продовжень) — зображення точки.

### Збиральна лінза: усі випадки (d — відстань предмета)
| Предмет | Зображення | Приклад |
|---|---|---|
| d > 2F | дійсне, перевернуте, зменшене, між F і 2F | фотоапарат, око |
| d = 2F | дійсне, перевернуте, рівне, на 2F | копіювальні пристрої |
| F < d < 2F | дійсне, перевернуте, збільшене, далі за 2F | проєктор, об'єктив мікроскопа |
| d = F | зображення немає (промені паралельні) | прожектор |
| d < F | **уявне, пряме, збільшене**, з того самого боку | лупа |

**Розсіювальна лінза** завжди дає **уявне, пряме, зменшене** зображення між лінзою і фокусом.

## 4. Формула тонкої лінзи

### 4.1. Виведення
Предмет висотою h на відстані d, зображення висотою H на відстані f. Промінь через центр дає подібні трикутники: H/h = f/d. Промінь, паралельний осі, після лінзи йде через фокус — ще пара подібних трикутників (з вершиною у фокусі за лінзою): H/h = (f − F)/F. Прирівнюємо: f/d = (f − F)/F → fF = d(f − F) → fF + dF = df. Поділимо на dfF:

**1/d + 1/f = 1/F = D.**

### 4.2. Правило знаків
- d > 0 завжди (дійсний предмет).
- f > 0 — дійсне зображення (за лінзою), f < 0 — уявне (з боку предмета).
- F > 0 — збиральна, F < 0 — розсіювальна.

### 4.3. Збільшення
**Γ = H/h = f/d.** |Γ| > 1 — збільшене. Від'ємне Γ (при f < 0 зі знаком) — пряме уявне; для дійсного — перевернуте.

Приклад: F = 10 см, предмет на 15 см: 1/f = 1/10 − 1/15 = 1/30 → f = 30 см, Γ = 2 — дійсне, перевернуте, удвічі збільшене. Розв'язання — дії з [[Алгебраїчні дроби|дробами]].

### 4.4. Чому d і f «міняються ролями»
Формула симетрична: якщо предмет поставити туди, де було зображення, зображення з'явиться там, де був предмет (оборотність променів). На одній відстані між предметом і екраном L > 4F є **два** положення лінзи, що дають чітке зображення (збільшене і зменшене).

## 5. Око

### 5.1. Будова
Око — оптична система: рогівка і **кришталик** (разом ≈ 60 дптр) створюють на **сітківці** дійсне, зменшене, **перевернуте** зображення. Мозок «перевертає» його. Зіниця — діафрагма, що регулює кількість світла.

**Акомодація**: м'язи змінюють кривизну кришталика, а з нею фокусну відстань, щоб чітко бачити і далекі, і близькі предмети (відстань до сітківки стала ≈ 17 мм). **Відстань найкращого зору** — 25 см: на ній довго читати без утоми.

### 5.2. Вади зору і окуляри
- **Короткозорість (міопія)**: око занадто сильне (або довге) — зображення далеких предметів фокусується **перед** сітківкою. Людина погано бачить вдалину. Виправляють **розсіювальними** лінзами (D < 0).
- **Далекозорість (гіперметропія)**: око слабке — зображення за сітківкою, важко бачити зблизька. Виправляють **збиральними** (D > 0).
- **Пресбіопія** (вікова): кришталик втрачає еластичність — потрібні окуляри для читання.

## 6. Оптичні прилади

- **Лупа** — збиральна лінза; предмет ставлять ближче за фокус. Збільшення ≈ 25 см/F. Лупа з F = 5 см — 5×.
- **Фотоапарат** — об'єктив дає на матриці дійсне зменшене перевернуте зображення. Фокусування — зміна відстані від об'єктива до матриці.
- **Проєктор** — предмет (слайд, екранчик) трохи далі за фокус — збільшене дійсне зображення на екрані.
- **Мікроскоп** — об'єктив (короткофокусний) дає збільшене дійсне зображення, окуляр (як лупа) збільшує його ще. Загальне збільшення — добуток: Γ = Γ_об · Γ_ок (до ~2000×; далі заважає дифракція, [[Хвильова оптика]]).
- **Телескоп-рефрактор** (Галілей, Кеплер) — довгофокусний об'єктив і короткофокусний окуляр. **Кутове** збільшення Γ = F_об/F_ок. Головне не збільшення, а діаметр об'єктива: що він більший, то більше світла збирає і дрібніші деталі розрізняє. Великі телескопи — **рефлектори** з увігнутими дзеркалами ([[Поширення і відбивання світла]]).

## 7. Кілька способів зрозуміти

| Модель | Що вона показує |
|---|---|
| Набір призм | Лінза — призми, що відхиляють промені до осі |
| Три зручні промені | Побудова зображення без формул |
| Подібні трикутники | Формула 1/d + 1/f = 1/F і збільшення f/d |
| Оптична сила | Діоптрії додаються — окуляри «підправляють» силу ока |
| Оборотність | Предмет і зображення можна поміняти місцями |

### Ключовий приклад: де буде зображення
Предмет висотою 2 см стоїть на відстані 30 см від збиральної лінзи з оптичною силою 5 дптр. Знайдіть положення, розмір і характер зображення.

**Спосіб 1 — формула.** F = 1/5 = 0,2 м = 20 см. 1/f = 1/20 − 1/30 = 1/60 → f = 60 см. Γ = 60/30 = 2, H = 4 см. Дійсне, перевернуте, збільшене.

**Спосіб 2 — таблиця випадків.** F < d < 2F (20 < 30 < 40) → дійсне, перевернуте, збільшене, далі за 2F (60 > 40). Збігається.

**Спосіб 3 — формула Ньютона.** Відстані від фокусів: x = d − F = 10 см, x′ = f − F; xx′ = F² → x′ = 400/10 = 40 см, f = 60 см. Зручно для швидких розрахунків.

**Спосіб 4 — побудова.** Промінь з верхівки предмета паралельно осі — після лінзи через задній фокус; промінь через центр — прямо. Перетин за лінзою, нижче осі, на 60 см — графічна перевірка.

## 8. Типові помилки

| Помилка | Як правильно |
|---|---|
| 1/d + 1/f = F | = 1/F |
| Забути знак F для розсіювальної | F < 0, D < 0 |
| Розсіювальна лінза може дати дійсне зображення | Від дійсного предмета — лише уявне |
| Лупа: предмет за фокусом | Ближче за фокус |
| Короткозорість виправляють збиральними | Розсіювальними |
| Збільшення телескопа — головне | Головне — діаметр об'єктива (світлосила, роздільна здатність) |
| D у дптр при F у см | D = 1/F, F — у метрах |
