# Закони Ньютона (динаміка)

Кінематика ([[Механічний рух]], [[Рівноприскорений рух]]) описувала, ЯК рухаються тіла. Динаміка відповідає на питання **чому**: що змушує тіло змінювати швидкість. Три закони Ньютона (1687, «Математичні начала натуральної філософії») — фундамент класичної механіки. Числові приклади перевірені обчисленням (Python).

Математика: вектори та їх додавання (`mathematics/Вектори і матриці.md`), лінійні рівняння (в `Рівноприскорений рух.md` та відео), тригонометрія для похилої площини.

---

## 1. Що таке сила
- **Сила F** — векторна міра взаємодії тіл: показує, наскільки сильно і в який бік одне тіло діє на інше.
- Одиниця — **ньютон (Н)**: 1 Н = 1 кг·м/с² (сила, що надає тілу масою 1 кг прискорення 1 м/с²).
- Сила — вектор: значення, напрямок, точка прикладання. Сили додаються як вектори.
- **Рівнодійна (результуюча) сила** — векторна сума всіх сил, що діють на тіло: `F = F₁ + F₂ + …`. Одна рівнодійна замінює дію всіх сил.
- Приклад на прямій: тягнемо вправо 50 Н, тертя 20 Н вліво → рівнодійна 50 − 20 = 30 Н вправо.
- Види сил (докладніше в наступних темах): тяжіння, реакція опори (нормальна), пружності, тертя, натягу, опору середовища.

## 2. Маса та інертність
- **Інертність** — властивість тіла чинити опір зміні швидкості. **Маса m** — міра інертності (кг). Чим більша маса, тим важче розігнати або зупинити.
- Маса — скаляр, не залежить від місця (на Місяці та на Землі та сама). Не плутати з вагою (це сила).
- **Вага тіла P** — сила, з якою тіло тисне на опору або тягне підвіс. Біля поверхні Землі при спокої `P = m·g`. 70 кг → 70·9,8 = 686 Н. На Місяці g ≈ 1,62 → 113 Н, а маса — та сама 70 кг.

## 3. Перший закон Ньютона (закон інерції)
**Тіло зберігає стан спокою або рівномірного прямолінійного руху, поки на нього не діють інші тіла (або дії скомпенсовані).**
- Умова: рівнодійна `ΣF = 0` ⇒ `a = 0` (швидкість не змінюється).
- Руйнує інтуїцію Арістотеля («щоб рухатись, потрібна сила»). Насправді сила потрібна для *зміни* швидкості. Шайба на льоду їде довго саме тому, що тертя мале.
- **Спокій і рівномірний рух — фізично рівноправні** (принцип відносності Галілея). Кинувши м'яч у вагоні, що їде рівномірно, ви побачите ті самі закони, що й на станції.
- **Інерціальна система відліку (ІСВ)** — система, у якій виконується перший закон. Усі системи, що рухаються рівномірно прямолінійно відносно ІСВ, теж інерціальні. Земля — наближено інерціальна. Автобус, що гальмує/поворачиває, — ні (тому нас «кидає вперед»: це не сила, а інерція).

## 4. Другий закон Ньютона
**Прискорення тіла прямо пропорційне рівнодійній силі й обернено пропорційне масі:**
`a = F / m`, або `F = m·a` (векторно: `ΣF = m·a`; прискорення співнапрямлене з рівнодійною).
- Приклад: автомобіль 1000 кг, рівнодійна 2000 Н → a = 2000/1000 = 2 м/с². Хто чим ударяє — отримує прискорення пропорційно силі.
- Подвоїли силу → прискорення ×2; подвоїли масу → прискорення ÷2.
- З одиниць: [F] = кг·м/с² = Н.
- **Загальніша форма (через імпульс):** `F = Δp / Δt`, де `p = m·v` — імпульс. Сила = швидкість зміни імпульсу. Працює і для змінної маси (ракета).
- Приклад: м'яч 0,45 кг ударяють, швидкість стала 25 м/с за 0,01 с: F = 0,45·25/0,01 = 1125 Н (≈ 115 кг-сили).
- Із другого закону — **стала сила ⇒ стале прискорення ⇒ рівноприскорений рух** (зв'язок з попередньою темою: `s = v₀t + at²/2`, `a = F/m`).
- Гальмування: автомобіль 1000 кг, v₀ = 20 м/с, гальмівний шлях 40 м → a = v₀²/(2s) = 5 м/с², сила гальмування F = 1000·5 = 5000 Н.

## 5. Третій закон Ньютона
**Сили взаємодії двох тіл рівні за модулем, протилежні за напрямом, прикладені до РІЗНИХ тіл і мають однакову природу:** `F₁₂ = −F₂₁`.
- «Дія дорівнює протидії». Кожна сила — частина **пари**.
- **Ключова помилка:** «сили однакові й протилежні, тож вони компенсуються». Ні! Вони діють на *різні* тіла, тому не можуть скласти нульову рівнодійну одного тіла. Компенсувати дію може лише інша сила на *те саме* тіло.
- Приклади: людина відштовхується від землі — Земля штовхає людину вперед; ракета викидає газ — газ штовхає ракету; плавець відштовхує воду назад — вода його вперед.
- Прискорення при однаковій силі взаємодії обернено пропорційні масам: `a₁/a₂ = m₂/m₁`. Два ковзанярі 60 кг і 40 кг відштовхуються: легший їде швидше. Імпульс пари зберігається (закон збереження імпульсу): `m₁v₁ = m₂v₂` → 60·1,0 = 40·1,5 = 60 кг·м/с.
- Сила тяжіння Землі на яблуко і сила тяжіння яблука на Землю рівні за модулем. Але прискорення Землі нікчемне через її масу.

## 6. Сили, які треба вміти малювати
1. **Тяжіння:** `F = m·g`, вниз. g ≈ 9,8 м/с² (≈ 10 в оцінках).
2. **Нормальна реакція опори N:** перпендикулярно до поверхні. Не завжди дорівнює mg! (у ліфті, на похилій).
3. **Тертя:** `F_тр = μ·N` (ковзання; μ — коефіцієнт тертя, залежить від матеріалів). Спрямоване проти руху (або проти тенденції до руху). Тертя спокою ≤ μ·N: не стрибає з нуля, а підлаштовується під прикладену силу до порога.
4. **Сила натягу нитки T:** уздовж нитки; для невагомої нерозтяжної нитки однакова по всій довжині.
5. **Сила пружності:** закон Гука `F = k·x` (x — деформація), спрямована до відновлення форми.
6. **Опір середовища:** зростає зі швидкістю.

## 7. Алгоритм розв'язування задач динаміки
1. **Рисунок і ІСВ.** Позначити тіла, напрям руху (або припустити).
2. **Діаграма сил для кожного тіла** (free-body diagram): стрілки *лише сил, що діють НА це тіло*.
3. **Осі:** обрати вісь вздовж руху; сили, що не лежать на осях, розкласти (sin/cos).
4. **Другий закон по осях:** `Σ Fₓ = m·aₓ`, `Σ F_y = m·a_y` (для рівноваги по перпендикулярній осі `a = 0`).
5. Для зв'язаних тіл — рівняння для кожного + умова зв'язку (однакове прискорення, T однакове).
6. Розв'язати систему, перевірити розмірність та знаки.

## 8. Приклади задач
**A. Тіло на горизонтальній поверхні з тертям.** Ящик 20 кг, μ = 0,3, штовхаємо силою 100 Н. N = mg = 196 Н; F_тр = 0,3·196 = 58,8 Н; a = (100 − 58,8)/20 ≈ 2,06 м/с².

**B. Ліфт.** Людина 70 кг на ваги. Ваги показують N (силу реакції) — це вага.
- Спокій / рівномірний рух: N = mg = 686 Н.
- Розгін вгору з a = 2 м/с²: N − mg = ma → N = m(g + a) = 70·11,8 = 826 Н (ваги більше — «перевантаження»).
- Розгін вниз з a = 2: N = m(g − a) = 70·7,8 = 546 Н (легше).
- Вільне падіння (обірваний трос): a = g → N = 0 — **невагомість** (тіло падає разом з опорою; тяжіння на нього діє, але вага = 0).

**C. Похила площина.** Кут 30°. Розкладаємо mg: вздовж площини mg sin θ, перпендикулярно mg cos θ; N = mg cos θ.
- Без тертя: a = g sin θ = 9,8·0,5 = 4,9 м/с² (не залежить від маси!).
- З тертям μ = 0,2: a = g(sin θ − μ cos θ) = 9,8·(0,5 − 0,2·0,866) ≈ 3,2 м/с².

**D. Машина Атвуда (два тіла на нитці через блок).** m₁ = 3 кг, m₂ = 2 кг (m₁ важче). Блок і нитка невагомі. Для обох: однакове |a|, однакове T. Для m₁: m₁g − T = m₁a. Для m₂: T − m₂g = m₂a. Складаємо: a = (m₁ − m₂)g / (m₁ + m₂) = 1·9,8/5 = 1,96 м/с². Натяг T = 2m₁m₂g/(m₁ + m₂) = 2·6·9,8/5 = 23,52 Н (менше за m₁g = 29,4 Н і більше за m₂g = 19,6 Н).

**E. Рівновага.** Тіло висить на двох нитках ⇒ ΣF = 0 ⇒ сума проєкцій на кожну вісь = 0 (з цього знаходять натяги).

## 9. Закон тяжіння (коротко)
`F = G·m₁·m₂ / r²`, G ≈ 6,67·10⁻¹¹ Н·м²/кг². Біля поверхні Землі `g = G·M / R² ≈ 9,8 м/с²`. g на Місяці ≈ 1,62 м/с². Ньютон побачив, що те ж тяжіння, що змушує яблуко падати, тримає Місяць на орбіті.

## Для програміста
- **Фізичний рушій** (Box2D, Bullet, Unity/Unreal) — це другий закон у циклі: сума сил → прискорення → швидкість → позиція.
```js
// per-frame, dt in seconds
acc = force / mass;          // F = m*a
vel = vel + acc * dt;        // semi-implicit Euler
pos = pos + vel * dt;
force = [0, 0];              // reset accumulator each frame
```
- **Акумулятор сил:** кожен кадр обнуляємо, додаємо гравітацію `m*g`, тертя, пружини, штовхання — потім ділимо на масу.
- **Тертя** в рушії: `friction = -mu * normalForce * sign(velocity)` (не міняє напрям швидкості — лише гасить).
- **Третій закон у зіткненнях:** імпульс, який отримує один об'єкт, віднімається у іншого (`impulse` застосовується з протилежними знаками) — інакше порушується збереження імпульсу.
- **Масштаб:** безрозмірні «пікселі» ≠ метри; тримайте одиниці (`mass` кг, `force` Н) або узгодьте масштаб.
- **Перевірка симуляції:** падіння без опору: `pos(t)` має збігатися з `h = g t²/2`; два тіла — загальний імпульс має зберігатися.
- Нульова або майже нульова маса → `acc = force / mass` дає великі/нескінченні значення: обмежте `mass ≥ ε` або використовуйте інверсну масу `invMass` (0 для нерухомих об'єктів) — стандартна практика.

## Типові помилки
1. Вважати, що сила потрібна для підтримки руху (насправді — для зміни швидкості).
2. «Сили третього закону компенсуються»: вони діють на різні тіла.
3. Плутати масу (кг) і вагу (Н); плутати вагу з силою тяжіння (вага = сила на опору).
4. Малювати на діаграмі сили, що діють *від* тіла на інші (діаграма — тільки сили НА тіло); додавати «силу інерції» в ІСВ.
5. Вважати N = mg завжди (ні: ліфт, похила, додаткові сили).
6. Забути розкласти силу на осі (sin/cos) та підставити знаки.
7. Плутати μN (максимум тертя спокою/сила ковзання) з реальною силою тертя спокою.
8. Не перевіряти розмірності й знаку прискорення.

## Шпаргалка
| Закон | Формула | Суть |
|---|---|---|
| 1-й | ΣF = 0 ⇒ v = const | інерція; ІСВ |
| 2-й | ΣF = m·a; F = Δp/Δt | сила змінює швидкість |
| 3-й | F₁₂ = −F₂₁ | дія = протидія, різні тіла |
| Вага | P = mg (спокій) | сила на опору |
| Тертя | F = μN | проти руху |
| Пружність | F = kx | закон Гука |
| Тяжіння | F = G m₁m₂/r² | g = GM/R² |
