# Застосування законів Ньютона

Знаючи закони Ньютона і види сил, можна розв'язати майже будь-яку задачу механіки за **одним алгоритмом**: намалювати сили, вибрати осі, записати другий закон у проекціях, розв'язати систему рівнянь. Ця нотатка розбирає основні типи задач — похилу площину, зв'язані тіла і блоки, рух по колу під дією сил, — і показує, чому алгоритм працює.

Пов'язані нотатки: [[Фізика — зміст]], [[Закони Ньютона]], [[Сили в механіці]], [[Рух по колу]], [[Рівноприскорений рух]], [[Системи рівнянь]], [[Тригонометричні функції]], [[Вектори на площині]]

## 1. Алгоритм і чому він працює

1. **Рисунок.** Зобразити кожне тіло окремо.
2. **Сили.** Для кожного тіла — лише сили, що діють **на нього**, кожна з відомим «автором» (Земля, нитка, опора, поверхня).
3. **Осі.** Вибрати осі так, щоб якомога більше сил і прискорення лежали вздовж них. Зазвичай одна вісь — уздовж прискорення.
4. **Другий закон у проекціях:** ΣFₓ = maₓ, ΣF_y = ma_y.
5. **Зв'язки.** Нитка нерозтяжна → однакові модулі прискорень; невагома → однаковий натяг; тіло не відривається від опори → a_y = 0.
6. **Розв'язати систему**, перевірити розмірність і граничні випадки.

Чому проекції: векторне рівняння ΣF⃗ = ma⃗ рівносильне двом числовим, бо два вектори рівні тоді й лише тоді, коли рівні їхні проекції на кожну вісь ([[Вектори на площині]]). Векторну задачу перетворюємо на алгебраїчну — [[Системи рівнянь]].

Чому зручно брати вісь уздовж прискорення: тоді по перпендикулярній осі a = 0, і одне рівняння стає «рівнянням рівноваги», з якого зазвичай знаходять N.

## 2. Похила площина

### 2.1. Розкладання сили тяжіння
Тіло на площині з кутом нахилу α. Осі: x — уздовж площини вниз, y — перпендикулярно до неї. Сила тяжіння mg вертикальна, вона утворює з віссю y кут α (кут між перпендикулярами до сторін кута дорівнює куту). Тому:
- уздовж площини: mg sin α — «скочувальна» складова;
- перпендикулярно: mg cos α — «притискальна» складова.

Перевірка граничними випадками: при α = 0 скочувальна 0, притискальна mg (горизонтальний стіл). При α = 90° скочувальна mg (вільне падіння), притискальна 0. Якщо переплутати sin і cos, перевірка це виявить.

### 2.2. Без тертя
y: N − mg cos α = 0 → N = mg cos α.
x: mg sin α = ma → **a = g sin α**. Не залежить від маси.

### 2.3. З тертям, рух униз
F_тр = μN = μmg cos α, спрямоване вгору вздовж площини.
a = g(sin α − μ cos α).

**Умова, що тіло лежить нерухомо:** mg sin α ≤ μmg cos α, тобто **tg α ≤ μ**. Звідси простий спосіб виміряти μ: поступово нахиляти дошку, поки брусок не зрушить; μ = tg α_гран.

### 2.4. Рух угору (тіло штовхнули)
Тепер і скочувальна складова, і тертя спрямовані вниз: модуль прискорення a = g(sin α + μ cos α). Тому вгору тіло гальмує швидше, ніж розганяється вниз.

### 2.5. Тягнуть уздовж площини вгору силою F
F − mg sin α − μmg cos α = ma.

## 3. Зв'язані тіла

### 3.1. Тіла на нитці по горизонталі
Бруски m₁ і m₂ зв'язані ниткою, тягнуть передній (m₂) силою F, тертя немає.
- Систему можна розглянути як одне тіло: F = (m₁ + m₂)a → a = F/(m₁ + m₂).
- Натяг знаходимо з рівняння для заднього бруска: T = m₁a = F·m₁/(m₁ + m₂).

Сенс: нитка розганяє лише задній брусок, тож натяг — частка сили, пропорційна частці маси позаду.

### 3.2. Тіло на столі і вантаж через блок
Брусок m₁ на столі (тертя μ), нитка через блок на краю стола, на ній висить вантаж m₂.
- Вантаж: m₂g − T = m₂a.
- Брусок: T − μm₁g = m₁a.
- Складемо: a = (m₂ − μm₁)g/(m₁ + m₂).

Якщо m₂ < μm₁, формула дає a < 0 — це означає, що система **стоїть** (тертя спокою не дає рушити), а не їде назад.

### 3.3. Машина Атвуда
Два вантажі m₁ > m₂ на нитці через нерухомий блок.
a = (m₁ − m₂)g/(m₁ + m₂), T = 2m₁m₂g/(m₁ + m₂).

Атвуд (1784) використовував її, щоб **сповільнити** падіння: при близьких масах прискорення мале, і його легко виміряти годинником того часу.

### 3.4. Рухомий блок
Вантаж підвішено на рухомому блоці, нитка одним кінцем закріплена. Вантаж утримують дві гілки нитки, тому сила, потрібна для рівноваги, удвічі менша, а кінець нитки рухається удвічі швидше за вантаж (див. [[Прості механізми]]).

## 4. Рух по колу під дією сил
Рівнодійна всіх сил дорівнює ma = mv²/R і спрямована до центра.

### 4.1. Конічний маятник
Кулька на нитці довжиною l описує горизонтальне коло, нитка утворює кут α з вертикаллю. Сили: mg вниз, T уздовж нитки.
- Вертикаль: T cos α = mg.
- Горизонталь (до центра): T sin α = mv²/r, r = l sin α.
- Ділимо: tg α = v²/(gr).

### 4.2. Віраж з нахилом
Дорогу на повороті нахиляють під кутом α, щоб доцентрову роль грала не лише сила тертя, а й горизонтальна складова реакції N. Без тертя: tg α = v²/(gR). Для цієї швидкості автомобіль проходить поворот навіть на льоду. Велосипедист нахиляється на повороті з тієї самої причини.

### 4.3. Вертикальне коло
Тіло на нитці в нижній точці: T − mg = mv²/R → T = m(g + v²/R) — нитка натягнута найсильніше. У верхній точці: T + mg = mv²/R → T = m(v²/R − g). Нитка не провисає, поки T ≥ 0, тобто v ≥ √(gR).

### 4.4. Опуклий і увігнутий міст
Опуклий, верхня точка: mg − N = mv²/R → N = m(g − v²/R) < mg.
Увігнутий, нижня точка: N = m(g + v²/R) > mg.

## 5. Кілька способів думати

| Підхід | Коли зручний |
|---|---|
| Кожне тіло окремо | Завжди працює; дає і прискорення, і внутрішні сили (натяги) |
| Система як одне тіло | Швидко дає прискорення: внутрішні сили (натяги) взаємно знищуються за третім законом |
| Вибір осей уздовж площини | Прискорення лише по одній осі, друге рівняння — рівновага |
| Граничні випадки | Перевірка: α → 0, α → 90°, μ → 0, m₂ → 0 |
| Енергія | Якщо потрібна лише швидкість, а не сили, — див. [[Механічна енергія]] |

### Ключовий приклад: брусок і вантаж через блок
На столі брусок m₁ = 3 кг (μ = 0,2), через блок висить вантаж m₂ = 2 кг. Знайдіть прискорення і натяг (g = 10 м/с²).

**Спосіб 1 — два рівняння.** Вантаж: 20 − T = 2a. Брусок: T − 6 = 3a. Складаємо: 14 = 5a → a = 2,8 м/с². T = 6 + 3 · 2,8 = 14,4 Н.

**Спосіб 2 — система як одне тіло.** «Рушійна» сила — вага вантажу 20 Н, «гальмівна» — тертя 6 Н, розганяємо загальну масу 5 кг: a = 14/5 = 2,8 м/с².

**Спосіб 3 — натяг через вантаж.** Вантаж падав би з прискоренням g, а падає з 2,8 м/с². Різницю «забирає» нитка: T = m₂(g − a) = 2 · 7,2 = 14,4 Н.

**Спосіб 4 — перевірка граничних випадків.** Якщо μ = 0: a = 20/5 = 4 м/с² (формула m₂g/(m₁ + m₂)) — більше, ніж з тертям, логічно. Якщо m₁ → 0: a → g (вантаж падає вільно) — формула (m₂ − μm₁)g/(m₁ + m₂) це дає. Якщо m₂ < μm₁ = 0,6 кг — система стоїть.

## 6. Типові помилки

| Помилка | Як правильно |
|---|---|
| Сила тяжіння вздовж площини mg cos α | mg sin α; перевірити при α = 90° |
| N = mg на похилій | N = mg cos α (і інше, якщо є додаткові сили) |
| Натяг нитки дорівнює вазі вантажу і в русі | T = m(g − a), якщо вантаж опускається з прискоренням |
| Від'ємне прискорення в задачі з тертям = рух назад | Система стоїть: тертя спокою не тягне назад |
| Окрема «доцентрова сила» на рисунку | Доцентрова — рівнодійна реальних сил |
| Сила, що тягне перший брусок, діє і на другий | На другий діє лише нитка |
| Однакові знаки для сил вгору і вниз | Кожна проекція — зі знаком відносно вибраної осі |
