# Рівноприскорений рух (кінематика, частина 2)

Продовження теми [[Механічний рух]]. Там швидкість була сталою; тут вона змінюється рівномірно. Числові приклади перевірені обчисленням (Python).

Математика, що тут використовується: лінійна функція й квадратична парабола (див. `mathematics/Функції.md`, `Найважливіші графіки.md`), площа під графіком (ідея інтеграла, `mathematics/calculus/Інтеграл.md`), вектори (`mathematics/Вектори і матриці.md`), тригонометрія для кидка під кутом.

---

## 1. Навіщо ця тема
У житті швидкість майже ніколи не стала: автомобіль розганяється, камінь падає, м'яч злітає й повертається. Найпростіша модель нерівномірного руху — коли швидкість змінюється **однаково за кожну секунду**. Це **рівноприскорений рух**. З нього виходять вільне падіння, кидки, гальмування, а також перший крок до динаміки: за другим законом Ньютона стала сила дає саме стале прискорення.

## 2. Прискорення
- **Прискорення a** — зміна швидкості за одиницю часу: `a = (v − v₀) / t`.
- Одиниця: м/с² (метр на секунду за секунду): «на скільки м/с змінюється швидкість щосекунди».
- **Вектор.** Знак у проекції на вісь: a > 0 — швидкість зростає *за напрямом осі*; a < 0 — зменшується за напрямом осі. Увага: «a < 0» не завжди означає гальмування!
  - Розгін: v і a однаково спрямовані.
  - Гальмування: v і a спрямовані протилежно.
  - Рух проти осі з a < 0 — це якраз розгін (швидкість росте за модулем).
- Рівноприскорений рух: **a = const** (за значенням і напрямом).
- Приклад: розгін 0 → 100 км/год за 8 с: 100 км/год ≈ 27,8 м/с, a = 27,8 / 8 ≈ 3,5 м/с².

## 3. Формули (виводимо, а не запам'ятовуємо)
1. **Швидкість:** `v = v₀ + a·t`. Прямо з означення прискорення. Графік v(t) — **пряма**, нахил = a.
2. **Переміщення через площу під графіком v(t).** Під лінією v(t) виходить трапеція (або трикутник, якщо v₀ = 0):
   `s = (v₀ + v)/2 · t` — середня швидкість помножена на час (бо швидкість росте лінійно, середня = середнє арифметичне).
3. Підставивши v = v₀ + at: **`s = v₀·t + a·t²/2`**.
   Геометрично: прямокутник v₀·t плюс трикутник (a·t)·t/2.
4. **Закон руху:** `x = x₀ + v₀·t + a·t²/2` — **парабола** x(t).
5. **Формула без часу:** `v² = v₀² + 2·a·s`. Виключаємо t: з (1) t = (v − v₀)/a, підставляємо в s = (v₀ + v)/2 · t → s = (v² − v₀²)/(2a). Корисна, коли час не відомий.
- Усі формули для *проекцій* на вісь; знаки v₀, a, s беруть із вибраного напряму осі.

## 4. Приклади
**A. Розгін зі стану спокою:** v₀ = 0, a = 2 м/с². Через 5 с: v = 2·5 = 10 м/с, s = 2·25/2 = 25 м.
**Правило непарних чисел (Галілей):** за послідовні однакові проміжки часу тіло з v₀ = 0 проходить відстані у відношенні **1 : 3 : 5 : 7 …** (при a = 2: шлях за 1 с = 1, за 2 с = 4, за 3 с = 9 → у кожну наступну секунду 1, 3, 5, 7, 9 м). Загальний шлях росте як **t²**: подвоїли час — шлях ×4.

**B. Гальмування:** v₀ = 10 м/с, a = −2 м/с². v = 10 − 2t = 0 → t = 5 с. s = 10·5 − 2·25/2 = 25 м. Через формулу без часу: s = v₀² / (2|a|) = 100/4 = 25 м ✓.

**C. Гальмівний шлях:** s = v₀² / (2|a|) — **квадратична залежність від швидкості**. При |a| = 5 м/с²:
- v = 10 м/с (36 км/год): s = 100/10 = 10 м.
- v = 20 м/с (72 км/год): s = 400/10 = 40 м.
- v = 40 м/с (144 км/год): s = 1600/10 = 160 м.
Швидкість ×2 → шлях ×4. Звідси правила безпеки: тримати дистанцію пропорційно *квадрату* швидкості.

## 5. Графіки рівноприскореного руху
| Графік | Вигляд | Що читається |
|---|---|---|
| a(t) | горизонтальна пряма | a = const; площа під нею = зміна швидкості Δv |
| v(t) | похила пряма | нахил = a; перетин осі t — момент зупинки; площа = s |
| x(t) | парабола | нахил дотичної = миттєва швидкість; вершина параболи — момент, коли v = 0 (розворот) |
- Тіло, що розвертається (кинуто вгору): v(t) перетинає вісь t, x(t) має максимум у вершині.
- **Площа під v(t) зі знаком:** площа нижче осі t — від'ємне переміщення; шлях (скаляр) — сума модулів площ.

## 6. Вільне падіння
- **Вільне падіння** — рух під дією лише сили тяжіння (опором повітря нехтуємо). Це рівноприскорений рух із **a = g ≈ 9,8 м/с²** (у задачах часто 10), спрямованим вниз.
- **Усі тіла падають однаково** (без повітря): прискорення не залежить від маси. Галілей, потім Д. Скотт на Місяці з молотком і пером (1971). Тому в формулах нема маси.
- Падіння з висоти h без початкової швидкості: `h = g·t²/2`, `t = √(2h/g)`, `v = g·t = √(2gh)`.
  - h = 20 м: t = √(40/9,8) ≈ 2,02 с, v ≈ 19,8 м/с ≈ 71 км/год.
  - За 1 с падіння: 4,9 м, швидкість 9,8 м/с; за 2 с: 19,6 м, швидкість 19,6 м/с.
- Опір повітря зростає зі швидкістю → з'являється **гранична швидкість** (парашутист ≈ 55 м/с у падінні, ≈ 5 м/с з відкритим парашутом).

## 7. Кидок вертикально вгору
- v₀ = 20 м/с, вісь вгору, a = −g.
- Підйом триває до v = 0: `t_вгору = v₀ / g ≈ 20/9,8 ≈ 2,04 с`.
- Максимальна висота: `h_max = v₀² / (2g) ≈ 400/19,6 ≈ 20,4 м`.
- **Час польоту до повернення** = 2·t_вгору ≈ 4,08 с — підйом і спуск **симетричні**: на кожній висоті швидкість при підйомі та спуску однакова за модулем.
- Швидкість повернення в початкову точку = v₀ за модулем (20 м/с).
- Вершина — це не «зупинка прискорення»: у верхній точці v = 0, але a = −g ≠ 0 (саме тому тіло повертається).

## 8. Кидок під кутом до горизонту (балістика)
- Ідея: **незалежність рухів по осях** — горизонтальний рух рівномірний (a_x = 0), вертикальний рівноприскорений (a_y = −g). Вектор швидкості розкладаємо через тригонометрію: `v_x = v₀·cos θ`, `v_y = v₀·sin θ`.
- Траєкторія — парабола.
- Час польоту: `T = 2·v₀·sin θ / g`. Дальність: `L = v₀²·sin 2θ / g`. Висота: `H = (v₀ sin θ)² / (2g)`.
- Приклад v₀ = 20 м/с, θ = 45°: T ≈ 2,89 с, L ≈ 40,8 м, H ≈ 10,2 м.
- **Максимальна дальність — при 45°** (бо sin 2θ найбільший при 2θ = 90°). Кути θ і 90° − θ дають однакову дальність.
- Горизонтальний кидок з висоти h: час падіння тільки від h: `t = √(2h/g)`, дальність `L = v₀·t`.

## 9. Алгоритм розв'язування
1. Рисунок: вісь, початок, напрямок; позначити v₀, a, x₀ зі знаками.
2. «Дано» в SI.
3. Вибрати формулу за тим, що відомо / невідоме:
   - немає s → `v = v₀ + at`;
   - немає v → `s = v₀t + at²/2`;
   - немає t → `v² = v₀² + 2as`;
   - немає a → `s = (v₀ + v)/2 · t`.
4. Для двох тіл — записати x₁(t) і x₂(t), прирівняти (зустріч).
5. Перевірити розмірність та здоровий глузд (час > 0, знаки).

## Для програміста
- Чисельна симуляція (метод Ейлера, «semi-implicit»):
```js
// dt in seconds; vel, pos, acc are vectors
vel = vel + acc * dt;
pos = pos + vel * dt;   // update velocity first
```
  Порядок (спершу швидкість, потім позиція) — *semi-implicit Euler*: стабільніший за «explicit» (де позицію оновлюють старою швидкістю).
- Точна формула пострілу: `pos = pos0 + vel0*t + 0.5*acc*t*t` — використовують для *передбачення траєкторії* (прицілювання, показ лінії кидка в іграх).
- **Frame-rate independence:** завжди множити на dt; для фізики краще фіксований крок (наприклад 1/60 с), а рендер — окремо.
- Тест правильності: порівняти симуляцію з аналітикою (для a = const метод Ейлера дає похибку O(dt); Verlet — точніший).
- Гравітація в іграх: `acc = [0, -9.8]` (або вгору, якщо вісь y екрана вниз — стеж за знаком!).
- Типова гра-помилка: перевірка «зіткнення з землею» один раз за кадр на великій швидкості → тіло «пролітає» крізь землю (tunneling). Лікування: менший dt, перевірка відрізка шляху (swept test).

## Типові помилки
1. Вважати, що a < 0 завжди гальмування (залежить від напряму v).
2. Підставляти швидкості в км/год, а прискорення в м/с².
3. Використовувати `s = v·t` при змінній швидкості (треба середню швидкість або формулу з a).
4. Забути знак: кидок вгору, а g підставили додатним без узгодження осі.
5. Думати, що в верхній точці прискорення = 0 (воно = g).
6. Вважати, що важче тіло падає швидше (без опору — однаково).
7. Плутати шлях і переміщення на розвороті (шлях = сума двох ділянок).
8. При кидку під кутом змішувати горизонтальну й вертикальну складові (треба розкладати).
