# Конденсатори

**Конденсатор** — пристрій для накопичення електричного заряду й енергії: два провідники (обкладки), розділені діелектриком. Його головна характеристика — **електроємність** C = q/U: скільки заряду він накопичує на кожен вольт напруги. Конденсатори є в кожному електронному пристрої: у фотоспалаху, дефібриляторі, блоці живлення, сенсорному екрані, фільтрах звуку, пам'яті комп'ютера.

Пов'язані нотатки: [[Фізика — зміст]], [[Електричне поле]], [[Потенціал і напруга]], [[З'єднання провідників]], [[Електромагнітні коливання]], [[Алгебраїчні дроби]]

## 1. Електроємність

### 1.1. Ідея
Зарядимо провідник. Що більший заряд, то вищий його потенціал — і їх відношення стале для даного провідника:

**C = q/φ** (для відокремленого провідника), **C = q/U** (для конденсатора).

Одиниця — **фарад**: 1 Ф = 1 Кл/В. Це дуже велика ємність; на практиці мкФ (10⁻⁶), нФ (10⁻⁹), пФ (10⁻¹²).

Аналогія: ємність — як **площа дна** посудини. Заряд — кількість води, напруга — висота рівня. У широку посудину (велика C) можна налити багато води, а рівень підніметься мало.

### 1.2. Ємність кулі
Потенціал кулі φ = kq/R, тому C = R/k = 4πε₀R. Ємність Землі (R = 6400 км): ≈ 7·10⁻⁴ Ф = 700 мкФ. Навіть уся Земля має ємність меншу за 1 Ф! Тому для накопичення заряду потрібна інша конструкція.

### 1.3. Навіщо дві обкладки
Якщо поруч з зарядженою пластиною поставити іншу, з протилежним зарядом, поля обох майже знищуються зовні і складаються між ними. Потенціал заряджених пластин один відносно одного росте значно повільніше з ростом заряду — тобто ємність набагато більша. Заряди «тримають» одне одного: + притягує − через тонкий діелектрик.

## 2. Плоский конденсатор

Дві паралельні пластини площею S на відстані d. Поле між ними однорідне ([[Електричне поле]]): E = σ/ε₀ = q/(ε₀S). Напруга U = Ed = qd/(ε₀S). Ємність:

**C = εε₀S/d.**

- **Більша площа** — більше місця для заряду → більша C.
- **Менша відстань** — заряди сильніше «тримають» одне одного, напруга менша при тому самому заряді → більша C.
- **Діелектрик** (ε) зменшує поле всередині в ε разів, тому та сама напруга вміщує в ε разів більше заряду.

Приклад: S = 1 м², d = 1 мм, повітря: C = 8,85·10⁻¹² · 1/10⁻³ ≈ 8,85 нФ. Щоб отримати 1 Ф з повітрям і d = 1 мм, знадобилась би площа ≈ 113 км².

Як роблять великі ємності: фольгові обкладки, згорнуті в рулон (велика S), тонкий шар діелектрика (мала d), діелектрики з великим ε (кераміка з ε ~ 1000+). **Електролітичні** конденсатори — шар оксиду завтовшки нанометри. **Іоністори (суперконденсатори)** — пористий вугіль з гігантською площею поверхні: тисячі фарад.

**Пробій:** у діелектрику дуже тонкому шарі поле велике; при перевищенні **напруги пробою** конденсатор руйнується. Тому на конденсаторах пишуть і ємність, і робочу напругу.

## 3. З'єднання конденсаторів

### 3.1. Паралельно
Обкладки з'єднані попарно: напруга на всіх однакова, заряди додаються.
q = q₁ + q₂ = C₁U + C₂U → **C = C₁ + C₂**.

Сенс: це те саме, що збільшити площу обкладок.

### 3.2. Послідовно
Конденсатори «в ланцюжок»: заряди на всіх однакові (внутрішні обкладки заряджаються через вплив), напруги додаються.
U = U₁ + U₂ = q/C₁ + q/C₂ → **1/C = 1/C₁ + 1/C₂**, C = C₁C₂/(C₁ + C₂).

Сенс: збільшилась відстань між крайніми обкладками. Загальна ємність **менша за найменшу**. Зате система витримує більшу напругу.

Зверніть увагу: це «дзеркально» до опорів ([[З'єднання провідників]]): для резисторів послідовно — сума, для конденсаторів — паралельно. Обчислення — як з [[Алгебраїчні дроби|алгебраїчними дробами]].

## 4. Енергія конденсатора

### 4.1. Виведення
Заряджаючи конденсатор, ми переносимо заряд маленькими порціями Δq з однієї обкладки на іншу. Спочатку напруга нуль, переносити легко; що більше заряду, то вища напруга і тим більше роботи на кожну порцію. Напруга росте лінійно від 0 до U, тож середня напруга U/2:

**W = qU/2 = CU²/2 = q²/(2C).**

Те саме — площа трикутника під графіком U(q), як енергія пружини kx²/2 під графіком F(x) ([[Механічна енергія]]). Аналогія повна: q ↔ x, U ↔ F, 1/C ↔ k.

### 4.2. Де зберігається енергія
У **полі** між обкладками. Густина енергії w = ε₀εE²/2 (Дж/м³). Це перший приклад, що поле має енергію — без зарядів між обкладками нічого немає, крім поля.

### 4.3. Застосування
- **Фотоспалах**: конденсатор повільно заряджається від батарейки і швидко розряджається через лампу — величезна потужність на мілісекунду.
- **Дефібрилятор**: ≈ 200 Дж за кілька мілісекунд.
- **Згладжування напруги** в блоках живлення, фільтри звуку (конденсатор пропускає змінний струм, але не постійний, [[Змінний струм і трансформатор]]).
- **Коливальний контур** у радіо ([[Електромагнітні коливання]]).
- **Сенсорний екран**: палець змінює ємність у точці дотику.

## 5. Кілька способів зрозуміти

| Модель | Що вона показує |
|---|---|
| Посудина з водою | C — «ширина», q — кількість, U — рівень |
| Пружина | W = q²/(2C) як kx²/2; 1/C — «жорсткість» |
| Заряди тримають одне одного | Близькі протилежні обкладки — велика ємність |
| Поле як склад енергії | Енергія — у полі між обкладками |
| Площа і відстань | Паралельне з'єднання — більша S; послідовне — більша d |

### Ключовий приклад: діелектрик у зарядженому конденсаторі
Плоский повітряний конденсатор ємністю 10 мкФ зарядили до 100 В і **від'єднали** від джерела. Між обкладки вставили пластину з ε = 5. Як змінились заряд, напруга, ємність і енергія?

**Спосіб 1 — формули.** Від'єднаний — заряд не може змінитися: q = CU = 10⁻³ Кл. Нова ємність C' = 5C = 50 мкФ. Напруга U' = q/C' = 20 В. Енергія: була CU²/2 = 0,05 Дж, стала q²/(2C') = 0,01 Дж.

**Спосіб 2 — фізика поля.** Діелектрик поляризується, його зв'язані заряди ослаблюють поле в 5 разів. Напруга U = Ed — теж у 5 разів менша. Енергія ~E² · об'єм · ε → у 5 разів менша.

**Спосіб 3 — куди поділась енергія.** 0,04 Дж «зникли»: поле **втягує** діелектрик усередину і виконує над ним роботу. Якщо пластину відпустити на краю, вона сама втягнеться.

**Спосіб 4 — порівняння з під'єднаним.** Якби конденсатор залишався підключеним до 100 В, сталою була б напруга: q' = 5·10⁻³ Кл, енергія 0,25 Дж — зросла б у 5 разів (джерело доклало заряд). Тому завжди спершу питають: **що стале — q чи U?**

## 6. Типові помилки

| Помилка | Як правильно |
|---|---|
| Ємність залежить від заряду | C = εε₀S/d — лише від геометрії і діелектрика |
| Послідовно: C = C₁ + C₂ | Паралельно — сума; послідовно — 1/C = 1/C₁ + 1/C₂ |
| W = qU | W = qU/2 (середня напруга під час заряджання) |
| Не розрізняти «від'єднаний» і «під'єднаний» | Від'єднаний — q = const; під'єднаний — U = const |
| 1 мкФ = 10⁻³ Ф | 10⁻⁶ Ф |
| Енергія в обкладках | Енергія в полі між ними |
| Збільшили d — ємність зросла | Зменшилась: C ~ 1/d |
