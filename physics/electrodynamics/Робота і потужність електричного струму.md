# Робота і потужність електричного струму

Електричний струм переносить енергію від джерела до споживача: у лампі вона стає світлом і теплом, у двигуні — механічною роботою, в акумуляторі — хімічною енергією. **Робота струму** A = UIt — скільки енергії перетворено, **потужність** P = UI — як швидко. Частина енергії завжди виділяється як тепло в провідниках — **закон Джоуля–Ленца** Q = I²Rt. Ця тема пояснює рахунки за електроенергію, вибір перерізу проводів, роботу запобіжників і чому лінії електропередач мають надвисоку напругу.

## 1. Робота струму

### 1.1. Виведення
За час t через ділянку проходить заряд q = It. Напруга U — робота поля з переміщення одиничного заряду ([[Потенціал і напруга]]). Отже

**A = qU = UIt.**

З законом Ома (для резистора) отримуємо ще дві форми: **A = I²Rt = U²t/R.**

Одиниця — джоуль (1 Дж = 1 В·А·с).

### 1.2. Кіловат-година
У побуті енергію рахують у кВт·год: 1 кВт·год = 1000 Вт · 3600 с = 3,6·10⁶ Дж = 3,6 МДж. Лічильник електроенергії вимірює саме роботу струму. Чайник 2 кВт за 3 хв: 2 · 0,05 = 0,1 кВт·год.

## 2. Потужність струму

### 2.1. Формули
**P = A/t = UI = I²R = U²/R**, одиниця ват (1 Вт = 1 В·А).

Яку формулу брати, залежить від того, що **стале**:
- при послідовному з'єднанні струм однаковий → зручно P = I²R: більша потужність на **більшому** опорі;
- при паралельному напруга однакова → зручно P = U²/R: більша потужність на **меншому** опорі.

Тому лампи 40 Вт і 100 Вт: у мережі (паралельно) яскравіше 100-ватна, а послідовно — 40-ватна ([[З'єднання провідників]]).

### 2.2. Номінальна потужність
На приладі пишуть потужність при **номінальній напрузі**: «230 В, 100 Вт». Звідси опір: R = U²/P = 529 Ом. При напрузі 115 В потужність буде (115/230)² = 1/4 — лише 25 Вт: P ~ U² ([[Квадратична функція]]).

Типові потужності: світлодіодна лампа 5–10 Вт, ноутбук 50 Вт, холодильник 150 Вт, праска 1–2 кВт, чайник 2–3 кВт, електроплита 6–8 кВт.

## 3. Закон Джоуля–Ленца

### 3.1. Формулювання
Кількість теплоти, що виділяється в провіднику зі струмом:

**Q = I²Rt.**

Джоуль (1841) і Ленц (1842) незалежно встановили це досвідом.

### 3.2. Чому I², а не I
Подвоїмо струм. Удвічі більше електронів проходить щосекунди, і кожен **ще й** удвічі швидше розганяється між зіткненнями (бо при подвоєному струмі через той самий резистор поле теж удвічі більше: U = IR). Удвічі більше зіткнень × удвічі більша енергія кожного = учетверо більше тепла.

### 3.3. Коли Q = A
Якщо вся енергія струму перетворюється на теплоту (нагрівники, лампи розжарювання, резистори), Q = A = UIt. Якщо є двигун або акумулятор, що заряджається, — Q < A: частина енергії йде в механічну чи хімічну. Формула Q = I²Rt для теплоти в обмотці залишається правильною завжди, а U²t/R — лише для чисто теплових споживачів.

### 3.4. Корисне і шкідливе тепло
Корисне: електрочайник, праска, обігрівач, паяльник, лампа розжарювання, зварювання, запобіжник.
Шкідливе: нагрівання проводів, обмоток двигунів, трансформаторів, процесорів. Його відводять радіаторами і вентиляторами.

## 4. Запобіжники і безпека
Якщо струм у проводці перевищить допустимий, провід перегріється — можлива пожежа. **Запобіжник** (плавкий або автоматичний вимикач) розриває коло при надмірному струмі: тонка вставка з легкоплавкого металу нагрівається найсильніше (великий R на одиницю довжини) і плавиться. Автомати використовують біметалеву пластину (повільне перевантаження) і електромагніт (миттєве коротке замикання).

Чому товщі проводи для потужних приладів: менший R — менше тепла I²R на кожному метрі. Для мідного проводу 1,5 мм² допустимий струм ≈ 16 А, 2,5 мм² — ≈ 25 А.

## 5. Передача енергії на відстань
Електростанція передає потужність P = UI через лінію з опором R_л. Втрати в лінії: P_втр = I²R_л = (P/U)²R_л. При тій самій переданій потужності **підвищення напруги в 10 разів зменшує втрати в 100 разів**. Тому ЛЕП працюють при 110–750 кВ, а біля споживача напругу знижують трансформаторами до 230 В ([[Змінний струм і трансформатор]]).

## 6. Кілька способів зрозуміти

| Модель | Що вона показує |
|---|---|
| Енергія на кулон | U — скільки енергії віддає кожен кулон; I — скільки кулонів щосекунди; P = UI |
| Тертя електронів | Тепло — результат зіткнень з ґраткою; I² — кількість × енергія зіткнень |
| Вода, що падає | P = (тиск) × (витрата) — як потужність водоспаду |
| Що стале | Послідовно — I²R, паралельно — U²/R |
| Квадратичність | P ~ U² і P ~ I²: зміна в 2 рази дає 4 рази |

### Ключовий приклад: чайник
Електрочайник 230 В, 2 кВт. Знайдіть струм, опір, час закипання 1,5 л води з 20 °C при ККД 85 % і вартість, якщо 1 кВт·год коштує 4,32 грн.

**Спосіб 1 — по кроках.** I = P/U = 2000/230 ≈ 8,7 А. R = U²/P = 52 900/2000 ≈ 26,5 Ом. Корисна теплота Q = cmΔt = 4200 · 1,5 · 80 = 504 кДж. Затрачено 504/0,85 ≈ 593 кДж. t = 593 000/2000 ≈ 296 с ≈ 5 хв.

**Спосіб 2 — у кВт·год.** 593 кДж = 593/3600 ≈ 0,165 кВт·год. Вартість 0,165 · 4,32 ≈ 0,71 грн.

**Спосіб 3 — перевірка через струм.** Q = I²Rt = 8,7² · 26,5 · 296 ≈ 593 кДж — та сама енергія.

**Спосіб 4 — що як напруга впала до 207 В (−10 %)?** P ~ U²: (0,9)² = 0,81, потужність 1620 Вт, час ≈ 366 с — на 23 % довше. Невелике падіння напруги помітно сповільнює нагрівання.

## 7. Типові помилки

| Помилка | Як правильно |
|---|---|
| кВт·год — одиниця потужності | Одиниця енергії: 3,6 МДж |
| Q = IRt | Q = I²Rt |
| Q = U²t/R для двигуна | Для двигуна лише Q = I²R_обмотки·t |
| При половинній напрузі — половина потужності | Чверть (P = U²/R) |
| Послідовно яскравіше лампа більшої номінальної потужності | Яскравіше лампа меншої номінальної потужності (більший R) |
| Висока напруга ЛЕП — щоб «швидше» доходила енергія | Щоб зменшити струм і втрати I²R |
| Запобіжник ставлять паралельно | Послідовно, щоб розривати коло |
