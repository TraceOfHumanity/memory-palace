# Перший закон термодинаміки

**Перший закон термодинаміки** — закон збереження енергії для теплових процесів: кількість теплоти, передана системі, йде на зміну її внутрішньої енергії і на роботу, яку система виконує: **Q = ΔU + A**. Щоб ним користуватися, треба навчитися обчислювати внутрішню енергію газу і роботу газу. Ця тема з'єднує механіку (робота), МКТ (енергія молекул) і теплоту в одну картину і готує ґрунт для теплових двигунів.

## 1. Внутрішня енергія ідеального газу

### 1.1. Одноатомний газ
У ідеальному газі молекули не взаємодіють, тому потенціальної енергії взаємодії немає. Внутрішня енергія — це лише сумарна кінетична енергія молекул. Для одноатомного газу (He, Ne, Ar) кожна молекула має в середньому (3/2)kT ([[Температура і теплова рівновага]]):

U = N · (3/2)kT = **(3/2)νRT**.

Внутрішня енергія ідеального газу залежить **лише від температури** (і кількості газу), а не від тиску чи об'єму. Тому:
- в ізотермічному процесі ΔU = 0;
- ΔU = (3/2)νRΔT для будь-якого процесу.

### 1.2. Двоатомні гази
Молекули O₂, N₂ ще й обертаються — це дві додаткові «степені свободи». Тому U = (5/2)νRT. Загальне правило: на кожну степінь свободи — (1/2)kT на молекулу. У шкільних задачах, якщо не сказано інше, газ вважають одноатомним.

## 2. Робота газу

### 2.1. Ізобарне розширення
Газ під поршнем площею S розширюється при сталому тиску p, поршень піднімається на Δh. Сила F = pS, робота A = F·Δh = pS·Δh = **p·ΔV**.

- Газ розширюється (ΔV > 0) — газ виконує додатну роботу.
- Газ стискають (ΔV < 0) — робота газу від'ємна, а **зовнішні сили** виконують над газом роботу A' = −A > 0.

### 2.2. Робота — площа під графіком p(V)
Якщо тиск змінюється, розіб'ємо процес на малі ділянки з майже сталим тиском: ΔA = pΔV. Сума — **площа під кривою p(V)** ([[Інтеграл]]). Це та сама ідея, що «шлях = площа під v(t)» і «робота = площа під F(x)».

Важливий наслідок: **робота залежить від шляху** процесу. З того самого стану 1 до стану 2 можна перейти різними кривими на діаграмі p–V — площі під ними різні. Тому робота і теплота — не властивості стану, а характеристики **процесу**, на відміну від внутрішньої енергії, яка визначається лише станом.

### 2.3. Робота в різних процесах
| Процес | Робота |
|---|---|
| Ізохорний (V = const) | A = 0 |
| Ізобарний | A = pΔV = νRΔT |
| Ізотермічний | A = νRT·ln(V₂/V₁) (площа під гіперболою) |
| Циклічний | A = площа всередині циклу на діаграмі p–V |

## 3. Перший закон

### 3.1. Формулювання
**Q = ΔU + A**

Теплота, отримана газом, іде на збільшення внутрішньої енергії і на виконання роботи газом. Або: ΔU = Q + A', де A' — робота зовнішніх сил над газом.

Знаки:
- Q > 0 — газ отримує теплоту; Q < 0 — віддає.
- A > 0 — газ розширюється і виконує роботу; A < 0 — газ стискають.
- ΔU > 0 — газ нагрівається; ΔU < 0 — охолоджується.

### 3.2. Чому вічний двигун першого роду неможливий
Двигун, що виконує роботу без підведення енергії, означав би A > 0 при Q = 0 і ΔU = 0 за цикл — суперечність з першим законом. Енергія не виникає з нічого. Французька академія наук ще 1775 року перестала розглядати проєкти вічних двигунів.

## 4. Перший закон для ізопроцесів

| Процес | ΔU | A | Q | Що відбувається |
|---|---|---|---|---|
| Ізохорний | (3/2)νRΔT | 0 | Q = ΔU | уся теплота йде на нагрівання |
| Ізобарний | (3/2)νRΔT | νRΔT | Q = (5/2)νRΔT | частина на нагрівання, частина на роботу |
| Ізотермічний | 0 | A | Q = A | уся теплота перетворюється на роботу |
| Адіабатний | −A | A | 0 | робота за рахунок внутрішньої енергії |

### 4.1. Теплоємність при сталому об'ємі і тиску
Щоб нагріти газ на ту саму ΔT при сталому тиску, треба **більше** теплоти, ніж при сталому об'ємі: частина йде на роботу розширення. Для одноатомного газу Q_p/Q_V = (5/2)/(3/2) = 5/3. Молярні теплоємності: C_V = (3/2)R, C_p = (5/2)R, C_p − C_V = R. Сенс R: робота, яку виконує 1 моль газу при ізобарному нагріванні на 1 К.

## 5. Адіабатний процес

### 5.1. Що це
Процес **без теплообміну**: Q = 0. Відбувається або в теплоізольованій посудині, або так швидко, що тепло не встигає передатися.

ΔU = −A: газ, розширюючись, виконує роботу **за рахунок своєї внутрішньої енергії** — і охолоджується. Стискаючись, нагрівається.

### 5.2. Приклади
- Велосипедний насос гріється — повітря швидко стискається.
- Дизельний двигун: повітря адіабатно стискають у ~20 разів, воно нагрівається до 600–700 °C, і впорснуте пальне спалахує саме, без свічки.
- Відкрили пляшку шампанського — з'являється туман: газ швидко розширився, охолодився нижче точки роси ([[Пара і вологість повітря]]).
- Хмари: вологе повітря, піднімаючись, потрапляє в зону меншого тиску, розширюється адіабатно і охолоджується.
- Вогнегасник з CO₂ вкривається інеєм.

### 5.3. Адіабата на діаграмі
Адіабата p(V) **крутіша** за ізотерму: при розширенні тиск падає і через збільшення об'єму, і через охолодження. Рівняння: pV^γ = const, γ = C_p/C_V (5/3 для одноатомного, 7/5 для двоатомного).

## 6. Кілька способів зрозуміти

| Модель | Що вона показує |
|---|---|
| Бюджет | Теплота — дохід, нагрівання (ΔU) і робота — витрати |
| Площа під графіком | Робота газу — площа під p(V); залежить від шляху |
| Поршень і молекули | Молекули, відбиваючись від поршня, що віддаляється, втрачають швидкість — газ охолоджується |
| Функція стану | U залежить лише від стану; Q і A — від процесу |
| Таблиця процесів | Кожен ізопроцес — вимикання одного з доданків у Q = ΔU + A |

### Ключовий приклад: ізобарне нагрівання
2 моль одноатомного газу ізобарно нагріли на 50 К. Знайдіть роботу газу, зміну внутрішньої енергії і передану теплоту (R = 8,31).

**Спосіб 1 — формули.** A = νRΔT = 2 · 8,31 · 50 = 831 Дж. ΔU = (3/2)νRΔT = 1246,5 Дж. Q = ΔU + A = 2077,5 Дж.

**Спосіб 2 — молярна теплоємність.** Q = νC_pΔT = 2 · (5/2) · 8,31 · 50 = 2077,5 Дж. З неї: A = Q · (2/5) = 831 Дж, ΔU = Q · (3/5).

**Спосіб 3 — площа.** На діаграмі p–V процес — горизонтальний відрізок. A = pΔV, а pΔV = νRΔT з рівняння стану: та сама величина.

**Спосіб 4 — частки.** Для одноатомного газу при ізобарному нагріванні завжди 60 % теплоти йде на нагрівання, 40 % — на роботу. Знаючи будь-яку з трьох величин, знаходимо інші.

## 7. Типові помилки

| Помилка | Як правильно |
|---|---|
| Робота газу при ізохорному нагріванні = pΔV | ΔV = 0 → A = 0 |
| В ізотермічному процесі Q = 0 | ΔU = 0, а Q = A |
| В адіабатному ΔT = 0 | Q = 0; температура змінюється |
| U залежить від тиску | Для ідеального газу — лише від T |
| Плутати роботу газу і роботу над газом | A' = −A |
| Робота однакова для будь-якого переходу 1 → 2 | Залежить від процесу (площа під кривою) |
| ΔU = (3/2)νRΔT лише для ізохорного | Для будь-якого процесу ідеального газу |
