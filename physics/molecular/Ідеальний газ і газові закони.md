# Ідеальний газ і газові закони

**Ідеальний газ** — модель газу, молекули якого — точки, що не взаємодіють на відстані і пружно зіштовхуються. Для такого газу тиск, об'єм і температура пов'язані одним рівнянням: **pV = νRT** (рівняння Менделєєва–Клапейрона). З нього випливають усі газові закони — Бойля–Маріотта, Гей-Люссака, Шарля. Найкраще в цій темі те, що ці закони можна **вивести** з руху молекул — від механіки окремих ударів до властивостей газу в балоні.

## 1. Модель ідеального газу

Припущення:
1. Розміри молекул нікчемні порівняно з відстанями між ними (у повітрі при нормальних умовах відстань ≈ 10 розмірів молекули).
2. Молекули не взаємодіють на відстані — лише при зіткненнях.
3. Зіткнення пружні (енергія зберігається).
4. Рух хаотичний: усі напрямки рівноймовірні.

Модель добре працює для розріджених газів (повітря, кисень, азот, гелій при звичайних умовах). Погано — при дуже високому тиску чи низькій температурі, коли молекули зближуються і притягання стає помітним (газ близький до зрідження).

## 2. Основне рівняння МКТ

### 2.1. Виведення тиску з ударів молекул
Нехай у кубі з ребром L є N молекул масою m₀. Розглянемо одну молекулу з проекцією швидкості vₓ на вісь x.
- Удар об стінку пружний: vₓ змінюється на −vₓ, зміна імпульсу 2m₀vₓ ([[Імпульс і закон збереження імпульсу]]).
- До тієї ж стінки молекула повертається через час 2L/vₓ.
- Середня сила від однієї молекули: F = Δp/Δt = 2m₀vₓ/(2L/vₓ) = m₀vₓ²/L.

Для N молекул, з урахуванням що в середньому vₓ² = v²/3 (три рівноправні напрямки): F = Nm₀v̄²/(3L). Тиск p = F/L²:

**p = (1/3)·n·m₀·v̄²**, n = N/V — концентрація молекул (м⁻³).

Через середню кінетичну енергію Ē = m₀v̄²/2:

**p = (2/3)·n·Ē.**

Тиск газу — це сумарний «імпульсний дощ» молекул: він пропорційний кількості молекул в одиниці об'єму і їхній середній енергії.

### 2.2. Зв'язок з температурою
Досліди показують, що p = nkT ([[Температура і теплова рівновага]]). Порівнявши з p = (2/3)nĒ:

**Ē = (3/2)kT.**

Це і є мікроскопічний зміст температури.

## 3. Рівняння стану

### 3.1. Рівняння Менделєєва–Клапейрона
p = nkT, n = N/V, N = νN_A, k·N_A = R:

**pV = νRT = (m/M)·RT**

- R = 8,31 Дж/(моль·К) — **універсальна газова стала**;
- ν — кількість речовини (моль);
- T — **абсолютна** температура (К).

Рівняння пов'язує всі макропараметри: знаючи три, знайдемо четвертий.

### 3.2. Молярний об'єм
При нормальних умовах (p₀ = 101 325 Па, T₀ = 273 К) один моль **будь-якого** газу займає V = RT/p ≈ 22,4 л. Кількість молекул в одиниці об'єму не залежить від роду газу — це **закон Авогадро**. Тяжчі молекули рухаються повільніше, але б'ють сильніше, і результат однаковий.

### 3.3. Густина газу
З pV = (m/M)RT: **ρ = pM/(RT)**. Густина пропорційна тиску і молярній масі, обернено пропорційна температурі. Звідси: гаряче повітря легше за холодне (повітряні кулі), гелій і водень легші за повітря.

### 3.4. Рівняння Клапейрона (для сталої маси)
Якщо кількість газу не змінюється: **pV/T = const**, або p₁V₁/T₁ = p₂V₂/T₂.

## 4. Ізопроцеси

Процес, у якому один з параметрів (T, p чи V) сталий. Для сталої маси газу:

### 4.1. Ізотермічний (T = const) — закон Бойля–Маріотта
**pV = const**, p₁V₁ = p₂V₂.

Стиснули газ удвічі — тиск подвоївся. Пояснення: молекули тієї самої швидкості, але в меншому об'ємі — частіше б'ють у стінки. Графік p(V) — **гіпербола** (ізотерма), [[Степеневі функції]]. Що вища температура, то далі від осей ізотерма.

Приклади: повільне стискання в насосі, бульбашка повітря, що спливає з глибини і розширюється.

### 4.2. Ізобарний (p = const) — закон Гей-Люссака
**V/T = const**, V₁/T₁ = V₂/T₂.

Нагріли газ під легким поршнем — газ розширюється пропорційно абсолютній температурі. Графік V(T) — пряма через початок координат (ізобара). Від 0 °C кожен градус змінює об'єм на 1/273 початкового.

### 4.3. Ізохорний (V = const) — закон Шарля
**p/T = const**, p₁/T₁ = p₂/T₂.

Нагріли закритий балон — тиск зростає пропорційно T. Графік p(T) — пряма через початок (ізохора). Продовження ізохор різних газів до p = 0 перетинається при T = 0 К — так і знайшли абсолютний нуль. Звідси: не можна кидати аерозольні балончики у вогонь; шини в спеку «тугіші».

### 4.4. Таблиця
| Процес | Сталий | Закон | Графік |
|---|---|---|---|
| Ізотермічний | T | pV = const | p(V) — гіпербола |
| Ізобарний | p | V/T = const | V(T) — пряма через 0 |
| Ізохорний | V | p/T = const | p(T) — пряма через 0 |

## 5. Суміші газів — закон Дальтона
Тиск суміші дорівнює сумі **парціальних тисків** — тисків, які створив би кожен газ окремо в тому самому об'ємі: p = p₁ + p₂ + … Молекули різних газів б'ють у стінку незалежно. Повітря: азот ≈ 78 % тиску, кисень ≈ 21 %.

## 6. Кілька способів зрозуміти

| Модель | Що вона показує |
|---|---|
| Град молекул | Тиск — удари: більше молекул або швидші молекули — більший тиск |
| Один закон замість трьох | Усі ізопроцеси — окремі випадки pV = νRT |
| Пропорції | p ~ 1/V, V ~ T, p ~ T — лише з абсолютною температурою |
| Графіки | Гіпербола і прямі через початок координат — «паспорти» процесів |
| Однаковий моль | 22,4 л для будь-якого газу — закон Авогадро |

### Ключовий приклад: балон з киснем
Балон об'ємом 40 л містить кисень (M = 0,032 кг/моль) під тиском 150 атм (1,5·10⁷ Па) при 27 °C. Знайдіть масу кисню і тиск, якщо балон нагріється до 57 °C.

**Спосіб 1 — рівняння стану.** m = pVM/(RT) = 1,5·10⁷ · 0,04 · 0,032/(8,31 · 300) ≈ 7,7 кг. Для нагрівання — ізохорний процес: p₂ = p₁T₂/T₁ = 150 · 330/300 = 165 атм.

**Спосіб 2 — через нормальні умови.** Зведемо газ до 1 атм і 273 К: V₀ = 40 л · 150 · 273/300 ≈ 5460 л. Молів: 5460/22,4 ≈ 244, маса 244 · 32 г ≈ 7,8 кг (різниця — округлення).

**Спосіб 3 — через молекули.** n = p/(kT) = 1,5·10⁷/(1,38·10⁻²³ · 300) ≈ 3,6·10²⁷ м⁻³. N = nV ≈ 1,45·10²⁶. ν = N/N_A ≈ 241 моль, m ≈ 7,7 кг.

**Спосіб 4 — пропорція для нагрівання.** Абсолютна температура зросла на 10 % (300 → 330 К), тиск теж на 10 %. Типова пастка: якщо порахувати в °C (27 → 57, «удвічі»), вийшло б 300 атм — небезпечна помилка.

## 7. Типові помилки

| Помилка | Як правильно |
|---|---|
| Температура в °C у рівнянні стану | Тільки в К |
| Тиск в атм і об'єм у л змішувати з R = 8,31 | В СІ: Па, м³ |
| Нагріли з 20 до 40 °C — тиск подвоївся | 293 → 313 К: +6,8 % |
| Ізотерма — пряма | Гіпербола p = const/V |
| Важкий газ має більший тиск при тих самих n, T | p = nkT від маси молекули не залежить |
| Молярна маса O₂ = 16 г/моль | 32 г/моль (дві атоми) |
| Рівняння Клапейрона для газу, що витікає | pV/T = const лише для сталої маси |
