# М'язи за рухами в суглобах (зведена таблиця)

Файл відповідає на питання: **які м'язи виконують певний рух**. Повні описи м'язів (початок, прикріплення, нерв) — у файлах по ділянках. Скорочення: **А** — агоністи (основні); **С** — синергісти й допоміжні; **Н** — нерв (сегменти).

Пов'язані файли: [[М'язова система — огляд]], [[Суглоби]], [[Іннервація м'язів — зведення]], [[М'язи голови]], [[М'язи шиї]], [[М'язи спини]], [[М'язи грудної клітки і діафрагма]], [[М'язи живота]], [[М'язи плечового пояса і плеча]], [[М'язи передпліччя і кисті]], [[М'язи тазового пояса і стегна]], [[М'язи гомілки і стопи]], [[М'язи промежини і тазового дна]].

## 1. Голова й шия

### Скронево-нижньощелепний суглоб
| Рух | М'язи |
|---|---|
| Закривання рота (піднімання щелепи) | **А:** жувальний, скроневий, присередній крилоподібний (V₃) |
| Відкривання рота (опускання) | **А:** бічний крилоподібний (V₃) + надпід'язикові (двочеревцевий, щелепно-під'язиковий, підборідно-під'язиковий); **С:** підпід'язикові (фіксують під'язикову кістку), підшкірний м'яз шиї |
| Висування | бічний + присередній крилоподібні, жувальний (поверхнева частина) |
| Втягування | скроневий (задні волокна), жувальний (глибока частина) |
| Бічні рухи | крилоподібні протилежного боку + скроневий, жувальний того ж боку |

### Атланто-потиличний і шийний відділ
| Рух | М'язи |
|---|---|
| **Кивання (згинання голови)** | **А:** передній прямий і довгий м'язи голови; **С:** груднинно-ключично-соскоподібний, надпід'язикові |
| **Розгинання голови** | **А:** напівостистий м'яз голови, ремінний м'яз голови, задні прямі, верхній косий, найдовший м'яз голови, трапецієподібний (верх); груднинно-ключично-соскоподібний (двостороннє) |
| **Згинання шиї** | довгий м'яз шиї, передній драбинчастий, груднинно-ключично-соскоподібний |
| **Розгинання шиї** | ремінні, напівостисті, випрямляч хребта (шийні частини), трапецієподібний |
| **Бічний нахил** | драбинчасті, груднинно-ключично-соскоподібний, ремінні, найдовший, піднімач лопатки, бічний прямий м'яз голови |
| **Обертання голови** | **А (в свій бік):** нижній косий м'яз голови (C1–C2), великий задній прямий, ремінний м'яз голови; **А (в протилежний бік):** груднинно-ключично-соскоподібний, напівостистий |

### Під'язикова кістка (ковтання)
| Рух | М'язи |
|---|---|
| Піднімання | надпід'язикові (двочеревцевий, шилопід'язиковий, щелепно-під'язиковий, підборідно-під'язиковий), шилоглотковий |
| Опускання | підпід'язикові (груднинно-під'язиковий, лопатково-під'язиковий, груднинно-щитоподібний, щито-під'язиковий) |

### Очі
| Рух | М'язи (нерв) |
|---|---|
| Відведення | бічний прямий (VI) |
| Приведення | присередній прямий (III) |
| Піднімання | верхній прямий (III), нижній косий (III) |
| Опускання | нижній прямий (III), верхній косий (IV) |
| Інторсія (обертання зверху всередину) | верхній косий, верхній прямий |
| Екторсія | нижній косий, нижній прямий |

## 2. Тулуб

### Хребет
| Рух | М'язи |
|---|---|
| **Згинання** | прямий м'яз живота, зовнішній і внутрішній косі, великий поперековий; шийна частина — драбинчасті, довгий м'яз шиї |
| **Розгинання** | випрямляч хребта (клубово-реберний, найдовший, остистий), поперечно-остисті (багатороздільні, напівостисті), міжостисті, квадратний м'яз попереку |
| **Бічний нахил** | внутрішній і зовнішній косі, квадратний м'яз попереку, випрямляч хребта, міжпоперечні (того ж боку) |
| **Обертання** | зовнішній косий (протилежного боку) + внутрішній косий (того ж боку), багатороздільні, обертачі, напівостисті (в протилежний бік) |

### Грудна клітка (дихання)
| Фаза | М'язи |
|---|---|
| Спокійний вдих | діафрагма (C3–C5), зовнішні міжреброві, м'язи, що піднімають ребра |
| Форсований вдих | + груднинно-ключично-соскоподібний, драбинчасті, великий і малий грудні, передній зубчастий, задній верхній зубчастий, випрямляч хребта |
| Спокійний видих | **пасивний** (еластична віддача) |
| Форсований видих | внутрішні міжреброві, підреброві, поперечний м'яз грудної клітки, м'язи живота, квадратний м'яз попереку, задній нижній зубчастий, найширший м'яз спини |

### Внутрішньочеревний тиск
Діафрагма + поперечний м'яз живота + косі + прямі + тазове дно.

## 3. Верхня кінцівка

### Лопатка (плечовий пояс)
| Рух | М'язи |
|---|---|
| Піднімання | трапецієподібний (верхня), піднімач лопатки, ромбоподібні |
| Опускання | трапецієподібний (нижня), малий грудний, підключичний |
| Приведення (ретракція) | трапецієподібний (середня), ромбоподібні |
| Відведення (протракція) | передній зубчастий, малий грудний |
| Обертання вгору | трапецієподібний (верхня й нижня), передній зубчастий |
| Обертання вниз | ромбоподібні, піднімач лопатки, малий грудний |

### Плечовий суглоб
| Рух | М'язи |
|---|---|
| **Згинання** | дельтоподібний (передня), великий грудний (ключична), дзьобоплечовий, двоголовий |
| **Розгинання** | дельтоподібний (задня), найширший м'яз спини, великий круглий, триголовий (довга головка) |
| **Відведення** | дельтоподібний (середня), надостьовий; >90° — обертання лопатки |
| **Приведення** | великий грудний, найширший м'яз спини, великий круглий, дзьобоплечовий, триголовий (довга головка) |
| **Внутрішнє обертання** | підлопатковий, великий грудний, найширший, великий круглий, дельтоподібний (передня) |
| **Зовнішнє обертання** | підостьовий, малий круглий, дельтоподібний (задня) |

### Ліктьовий суглоб
| Рух | М'язи |
|---|---|
| **Згинання** | плечовий (головний), двоголовий, плечо-променевий; допоміжні: круглий пронатор, згиначі зап'ястка |
| **Розгинання** | триголовий, ліктьовий м'яз |

### Передпліччя
| Рух | М'язи |
|---|---|
| **Пронація** | квадратний пронатор, круглий пронатор; плечо-променевий (із супінованого положення до середнього) |
| **Супінація** | супінатор, двоголовий (при зігнутому лікті); плечо-променевий (з пронованого до середнього) |

### Зап'ясток
| Рух | М'язи |
|---|---|
| Згинання | променевий і ліктьовий згиначі зап'ястка, довгий долонний; допоміжні: згиначі пальців, довгий відвідний |
| Розгинання | довгий і короткий променеві розгиначі зап'ястка, ліктьовий розгинач зап'ястка; допоміжні: розгинач пальців |
| Променеве відведення | променевий згинач, довгий і короткий променеві розгиначі, довгий відвідний, короткий розгинач великого пальця |
| Ліктьове приведення | ліктьовий згинач і розгинач зап'ястка |

### Пальці II–V
| Рух | М'язи |
|---|---|
| Згинання MCP | червоподібні, міжкісткові, поверхневий і глибокий згиначі |

| Згинання DIP | глибокий згинач пальців |

| Розгинання IP | червоподібні, міжкісткові (через розгинальний апарат) |
| Відведення | тильні міжкісткові (DAB), відвідний м'яз мізинця |
| Приведення | долонні міжкісткові (PAD) |

### Великий палець
| Рух | М'язи |
|---|---|
| Згинання | довгий згинач, короткий згинач |
| Розгинання | довгий і короткий розгиначі |

| Відведення (від долоні) | короткий відвідний |
| Приведення | привідний м'яз, перший тильний міжкістковий |

## 4. Нижня кінцівка

### Кульшовий суглоб
| Рух | М'язи |
|---|---|
| **Згинання** | клубово-поперековий, прямий м'яз стегна, кравецький, натягувач широкої фасції, гребінний, привідні |
| **Розгинання** | великий сідничий, задні м'язи стегна, великий привідний (сухожилкова частина) |
| **Відведення** | середній і малий сідничі, натягувач широкої фасції, грушоподібний (при згинанні) |
| **Приведення** | довгий, короткий і великий привідні, тонкий, гребінний |
| **Зовнішнє обертання** | великий сідничий, грушоподібний, близнюкові, внутрішній і зовнішній затульні, квадратний м'яз стегна, кравецький |
| **Внутрішнє обертання** | малий і середній сідничі (передні), натягувач широкої фасції |

### Колінний суглоб
| Рух | М'язи |
|---|---|

| Згинання | задні м'язи стегна, тонкий, кравецький, литковий, підколінний, підошовний |
| Внутрішнє обертання гомілки | напівсухожилковий, напівперетинчастий, підколінний, кравецький, тонкий |
| Зовнішнє обертання гомілки | двоголовий м'яз стегна |

| Рух | М'язи |
|---|---|
| Тильне згинання | передній великогомілковий, довгий розгинач пальців, довгий розгинач великого пальця, третій малогомілковий |
| Підошовне згинання | литковий, камбалоподібний; допоміжні: задній великогомілковий, довгі згиначі пальців і великого пальця, малогомілкові, підошовний |

## 5. Тести сили за сегментами (міотоми) і рефлекси

Рухи, за якими оцінюють **міотоми** (сегментарна іннервація):

| Сегмент | Рух для перевірки | Типовий м'яз |
|---|---|---|
| **C1–C2** | згинання шиї | довгі м'язи шиї |
| **C3** | бічний нахил шиї | драбинчасті |
| **C4** | піднімання плечей | трапецієподібний, піднімач лопатки |
| **C5** | відведення плеча | дельтоподібний, надостьовий; зовнішнє обертання (підостьовий) |
| **C5–C6** | згинання ліктя | двоголовий |
| **C6** | розгинання зап'ястка | променеві розгиначі зап'ястка |
| **C7** | розгинання ліктя; згинання зап'ястка | триголовий; променевий згинач |
| **C8** | згинання пальців | глибокий згинач пальців |
| **T1** | відведення пальців | тильні міжкісткові |
| **L1–L2** | згинання стегна | клубово-поперековий |
| **L3** | розгинання коліна | чотириголовий |
| **L4** | тильне згинання стопи | передній великогомілковий |
| **L5** | розгинання великого пальця стопи; відведення стегна | довгий розгинач великого пальця; середній сідничий |
| **S1** | підошовне згинання («на пальцях»), еверсія | литковий, камбалоподібний, малогомілкові |
| **S2** | згинання коліна | задні м'язи стегна |
| **S2–S4** | сфінктери, м'язи промежини | |

### Сухожилкові рефлекси
| Рефлекс | Сегмент |
|---|---|
| Двоголового м'яза плеча | C5–C6 |
| Плечо-променевий | C5–C6 |
| Триголового м'яза плеча | C7 |
| Колінний | L2–L4 (переважно L3–L4) |
| Ахіллів | S1–S2 |

Шкала сили м'язів (MRC): **0** — немає скорочення; **1** — видно скорочення, рухів немає; **2** — рух без сили тяжіння; **3** — рух проти сили тяжіння; **4** — рух проти помірного опору; **5** — норма.
