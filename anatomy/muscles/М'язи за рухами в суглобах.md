# М'язи за рухами в суглобах (зведена таблиця)

Файл відповідає на питання: **які м'язи виконують певний рух**. Повні описи м'язів (початок, прикріплення, нерв) — у файлах по ділянках. Скорочення: **А** — агоністи (основні); **С** — синергісти й допоміжні; **Н** — нерв (сегменти).

## 1. Голова й шия

### Скронево-нижньощелепний суглоб
| Рух | М'язи |
|---|---|
| Закривання рота (піднімання щелепи) | **А:** жувальний, скроневий, присередній крилоподібний (V₃) |
| Відкривання рота (опускання) | **А:** бічний крилоподібний (V₃) + надпід'язикові (двочеревцевий, щелепно-під'язиковий, підборідно-під'язиковий); **С:** підпід'язикові (фіксують під'язикову кістку), підшкірний м'яз шиї |
| Висування | бічний + присередній крилоподібні, жувальний (поверхнева частина) |
| Втягування | скроневий (задні волокна), жувальний (глибока частина) |
| Бічні рухи | крилоподібні протилежного боку + скроневий, жувальний того ж боку |

### Атланто-потиличний і шийний відділ
| Рух | М'язи |
|---|---|
| **Кивання (згинання голови)** | **А:** передній прямий і довгий м'язи голови; **С:** груднинно-ключично-соскоподібний, надпід'язикові |
| **Розгинання голови** | **А:** напівостистий м'яз голови, ремінний м'яз голови, задні прямі, верхній косий, найдовший м'яз голови, трапецієподібний (верх); груднинно-ключично-соскоподібний (двостороннє) |
| **Згинання шиї** | довгий м'яз шиї, передній драбинчастий, груднинно-ключично-соскоподібний |
| **Розгинання шиї** | ремінні, напівостисті, випрямляч хребта (шийні частини), трапецієподібний |
| **Бічний нахил** | драбинчасті, груднинно-ключично-соскоподібний, ремінні, найдовший, піднімач лопатки, бічний прямий м'яз голови |
| **Обертання голови** | **А (в свій бік):** нижній косий м'яз голови (C1–C2), великий задній прямий, ремінний м'яз голови; **А (в протилежний бік):** груднинно-ключично-соскоподібний, напівостистий |

### Під'язикова кістка (ковтання)
| Рух | М'язи |
|---|---|
| Піднімання | надпід'язикові (двочеревцевий, шилопід'язиковий, щелепно-під'язиковий, підборідно-під'язиковий), шилоглотковий |
| Опускання | підпід'язикові (груднинно-під'язиковий, лопатково-під'язиковий, груднинно-щитоподібний, щито-під'язиковий) |

### Очі
| Рух | М'язи (нерв) |
|---|---|
| Відведення | бічний прямий (VI) |
| Приведення | присередній прямий (III) |
| Піднімання | верхній прямий (III), нижній косий (III) |
| Опускання | нижній прямий (III), верхній косий (IV) |
| Інторсія (обертання зверху всередину) | верхній косий, верхній прямий |
| Екторсія | нижній косий, нижній прямий |

## 2. Тулуб

### Хребет
| Рух | М'язи |
|---|---|
| **Згинання** | прямий м'яз живота, зовнішній і внутрішній косі, великий поперековий; шийна частина — драбинчасті, довгий м'яз шиї |
| **Розгинання** | випрямляч хребта (клубово-реберний, найдовший, остистий), поперечно-остисті (багатороздільні, напівостисті), міжостисті, квадратний м'яз попереку |
| **Бічний нахил** | внутрішній і зовнішній косі, квадратний м'яз попереку, випрямляч хребта, міжпоперечні (того ж боку) |
| **Обертання** | зовнішній косий (протилежного боку) + внутрішній косий (того ж боку), багатороздільні, обертачі, напівостисті (в протилежний бік) |

### Грудна клітка (дихання)
| Фаза | М'язи |
|---|---|
| Спокійний вдих | діафрагма (C3–C5), зовнішні міжреброві, м'язи, що піднімають ребра |
| Форсований вдих | + груднинно-ключично-соскоподібний, драбинчасті, великий і малий грудні, передній зубчастий, задній верхній зубчастий, випрямляч хребта |
| Спокійний видих | **пасивний** (еластична віддача) |
| Форсований видих | внутрішні міжреброві, підреброві, поперечний м'яз грудної клітки, м'язи живота, квадратний м'яз попереку, задній нижній зубчастий, найширший м'яз спини |

### Внутрішньочеревний тиск
Діафрагма + поперечний м'яз живота + косі + прямі + тазове дно.

| Рух | М'язи |

| **Внутрішнє обертання** | підлопатковий, великий грудний, найширший, великий круглий, дельтоподібний (передня) |

|---|---|
| **Згинання** | плечовий (головний), двоголовий, плечо-променевий; допоміжні: круглий пронатор, згиначі зап'ястка |

| **Супінація** | супінатор, двоголовий (при зігнутому лікті); плечо-променевий (з пронованого до середнього) |

|---|---|

| Розгинання | довгий і короткий променеві розгиначі зап'ястка, ліктьовий розгинач зап'ястка; допоміжні: розгинач пальців |
| Променеве відведення | променевий згинач, довгий і короткий променеві розгиначі, довгий відвідний, короткий розгинач великого пальця |

## 4. Нижня кінцівка

### Кульшовий суглоб
| Рух | М'язи |
|---|---|
| **Згинання** | клубово-поперековий, прямий м'яз стегна, кравецький, натягувач широкої фасції, гребінний, привідні |
| **Розгинання** | великий сідничний, задні м'язи стегна, великий привідний (сухожилкова частина) |

| **Зовнішнє обертання** | великий сідничний, грушоподібний, близнюкові, внутрішній і зовнішній затульні, квадратний м'яз стегна, кравецький |
| **Внутрішнє обертання** | малий і середній сідничні (передні), натягувач широкої фасції |

| Підошовне згинання | литковий, камбалоподібний; допоміжні: задній великогомілковий, довгі згиначі пальців і великого пальця, малогомілкові, підошовний |

## 5. Тести сили за сегментами (міотоми) і рефлекси

Рухи, за якими оцінюють **міотоми** (сегментарна іннервація):

| Сегмент | Рух для перевірки | Типовий м'яз |
|---|---|---|
| **C1–C2** | згинання шиї | довгі м'язи шиї |
| **C3** | бічний нахил шиї | драбинчасті |
| **C4** | піднімання плечей | трапецієподібний, піднімач лопатки |
| **C5** | відведення плеча | дельтоподібний, надостьовий; зовнішнє обертання (підостьовий) |
| **C5–C6** | згинання ліктя | двоголовий |
| **C6** | розгинання зап'ястка | променеві розгиначі зап'ястка |
| **C7** | розгинання ліктя; згинання зап'ястка | триголовий; променевий згинач |
| **C8** | згинання пальців | глибокий згинач пальців |
| **T1** | відведення пальців | тильні міжкісткові |
| **L1–L2** | згинання стегна | клубово-поперековий |
| **L3** | розгинання коліна | чотириголовий |
| **L4** | тильне згинання стопи | передній великогомілковий |
| **L5** | розгинання великого пальця стопи; відведення стегна | довгий розгинач великого пальця; середній сідничний |
| **S1** | підошовне згинання («на пальцях»), еверсія | литковий, камбалоподібний, малогомілкові |
| **S2** | згинання коліна | задні м'язи стегна |
| **S2–S4** | сфінктери, м'язи промежини | |

### Сухожилкові рефлекси
| Рефлекс | Сегмент |
|---|---|
| Двоголового м'яза плеча | C5–C6 |
| Плечо-променевий | C5–C6 |
| Триголового м'яза плеча | C7 |
| Колінний | L2–L4 (переважно L3–L4) |
| Ахіллів | S1–S2 |

Шкала сили м'язів (MRC): **0** — немає скорочення; **1** — видно скорочення, рухів немає; **2** — рух без сили тяжіння; **3** — рух проти сили тяжіння; **4** — рух проти помірного опору; **5** — норма.

## Питання і завдання для закріплення

Спершу відповідайте самостійно, потім звіряйтеся з відповідями в кінці розділу.

**1.** Які м'язи закривають і відкривають рот?

**2.** Які м'язи згинають і розгинають голову в атланто-потиличному суглобі?

**3.** Які м'язи повертають голову в свій і протилежний бік?

**4.** Які м'язи ока піднімають і опускають очне яблуко?

**5.** Які м'язи виконують інторсію й екторсію ока?

**6.** Які м'язи згинають, розгинають і обертають хребет?

**7.** Які м'язи працюють при спокійному і форсованому вдиху й видиху?

**8.** Які м'язи піднімають, опускають, приводять і відводять лопатку?

**9.** Які м'язи обертають лопатку вгору і вниз?

**10.** Які м'язи згинають, розгинають, відводять і приводять плече?

**11.** Які м'язи обертають плече назовні і всередину?

**12.** Які м'язи згинають і розгинають лікоть?

**13.** Які м'язи пронують і супінують передпліччя? Яка роль плечо-променевого?

**14.** Які м'язи згинають і розгинають зап'ясток, відводять і приводять кисть?

**15.** Хто згинає MCP, PIP і DIP суглоби пальців II–V?

**16.** Хто відводить і приводить пальці кисті?

**17.** Які м'язи рухають великий палець кисті в усіх напрямках?

**18.** Які м'язи згинають, розгинають, відводять і приводять стегно?

**19.** Які м'язи обертають стегно назовні і всередину?

**20.** Які м'язи згинають і розгинають коліно, обертають гомілку?

**21.** Які м'язи виконують тильне й підошовне згинання, інверсію й еверсію?

**22.** Які м'язи рухають пальці стопи?

**23.** Назвіть міотоми верхньої кінцівки з рухом і м'язом для перевірки.

**24.** Назвіть міотоми нижньої кінцівки з рухом і м'язом для перевірки.

**25.** Назвіть сухожилкові рефлекси та їхні сегменти.

### Відповіді

1. Закривають — жувальний, скроневий, присередній крилоподібний; відкривають — бічний крилоподібний і надпід'язикові.
2. Згинають — передній прямий і довгий м'язи голови (допомагають груднинно-ключично-соскоподібні й надпід'язикові); розгинають — напівостистий, ремінний, задні прямі, верхній косий, найдовший м'язи голови, трапецієподібний.
3. У свій бік — нижній косий, великий задній прямий, ремінний м'яз голови; у протилежний — груднинно-ключично-соскоподібний.
4. Піднімають — верхній прямий і нижній косий; опускають — нижній прямий і верхній косий.
5. Інторсія — верхній косий і верхній прямий; екторсія — нижній косий і нижній прямий.
6. Згинають — прямий і косі м'язи живота, великий поперековий; розгинають — випрямляч хребта, поперечно-остисті, міжостисті, квадратний м'яз попереку; обертають — зовнішній косий протилежного й внутрішній косий свого боку, багатороздільні, обертачі.
7. Спокійний вдих — діафрагма, зовнішні міжреброві; форсований — плюс драбинчасті, груднинно-ключично-соскоподібні, грудні, передній і задній верхній зубчасті; спокійний видих пасивний; форсований — внутрішні міжреброві, м'язи живота, квадратний м'яз попереку, задній нижній зубчастий.
8. Піднімають — трапецієподібний (верхня частина), підіймач лопатки, ромбоподібні; опускають — нижня частина трапецієподібного, малий грудний, підключичний; приводять — середня частина трапецієподібного, ромбоподібні; відводять — передній зубчастий, малий грудний.
9. Угору — трапецієподібний (верхня й нижня частини), передній зубчастий; униз — ромбоподібні, підіймач лопатки, малий грудний.
10. Згинають — передня частина дельтоподібного, ключична частина великого грудного, дзьобоплечовий, двоголовий; розгинають — задня частина дельтоподібного, найширший, великий круглий, довга головка триголового; відводять — дельтоподібний, надостьовий; приводять — великий грудний, найширший, великий круглий, дзьобоплечовий.
11. Назовні — підостьовий, малий круглий, задня частина дельтоподібного; всередину — підлопатковий, великий грудний, найширший, великий круглий, передня частина дельтоподібного.
12. Згинають — плечовий, двоголовий, плечо-променевий; розгинають — триголовий, ліктьовий.
13. Пронують — квадратний і круглий пронатори; супінують — супінатор, двоголовий; плечо-променевий повертає передпліччя в середнє положення з обох крайніх.
14. Згинають — променевий і ліктьовий згиначі, довгий долонний; розгинають — довгий і короткий променеві й ліктьовий розгиначі зап'ястка; відводять — променеві згинач і розгиначі, довгий відвідний і короткий розгинач великого пальця; приводять — ліктьові згинач і розгинач.
15. MCP — червоподібні, міжкісткові, згиначі; PIP — поверхневий згинач; DIP — глибокий згинач.
16. Відводять — тильні міжкісткові, відвідний мізинця; приводять — долонні міжкісткові.
17. Згинання — довгий і короткий згиначі; розгинання — довгий і короткий розгиначі; відведення — довгий (у площині кисті) і короткий (від долоні) відвідні; приведення — привідний і I тильний міжкістковий; протиставлення — протиставляч.
18. Згинають — клубово-поперековий, прямий стегна, кравецький, натягувач широкої фасції, гребінний; розгинають — великий сідничний, задня група стегна; відводять — середній і малий сідничні, натягувач широкої фасції; приводять — привідні, тонкий, гребінний.
19. Назовні — великий сідничний, грушоподібний, близнюкові, затульні, квадратний стегна, кравецький; всередину — передні волокна середнього й малого сідничних, натягувач широкої фасції.
20. Розгинає — чотириголовий; згинають — задня група стегна, тонкий, кравецький, литковий, підколінний; всередину — напівсухожилковий, напівперетинчастий, підколінний, тонкий, кравецький; назовні — двоголовий.
21. Тильне — передній великогомілковий, довгі розгиначі, третій малогомілковий; підошовне — литковий, камбалоподібний (з допоміжними); інверсія — передній і задній великогомілкові; еверсія — малогомілкові.
22. Великий палець — довгий і короткий згиначі та розгиначі; II–V — довгий і короткий згиначі, квадратний м'яз підошви, червоподібні, довгий і короткий розгиначі; відведення — тильні міжкісткові й відвідні; приведення — підошовні міжкісткові, привідний великого пальця.
23. C5 — відведення плеча (дельтоподібний), C5–C6 — згинання ліктя (двоголовий), C6 — розгинання зап'ястка (променеві розгиначі), C7 — розгинання ліктя (триголовий), C8 — згинання пальців (глибокий згинач), T1 — відведення пальців (тильні міжкісткові).
24. L1–L2 — згинання стегна (клубово-поперековий), L3 — розгинання коліна (чотириголовий), L4 — тильне згинання стопи (передній великогомілковий), L5 — розгинання великого пальця (довгий розгинач великого пальця), S1 — підошовне згинання (литковий і камбалоподібний).
25. Двоголовий і плечо-променевий — C5–C6, триголовий — C7, колінний — L2–L4 (переважно L3–L4), ахіллів — S1–S2.
