# М'язова система — огляд (*systema musculare*, *myologia*)

Наука про м'язи — **міологія**.

Пов'язані файли: [[Скелет — огляд]], [[Суглоби]], [[Анатомічна термінологія]], [[Скелетний м'яз — будова і скорочення]], [[Допоміжний апарат м'язів]], [[М'язи за рухами в суглобах]], [[Іннервація м'язів — зведення]].

## 1. Види м'язової тканини

| Ознака | Скелетна (поперечносмугаста) | Серцева | Гладка |
|---|---|---|---|
| Розташування | кріпиться до кісток | стінка серця | стінки порожнистих органів, судин, шкіра |
| Клітина | довге багатоядерне волокно (10–100 мкм завтовшки, довжина до 30 см і більше) | одно- або двоядерна, розгалужена | веретеноподібна, одне ядро (довжина 20–500 мкм) |
| Смугастість | є | є | немає |
| Контроль | довільний (свідомий) | мимовільний | мимовільний |
| Нервова регуляція | соматичні рухові нейрони | вегетативні нерви; автоматія | вегетативні нерви, гормони; автоматія |
| Швидкість скорочення | швидка | середня | повільна |
| Втома | швидка | дуже стійка | дуже стійка |
| Регенерація | обмежена (сателітні клітини) | практично відсутня | добра |
| Особливості | нейром'язові синапси; саркомери | вставні диски, щілинні контакти | немає саркомерів; кальмодулін, міозин-кіназа легких ланцюгів |

Цей розділ описує **скелетні м'язи**.

## 2. Загальні відомості про скелетні м'язи

- Людина має понад 600 скелетних м'язів (за різними підрахунками 640–650).
- Маса: 40–45 % маси тіла в чоловіків, 30–35 % у жінок.
- Функції:
  - **Рух**: м'язи тягнуть за кістки через сухожилки й рухають суглоби.
  - **Підтримка положення тіла** (постава, тонус).
  - **Стабілізація суглобів**.
  - **Виробництво тепла** (близько 75 % енергії скорочення виділяється як тепло; тремтіння).
  - **Захист** органів (м'язи живота).
  - **Дихання** (діафрагма, міжреберні м'язи).
  - **Ковтання, мовлення, мімічні рухи.**
  - **Венозне й лімфатичне повернення** («м'язовий насос»).
  - **Запас білка й глікогену**; ендокринна функція (міокіни: IL-6, іризин).
- Властивості: **збудливість**, **провідність**, **скоротливість**, **розтяжність**, **пружність**.
- Найдовший м'яз — кравецький (*m. sartorius*). Найбільший м'яз — великий сідничний. Найменший — стремінцевий. Найсильніший за масою — жувальний. Найтовще сухожилля — ахіллове (п'яткове).

## 3. Будова м'яза як органа

| Частина | Латинська назва | Опис |
|---|---|---|
| Черевце | *venter* | Скорочувана частина. Складається з м'язових волокон |
| Сухожилок | *tendo* | Щільна колагенова частина. Передає силу до кістки. Початковий кінець — **головка** (*caput*), кінцевий — **хвіст** (*cauda*) |
| Апоневроз | *aponeurosis* | Плоский широкий сухожилок |
| Початок | *origo* | Нерухоме (або менш рухоме) прикріплення, зазвичай проксимальне |
| Прикріплення | *insertio* | Рухоме прикріплення, зазвичай дистальне |
| Футляр | *vagina* | Фасціальна оболонка м'яза |

- **Початок і прикріплення** взаємозамінні: при зміні опорної точки (підтягування на перекладині) рухаються обидва кінці.
- У багатьох м'язах кілька **головок** (двоголовий: 2; триголовий: 3; чотириголовий: 4).

### Оболонки м'яза (з середини назовні)
- **Ендомізій** (*endomysium*) — навколо кожного волокна.
- **Перимізій** (*perimysium*) — навколо пучка волокон (**fasciculus**).
- **Епімізій** (*epimysium*) — навколо всього м'яза. Продовження — сухожилок.
- **Фасція** (*fascia*) — зовнішня оболонка (див. [[Допоміжний апарат м'язів]]).

## 4. Класифікація за формою й будовою

### За розташуванням волокон

| Тип | Опис | Приклади | Властивість |
|---|---|---|---|
| **Паралельні** (веретеноподібні, стрічкоподібні) | Волокна паралельні довгій осі | двоголовий м'яз плеча, кравецький, прямий м'яз живота | Великий хід, менша сила |
| **Перисті** (*musculus pennatus*) | Волокна під кутом до сухожилка | | Більша сила, менший хід |
| — одноперисті | Волокна з одного боку сухожилка | довгий розгинач пальців, задній великогомілковий | |
| — двоперисті | З обох боків | прямий м'яз стегна, довгий згинач великого пальця | |
| — багатоперисті | Багато сухожилків | дельтоподібний (середня частина), підлопатковий | Найбільша сила |
| **Збіжні** (трикутні) | Віяло волокон до одного сухожилка | великий грудний, малий сідничий, скроневий | Різні напрямки тяги |
| **Колові** (сфінктери) | Кільце навколо отвору | коловий м'яз рота, коловий м'яз ока, сфінктери | Закривають отвір |
| **Двочеревцеві** | Два черевця й проміжне сухожилля | двочеревцевий, лопатково-під'язиковий | |
| **З сухожилковими перемичками** | Поперечні сухожилкові смуги | прямий м'яз живота (3–4 перемички) | |

**Фізіологічний поперечний переріз** (*PCSA*) — сума площ перерізів усіх волокон. Він визначає силу м'яза. У перистих м'язів PCSA більший за анатомічний переріз.

### За формою
Довгі, короткі, широкі, колові, квадратні, трикутні, ромбоподібні, зубчасті, камбалоподібні, пірамідальні, круглі.

### За кількістю суглобів, через які проходить м'яз
- **Односуглобові** — діють на один суглоб (плечовий м'яз).
- **Двосуглобові** — на два суглоби (прямий м'яз стегна; двоголовий м'яз стегна — довга головка; двоголовий м'яз плеча).
- **Багатосуглобові** — на кілька (згиначі й розгиначі пальців).

**Активна недостатність** — двосуглобовий м'яз не розвиває достатньої сили, коли він вкорочений в обох суглобах одночасно (прямий м'яз стегна слабне при одночасному згинанні стегна й розгинанні коліна).
**Пасивна недостатність** — м'яз не дозволяє повний рух в обох суглобах одночасно (наприклад, підколінні м'язи обмежують повне згинання у стегні при розігнутому коліні).
**Тенодезний ефект** — розгинання зап'ястка пасивно згинає пальці (розтягує згиначі), а згинання зап'ястка пасивно розгинає їх.

### За функцією
| Термін | Значення |
|---|---|
| **Агоніст** (провідний м'яз, *prime mover*) | Основний м'яз, що виконує рух |
| **Антагоніст** | М'яз, що виконує протилежний рух (або уповільнює рух) |
| **Синергіст** | М'яз, що допомагає агоністу або усуває небажаний рух |
| **Фіксатор (стабілізатор)** | М'яз, що утримує кістку нерухомо, щоб агоніст мав опору |
| **Згинач / розгинач** | Згинання / розгинання |
| **Відвідний / привідний** | Відведення / приведення |
| **Обертач, пронатор, супінатор** | Обертання, пронація, супінація |
| **Підіймач / опускач** | Піднімає / опускає |
| **Напружувач** | Натягує (фасцію, перетинку) |
| **Сфінктер** | Звужує отвір |
| **Протиставляч** (*opponens*) | Протиставляє палець |

**Взаємне гальмування (реципрокна іннервація):** при скороченні агоніста антагоніст розслабляється (рефлекторно).
**Співскорочення:** обидва скорочуються одночасно — стабілізація суглоба.

## 5. Номенклатура м'язів: як розуміти назву

| Принцип | Приклади |
|---|---|
| За формою | дельтоподібний (*deltoideus*), трапецієподібний, ромбоподібний, камбалоподібний (*soleus*), зубчастий, квадратний, круглий, грушоподібний |
| За функцією | згинач (*flexor*), розгинач (*extensor*), привідний, відвідний, пронатор, супінатор, напружувач, підіймач |
| За положенням | передній (*anterior*), задній, поверхневий, глибокий, присередній, бічний, великогомілковий (*tibialis*), променевий (*radialis*) |
| За напрямком волокон | прямий (*rectus*), поперечний (*transversus*), косий (*obliquus*) |
| За розміром | великий (*major*), малий (*minor*), найбільший (*maximus*), найменший (*minimus*), довгий (*longus*), короткий (*brevis*), широкий (*latissimus*) |
| За кількістю головок | двоголовий (*biceps*), триголовий (*triceps*), чотириголовий (*quadriceps*) |
| За місцем початку й прикріплення | груднинно-ключично-соскоподібний (груднина, ключиця → соскоподібний відросток), плечо-променевий |
| За функцією і положенням (комбінація) | довгий розгинач великого пальця, поверхневий згинач пальців |

## 6. М'язи як важелі

Кістка — важіль, суглоб — точка опори, м'яз — сила, вага кінцівки або тіла — навантаження.

| Клас важеля | Положення елементів | Приклади |
|---|---|---|
| **I клас** (важіль рівноваги) | Опора між силою й навантаженням | розгинання голови на атланто-потиличному суглобі |
| **II клас** (важіль сили) | Навантаження між опорою й силою | підйом на пальці стоп (опора — головки плеснових, сила — ахіллове сухожилля, навантаження — вага тіла) |
| **III клас** (важіль швидкості) | Сила між опорою й навантаженням | згинання ліктя двоголовим м'язом; більшість м'язів тіла |

- Більшість важелів у тілі — III класу: дають швидкість і ширину руху, але втрачають у силі.
- **Плече сили** — відстань від осі суглоба до лінії тяги м'яза. Більше плече — більше момент сили.
- Надколінок, горохоподібна кістка й інші сесамоподібні кістки збільшують плече сили.
- Момент сили змінюється залежно від кута в суглобі.

## 7. Види скорочення

| Вид | Опис |
|---|---|
| **Ізометричне** | Довжина м'яза не змінюється, суглоб не рухається (утримання вантажу) |
| **Ізотонічне** | Напруження стале, довжина змінюється |
| — **концентричне** | М'яз скорочується (укорочується) і долає навантаження |
| — **ексцентричне** | М'яз розтягується під навантаженням (опускання вантажу). Розвиває більшу силу; більше мікропошкоджень |
| **Ізокінетичне** | Швидкість руху стала (на тренажері) |
| **Ауксотонічне** | Змінне напруження (більшість рухів) |
| **Тонус** | Мінімальне постійне напруження м'яза в спокої; підтримує позу |

Докладніше про механізм скорочення — [[Скелетний м'яз — будова і скорочення]].

## 8. Рухова одиниця

- **Рухова одиниця** = один α-мотонейрон + усі м'язові волокна, що він іннервує.
- Розмір (коефіцієнт іннервації):
  - очні м'язи: 1 нейрон — 3–10 волокон (точні рухи);
  - м'язи пальців: ~100–300;
  - литковий м'яз: ~1000–2000 і більше.
- **Правило розміру** (Хеннемана): спершу вмикаються малі (повільні) одиниці, потім більші (швидкі).
- Сила регулюється **кількістю** задіяних одиниць (рекрутування) і **частотою** імпульсів.

## 9. Кровопостачання й іннервація м'язів

- **Кровопостачання:** кожен м'яз має одну або кілька **живильних артерій** (*aa. nutriciae*), що входять біля воріт м'яза. Капілярна мережа густа: біля кожного волокна 3–5 капілярів. У спокої м'язи отримують близько 20 % серцевого викиду, при навантаженні — до 80 %. Вени мають клапани: скорочення м'язів стискає вени й просуває кров до серця (**м'язовий насос**, особливо литка).
- **Іннервація:**
  - **Рухова** (еферентна): α-мотонейрони (до екстрафузальних волокон), γ-мотонейрони (до інтрафузальних волокон веретен).
  - **Чутлива** (аферентна): м'язові веретена (довжина), сухожилкові органи Гольджі (напруження), вільні нервові закінчення (біль).
  - **Вегетативна**: до судин м'яза.
  - Кожен м'яз має **нервову ніжку** (нерв входить поблизу центру м'яза).
- Один м'яз може мати кілька нервів. Нерви мають сегментарне походження (**міотоми**): сегменти спинного мозку вказують у таблицях як C5–C6, L2–L4 тощо.

## 10. Розвиток м'язів

| Групи м'язів | Походження |
|---|---|
| Глибокі м'язи спини | **епаксіальна** частина міотомів (дорсальні гілки спинномозкових нервів) |
| М'язи тулуба й кінцівок (вентральні) | **гіпаксіальна** частина міотомів (вентральні гілки); м'язи кінцівок — з мігруючих клітин міотомів |
| М'язи ока | прехордальна мезодерма й сомітомери (нерви III, IV, VI) |
| М'язи язика | потиличні соміти (нерв XII) |
| Жувальні м'язи | 1-ша глоткова дуга (V₃) |
| Мімічні м'язи | 2-га глоткова дуга (VII) |
| Шилоглотковий м'яз | 3-тя дуга (IX) |
| М'язи глотки, гортані | 4–6 дуги (X) |
| Гладка м'язова тканина | спланхнічна мезодерма |

- Кількість м'язових волокон закладається до народження й майже не збільшується. Ріст м'язів — **гіпертрофія** (збільшення волокон), а не гіперплазія.
- Після пошкодження волокна частково відновлюються **сателітними клітинами**.

## 11. Вікові зміни й адаптація

- **Гіпертрофія** — від силових тренувань (збільшення поперечника волокон).
- **Атрофія** — від бездіяльності, денервації, іммобілізації. Розвивається швидко: протягом днів і тижнів.
- **Саркопенія** — втрата м'язової маси й сили з віком (від 30–40 років: 3–8 % за десятиліття; після 60 — швидше). Профілактика: силові вправи, білок, вітамін D.
- Тренування сили змінює переважно швидкі волокна, витривалості — повільні й капіляризацію.
