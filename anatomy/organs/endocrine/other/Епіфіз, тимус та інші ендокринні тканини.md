# Епіфіз, тимус та інші ендокринні тканини

Окрім основних залоз, гормони виробляють і інші органи. Тут описано **епіфіз** (мелатонін), **тимус**, **жирову тканину**, **серце**, **нирки**, **кишку**, **кістку** та **плаценту**.

## 1. Епіфіз (шишкоподібне тіло, *glandula pinealis*)

| Показник | Значення |
|---|---|
| Положення | **епіталамус**, **над покрівлею середнього мозку (задня стінка III шлуночка)** |
| Розмір | **5–8 мм, ~150 мг** |
| Форма | **шишка** |
| Клітини | **пінеалоцити** (виробляють мелатонін), **гліальні** |
| Зв'язок | **ніжка епіфіза**, **повідки**, **задня спайка** |
| **Бар'єр** | **немає ГЕБ** (циркумвентрикулярний орган) |

Деталі: [[Проміжний мозок і базальні ядра]].

### Мелатонін
- **Синтез**: **триптофан → серотонін → N-ацетилсеротонін → мелатонін** (ферменти **AANAT**, HIOMT).
- **Секреція**: **вночі (пік 2–4 год ночі), пригнічується світлом**; ↓ з віком.
- **Регуляція**: **світло → сітківка → ретиногіпоталамічний шлях → супрахіазматичне ядро (СХЯ — «біологічний годинник») → верхній шийний симпатичний вузол → епіфіз (норадреналін → β₁)**.
- **Дія**: **сигнал «темно» — регуляція циркадних ритмів і сну**; **зниження температури**; антиоксидант; сезонні ритми (тварини). **Лікування**: **безсоння, джетлаг, розлади сну**.
- **Рецептори**: **MT₁, MT₂** (мембранні).

### Хвороби
**Пухлини епіфіза** (**герміногенна, пінеалоцитома**; **синдром Паріно** — параліч погляду вгору; **гідроцефалія** — блок водопроводу). **Кальцифікація епіфіза** — **орієнтир на рентгені** (зміщення = об'ємний процес). **Передчасне статеве дозрівання** при деструкції (рідко).

## 2. Тимус (вилочкова залоза, *thymus*)

| Показник | Значення |
|---|---|
| Положення | **верхнє переднє середостіння**, **за грудниною**, **перед дугою аорти і плечоголовною веною** |
| **Розвиток** | **3-я глоткова кишеня** (ентодерма) |
| Маса | **найбільший у дитинстві (~15 г при народженні; максимум 30–40 г у пубертаті)** → **інволюція (жирове переродження) з віком** |
| Будова | **частки, кора (щільна — Т-лімфоцити), мозкова речовина (тільця Гассаля)** |

### Функція
**«Школа Т-лімфоцитів»**: **дозрівання, відбір (позитивна і негативна селекція)** → **толерантність**.
**Гормони**: **тимозин, тимопоетин, тимуліни** (дозрівання Т-клітин).
**Роль**: **імунітет**; **максимальна в дитинстві**.

Деталі: [[Плевра і середостіння]], [[Мікроциркуляція і лімфатична система]].

### Хвороби
| Хвороба | Суть |
|---|---|
| **Синдром ДіДжорджі (22q11)** | **аплазія тимуса і паращитоподібних**: **Т-клітинний імунодефіцит + гіпокальціємія + вади серця**: [[Паращитоподібні залози і кальцієвий обмін]] |
| **Міастенія** | **тимома, гіперплазія** (**70–80% мають патологію тимуса**): **тимектомія**: [[Нервовий імпульс і синапс]] |
| **Тимома** | **пухлина переднього середостіння**; **паранеопластичні: міастенія, аплазія еритроцитів** |
| **Гіперплазія/інволюція** | |

## 3. Жирова тканина (**ендокринний орган!**)

**Адипоцити** виробляють **адипокіни**.
| Гормон | Дія |
|---|---|
| **Лептин** | **сигнал насичення**; **↑ з жиром**; **гіпоталамус (дугоподібне ядро) → ↓ апетит, ↑ витрата**; **необхідний для пубертату/овуляції**; **дефіцит → ожиріння**; **резистентність при ожирінні** |
| **Адипонектин** | **↑ чутливість до інсуліну**; **↓ при ожирінні** |
| **Резистин, ІЛ-6, ФНП-α** | **запалення, інсулінорезистентність** |
| **Естрогени (ароматаза)** | **з андрогенів** (у чоловіків ожиріння → гінекомастія; у жінок після менопаузи — джерело) |
| **Ангіотензиноген** | **АТ** |

**Метаболічний синдром**: **вісцеральне ожиріння + інсулінорезистентність + гіпертензія + дисліпідемія** → **ризик діабету, серцево-судинних хвороб**: [[Інсулін, глюкагон і цукровий діабет]].

## 4. Серце — ANP, BNP

- **ANP (передсердний натрійуретичний пептид)** — **кардіоміоцити передсердь при розтягу**; **BNP (мозковий НП)** — **шлуночки при перевантаженні об'ємом/тиском**.
- **Дії**: **↑ ШКФ, ↑ натрійурез і діурез, вазодилатація, ↓ ренін, альдостерон, АДГ** → **↓ ОЦК, ↓ АТ**.
- **Клінічно**: **BNP/NT-proBNP — маркер серцевої недостатності**; **сакубітрил** (інгібітор неприлізину — підсилює НП): [[Серце — стінка і перикард]], [[Серце — іннервація]].

## 8. Кістки

- **Склеростин** — гальмує остеобласти (ромосозумаб блокує).

## 14. Мнемоніки

- **Епіфіз → мелатонін (ніч, світло гальмує); СХЯ — годинник**.
- **Тимус — Т-клітини; інволюція з віком; ДіДжорджі — аплазія тимуса + паращитоподібних**.
- **Лептин (жир) — насичення; грелін (шлунок) — голод**.
- **ANP/BNP — з серця; ↓ ОЦК; BNP — маркер СН**.
- **МЕН-1: «3P»** (паращитоподібні, гіпофіз, підшлункова); **МЕН-2: медулярний рак + феохромоцитома (+ ПТГ)**.
