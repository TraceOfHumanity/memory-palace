# Ендокринна система — огляд (*systema endocrinum*)

Ендокринна система керує організмом за допомогою **гормонів**. Залози виділяють їх безпосередньо в кров, і вони діють на віддалені клітини-мішені. Ця система регулює обмін речовин, ріст, розвиток, розмноження, водно-сольовий баланс і реакцію на стрес. Вона діє повільніше за нервову систему, але довше.

## 4. Механізми дії гормонів

### Мембранні рецептори (пептидні, катехоламіни)
| Шлях | Вторинний посередник | Приклади |
|---|---|---|
| **G_s → аденілатциклаза → cAMP → протеїнкіназа A** | **cAMP ↑** | глюкагон, АКТГ, ТТГ, ЛГ, ФСГ, β-адреноміметики, ПТГ, АДГ (V₂) |
| **G_i → cAMP ↓** | | α₂, соматостатин |
| **G_q → фосфоліпаза C → IP₃ + DAG → Ca²⁺, протеїнкіназа C** | **IP₃/Ca²⁺** | α₁, АДГ (V₁), окситоцин, ангіотензин II, ТРГ |
| **Тирозинкіназа** | каскад фосфорилювання | **інсулін, ІФР-1** |
| **JAK-STAT** | | **СТГ, пролактин, лептин** |
| **Гуанілатциклаза → cGMP** | | **ANP, NO** |

### Ядерні рецептори (стероїди, T₃/T₄, вітамін D)
Гормон проходить крізь мембрану → зв'язується з рецептором у цитоплазмі/ядрі → комплекс зв'язується з **елементом відповіді (HRE) на ДНК** → **зміна транскрипції генів** → **синтез білків**. Дія **повільна** (години), **тривала**.

## 5. Регуляція секреції

### Негативний зворотний зв'язок (основний)
Продукт залози **гальмує** вищий центр. Приклад: **кортизол → гальмує АКТГ і КРГ**.
- **Довга петля**: гормон залози → гіпоталамус/гіпофіз.
- **Коротка петля**: гормон гіпофіза → гіпоталамус.
- **Ультракоротка петля**: гормон → власна клітина.

### Позитивний зворотний зв'язок (рідко)
**Високий естрадіол → сплеск ЛГ → овуляція**: [[Менструальний цикл і жіночі гормони]]; **окситоцин у пологах**: [[Пологи і післяпологовий період]].

### Інші механізми
| Механізм | Приклад |
|---|---|
| **Прямий вплив метаболіту** | **глюкоза → інсулін**; **Ca²⁺ → ПТГ** |
| **Нервова регуляція** | **симпатика → мозкова речовина надниркових** |
| **Ритми** | **циркадний (кортизол — максимум зранку; мелатонін — вночі)**; **пульсуючий (ГнРГ, СТГ)**; **сезонний**; місячний (цикл) |
| **Стрес** | **АКТГ, кортизол, катехоламіни** |

## 6. Гіпоталамо-гіпофізарна система (стисло)

Гіпоталамус → **ліберини/статини** → **передній гіпофіз** (через **портальну систему**) → **тропні гормони** → **периферичні залози** → гормони → **зворотний зв'язок**. Задній гіпофіз — **нервові волокна** від гіпоталамуса (**АДГ, окситоцин**). Деталі: [[Гіпоталамус і гіпофіз]], [[Гормони гіпофіза — осі і хвороби]].

## 7. Рецептори і чутливість

- Дія залежить від **кількості рецепторів** клітини-мішені.
- **Down-регуляція** (↓ рецепторів при надлишку гормона: ожиріння → ↓ рецептори інсуліну).
- **Up-регуляція** (↑ рецепторів при дефіциті).
- **Резистентність до гормона** (діабет 2 типу, нечутливість до андрогенів, нефрогенний нецукровий діабет).

## 8. Типи порушень

| Тип | Суть | Приклад |
|---|---|---|
| **Гіперфункція** (надлишок) | пухлина (аденома), гіперплазія, аутоімунне (Грейвса), екзогенні гормони | **Кушинг, Грейвса, акромегалія** |
| **Гіпофункція** (дефіцит) | руйнування, аутоімунне, дефект синтезу, недостатність гіпофіза | **Аддісон, гіпотиреоз, діабет 1 типу** |
| **Рецепторні** | резистентність | **діабет 2 типу, нефрогенний нецукровий діабет** |
| **Первинні / вторинні / третинні** | **ураження залози / гіпофіза / гіпоталамуса** | ↑ або ↓ тропних гормонів визначає рівень |

**Правило діагностики**: **розглядати парами «тропний гормон — периферичний гормон»** (**↑ ТТГ + ↓ T₄ = первинний гіпотиреоз; ↓ ТТГ + ↓ T₄ = центральний**).

## 11. Мнемоніки

- **Пептиди — мембранні рецептори, швидко**; **стероїди і йодтироніни — ядерні рецептори, повільно, тривало**.
- **Вісь: гіпоталамус → гіпофіз → залоза → гормон → зворотний зв'язок**.
- **Тропні гормони: ТТГ, АКТГ, ФСГ, ЛГ** («FLAT» — ФСГ, ЛГ, АКТГ, ТТГ) + **СТГ, пролактин** (нетропні).
- Тест: **гіпофункція → стимуляція; гіперфункція → супресія**.
- **Первинна — залоза; вторинна — гіпофіз; третинна — гіпоталамус**.
