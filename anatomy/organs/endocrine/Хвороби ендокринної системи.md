Це зведення основних ендокринних хвороб. Воно допомагає швидко знайти потрібну залозу за симптомами та аналізами. Деталі — у файлах про кожну залозу.

## 1. Принцип діагностики: «що → де → чому»

1. **Що**: гормональний надлишок (**гіперфункція**) чи дефіцит (**гіпофункція**), чи **резистентність**.
2. **Де**: **первинна** (залоза), **вторинна** (гіпофіз), **третинна** (гіпоталамус).
3. **Чому**: **аутоімунне, пухлина, інфекція, ятрогенне, генетичне, дефіцит речовини (йод), ліки**.

**Логіка пар «тропний — периферичний гормон»**:
| Результат | Висновок |
|---|---|
| **↑ ТТГ + ↓ T₄** | **первинний гіпотиреоз** |
| **↓ ТТГ + ↓ T₄** | **центральний гіпотиреоз** |
| **↓ ТТГ + ↑ T₄** | **гіпертиреоз (первинний)** |
| **↑ АКТГ + ↓ кортизол** | **первинна надниркова недостатність (Аддісон)** |
| **↓ АКТГ + ↓ кортизол** | **вторинна** |
| **↑ ФСГ/ЛГ + ↓ статеві** | **первинний гіпогонадизм** |

## 2. Симптоми за системами → залоза

| Симптом | Можливі ендокринні причини |
|---|---|
| **Схуднення при хорошому апетиті** | **гіпертиреоз, діабет, феохромоцитома** |
| **Набір ваги** | **гіпотиреоз, Кушинг, гіперінсулінізм, СПКЯ, гіпоталамічне ожиріння** |
| **Постійна втома, слабкість** | **гіпотиреоз, Аддісон, діабет, гіперкальціємія, гіпопітуїтаризм** |
| **Спрага, поліурія** | **діабет, нецукровий діабет, гіперкальціємія** |
| **Тахікардія, пітливість, тремор** | **гіпертиреоз, феохромоцитома, гіпоглікемія** |
| **Брадикардія, зябкість, запор** | **гіпотиреоз** |
| **Гіпертензія (вторинна)** | **Кушинг, Конна, феохромоцитома, акромегалія, гіпер- і гіпотиреоз, гіперпаратиреоз** |
| **Гіпотензія** | **Аддісон, гіпопітуїтаризм** |
| **Остеопороз, переломи** | **гіперпаратиреоз, Кушинг, гіпертиреоз, гіпогонадизм, ГК** |
| **Камені в нирках** | **гіперпаратиреоз** |

| **Гірсутизм, акне** | **СПКЯ, ВГНЗ, пухлина надниркових/яєчників, Кушинг** |
| **Галакторея** | **пролактинома, гіпотиреоз, ліки** |
| **Збільшення рук і ніг, грубі риси** | **акромегалія** |
| **Шкіра: гіперпігментація** | **Аддісон** |

| **Зоб, вузол на шиї** | **щитоподібна** |
| **Головний біль + поля зору** | **аденома гіпофіза** |

## 3. Хвороби по залозах (зведення)

| Залоза | Гіперфункція | Гіпофункція |
|---|---|---|
| **Гіпофіз** | **акромегалія/гігантизм (СТГ)**, **пролактинома**, **Кушинг (АКТГ)**, ТТГ-ома | **гіпопітуїтаризм (Шихан)**, **нецукровий діабет**; **СНАДГ (надлишок АДГ)** |
| **Щитоподібна** | **Грейвса, токсична аденома, тиреоїдити (фаза тиреотоксикозу)** | **Хашимото, дефіцит йоду, кретинізм**; **рак** |
| **Паращитоподібні** | **гіперпаратиреоз** (гіперкальціємія) | **гіпопаратиреоз** (гіпокальціємія) |
| **Надниркова кора** | **Кушинг, Конна, вірилізуючі пухлини** | **Аддісон**, **ВГНЗ**, вторинна |
| **Мозкова речовина** | **феохромоцитома** | — |
| **Підшлункова (острівці)** | **інсулінома**, гастринома | **діабет 1 і 2** |
| **Гонади** | передчасне статеве дозрівання; пухлини | **гіпогонадизм, ПНЯ, Тернер, Клайнфельтер** |
| **Епіфіз** | пухлини | — |

## 4. Невідкладні ендокринні стани

| Стан | Ключові ознаки | Невідкладна допомога |
|---|---|---|
| **Діабетичний кетоацидоз** | **гіперглікемія, кетони, ацидоз, Куссмауль, запах ацетону** | **рідина + інсулін в/в + калій** |
| **Гіперосмолярний стан** | **глюкоза > 33, зневоднення, кома** | рідина, інсулін |
| **Тяжка гіпоглікемія** | **сплутаність, судоми, кома** | **глюкоза в/в / глюкагон** |
| **Надниркова (аддісонічна) криза** | **шок, блювання, біль у животі, гіпонатріємія/гіперкаліємія** | **гідрокортизон 100 мг в/в + фізрозчин + глюкоза** |
| **Тиреотоксичний криз** | **лихоманка, тахікардія, делірій** | **β-блокатор, тіонаміди, стероїди, охолодження** |
| **Мікседемна кома** | **гіпотермія, брадикардія, гіповентиляція** | **левотироксин в/в + гідрокортизон, зігрівання** |
| **Гіперкальціємічний криз** | **зневоднення, кома** | **фізрозчин, біфосфонати, кальцитонін** |
| **Гіпокальціємічна тетанія** | **ларингоспазм, судоми, ↑ QT** | **в/в кальцій глюконат** |
| **Криз при феохромоцитомі** | **гіпертонічний криз** | **α-блокатор** (фентоламін), потім β |
| **Апоплексія гіпофіза** | **раптовий головний біль, втрата зору** | **стероїди, хірургія** |
| **Нецукровий діабет (гостра)** | **поліурія, гіпернатріємія** | **десмопресин, рідина** |

## 5. Скринінг і профілактика

| Захворювання | Скринінг |
|---|---|
| **Вроджений гіпотиреоз, ВГНЗ, фенілкетонурія** | **неонатальний скринінг (кров із п'ятки)** |
| **Діабет 2 типу** | **глюкоза натще/HbA1c з 35–45 років або раніше при ризиках (ожиріння, спадковість, ГЦД в анамнезі)** |
| **Гестаційний діабет** | **ОГТТ на 24–28 тижнях** |
| **Щитоподібна залоза** | **ТТГ при симптомах, вагітності, ризиках** |
| **Остеопороз** | **ДЕКСА у жінок > 65, чоловіків > 70 або ризики** |
| **Йодування солі, достатній вітамін D, помірна фізична активність, нормальна вага** | профілактика |

## 6. Ятрогенні ендокринні розлади

- **Глюкокортикоїди** → Кушинг, діабет, остеопороз, пригнічення осі HPA.
- **Аміодарон, літій** → дисфункція щитоподібної, нефрогенний нецукровий діабет.
- **Антипсихотики** → гіперпролактинемія, ожиріння, діабет.
- **Імунотерапія пухлин** → **гіпофізит, тиреоїдит, надниркова недостатність**.
- **Іонізуюче опромінення голови/шиї** → гіпопітуїтаризм, гіпотиреоз.
- **Операції (щитоподібна, паращитоподібні)** → гіпопаратиреоз, пошкодження нервів.

## 7. Мнемоніки

- **Гіпер- — «швидко/гаряче/худне» (тиреоїд), «ожиріння/гіпертензія/діабет» (Кушинг)**; **гіпо- — «повільно/холодно/набирає вагу» (гіпотиреоз), «слабкість/гіперпігментація/гіпотензія» (Аддісон)**.
- **Пара «ТТГ — T₄» розрізняє первинне та центральне**.
- **Невідкладно: кетоацидоз, гіпоглікемія, криз Аддісона, тиреотоксичний криз, мікседемна кома, гіпер- і гіпокальціємія**.
- **Гормони дефіцитні — заміщуй: кортизол першим, потім левотироксин**.
- **Діабет 3П: поліурія, полідипсія, поліфагія; HbA1c ≥ 6,5%**.
