# Інсулін, глюкагон і цукровий діабет

Ендокринна частина підшлункової залози — **острівці Лангерганса**. Вони виробляють **інсулін** (знижує глюкозу) і **глюкагон** (підвищує). Порушення цієї системи — **цукровий діабет** — одна з найпоширеніших хвороб у світі.

Пов'язані файли: [[Ендокринна система — огляд]], [[Підшлункова залоза]], [[Регуляція травлення]], [[Гормони надниркових і їхні хвороби]], [[Гормони гіпофіза — осі і хвороби]], [[Печінка — функції]], [[Нирка — утворення сечі]], [[Нирка — регуляція гомеостазу]], [[Хвороби судин]], [[Серце — хвороби]], [[Неврологічне обстеження і синдроми]], [[Вегетативна нервова система]], [[Хвороби ендокринної системи]], [[Хвороби ока]], [[Шкірна чутливість і біль]], [[Хвороби шкіри]].

## 1. Острівці Лангерганса (нагадування)

Детальна будова — у файлі [[Підшлункова залоза]]. **~1–2 млн** острівців (**1–2% маси залози**, більше в **хвості**); **густе кровопостачання**.

| Клітина | Частка | Гормон | Основна дія |
|---|---|---|---|
| **β (бета)** | **~70%** (центр) | **інсулін**, **С-пептид**, **амілін** | ↓ глюкоза |
| **α (альфа)** | **~20%** (периферія) | **глюкагон** | ↑ глюкоза |
| **δ (дельта)** | ~5% | **соматостатин** | гальмує α, β |
| **PP (F)** | 1–5% | панкреатичний поліпептид | ↓ секреція підшлункової |
| **ε** | <1% | **грелін** | |

**Паракринна взаємодія**: **інсулін гальмує α-клітини**, **глюкагон стимулює β**, **соматостатин гальмує обох**. **Кровотік у острівці**: **від β → α → δ**.

## 2. Інсулін

### Синтез
**Препроінсулін → проінсулін** (**ЕПР**) → **в апараті Гольджі розщеплення на інсулін (51 амінокислота: ланцюги A і B, дисульфідні містки) + С-пептид** (еквімолярно) → **гранули** → **екзоцитоз**.
- **С-пептид** — маркер **власної секреції** інсуліну (**немає при введенні препарату**; **↑ при інсуліномі, ↓ при діабеті 1 типу**).
- T½ **5–6 хв** (**печінка руйнує ~50% при першому проході**).

### Регуляція секреції
| Стимулятори | Гальмівні |
|---|---|
| **↑ глюкоза (головний)** | **↓ глюкоза** |
| **Амінокислоти (аргінін, лейцин)** | **соматостатин** |
| **Інкретини: ГПП-1, ГІП** (кишка → **«інкретиновий ефект»**) | **адреналін (α₂)**, **симпатика** |
| **Парасимпатика (X, ACh)** | |
| **Глюкагон, СТГ, кортизол (на довшій дистанції)** | **голодування** |
| **Сульфонілсечовини (ліки)** | |

**Механізм секреції (β-клітина)**: **глюкоза → GLUT2 → глюкокіназа → АТФ ↑ → закриття K_ATP-каналів → деполяризація → відкриття Ca²⁺-каналів → ↑ Ca²⁺ → екзоцитоз інсуліну**.
**Двофазна відповідь**: **перша (швидка, 5–10 хв — готові гранули)**, **друга (повільна, нова синтезована)**.
**Сульфонілсечовини** блокують K_ATP; **інкретини** посилюють секрецію **залежно від глюкози**.

### Рецептор і сигнальний шлях
**Тирозинкіназний рецептор** → **IRS → PI3K → Akt → GLUT4 переміщується на мембрану (м'язи, жир)**; також **MAPK (ріст)**.

### Дії інсуліну (**анаболічний гормон**)
| Тканина | Дія |
|---|---|
| **М'язи, жир** | **↑ GLUT4 → поглинання глюкози**; **↑ глікоген (м'язи)**; **↑ синтез білка** |
| **Печінка** | **↑ глікогенез, гліколіз, ліпогенез**; **↓ глюконеогенез, глікогеноліз, кетогенез** (**ключова дія: блок виходу глюкози**) |
| **Жирова** | **↑ синтез ТГ; ↓ ліполіз (ліпаза чутлива до гормонів)** |
| **Білки** | **↑ поглинання АК, синтез; ↓ протеоліз** |
| **K⁺** | **↑ поглинання K⁺ клітинами** (**гіпокаліємія при введенні інсуліну; лікування гіперкаліємії**) |
| **Ріст** | **мітогенна дія** |
| **Мозок** | **GLUT1/3 — не залежить від інсуліну** (мозок поглинає глюкозу **без інсуліну**) |

**Підсумок**: **«накопичення»** — після їжі.

### Не залежать від інсуліну
**Мозок (GLUT1, GLUT3)**, **еритроцити**, **нирки**, **кишка**, **ендотелій**, **печінка (GLUT2 — вільний вхід)**.

## 3. Глюкагон

| Показник | Значення |
|---|---|
| Будова | **29 амінокислот** (з **проглюкагону**) |
| Джерело | **α-клітини** |
| T½ | ~5 хв |
| Рецептор | **G_s → cAMP → ПКА** (печінка) |

### Регуляція
**Стимулюють**: **↓ глюкоза (гіпоглікемія)**, **амінокислоти (білкова їжа)**, **адреналін, симпатика, голодування, стрес**, **фізичне навантаження**. **Гальмують**: **↑ глюкоза, інсулін, соматостатин, ГПП-1**.

### Дії (**«гормон голодування»**)
| Орган | Дія |
|---|---|
| **Печінка** | **↑ глікогеноліз, глюконеогенез, кетогенез**; **↓ глікогенез** → **↑ глюкоза крові** |
| **Жирова тканина** | ↑ ліполіз |
| **Серце** | ↑ скоротливість (**глюкагон при отруєнні β-блокаторами**) |

**Лікування тяжкої гіпоглікемії**: **глюкагон в/м (якщо немає венозного доступу)**.

## 4. Регуляція глюкози в крові (гомеостаз)

**Норма (натще)**: **3,9–5,5 ммоль/л (70–99 мг/дл)**.

| Стан | Гормони |
|---|---|
| **Після їжі (↑ глюкоза)** | **↑ інсулін, ↓ глюкагон** → поглинання, накопичення |
| **Натще / голодування (↓ глюкоза)** | **↓ інсулін, ↑ глюкагон** → глікоген → глюконеогенез → кетони |
| **Стрес/гіпоглікемія** | **адреналін, кортизол, СТГ** (**контррегуляторні гормони**: ↑ глюкоза) |

### Метаболізм у фазах
| Фаза | Джерело енергії |
|---|---|
| **0–4 год після їжі** | **глюкоза з їжі**; **інсулін ↑ → накопичення** |
| **4–16 год (натще)** | **глікогеноліз печінки** (запас ~100 г; вистачає на ~12–24 год) |
| **> 16–24 год** | **глюконеогенез** (лактат, амінокислоти, гліцерол); **ліполіз → ЖК** |
| **Голодування днями** | **кетонові тіла** (мозок використовує) |

Деталі печінки: [[Печінка — функції]].

### Контррегуляторні гормони (проти інсуліну)
**Глюкагон, адреналін, кортизол, СТГ** → **↑ глюкоза** (**гіперглікемічні гормони**). **Інсулін — єдиний гормон, що знижує глюкозу**.

## 5. Цукровий діабет (ЦД)

**Група хронічних хвороб з гіперглікемією**, зумовлених **абсолютною або відносною нестачею інсуліну** або **резистентністю** до нього.

### Критерії діагностики (ВООЗ/ADA)
| Тест | Норма | Предіабет | **Діабет** |
|---|---|---|---|
| **Глюкоза натще** | < 5,6 | 5,6–6,9 | **≥ 7,0 ммоль/л** (двічі) |
| **ОГТТ (2 год, 75 г)** | < 7,8 | 7,8–11,0 | **≥ 11,1 ммоль/л** |
| **HbA1c** | < 5,7% | 5,7–6,4% | **≥ 6,5%** |
| **Випадкова глюкоза + симптоми** | | | **≥ 11,1 ммоль/л** |

**HbA1c** — **глікований гемоглобін** (середня глюкоза за **2–3 місяці**). **Ціль**: **< 7%** (у більшості).

### Типи діабету
| Тип | Суть | Ключове |
|---|---|---|
| **1 тип (T1DM)** | **аутоімунне руйнування β-клітин** → **абсолютна нестача інсуліну** | **діти і молоді (пік 10–14 років), раптовий початок, худі**; **антитіла (GAD, ICA, IA-2)**; **схильність до кетоацидозу**; **С-пептид ↓**; **інсулін обов'язково** |
| **2 тип (T2DM)** | **резистентність до інсуліну + ↓ секреція** | **90–95% діабету**; **> 40 років, ожиріння, спадковість, малорухливість**; **поступовий, часто безсимптомний**; **С-пептид норма/↑**; **дієта, метформін; інсулін пізніше** |
| **Гестаційний (ГЦД)** | **вагітність** (**ПЛ, кортизол → ІР**) | **24–28 тижнів ОГТТ**; **макросомія, ризик T2DM** |
| **Інші** | **MODY (моногенні)**, **панкреатичний (панкреатит, муковісцидоз, гемохроматоз)**, **ендокринні (Кушинг, акромегалія, феохромоцитома)**, **ліки (стероїди)** | |
| **LADA** | **аутоімунний у дорослих** (повільний) | |

### Патогенез T2DM
**Ожиріння (особливо вісцеральне) → ↑ вільні жирні кислоти, адипокіни, запалення → інсулінорезистентність (м'язи, жир, печінка) → компенсаторна гіперінсулінемія → виснаження β-клітин → гіперглікемія**.

| **Полідипсія** | зневоднення |
| **Поліфагія** | клітини «голодні» |
| **Схуднення** (T1) | катаболізм |

| **Кетоацидоз (T1)** | |

## 7. Гострі ускладнення

### Діабетичний кетоацидоз (ДКА) — T1DM
**Абсолютний дефіцит інсуліну** → **ліполіз → ЖК → кетогенез (ацетоацетат, β-гідроксибутират, ацетон)** + **гіперглікемія**.
- **Тригер**: **інфекція, пропуск інсуліну, початок T1**.
- **Ознаки**: **гіперглікемія (> 13,9), кетонемія, метаболічний ацидоз (pH < 7,3, ↓ HCO₃⁻), дегідратація**; **нудота, блювання, біль у животі, глибоке дихання Куссмауля, запах ацетону з рота, сплутаність, кома**; **гіперкаліємія (за рахунок виходу з клітин), але загальний K⁺ ↓**.
- **Лікування**: **рідина (фізрозчин)**, **інсулін в/в**, **калій (контроль)**, **діагностика причини**; **ускладнення — набряк мозку (діти)**.

### Гіперосмолярний гіперглікемічний стан (ГГС) — T2DM
**Глюкоза > 33 ммоль/л, осмолярність > 320, без значного кетозу**; **літні**; **тяжке зневоднення, сплутаність, кома**; **смертність висока**.

### Гіпоглікемія
**Глюкоза < 3,9 ммоль/л (< 3,0 — тяжка)**; **причини**: **надлишок інсуліну/сульфонілсечовини, пропуск їжі, навантаження, алкоголь**; **симптоми**:
- **Адренергічні**: **тремор, пітливість, серцебиття, тривога, голод** (катехоламіни).
- **Нейроглікопенічні**: **головний біль, сплутаність, судоми, кома** (недостача глюкози мозку).
**Тріада Уіппла** (інсулінома): **симптоми + низька глюкоза + зникають після глюкози**.
**Лікування**: **15 г швидких вуглеводів (глюкоза)**; **тяжка: в/в глюкоза 40% або глюкагон в/м**.

## 8. Хронічні ускладнення

### Мікросудинні
| Ускладнення | Суть |
|---|---|
| **Діабетична ретинопатія** | **ураження сітківки** (мікроаневризми, крововиливи, новоутворені судини) — **головна причина сліпоти працездатних**; **скринінг щороку** |
| **Діабетична нефропатія** | **діабетичний гломерулосклероз** (Кіммельстіль — Вільсон); **мікроальбумінурія → протеїнурія → ХХН**; **головна причина діалізу**: [[Хвороби сечової системи]] |
| **Діабетична нейропатія** | **дистальна симетрична («шкарпетки»)** (оніміння, біль, ↓ вібрація, втрата захисної чутливості), **автономна** (ортостатична гіпотензія, гастропарез, ЕД, нейрогенний міхур), **мононейропатії**: [[Вегетативна нервова система]], [[Неврологічне обстеження і синдроми]] |

### Макросудинні
**Атеросклероз прискорений**: **ІХС (інфаркт — часто «німий»)**, **інсульт**, **хвороби артерій ніг**; **діабет — еквівалент ІХС**: [[Хвороби судин]], [[Серце — хвороби]].

### Діабетична стопа
**Нейропатія + ішемія + інфекція → виразки → гангрена → ампутація**; **щоденний огляд, взуття, догляд**.

### Інше
Інфекції (шкіра, ІСШ, кандидоз), **катаракта, глаукома**, **гастропарез**, шкірні ураження.

**Профілактика**: **глікемічний контроль (HbA1c < 7%), АТ < 130/80, ліпіди (статини), відмова від паління, щорічні огляди (очі, нирки, ноги)**.

## 9. Лікування діабету

### Немедикаментозне
**Дієта (контроль вуглеводів, клітковина), фізична активність (150 хв/тиждень), зменшення маси тіла, відмова від паління, навчання**.

### T1DM — інсулін
| Тип | Дія | Початок / пік / тривалість |
|---|---|---|
| **Ультракороткий (лізпро, аспарт)** | на їжу | 10–15 хв / 1–2 год / 3–5 год |
| **Короткий (регулярний)** | | 30 хв / 2–4 год / 6–8 год |
| **Середній (NPH)** | базальний | 1–2 год / 4–10 год / 12–18 год |
| **Тривалий (гларгін, деглюдек)** | **базальний** | 2 год / плато / 24–42 год |

**Схема**: **базис-болюс** (тривалий + ультракороткий на їжу), **інсулінова помпа**, **безперервний моніторинг глюкози (CGM)**.
**Побічні**: **гіпоглікемія, ліподистрофія, збільшення ваги**.

### T2DM — ліки
| Група | Приклад | Механізм | Нюанси |
|---|---|---|---|
| **Бігуаніди** | **метформін** | **↓ глюконеогенез, ↑ чутливість** | **1-ша лінія**; **без гіпоглікемії**; ризик лактоацидозу при ХНН |
| **Сульфонілсечовини** | гліклазид, глімепірид | **↑ секреція (K_ATP)** | **гіпоглікемія, ↑ вага** |
| **Інгібітори SGLT2** | **емпагліфлозин, дапагліфлозин** | **↑ глюкозурія (нирки)** | **кардіо- і нефропротекція**, ↓ вага; **ІСШ, кетоацидоз (еуглікемічний)** |
| **Агоністи ГПП-1** | **семаглутид, ліраглутид** | **інкретини: ↑ інсулін, ↓ глюкагон, ↓ апетит** | **↓ вага**, кардіозахист; нудота, панкреатит |
| **Інгібітори ДПП-4** | ситагліптин | ↑ ендогенні інкретини | нейтральні за вагою |
| **Тіазолідиндіони** | піоглітазон | **↑ чутливість (PPARγ)** | набряки, ↑ вага, серцева недостатність |
| **Інсулін** | | | пізні стадії |

**Хірургія ожиріння (баріатрія)** — ремісія T2DM.

## 10. Мнемоніки

- **Інсулін: ↓ глюкоза, анаболізм, GLUT4, K⁺ всередину**; **глюкагон: ↑ глюкоза (глікогеноліз, глюконеогенез)**.
- **Інсулін — єдиний гіпоглікемічний гормон; 4 гіперглікемічних: глюкагон, адреналін, кортизол, СТГ**.
- **Діабет: поліурія, полідипсія, поліфагія; глюкоза ≥ 7,0 натще, HbA1c ≥ 6,5%**.
- **T1: аутоімунний, ДКА, інсулін; T2: резистентність, ожиріння, метформін**.
- **ДКА: кетони + ацидоз + Куссмауль**; **ГГС: > 33, осмолярність > 320**.
- **Мікросудинні: очі, нирки, нерви; макросудинні: серце, мозок, ноги**.
