# Яєчко і придаток яєчка (*testis*, *epididymis*)

Яєчко — парна чоловіча статева залоза. Воно виробляє **сперматозоїди** і гормон **тестостерон**. Придаток яєчка забезпечує дозрівання й накопичення сперматозоїдів. Яєчка лежать у **мошонці**, де температура на **2–3 °C нижча** за температуру тіла.

## 1. Яєчко (*testis*, *orchis*)

| Показник | Значення |
|---|---|
| Форма | овальна, злегка сплющена |
| Довжина | **4–5 см** |
| Ширина | 2–3 см |
| Маса | **15–25 г** |
| Об'єм | **15–25 мл** (в нормі > 12 мл) |
| Положення | **мошонка**, ліве **трохи нижче** правого |
| Консистенція | щільно-еластична |

### Поверхні, краї, полюси
- **Верхній і нижній полюс**; **латеральна й медіальна поверхні**.
- **Передній (вільний) край** і **задній край** (**до нього прилягає придаток і судини**).
- **Висить** на **сім'яному канатику**.

### Оболонки (від яєчка назовні)
| Оболонка | Походження |
|---|---|
| **Білкова оболонка** (*tunica albuginea*) | щільна фіброзна капсула; на задньому краї утворює **середостіння яєчка** (*mediastinum testis*) |
| **Піхвова оболонка** (*tunica vaginalis*) | **вісцеральний і парієтальний листки** (залишок **очеревини**, **вагінальний відросток**); між ними — **порожнина** (гідроцеле!) |
| **Внутрішня сім'яна фасція** | з поперечної фасції живота |
| **М'яз-підіймач яєчка (кремастер)** + фасція | з внутрішнього косого м'яза живота |
| **Зовнішня сім'яна фасція** | з апоневрозу зовнішнього косого м'яза |
| **М'ясиста оболонка (дартос)** | гладкі м'язи мошонки |
| **Шкіра мошонки** | |

Шари походять від **шарів передньої черевної стінки**, через які яєчко опускалося: [[М'язи живота]].

### Будова яєчка
- **Перегородки** (*septula testis*) діляться на **~250–300 часточок**.
- Кожна часточка: **1–4 звивисті сім'яні канальці** (*tubuli seminiferi contorti*; **довжина ~70–80 см кожен**, **загальна ~250–300 м** на яєчко).
- **Прямі канальці** → **сітка яєчка** (*rete testis*, у середостінні) → **виносні канальці** (12–15) → **придаток**.
- **Інтерстиційна тканина** між канальцями: **клітини Лейдіга**.

### Мікроскопічна будова звивистого канальця
| Клітини | Функція |
|---|---|
| **Сперматогенні клітини** (сперматогонії → сперматоцити → сперматиди → **сперматозоїди**) | **сперматогенез**: [[Сперматогенез і чоловічі гормони]] |
| **Клітини Сертолі** (підтримувальні) | **живлення, фагоцитоз**, **гематотестикулярний бар'єр** (щільні контакти), **інгібін, АМГ, андрогензв'язувальний білок**, **ФСГ-рецептор** |
| **Клітини Лейдіга** (інтерстиційні) | **тестостерон** (під контролем **ЛГ**) |
| **Міоїдні клітини** | скорочення канальця |

**Гематотестикулярний бар'єр** — захищає сперматозоїди від імунної системи (аутоімунний орхіт при порушенні).

## 2. Придаток яєчка (*epididymis*)

Витягнута структура на **задньо-верхньому краї** яєчка.

| Частина | Опис |
|---|---|
| **Головка** (*caput*) | вгорі; приймає **виносні канальці** |
| **Тіло** (*corpus*) | |
| **Хвіст** (*cauda*) | внизу, переходить у **сім'явивідну протоку** |

- **Протока придатка** — **одна звивиста трубка**, довжина **~6 м** (!), стінка з **стереоціліями** (епітелій).
- **Функції**: **дозрівання сперматозоїдів** (набувають **рухливості й здатності до запліднення** за **~12 днів**), **накопичення** (хвіст), **всмоктування рідини**, **секреція**.
- **Транзит**: 10–14 днів.

**Придатки яєчка** (рудименти): **гідатида Морганьї** (залишок парамезонефричної протоки) — **перекрут** у дітей (**«синя крапка»**).

## 3. Сім'яний канатик (*funiculus spermaticus*)

Йде від яєчка через **пахвинний канал** у **черевну порожнину**. Довжина ~**15 см**.

### Вміст
| Структура | Опис |
|---|---|
| **Сім'явивідна протока** (*ductus deferens*) | |
| **Яєчкова артерія** (*a. testicularis*) | з **черевної аорти (L2)** |
| **Артерія сім'явивідної протоки** | з **нижньої міхурової** |
| **Артерія кремастера** | з **нижньої надчеревної** |
| **Гроноподібне венозне сплетення** (*plexus pampiniformis*) | відводить кров, **охолоджує артеріальну кров** (**протиточний обмін**) |
| **Лімфатичні судини** | до **поперекових вузлів** |
| **Нерви**: **статево-стегновий (генітальна гілка)**, **симпатичні**, **клубово-пахвинний** | |
| **Залишок піхвового відростка** | |

### Пахвинний канал (чоловіки)
**Довжина 4–5 см**; **глибокий** (внутрішній) і **поверхневий** (зовнішній) **пахвинні кільця**. Проходить **сім'яний канатик**. Слабке місце → **пахвинна грижа**: [[М'язи живота]].

## 4. Опускання яєчка

| Етап | Час |
|---|---|
| **Поперекова ділянка** | 3–4 місяць |
| **Внутрішнє пахвинне кільце** | 7 місяць |
| **Пахвинний канал** | 7–8 місяць |
| **Мошонка** | **8–9 місяць** (до народження) |

Керує **губернакулум яєчка** (*gubernaculum testis*), **андрогени**, **INSL3**.
- **Крипторхізм**: неопущення (3% доношених, 30% недоношених; **часто опускаються до 6 місяців**); **підвищений ризик безпліддя, раку, перекруту, грижі**; **орхідопексія** до **12–18 місяців**.
- **Ектопія** (в іншому місці).

## 5. Температурна регуляція

**Оптимум сперматогенезу ~34–35 °C** (2–3 °C нижче тіла).
| Механізм | Опис |
|---|---|
| **М'яз-підіймач яєчка** | **холодно → підтягує яєчка** до тіла; **тепло → розслабляє** (**кремастерний рефлекс L1–L2**) |
| **М'ясиста оболонка (дартос)** | **зморщує мошонку** (холод) → ↓ поверхня |
| **Гроноподібне сплетення** | **охолоджує кров** (протиточний) |
| **Мошонка** | тонка шкіра, мало жиру, потові залози |

**Перегрів** (гарячі ванни, тісна білизна, **варикоцеле**, лихоманка) → **↓ якість сперми**.

## 6. Кровопостачання, іннервація, лімфа

| | Опис |
|---|---|
| **Артерії** | **яєчкова** (аорта, L2): основа; **артерія сім'явивідної протоки**, **кремастерна**; **анастомози** |
| **Вени** | **гроноподібне сплетення** → **яєчкова вена**: **права** → **НПВ** (гострий кут); **ліва** → **ліва ниркова вена** (під прямим кутом) → **варикоцеле частіше зліва** |
| **Лімфа** | **поперекові (парааортальні) вузли** (**рак яєчка** метастазує сюди, не в пахвинні!); **мошонка** → **пахвинні** |
| **Нерви** | **яєчкове сплетення** (**T10–L1**, симпатика), **статево-стегновий (L1–L2)**, клубово-пахвинний; **біль у яєчку іррадіює у попереково-пахвинну ділянку** (**камінь сечоводу — біль в яєчку**) |

Деталі: [[Аорта і її гілки]], [[Вени — нижня порожниста і ворітна системи]], [[Нирка — будова і положення]], [[Вегетативна нервова система]].

## 7. Хвороби яєчка і придатка

| Хвороба | Суть | Ключове |
|---|---|---|
| **Перекрут яєчка** | **невідкладно**: **скручування сім'яного канатика** → ішемія; **підлітки** | **раптовий сильний біль**, нудота; **яєчко високо, горизонтально**; **відсутній кремастерний рефлекс**; **симптом Прена (біль не зменшується при підніманні)**; **операція за 6 годин** |
| **Епідидиміт / орхіт** | **інфекція** (хламідії, гонорея — молоді; E. coli — старші); **паротит** (орхіт) | **поступовий біль, набряк, лихоманка**; **симптом Прена (біль зменшується при підніманні)** |
| **Гідроцеле** | рідина між листками піхвової оболонки | безболісна **просвічується** |
| **Варикоцеле** | **розширення гроноподібного сплетення** (зліва 90%) | «**клубок черв'яків**», **тяжкість**; **безпліддя**; якщо розширення **праворуч або виникло раптово** — шукати пухлину, що стискає вену |
| **Сперматоцеле** | кіста придатка | |
| **Пухлини яєчка** | **герміногенні** (**семінома**, **несеміноми**) — **15–35 років**; **безболісне ущільнення**; **маркери: АФП, β-ХГЛ, ЛДГ**; **орхіектомія через пахвинний доступ** (не через мошонку!); **висока виліковність** | |
| **Крипторхізм** | | |
| **Атрофія** | паротит, травма | |
| **Травма яєчка** | | |
| **Гематоцеле** | | |
| **Гіпогонадизм** | ↓ тестостерон: [[Сперматогенез і чоловічі гормони]] |

### Самообстеження
**Щомісяця** (після теплого душу): пальпація кожного яєчка; **норма — гладке, еластичне**; **патологія — вузлик, збільшення**.

## 8. Мнемоніки

- Яєчко: **оболонки — білкова, піхвова, фасції, кремастер, дартос, шкіра**.
- **Лейдіг — тестостерон (ЛГ); Сертолі — сперматогенез (ФСГ), АМГ, бар'єр**.
- **Лімфа яєчка → поперекові вузли**; **ліва вена → ліва ниркова** (варикоцеле зліва).
- **Перекрут — невідкладно (6 год)**, відсутній кремастерний рефлекс.
- Рак яєчка: **15–35 років, безболісний вузлик, АФП/β-ХГЛ**.
