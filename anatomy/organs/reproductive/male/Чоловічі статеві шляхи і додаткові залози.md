# Чоловічі статеві шляхи і додаткові залози

Сперматозоїди з придатка яєчка рухаються **сім'явивідною протокою**, потрапляють у сечівник і виводяться при еякуляції. По дорозі до них додаються секрети **додаткових залоз**. Разом вони утворюють **сперму (еякулят)**.

## 1. Сім'явивідна протока (*ductus deferens*)

| Показник | Значення |
|---|---|
| Довжина | **~40–45 см** |
| Діаметр | 2–3 мм (**щільна, «як шнурок»**; пальпується в мошонці) |
| Стінка | **товста м'язова** (3 шари гладких м'язів) — **перистальтика** при еякуляції; слизова — **псевдобагатошаровий епітелій зі стереоціліями** |
| Початок | **хвіст придатка яєчка** |
| Кінець | зливається з **протокою сім'яного міхурця** в **сім'явикидну протоку** |

### Відділи (4)
| Відділ | Положення |
|---|---|
| **Мошонкова** | в складі **сім'яного канатика** до зовнішнього кільця |
| **Канатикова** | **пахвинний канал** → внутрішнє кільце |
| **Тазова** | заочеревинно в тазу, **огинає** зовнішню клубову артерію, **перехрещує сечовід спереду** (сім'явивідна протока «над» сечоводом) |
| **Ампула** | розширена **кінцева частина**, **за дном міхура**, **медіально від сім'яного міхурця** |

**Вазектомія** (перев'язка/перерізання протоки): **контрацепція** (сперматозоїди не потрапляють у сперму; **яєчка працюють, тестостерон не змінюється**; ефект через 3 місяці).

## 2. Сім'явикидна протока (*ductus ejaculatorius*)

- **Довжина ~2 см**; утворена злиттям **ампули сім'явивідної протоки** і **протоки сім'яного міхурця**.
- Проходить **через передміхурову залозу** (позаду середньої частки) і відкривається на **сім'яному горбку** простатичної частини сечівника.
- **Виштовхує сперму** при еякуляції.

## 3. Сім'яні міхурці (*vesiculae seminales*)

| Показник | Значення |
|---|---|
| Положення | **між дном міхура і прямою кишкою**, **ззаду передміхурової залози** (**пальпується при ПРД** лише збільшені) |
| Розмір | ~5 см довжина |
| Будова | **складчаста звивиста трубка** з **залозистим епітелієм** |
| **Секрет** | **~60–70% об'єму сперми**; **в'язка лужна рідина** з **фруктозою** (**джерело енергії** для сперматозоїдів), **простагландинами**, **фібриногеном** (згортання сперми), **аскорбіновою кислотою** |

Рак/запалення (**везикуліт**).

## 4. Передміхурова залоза (простата, *prostata*)

| Показник | Значення |
|---|---|
| Форма | **каштан**, неспарена |
| Розмір | ~4 × 3 × 2 см |
| Маса | **~20 г** (у дорослого чоловіка) |
| Положення | **під дном міхура**, **навколо початкової частини сечівника**; спереду — **лобковий симфіз** (**простір Ретціуса**), ззаду — **пряма кишка** (**пальпується через пряму кишку**) |
| **Секрет** | **~25–30% об'єму сперми**; **слабокисла рідина**: **цитрат**, **цинк**, **ПСА** (простат-специфічний антиген — **розріджує** згорнуту сперму), **кисла фосфатаза**, **спермін** (запах) |

### Частини (анатомічні)
| Частина | Положення |
|---|---|
| **Основа (*basis*)** | до дна міхура |
| **Верхівка (*apex*)** | вниз, до діафрагми таза |
| **Права і ліва частки** | |
| **Перешийок (середня частка)** | між сечівником і сім'явикидними протоками |

### Зони (за МакНілом)
| Зона | Частка | Значення |
|---|---|---|
| **Периферична** | **~70%** | **рак простати (70%)** — **пальпується при ПРД** (ззаду) |
| **Центральна** | ~25% | навколо сім'явикидних проток |
| **Перехідна** | **~5%** | **навколо уретри** — **доброякісна гіперплазія (ДГПЗ)** |
| **Передня фібром'язова строма** | | |

### Капсула і фасції
- **Тонка капсула**; **фасція Денонвільє (ректопростатична)**.
- **Венозне сплетення простати** (**Санторіні**): **без клапанів** → **зв'язок із хребтовими венами** (**метастази раку простати в кістки**).

### Кровопостачання, нерви, лімфа
| | Опис |
|---|---|
| **Артерії** | **нижня міхурова**, **середня прямокишкова**, **внутрішня статева** (простатичні гілки) |
| **Вени** | **простатичне сплетення** → **внутрішні клубові**; зв'язок з хребтовими |
| **Нерви** | **тазове (нижнє підчеревне) сплетення**; **печеристі нерви (ерекція)** — **ризик ушкодження при простатектомії → еректильна дисфункція** |
| **Лімфа** | **внутрішні клубові, крижові** вузли |

### Функції
1. **Секрет** для сперми (**живить, розріджує, захищає**).
2. **Гладкі м'язи** — **виштовхування при еякуляції**, **закриття шийки міхура**.
3. **Захист сперми** від кислого середовища піхви: лужний секрет.

### Хвороби простати
| Хвороба | Суть |
|---|---|
| **ДГПЗ (доброякісна гіперплазія)** | **> 50 років**; **перехідна зона** → **стискає уретру**: **слабкий струмінь, нічні позиви, затримка**: [[Сечівник і сечовипускання]]; **α₁-блокатори, 5α-редуктази, ТУР** |
| **Простатит** | **гострий** (лихоманка, біль, дизурія; **ПРД — болісна, гаряча простата, не масажувати!**), **хронічний** (бактеріальний, абактеріальний — синдром хронічного тазового болю) |
| **Рак простати** | **2-й за частотою рак у чоловіків**; **периферична зона**, **аденокарцинома**; **ПСА ↑**; **ПРД — тверда, горбиста, асиметрична**; **біопсія** (Глісон); **метастази — кістки (остеобластні), лімфовузли**; **лікування**: простатектомія, променева, **андрогенна депривація** |
| **Абсцес простати** | |

**ПСА** — **не специфічний** для раку (↑ при ДГПЗ, простатиті, після ПРД/катетеризації); **скринінг** — індивідуально.

## 5. Бульбоуретральні залози (Купера, *glandulae bulbourethrales*)

- **Парні**, розмір **горошини** (~1 см).
- Лежать у **діафрагмі таза** (глибокий поперечний м'яз промежини), протоки відкриваються в **цибулинну частину** сечівника.
- **Секрет**: **слизовий прозорий** (**«прееякулят»**) — **нейтралізує кислоту** сечівника, **змащує**.
- Іннервація: симпатика/парасимпатика.

## 6. Уретра як статевий шлях

**Сечостатевий канал**: [[Сечівник і сечовипускання]]. Сперма проходить **простатичну → перетинчасту → губчасту** частини.

## 7. Сперма (еякулят)

| Показник | Норма (ВООЗ) |
|---|---|
| **Об'єм** | **1,5–5 мл** (≥ 1,4 мл) |
| **pH** | **7,2–8,0** (лужна) |
| **Концентрація** | **≥ 16 млн/мл** (в середньому 40–100) |
| **Загальна кількість** | **≥ 39 млн** у еякуляті |
| **Рухливість** | **≥ 42% (прогресивна ≥ 30%)** |
| **Морфологія** | **≥ 4%** нормальних форм |
| **Життєздатність** | ≥ 54% |
| **Розрідження** | **15–60 хв** (ПСА) |

### Склад
| Компонент | Частка |
|---|---|
| **Сперматозоїди** | **< 5%** (!) |
| **Сім'яні міхурці** | 60–70% |
| **Простата** | 25–30% |
| **Придаток, залози Купера** | ~5% |

### Терміни
**Нормозооспермія**, **олігозооспермія** (↓ кількість), **астенозооспермія** (↓ рухливість), **тератозооспермія** (морфологія), **азооспермія** (немає сперматозоїдів), **аспермія** (немає еякуляту), **гемоспермія** (кров).

Спермограма — **основний тест** чоловічого безпліддя.

## 8. Еякуляція (фази)

1. **Еміссія** (**симпатика T10–L2**): **скорочення придатка, протоки, міхурців, простати** → сперма в простатичну уретру; **закриття внутрішнього сфінктера** (**не дає ретроградній еякуляції**).
2. **Експульсія** (**соматичні нерви S2–S4**, **статевий нерв**): **ритмічні скорочення цибулинно-губчастого, сідничо-печеристого м'язів** → **виштовхування** (6–10 скорочень).

**Ретроградна еякуляція** (у міхур): діабет, **ТУР простати**, α-блокатори. Деталі: [[Статева відповідь і контрацепція]].

## 9. Мнемоніки

- Шлях: **яєчко → придаток → сім'явивідна протока → ампула → сім'явикидна протока (через простату) → сечівник**.
- Сперма: **сім'яні міхурці 60–70% (фруктоза), простата 25–30% (ПСА, цитрат)**, сперматозоїди < 5%.
- **Простата**: **ДГПЗ — перехідна (навколо уретри), рак — периферична (ПРД)**.
- Сім'явивідна протока **перехрещує сечовід** («вода під мостом» у жінок — маткова артерія).
- **Вазектомія**: перев'язка протоки; тестостерон не змінюється.
