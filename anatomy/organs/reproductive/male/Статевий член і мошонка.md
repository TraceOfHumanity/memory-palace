# Статевий член і мошонка (*penis*, *scrotum*)

Статевий член — орган сечовипускання й копуляції. Він має **печеристу тканину**, яка наповнюється кров'ю при **ерекції**. Мошонка — шкірно-м'язовий мішок для яєчок; вона підтримує їхню температуру.

## 1. Статевий член (*penis*)

### Частини
| Частина | Опис |
|---|---|
| **Корінь** (*radix*) | **прикріплений** до лобкових і сідничих кісток (в **глибокій промежині**) |
| **Тіло (стовбур)** (*corpus*) | вільна частина, **висить** |
| **Головка** (*glans*) | **кінцева частина**, розширена; **вінець**; **зовнішній отвір сечівника** (на верхівці) |
| **Шийка** | між тілом і головкою |

### Розміри
У **розслабленому** стані ~**9–10 см** (від кореня), **збільшений** (ерекція) **~13 см** (значні індивідуальні варіації); діаметр ~3–3,5 см.

### Печеристі й губчасте тіла
| Тіло | Кількість | Опис |
|---|---|---|
| **Печеристі тіла статевого члена** (*corpora cavernosa penis*) | **парні**, на **дорсальній (верхній)** стороні | **основа ерекції**; **відносно довгі** ніжки (*crura*) прикріпляються до **сідничо-лобкових гілок**; **білкова оболонка** (*tunica albuginea*) — щільна; **перегородка** |
| **Губчасте тіло** (*corpus spongiosum*) | **непарне**, **знизу** | **містить сечівник**; **розширюється: цибулина (*bulbus*) на корені і головка (*glans*)** |

- **Печеристі тіла** заповнюються **кров'ю** (**лакуни — синусоїди**) при ерекції.
- **Губчасте тіло** — **менш тверде** (щоб **сечівник не стискався** і **сперма проходила**).

### Оболонки (від глибини назовні)
1. **Білкова оболонка** тіл.
2. **Глибока фасція члена (Бака)** — навколо всіх тіл.
3. **Підшкірна клітковина** (дартос, **без жиру**, **легко набрякає**).
4. **Шкіра** — тонка, рухома; на головці утворює **крайню плоть** (*preputium*) з **вуздечкою** (*frenulum*).

### Фасції (важливі для травми)
**Глибока фасція Бака** обмежує **гематому** при травмі члена; **поверхнева фасція (Коллеса)** — поширення сечі при розриві сечівника → мошонка, промежина, живіт.

## 2. Ерекція (механізм)

**Ерекція** — **збільшення, ущільнення** члена. Гемодинамічний процес:

1. **Сексуальна стимуляція** (дотик, візуальна, психогенна) → **парасимпатичні (S2–S4)** **тазові нерви** → **печеристі нерви**.
2. **Вивільнення NO** (**оксид азоту**) з нервових закінчень та ендотелію → **cGMP ↑** → **розслаблення гладких м'язів** печеристих тіл і артерій.
3. **Припливу крові** (**гелікоїдні артерії** розширюються) → **заповнення лакун**.
4. **Венозна оклюзія**: **розтяг тіл стискає вени** під **білковою оболонкою** (**субтуніцеальні венули**) → **відтік крові ↓** → **жорсткість**.
5. **Скорочення** сідничо-печеристого м'яза → **максимальний тиск** (**ригідна ерекція**).

**Детумесценція (завершення)**: **симпатика** (норадреналін, α₁) → **скорочення гладких м'язів**, **ФДЕ-5 розщеплює cGMP**.

| Нерви | Роль |
|---|---|
| **Парасимпатичні (S2–S4)**: **печеристі нерви** | **ерекція** («**Point**») |
| **Симпатичні (T10–L2)** | **детумесценція**, **еякуляція** |
| **Соматичні — статевий нерв** | чутливість (**дорсальний нерв члена**), **скорочення м'язів (бульбокавернозний)** |

### Фармакологія
**Інгібітори ФДЕ-5** (**силденафіл, тадалафіл**): ↑ cGMP → **ерекція при стимуляції**; **протипоказані з нітратами** (різка гіпотензія).

Деталі: [[Вегетативна нервова система]], [[Статева відповідь і контрацепція]].

### Рефлекси
- **Психогенна** (кора, лімбічна система) і **рефлекторна** (**S2–S4**, дотик).
- **Нічні ерекції** (**REM-сон**; діагностика: органічна чи психогенна дисфункція).

## 3. Кровопостачання

### Артерії (з **внутрішньої статевої**, ← внутрішня клубова)
| Артерія | Живить |
|---|---|
| **Глибока артерія члена** (*a. profunda penis*) | **печеристі тіла** (**основна для ерекції**) → **гелікоїдні артерії** |
| **Дорсальна артерія члена** | **головка, шкіра, фасція** |
| **Артерія цибулини, уретральна артерія** | **губчасте тіло, сечівник** |
| **Поверхневі зовнішні статеві артерії** (з стегнової) | шкіра |

### Вени
| Вена | Дренаж |
|---|---|
| **Поверхнева дорсальна** | шкіра → **велика підшкірна вена** (зовнішні статеві) |
| **Глибока дорсальна** (*v. dorsalis profunda*) | **головка, тіла** → **венозне сплетення простати (Санторіні)** → внутрішня клубова |

Деталі: [[Артерії нижньої кінцівки і таза]], [[Вени — нижня порожниста і ворітна системи]].

### Лімфа
- **Шкіра, крайня плоть** → **поверхневі пахвинні вузли**.
- **Головка, глибокі структури** → **глибокі пахвинні, зовнішні клубові**.
**Рак статевого члена** метастазує в **пахвинні вузли**.

## 4. Іннервація

| Нерв | Склад | Функція |
|---|---|---|
| **Дорсальний нерв члена** (*n. dorsalis penis*) | гілка **статевого (S2–S4)**; **чутливий** | **чутливість головки і шкіри** |
| **Печеристі нерви** | **парасимпатичні S2–S4** (**через тазове сплетення**; близько до **простати** — ризик при операціях) | **ерекція** |
| **Симпатичні (T10–L2)** | **підчеревне сплетення** | еякуляція, детумесценція |
| **Нерви до м'язів** (**бульбокавернозного, сідничо-печеристого**) | S2–S4 | **скорочення при ерекції та еякуляції** |

**Бульбокавернозний рефлекс** (S2–S4): стискання головки → скорочення анального сфінктера: **оцінка цілісності сакральних сегментів**.

## 5. Мошонка (*scrotum*)

| Показник | Значення |
|---|---|
| Положення | **між стегнами**, нижче члена |
| Будова | **шкіра** (пігментована, **складки**, **волосся**, **сальні та потові залози**) + **дартос** (гладка м'язова оболонка, **перегородка мошонки**) |
| Відділи | **два (праве і ліве яєчка)**, розділені **шов (raphe)** і перегородкою |
| Функція | **терморегуляція яєчок**: 34–35 °C: [[Яєчко і придаток яєчка]] |

- **Шкіра**: **тонка, багато потових залоз** (охолодження).
- **Дартос**: **скорочується** на холоді (зморщується мошонка), **розслабляється** при теплі.
- Кровопостачання: **зовнішні статеві артерії**, **промежинні** (з внутрішньої статевої), **кремастерна**.
- Іннервація: **пахвинно-статевий** (L1), **клубово-пахвинний**, **задні шкірні гілки** (S2–S3), **статево-стегновий**.
- Лімфа: **поверхневі пахвинні**.

### Хвороби мошонки
**Набряк** (серцева недостатність, нефроз), **гангрена Фурньє** (некротизуючий фасціїт: діабет, **невідкладно**), **рак** (історичний: «рак трубочистів»), **гідроцеле**, **грижа** (пахвинно-мошонкова): [[Хвороби статевої системи]].

## 6. Крайня плоть і обрізання (циркумцизія)

**Крайня плоть** — захист головки; **фімоз** (**неможливо відтягнути** після 3–5 років — патологія), **парафімоз** (защемлення — **невідкладно**), **баланопостит** (запалення), **рак**. **Обрізання** — зменшує **ВІЛ-ризик, ІСШ, баланіти**; **за показаннями / культурально**.

| Вада | Суть |
|---|---|

| **Епіспадія** | на верхній |
| **Мікропеніс** | < 2,5 SD: гормональні (гіпогонадизм) |
| **Фімоз** | |
| **Ектопія, аплазія** | |

## 8. Хвороби члена

| Хвороба | Суть |
|---|---|
| **Еректильна дисфункція (ЕД)** | **неможливість досягти/утримати ерекцію** (> 3 міс); **причини**: **судинні (атеросклероз — «ранній маркер серцево-судинних хвороб»)**, **діабет**, **неврологічні**, **ліки** (β-блокатори, антидепресанти), **гормональні**, **психогенні**; **ФДЕ-5** |
| **Пріапізм** | **тривала болісна ерекція > 4 год** — **невідкладно** (серпоподібноклітинна анемія, ліки) |
| **Хвороба Пейроні** | **фіброзна бляшка** у білковій оболонці → **викривлення** |
| **Перелом члена** | **розрив білкової оболонки** під час ерекції: **різкий хрускіт, біль, гематома («баклажан»)**, **невідкладно** |
| **Баланіт/баланопостит** | кандидоз, інфекція |
| **ІПСШ** | герпес, ВПЛ (бородавки), сифіліс (**твердий шанкр**) |
| **Рак члена** | плоскоклітинний; **ВПЛ, фімоз**; пізній |
| **Фімоз/парафімоз** | |
| **Ретроградна/передчасна еякуляція** | |

## 9. Мнемоніки

- Член: **2 печеристих тіла (зверху) + 1 губчасте (знизу, з сечівником)**.
- Ерекція: **парасимпатика S2–S4 → NO → cGMP ↑ → розширення артерій + стиснення вен**.
- **Симпатика (T10–L2) — детумесценція, еякуляція**; **ФДЕ-5 (силденафіл) — ↑ cGMP**.
- Кровопостачання: **глибока артерія члена — печеристі тіла (ерекція)**.
- Лімфа: **пахвинні** (на відміну від яєчка → поперекові).
- Невідкладні: **перелом члена, пріапізм, парафімоз, перекрут яєчка**.
