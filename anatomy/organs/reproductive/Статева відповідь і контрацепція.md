# Статева відповідь і контрацепція

Статева відповідь — фізіологічні зміни під час сексуальної активності. Контрацепція запобігає вагітності. Для безпліддя існують методи діагностики й допоміжні репродуктивні технології.

Пов'язані файли: [[Статева система — огляд]], [[Статевий член і мошонка]], [[Чоловічі статеві шляхи і додаткові залози]], [[Піхва і зовнішні жіночі статеві органи]], [[Матка і маткові труби]], [[Менструальний цикл і жіночі гормони]], [[Запліднення і вагітність]], [[Сперматогенез і чоловічі гормони]], [[Хвороби статевої системи]], [[Вегетативна нервова система]], [[Спинний мозок]], [[Проміжний мозок і базальні ядра]], [[Нервовий імпульс і синапс]].

## 1. Нервова регуляція статевої відповіді

| Компонент | Центри / нерви | Роль |
|---|---|---|
| **Кора, лімфа** | **кора, мигдалик, гіпоталамус** | **бажання, збудження, контекст** |
| **Спинальні центри** | **S2–S4** (**парасимпатика**: **ерекція, лубрикація**); **T10–L2** (**симпатика**: еміссія, оргазм) | **рефлекси** |
| **Соматичні** | **статевий нерв (S2–S4)** | **чутливість, м'язи промежини** |

**Мозок**: **гіпоталамус** (преоптична ділянка), **лімбічна система**, **нейромедіатори**: **дофамін** (↑ бажання), **серотонін** (↓), **окситоцин** (зв'язок, оргазм), **ендорфіни**, **NO** (ерекція). **Гормони**: **тестостерон — лібідо (обох статей)**, **естрогени — лубрикація, слизова**.

Деталі: [[Вегетативна нервова система]].

## 2. Цикл статевої відповіді (за Мастерсом і Джонсон)

| Фаза | Опис |
|---|---|
| **1. Збудження (excitement)** | **ерекція** (чоловіки), **лубрикація піхви, набряк** клітора, малих губ; **↑ ЧСС, АТ, дихання** |
| **2. Плато** | **максимальне збудження**; **збільшення яєчок, змінюється ареола**, «сексуальний рум'янець» |
| **3. Оргазм** | **ритмічні скорочення (0,8 с)** м'язів малого таза: **чоловіки — еміссія + експульсія (еякуляція)**; **жінки — скорочення матки, піхви (3–15 разів)**; **↑↑ ЧСС (до 180), АТ**; **окситоцин** |
| **4. Резолюція (розв'язка)** | **розслаблення**, **зниження ерекції**; **рефрактерний період (чоловіки: хвилини–години)**; **жінки — можливі множинні оргазми** |

**Додаткова фаза (Каплан): бажання (лібідо)**.

### Чоловіки
- **Ерекція**: **парасимпатика (S2–S4) → NO → cGMP**: [[Статевий член і мошонка]].
- **Еякуляція**: **еміссія (симпатика T10–L2: протоки, міхурці, простата → сечівник; закриття шийки)** → **експульсія (S2–S4, статевий нерв: бульбокавернозний м'яз)**: [[Чоловічі статеві шляхи і додаткові залози]].
- **Рефрактерний період** після оргазму.

### Жінки
- **Лубрикація**: **транссудат стінки піхви** (судинний приплив, **парасимпатика**), залози Бартоліна (мало).
- **Клітор**: **ерекція печеристих тіл**.
- **Піхва**: **подовжується, розширюється** (**«намет»**), **нижня третина — «оргастична манжета»**.
- **Матка**: **піднімається**.
- **Оргазм**: **ритмічні скорочення** матки, піхви, **тазового дна**.
- **Клітор і піхва**: **клітор — основний** (його внутрішня частина оточує піхву, **ніжки, цибулини**); «точка G» — **спірна**.

Деталі: [[Піхва і зовнішні жіночі статеві органи]].

## 3. Порушення статевої функції

### Жінки
| Стан | Суть |
|---|---|
| **Знижене бажання** | **гормони, депресія, ліки, відносини** |

**Лікування**: **діагностика причин**, **психотерапія**, **гормони**, **ліки**.

## 4. Контрацепція

**Контрацепція** — запобігання вагітності. **Ефективність** — **індекс Перля** (вагітностей на 100 жінок за рік; **типове використання**).

### Методи за принципом

| Метод | Механізм | Ефективність (типово) |
|---|---|---|
| **Бар'єрні** | | |
| — **Презерватив чоловічий** | механічний бар'єр; **також захист від ІПСШ** | **~87%** (13 вагітностей/100) |
| — **Презерватив жіночий, діафрагма, ковпачок** | | 79–88% |
| **Гормональні комбіновані (КОК)** | **естроген + прогестин** → **пригнічення овуляції** (**↓ ФСГ/ЛГ**), густий слиз, тонкий ендометрій | **~91–99%** |
| **Гормональні прогестинові** | **міні-пілюля**, **ін'єкція (медроксипрогестерон, 3 міс.)**, **імплант (3 роки)**, **ВМС-LNG** | імплант, ВМС **>99%** |
| **Пластир, вагінальне кільце** | комбінований гормональний | ~91% |
| **Внутрішньоматкові засоби (ВМС)** | | |
| — **мідна ВМС** | **іони міді → токсично для сперматозоїдів + запалення ендометрія**; **5–10 років**; **безгормональна**; **екстрена контрацепція (до 5 днів)** | **>99%** |
| — **гормональна ВМС (левоноргестрел)** | ↓ ендометрій, слиз; **5 років**; **↓ менструальна кровотеча** | **>99%** |
| **Екстрена (постковітальна)** | **левоноргестрел (до 72 год)**, **улипристал (до 120 год)**, **мідна ВМС (до 5 днів)** | залежить від часу |
| **Стерилізація** | | |
| — **Жіноча (перев'язка маткових труб)** | **перешкода труб** | **>99%**, **незворотна** |
| — **Чоловіча (вазектомія)** | **перев'язка сім'явивідних проток**; **спермограма через 3 міс.** | **>99%**, **тестостерон не змінюється** |
| **Методи, що ґрунтуються на спостереженні** | **календарний, температурний, слизовий, ЛГ-тест** | **~76–88% (низька)** |
| **Перерваний статевий акт** | | **~78%** (≈22 вагітності на 100) |
| **Лактаційна аменорея (ЛАМ)** | **виключно ГВ < 6 міс. + аменорея** | ~98% (при строгому дотриманні) |

### Гормональна контрацепція: механізм
**↑ естроген + прогестин** → **негативний зворотний зв'язок** на гіпоталамус/гіпофіз → **↓ ФСГ, ЛГ → немає овуляції**; **цервікальний слиз густий**; **ендометрій тонкий**: [[Менструальний цикл і жіночі гормони]].

### Побічні ефекти і ризики КОК
- **Венозна тромбоемболія** (ризик ×2–4; вище при **паління, ожиріння, мігрені з аурою, > 35 років**); **інсульт, інфаркт** (рідко).
- **Головний біль, нудота, болючість грудей, прориви**.
- **Переваги**: **регулярні менструації, ↓ дисменорея, ↓ акне, ↓ ризик раку яєчників і ендометрія**.
- **Протипоказання**: **ТГВ в анамнезі, мігрень з аурою, паління > 35, гіпертензія, рак молочної залози, захворювання печінки**.

### Вибір методу
**Фактори**: **ефективність**, **захист від ІПСШ**, **безпека, зворотність**, **побажання, прийом ліків, вік, ожиріння**, **лактація**.

## 5. Переривання вагітності (аборт)

- **Медикаментозний** (міфепристон + мізопростол, **до 9–12 тижнів**) і **хірургічний** (вакуумна аспірація, **кюретаж**).
- **Ускладнення**: **кровотеча, інфекція, залишки тканини, перфорація матки**.
- Законодавство залежить від країни.

## 6. Безпліддя (**репродуктивна медицина**)

**Безпліддя** — **відсутність вагітності після 12 місяців** (**6 міс. після 35 р.**) регулярного незахищеного життя. **Часте**: **~10–15% пар**.

### Причини
| Чоловічий фактор | ~**30–40%** |
|---|---|
| Жіночий фактор | **~30–40%** (**ановуляція (СПКЯ), трубний фактор (ЗЗОМТ), ендометріоз, міома, вік, шийковий**) |
| Обидва / невідомі | **~20–30%** |

### Обстеження
| Метод | Для кого |
|---|---|
| **Спермограма** | чоловік: [[Чоловічі статеві шляхи і додаткові залози]] |
| **Овуляція** (**прогестерон на 21 день, УЗД, ЛГ-тест**) | жінка |
| **АМГ, ФСГ, антральні фолікули** | **яєчниковий резерв** |
| **Прохідність труб** | **ГСГ (гістеросальпінгографія)**, **соногістеросальпінгографія**, **лапароскопія** |
| **УЗД матки/яєчників, гістероскопія** | |
| **Гормони** (ТТГ, пролактин, андрогени) | |

### Допоміжні репродуктивні технології (ДРТ)
| Метод | Суть |
|---|---|
| **Стимуляція овуляції** | **летрозол, кломіфен, гонадотропіни** |
| **Внутрішньоматкова інсемінація (ВМІ)** | **сперма в матку** в день овуляції |
| **ЕКЗ (екстракорпоральне запліднення, IVF)** | **стимуляція → забір ооцитів → запліднення in vitro → ембріони (5 день) → перенос у матку**; **вагітність ~30–40% за цикл (залежить від віку)** |
| **ІЦСІ (ICSI)** | **введення одного сперматозоїда в ооцит** (**чоловічий фактор**) |
| **Донорство** (**гамет, ембріонів**), **сурогатне материнство**, **кріоконсервація** | |
| **Преімплантаційна діагностика (ПГТ)** | **генетика ембріона** |

**Вік жінки** — **головний фактор** (**після 35 років ↓ якість ооцитів**; **після 40 — різко**).

## 7. Профілактика ІПСШ

**Бар'єрні методи (презерватив)**, **вакцинація** (**ВПЛ, гепатит B**), **скринінг**, **обмеження партнерів**, **ПКП/ПрЕП (ВІЛ)**: [[Хвороби статевої системи]].

## 8. Мнемоніки

- **Фази відповіді: бажання → збудження → плато → оргазм → резолюція**.
- **Ерекція — парасимпатика (S2–S4), еякуляція — симпатика (T10–L2) + статевий нерв**.
- **КОК: естроген + прогестин → блок овуляції**; **ВМС >99%, імплант >99%, презерватив ~87%**.
- **Єдиний метод, що захищає від ІПСШ — презерватив**.
- **Безпліддя: 12 місяців; чоловічий фактор 30–40%**; **ЕКЗ, ІЦСІ**.
