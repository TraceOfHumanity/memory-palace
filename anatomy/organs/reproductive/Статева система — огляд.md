# Статева система — огляд (*systema genitalia*)

Статева система забезпечує розмноження. Вона виробляє **статеві клітини** (гамети), **статеві гормони**, створює умови для **запліднення**, розвитку плода й пологів. Будова чоловічої та жіночої систем різна, але обидві розвиваються з одних зачатків.

## 1. Склад системи

| Відділ | Чоловіки | Жінки |
|---|---|---|
| **Гонади** (статеві залози) | **яєчка** | **яєчники** |
| **Статеві шляхи** | придаток яєчка, сім'явивідна протока, сечівник | маткові труби, матка, піхва |
| **Додаткові залози** | передміхурова, сім'яні міхурці, бульбоуретральні | великі присінкові залози, залози Скіна |
| **Зовнішні статеві органи** | статевий член, мошонка | **вульва**: лобок, статеві губи, клітор, присінок |
| **Молочні залози** | рудиментарні | розвинені (лактація) |

Поділ за положенням: **внутрішні** органи (в тазу) і **зовнішні** (на промежині).

| Функція | Опис |

| **Гаметогенез** | сперматогенез (яєчка), оогенез (яєчники) |
| **Гормональна** | **тестостерон, естрогени, прогестерон**, інгібін, релаксин |
| **Запліднення** | злиття сперматозоїда й яйцеклітини (маткова труба) |
| **Вагітність** | розвиток зародка в матці |
| **Пологи, лактація** | |
| **Формування статевих ознак** | первинні (органи) і вторинні (волосся, голос, молочні залози) |
| **Статева поведінка** | лібідо, статева відповідь |

## 3. Регуляція: вісь «гіпоталамус — гіпофіз — гонади»

| Рівень | Гормон | Ефект |
|---|---|---|
| **Гіпоталамус** | **гонадоліберин (ГнРГ, GnRH)** — **пульсуючий** | стимулює гіпофіз |
| **Передній гіпофіз** | **ФСГ** (фолікулостимулювальний), **ЛГ** (лютеїнізувальний) | стимулюють гонади |
| **Гонади** | **чоловіки**: тестостерон, інгібін В; **жінки**: естрогени, прогестерон, інгібін | **зворотний зв'язок** |

- **Чоловіки**: **ЛГ → клітини Лейдіга → тестостерон**; **ФСГ → клітини Сертолі → сперматогенез**; **інгібін В** гальмує ФСГ.
- **Жінки**: **ФСГ → ріст фолікула, естрогени**; **ЛГ → овуляція, жовте тіло, прогестерон**; **цикл**.
- **Пролактин** (гіпофіз): лактація; його підвищення **гальмує ГнРГ** (безпліддя).

Деталі гіпоталамуса: [[Проміжний мозок і базальні ядра]]. Повний розділ про гормони гіпофіза буде в ендокринній системі.

## 4. Розвиток статевої системи

### Генетична стать
- **Хромосоми**: **XY — чоловік**, **XX — жінка**; **SRY-ген** (Y-хромосома) → **яєчко**.
- До **7-го тижня** зачатки **індиферентні** (однакові).

### Гонади
- **Статевий тяж** → у чоловіків **яєчко** (SRY → клітини Сертолі, Лейдіга); у жінок (без SRY) → **яєчник**.
- **Первинні статеві клітини (гоноцити)** мігрують із **жовткового мішка** (4–6 тиждень).

### Протоки
| Протока | Чоловіки | Жінки |
|---|---|---|
| **Мезонефрична (Вольфова)** | **придаток яєчка, сім'явивідна протока, сім'яні міхурці** (під впливом **тестостерону**) | **регресує** |
| **Парамезонефрична (Мюллерова)** | **регресує** (**антимюлерів гормон — клітини Сертолі**) | **маткові труби, матка, верхня частина піхви** |

### Зовнішні органи
- **Чоловіки**: **дигідротестостерон (ДГТ)** → **статевий член, мошонка, передміхурова залоза**.
- **Жінки**: **без андрогенів** → **клітор, статеві губи, нижня частина піхви**.

### Опускання гонад
- **Яєчка**: з поперекової ділянки через **пахвинний канал** у **мошонку**; **до 7–9 місяця** (**крипторхізм** — неопущення).
- **Яєчники**: опускаються у **малий таз**.

### Вади і порушення розвитку статі
**Крипторхізм, гіпоспадія, синдром нечутливості до андрогенів (XY, жіночий фенотип)**, **синдром Тернера (45,X)**, **Клайнфельтера (47,XXY)**, **вроджена гіперплазія надниркових залоз** (недорозвиток зовнішніх статевих органів), **агенезія матки (Майєра — Рокітанського)**, **двурога матка**: [[Хвороби статевої системи]].

## 5. Статеве дозрівання (пубертат)

| Стать | Вік початку | Ознаки |
|---|---|---|
| **Дівчатка** | 8–13 років | **телархе** (груди), **пубархе**, **ріст**, **менархе** (~12–13) |
| **Хлопчики** | 9–14 років | **збільшення яєчок**, пубархе, ріст, **мутація голосу**, **полюції** |

Тригер: **активація ГнРГ** (маса тіла, лептин). **Передчасне** (< 8 / < 9 років) і **затримане** статеве дозрівання — [[Хвороби статевої системи]].

## 6. Вторинні статеві ознаки

| | Чоловіки | Жінки |
|---|---|---|
| **Гормон** | тестостерон | естрогени |
| **Ознаки** | **борода, оволосіння, низький голос, м'язи, широкі плечі** | **розвиток молочних залоз, широкий таз, розподіл жиру, тонкий голос** |

## 7. Кровопостачання, іннервація (загальне)

- Артерії: **яєчкова/яєчникова** (з аорти), **внутрішня клубова** (внутрішня статева, маткова): [[Аорта і її гілки]], [[Артерії нижньої кінцівки і таза]].
- Вени: **яєчкова/яєчникова** (права → НПВ, ліва → ліва ниркова), **венозні сплетення**: [[Вени — нижня порожниста і ворітна системи]].
- Іннервація: **симпатика (T10–L2)** — еякуляція; **парасимпатика (S2–S4)** — **ерекція**; **статевий нерв** — соматична: [[Вегетативна нервова система]], [[Поперекове і крижове сплетення]].
- Лімфа: чоловіки — яєчко → **поперекові**; шкіра, статевий член — **пахвинні**. Жінки — яєчник → поперекові; матка → клубові; вульва → пахвинні.

## 9. Мнемоніки

- **XY — SRY — яєчко — тестостерон — Вольфова протока → чоловік**; **XX — яєчник — Мюллерова протока → жінка**.
- Вісь: **ГнРГ → ЛГ, ФСГ → гонади → гормони → зворотний зв'язок**.
- **Клітини Лейдіга — тестостерон; клітини Сертолі — підтримка сперматогенезу, АМГ**.
- Іннервація ерекції — **S2–S4** (парасимпатика, «**Point**»); еякуляція — **T10–L2** (симпатика, «**Shoot**»).
