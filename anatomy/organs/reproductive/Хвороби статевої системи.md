# Хвороби статевої системи

Це зведення основних хвороб чоловічих і жіночих статевих органів. Для кожної наведено суть, ключові ознаки й принципи лікування. Детальну анатомію та фізіологію шукай у файлах про окремі органи.

## 1. Симптоми й орієнтири

### Чоловіки
| Ознака | Можливі причини |
|---|---|
| **Біль у мошонці (гострий)** | **перекрут яєчка (невідкладно!)**, епідидиміт, орхіт, травма |
| **Збільшення мошонки** | гідроцеле, варикоцеле, грижа, пухлина |
| **Виділення з уретри, дизурія** | **уретрит (гонорея, хламідіоз)** |
| **Слабкий струмінь, ніктурія** | **ДГПЗ**: [[Сечівник і сечовипускання]] |
| **Безпліддя** | варикоцеле, гіпогонадизм, обструкція |
| **Еректильна дисфункція** | судинна, діабет, гормональна, психогенна |

### Жінки
| Ознака | Можливі причини |
|---|---|
| **Аномальна маткова кровотеча (АМК)** | **ановуляція, міома, поліпи, аденоміоз, гіперплазія/рак, коагулопатія, вагітність (!)** |
| **Постменопаузальна кровотеча** | **рак ендометрія — до онколога!** |
| **Біль у тазу** | **ендометріоз, ЗЗОМТ, кіста, міома, позаматкова вагітність**, апендицит |
| **Виділення з піхви, свербіж** | **вагіноз, кандидоз, трихомоніаз, ІПСШ** |
| **Дисменорея** | первинна / ендометріоз |
| **Безпліддя** | ановуляція, трубний фактор |
| **Аменорея, олігоменорея** | **вагітність**, СПКЯ, гіперпролактинемія: [[Менструальний цикл і жіночі гормони]] |
| **Утвір у молочній залозі** | **фіброаденома, кіста, рак** |

**Золоте правило: у жінки репродуктивного віку з болем у животі й затримкою менструації виключити позаматкову вагітність** (тест на ХГЛ).

## 2. Хвороби чоловічих статевих органів

| Орган | Хвороби |
|---|---|
| **Яєчко і придаток** | **перекрут яєчка**, **епідидиміт, орхіт**, **гідроцеле, варикоцеле**, **крипторхізм**, **рак яєчка**, **гіпогонадизм** |
| **Простата** | **ДГПЗ, простатит, рак простати** |
| **Статевий член** | **ЕД, пріапізм, хвороба Пейроні, фімоз/парафімоз, баланопостит, гіпоспадія, рак члена, перелом** |
| **Мошонка** | **гангрена Фурньє, гідроцеле, грижа** |

Деталі: [[Яєчко і придаток яєчка]], [[Чоловічі статеві шляхи і додаткові залози]], [[Статевий член і мошонка]], [[Сперматогенез і чоловічі гормони]].

### Невідкладні (чоловіки)
| Стан | Дія |
|---|---|
| **Перекрут яєчка** | **операція до 6 год** |
| **Пріапізм** (> 4 год) | дренаж, фенілефрин |
| **Парафімоз** | вправлення |
| **Перелом члена** | операція |
| **Гангрена Фурньє** | антибіотики + хірургія |
| **Гостра затримка сечі** | катетеризація |

### Рак простати
- **Аденокарцинома, периферична зона**; **ПСА ↑**; **ПРД**; **біопсія (Глісон)**; **метастази — кістки (остеобластні)**; **лікування**: **спостереження, простатектомія, променева, андрогенна депривація**.
- **Скринінг** — індивідуально (ПСА + ПРД; **обговорення переваг/ризиків**).

### Рак яєчка
- **15–35 років**; **безболісний вузлик**; **АФП, β-ХГЛ, ЛДГ**; **орхіектомія**; **виліковний > 90%**.

## 3. Хвороби жіночих статевих органів

| Орган | Хвороби |
|---|---|
| **Вульва, піхва** | **вагіноз, кандидоз, трихомоніаз**, **кіста Бартоліна**, **ІПСШ**, **VIN, рак вульви/піхви**, **атрофічний вагініт**, **пролапс** |
| **Шийка матки** | **цервіцит, дисплазія (CIN), рак шийки**, ектопія |
| **Матка** | **міома, ендометріоз/аденоміоз, поліпи, гіперплазія, рак ендометрія**, **ендометрит** |
| **Труби** | **сальпінгіт, гідросальпінкс, позаматкова вагітність**, трубне безпліддя |
| **Яєчник** | **функціональні кісти, СПКЯ, ендометріоми, дермоїдна кіста, перекрут, рак яєчника, ПНЯ** |
| **Молочна залоза** | **мастит, фіброаденома, мастопатія, рак** |

Деталі: [[Піхва і зовнішні жіночі статеві органи]], [[Матка і маткові труби]], [[Яєчник]], [[Молочна залоза]].

### Невідкладні (жінки)
| Стан | Ознаки |
|---|---|
| **Позаматкова вагітність (розрив)** | **біль, кровотеча, шок**; **ХГЛ +, порожня матка на УЗД**; **операція** |
| **Перекрут кісти/яєчника** | **гострий біль, нудота**; **лапароскопія** |
| **ЗЗОМТ (тубооваріальний абсцес)** | лихоманка, біль; **антибіотики, дренаж** |
| **Масивна маткова кровотеча** | **стабілізація, транексамова кислота, хірургія** |
| **Прееклампсія/еклампсія, відшарування плаценти** | [[Запліднення і вагітність]] |
| **Післяпологова кровотеча** | [[Пологи і післяпологовий період]] |

### Ендометріоз
- **Ендометріоподібна тканина поза маткою** (**яєчники, очеревина, дуглас, крижово-маткові зв'язки**); **естроген-залежний**; **25–35 років**.
- **Тріада: дисменорея, діспареунія, безпліддя**; **хронічний біль у тазу**.
- **Діагноз**: **УЗД, МРТ, лапароскопія (золотий стандарт)**.
- **Лікування**: **НПЗП, гормональне (КОК, прогестини, агоністи ГнРГ)**, **хірургія**.

### Міома матки
- **Найчастіша** пухлина жіночих органів (до 70% жінок до 50 р.); **естроген-залежна**; **гладком'язова**.
- **Ознаки**: **меноррагія, тиск, біль, безпліддя**; **стискання сечового міхура/прямої кишки**.
- **Лікування**: **спостереження, ліки (улипристал, агоністи ГнРГ), міомектомія, емболізація, гістеректомія**.

### СПКЯ
- **Роттердамські критерії (2 з 3)**: **олігоановуляція**, **клінічна/біохімічна гіперандрогенія (гірсутизм, акне)**, **полікістозні яєчники на УЗД**.
- **Ризики**: **діабет 2 типу, метаболічний синдром, гіперплазія/рак ендометрія, безпліддя**.
- **Лікування**: **зниження ваги, метформін, КОК, летрозол (індукція овуляції)**.

## 4. Рак жіночих статевих органів

| Рак | Ключове |
|---|---|
| **Рак шийки матки** | **ВПЛ 16/18**; **скринінг (мазок, ВПЛ-тест)**; **вакцина**; контактні кровотечі; **виліковний при ранній стадії** |
| **Рак ендометрія** | **постменопаузальна кровотеча**; **естроген, ожиріння**; **гістероскопія, біопсія**; хірургія |
| **Рак яєчника** | **пізні симптоми (здуття, асцит)**; **CA-125, BRCA**; **найлетальніший** гінекологічний |
| **Рак вульви, піхви** | ВПЛ, лихенний склероз |
| **Рак молочної залози** | **найчастіший**; **мамографія**; **ER/PR/HER2** |

**Вакцина проти ВПЛ** (9-валентна; **до початку статевого життя**) + **скринінг** = **профілактика раку шийки**.

## 5. Інфекції, що передаються статевим шляхом (ІПСШ)

| Інфекція | Збудник | Ключове | Лікування |
|---|---|---|---|
| **Гонорея** | *Neisseria gonorrhoeae* | **гнійні виділення, дизурія**; **жінки часто безсимптомно**; **ЗЗОМТ, безпліддя**; діплококи при мікроскопії | **цефтріаксон** |
| **Хламідіоз** | *Chlamydia trachomatis* | **найчастіша бактеріальна ІПСШ**; **безсимптомна**; **ЗЗОМТ, безпліддя, позаматкова**; **у чоловіків уретрит, епідидиміт** | **доксициклін/азитроміцин** |
| **Сифіліс** | *Treponema pallidum* | **первинний — безболісна виразка (твердий шанкр)**; **вторинний — висип (долоні, підошви), широкі кондиломи**; **третинний — гуми, нейросифіліс, аортит** | **пеніцилін** |
| **Герпес (ВПГ-2)** | вірус | **болісні пухирці/виразки, рецидиви** | **ацикловір** (не виліковує) |
| **ВПЛ** | вірус папіломи | **кондиломи (6, 11)**; **рак (16, 18)** | вакцина; видалення |
| **Трихомоніаз** | *Trichomonas vaginalis* | **пінисті виділення** | метронідазол |
| **Бактеріальний вагіноз, кандидоз** | не ІПСШ суворо | | |
| **ВІЛ** | вірус | **імунодефіцит**; **ПКП/ПрЕП, АРТ** | |
| **Гепатит B/C** | віруси | передаються і статевим шляхом | вакцина (B), противірусні |
| **Mycoplasma genitalium** | бактерія | уретрит, цервіцит | азитроміцин, моксифлоксацин |
| **Лобкові воші, короста** | паразити | свербіж | місцеві засоби |

**Профілактика**: **презерватив**, **вакцини (ВПЛ, гепатит B)**, **скринінг**, **лікування партнерів**.
**Ускладнення**: **ЗЗОМТ, безпліддя, позаматкова вагітність, хронічний біль, внутрішньоутробні інфекції**: [[Статева відповідь і контрацепція]].

## 8. Профілактика і скринінг

- **ВПЛ-вакцинація** (9–14 років; до початку життя).
- **Скринінг шийки** (з 21–25 років, раз на 3–5 років).
- **Мамографія** (після 40–50), **самообстеження молочних залоз**.
- **Самообстеження яєчок**.
- **Безпечна поведінка (презерватив), вакцина гепатит B**.
- **Фолієва кислота при плануванні вагітності**.
- **Здоровий спосіб життя** (вага, фізична активність, відмова від паління).

## 9. Мнемоніки

- **Невідкладно: перекрут яєчка (6 год), позаматкова вагітність, перекрут яєчника, перелом/пріапізм, гангрена Фурньє**.
- **Рак: яєчка (15–35 років, АФП/β-ХГЛ), простата (периферична зона, ПСА), шийка (ВПЛ), ендометрій (кровотеча постменопауза), яєчник (CA-125, пізно)**.
- **Ендометріоз**: **дисменорея + діспареунія + безпліддя**.
- **СПКЯ**: **олігоановуляція + гіперандрогенія + полікістозні яєчники (2 з 3)**.
- **ІПСШ: гонорея (діплокок), хламідія (безсимптомна), сифіліс (шанкр)**.
- **ВПЛ 16/18 → рак; 6/11 → кондиломи**.
