# Менструальний цикл і жіночі гормони

Менструальний цикл — циклічні зміни в яєчниках і матці, що готують організм до можливої вагітності. Він керується віссю **«гіпоталамус — гіпофіз — яєчники»**. Якщо запліднення не настало, слизова матки (**ендометрій**) відторгається — це **менструація**.

Пов'язані файли: [[Статева система — огляд]], [[Яєчник]], [[Матка і маткові труби]], [[Піхва і зовнішні жіночі статеві органи]], [[Молочна залоза]], [[Запліднення і вагітність]], [[Статева відповідь і контрацепція]], [[Хвороби статевої системи]], [[Проміжний мозок і базальні ядра]], [[Нервовий імпульс і синапс]], [[Кісткова тканина]], [[Серце — коронарні судини]], [[Гормони гіпофіза — осі і хвороби]].

## 1. Основні показники

| Показник | Значення |
|---|---|
| **Тривалість циклу** | **21–35 днів** (в середньому **28**); рахується від **першого дня менструації** |
| **Менструація** | **3–7 днів**; крововтрата **30–80 мл** (> 80 — меноррагія) |
| **Овуляція** | **~14-й день** (за 28-денного циклу); **за 14 днів до наступної менструації** |
| **Менархе** | **11–14 років** (в середньому ~12,5) |
| **Менопауза** | **45–55 років** (в середньому ~51); **відсутність менструацій 12 місяців** |
| **Фертильне вікно** | **5 днів до овуляції + день овуляції** (сперматозоїди живуть до 5 днів, яйцеклітина 12–24 год) |

## 2. Дві паралельні сторони циклу

| Яєчниковий цикл | Маточний (ендометріальний) цикл |
|---|---|
| **Фолікулярна фаза** (дні 1–14): росте фолікул | **Менструальна** (1–5), **проліферативна** (6–14) |
| **Овуляція** (день ~14) | |
| **Лютеїнова фаза** (дні 15–28): жовте тіло | **Секреторна** (15–28) |

**Фолікулярна фаза — змінна** (10–20 днів); **лютеїнова — стала (14 днів)**.

## 3. Гормони осі і їхні функції

| Гормон | Джерело | Основна дія |
|---|---|---|
| **ГнРГ** | **гіпоталамус** (пульсуючий, **кожні 60–90 хв**) | стимулює гіпофіз |
| **ФСГ** | передній гіпофіз | **ріст фолікулів**, **естрогени** (гранульозні клітини, ароматаза) |
| **ЛГ** | передній гіпофіз | **текальні клітини — андрогени**; **овуляція (сплеск)**; **жовте тіло — прогестерон** |
| **Естрадіол (E₂)** | **гранульозні клітини** (фолікул) | **проліферація ендометрія**, цервікальний слиз, **негативний і позитивний зворотний зв'язок** |
| **Прогестерон** | **жовте тіло** | **секреторна трансформація ендометрія**, ↑ температура, **негативний зворотний зв'язок** |
| **Інгібін В/A** | гранульозні | ↓ ФСГ |

## 4. Фази циклу (28-денний)

### 4.1. Менструальна фаза (дні 1–5)
- **Падіння естрогенів і прогестерону** (регрес жовтого тіла).
- **Спазм спіральних артерій** ендометрія (**простагландин F₂α**) → **ішемія → некроз → відторгнення функціонального шару** → **кровотеча (менструація)**.
- **ФСГ ↑** (зняття гальмування) → **набір нової когорти фолікулів**.

### 4.2. Проліферативна (фолікулярна) фаза (дні 6–14)
- **Яєчник**: **ФСГ** → **ріст 15–20 фолікулів** → **домінантний фолікул** (до 20 мм); **естрадіол ↑**.
- **Ендометрій**: **естрадіол** → **проліферація залоз і строми, ріст спіральних артерій**; **товщина 3–5 → 8–10 мм**.
- **Цервікальний слиз**: **водянистий, прозорий, розтяжний** («як білок яйця»; **симптом «папороті»**) — **сприятливий для сперматозоїдів**.
- **Температура** — **низька**.

### 4.3. Овуляція (день ~14)
**Механізм**: **високий естрадіол** (> 200 пг/мл протягом 50 год) → **позитивний зворотний зв'язок** → **сплеск ЛГ (і ФСГ)**:
1. **Сплеск ЛГ** (**~36 годин до овуляції**; **10–12 год до розриву**).
2. **Завершення мейозу I** → **вторинний ооцит**.
3. **Ферменти** (протеази, простагландини) **розплавляють стінку фолікула** → **розрив** → **вихід ооцита з променистим вінцем**.
4. **Жовте тіло** починає формуватись.

**Ознаки**: **біль овуляції (Миттельшмерц)**, **прозорий слиз**, **базальна температура — зниження, потім ↑ на 0,3–0,5 °C**, **ЛГ-тест (тест на овуляцію) позитивний**.

### 4.4. Секреторна (лютеїнова) фаза (дні 15–28)
- **Яєчник**: **жовте тіло** (**ЛГ**) → **прогестерон ↑↑** (до 10–20 нг/мл) + естрадіол (2-й пік); **інгібін А**.
- **Ендометрій**: **прогестерон** → **секреторна трансформація**: **звивисті залози**, **глікоген, секрет**, **набряк строми**, **децидуалізація**; **товщина 8–15 мм**; **«вікно імплантації»** (дні **20–24**, 6–10 днів після овуляції).
- **Цервікальний слиз**: **густий, липкий** (**бар'єр**).
- **Температура**: **вища на 0,3–0,5 °C** (**термогенна дія прогестерону**).
- **Груди**: **набряк, болючість**; **ПМС**.

**Якщо запліднення немає**: **жовте тіло регресує** через **14 днів** → **↓ прогестерон і естрадіол** → **менструація**.
**Якщо вагітність**: **ХГЛ** (бластоцисти, з 6–8 днів) **підтримує жовте тіло** (до 8–10 тижнів; потім плацента): [[Запліднення і вагітність]].

## 5. Регуляція (зворотні зв'язки)

| Рівень естрадіолу | Ефект на гіпофіз/гіпоталамус |
|---|---|
| **Низький/помірний** (рання фолікулярна) | **негативний** (гальмує ФСГ/ЛГ) |
| **Високий, тривалий** (пізня фолікулярна) | **позитивний → сплеск ЛГ** |
| **Прогестерон + естрадіол** (лютеїнова) | **сильний негативний** (↓ ФСГ, ЛГ; **пригнічення нових фолікулів**) |

**Принцип контрацепції**: **комбіновані оральні контрацептиви (естроген + прогестин)** і прогестини → **негативний зворотний зв'язок** → **немає сплеску ЛГ → немає овуляції**: [[Статева відповідь і контрацепція]].

## 6. Дії естрогенів і прогестерону

### Естрогени (естрадіол)
| Орган | Дія |
|---|---|
| **Матка** | **проліферація ендометрія**; ріст міометрія; **цервікальний слиз ↑** |
| **Піхва** | **товстий епітелій, глікоген** (pH ↓) |
| **Молочна залоза** | **ріст проток** |
| **Кістки** | **↓ резорбція**, **закриття зон росту (в пубертаті)**; **дефіцит → остеопороз** |
| **Метаболізм** | **↓ ЛПНЩ, ↑ ЛПВЩ** (**судинний захист**; **після менопаузи ризик ↑**); **затримка Na⁺/води**; **↑ згортання** (ризик тромбозів при ЕК) |
| **Вторинні ознаки** | **груди, таз, жирові відкладення (стегна)**, **шкіра** |
| **Мозок** | настрій, пам'ять, **терморегуляція** (припливи при дефіциті) |
| **Гіпофіз** | зворотний зв'язок |

### Прогестерон
| Орган | Дія |
|---|---|
| **Матка** | **секреторна трансформація**; **розслаблення міометрія** (вагітність); **густий цервікальний слиз** |
| **Молочна залоза** | **ріст альвеол** |
| **Температура** | **↑ на 0,3–0,5 °C** |
| **Метаболізм** | **↓ чутливість до інсуліну**, **діуретична (антиальдостерон)**, **заспокійливий (нейростероїди)** |
| **Дихання** | ↑ |

### Інші
**Андрогени** (тека, надниркові): **лібідо, оволосіння**; **естрогени — з андрогенів** (ароматаза).

## 7. Порушення циклу

| Термін | Опис |
|---|---|
| **Первинна аменорея** | **немає менархе до 15 років** (або 13 без вторинних ознак): **Тернер, агенезія матки, атрезія пліви, затримка пубертату, гіпоталамічні** |
| **Вторинна аменорея** | **відсутність > 3–6 місяців** після регулярних: **вагітність (!)**, **СПКЯ**, **гіперпролактинемія**, **гіпоталамічна (стрес, схуднення, спорт, анорексія)**, **ПНЯ**, **гіпотиреоз**, **синдром Ашермана** |
| **Олігоменорея** | **цикл > 35 днів** |
| **Поліменорея** | **цикл < 21 день** |
| **Меноррагія (гіперменорея)** | **> 80 мл / > 7 днів**: міома, поліпи, аденоміоз, коагулопатії, **ановуляторні**, ДМК |
| **Метрорагія** | **міжменструальна кровотеча** |
| **Дисменорея** | **болісні менструації**: **первинна** (**простагландини**, молоді; НПЗП), **вторинна** (ендометріоз, аденоміоз) |
| **ПМС / ПМДР** | **передменструальний синдром**: роздратування, набряк, біль; лютеїнова фаза |
| **Дисфункціональна маткова кровотеча** | **ановуляція**: естроген без прогестерону → **гіперплазія ендометрія** |
| **Ановуляція** | СПКЯ, стрес, ІМТ, щитоподібна залоза |

### Менопауза
- **Вичерпання фолікулів** → **↓ естрадіол, інгібін → ↑↑ ФСГ, ЛГ**.
- **Перименопауза** (нерегулярні цикли 3–5 років) → **менопауза** (**12 міс. аменореї**; ФСГ > 30) → **постменопауза**.
- **Симптоми**: **припливи, нічна пітливість** (вазомоторні), **атрофія піхви/діспареунія**, **безсоння, настрій**, **остеопороз**, **серцево-судинний ризик**.
- **Менопаузальна гормональна терапія (МГТ)**: **естроген (+ прогестерон при матці)**; **ризики**: тромбоз, рак молочної залози (довготривало).

## 8. Базальна температура і методи спостереження

- **Базальна температура** (вранці, в ректальному/вагінальному/пероральному вимірюванні): **двофазна крива** (↓ перед овуляцією, **↑ після**) — **підтверджує овуляцію** (ретроспективно).
- **Цервікальний слиз**, **ЛГ-тести**, **УЗД фолікулометрія**.
- **Методи «безпечних днів»** — **ненадійні** (індекс Перля 15–25).

## 9. Мнемоніки

- **Фази: менструальна → проліферативна (ФСГ, естрадіол) → овуляція (сплеск ЛГ) → секреторна (прогестерон)**.
- **Лютеїнова фаза — 14 днів (стала)**; **фолікулярна — змінна**.
- **Естрадіол — проліферація; прогестерон — секреція + температура ↑**.
- **Високий E₂ → позитивний зв'язок → ЛГ-сплеск → овуляція**.
- **Падіння прогестерону → менструація**; **ХГЛ → підтримує жовте тіло**.
- Менопауза: **ФСГ ↑↑, естрадіол ↓**.
