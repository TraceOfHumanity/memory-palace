# Яєчник (*ovarium*)

Яєчник — парна жіноча статева залоза. Він виробляє **яйцеклітини** і гормони **естрогени та прогестерон**. Яєчник розташований у малому тазу й зв'язаний із маткою та тазовою стінкою зв'язками.

## 1. Положення і розміри

| Показник | Значення |
|---|---|
| Положення | **яєчникова ямка** на бічній стінці малого таза: між **зовнішніми і внутрішніми клубовими судинами**, **перед сечоводом** |
| Розміри | **3–4 × 2 × 1 см** (мигдалеподібний) |
| Маса | **5–8 г** (у репродуктивний період); **після менопаузи — менше** |
| Об'єм | 5–15 мл (у репродуктивному віці) |
| Поверхня | гладка (дитина) → **горбиста** (після овуляцій) |

### Сусіди (яєчникова ямка)
- **Спереду** — **широка зв'язка матки**.
- **Ззаду** — **сечовід, внутрішні клубові судини**.
- **Зверху** — **зовнішня клубова вена**.
- **Поруч** — **затульний нерв** (біль від яєчника може віддавати у **внутрішню поверхню стегна**).

**Ураження яєчника — ризик для сечоводу (при хірургії).**

## 2. Зв'язки яєчника

| Зв'язка | Прикріплення |
|---|---|
| **Підвішувальна зв'язка яєчника** (*lig. suspensorium ovarii*, **лійково-тазова**) | від **верхнього полюса** до **тазової стінки**; **містить яєчникову артерію і вену** |
| **Власна зв'язка яєчника** (*lig. ovarii proprium*) | від **нижнього полюса** до **матки** (позаду і нижче місця відходження труби) |
| **Брижа яєчника** (*mesovarium*) | складка **широкої зв'язки**; **прикріплює яєчник** (**ворота яєчника**: судини, нерви) |

**Яєчник не вкритий очеревиною**: його поверхня покрита **зародковим епітелієм**, а очеревина закінчується по лінії прикріплення брижі (*лінія Фарре*) — **яйцеклітина виходить у порожнину очеревини** → **труба**. Це пояснює **поширення раку яєчника** по очеревині.

## 3. Будова

На розрізі:
| Шар | Опис |
|---|---|
| **Зародковий (поверхневий) епітелій** | **кубічний** (мезотелій); **джерело епітеліальних пухлин** |
| **Білкова оболонка** (*tunica albuginea*) | щільна сполучна тканина під епітелієм |
| **Кіркова речовина** (*cortex*) | **фолікули, жовті тіла**, строма |
| **Мозкова речовина** (*medulla*) | **судини, нерви**, пухка сполучна тканина |

## 4. Фолікули і оогенез

### Резерв яйцеклітин
| Вік | Число ооцитів |
|---|---|
| **Плід (20 тижнів)** | **6–7 млн** (максимум) |
| **Народження** | **1–2 млн** |
| **Пубертат** | **~300–400 тис.** |
| **Протягом життя** | **~400–500 овулюють** |
| **Менопауза** | **< 1000** |

**Нові ооцити не утворюються** — **резерв вичерпний** (**овариальний резерв**, **АМГ** як маркер).

### Оогенез
| Етап | Час | Опис |
|---|---|---|
| **Оогонії** (2n) | **внутрішньоутробно** | **мітоз** |
| **Первинний ооцит** (2n, 4C) | **плід** → **мейоз I починається, зупиняється в профазі I** | **«сплять» до пубертату** (**до 40–50 років!**) |
| **Вторинний ооцит** (n, 2C) | **перед овуляцією (мейоз I завершується)** | **мейоз II зупиняється на метафазі II** |
| **Яйцеклітина (овум)** (n) | **після запліднення**: завершується мейоз II | + **друге полярне тільце** |

- Один ооцит → **одна яйцеклітина + 3 полярні тільця** (які дегенерують) — **цитоплазма зберігається**.
- **Довготривала зупинка мейозу** → **вікові хромосомні порушення (синдром Дауна — зростає після 35 р.)**.

### Стадії розвитку фолікула

| Стадія | Опис |
|---|---|
| **Примордіальний фолікул** | **первинний ооцит** + **один шар плоских фолікулярних клітин**; **резерв** (мільйони) |
| **Первинний фолікул** | ооцит + **кубічні гранульозні клітини**; **прозора оболонка (zona pellucida)** |
| **Вторинний (преантральний)** | **багатошарові гранульозні клітини**; **тека** формується (**тека-клітини**: андрогени) |
| **Третинний (антральний, Граафів міхурець)** | **порожнина (антрум) з фолікулярною рідиною**; **ооцит на горбку (cumulus oophorus)**; **промениста вінець (corona radiata)**; **тека інтерна і екстерна** |
| **Зрілий (преовуляторний) фолікул** | **~20 мм**; **виступає** на поверхні |
| **Овуляція** | **розрив**, вихід вторинного ооцита |
| **Жовте тіло (corpus luteum)** | **залишок фолікула** → **прогестерон** |
| **Біле тіло (corpus albicans)** | **рубець** після регресу жовтого тіла |
| **Атретичний фолікул (атрезія)** | **99% фолікулів гинуть** (**апоптоз**) |

- Щомісяця **росте ~15–20 фолікулів**; **один (домінантний)** овулює (**ФСГ-залежний відбір**).
- **Двоклітинна теорія**: **тека-клітини** (ЛГ → **андрогени**) → **гранульозні** (ФСГ → **ароматаза → естрогени**).

### Овуляція
- **Пік ЛГ** (~**36 год до овуляції**; **ЛГ-сплеск** після **високого естрадіолу**) → **мейоз I завершується**, **ферменти розкладають стінку** → **вихід ооцита** (з коронарними клітинами) у **очеревинну порожнину → фімбрії труби**.
- **Біль овуляції (Миттельшмерц)**: одностороння, 1–2 дні.
- **Ооцит живе 12–24 год** (дієздатний).

### Жовте тіло
- **Формується** з **гранульозних і текальних клітин** (**лютеїнізація**, під дією ЛГ).
- Виробляє **прогестерон (+ естрадіол, інгібін A)**.
- **Живе ~14 днів**, якщо **немає вагітності** → **регрес** (біле тіло); **при вагітності** — **ХГЛ підтримує** (до 8–10 тижнів: потім плацента).
Деталі: [[Менструальний цикл і жіночі гормони]].

## 5. Гормони яєчника

| Гормон | Клітини | Дія |
|---|---|---|
| **Естрогени (естрадіол, естрон, естріол)** | **гранульозні** (ароматаза), жовте тіло | **вторинні ознаки, ріст ендометрія (проліферація)**, **кістки**, **ліпіди**, **зворотний зв'язок** |
| **Прогестерон** | **жовте тіло** | **секреторна фаза ендометрія**, **підготовка до вагітності**, **↑ температура тіла**, **гальмує ЛГ** |
| **Андрогени (тестостерон, андростендіон)** | **тека-клітини** | **субстрат для естрогенів**, лібідо; **надлишок — СПКЯ** |
| **Інгібін A, B** | гранульозні | ↓ ФСГ |
| **АМГ** | дрібні фолікули | **маркер овариального резерву** |
| **Релаксин** | жовте тіло | вагітність |

## 6. Кровопостачання, лімфа, іннервація

| | Опис |
|---|---|
| **Артерії** | **яєчникова артерія** (з **черевної аорти, L2**) — через **підвішувальну зв'язку**; **яєчникова гілка маткової артерії** (**анастомоз**) |
| **Вени** | **яєчникове сплетення** → **права яєчникова вена → НПВ**; **ліва → ліва ниркова** |
| **Лімфа** | **поперекові (парааортальні) вузли** — **рак яєчника → парааортальні** |
| **Нерви** | **яєчникове сплетення** (**симпатика T10–T11**), **парасимпатика (блукаючий)**; **біль — T10** (навколопупкова) |

## 7. Хвороби яєчника

| Хвороба | Суть |
|---|---|
| **Функціональні кісти** | **фолікулярна, кіста жовтого тіла**; зазвичай **безсимптомні, регресують** |
| **Синдром полікістозних яєчників (СПКЯ)** | **гіперандрогенія**, **оліго-/ановуляція**, **полікістозна морфологія** (критерії Роттердам); **найчастіша ендокринопатія** у жінок; **ожиріння, інсулінорезистентність, гірсутизм, акне, безпліддя**; **ризик діабету, раку ендометрія** |
| **Ендометріома («шоколадна кіста»)** | **ендометріоз** |
| **Дермоїдна кіста (зріла тератома)** | **тканини всіх шарів** (волосся, зуби); **перекрут** |
| **Перекрут яєчника** | **невідкладно**; **гострий біль**, нудота; **кіста > 5 см**; **лапароскопія** |
| **Абсцес** (ЗЗОМТ) | |
| **Рак яєчника** | **епітеліальний (серозна цистаденокарцинома, ~90%)**; **«тихий вбивця»**: **пізні симптоми** (здуття, асцит); **CA-125**; **BRCA1/2**; **дитячі/молоді — герміногенні**; **стромальні (гранульозоклітинні — естрогени; Сертолі-Лейдіг — андрогени)**; **метастаз Крукенберга** (з шлунка) |
| **Передчасна недостатність яєчників (ПНЯ)** | менопауза < 40 років; **Тернер, аутоімунні, хіміо** |
| **Менопауза (клімакс)** | вичерпання фолікулів: **↓ естрадіол, ↑ ФСГ**; **припливи, сухість піхви, остеопороз** |
| **Безпліддя** | ановуляція, ПНЯ |

## 8. Мнемоніки

- **Яєчник — не вкритий очеревиною (зародковий епітелій)**.
- **Підвішувальна зв'язка — судини; власна — до матки**.
- Оогенез: **первинний ооцит зупинений у профазі I (до пубертату), вторинний — у метафазі II (до запліднення)**.
- **Двоклітинна теорія**: **тека + ЛГ → андрогени; гранульоза + ФСГ → ароматаза → естрогени**.
- Стадії фолікула: **примордіальний → первинний → вторинний → антральний → зрілий → овуляція → жовте → біле тіло**.
- **Резерв**: 6–7 млн (плід) → 1–2 млн (народження) → ~400 овуляцій.
