# Молочна залоза (*mamma*, *glandula mammaria*)

Молочна залоза — парна видозмінена потова залоза. Вона виробляє **молоко** для вигодовування немовляти. Залоза розвивається під впливом **естрогенів і прогестерону**, а лактація керується **пролактином** і **окситоцином**.

## 1. Положення

| Показник | Значення |
|---|---|
| Положення | **на передній грудній стінці**, на **великому грудному м'язі** |
| Межі | від **III до VI–VII ребра**; **від краю груднини до передньої пахвової лінії** |
| **Хвіст (Спенса)** | **виступ залози в пахву** (*processus axillaris*) |
| Маса | **~150–200 г** (до вагітності); **400–900 г** при лактації |
| Асиметрія | **норма** (ліва часто більша) |

### Сосок і ареола
| Структура | Опис |
|---|---|
| **Сосок (*papilla mammaria*)** | на рівні **IV міжребер'я**; **гладка мускулатура**, **15–25 молочних проток**; **чутливий**; **ерекція** |
| **Ареола** | **пігментована**; **сальні залози Монтгомері** (смазка); **темнішає при вагітності** |

## 2. Будова

### Залозиста тканина
- **15–20 часток** (*lobi*) — **радіально**; кожна має **вивідну протоку**.
- **Частка → часточки → альвеоли (ацинуси)** — **секреторні відділи**; оточені **міоепітеліальними клітинами**.
- **Молочна протока** → **молочний синус (*sinus lactiferus*)** (розширення під ареолою) → **отвір на соску**.

### Строма
| Компонент | Функція |
|---|---|
| **Жирова тканина** | основний об'єм (розмір залежить від жиру) |
| **Сполучна тканина** | **зв'язки Купера** (*ligamenta suspensoria*) — **підтримка** від **шкіри до фасції**; **втягнення шкіри при раку** («лимонна шкірка», **симптом «умбілікації»**) |
| **Фасція** | **позаду залози — ретромамарний простір**, **велика грудна фасція** (рухомість) |

### Гістологія
| Стан | Вигляд |
|---|---|
| **Спокій (до вагітності)** | **протоки** + **мало альвеол**, **багато жиру** |
| **Вагітність** | **проліферація проток і альвеол** (естрогени → протоки; прогестерон → альвеоли) |
| **Лактація** | **альвеоли заповнені секретом**, **мало строми** |
| **Інволюція (менопауза)** | **атрофія залозистої тканини**, **заміщення жиром** |

## 3. Кровопостачання, лімфа, нерви

### Артерії
| Артерія | Походження | Частка |
|---|---|---|
| **Внутрішня грудна (медіальні гілки)** | підключична | **~60% (медіальна частина)** |
| **Бічна грудна** | пахвова | **~30% (латеральна)** |
| **Міжреброві гілки** (II–IV) | аорта | |
| Грудоакромійна | пахвова | |

Деталі: [[Артерії верхньої кінцівки]].

### Вени
**Поверхневі**, **внутрішня грудна**, **бічна грудна**, **міжреброві**; **зв'язок з хребтовими венами (Батсона)** → **метастази в кістки (хребет)**.

### Лімфатичний відтік (**дуже важливий — рак**)
| Група вузлів | Частка лімфи |
|---|---|
| **Пахвові (аксілярні)** | **~75%**; 20–40 вузлів; **рівні I–III** (відносно **малого грудного м'яза**: I — латерально, II — позаду, III — медіально) |
| **Парастернальні (внутрішні грудні)** | **~20–25%** (**медіальні квадранти**) |
| **Надключичні, міжгрудні (Роттера)** | |
| **Протилежна молочна залоза, черевна** | **через поверхневі зв'язки** |

- **Сторожовий лімфатичний вузол** — **перший** на шляху; **біопсія** → **стадіювання**, **уникнення повної лімфодисекції**.
- **Метастази**: **кістки, легені, печінка, мозок**.

Деталі: [[Мікроциркуляція і лімфатична система]].

### Нерви
**Міжреброві нерви (T2–T6)** (**латеральні і передні шкірні гілки**), **надключичні (C3–C4)**; **симпатика** (судини, гладкі м'язи соска).

## 4. Розвиток

- З **ектодерми** (**молочні лінії** — від пахви до пахвини) на **5–6 тижні**; **молочні горбики**.
- **Вади**: **політелія** (додаткові соски), **полімастія**, **ателія**, **амастія**, **інвертований сосок**.
- **Новонароджені**: **набряк залоз («відьмине молоко»)** — **материнські гормони**.
- **Пубертат**: **телархе** (естрогени) — **Таннер I–V**.
- **Вагітність**: **розвиток**; **менопауза**: **інволюція**.

## 5. Гормональна регуляція

| Гормон | Місце | Дія |
|---|---|---|
| **Естрогени** | яєчник, плацента | **ріст проток**, **строма**, **жир** |
| **Прогестерон** | жовте тіло, плацента | **ріст альвеол і часточок** |
| **Пролактин** | передній гіпофіз | **синтез молока (лактогенез)**; **↑ при вагітності**, **сосанні** |
| **Окситоцин** | **гіпоталамус → нейрогіпофіз** | **вихід молока (рефлекс «молоковиділення»)** — **скорочення міоепітеліальних клітин** |
| **Плацентарний лактоген (ПЛ), ХГЛ** | плацента | розвиток |
| **Інсулін, кортизол, тироксин** | | підтримка |

### Лактація (етапи)
| Етап | Опис |
|---|---|
| **Маммогенез** | розвиток залози: пубертат, вагітність |
| **Лактогенез I** (**вагітність**, 2-й триместр) | **початок синтезу**; **молозиво** |
| **Лактогенез II** (**через 2–3 дні після пологів**) | **активна секреція**: **падіння прогестерону після відходження плаценти** → **пролактин діє** → **«прихід молока»** |
| **Галактопоез (підтримка)** | **сосання → пролактин ↑** (**рефлекс пролактину**); **спорожнення** (**ауторегуляція**) |
| **Виведення молока** | **сосання → гіпоталамус → окситоцин ↑ → скорочення міоепітелію** (**рефлекс викиду**); **також психогенно (плач дитини)** |
| **Припинення (інволюція)** | **застій молока**, ↓ пролактин |

- **Пролактин гальмує овуляцію** (**ГнРГ ↓**) → **лактаційна аменорея** (**часткова контрацепція, якщо виключне ГВ < 6 міс.**).
- **Дофамін** (гіпоталамус) **гальмує пролактин**: **бромокриптин/каберголін** (гіперпролактинемія).

## 6. Молоко

| Тип | Час | Особливості |
|---|---|---|
| **Молозиво (colostrum)** | **перші 3–5 днів** | **густе, жовте**; **багато IgA, білка, лактоферину, лейкоцитів, вітамінів**; **мало жиру і лактози**; **імунітет новонародженого**; **«перше щеплення»** |
| **Перехідне** | 5–14 днів | |
| **Зріле молоко** | з 2 тижня | **біла рідина** |

### Склад зрілого молока (на 100 мл)
| Компонент | Вміст | Особливості |
|---|---|---|
| **Вода** | ~87% | |
| **Лактоза** (молочний цукор) | ~7 г | **основний вуглевод**; ↑ всмоктування Ca |
| **Жир** | ~3,5–4 г | **ліпаза**, **ПНЖК (DHA)**; **змінюється за кормлення (заднє молоко жирніше)** |
| **Білок** | ~1 г | **казеїн + сироваткові (α-лактальбумін, лактоферин, лізоцим, sIgA)** |
| **Олігосахариди** | | **пребіотики** |
| **Вітаміни, мінерали** | | **вітамін D мало** (добавка), **залізо — біодоступне** |
| **Клітини (макрофаги, лімфоцити), антитіла (sIgA)** | | **імунний захист** |

**Переваги вигодовування**: **ідеальне живлення**, **імунний захист** (↓ ІДП, діарея, середній отит, НЕК), **↓ ризик ожиріння, діабету, СМС**; **для матері** — **↓ крововтрата (окситоцин → скорочення матки)**, **↓ ризик раку молочної залози та яєчників**, емоційний зв'язок з дитиною. **ВООЗ**: **виключно грудне до 6 місяців**, потім з прикормом до 2 років.

## 7. Хвороби молочної залози

| Хвороба | Суть |
|---|---|
| **Мастит** | **запалення** (лактаційний: **Staphylococcus aureus**, **тріщини соска**); **біль, червоніння, жар, лихоманка**; **продовжувати годування**, антибіотики; **абсцес** (дренаж) |
| **Лактостаз** | застій |
| **Фіброзно-кістозні зміни (мастопатія)** | **циклічний біль, ущільнення**; доброякісні |
| **Фіброаденома** | **найчастіша доброякісна пухлина у молодих (15–35 років)**; **гладка, рухома, «мармурка»** |
| **Філлодна пухлина** | |
| **Внутрішньопротокова папілома** | **виділення з соска (кров'яні)** |
| **Гінекомастія (чоловіки)** | **естрогени/тестостерон**; ліки, пубертат, Клайнфельтер |
| **Галакторея** | **виділення молока поза лактацією**: **гіперпролактинемія** (**пролактинома**, ліки, гіпотиреоз) |
| **Рак молочної залози** | **найчастіший рак у жінок**; **інвазивна протокова карцинома (~75%)**; **ризик**: вік, **BRCA1/2**, сімейний анамнез, пізні/відсутні пологи, раннє менархе, ожиріння, ГЗТ, алкоголь; **ознаки**: **безболісне ущільнення**, **втягнення шкіри/соска**, **«лимонна шкірка»**, **виділення**, **збільшені пахвові вузли**, **хвороба Педжета соска** (екзема); **скринінг**: **мамографія (з 40–50 років)**, **самообстеження**, **УЗД**; **діагноз**: **біопсія (трійний тест)**; **рецептори ER/PR/HER2** → **лікування** (операція, хіміо-, гормональна — **тамоксифен, інгібітори ароматази**, **таргетна — трастузумаб**, променева) |

### Класифікація пухлин (TNM)
**T**, **N** (пахвові вузли), **M**.

### Самообстеження
**Щомісяця** (**після менструації**): **огляд і пальпація** обох залоз і пахв.

## 8. Мнемоніки

- Залоза: **15–20 часток → часточки → альвеоли → протоки → синуси → сосок**; **IV міжребер'я — сосок**.
- **Лімфа: пахвові (75%), парастернальні (25%)**; **сторожовий вузол**.
- **Пролактин — синтез; окситоцин — викид**.
- **Естрогени — протоки; прогестерон — альвеоли**.
- **Молозиво** — IgA, імунітет.
- Рак: **вузол, втягнення, «лимонна шкірка»**; **BRCA1/2**.
