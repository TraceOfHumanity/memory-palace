# Піхва і зовнішні жіночі статеві органи (*vagina*, *vulva*)

Піхва — м'язово-перетинчаста трубка між шийкою матки та вульвою. Вона є органом копуляції й **родовим каналом**. Зовнішні статеві органи (**вульва**) лежать на промежині: статеві губи, клітор, присінок піхви та залози.

## 1. Піхва (*vagina*, *colpos*)

| Показник | Значення |
|---|---|
| Довжина | **7–10 см** (передня стінка коротша, **~7 см**; задня **~9–10 см**) |
| Положення | **між сечівником і сечовим міхуром (спереду) та прямою кишкою (ззаду)**; **вісь вперед-вгору (під кутом ~90° до матки)** |
| Стінка | **тонка, розтяжна** |
| Верх | **охоплює шийку матки** — утворює **склепіння** |
| Низ | **вхід (присінок піхви)**, **дівоча пліва** |

### Склепіння піхви (*fornix vaginae*)
**Передній, задній і два бічні**; **заднє склепіння** — **найглибше** (**2–3 см**) і межує з **прямокишково-матковою заглибиною (Дугласів простір)** → **кульдоцентез** (пункція), **доступ до тазу**, **гній/кров**; **перетинчасте** — тонка стінка.

### Стінки
| Оболонка | Склад |
|---|---|
| **Слизова** | **багатошаровий плоский неороговілий епітелій**; **поперечні складки** (*rugae*); **залоз немає** (зволоження — **транссудат** через стінку + цервікальний слиз); **глікоген** у клітинах → **молочна кислота** (*Lactobacillus*) |
| **М'язова** | **тонка**, **гладка** (**зовнішній поздовжній, внутрішній циркулярний**), **сфінктер у нижній частині** (**цибулинно-губчастий м'яз**) |
| **Адвентиція** | **венозне сплетення**, нерви |

### Мікробіом піхви
- **Домінують лактобацили** (*Lactobacillus crispatus*) → **молочна кислота** → **pH 3,8–4,5** (кисле середовище — захист від інфекцій).
- **Естрогени** → **глікоген** → підтримка лактобацил. **Менопауза/дитинство** — pH ↑ (6–7), **атрофія**.
- **Порушення** (антибіотики, душування) → **бактеріальний вагіноз** (pH > 4,5; «рибний» запах; **ключові клітини**), **кандидоз** («творожисті» виділення, свербіж).

### Дівоча пліва (*hymen*)
**Тонка складка слизової** при вході; **форми різні** (кільцеподібна, півмісячна…); **не показник «цнотливості»**; розривається не тільки при статевому акті (спорт, тампони); **вроджена атрезія** → **гематокольпос** у підлітків (аменорея + біль).

### Кровопостачання, лімфа, нерви
| | Опис |
|---|---|
| **Артерії** | **піхвова артерія** (внутрішня клубова), **гілки маткової (шийково-піхвові)**, **середня прямокишкова**, **внутрішня статева** (нижня третина) |
| **Вени** | **піхвове венозне сплетення** → внутрішня клубова |
| **Лімфа** | **верхні 2/3** → **клубові (внутрішні/зовнішні)**; **нижня 1/3** → **пахвинні (поверхневі)** |
| **Нерви** | **верхні 2/3 — вегетативні** (матково-піхвове сплетення; **нечутлива до болю**); **нижня 1/3 — соматичний статевий нерв (S2–S4)** (**чутлива**) |

Деталі: [[Артерії нижньої кінцівки і таза]], [[Вегетативна нервова система]].

### Топографія
- **Спереду**: **сечівник** (його нижня частина вшита в піхву), **сечовий міхур** (міхурово-піхвова перегородка): **міхурово-піхвова нориця**.
- **Ззаду**: **пряма кишка** (прямокишково-піхвова перегородка): **ректовагінальна нориця**; **анальний канал** (**центральне сухожилля промежини**).
- **Збоку**: **підіймач заднього проходу**, **кардинальні зв'язки**, **сечоводи** (в 2 см від склепіння).
- **Цистоцеле, ректоцеле, ентероцеле** — випинання (**пролапс**) через піхву: [[Хвороби статевої системи]].

## 2. Зовнішні статеві органи — **вульва** (*vulva*, *pudendum femininum*)

| Структура | Опис |
|---|---|
| **Лобок** (*mons pubis*) | **жирова подушка** над симфізом; **волосся** |
| **Великі статеві губи** (*labia majora*) | **дві шкірні складки**, **жир**, **волосся**, **сальні й потові залози**; **кругла зв'язка матки закінчується тут**; **гомолог мошонки** |
| **Малі статеві губи** (*labia minora*) | **тонкі складки без волосся і жиру**, **багато сальних залоз**, **судин, нервів**; **розширюються при збудженні**; **гомолог шкіри статевого члена** |
| **Клітор** (*clitoris*) | **печеристі тіла**, **головка**, **крайня плоть**; **8000+ нервових закінчень** (**чутливий орган**); **гомолог статевого члена** |
| **Присінок піхви** (*vestibulum vaginae*) | **простір між малими губами**; **отвір сечівника, піхви, протоки залоз** |
| **Цибулини присінка** | **печеристі тканини** (гомолог губчастого тіла) по боках присінка; **ерекційна тканина** |

Складки: **вуздечка клітора**, **вуздечка статевих губ**, **пліва**.

### Клітор
| Частина | Опис |
|---|---|
| **Головка** (*glans clitoridis*) | видима частина (**~1 см**) |
| **Тіло** | |
| **Ніжки (*crura*)** | **прикріплюються до сідничо-лобкових гілок** (**до 9–10 см** всередині) |
| **Печеристі тіла** | **ерекція при збудженні** (парасимпатика S2–S4, NO) |
| **Іннервація** | **дорсальний нерв клітора** (від **статевого, S2–S4**) |

Клітор — орган з дуже високою чутливістю (**понад 8000 нервових закінчень**); його основна функція — сексуальна чутливість.

### Залози присінка
| Залоза | Положення | Секрет |
|---|---|---|
| **Великі присінкові залози Бартоліна** | **4 і 8 годин від входу піхви**, **в глибині великих губ** | **слиз (змащення)**; **кіста/абсцес Бартоліна** |
| **Малі присінкові залози** | навколо присінка | |
| **Парауретральні залози Скіна** | **навколо сечівника** | **гомолог простати** |

### Кровопостачання, іннервація, лімфа (вульви)
- **Артерії**: **внутрішня статева артерія** (**промежинні, задні губні, дорсальна і глибока клітора**); **зовнішні статеві** (з стегнової).
- **Вени**: **внутрішні статеві → внутрішні клубові**; **зовнішні** → **великі підшкірні**.
- **Лімфа**: **поверхневі пахвинні** (потім глибокі пахвинні, клубові): **рак вульви → пахвинні**.
- **Нерви**: **статевий нерв (S2–S4)** (промежинні, **дорсальний нерв клітора**), **клубово-пахвинний, пахвинно-статевий, задні шкірні нерви стегна**.
**Блокада статевого нерва** — знеболення пологів (біля сідничної ості).

## 3. Промежина (*perineum*)

| Ділянка | Опис |
|---|---|
| **Сечостатевий трикутник** | спереду; **сечівник, піхва** |
| **Анальний трикутник** | ззаду; **анус** |
| **Центральне сухожилля промежини** (*centrum tendineum perinei*) | **між піхвою і анусом**; **вузол прикріплення м'язів**; **розриви при пологах**; **епізіотомія** |

Деталі м'язів: [[М'язи промежини і тазового дна]].

### Розриви промежини (пологи)
| Ступінь | Ушкодження |
|---|---|
| **I** | шкіра, слизова |
| **II** | + м'язи промежини |
| **III** | + **анальний сфінктер** |
| **IV** | + **слизова прямої кишки** |

**Профілактика**: захист промежини, **епізіотомія (за показаннями)**.

## 4. Тазове дно і утримання органів

**Тазове дно** (**підіймач заднього проходу**, **куприковий м'яз**, **фасції**) підтримує **матку, піхву, міхур, пряму кишку**. **Ослаблення** (**пологи, вік, ожиріння, хронічний кашель**) → **пролапс**: **цистоцеле, ректоцеле, ентероцеле, випадіння матки**, **стресове нетримання сечі**; **вправи Кегеля**.

## 5. Менопауза і зміни

**Дефіцит естрогенів** → **атрофія вульви і піхви**: **сухість, діспареунія, ↑ pH, інфекції (генітоуринарний синдром)**; **лікування**: **місцеві естрогени, зволожувачі**.

## 6. Розвиток

- **Піхва**: **верхня частина** — з **Мюллерових проток**; **нижня** — з **урогенітального синусу (синусові бульби)**.
- **Зовнішні органи**: **без андрогенів** → **жіночі**.
- **Вади**: **атрезія піхви/пліви** (гематокольпос), **септа піхви**, **агенезія (MRKH)**, **злиття губ**, **вроджена гіперплазія надниркових залоз (віризація)**.

## 7. Хвороби піхви і вульви

| Хвороба | Суть |
|---|---|
| **Бактеріальний вагіноз** | **↓ лактобацили**, **Gardnerella**; **pH > 4,5, «рибний» запах, ключові клітини**; **метронідазол** |
| **Вагінальний кандидоз** | *Candida albicans*; **свербіж, «творожисті» виділення**, почервоніння; **антимікотики** |
| **Трихомоніаз** | *Trichomonas*; **пінисті зеленувато-жовті виділення**; **ІПСШ**; метронідазол (з партнером) |
| **Вульвовагініт** | |
| **ІПСШ** | хламідії, гонорея, **герпес (виразки)**, **ВПЛ (кондиломи)**, **сифіліс (твердий шанкр)** |
| **Кіста/абсцес Бартоліна** | **закупорка протоки**; **болісний набряк** у нижній частині вульви |
| **Дисплазія/рак піхви, вульви (VIN)** | **ВПЛ**; **свербіж, виразка**, **лихенний склероз** |
| **Атрофічний вагініт** | менопауза |
| **Пролапс (цистоцеле, ректоцеле)** | тазове дно |
| **Нориці** | **міхурово-піхвова, ректовагінальна** (пологи, операції, радіація) |
| **Вагінізм** | мимовільний спазм м'язів піхви |
| **Діспареунія** | біль під час акту |
| **Калічення жіночих статевих органів** | шкідлива практика; ускладнення — інфекції, проблеми в пологах |

## 8. Мнемоніки

- **Піхва**: **7–10 см, pH 3,8–4,5 (лактобацили)**, **немає залоз**; **верхні 2/3 — вегетативна (безболісно), нижня 1/3 — соматична (болісно)**.
- **Склепіння**: **заднє — найглибше (Дугласів простір)**.
- **Вульва**: **лобок, великі губи, малі губи, клітор, присінок**; **залози Бартоліна (4 і 8 годин)**.
- **Лімфа**: **верхні 2/3 піхви → клубові; нижня 1/3 і вульва → пахвинні**.
- **Розриви промежини**: I шкіра, II м'язи, III сфінктер, IV слизова прямої кишки.
