# Підшлункова залоза (*pancreas*)

Підшлункова залоза — змішана залоза. **Екзокринна частина** (98%) виробляє **панкреатичний сік** з ферментами й бікарбонатом. **Ендокринна частина** (2%, острівці Лангерганса) виробляє **інсулін, глюкагон, соматостатин** — гормони обміну глюкози.

Пов'язані файли: [[Травна система — огляд]], [[Шлунок — будова]], [[Тонка кишка — будова]], [[Тонка кишка — травлення і всмоктування]], [[Печінка — будова]], [[Жовчний міхур і жовчні шляхи]], [[Печінка — функції]], [[Регуляція травлення]], [[Очеревина]], [[Аорта і її гілки]], [[Вени — нижня порожниста і ворітна системи]], [[Вегетативна нервова система]], [[Хвороби травної системи]], [[Нирка — будова і положення]], [[Інсулін, глюкагон і цукровий діабет]], [[Ендокринна система — огляд]].

## 1. Положення і розміри

| Показник | Значення |
|---|---|
| Положення | **заочеревинно**, **на задній стінці живота**, **поперек L1–L2**, за шлунком (**сальникова сумка**) |
| Довжина | **15–20 см** |
| Маса | **70–100 г** |
| Колір | сіро-рожевий, **часточкова** |
| Рівень | **L1–L2** |

### Частини
| Частина | Положення | Відношення |
|---|---|---|
| **Голівка** (*caput*) | **в С-подібній петлі дванадцятипалої кишки** (справа від L2) | **загальна жовчна протока** проходить ззаду/у товщі голівки; **ворітна вена** позаду шийки; **гачкоподібний відросток** (*processus uncinatus*) — під верхньою брижовою веною й артерією |
| **Шийка** (*collum*) | перед **ворітною веною** і початком **ВБВ** | |
| **Тіло** (*corpus*) | перед аортою, ВБА, лівою ниркою і надниркою | **задня стінка шлунка** спереду |
| **Хвіст** (*cauda*) | досягає **воріт селезінки** (**селезінково-ниркова зв'язка**) | **селезінкова артерія й вена** йдуть по верхньому/задньому краю |

### Відношення (чому рак підшлункової проявляється рано/пізно)
- **Голівка**: стискає **холедох** → **безболісна механічна жовтяниця** (**синдром Курвуазьє**).
- **Тіло і хвіст**: пізні симптоми; стискання **ворітної, селезінкової** вен → **тромбоз, варикоз шлунка**, біль у спині (**чревне сплетення**).
- **Задня стінка шлунка** → виразка пенетрує в підшлункову.

## 2. Протоки

| Протока | Опис |
|---|---|
| **Головна (Вірсунгова)** (*ductus pancreaticus*) | **з хвоста до голівки**, в центрі залози; **вздовж усього органа**; об'єднується з **холедохом** в **ампулі Фатера** → **великий дуоденальний сосочок** (під контролем **сфінктера Одді**) |
| **Додаткова (Санторіні)** (*ductus pancreaticus accessorius*) | відкривається на **малому дуоденальному сосочку** (вище) |

- **Pancreas divisum** (~10% людей): головна й додаткова не з'єднуються → дренаж через малий сосочок; ризик **панкреатиту**.
- Деталі: [[Жовчний міхур і жовчні шляхи]].

## 3. Мікроскопічна будова

### Екзокринна частина (~98% маси)
- **Ацинуси** (кінцеві відділи; **серозного** типу): **ацинарні клітини** з **зимогенними гранулами**; ферменти.
- **Вставні протоки** з **центроацинозними клітинами** → міжчасточкові → головна: **бікарбонат** (клітини проток).
- **Клітини**: **ацинарні** (ферменти), **протокові** (бікарбонат, вода).

### Ендокринна частина — **острівці Лангерганса** (~1–2 млн; **2% маси**)
Тіло містить ~1–2 млн острівців (розмір 100–200 мкм), **густо васкуляризовані**.

| Клітина | Частка | Гормон | Дія |
|---|---|---|---|
| **α (альфа)** | ~20% | **глюкагон** | **↑ глюкоза** (глікогеноліз, глюконеогенез) |
| **β (бета)** | ~70% | **інсулін**, **С-пептид**, **амілін** | **↓ глюкоза** |
| **δ (дельта)** | ~5% | **соматостатин** | ↓ інсулін, глюкагон, секрецію |
| **PP (F)** | ~1–5% | **панкреатичний поліпептид** | ↓ секреція підшлункової, ↑ насичення |
| **ε (епсилон)** | <1% | **грелін** | |

Деталі гормонів — в ендокринній системі (окремий розділ; буде пізніше).

## 4. Панкреатичний сік

| Показник | Значення |
|---|---|
| Об'єм | **1,5–2 л/добу** |
| **pH** | **8,0–8,3** (бікарбонат) |
| Склад | **бікарбонат (HCO₃⁻, ~120 ммоль/л)**, вода, ферменти, іони |

### Ферменти (ацинарні клітини)
| Група | Фермент | Субстрат | Продукт |
|---|---|---|---|
| **Протеази** (**неактивні, зимогени**) | **трипсиноген** → **трипсин** | білки | пептиди (C-кінцеві Arg, Lys) |
| | **хімотрипсиноген** → **хімотрипсин** | білки | пептиди (ароматичні) |
| | **проеластаза** → **еластаза** | еластин, білки | |
| | **прокарбоксипептидази** A, B → | C-кінці | амінокислоти |
| **Ліполітичні** | **ліпаза** (+ **коліпаза**) | **тригліцериди** | **ЖК + 2-моногліцерид** |
| | **фосфоліпаза A₂** | фосфоліпіди | лізолецитин |
| | **холестеролестераза** | ефіри холестерину | |
| **Амілолітичні** | **α-амілаза** | **крохмаль, глікоген** | **мальтоза, декстрини** |
| **Нуклеази** | **РНКаза, ДНКаза** | нуклеїнові кислоти | нуклеотиди |

### Активація (захист від самоперетравлення)
1. Ферменти синтезуються як **неактивні зимогени** й зберігаються в **зимогенних гранулах** з **інгібітором трипсину (SPINK1)**.
2. У дванадцятипалій **ентерокіназа** (щіткова облямівка) → **трипсиноген → трипсин**.
3. **Трипсин** активує **всі інші** зимогени (**каскад**) і сам себе (**автокаталіз**).

**Передчасна активація в залозі** → **автоперетравлення** → **панкреатит**.

### Бікарбонат
Секретується **протоковими клітинами** (**карбоангідраза**; CFTR Cl⁻/HCO₃⁻-обмінник); **нейтралізує кислоту** (pH 1–2 → 6–7). Важливо для оптимуму ферментів.

## 5. Регуляція секреції

| Фаза | Тригер | Механізм | Частка |
|---|---|---|---|
| **Цефалічна** | вигляд, запах, смак | **блукаючий нерв (ACh)** → ферменти | ~20% |
| **Шлункова** | розтяг шлунка | вагус, гастрин | ~10% |
| **Кишкова** | **хімус у дванадцятипалій** | **гормони** | **~70%** |

### Гормональна регуляція (кишкова фаза)
| Гормон | Клітини | Тригер | Дія на підшлункову |
|---|---|---|---|
| **Секретин** | **S-клітини** (дванадцятипала) | **кислота (pH < 4,5)** у дванадцятипалій | **↑ бікарбонат + вода** (протокові клітини) |
| **Холецистокінін (ХЦК)** | **I-клітини** (дванадцятипала, порожня) | **жири, білки (пептиди, АК)** | **↑ ферменти** (ацинарні) + скорочення міхура |
| **ACh** (блукаючий) | — | | ↑ ферменти |

- **Секретин** → **вода + HCO₃⁻**; **ХЦК** → **ферменти**; потенціюють одне одного.
- Деталі: [[Регуляція травлення]].

## 6. Ендокринна функція (регуляція глюкози)

| Умови | Гормон | Ефект |
|---|---|---|
| **↑ глюкоза (після їжі)** | **інсулін** (β) | ↑ поглинання глюкози м'язами, жиром; **глікогеногенез**; ↓ глюконеогенез; ↑ ліпогенез |
| **↓ глюкоза (натще)** | **глюкагон** (α) | глікогеноліз, глюконеогенез, кетогенез |
| **Обидва** | **соматостатин** (δ) | паракринне гальмування |

**Інсулін**: прогормон → **інсулін + C-пептид**; секреція — **глюкоза** (GLUT2 → АТФ → блок K⁺-каналів → деполяризація → Ca²⁺ → екзоцитоз), **амінокислоти, ГІП, ГПП-1, парасимпатика**; ↓ **соматостатин, адреналін**.

**Цукровий діабет**:
- **1-й тип**: аутоімунне руйнування β-клітин.
- **2-й тип**: інсулінорезистентність + ↓ секреція.
- Ліки: інсулін; метформін; **агоністи ГПП-1**; **інгібітори SGLT2**.

## 7. Кровопостачання

| Частина | Артерії |
|---|---|
| **Голівка** | **верхні** (шлунково-дванадцятипала ← черевний) і **нижні** (ВБА) **підшлунково-дванадцятипалі** — **передні та задні дуги** |
| **Тіло і хвіст** | **селезінкова артерія** (підшлункові гілки; **велика підшлункова артерія**, дорсальна підшлункова артерія) |

→ **анастомоз черевного стовбура і ВБА** (**«кровообіг між передньою і середньою кишкою»**). Деталі: [[Аорта і її гілки]].

**Вени** → **верхня брижова** і **селезінкова** → **ворітна** (**злиття позаду шийки**): [[Вени — нижня порожниста і ворітна системи]].

**Лімфа**: **панкреатичні, селезінкові, черевні** вузли.

## 8. Іннервація

- **Парасимпатична**: **блукаючий нерв** → ↑ ферменти, інсулін.
- **Симпатична**: **черевне сплетення (T6–T10)** → ↓ секреція, судини; **біль** (від капсули/нервів): **опоясувальний біль у верхній частині живота, віддає в спину** (**панкреатит, рак**).

## 9. Розвиток

- **Передня кишка**: **два зачатки**: **дорсальний** (тіло, хвіст, частина голівки) і **вентральний** (частина голівки, гачок); вентральний **повертається** і зливається з дорсальним (6-й тиждень).
- **Кільцеподібна підшлункова залоза** (*pancreas anulare*): вентральний зачаток охоплює дванадцятипалу → **обструкція дванадцятипалої** (новонароджені; синдром Дауна): **«подвійна бульбашка»**.
- **Pancreas divisum**.

## 10. Хвороби підшлункової залози

### Гострий панкреатит
- **Суть**: **автоперетравлення** (передчасна активація трипсину).
- **Причини**: **камені жовчного міхура (до 40%)**, **алкоголь (30%)** (**«GET SMASHED»**: Gallstones, Ethanol, Trauma, Steroids, Mumps, Autoimmune, Scorpion, Hyperlipidemia/Hypercalcemia, ERCP, Drugs), гіпертригліцеридемія, ЕРХПГ, ліки.
- **Клініка**: **інтенсивний біль у верхній частині живота, віддає в спину («опоясувальний»)**, **нудота, блювання**; **зменшується в положенні сидячи, нахилившись вперед**.
- **Діагноз** (2 з 3): **біль**, **амілаза/ліпаза ↑ > 3× норми**, **КТ**.
- **Ускладнення**: **некроз, абсцес, псевдокіста**, **ГРДС**, **гіпокальціємія**, **шок**, **синдром Каллена і Грея Тернера** (синці навколо пупка/боків — геморагічний).
- **Лікування**: **рідина, знеболення, голод/ентеральне харчування**; ЕРХПГ при камені.

### Хронічний панкреатит
- **Алкоголь (70–80%)**: **фіброз, кальцифікація, біль**; **екзокринна недостатність** (**стеаторея, схуднення**), **ендокринна недостатність** (**діабет**). Лікування: **ферменти (панкреатин)**, інсулін, знеболення.
- Діагностика: КТ — **кальцифікати**; **фекальна еластаза** ↓.

### Рак підшлункової (протокова аденокарцинома)
- **Голівка (70%)**: **безболісна жовтяниця**, **синдром Курвуазьє**, **свербіж**, світлий кал, **темна сеча**.
- **Тіло/хвіст**: **біль у спині**, схуднення; **тромбофлебіт мігруючий (Труссо)**; **новий діабет**.
- **Фактори**: куріння, хронічний панкреатит, діабет, спадковість (**BRCA2, KRAS**).
- **Маркер**: **CA 19-9**; діагностика: **КТ, ендоУЗД**; лікування: **операція Віппла** (панкреатодуоденектомія) — рідко (< 20% операбельні); **поганий прогноз** (5 р. — ~10%).

### Нейроендокринні пухлини
- **Інсулінома** (гіпоглікемія; **тріада Уіппла**).
- **Гастринома** (Золлінгер — Еллісон).
- **Глюкагонома**, **ВІПома**, **соматостатинома**. **МЕН-1**.

### Інші
- **Муковісцидоз**: в'язкий секрет → **обструкція проток** → **панкреатична недостатність**: [[Бронхіальне дерево]].
- **Псевдокіста**.
- **Цукровий діабет**.

## 11. Діагностика

| Метод | Що показує |
|---|---|
| **Амілаза, ліпаза** (кров) | гострий панкреатит (ліпаза специфічніша) |
| **Фекальна еластаза** | екзокринна недостатність |
| **УЗД, КТ, МРТ/МРХПГ, ендоУЗД** | структура, пухлини, камені |
| **ЕРХПГ** | протоки (діагностика/лікування) |
| **Глюкоза, HbA1c, С-пептид** | ендокринна функція |

## 12. Мнемоніки

- Положення: **L1–L2, заочеревинно**, **голівка — в петлі дванадцятипалої**; **хвіст — до селезінки**.
- Ферменти: **трипсин (активує ентерокіназа)**; **ліпаза + коліпаза**; **α-амілаза**.
- **Секретин → бікарбонат (вода)**; **ХЦК → ферменти**.
- Острівці: **α — глюкагон, β — інсулін, δ — соматостатин**.
- Панкреатит: **GET SMASHED**; біль **опоясувальний, у спину**.
- Рак голівки: **безболісна жовтяниця (Курвуазьє)**.
