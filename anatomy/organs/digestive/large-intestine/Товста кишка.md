# Товста кишка (*intestinum crassum*)

Товста кишка завершає травлення. Вона **всмоктує воду й електроліти**, формує **кал**, містить величезну кількість **бактерій** (мікробіом) і виводить залишки. Її довжина **~1,5 м**. Вона розташована навколо петель тонкої кишки у вигляді «рамки».

Пов'язані файли: [[Травна система — огляд]], [[Тонка кишка — будова]], [[Тонка кишка — травлення і всмоктування]], [[Пряма кишка і анальний канал]], [[Очеревина]], [[Аорта і її гілки]], [[Вени — нижня порожниста і ворітна системи]], [[Мікроциркуляція і лімфатична система]], [[Вегетативна нервова система]], [[Регуляція травлення]], [[М'язи живота]], [[Хвороби травної системи]].

## 1. Частини

| Частина | Положення | Особливості |
|---|---|---|
| **Сліпа кишка** (*caecum*) | **права клубова ямка**, нижче впадіння клубової | **мішок 6–8 см**; **червоподібний відросток** |
| **Висхідна ободова** (*colon ascendens*) | право, вгору до печінки | **заочеревинна** (задня стінка); **правий (печінковий) згин** |
| **Поперечна ободова** (*colon transversum*) | через живіт, **внутрішньоочеревинна** (**брижа**) | найрухоміша; провисає; **лівий (селезінковий) згин** |
| **Низхідна ободова** (*colon descendens*) | ліворуч, вниз | **заочеревинна** |
| **Сигмоподібна ободова** (*colon sigmoideum*) | **S-подібна**, ліва клубова ямка → таз | **внутрішньоочеревинна**, брижа; **заворот** |
| **Пряма кишка** (*rectum*) | таз | [[Пряма кишка і анальний канал]] |
| **Анальний канал** | промежина | |

Довжина: сліпа 6–8 см; висхідна 12–20; поперечна 40–50; низхідна 20–25; сигмоподібна 40–50; пряма 15; анальний 3–4. Діаметр: сліпа ~7 см → сигмоподібна ~3 см.

## 2. Ознаки товстої кишки (відмінності від тонкої)

| Ознака | Опис |
|---|---|
| **Три поздовжні м'язові стрічки** (*taeniae coli*) | **вільна, брижова, сальникова**; збираються біля основи апендикса (**орієнтир при апендектомії**) |
| **Гаустри (вздуття)** (*haustra coli*) | мішкоподібні випини між складками; **ритм ферментації** |
| **Сальникові відростки** (*appendices epiploicae*) | жирові виступи по ходу |
| **Більший діаметр** | |
| **Сіро-блідо-зелений колір** | |

Стрічки — **не** суцільний шар: поздовжні м'язи зібрані в 3 стрічки → **гаустри**. Деталі: [[Очеревина]].

## 3. Сліпа кишка і ілеоцекальний кут

### Сліпа кишка
- Розташована у **правій клубовій ямці**, **нижче** клубово-сліпокишкового клапана.
- Повністю вкрита очеревиною (**рухлива**; іноді мезо — **мобільна сліпа**).
- **Ілеоцекальний клапан** (Баугінієва заслінка, *valva ileocaecalis*): губи клапана; **запобігає зворотному току** з товстої в тонку; **регулює** порції (гастроілеальний рефлекс).

### Червоподібний відросток (апендикс, *appendix vermiformis*)
| Показник | Значення |
|---|---|
| Довжина | **6–8 см** (2–20) |
| Діаметр | 6–8 мм |
| Початок | **задньо-медіальна стінка сліпої**, **~2–3 см нижче ілеоцекального клапана**, де сходяться **три стрічки** |
| Брижа | **брижа апендикса** (*mesoappendix*) з **апендикулярною артерією** (кінцева, з клубово-ободової) |
| **Положення** | **ретроцекальне** (~65% — найчастіше), **тазове** (~30%), підцекальне, **ілеальне** (передньо/заднє) |
| Стінка | **багато лімфоїдної тканини** (фолікули) — «кишкова мигдалина» |

**Проєкція**: **точка Мак-Бернея** — на межі **зовнішньої та середньої третин** лінії між **пупком** і **правою передньою верхньою клубовою остю**; **точка Ланца** — між правою і середньою третинами лінії, що з'єднує ості.
**Апендицит**: [[Хвороби травної системи]].

## 4. Ободова кишка (*colon*)

### Висхідна і низхідна
- **Заочеревинно**; **очеревина лише спереду**.
- **Правий і лівий жолоби** (канали) — шляхи поширення гною.
- **Висхідна** — до **печінкового згину** (під правою часткою печінки); **низхідна** — від **селезінкового згину** (підвішений **діафрагмово-ободовою зв'язкою**) до клубового гребеня.

### Поперечна ободова
- **Між печінковим і селезінковим згинами**; **брижа поперечної ободової** (*mesocolon transversum*) ділить **черевну порожнину** на **верхній і нижній поверх** (**«горизонт» черевної порожнини**).
- **Великий сальник** прикріплений до неї.
- **Селезінковий згин** — вище, глибше.

### Сигмоподібна
- **S-подібна**, у лівій клубовій ямці й тазі; брижа довга.
- **Заворот сигмоподібної** (літні, закрепи): на рентгені — симптом «кавового зерна», непрохідність; **дивертикули** (дивертикульоз, дивертикуліт — **«лівосторонній апендицит»**).
- **Сигмоїдоскопія**, колоноскопія.

## 5. Стінка

| Оболонка | Особливості |
|---|---|
| **Слизова** | **без ворсинок**, **крипти** (багато **келихоподібних клітин** — слиз); **циліндричний епітелій** з **колоноцитами** (всмоктування Na⁺, води); **лімфоїдні фолікули** (аппендикс) |
| **Підслизова** | |
| **М'язова** | **внутрішній циркулярний**; **зовнішній поздовжній** — **у 3 стрічках** |
| **Серозна** | очеревина (відсутня на заочеревинних поверхнях) |

Крипти — ~ **10 млн**; **келихоподібні клітини** складають до **50%** — слиз полегшує проходження калу.

## 6. Кровопостачання

| Відділ | Артерія | Походження |
|---|---|---|
| **Сліпа, апендикс, висхідна** | **клубово-ободова**, **права ободова** (**верхня брижова**) | **середня кишка** |
| **Поперечна (2/3 праві)** | **середня ободова** (верхня брижова) | |
| **Поперечна (1/3 ліва), низхідна, сигмоподібна** | **ліва ободова, сигмоподібні** (**нижня брижова**) | **задня кишка** |

- **Граничні артерії Драммонда** (*marginal artery*) — вздовж ободової кишки: **колатеральний шлях**.
- **Дуга Ріолана** — з'єднання верхньої і нижньої брижових.
- **Критичні зони (водорозділ)**: **селезінковий згин (точка Грифітса)** і **ректосигмоїдний відділ (точка Зудека)** — найменше колатералів → **ішемічний коліт**.

**Вени** → верхня і нижня брижові → **ворітна**: [[Вени — нижня порожниста і ворітна системи]]. Деталі артерій: [[Аорта і її гілки]].

**Лімфа**: епіколічні, паракколічні, проміжні, **головні (брижові)** вузли → цистерна хілі. Метастази раку — по лімфі і ворітній вені (**печінка**).

## 7. Іннервація

| Відділ | Парасимпатика | Симпатика |
|---|---|---|
| **До лівого згину** | **блукаючий нерв** | **верхнє брижове** (T10–L2) |
| **Після лівого згину** (низхідна, сигмоподібна, пряма) | **тазові нерви S2–S4** | **нижнє брижове** (L1–L2), підчеревне |

**Чутлива іннервація**: біль — **T11–L2** (нижні відділи — **надлобковий** біль, внизу живота).

Ентеральна система: **Мейснер, Ауербах**. **Хвороба Гіршпрунга**: відсутність гангліїв.

## 8. Функції

### 1. Всмоктування води й електроліти
- Вода: до **~1–1,5 л/добу** (макс. 5 л).
- **Na⁺** активно (ENaC, Na⁺/H⁺), **Cl⁻**, **K⁺** секретується; **коротколанцюгові жирні кислоти** (бутират) — енергія для колоноцитів.
- Кал: **75% вода, 25% тверде**.

### 2. Бактеріальне перетравлення (мікробіом)
- **10¹³–10¹⁴ бактерій** (*Bacteroides, Firmicutes*, *E. coli*, *Bifidobacterium*, *Clostridia*); маса ~0,2–1 кг; бактерії становлять 30–50% сухої маси калу.
- **Ферментація** клітковини → **коротколанцюгові ЖК** (бутират, пропіонат, ацетат), **гази** (H₂, CO₂, CH₄).
- **Синтез вітаміну K, біотину, фолату** (B₁₂ синтезується, але в товстій кишці майже не всмоктується).
- **Деконъюгація жовчних кислот**, перетворення **білірубіну → уробіліноген → стеркобілін** (колір калу).
- **Захист** (колонізаційна резистентність).
- **Дисбіоз**: антибіотики → *Clostridioides difficile* (псевдомембранозний коліт).

### 3. Формування і накопичення калу
- **Кал**: ~100–200 г/добу; **вода, клітковина, бактерії, слиз, клітини епітелію, жовчні пігменти**, мало жиру.

### 4. Секреція
Слиз, K⁺, бікарбонат.

## 9. Моторика

| Тип | Опис |
|---|---|
| **Сегментація (гаустральна)** | **змішування**, всмоктування води; повільна |
| **Масові скорочення (перистальтика)** | **1–3 рази/день** (особливо після їжі — **гастроколічний рефлекс**) → **кал у пряму кишку** → **позив до дефекації** |
| **Антиперистальтика** | у проксимальній частині — затримка хімусу |

Транзит: **12–48 год** (до 72). Регуляція: **гастроколічний рефлекс** (після їжі), симпатика ↓, парасимпатика ↑, **серотонін**, **моторика** — дефекація: [[Пряма кишка і анальний канал]].

## 10. Розвиток

- **Задня кишка** (від 2/3 поперечної до анального каналу) і частина **середньої** (сліпа, висхідна).
- **Ротація кишки**: середня кишка (**270° проти годинникової**); сліпа кишка **опускається** з правого підребер'я в клубову ямку.
- **Вади**: **мальротація** (сліпа в лівому/правому підребер'ї; **заворот**), **хвороба Гіршпрунга** (агангліоз — мегаколон), **атрезія**, **дивертикул Меккеля**, **нерухома сліпа**.

## 11. Хвороби товстої кишки

| Хвороба | Суть |
|---|---|
| **Гострий апендицит** | запалення апендикса (обструкція каменем/лімфоїдною гіперплазією); **біль — спочатку навколо пупка (T10), потім у правій клубовій ямці**; нудота, лихоманка; **симптоми** Мак-Бернея, Ровзінга, Ситковського, Щоткіна — Блюмберга; **апендектомія**; ускладнення — **перфорація, перитоніт, абсцес** |
| **Виразковий коліт (ВК)** | **безперервне** запалення **слизової** від прямої кишки; **кров'яний пронос**, тенезми; ризик раку; **первинний склерозуючий холангіт** |
| **Хвороба Крона** | трансмуральне, сегментарне, **«стрибки»**; нориці |
| **Синдром подразненої кишки (СПК)** | функціональний; **біль, зміна випорожнень**, без органічних змін (критерії Рим IV) |
| **Дивертикульоз / дивертикуліт** | **сигмоподібна**; біль зліва; дієта з клітковиною |
| **Поліпи** | **аденоматозні** (передрак) → **рак** (аденома-карцинома) |
| **Колоректальний рак (КРР)** | 2-й за частотою; **скринінг після 45–50**; **кров у калі**, анемія, зміна ритму, схуднення; **колоноскопія**; хірургія |
| **Ішемічний коліт** | селезінковий згин; біль + кров'яний пронос |
| **Псевдомембранозний коліт** | *C. difficile* після антибіотиків |
| **Запор** | < 3 випорожнень/тиждень |
| **Діарея** | рідкий кал > 3/день |
| **Завороти** | сигмоподібна, сліпа |
| **Інфекції** | дизентерія (шигела), амебіаз, сальмонельоз |

### Хвороба Крона vs ВК
| Ознака | Крона | ВК |
|---|---|---|
| Ураження | **будь-де (рот–анус)**, частіше **термінальна клубова** | **лише товста** (від прямої кишки) |
| Поширення | **переривчасте («стрибки»)** | **безперервне** |
| Глибина | **трансмуральне** | **слизова** |
| Кров | рідше | **часто** |
| Нориці, стриктури | **часто** | рідко |
| Гістологія | **гранульоми** | **крипт-абсцеси** |

## 12. Мнемоніки

- Ознаки товстої: **3 стрічки, гаустри, сальникові відростки**.
- Апендикс: **точка Мак-Бернея**; **ретроцекальний** — найчастіше; **три стрічки сходяться** біля основи.
- **Дуги Драммонда і Ріолана**; **критичні зони — селезінковий згин і ректосигмоїд**.
- **Заочеревинні**: висхідна, низхідна; **внутрішньоочеревинні**: сліпа, поперечна, сигмоподібна.
- Парасимпатика: **X до лівого згину, S2–S4 далі**.
- Крон — **трансмуральний, «стрибки», гранульоми**; ВК — **слизова, безперервно, від прямої**.
