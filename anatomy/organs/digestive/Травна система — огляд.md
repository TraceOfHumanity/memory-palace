# Травна система — огляд (*systema digestorium*)

Травна система розщеплює їжу на молекули, які всмоктуються в кров і лімфу, і виводить неперетравлене. Вона починається ротом і закінчується анальним отвором. Довжина травного тракту ~**8–9 м** (у живої людини коротша через тонус).

## 1. Функції

| Функція | Зміст |
|---|---|
| **Моторна (механічна)** | жування, ковтання, перистальтика, змішування, виведення |
| **Секреторна** | слина, шлунковий сік, жовч, панкреатичний і кишковий сік |
| **Травлення (гідроліз)** | ферменти розщеплюють білки, жири, вуглеводи, нуклеїнові кислоти |
| **Всмоктування** | вода, іони, мономери, вітаміни → кров і лімфа |
| **Екскреція** | виведення калу, жовчних пігментів, ліків |
| **Бар'єрна й імунна** | ~70% імунних клітин організму в кишці (GALT) |
| **Ендокринна** | гастрин, секретин, холецистокінін, грелін, інсулін (підшлункова) |
| **Мікробіом** | ~10¹³–10¹⁴ бактерій; синтез вітамінів K, B₁₂, захист |

## 2. Склад

### Травний канал (*canalis alimentarius*)
| Відділ | Органи |
|---|---|
| **Передня частина (верхній відділ)** | ротова порожнина → глотка → **стравохід** |
| **Середня частина** | **шлунок** → **тонка кишка** (дванадцятипала, порожня, клубова) |
| **Задня частина** | **товста кишка** (сліпа з апендиксом, ободова, сигмоподібна) → **пряма кишка** → анальний канал |

### Травні залози
| Залози | Секрет |
|---|---|
| **Слинні** (великі: привушна, під'язикова, піднижньощелепна; малі) | слина |
| **Печінка** | жовч |
| **Підшлункова залоза** | панкреатичний сік |
| **Залози стінки**: шлункові, кишкові | шлунковий, кишковий сік |

## 3. Шари стінки травного каналу

Від просвіту назовні (з винятками в окремих відділах):

| Оболонка | Склад |
|---|---|
| **Слизова** (*tunica mucosa*) | епітелій, власна пластинка (лімфоїдна тканина), **м'язова пластинка слизової** |
| **Підслизова** (*tela submucosa*) | пухка сполучна тканина, судини, **підслизове нервове сплетення Мейснера** |
| **М'язова** (*tunica muscularis*) | **внутрішній циркулярний** і **зовнішній поздовжній** шари гладких м'язів; між ними **міжм'язове сплетення Ауербаха** |
| **Серозна (адвентиція)** | **очеревина** (внутрішньочеревні органи) або **адвентиція** (стравохід, пряма кишка) |

Винятки: у верхній третині стравоходу — **посмуговані** м'язи; у шлунку — додатковий **косий шар**; **сфінктери** — потовщення циркулярного шару.

Ентеральна нервова система: [[Регуляція травлення]], [[Вегетативна нервова система]].

## 4. Шлях їжі й час

| Етап | Тривалість |
|---|---|
| Ротова порожнина | 15–20 с |
| Глотка, стравохід | рідина 1–2 с, грудка їжі 8–10 с |
| Шлунок | 2–6 год (залежить від складу) |
| Тонка кишка | 3–5 год |
| Товста кишка | 12–48 год (до 72) |
| Загальний | 24–72 год |

## 5. Кровопостачання (загальне)

- **Артерії**: черевний стовбур (передня кишка), верхня брижова (середня), нижня брижова (задня): [[Аорта і її гілки]].
- **Венозна кров** від непарних органів → **ворітна вена** → печінка: [[Вени — нижня порожниста і ворітна системи]].
- **Лімфа** — брижові вузли, цистерна хілі; жири всмоктуються в лімфу.

### Печінка як «фільтр»
Все, що всмоктується в кишці (крім жирів у лімфу), потрапляє в печінку: «**ефект першого проходження**» ліків.

## 6. Іннервація

| Тип | Джерело | Ефект |
|---|---|---|
| **Парасимпатична** | **блукаючий нерв** (до лівого згину ободової кишки), **тазові нерви S2–S4** (нижня частина) | ↑ перистальтика, ↑ секреція |
| **Симпатична** | **T5–L2** → черевні та брижові вузли | ↓ перистальтика, звуження судин, скорочення сфінктерів |
| **Ентеральна** | сплетення Мейснера і Ауербаха | автономне керування |
| **Соматична** | язик, жувальні м'язи, зовнішній сфінктер заднього проходу | довільне |

## 7. Розвиток

- Ентодерма **первинної кишки** → епітелій і залози; мезодерма → м'язи, сполучна тканина, серозна.
- Кишка ділиться на **передню, середню, задню**; кожна має **свою артерію** (черевна, верхня брижова, нижня брижова).
- **Ротація кишки** (6–10 тижнів): **фізіологічна пупкова грижа** → повернення; порушення → **мальротація**, вади (атрезія, дивертикул Меккеля, омфалоцеле, гастрошизис, хвороба Гіршпрунга).

| Показник | Значення |

| Жовч | 0,5–1 л/добу |
| Панкреатичний сік | 1,5–2 л/добу |

## 10. Мнемоніки

- Шлях: **рот → глотка → стравохід → шлунок → дванадцятипала → порожня → клубова → сліпа → ободова → пряма → анус**.
- Шари стінки: **слизова — підслизова — м'язова — серозна** («С-П-М-С»).
- Сплетення: **Мейснер — підслизове, Ауербах — міжм'язове** («М — під, А — між»).
- Вся кров від кишки → **ворітна вена → печінка**.
