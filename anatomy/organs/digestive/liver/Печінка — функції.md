# Печінка — функції

Печінка — центральний орган обміну речовин. Вона регулює рівень глюкози, синтезує білки плазми й жовч, знешкоджує токсини та ліки, зберігає вітаміни й залізо. Втрата функції (недостатність) загрожує життю.

Пов'язані файли: [[Травна система — огляд]], [[Печінка — будова]], [[Жовчний міхур і жовчні шляхи]], [[Підшлункова залоза]], [[Тонка кишка — травлення і всмоктування]], [[Вени — нижня порожниста і ворітна системи]], [[Дихання — газообмін і транспорт газів]], [[Регуляція травлення]], [[Хвороби травної системи]].

## 1. Огляд функцій

| Група | Функції |
|---|---|
| **Метаболічні** | вуглеводи, жири, білки, вітаміни, залізо |
| **Синтетичні** | білки плазми, фактори згортання, жовч, холестерин |
| **Детоксикація** | ліки, алкоголь, аміак, гормони |
| **Екскреторні** | жовч, білірубін, холестерин |
| **Депонувальні** | глікоген, вітаміни A, D, B₁₂, K, залізо, мідь, кров (~500 мл) |
| **Імунні** | клітини Купфера (фагоцитоз) |
| **Кровотворення** | у плода |
| **Ендокринні** | ІФР-1, ангіотензиноген, тромбопоетин, гепсидин |

## 2. Метаболізм вуглеводів

Печінка **підтримує рівень глюкози** в крові (4,0–5,5 ммоль/л):

| Процес | Опис | Регуляція |
|---|---|---|
| **Глікогеногенез** | глюкоза → **глікоген** (запас: **~70–100 г** у печінці) | **інсулін** ↑ |
| **Глікогеноліз** | глікоген → **глюкоза** | **глюкагон, адреналін** ↑ |
| **Глюконеогенез** | глюкоза з **лактату, амінокислот, гліцеролу** (натще, голодування) | **глюкагон, кортизол** ↑ |
| **Перетворення** фруктози і галактози в глюкозу | |

- **Глюкоза-6-фосфатаза** є **лише в печінці** і нирках (дає вільну глюкозу в кров; м'язовий глікоген її не віддає).
- **Гіпоглікемія** при тяжких ураженнях печінки.
- **Хвороби накопичення глікогену** (хвороба Гірке: дефіцит глюкозо-6-фосфатази).

## 3. Метаболізм жирів

| Процес | Опис |
|---|---|
| **β-окиснення жирних кислот** | енергія; **ацетил-КоА** |
| **Кетогенез** | ацетил-КоА → **кетонові тіла** (ацетоацетат, β-гідроксибутират) — паливо для мозку при голодуванні, діабеті |
| **Ліпогенез** | надлишок вуглеводів → **жирні кислоти → тригліцериди** |
| **Синтез холестерину** | (HMG-КоА-редуктаза; мішень **статинів**) |
| **Синтез ліпопротеїнів** | **ЛПДНЩ** (VLDL), ЛПВЩ (HDL) |
| **Утворення жовчних кислот** з холестерину | **основний шлях виведення холестерину** |
| **Захоплення залишків хіломікронів**, ЛПНЩ | |

**Жирова печінка (стеатоз)**: надлишок ТГ у гепатоцитах — алкоголь, **ожиріння, діабет (НАЖХП/MASLD)** → **стеатогепатит** → цироз.

## 4. Метаболізм білків

| Процес | Опис |
|---|---|
| **Синтез білків плазми** | **альбумін** (~12 г/добу; онкотичний тиск; транспорт), **α-** і **β-глобуліни**, **трансферин**, **церулоплазмін**, **α1-антитрипсин**, **фібриноген** (— **імуноглобуліни** синтезують **плазмоцити**, **не печінка**) |
| **Фактори згортання** | **I, II (протромбін), V, VII, IX, X** (+ **вітамін K-залежні: II, VII, IX, X**); **протеїни C, S**; **антитромбін III** |
| **Дезамінування, трансамінування** | амінокислоти → енергія; **АЛТ, АСТ** (маркери ураження) |
| **Цикл сечовини (орнітиновий)** | **аміак (NH₃) → сечовина** (токсично → нетоксично) — **тільки в печінці**; виводиться нирками |
| **Синтез амінокислот** (незамінних — ні) | |

### Аміак і енцефалопатія
- **NH₃** утворюється в кишці (бактерії), нирках, м'язах.
- Печінка перетворює в **сечовину**. При **цирозі / портокавальних шунтах** → **↑ NH₃** → **токсичний вплив на мозок** (астроцити → глутамін → набряк) → **печінкова енцефалопатія** (сплутаність, «флаппінг-тремор», кома). Лікування: **лактулоза**, рифаксимін.

## 5. Білірубін і жовтяниця

### Метаболізм гема
1. **Старі еритроцити** (120 днів) → **селезінка, печінка (Купфер)**.
2. **Гем** → **білівердин** → **непрямий (вільний, некон'югований) білірубін** (**ліпофільний**, токсичний, **зв'язаний з альбуміном**).
3. **Печінка**: захоплення гепатоцитами → **кон'югація з глюкуроновою кислотою** (фермент **УДФ-глюкуронілтрансфераза**) → **прямий (кон'югований) білірубін** (водорозчинний).
4. **Екскреція** в **жовч** → кишка.
5. **Бактерії кишки** → **уробіліноген** → **(1) стеркобілін** (кал, **колір**), **(2) реабсорбція → кров → нирки (уробілін, колір сечі)**, **(3) знову в жовч** (ентерогепатична).

### Норма білірубіну
**Загальний 3,4–20,5 мкмоль/л** (непрямий 75%, прямий 25%); **жовтяниця — > 34 мкмоль/л** (склери) → шкіра.

### Види жовтяниць
| Тип | Причина | ↑ білірубін | Сеча | Кал | Свербіж |
|---|---|---|---|---|---|
| **Надпечінкова (гемолітична)** | **гемоліз** (анемія, малярія, резус-конфлікт) | **непрямий** | **норма (без білірубіну)**, ↑ уробілін | **темний** (↑ стеркобілін) | ні |
| **Печінкова (паренхіматозна)** | **гепатит, цироз** (ушкодження гепатоцитів) | **і прямий, і непрямий** | **темна (білірубін +)** | **світліший** | є |
| **Підпечінкова (механічна, обструктивна)** | **камінь, пухлина** (голівка підшлункової — **синдром Курвуазьє**) | **прямий** | **темна («пиво»)** | **знебарвлений (ахолічний)** | **виражений** (жовчні кислоти) |

### Новонароджені
- **Фізіологічна жовтяниця** (2–3 день): **незріла УДФ-глюкуронілтрансфераза**, швидкий гемоліз; **ядерна жовтяниця** (білірубін > 340 → мозок): **фототерапія**.
- **Спадкові**: **Жильбера** (легка, доброякісна, **↓ УДФ-ГТ**), **Криглера — Найяра** (тяжка), **Дубіна — Джонсона** (↑ прямий).

## 6. Жовч

| Показник | Значення |
|---|---|
| Об'єм | **0,5–1 л/добу** |
| Склад | **вода (97%)**, **жовчні кислоти (солі)** (~0,7%), **фосфоліпіди (лецитин)**, **холестерин**, **білірубін**, електроліти (бікарбонат), слиз |
| **pH** | 7,0–8,0 (печінкова), 6,5–7 (міхурова) |
| Колір | **золотисто-жовта (печінкова)**, **темно-коричнева (міхурова)** |

### Функції жовчі
1. **Емульгування і всмоктування жирів** (жовчні кислоти).
2. **Всмоктування жиророзчинних вітамінів** (A, D, E, K).
3. **Екскреція**: холестерин, білірубін, ліки, важкі метали.
4. **Нейтралізація кислоти** (бікарбонат), **стимуляція перистальтики**, **бактеріостатична**.

### Жовчні кислоти
**Холева, хенодезоксихолева** (первинні, з холестерину) → **кон'югація з глікоколом, таурином** (**солі**) → у кишці бактерії → **вторинні** (дезоксихолева, літохолева). **Ентерогепатична циркуляція** (~95% реабсорбується в клубовій кишці): [[Тонка кишка — травлення і всмоктування]].

### Регуляція жовчоутворення
- **Жовчні кислоти** (з портальної крові) → ↑ секреція (**холерез**).
- **Секретин** → ↑ бікарбонат у жовчі.
- **Блукаючий** ↑.
- **ХЦК** → скорочення міхура: [[Жовчний міхур і жовчні шляхи]].

## 7. Детоксикація і біотрансформація

**Печінка знешкоджує** ліки, токсини, гормони, алкоголь.

### Фази
| Фаза | Реакції | Ферменти |
|---|---|---|
| **Фаза I (модифікація)** | **окиснення, відновлення, гідроліз** | **цитохроми P450 (CYP3A4, 2D6, 2C9…)**; зона 3 ацинуса |
| **Фаза II (кон'югація)** | глюкуронування, сульфування, глутатіонування, ацетилювання | UGT, GST, NAT: **водорозчинні** → з жовчю/сечею |

- **Ефект першого проходження** (*first-pass*): ліки, що всмоктуються в кишці, йдуть **через печінку** → **частково руйнуються** (нітрогліцерин, пропранолол → сублінгвально, інші шляхи).
- **Індуктори CYP** (рифампіцин, фенітоїн, алкоголь, куріння) і **інгібітори** (кларитроміцин, грейпфрут) → взаємодії ліків.
- **Алкоголь**: **алкогольдегідрогеназа** → **ацетальдегід** (токсичний) → **ацетат**; **NADH ↑** → жирова печінка, гіпоглікемія, лактат.
- **Парацетамол**: у надлишку → **NAPQI** (токсичний) → **некроз** гепатоцитів (**зона 3**); антидот — **N-ацетилцистеїн**.
- **Гормони**: **естрогени, альдостерон, інсулін, тироксин** інактивуються (при цирозі: **гінекомастія, «судинні зірочки», пальмарна еритема**).

## 9. Інші функції

- **Імунна**: **клітини Купфера** фагоцитують бактерії з портальної крові (захист від кишкової флори); **NK-клітини**, імунологічна толерантність.
- **Терморегуляція**: теплопродукція (~20% тепла в спокої).
- **Ренін-ангіотензин**: **ангіотензиноген** синтезується печінкою.
- **Регенерація**: після резекції **відновлюється** за 4–8 тижнів (гепатоцити діляться).

## 10. Печінкова недостатність

| Тип | Опис |
|---|---|
| **Гостра** | **вірус, парацетамол, токсини**; за днів–тижні: **жовтяниця, коагулопатія, енцефалопатія** |
| **Хронічна** (цироз) | |

### Ознаки (цироз, портальна гіпертензія)
**Жовтяниця, асцит, ↓ альбумін (набряки), ↓ фактори згортання (кровоточивість, ↑ МНО), енцефалопатія, судинні зірочки, пальмарна еритема, гінекомастія, спленомегалія, варикоз стравоходу, «голова медузи»**, гепаторенальний синдром.

### Лабораторні показники
| Тест | Що показує |
|---|---|
| **АЛТ, АСТ** | **ураження гепатоцитів** (цитоліз): АЛТ — печінка; АСТ — печінка, серце, м'язи; алкоголь — **АСТ:АЛТ > 2** |
| **ЛФ (лужна фосфатаза), ГГТ** | **холестаз** |
| **Білірубін** (прямий/непрямий) | жовтяниця |
| **Альбумін, МНО (протромбіновий час)** | **синтетична функція** (печінкова недостатність) |
| **Аміак** | енцефалопатія |
| **Вірусні маркери** | HBsAg, анти-HCV |
| **УЗД, КТ, МРТ, еластографія (Фіброскан)** | фіброз, пухлини |
| **Біопсія** | |

### Класифікація Чайлда — П'ю (тяжкість цирозу): білірубін, альбумін, МНО, асцит, енцефалопатія → **A, B, C**.

## 11. Мнемоніки

- Печінка: **глюкоза (глікоген, глюконеогенез), жири (кетони, ЛПДНЩ, холестерин), білки (альбумін, фактори, сечовина), жовч, детоксикація**.
- **Жовтяниці**: **надпечінкова — непрямий білірубін, сеча норма**; **печінкова — обидва, темна сеча**; **підпечінкова — прямий, ахолічний кал, свербіж**.
- **Фактори згортання, що залежать від вітаміну K: II, VII, IX, X** (1972 — «10, 9, 7, 2»).
- Цикл сечовини — **лише в печінці**; **цироз → ↑ аміак → енцефалопатія**.
- Ліки: **ефект першого проходження**; **P450 — зона 3**.
