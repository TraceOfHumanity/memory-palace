# Жовчний міхур і жовчні шляхи (*vesica biliaris*, *viae biliferae*)

Жовч утворюється в печінці й відводиться жовчними протоками. **Жовчний міхур** накопичує, концентрує й виштовхує її в дванадцятипалу кишку під час їжі. Вихід регулює **сфінктер Одді**.

## 1. Внутрішньопечінкові шляхи

| Структура | Опис |
|---|---|
| **Жовчні канальці** | між гепатоцитами |
| **Канали Герінга** | сполучні |
| **Міжчасточкові протоки** | в портальних тріадах |
| **Сегментарні, часткові** | |
| **Права та ліва печінкові протоки** (*ductus hepaticus dexter, sinister*) | виходять з воріт печінки |

## 2. Позапечінкові шляхи

| Протока | Опис |
|---|---|
| **Загальна печінкова протока** (*ductus hepaticus communis*) | злиття правої і лівої; довжина 2–6 см; діаметр 4–6 мм |
| **Міхурова протока** (*ductus cysticus*) | від шийки жовчного міхура; 3–4 см; **спіральна складка (клапан Гейстера)** |
| **Загальна жовчна протока (холедох)** (*ductus choledochus*) | **злиття печінкової і міхурової**; **6–8 см**; діаметр до 6 мм (норма **< 6 мм**; > 8 — розширення) |

### Холедох: чотири частини
| Частина | Положення |
|---|---|
| **Супрадуоденальна** | в **печінково-дванадцятипалій зв'язці** (праворуч від власної печінкової артерії, спереду від ворітної вени) |
| **Ретродуоденальна** | **позаду верхньої частини дванадцятипалої** |
| **Панкреатична** | **в борозні/товщі голівки підшлункової залози** |
| **Інтрамуральна (інтрадуоденальна)** | **у стінці дванадцятипалої**; відкривається на **великому дуоденальному сосочку (Фатера)** |

### Ампула Фатера і сфінктер Одді
- **Ампула Фатера** (*ampulla hepatopancreatica*) — спільна порожнина жовчної та головної панкреатичної проток у стінці дванадцятипалої.
- Відкривається на **великому дуоденальному сосочку** (*papilla duodeni major*; **низхідна частина**, **8–10 см від пілоруса**).
- **Сфінктер Одді** (*m. sphincter ampullae*): **гладком'язовий**; регулює вихід жовчі й панкреатичного соку; **закритий між їжею**, **відкривається при ХЦК**.
- **Малий дуоденальний сосочок** — додаткова панкреатична протока (Санторіні).

## 3. Жовчний міхур (*vesica biliaris*, *vesica fellea*)

| Показник | Значення |
|---|---|
| Положення | **ямка жовчного міхура** на вісцеральній поверхні печінки; **на межі правої і квадратної часток** |
| Форма | грушоподібна |
| Довжина | 7–10 см |
| Ширина | 2–4 см |
| **Об'єм** | **30–50 мл** |
| Проєкція | **точка Кера** — перетин **правої реберної дуги** з **зовнішнім краєм правого прямого м'яза живота** (9-й реберний хрящ); **точка Мерфі** (там само) |

### Частини
| Частина | Опис |
|---|---|
| **Дно** (*fundus*) | виступає з-під нижнього краю печінки |
| **Тіло** (*corpus*) | |
| **Шийка** (*collum*) | перехід у міхурову протоку; **кишеня Гартмана** — випин шийки (камені застрягають) |
| **Міхурова протока** | |

### Трикутник Кало (гепатоцистичний)
Межі: **міхурова протока (знизу)**, **загальна печінкова протока (медіально)**, **нижня поверхня печінки (зверху)**. Містить **міхурову артерію** (з правої печінкової). **Ключовий орієнтир при холецистектомії** (ризик ушкодження холедоха/артерії).

### Стінка
| Оболонка | Склад |
|---|---|
| **Слизова** | **складки** (рядки), **одношаровий циліндричний** епітелій; **без підслизової**; **синуси Рокітанського — Ашоффа** (ямки) |
| **М'язова** | гладка |
| **Серозна** | очеревина (знизу), **адвентиція** (контакт із печінкою) |

### Кровопостачання
- **Міхурова артерія** (*a. cystica*) — з **правої печінкової** (в трикутнику Кало); кінцева (гангрена при тромбозі).
- Вени → **ворітна** (міхурова) або безпосередньо в печінку.

### Іннервація
Симпатична (T7–T10), парасимпатична (блукаючий), **права діафрагмова** (біль у **правому плечі**), біль — **правий підребер'я**, **лопатка**.

## 4. Функції жовчного міхура

1. **Накопичує жовч** (між їжею); сфінктер Одді закритий → жовч йде **в міхур** через міхурову протоку.
2. **Концентрує** жовч в **5–20 разів** (**всмоктування води й Na⁺, Cl⁻**) → **темна, густа, pH 6–7**; об'єм 30–50 мл, але **вміщує жовч з 12–24 год**.
3. **Виштовхує** жовч у кишку під час їжі.
4. Слиз (захист).

### Регуляція скорочення
| Стимул | Механізм |
|---|---|
| **Їжа (жири, амінокислоти)** у дванадцятипалій | **I-клітини** → **холецистокінін (ХЦК)** → **скорочення міхура + розслаблення сфінктера Одді** → **жовч у кишку** |
| **Блукаючий нерв** | ↑ тонус |
| **Секретин** | ↑ жовчоутворення (бікарбонат) |
| **Симпатика, соматостатин** | ↓ |

Деталі: [[Регуляція травлення]].

Жовчний міхур **не обов'язковий** — після холецистектомії жовч надходить прямо в кишку (діарея, постхолецистектомічний синдром).

## 5. Хвороби

### Жовчнокам'яна хвороба (ЖКХ, холелітіаз)
- **Камені**: **холестеринові (80%)** — «**4F**» (*Female, Fat, Fertile, Forty*: жінки, ожиріння, вагітності, > 40); **пігментні** (гемолітична анемія, цироз).
- **Механізм**: перенасичення жовчі холестерином, ↓ жовчні кислоти, **застій**.
- **Безсимптомні** (60–80%) або **жовчна колька**: **різкий біль у правому підребер'ї**, віддає **в праву лопатку**, **після жирної їжі**, **нудота, блювання**; 1–6 год.
- Діагностика: **УЗД** (**акустична тінь**).

### Ускладнення
| Стан | Суть |
|---|---|
| **Гострий холецистит** | запалення (обструкція міхурової протокою каменем); **біль > 6 год, лихоманка, лейкоцитоз**; **симптом Мерфі** (болісний вдих при пальпації під реберною дугою); УЗД: потовщена стінка, рідина; **холецистектомія (лапароскопічна)** |
| **Хронічний холецистит** | |
| **Холедохолітіаз** | камінь у холедоху → **механічна жовтяниця**; **ЕРХПГ + папілотомія** |
| **Гострий холангіт** | інфекція: **тріада Шарко** (**біль, жовтяниця, лихоманка**); **п'ятірка Рейнольдса** (+ гіпотензія, сплутаність); **невідкладне дренування** |
| **Гострий біліарний панкреатит** | камінь у ампулі Фатера → ↑ панкреатичний тиск: [[Підшлункова залоза]] |
| **Емпієма, гангрена, перфорація міхура** | |
| **Жовчно-кишкова нориця, ілеус** | камінь у кишку → непрохідність |
| **Порцелановий міхур** | кальцифікація — **ризик раку** |

### Пухлини
- **Рак жовчного міхура** (з камінням; пізня діагностика).
- **Холангіокарцинома** (рак проток; **пухлина Клацкіна** — на злитті печінкових проток).
- **Пухлина голівки підшлункової** → **синдром Курвуазьє** (**безболісно збільшений жовчний міхур + жовтяниця**): [[Печінка — функції]].
- **Рак ампули Фатера**.

### Інші
- **Дискінезія жовчних шляхів** (гіпо-/гіпертонічна): функціональна, біль без каменів; **дисфункція сфінктера Одді**.
- **Первинний біліарний холангіт**, **первинний склерозуючий холангіт** (ВК): аутоімунні, холестаз.
- **Атрезія жовчних шляхів** (новонароджені): **жовтяниця**, знебарвлений кал; **операція Касаї** до 2 місяців.
- **Кісти холедоха**.

## 6. Діагностика

| Метод | Показання |
|---|---|
| **УЗД органів черевної порожнини** | камені, холецистит, розширення проток |
| **КТ, МРТ/МРХПГ** | протоки, пухлини |
| **ЕРХПГ** (ендоскопічна ретроградна холангіопанкреатографія) | діагностика + лікування (**папілотомія**, камені, стенти) |
| **Холецинтиграфія (HIDA)** | функція міхура, обструкція |
| **Лабораторія** | **↑ ЛФ, ГГТ, прямий білірубін** (холестаз); амілаза |

## 7. Мнемоніки

- Шлях жовчі: **гепатоцит → канальці → протоки → печінкова → (міхурова ↔ міхур) → холедох → ампула Фатера → сфінктер Одді → дванадцятипала**.
- **Холедох**: **супрадуоденальна, ретродуоденальна, панкреатична, інтрамуральна**.
- **Трикутник Кало**: **міхурова протока + печінкова протока + печінка**; всередині — **міхурова артерія**.
- **Тріада Шарко**: **біль + жовтяниця + лихоманка** (холангіт).
- **Курвуазьє**: **безболісно збільшений міхур + жовтяниця** — **рак підшлункової**.
- Холестеринові камені — **4F**.
- **ХЦК** → **міхур скорочується, Одді розслаблюється**.
