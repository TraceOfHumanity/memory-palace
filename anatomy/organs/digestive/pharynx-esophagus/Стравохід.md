# Стравохід (*oesophagus*)

Стравохід — м'язова трубка, що проводить їжу від глотки до шлунка. Він має **три звуження**, **два сфінктери** і перистальтику. Захист від рефлюксу забезпечує **нижній стравохідний сфінктер**.

Пов'язані файли: [[Травна система — огляд]], [[Глотка і ковтання]], [[Шлунок — будова]], [[Шлунок — секреція і моторика]], [[Плевра і середостіння]], [[Аорта і її гілки]], [[Вени — нижня порожниста і ворітна системи]], [[Вени — верхня порожниста система]], [[М'язи грудної клітки і діафрагма]], [[Черепні нерви]], [[Вегетативна нервова система]], [[Хребет]], [[Хвороби травної системи]].

## 1. Положення і розміри

| Показник | Значення |
|---|---|
| Початок | рівень **C6** (нижній край перснеподібного хряща) |
| Кінець | **T11** (впадає в шлунок, **кардіальний отвір**) |
| Довжина | **~25 см** (від різців до кардії ~40 см) |
| Діаметр | 2–3 см (в спокої щілиноподібний) |
| Відділи | **шийний** (5–6 см), **грудний** (~16–18 см), **черевний** (1–4 см) |

### Ділянки
| Відділ | Рівень | Відношення |
|---|---|---|
| **Шийний** | C6–T2 | позаду трахеї; **поворотні гортанні нерви** з боків |
| **Грудний** | T2–T10 | заднє середостіння; **перед ним** — трахея, лівий головний бронх, **ліве передсердя**; **ззаду** — хребет, **грудна аорта**, грудна протока; **ліворуч** — дуга аорти |
| **Черевний** | T10–T11 | через **стравохідний отвір діафрагми (T10)**; короткий; під діафрагмою → шлунок |

Діафрагма: **отвір стравохіда на T10** (разом із блукаючими нервами).

## 2. Три анатомічні звуження

| Звуження | Рівень | Відстань від різців | Причина |
|---|---|---|---|
| **1. Глоткове** (перснеподібне) | **C6** | ~15 см | **перснеглотковий м'яз** (верхній сфінктер) |
| **2. Біфуркаційне (аортальне)** | **T4–T5** | ~25 см | **дуга аорти** (зліва) і **лівий головний бронх** (спереду) |
| **3. Діафрагмальне** | **T10** | ~40 см | **стравохідний отвір діафрагми** |

Тут застрягають **сторонні тіла**, виникають **стриктури** (опіки), **рак**.

## 3. Стінка

| Оболонка | Склад |
|---|---|
| **Слизова** | **багатошаровий плоский неороговілий епітелій** (як ротова порожнина); власна пластинка; **м'язова пластинка слизової**. На межі зі шлунком (**Z-лінія**, «зубчаста») — перехід в **циліндричний** |
| **Підслизова** | залози, судинне сплетення (варикоз), сплетення Мейснера |
| **М'язова** | **верхня 1/3 — посмуговані м'язи**; **середня 1/3 — змішані**; **нижня 1/3 — гладкі** (внутрішній циркулярний, зовнішній поздовжній); сплетення Ауербаха |
| **Адвентиція** | **без серози** у шийному і грудному відділах (**немає очеревини** → швидке поширення інфекції; шви накладають важко); серозна — тільки черевна частина |

## 4. Сфінктери

| Сфінктер | Положення | Тип | Функція |
|---|---|---|---|
| **Верхній стравохідний (перснеглотковий)** (*UES*) | C6 | посмугований (нижній констриктор) | відкривається при ковтанні, **закритий у спокої** (запобігає аерофагії й рефлюксу в глотку) |
| **Нижній стравохідний (кардіальний)** (*LES*) | T10–T11, над діафрагмою | **гладком'язовий, фізіологічний** (не має анатомічного кільця) | **тонічно закритий** (тиск 10–30 мм рт. ст.), відкривається при ковтанні (**вагально-опосередковане розслаблення**) |

### Антирефлюксний механізм (4 чинники)
1. **Тонус LES**.
2. **Діафрагмальні ніжки** (правий ніжка охоплює стравохід — «зовнішній сфінктер»).
3. **Гострий кут Гіса** (між стравоходом і дном шлунка) — клапанна дія.
4. **Слизова складка** (клапан Губарева) і **внутрішньочеревний тиск** (черевна частина стравоходу під впливом тиску).

Порушення → **гастроезофагеальний рефлюкс (ГЕРХ)**.

## 5. Моторика

### Перистальтика
- **Первинна** — хвиля після ковтання (швидкість 2–4 см/с); ~8–10 с.
- **Вторинна** — місцева, при розтягненні залишками їжі (без ковтання).
- **Третинна** — патологічні некоординовані скорочення.

Регуляція: **довгастий мозок (центр ковтання)** → **блукаючий нерв**; в посмугованій частині — прямо (**подвійне ядро**); в гладком'язовій — через **ентеральну нервову систему** (ACh — скорочення; NO, VIP — розслаблення). Деталі: [[Регуляція травлення]].

## 6. Кровопостачання

| Відділ | Артерії | Вени |
|---|---|---|
| **Шийний** | **нижня щитоподібна** | нижня щитоподібна → плечоголовна |
| **Грудний** | **стравохідні гілки грудної аорти** (3–5), бронхіальні | **непарна, напівнепарна** (→ ВПВ) |
| **Черевний** | **ліва шлункова**, нижня діафрагмова | **ліва шлункова** → **ворітна** |

**Портокавальний анастомоз**: нижня частина стравоходу — венозні сплетення зв'язують ворітну (ліва шлункова) і порожнисті (непарна) вени → **варикоз вен стравоходу при портальній гіпертензії** → кровотеча: [[Вени — нижня порожниста і ворітна системи]].

## 7. Іннервація і лімфа

| | Опис |
|---|---|
| **Парасимпатична** | **блукаючі нерви**; на нижньому відділі утворюють **стравохідне сплетення**: **передній (лівий)** і **задній (правий)** блукаючі стовбури проходять через діафрагму |
| **Симпатична** | симпатичний стовбур (T5–T9), великий внутрішностний нерв |
| **Поворотний гортанний** | шийний стравохід |
| **Чутлива** | біль (спазм, розтяг) — T4–T8: **іррадіація в серце-подібну ділянку** (**неможливо відрізнити від стенокардії**) |
| **Лімфа** | **шийний** → глибокі шийні; **грудний** → бронхо-середостінні (біфуркаційні), заглоткові; **черевний** → **черевні, шлункові** |

## 8. Розвиток

- **Передня кишка** → глотка, стравохід.
- Стравохід довшає, **ентодерма** → епітелій.
- **Атрезія стравоходу** + **трахео-стравохідна нориця** (1:3000) — **найчастіше** сліпий верхній кінець + нижній зв'язок з трахеєю (тип C, 85%): новонароджений — пінясті слини, кашель при годуванні, ціаноз; **зонд не проходить**.

## 9. Хвороби стравоходу

| Хвороба | Суть | Ознаки |
|---|---|---|
| **ГЕРХ** (гастроезофагеальна рефлюксна хвороба) | забросу кислого вмісту; ослаблення LES | **печія**, регургітація, кашель, охриплість; **езофагіт** |
| **Стравохід Барретта** | **метаплазія** (плоский → циліндричний епітелій) від хронічного рефлюксу | передрак (**аденокарцинома**); ендоскопія + біопсія |
| **Грижа стравохідного отвору діафрагми** | кардія/дно шлунка в грудну порожнину: **ковзна (90%)** і **параезофагеальна** | печія, дисфагія |
| **Ахалазія кардії** | втрата нейронів Ауербаха; **LES не розслаблюється**; стравохід розширений | прогресуюча **дисфагія до рідкої і твердої їжі**; регургітація; рентген — **«дзьоб пташки»**; лікування — міотомія за Геллером, дилатація |
| **Рак стравоходу** | **плоскоклітинний** (верхній/середній; куріння, алкоголь, гарячі напої) і **аденокарцинома** (нижній; Барретт) | прогресуюча дисфагія, схуднення; **пізнє виявлення** |
| **Стриктури** | опіки лугом/кислотою, ГЕРХ | |
| **Варикозні вени** | портальна гіпертензія | **масивна кровотеча (блювота кров'ю)**: ендоскопічне лігування, β-блокатори, зонд Блекмора |
| **Синдром Мелорі — Вейса** | розрив слизової при блюванні (алкоголь) | кровотеча |
| **Синдром Бурхаве** | розрив стінки при блюванні — **медіастиніт** | |
| **Ценкерівський дивертикул** | глоткові: [[Глотка і ковтання]] | |
| **Езофагіт** | кандидоз, герпес, ліки, еозинофільний | одинофагія |
| **Стороннє тіло** | | |

### Дисфагія: диференціація
- **Тверда їжа → прогресуюча** — механічна (рак, стриктура).
- **Рідке й тверде одночасно** — моторна (ахалазія, склеродермія).
- **Перемежована** — кільце Шацького, спазм.

## 11. Мнемоніки

- Стравохід: **C6 → T10 (діафрагма) → T11 (кардія)**, довжина 25 см.
- 3 звуження: **C6 (глотка), T4–T5 (дуга аорти + бронх), T10 (діафрагма)**; відстань від різців **15 — 25 — 40 см**.
- Верхня 1/3 — **посмугована**, нижня — **гладка**; **без серози**.
- Варикоз стравоходу — **ліва шлункова ↔ непарна**.
- Ахалазія — **«дзьоб пташки»**, ГЕРХ — **печія**.
