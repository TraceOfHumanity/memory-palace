# Зуби (*dentes*)

Зуби подрібнюють їжу. Кожен зуб має коронку, шийку й корінь. Він міцно вкорінений в **альвеолі** щелепи й утримується **зубо-ясеневим апаратом**. Зуби також беруть участь у мовленні та формуванні обличчя.

Пов'язані файли: [[Травна система — огляд]], [[Ротова порожнина і язик]], [[Слинні залози]], [[Череп — лицевий відділ]], [[Суглоби]], [[М'язи голови]], [[Черепні нерви]], [[Артерії голови і шиї]], [[Хвороби травної системи]], [[Кісткова тканина]].

## 1. Кількість і формули

| Зуби | Кількість |
|---|---|
| **Молочні** (*dentes decidui*) | **20** (по 10 на щелепі) |
| **Постійні** (*dentes permanentes*) | **32** (по 16 на щелепі) |

### Постійні зуби (на одну половину кожної щелепи)
| Зуб | Кількість | Позначка (FDI) |
|---|---|---|
| **Різці** (*incisivi*) | 2 | 1, 2 |
| **Ікло** (*caninus*) | 1 | 3 |
| **Премоляри** (*praemolares*, малі кутні) | 2 | 4, 5 |
| **Моляри** (*molares*, великі кутні) | 3 | 6, 7, 8 |

**Зубна формула дорослого**: **2 · 1 · 2 · 3** (різці · ікло · премоляри · моляри) — по половині щелепи, **усього 32**.
**Молочні**: **2 · 1 · 0 · 2** (різці · ікло · премолярів нема · моляри) — **20**.

### Нумерація FDI (дві цифри)
**Перша цифра** — квадрант (1 — верхній правий, 2 — верхній лівий, 3 — нижній лівий, 4 — нижній правий; для молочних 5–8); **друга цифра** — зуб від середини (1 — центральний різець … 8 — зуб мудрості).
Приклад: **26** — перший моляр верхньої щелепи ліворуч.

## 2. Прорізування

| Зуб (молочний) | Вік прорізування |
|---|---|
| Центральні різці | 6–8 міс (нижні) |
| Бічні різці | 8–12 міс |
| Перші моляри | 12–16 міс |
| Ікла | 16–20 міс |
| Другі моляри | 20–30 міс |
| **Повний набір (20)** | ~**2,5–3 роки** |

| Зуб (постійний) | Вік |
|---|---|
| **Перші моляри («шестирічні»)** | **6–7 років** |
| Центральні різці | 6–8 |
| Бічні різці | 7–9 |
| Ікла | 9–12 |
| Перші премоляри | 10–11 |
| Другі премоляри | 10–12 |
| **Другі моляри** | **11–13** |
| **Треті моляри (зуби мудрості)** | **17–25** (можуть не прорізатись) |

**Зміна зубів** (6–12 років): молочні зуби випадають, коріння **розсмоктується** (остеокласти).

## 3. Будова зуба

### Частини
| Частина | Опис |
|---|---|
| **Коронка** (*corona dentis*) | видима частина над ясенами |
| **Шийка** (*collum dentis*) | між коронкою й коренем (на межі з яснами) |
| **Корінь** (*radix dentis*) | в альвеолі; **верхівка кореня** з **отвором** (для судин і нервів) |

Кількість коренів: різці, ікла, премоляри — **1** (верхні перші премоляри — 2); **верхні моляри — 3**, **нижні моляри — 2**.

### Тканини
| Тканина | Склад | Особливості |
|---|---|---|
| **Емаль** (*enamelum*) | **96–97% мінеральних речовин** (гідроксиапатит), без клітин | **найтвердіша тканина організму**; покриває **коронку**; утворюється **амелобластами** (потім зникають — **не регенерує**) |
| **Дентин** (*dentinum*) | ~70% мінерали, 20% органіка (колаген) | основа зуба; **дентинні канальці** з відростками **одонтобластів**; чутливий; утворюється протягом життя |
| **Цемент** (*cementum*) | ~50% мінерали, як кістка | покриває **корінь**; **цементоцити**; прикріплення периодонтальних волокон |
| **Пульпа** (*pulpa dentis*) | пухка сполучна тканина | **судини, нерви, одонтобласти** в **порожнині зуба** і **кореневих каналах**; **живлення і чутливість** зуба |

### Порожнина зуба
- **Коронкова порожнина** + **кореневі канали** → **верхівковий отвір**.
- **Пульпа реагує на подразники болем** (холод, тепло, солодке).
- У молочних зубах пульпа велика.

## 4. Зубний (периодонтальний) апарат — **пародонт**

Пародонт утримує зуб:
| Структура | Опис |
|---|---|
| **Ясна** (*gingiva*) | слизова, ороговілий епітелій, прикріплена до кістки і шийки; **ясеневий жолобок (борозна)** |
| **Періодонт** (*periodontium*) | **зв'язка між цементом і альвеолою** (**Шарпеєві волокна**), амортизує, багато нервових закінчень (**відчуття тиску**) |
| **Альвеолярна кістка** (*alveolus dentalis*) | **лунка** в **альвеолярному відростку** щелепи; пластинчаста кістка |
| **Цемент** | |

Зубо-щелепне з'єднання — **вклинення** (*gomphosis*), різновид нерухомого з'єднання. Див. [[Суглоби]].

## 5. Типи зубів і функції

| Група | Форма коронки | Функція | Коренів |
|---|---|---|---|
| **Різці** | долотоподібна | відкушування | 1 |
| **Ікла** | конічна (найдовший корінь) | розривання; опора для виразу обличчя | 1 |
| **Премоляри** | 2 горбки | розчавлювання | 1–2 |
| **Моляри** | 4–5 горбків | перетирання | 2–3 |

### Поверхні зуба
- **Вестибулярна (губна/щічна)**, **язикова (піднебінна)**, **жувальна**, **апроксимальна (медіальна/дистальна)**.
- Щілина між зубами — **діастема**.

## 6. Прикус (оклюзія)

**Прикус** — змикання зубних рядів.

| Тип | Опис |
|---|---|
| **Ортогнатичний (норма)** | верхні різці перекривають нижні на 1/3; **горбки нижніх молярів** входять між горбками верхніх |
| **Прогнатія, прогенія** | вперед (верхня/нижня) |
| **Відкритий, глибокий, перехресний** | |
| **Мальоклюзія** | порушення; **ортодонтія** (брекети) |

Жування: **скронево-нижньощелепний суглоб** + жувальні м'язи (V3): [[М'язи голови]], [[Суглоби]].

## 7. Кровопостачання і іннервація

| Зуби | Артерії | Нерви (**V**) |
|---|---|---|
| **Верхні** | **верхні альвеолярні** (з верхньощелепної, підочноямкової) | **V2**: верхні альвеолярні (задні, середні, передні) |
| **Нижні** | **нижня альвеолярна** (з верхньощелепної) → **нижньощелепний канал** → підборідна | **V3**: **нижній альвеолярний** нерв → підборідний |

- **Ясна**: V2/V3 (щічні, язикові нерви).
- **Мандибулярна анестезія** — блокада нижнього альвеолярного нерва біля **язички нижньої щелепи**.
- **Лімфа**: підборідні, піднижньощелепні, шийні.
- **Одонтогенна інфекція** → абсцес, флегмона, **верхньощелепний синусит**, **тромбоз печеристого синуса**: [[Навколоносові пазухи]], [[Вени — верхня порожниста система]].

## 8. Розвиток

- **Зубна пластинка** (ектодерма) → **емальовий орган** (емаль); **зубний сосочок** (мезенхіма нервового гребеня) → дентин, пульпа; **зубний мішечок** → цемент, періодонт.
- Закладка молочних — **6–7 тиждень** ембріона; постійних — з 20-го тижня.
- Мінералізація — з 4-го місяця.
- **Порушення**: адентія, надкомплектні зуби, **тетрациклінові зуби** (жовті), **флюороз**, гіпоплазія емалі.

## 9. Хвороби зубів

| Стан | Суть |
|---|---|
| **Карієс** | руйнування емалі й дентину бактеріями (*Streptococcus mutans*) і кислотою від цукрів; **профілактика**: фториди, гігієна, обмеження цукру |
| **Пульпіт** | запалення пульпи (нічний біль); ендодонтичне лікування (**депульпація**) |
| **Періодонтит** | запалення периодонта; **кіста, гранульома** |
| **Гінгівіт** | запалення ясен (зубний наліт) → **пародонтит** (втрата кістки) |
| **Пародонтоз** | дистрофічне |
| **Зубний камінь** | мінералізований наліт |
| **Ускладнення** | флегмона, остеомієліт, сепсис, ендокардит (профілактика у групах ризику): [[Серце — хвороби]] |
| **Ретенція, дистопія зубів мудрості** | видалення |
| **Бруксизм** | скрегіт зубами |
| **Травма** | перелом, вивих |

## 10. Мнемоніки

- Формула: **2-1-2-3 = 8 на половину = 32**; молочні **2-1-0-2 = 5 на половину = 20**.
- Перший постійний зуб — **шестирічний моляр** (6–7 років).
- **Емаль — тверда, без клітин, не відновлюється**; **дентин — основа**; **цемент — на корені**; **пульпа — нерви й судини**.
- Прорізування молочних: **6 міс — нижні центральні різці**.
- Нижня щелепа — **V3**, верхня — **V2**.
