# Шлунок — будова (*gaster*, *ventriculus*)

Шлунок — розширена частина травного каналу між стравоходом і дванадцятипалою кишкою. Він накопичує їжу, змішує її з шлунковим соком, частково перетравлює (білки) і порціями передає в кишку.

Пов'язані файли: [[Травна система — огляд]], [[Стравохід]], [[Шлунок — секреція і моторика]], [[Тонка кишка — будова]], [[Печінка — будова]], [[Підшлункова залоза]], [[Очеревина]], [[Аорта і її гілки]], [[Вени — нижня порожниста і ворітна системи]], [[Мікроциркуляція і лімфатична система]], [[Вегетативна нервова система]], [[М'язи живота]], [[Хвороби травної системи]].

## 1. Положення і розміри

| Показник | Значення |
|---|---|
| Положення | **ліве підребер'я** і **надчеревна ділянка**; **~3/4 ліворуч** і 1/4 праворуч від серединної лінії |
| Рівень | **T10–L1** (кардія — T11; пілорус лежить на рівні L1, на транспілоричній площині Аддісона) |
| Об'єм | **порожній ~50 мл**; **розтягнутий 1,5–3 л** (до 4 л) |
| Довжина | ~25–30 см |
| Форма | залежить від тонусу, статури: **ріг, гачок, панчоха, каскад** (рентген) |

**Проєкція** на передню стінку: майже вся — в лівому підребер'ї, і частково епігастрії; **під лівим куполом діафрагми**; **перкусія — тимпанічний звук (простір Траубе)**.

## 2. Частини

| Частина | Опис |
|---|---|
| **Кардіальна частина** (*pars cardiaca*) | навколо **кардіального отвору** (вхід зі стравоходу); **немає анатомічного сфінктера**, але є фізіологічний |
| **Дно (склепіння)** (*fundus*) | вище кардії, під лівим куполом діафрагми; містить **газовий міхур** |
| **Тіло** (*corpus*) | основна частина |
| **Пілоричний відділ** (*pars pylorica*) | **привратниковий антральний відділ** (*antrum*) → **канал привратника** (*canalis pyloricus*) → **пілоричний сфінктер** |
| **Пілоричний (воротарів) отвір** (*ostium pyloricum*) | в дванадцятипалу кишку; **сфінктер** (*m. sphincter pylori*) — потовщення циркулярного шару |

### Краї
| Край | Опис |
|---|---|
| **Мала кривина** (*curvatura minor*) | вгнута, права; тут **кутова вирізка** (*incisura angularis*) — перехід тіла в пілоричний відділ; прикріплений **малий сальник** (печінково-шлункова зв'язка) |
| **Велика кривина** (*curvatura major*) | опукла, ліва, ~4–5 разів довша; **великий сальник** (шлунково-ободова зв'язка), шлунково-селезінкова |

### Стінки
- **Передня** — ліва частка печінки, діафрагма, передня черевна стінка.
- **Задня** — **сальникова сумка** → підшлункова залоза, ліва нирка і надниркова, селезінка (**«ложе шлунка»**).

## 3. Відношення (топографія)

| Орган | Відношення |
|---|---|
| **Печінка** | ліва частка спереду; мала кривина → малий сальник |
| **Діафрагма** | зверху |
| **Селезінка** | ззаду-ліворуч (шлунково-селезінкова зв'язка) |
| **Підшлункова залоза** | ззаду (через сальникову сумку) — **виразка задньої стінки → пенетрація** |
| **Поперечна ободова кишка** | знизу |
| **Ліва нирка і надниркова** | задньо |

Деталі очеревинних зв'язок: [[Очеревина]].

## 4. Стінка шлунка (4 оболонки)

| Оболонка | Склад |
|---|---|
| **Слизова** | **однорядний циліндричний епітелій** (слизові поверхневі клітини); **шлункові ямки**, складки, **шлункові поля**; залози |
| **Підслизова** | судини, нерви (Мейснер) |
| **М'язова** | **3 шари гладких м'язів**: **зовнішній поздовжній**, **середній циркулярний** (в пілорусі → **сфінктер**), **внутрішній косий** (унікальний, для змішування) |
| **Серозна** | **очеревина** (вісцеральна), без неї по кривинах (де прикріпляються сальники) |

### Рельєф слизової
- **Складки** (*plicae gastricae*) — поздовжні, особливо вздовж малої кривини (**«шлункова доріжка»** — *Magenstrasse*).
- **Шлункові поля** (*areae gastricae*) — 1–6 мм.
- **Шлункові ямки** (*foveolae gastricae*) — вхід у залози; **ямкові клітини** секретують слиз.

## 5. Залози шлунка і їх клітини

Залози — прості трубчасті. За відділами:

| Залози | Положення | Клітини |
|---|---|---|
| **Кардіальні** | біля кардії (вузька зона) | слизові клітини (муцин) |
| **Власні (фундальні)** | **дно і тіло** (**~80% секреції**) | **головні**, **парієтальні (обкладові)**, **шийкові слизові**, **ендокринні** |
| **Пілоричні** | антральний відділ | слизові; **G-клітини** (гастрин); D-клітини (соматостатин) |

### Клітини власних залоз
| Клітина | Положення | Секреція | Функція |
|---|---|---|---|
| **Парієтальні (обкладові)** | середина залози | **HCl** (H⁺/K⁺-АТФаза, **протонна помпа**), **внутрішній фактор** (для B₁₂) | ацидифікація, захист; **пернікіозна анемія** при втраті |
| **Головні (зимогенні)** | глибока частина | **пепсиноген** (→ пепсин при pH < 3), **шлункова ліпаза**, прохімозин (дитяча) | перетравлення білків |
| **Слизові (шийкові)** | шийка залози | **слиз і бікарбонат** | захист слизової; **бар'єр** |
| **Ентерохромафіноподібні (ECL)** | | **гістамін** | стимулює парієтальні (H₂) |
| **G-клітини** | антрум | **гастрин** | ↑ HCl |
| **D-клітини** | антрум/тіло | **соматостатин** | ↓ HCl, ↓ гастрин |
| **Грелін-клітини** | дно | **грелін** («гормон голоду») | апетит |
| **Стовбурові клітини** | шийка | | оновлення епітелію кожні **3–5 днів** |

### Слизово-бікарбонатний бар'єр
**Шар слизу** (0,2–0,5 мм) + **бікарбонат** (pH на поверхні епітелію ~7, у просвіті 1–2) + **щільні контакти** + **простагландини** + швидка регенерація. Порушення (H. pylori, НПЗП, алкоголь, стрес) → **ерозії, виразка**.

## 6. Сфінктери

- **Кардіальний** — LES (фізіологічний): [[Стравохід]].
- **Пілоричний** — анатомічний (потовщення циркулярного м'яза): **регулює евакуацію в дванадцятипалу кишку** (порціями ~3 мл). **Гіпертрофічний пілоростеноз** — діти 2–8 тижнів: проєктильне блювання «фонтаном», пальпується **«оливка»**, чоловіки; **пілоромоітомія** (Рамштедт).

## 7. Кровопостачання

Джерело — **черевний стовбур** (T12). **Артеріальні дуги** уздовж кривин:

| Артерія | Походження | Живить |
|---|---|---|
| **Ліва шлункова** (*a. gastrica sinistra*) | черевний стовбур | мала кривина (ліва частина) + стравохід |
| **Права шлункова** (*a. gastrica dextra*) | загальна/власна печінкова | мала кривина (права частина); анастомоз з лівою |
| **Права шлунково-сальникова** | шлунково-дванадцятипала (з загальної печінкової) | велика кривина (права) |
| **Ліва шлунково-сальникова** | селезінкова | велика кривина (ліва) |
| **Короткі шлункові** (5–7) | селезінкова | дно |
| **Задня шлункова** | селезінкова | задня стінка |

Багате кровопостачання → **ішемічна виразка рідкісна**; **кровотеча з виразки** — з **лівої шлункової** (мала кривина) або **шлунково-дванадцятипалої** (задня стінка дванадцятипалої).

**Вени**: ліва і права шлункові → **ворітна**; шлунково-сальникові → верхня брижова/селезінкова. **Анастомоз з стравохідними венами** → варикоз: [[Вени — нижня порожниста і ворітна системи]]. Артерії: [[Аорта і її гілки]].

## 8. Іннервація і лімфа

| | Опис |
|---|---|
| **Парасимпатична** | **блукаючі нерви** (передній — до шлунка і печінки; задній — до шлунка й черевного сплетення); **ACh** ↑ HCl, ↑ моторика |
| **Симпатична** | **черевне сплетення** (T6–T9, великий внутрішностний), ↓ моторика, звуження судин |
| **Ентеральна** | сплетення Мейснера і Ауербаха |
| **Чутлива (біль)** | симпатичні аференти T6–T9 → **епігастрій** |
| **Лімфа** | **шлункові (мала кривина)**, **шлунково-сальникові (велика)**, **селезінкові, пілоричні** → **черевні** вузли → кишковий стовбур; **метастаз у вузол Вірхова** (лівий надключичний): [[Мікроциркуляція і лімфатична система]] |

### Ваготомія
Перерізання блукаючих нервів (раніше при виразці): ↓ HCl; ускладнення — демпінг-синдром, діарея, гастропарез.

## 9. Вікові особливості

| Вік | Форма й об'єм |
|---|---|
| **Новонароджений** | ~**7–10 мл** (перший день), 30–35 мл (до 7 днів); **вертикальний, рогоподібний** |
| **Грудний** | 100 мл (3 міс), 250 (1 рік) |
| **Дорослий** | ~ **1,5–3 л** |
| **Старість** | атрофія слизової, ↓ HCl (ахлоргідрія) |

Кардіальний сфінктер у немовлят слабкий → **зригування**.

## 10. Розвиток

- **Передня кишка**: розширення; **обертається** (90° за годинниковою стрілкою): **ліва поверхня → передня** (отже **лівий блукаючий нерв — передній**).
- **Велика кривина** росте швидше → стає **ліво-нижньою**.
- **Сальникова сумка** утворюється із заднього простору.
- Вада: **гіпертрофічний пілоростеноз** (набутий), **атрезія**, **ротація**.

## 11. Клінічні поняття

| Стан | Суть |
|---|---|
| **Гастрит** | запалення слизової; **H. pylori**, НПЗП, алкоголь, аутоімунний (атрофічний, **пернікіозна анемія**) |
| **Виразка шлунка / дванадцятипалої кишки** | дефект слизової: **H. pylori (70–90%)**, НПЗП; біль в епігастрії; **дуоденальна** — біль «голодний», ніччю, зменшується після їжі; **шлункова** — після їжі; ускладнення: **кровотеча**, **перфорація** (вільне повітря під діафрагмою, «кинджальний» біль), **пенетрація**, **стеноз** |
| **Рак шлунка** | **аденокарцинома**; H. pylori, нітрати, куріння; **дифузний (перснеподібноклітинний)**, **кишковий**; симптоми пізні (схуднення, анемія, **вузол Вірхова**, **вузол Мері Джозеф**) |
| **Кровотеча** | **блювота «кавовою гущею»**, мелена |
| **Грижа стравохідного отвору** | кардія/дно в грудях |
| **Гастропарез** | діабет |
| **Демпінг-синдром** | після резекції |
| **Пілоростеноз** | у дітей, і при виразці |
| **Синдром Золлінгера — Еллісона** | **гастринома**: ↑ гастрин → множинні виразки |
| **Безоар** | |

**Ендоскопія (ЕГДС)**, **біопсія**, **тест на H. pylori** (дихальний, антиген у калі).

## 12. Мнемоніки

- Частини: **кардія — дно — тіло — антрум — пілорус**.
- Кривини: **мала — права (малий сальник)**, **велика — ліва (великий сальник)**.
- Артерії: **ліва шлункова (черевний), права шлункова (печінкова), шлунково-сальникові (права від шлунково-дванадцятипалої, ліва від селезінкової)**.
- Клітини: **парієтальні — HCl + внутрішній фактор**; **головні — пепсиноген**; **G — гастрин**; **ECL — гістамін**.
- Виразка: **H. pylori**; перфорація → **повітря під діафрагмою**.
