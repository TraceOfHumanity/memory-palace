# Регуляція травлення

Травлення керують три системи: **нервова** (вегетативна і ентеральна), **гормональна** і **паракринна**. Вони узгоджують секрецію, моторику й кровотік залежно від їжі. Основний принцип: їжа в одному відділі готує наступні.

## 1. Нервова регуляція

### Ентеральна нервова система (ЕНС, «мозок кишки»)
- **~100–500 млн нейронів** у стінці травного каналу (від стравоходу до анального каналу) — стільки ж, як у спинному мозку.
- Працює **автономно** (рефлекси без участі мозку); ЦНС лише **модулює**.

| Сплетення | Положення | Функція |
|---|---|---|
| **Підслизове (Мейснера)** | підслизова | **секреція, кровотік, всмоктування** (**локальне**) |
| **Міжм'язове (Ауербаха)** | між циркулярним і поздовжнім шарами | **моторика** (перистальтика) |

Нейрони: **чутливі (внутрішні первинні аферентні)** (механо-, хемо- рецептори), **вставні**, **рухові** (збудливі — **ACh, субстанція P**; гальмівні — **NO, VIP**), **секретомоторні**.
Клітини Кахаля (**пейсмейкери** повільних хвиль).

**Хвороба Гіршпрунга** — немає ганглійних клітин (дистальна кишка) → **мегаколон**; **ахалазія** — втрата нейронів у стравоході.

### Позакишкова (вегетативна) регуляція
| Відділ | Нерви | Ефекти |
|---|---|---|
| **Парасимпатичний** | **блукаючий (X)** (стравохід → лівий згин), **тазові нерви S2–S4** (далі) | **↑ секреція, ↑ моторика**, **розслаблення сфінктерів**, ↑ кровотік |
| **Симпатичний** | **T5–L2** (черевне, брижові сплетення) | **↓ моторика, ↓ секреція, скорочення сфінктерів**, **вазоконстрикція** (кров до м'язів при стресі) |

**Правило**: **«Rest and digest»** (парасимпатика) vs **«Fight or flight»** (симпатика). Деталі: [[Вегетативна нервова система]].

### Рефлекси
| Рефлекс | Опис |
|---|---|
| **Короткі (локальні, ентеральні)** | в межах стінки: **перистальтичний рефлекс** (розтяг → скорочення вище, розслаблення нижче) |
| **Довгі (вагальні)** | **вагально-вагальні**: шлунок/кишка → довгастий мозок → назад |
| **Гастроколічний** | їжа в шлунку → масові рухи в товстій |
| **Гастроілеальний** | → розслаблення ілеоцекального клапана |
| **Ентерогастральний** | кислота/жир у дванадцятипалій → **↓ евакуація** |
| **Ректо-сфінктерний** | дефекація |
| **Ковтання, блювання** | центри в довгастому мозку |

## 2. Гормони шлунково-кишкового тракту

Продукуються **ентероендокринними клітинами** слизової (багато; **найбільший ендокринний орган**).

| Гормон | Клітини, місце | Тригер | Дія |
|---|---|---|---|
| **Гастрин** | **G-клітини** (антральний відділ шлунка, дванадцятипала) | **пептиди, АК, розтяг, ACh (GRP)**; ↓ pH < 3 гальмує | **↑ HCl** (парієтальні через **ECL**/гістамін), **ріст слизової**, ↑ моторика |
| **Холецистокінін (ХЦК)** | **I-клітини** (дванадцятипала, порожня) | **жири, амінокислоти** | **скорочення жовчного міхура**, **розслаблення сфінктера Одді**, **↑ ферменти підшлункової**, ↓ евакуація шлунка, **насичення** |
| **Секретин** | **S-клітини** (дванадцятипала) | **кислота (pH < 4,5)** | **↑ бікарбонат підшлункової і жовчі**, ↓ гастрин і HCl, ↓ моторика шлунка |
| **GIP (глюкозозалежний інсулінотропний пептид)** | **K-клітини** (дванадцятипала, порожня) | **глюкоза, жири** | **↑ інсулін** (**інкретин**), ↓ секреція і моторика шлунка |
| **ГПП-1** (глюкагоноподібний пептид-1) | **L-клітини** (клубова, товста) | **поживні речовини** | **↑ інсулін, ↓ глюкагон, ↓ апетит, ↓ евакуація** (**інкретин**; ліки — **семаглутид**) |
| **Мотилін** | **M-клітини** (дванадцятипала, порожня) | натще, pH, ліпіди | **↑ ММК** («прибиральниця» кожні 90 хв); еритроміцин імітує |
| **Грелін** | **шлунок (дно)** | **натще** | **↑ апетит** («гормон голоду»), ↑ секреція, ↑ моторика |
| **Соматостатин** | **D-клітини** (шлунок, дванадцятипала, підшлункова) | кислота, пептиди | **гальмує майже все** (гастрин, ХЦК, секретин, HCl, інсулін) |
| **Вазоактивний інтестинальний пептид (VIP)** | нейрони | | **розслаблення** гладких м'язів, ↑ секреція води й електролітів, вазодилатація |
| **Пептид YY (PYY)** | L-клітини | їжа | **↓ апетит, ↓ моторика** («ілеальне гальмо») |
| **Нейротензин** | N-клітини | жир | ↓ моторика шлунка |
| **Серотонін (5-HT)** | **ентерохромафінні (ЕС) клітини** (кишка) | розтяг, подразнення | **моторика (перистальтичний рефлекс), секреція, нудота** (**5-HT₃** → блювання) |
| **Гістамін** | **ECL-клітини** | гастрин, ACh | **↑ HCl** (H₂) |
| **Лептин** | жирова тканина, шлунок | | насичення |

### Групи гормонів
- **Родина гастрину**: **гастрин, ХЦК** (подібний C-кінець).
- **Родина секретину**: **секретин, GIP, VIP, глюкагон, ГПП-1**.
- **Інкретини** (**GIP, ГПП-1**): «**інкретиновий ефект**» — пероральна глюкоза викликає **більшу інсулінову відповідь**, ніж внутрішньовенна.

## 3. Фази травлення

| Фаза | Тригер | Нервові/гормональні механізми |
|---|---|---|
| **Цефалічна** (до їжі, ~30% секреції) | **вигляд, запах, смак, думка**, жування | **X нерв** → слина, шлунковий сік, підшлункова; рефлекси |
| **Ротова** | їжа в роті | слина (IX, VII), початок ковтання |
| **Шлункова** (**~60%**) | **розтяг, пептиди** | гастрин, вагус; моторика |
| **Кишкова** (**~10% + гальмування**) | **хімус у дванадцятипалій** | **секретин, ХЦК, GIP**; **ентерогастральний рефлекс**; **підшлункова, жовч** |
| **Всмоктування і товста** | | ГПП-1, PYY; **гастроколічний рефлекс** |
| **Голодна (міжтравна)** | натще | **ММК (мотилін)** |

## 4. Регуляція апетиту (коротко)

| Сигнал | Дія |
|---|---|
| **Грелін** (шлунок) | **↑ апетит** (гіпоталамус, дугоподібне ядро) |
| **Лептин** (жирова тканина) | **↓ апетит** (довготривала регуляція) |
| **ХЦК, ГПП-1, PYY, інсулін** | **насичення** |
| **Блукаючий нерв** (розтяг шлунка) | насичення |

**Центри**: **гіпоталамус** (латеральне ядро — **голод**; вентромедіальне — **насичення**): [[Проміжний мозок і базальні ядра]].

**Ліки (ГПП-1 агоністи)** — діабет, ожиріння.

## 5. Мікробіом і вісь «кишка — мозок»

- **Бактерії кишки** (10¹³–10¹⁴): ферментація, вітаміни, імунітет.
- **Вісь кишка–мозок**: блукаючий нерв, серотонін (90% організму — в кишці), цитокіни, метаболіти бактерій (КЛЖК); **настрій, апетит, біль**; **СПК** — порушення.
- **Пробіотики, пребіотики**, **трансплантація калу** (*C. difficile*).

## 6. Клінічні поняття

| Стан | Суть |
|---|---|
| **Гіпергастринемія** | **Золлінгер — Еллісон** (гастринома), атрофічний гастрит, ІПП |
| **Недостатність секретину/ХЦК** | целіакія (ураження слизової) → панкреатична недостатність |
| **Гастропарез** | діабет (вагус) |
| **Нейрогенні розлади** | хвороба Гіршпрунга, ахалазія, **ілеус** |
| **Діабет і інкретини** | **ГПП-1 агоністи**, **ДПП-4 інгібітори** (↓ розпад інкретинів) |
| **Карциноїдний синдром** | **серотонін** (нейроендокринна пухлина): **діарея, припливи** |
| **ВІПома** | **водяниста діарея, гіпокаліємія** |
| **СПК** | функціональний |
| **Нудота й блювання** | **5-HT₃** (ондансетрон), **D₂**, **NK₁**: [[Шлунок — секреція і моторика]] |

## 7. Мнемоніки

- Гормони: **гастрин ↑ HCl; секретин ↑ бікарбонат; ХЦК ↑ ферменти і міхур; GIP/ГПП-1 ↑ інсулін; мотилін ↑ «прибиральниця»; грелін ↑ апетит; соматостатин гальмує все**.
- **S — Secretin (acid → bicarb), I — ХЦК (жири), G — гастрин, K — GIP, M — мотилін, D — соматостатин, L — ГПП-1/PYY**.
- Сплетення: **Мейснер — під (секреція), Ауербах — між (моторика)**.
- **Парасимпатика — «відпочинь і травлення»**; **симпатика — «бий або тікай»**.
- Інкретини: **GIP + ГПП-1**.
