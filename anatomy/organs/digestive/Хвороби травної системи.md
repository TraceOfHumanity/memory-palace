# Хвороби травної системи

Це зведення основних хвороб травної системи. Для кожної наведено суть, ознаки, діагностику й принципи лікування. Детальну анатомію й фізіологію шукай у файлах про окремі органи.

## 1. Симптоми

| Симптом | Значення |
|---|---|
| **Дисфагія** | труднощі ковтання: орофарингеальна (нервово-м'язова), стравохідна (механічна: пухлина, стриктура; моторна: ахалазія) |
| **Одинофагія** | болісне ковтання (езофагіт) |
| **Печія** | жар за грудниною (ГЕРХ) |
| **Нудота, блювання** | багато причин: [[Шлунок — секреція і моторика]] |

| **Кровотеча** | **блювота кров'ю (гематемезис)**, **кавова гуща**, **мелена** (чорний кал; верхній відділ), **гематохезія** (свіжа кров; нижній), прихована |
| **Жовтяниця** | ↑ білірубін: [[Печінка — функції]] |
| **Здуття, гази** | |
| **Схуднення** | пухлина, мальабсорбція |
| **Анорексія** | |
| **Тенезми** | хибні позиви |

### Локалізація болю в животі (9 ділянок)
| Ділянка | Можливі причини |
|---|---|
| **Праве підребер'я** | **жовчний міхур** (колька, холецистит), печінка, **дванадцятипала**, права нирка |
| **Епігастрій** | **шлунок** (виразка, гастрит), **підшлункова**, стравохід, **інфаркт нижньої стінки** |
| **Ліве підребер'я** | селезінка, хвіст підшлункової, шлунок |
| **Навколопупкова** | **ранній апендицит**, тонка кишка, **ішемія**, панкреатит |
| **Права клубова ямка** | **апендицит**, Крон (клубова), сліпа, яєчник (кіста, перекрут), позаматкова вагітність, камінь сечоводу |
| **Ліва клубова ямка** | **дивертикуліт**, сигмоподібна, яєчник |
| **Надлобкова** | сечовий міхур (цистит), матка |
| **Фланки** | нирки (колька), сечоводи |

**Вісцеральний біль** — тупий, **по середній лінії**: **передня кишка → епігастрій**, **середня → навколо пупка**, **задня → надлобкова**.
**Соматичний (парієтальний)** — гострий, точний: [[Очеревина]].

## 2. Невідкладна хірургічна патологія («гострий живіт»)

| Стан | Ознаки |
|---|---|
| **Гострий апендицит** | **біль навколо пупка → права клубова ямка**, лихоманка, нудота; **симптоми** Мак-Бернея, Ровзінга, Ситковського, Щоткіна — Блюмберга; **апендектомія**; ускладнення: перфорація, абсцес |
| **Перфорація виразки** | **раптовий «кинджальний» біль**, дошкоподібний живіт; **вільне повітря під діафрагмою** на рентгені |
| **Гострий холецистит** | біль у правому підребер'ї, симптом Мерфі: [[Жовчний міхур і жовчні шляхи]] |
| **Гострий панкреатит** | опоясувальний біль, ↑ амілаза/ліпаза: [[Підшлункова залоза]] |
| **Кишкова непрохідність** | біль, **блювання, здуття, затримка газів і калу**; **рентген: чаші Клойбера** |
| **Мезентеріальна ішемія** | біль непропорційний огляду; [[Аорта і її гілки]] |
| **Розрив аневризми черевної аорти** | біль, шок, пульсуюче утворення |
| **Защемлена грижа** | **болісна пухлина**, не вправляється |
| **Кровотеча з ШКТ** | гематемезис, мелена |
| **Перитоніт** | [[Очеревина]] |
| **Позаматкова вагітність, перекрут яєчника** | гінекологічні причини |

## 5. Хвороби шлунка і дванадцятипалої кишки

| Хвороба | Ключове |
|---|---|
| **Гастрит** | гострий (НПЗП, алкоголь, **H. pylori**); хронічний (H. pylori — **тип B**, аутоімунний — **тип A**, **пернікіозна анемія**) |
| **Виразкова хвороба** | **H. pylori (~70–90%)**, **НПЗП**; **дуоденальна** — біль «голодний», нічний, **зменшується після їжі**; **шлункова** — біль **після їжі**; **ускладнення**: кровотеча, перфорація, пенетрація, стеноз; лікування — **ерадикація H. pylori** (ІПП + 2 антибіотики) |
| **Рак шлунка** | аденокарцинома; **H. pylori, нітрозаміни, куріння**; ранні симптоми — «шлункове» нездужання; **вузол Вірхова**, **Мері Джозеф**, **Крукенберга** (метастаз у яєчник) |
| **Гастропарез** | діабет |
| **Синдром Золлінгера — Еллісона** | гастринома |
| **Гіпертрофічний пілоростеноз** | у дітей, проєктильне блювання |
| **Демпінг-синдром** | після гастректомії |
| **Функціональна диспепсія** | без органічної причини |

Деталі: [[Шлунок — будова]], [[Шлунок — секреція і моторика]].

**Тест на H. pylori**: уреазний дихальний, антиген у калі, **гістологія**.

## 13. Принципи лікування

- **Ерадикація H. pylori**; **ІПП, блокатори H₂**, антациди.
- **Антибіотики** (інфекції), **пробіотики**.
- **Дієта**: безглютенова (целіакія), клітковина (дивертикули, запор), низькожирова (панкреатит, ЖКХ).
- **Хірургія**: апендектомія, холецистектомія, резекції, стоми.
- **Ендоскопічні втручання**: полектомія, лігування варикозу, ЕРХПГ, дилатація.
- **Трансплантація печінки**.
- **Нутритивна підтримка** (ентеральне/парентеральне).

## 14. Мнемоніки

- Біль: **епігастрій — шлунок; навколо пупка — тонка; права клубова — апендикс; праве підребер'я — жовчний міхур**.
- **Мелена** — верхній відділ; **гематохезія** — нижній.
- Виразка: **H. pylori + НПЗП**; дуоденальна — **голодний біль**.
- Кишка: **Крон — «стрибки», трансмурально; ВК — безперервно, слизова, пряма**.
- Печінка: **цироз → портальна гіпертензія + недостатність**.
- Панкреатит: **GET SMASHED**; жовчний міхур: **4F**.
