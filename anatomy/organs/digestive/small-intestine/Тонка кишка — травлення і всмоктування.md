# Тонка кишка — травлення і всмоктування

У тонкій кишці їжа остаточно розщеплюється до **мономерів**, і вони всмоктуються. Тут діють ферменти **підшлункового соку**, **жовч** і ферменти **щіткової облямівки** ентероцитів. Кишка також рухається двома типами скорочень: **сегментація** змішує, **перистальтика** просуває.

Пов'язані файли: [[Травна система — огляд]], [[Тонка кишка — будова]], [[Шлунок — секреція і моторика]], [[Підшлункова залоза]], [[Печінка — функції]], [[Жовчний міхур і жовчні шляхи]], [[Товста кишка]], [[Регуляція травлення]], [[Мікроциркуляція і лімфатична система]], [[Вени — нижня порожниста і ворітна системи]], [[Хвороби травної системи]].

## 1. Види травлення

| Тип | Де | Опис |
|---|---|---|
| **Порожнинне** | просвіт кишки | ферменти підшлункового соку, слини, шлункового |
| **Пристінкове (мембранне)** | **щіткова облямівка** ентероцитів | ферменти на мембрані: **кінцеве розщеплення** димерів/олігомерів до мономерів + одразу всмоктування (Уголєв) |
| **Внутрішньоклітинне** | всередині ентероцитів | деякі дипептиди |

## 2. Секрети, що діють

| Секрет | Об'єм/добу | Склад |
|---|---|---|
| **Панкреатичний сік** | 1,5–2 л | ферменти + **бікарбонат** (pH 8): [[Підшлункова залоза]] |
| **Жовч** | 0,5–1 л | жовчні кислоти (**емульгування**), холестерин, білірубін: [[Жовчний міхур і жовчні шляхи]] |
| **Кишковий сік** | 1–2 л | слиз, вода, електроліти; **ентерокіназа** (активує трипсиноген) |
| **Секрет залоз Бруннера** | | **слиз і бікарбонат** — захист дванадцятипалої |

### Нейтралізація кислоти
Кислий хімус (pH 1–2) → **бікарбонат** (підшлункова, Бруннера, жовч) → **pH 6–7** (оптимум ферментів). Недостатність → виразка.

## 3. Перетравлення вуглеводів

| Етап | Фермент | Місце | Продукт |
|---|---|---|---|
| **Крохмаль** | **α-амілаза** (слинна, **підшлункова**) | рот, дванадцятипала | **мальтоза, мальтотріоза, декстрини** |
| **Мальтоза** | **мальтаза** | щіткова облямівка | **2 глюкози** |
| **Сахароза** | **сахараза-ізомальтаза** | | **глюкоза + фруктоза** |
| **Лактоза** | **лактаза** | | **глюкоза + галактоза** |
| **Клітковина** | — | не перетравлюється людиною (бактерії в товстій) | |

### Всмоктування вуглеводів
| Моносахарид | Транспортер | Механізм |
|---|---|---|
| **Глюкоза, галактоза** | **SGLT1** (апікальна) | **вторинний активний** (разом з **Na⁺**); потім **GLUT2** (базолатеральна) — **полегшена дифузія** |
| **Фруктоза** | **GLUT5** (апікальна) → **GLUT2** | полегшена дифузія |

Na⁺/K⁺-АТФаза підтримує градієнт. **Оральна регідратація**: глюкоза + Na⁺ → вода слідує (холера!).

## 4. Перетравлення білків

| Етап | Фермент | Продукт |
|---|---|---|
| **Шлунок** | **пепсин** | поліпептиди |
| **Дванадцятипала** | **трипсин** (з трипсиногену ентерокіназою), **хімотрипсин**, **еластаза**, **карбоксипептидази** A, B | олігопептиди, ди-, трипептиди |
| **Щіткова облямівка** | **аміно-, ди-, трипептидази** | амінокислоти, ди-/трипептиди |

### Всмоктування білків
- **Амінокислоти**: **Na⁺-залежні** вторинні активні транспортери (різні для нейтральних, основних, кислих).
- **Ди- і трипептиди**: **PepT1** (H⁺-залежний) → розщеплюються всередині ентероцита до АК.
- В кров (ворітну) виходять **амінокислоти** (полегшена дифузія).
- Рівень всмоктування: **>95%** білків.

## 5. Перетравлення і всмоктування жирів

Жири (в основному **тригліцериди**) потребують **емульгування** й **міцелярного** транспорту.

### Етапи
1. **Емульгування**: **жовчні кислоти**, лецитин, перистальтика → **дрібні краплі (0,5–1 мкм)** (збільшення поверхні).
2. **Ліполіз**: **панкреатична ліпаза** (+ **коліпаза**) → **2 вільні жирні кислоти + 2-моногліцерид** (ЖК + МГ).
3. **Міцели**: жовчні кислоти + ЖК + МГ + холестерин + жиророзчинні вітаміни (**A, D, E, K**) → **міцели** (3–10 нм) підходять до щіткової облямівки.
4. **Всмоктування (дифузія)** ЖК, МГ — **пасивно**; холестерин — **NPC1L1** (мішень езетимібу).
5. **Ресинтез** тригліцеридів в **гладкій ЕПС** ентероцита.
6. Упаковка в **хіломікрони** (ТГ + холестерин + ліпопротеїни apoB-48).
7. **Екзоцитоз → лактеаль (лімфа)** → грудна протока → кров.

**Короткі і середні ЖК** (< 12 C) — всмоктуються **безпосередньо в ворітну вену** (без хіломікронів).

### Жовчні кислоти
- **Первинні**: **холева** і **хенодезоксихолева** (з холестерину в печінці).
- **Ентерогепатична циркуляція**: **~95% реабсорбується в термінальній клубовій кишці** (**NTCP/ASBT**) → ворітна вена → печінка → жовч знову (**6–10 циклів/добу**); втрата 0,5 г/добу.
- Порушення (резекція клубової, хвороба Крона) → **стеаторея**, діарея.

### Стеаторея
Жирний кал (> 7 г/добу): недостатність ліпази (панкреатит, муковісцидоз), жовчі (обструкція), мальабсорбція (целіакія).

## 6. Нуклеїнові кислоти
**Нуклеази** (панкреатичні) → нуклеотиди → нуклеотидази → нуклеозиди → основи, рибоза.

## 7. Всмоктування води й електролітів

| Речовина | Механізм | Частка |
|---|---|---|
| **Вода** | **осмотично** слідує за Na⁺ і розчиненими речовинами; **через щільні контакти** (парацелюлярно) і аквапорини | ~**8–9 л/добу** надходить у просвіт (з їжею 2 л + секрети 7 л) → **тонка кишка всмоктує ~7–8 л**, товста ~1–1,5 л; з калом ~0,1–0,2 л |
| **Na⁺** | Na⁺/глюкоза (SGLT1), Na⁺/H⁺ (NHE3), Na⁺/амінокислоти | |
| **Cl⁻** | парацелюлярно, обмін на HCO₃⁻ | секреція Cl⁻ — **криптами** (CFTR) → **секреторна діарея** (**холера**) |
| **K⁺** | пасивно | |
| **Ca²⁺** | **дванадцятипала**: **кальбіндин**, **вітамін D** (кальцитріол) | ~30% з їжі |
| **Fe²⁺** | **дванадцятипала**: **DMT1**; **гем** — HCP1; **гепсидин** регулює; Fe³⁺ → Fe²⁺ (дуоденальний цитохром b, вітамін C, HCl) | **~10%** з їжі |
| **Mg²⁺, фосфат** | | |

## 8. Вітаміни

| Вітамін | Де/як всмоктується |
|---|---|
| **Жиророзчинні A, D, E, K** | **міцели**, лімфа (з жиром) |
| **Водорозчинні** (C, B) | **Na⁺-залежні** транспортери, пасивно |
| **B₁₂** | **термінальна клубова кишка**; комплекс з **внутрішнім фактором**; нестача → **пернікіозна анемія**: [[Шлунок — секреція і моторика]] |
| **Фолат (B₉)** | проксимальна порожня |
| **K** | також синтезується бактеріями товстої |

## 9. Моторика тонкої кишки

| Тип | Опис | Функція |
|---|---|---|
| **Сегментація (ритмічна)** | **циркулярні** скорочення різних ділянок; 12/хв у дванадцятипалій → 8/хв у клубовій | **змішування** хімусу, контакт зі слизовою; **без просування** |
| **Перистальтика** | коротка хвиля 2–4 см; поштовхи **~1–2 см/с** | **просування** до товстої |
| **Мігруючий моторний комплекс (ММК)** | кожні **90–120 хв** натще (мотилін): хвиля від шлунка до клубової | **«прибиральниця»** — виводить залишки, бактерії; запобігає **бактеріальному надмірному росту (SIBO)** |
| **Маятникоподібні рухи** | поздовжні скорочення | змішування |
| **Рух ворсинок** | скорочення гладких м'язів | «насос» для лактеалі |

### Регуляція
- **Ритм**: **клітини Кахаля** — повільні хвилі (12/хв дванадцятипала → 8/хв клубова).
- **Нервова**: парасимпатика ↑, симпатика ↓; **ентеральні рефлекси** (**перистальтичний рефлекс** Бейліса — Старлінга: розтяг → скорочення вище, розслаблення нижче).
- **Гормони**: ↑ **мотилін, гастрин, ХЦК, серотонін, інсулін**; ↓ **секретин, глюкагон**.
- **Гастроілеальний рефлекс**: їжа в шлунку → розслаблення **ілеоцекального клапана** → хімус в сліпу.
- **Ілеоцекальний клапан** (Баугінієва заслінка) — запобігає зворотному току з товстої в тонку.
- **Транзит**: **3–5 год** (до сліпої).

## 10. Зведена таблиця: що де всмоктується

| Відділ | Всмоктується |
|---|---|
| **Дванадцятипала** | **залізо, кальцій, фолат**; частково всі |
| **Порожня** | **вуглеводи, білки, жири, вітаміни**, вода, Na⁺ — **основна** |

## 11. Клінічні поняття

| Стан | Суть |
|---|---|
| **Мальабсорбція** | порушене всмоктування: целіакія, Крон, панкреатична недостатність, лямбліоз |
| **Целіакія** | глютен → атрофія ворсинок: [[Тонка кишка — будова]] |
| **Лактазна недостатність** | молочний цукор не розщеплюється → **осмотична діарея**, здуття, гази (ферментація бактеріями) |
| **Стеаторея** | жирний кал |
| **Синдром короткої кишки** | після резекції (> 100 см — важка) |
| **SIBO** | надмірний ріст бактерій: здуття, діарея, дефіцит B₁₂ |
| **Холера** | токсин → ↑ cAMP → ↑ секреція Cl⁻ → **«рисовий відвар», 20 л/добу**; **оральна регідратація**; **Vibrio cholerae** |
| **Діарея** | осмотична (лактоза, проносні), секреторна (холера), запальна (Крон, інфекції), моторна |
| **Дефіцити** | залізо (дуоденальна резекція), B₁₂ (клубова), Ca, вітамін D, K |
| **Глютен** | целіакія |

## 12. Мнемоніки

- Жир: **емульгування (жовч) → ліполіз (ліпаза + коліпаза) → міцели → ентероцит → хіломікрони → лімфа**.
- Вуглеводи: **ферменти щіткової облямівки → мономери → SGLT1/GLUT5/GLUT2 → ворітна вена**.
- Білки: **пепсин → трипсин/хімотрипсин → пептидази → АК → ворітна вена**.
- **Дванадцятипала — Fe, Ca; клубова — B₁₂ + жовчні кислоти**.
- **Сегментація — змішування, перистальтика — просування**, ММК — **«прибиральниця»**.
