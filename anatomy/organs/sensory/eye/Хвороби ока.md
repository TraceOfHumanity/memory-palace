# Хвороби ока

Це зведення основних очних хвороб. Для кожної наведено суть, ознаки й принципи лікування. Анатомію шукай у файлах про будову й допоміжний апарат ока.

## 1. Симптоми й що вони означають

| Симптом | Можливі причини |
|---|---|
| **Раптова безболісна втрата зору (одне око)** | **оклюзія центральної артерії сітківки (емболія)**, **оклюзія вени**, **відшарування сітківки**, **крововилив у склисте тіло**, **неврит зорового нерва**, **амавроз фугаксу (минуща — сонна артерія)** |
| **Раптова болісна втрата зору** | **гострий напад закритокутової глаукоми**, **неврит**, **гігантоклітинний артеріїт (скроневий)** |
| **Поступова втрата зору** | **катаракта, відкритокутова глаукома, макулярна дегенерація, діабетична ретинопатія** |
| **Червоне око** | **кон'юнктивіт**, **іридоцикліт**, **глаукома**, **кератит**, **склерит**, **субкон'юнктивальний крововилив** |
| **Біль в оці** | **кератит, іридит, глаукома, неврит** |
| **Світлобоязнь** | **кератит, увеїт, мігрень** |
| **«Мушки»** | **деструкція склистого тіла** (**+ спалахи, завіса — відшарування сітківки: невідкладно!**) |
| **Спалахи світла** | **відшарування склистого тіла/сітківки, мігрень** |
| **Двоїння (диплопія)** | **параліч III, IV, VI, міастенія, орбіта, діабет**; **монокулярна — катаракта, астигматизм** |
| **Нічна сліпота** | **дефіцит вітаміну A, пігментний ретиніт** |
| **Ореоли навколо ліхтарів** | **глаукома, катаракта, набряк рогівки** |

## 2. Невідкладні стани в офтальмології

| Стан | Ознаки | Допомога |
|---|---|---|
| **Оклюзія центральної артерії сітківки** | **раптова безболісна сліпота**; **вишнево-червона пляма на блідій сітківці**; **емболія** | **негайно** (до 90 хв): **масаж ока, зниження ВОТ**, пошук **фібриляції/каротидного стенозу**: [[Хвороби судин]] |
| **Гострий закритокутовий напад глаукоми** | **сильний біль, ↓ зір, ореоли, розширена зіниця, «кам'яне» око**, нудота | **ліки для ↓ ВОТ (діамокс, маніт, міотики)**, **лазерна іридотомія** |
| **Відшарування сітківки** | **спалахи, «мушки», «завіса» перед оком** | **термінова хірургія** |
| **Хімічний опік ока** | **біль, ↓ зір** | **негайне промивання водою 15–30 хв** |
| **Проникаюче поранення, стороннє тіло** | | **не тиснути**, не вилучати, захисна пов'язка, **офтальмолог** |
| **Орбітальний целюліт** | **екзофтальм, біль при русі, лихоманка** | антибіотики, МРТ |
| **Гігантоклітинний артеріїт** | **головний біль, біль при жуванні, раптова сліпота** | **стероїди негайно**, біопсія скроневої артерії |
| **Ендофтальміт** | **після операції/травми; біль, гіпопіон** | **інтравітреальні антибіотики** |
| **Гіфема** | **кров у передній камері (травма)** | |

| Хвороба | Суть |
|---|---|
| **Кератит** | **запалення рогівки**: **бактеріальний (лінзи!)**, **вірусний (герпес — дендритна виразка)**, **грибковий**, **акантамебний**; **біль, світлобоязнь, ↓ зір**; **флуоресцеїн** виявляє |
| **Виразка рогівки** | **невідкладно** |

| **Дистрофії** | |
| **Помутніння («більмо»)** | **рубці** |

## 5. Катаракта

**Помутніння кришталика** — **найчастіша причина оборотної сліпоти** у світі.
| Тип | Причина |
|---|---|
| **Вікова (старече) — найчастіша** | **окислення, ущільнення (> 60)** |
| **Вроджена** | **краснуха, галактоземія, генетика** |
| **Вторинна** | **діабет, стероїди, травма, опромінення, увеїт** |

- **Ознаки**: **поступове ↓ зору, «туман», засліплення від світла, ореоли**, **«друге зір» (міопізація)**, **монокулярна диплопія**; **офтальмоскопія — відсутність червоного рефлексу (лейкокорія у дітей — тривожно: ретинобластома!)**.
- **Лікування**: **факоемульсифікація + імплантація інтраокулярної лінзи (ІОЛ)** — **найчастіша операція**, **швидка, ефективна**.

## 6. Глаукома

**Група захворювань з ураженням зорового нерва та втратою поля зору**, зазвичай через **підвищений ВОТ** (> 21 мм рт. ст.).

| Тип | Суть |
|---|---|
| **Первинна відкритокутова (хронічна проста)** | **найчастіша (90%)**; **повільний, безсимптомний; ↑ ВОТ (↓ відтоку трабекулярної сітки)**; **втрата периферичного зору → «тунельний зір»** |
| **Закритокутова** | **закриття кута передньої камери**; **гострий напад (невідкладно)** або хронічна; **гіперметропи, літні жінки** |
| **Нормотензивна** | ВОТ нормальний |
| **Вроджена** | діти: **буфтальм (великі очі), помутніння рогівки, сльозотеча** |
| **Вторинна** | увеїт, стероїди, травма, неоваскуляризація |

- **Діагноз**: **тонометрія (ВОТ)**, **гоніоскопія (кут)**, **офтальмоскопія (збільшена екскавація диска)**, **периметрія (дефекти поля)**, **ОКТ**.
- **Лікування**: **краплі (простагландини, β-блокатори (тимолол), ІКА, α₂-агоністи)**, **лазер (трабекулопластика, іридотомія)**, **операція (трабекулектомія, шунти)**; **скринінг після 40 років**; **втрата зору необоротна**.

## 7. Хвороби сітківки

| Хвороба | Суть |
|---|---|
| **Діабетична ретинопатія** | **мікроаневризми, крововиливи, ексудати, неоваскуляризація (проліферативна)**; **головна причина сліпоти працездатних**; **скринінг щороку; лазерна коагуляція, анти-VEGF**: [[Інсулін, глюкагон і цукровий діабет]] |
| **Гіпертонічна ретинопатія** | **звуження артеріол, симптом «перехресту» (Салюса — Гунна), ватоподібні ексудати, набряк диска** |
| **Вікова макулярна дегенерація (ВМД)** | **центральний зір ↓ (макула)**; **суха (90%; друзи, атрофія)**, **волога (неоваскуляризація; анти-VEGF)**; **«викривлення ліній» (сітка Амслера)**; **> 50 років** |
| **Відшарування сітківки** | **розрив → рідина → відшарування**; **міопія, травма, вік**; **завіса, спалахи**; **хірургія** |
| **Оклюзія центральної артерії** | **невідкладно**, емболія |
| **Оклюзія вени сітківки** | **раптова ↓ зору; «кров і грім» (крововиливи, набряк)**; **гіпертензія, діабет** |
| **Пігментний ретиніт** | **спадкова дегенерація паличок: нічна сліпота → тунельний зір** |
| **Ретинопатія недоношених** | **неоваскуляризація; киснева терапія**; **скринінг недоношених** |
| **Ретинобластома** | **діти; лейкокорія («котяче око»); RB1** |

## 8. Хвороби судинної оболонки

**Увеїт** — запалення **райдужки (іріт), війкового тіла (іридоцикліт), хоріоїдеї**: **біль, світлобоязнь, червоне око («циліарна ін'єкція»), ↓ зір, звужена зіниця**; **причини**: **аутоімунні (анкілозуючий спондиліт HLA-B27, саркоїдоз, ювенільний артрит, хвороба Бехчета)**, **інфекції (туберкульоз, сифіліс, токсоплазмоз, герпес)**; **лікування**: **стероїди, мідріатики**, причини.

## 9. Хвороби зорового нерва і шляху

| Хвороба | Суть |
|---|---|
| **Неврит зорового нерва** | **розсіяний склероз (часто перший прояв)**: **↓ зору, біль при русі ока, дефект кольору, аферентний зіничний дефект**; **МРТ; стероїди** |
| **Застійний диск (папілоедема)** | **↑ ВЧТ**: **двобічний набряк диска, збільшення сліпої плями; зір довго збережений**: [[Оболонки, шлуночки і ліквор]] |
| **Атрофія зорового нерва** | **бліді диски** (глаукома, неврит, компресія, токсини) |
| **Ішемічна нейропатія** | **артеріїт, атеросклероз** |
| **Пухлини** | **гліома зорового нерва (НФ1), менінгіома** |
| **Хіазма** | **аденома гіпофіза → бітемпоральна геміанопсія** |
| **Гомонімна геміанопсія** | **ураження тракту/променистості/кори (інсульт)**: [[Кровопостачання мозку]], [[Провідні шляхи]] |

|---|---|

| **Хіазма (центр)** | **бітемпоральна геміанопсія** |

## 10. Косоокість і амбліопія

**Косоокість** (діти 2–4%); **амбліопія («ледаче око»)** — **функціональне ↓ зору при нормальному оці** (мозок ігнорує): **лікування до 7–8 років** (заклеювання здорового ока, окуляри): [[Око — допоміжний апарат і орбіта]]. **Скринінг дітей** (рефлекс Брюкнера, візус).

## 11. Інші ураження

- **Міопія прогресуюча**: **ускладнення — відшарування сітківки, глаукома, макулопатія**.
- **Хвороба Грейвса (ендокринна офтальмопатія)**: **екзофтальм, ретракція повік, диплопія, ураження рогівки/нерва**: [[Щитоподібна залоза]].
- **Травми**: **контузія, гіфема, розрив, проникаючі, опіки**.
- **Інфекції**: **герпес зостер офтальмікус** (V1; **ризик ураження рогівки, знак Гатчінсона**).
- **Синдром Горнера, параліч III/IV/VI**: [[Черепні нерви]], [[Вегетативна нервова система]].

## 13. Профілактика

**Щорічний огляд (діабет, > 40 років, гіпертензія)**, **захист від УФ (окуляри)**, **відмова від паління**, **вітамін A, лютеїн, омега-3**, **гігієна лінз**, **захист при роботі**, **скринінг дітей**.

## 14. Мнемоніки

- **Раптова безболісна сліпота — артерія сітківки; болісна — закритокутова глаукома**.
- **Катаракта — туман, ореоли; глаукома — тунельний зір (ВОТ)**; **ВМД — центр (макула)**.
- **«Мушки + спалахи + завіса» = відшарування сітківки**.
- **Папілоедема — ↑ ВЧТ; неврит — розсіяний склероз**.
- **Бітемпоральна геміанопсія — хіазма (гіпофіз)**.
- **Хімічний опік — промивати негайно.**
