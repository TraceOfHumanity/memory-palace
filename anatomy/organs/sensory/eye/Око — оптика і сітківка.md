# Око — оптика і сітківка

Око працює як камера. Рогівка й кришталик **заломлюють світло** й фокусують зображення на **сітківці**. Фоторецептори перетворюють світло на нервові сигнали, а сітківка вже обробляє їх. Тут описано оптику ока, будову сітківки, фототрансдукцію, акомодацію, зіничний рефлекс і зоровий шлях.

Пов'язані файли: [[Органи чуття — огляд]], [[Око — будова очного яблука]], [[Око — допоміжний апарат і орбіта]], [[Хвороби ока]], [[Провідні шляхи]], [[Проміжний мозок і базальні ядра]], [[Кора великих півкуль]], [[Черепні нерви]], [[Стовбур мозку]], [[Вегетативна нервова система]], [[Нервовий імпульс і синапс]].

## 1. Оптична система ока

| Структура | Показник заломлення | Сила |
|---|---|---|
| **Рогівка** | 1,376 | **~43 D** |
| **Водяниста волога** | 1,336 | |
| **Кришталик** | 1,386–1,406 | **~15–20 D** (змінна) |
| **Склисте тіло** | 1,336 | |
| **Усе око (без акомодації)** | | **~58–60 D** |

- **Діоптрія (D)** = 1 / фокусна відстань (м).
- **Редукована (схематична) очна модель**: зображення **зменшене і перевернуте** (мозок «перевертає»).
- **Задній фокус** — на **сітківці** у **емметропа** (норма).

### Діафрагма
**Зіниця** регулює **кількість світла** і **глибину різкості**; **менша зіниця → різкість краща**.

## 2. Акомодація

**Акомодація** — зміна **заломлювальної сили кришталика** для **фокусування на близьких предметах**.

| Дія | Далеко | Близько |
|---|---|---|
| **Війковий м'яз** | **розслаблений** | **скорочений** (**парасимпатика III**) |
| **Циннові зв'язки** | **натягнуті** | **розслаблені** |
| **Кришталик** | **сплощений (менше D)** | **випуклий (більше D, +передня поверхня)** |
| Зіниця | | **звужується** |
| Очі | | **сходяться (конвергенція)** |

**Тріада ближнього зору**: **акомодація + конвергенція + міоз**.
- **Найближча точка ясного бачення**: **~10 см (дитина) → 25 см (25 років) → 100 см+ (60 років)**: **пресбіопія**.
- **Діапазон акомодації** — з віком ↓ (твердість кришталика).

## 3. Порушення рефракції

| Стан | Суть | Корекція |
|---|---|---|
| **Емметропія** | норма | — |
| **Міопія (короткозорість)** | **око довге** або сильна рефракція → **фокус перед сітківкою**; **погано вдалину** | **мінусові (розсіювальні) лінзи** |
| **Гіперметропія (далекозорість)** | **око коротке** → **фокус за сітківкою**; **погано зблизька** (молоді акомодують) | **плюсові (збиральні) лінзи** |
| **Астигматизм** | **нерівномірна кривизна рогівки** → **розмитість в усіх відстанях** | **циліндричні лінзи** |
| **Пресбіопія** | **вік 40+**, **ригідний кришталик** | **плюсові для читання** |
| **Анізометропія** | різна рефракція очей | |

**Хірургія**: **ЛАСІК, ФРК** (рогівка), **заміна кришталика (ІОЛ)**: [[Хвороби ока]].

## 4. Сітківка (*retina*): шари

**Світло проходить через усі шари і потрапляє на фоторецептори (інвертована сітківка)**.

Від **склистого тіла** до **хоріоїдеї**:
| Шар | Клітини |
|---|---|
| 1. **Внутрішня межова мембрана** | |
| 2. **Шар нервових волокон** | аксони гангліонарних клітин → **зоровий нерв** |
| 3. **Шар гангліонарних клітин** | **гангліонарні клітини (RGC)** — **вихідні нейрони** |
| 4. **Внутрішній плексиформний шар** | синапси |
| 5. **Внутрішній ядерний шар** | **біполярні, горизонтальні, амакринні** |
| 6. **Зовнішній плексиформний шар** | синапси |
| 7. **Зовнішній ядерний шар** | **ядра фоторецепторів** |
| 8. **Зовнішня межова мембрана** | |
| 9. **Шар паличок і колбочок (фоторецептори)** | **зовнішні сегменти** |
| 10. **Пігментний епітелій** | **меланін** (поглинає розсіяне світло), **фагоцитоз зовнішніх сегментів**, **вітамін A (цикл ретиналю)** |

### Типи нейронів
| Нейрон | Функція |
|---|---|
| **Фоторецептори (палички, колбочки)** | перетворення світла в сигнал |
| **Біполярні** | **пряма передача** (рецептор → гангліонарна) |
| **Гангліонарні** | **аксони → зоровий нерв**; **~1 млн** |
| **Горизонтальні** | **латеральне гальмування** (контраст) |
| **Амакринні** | модуляція (рух, контраст) |
| **Клітини Мюллера (глія)** | опора, живлення |

## 5. Палички і колбочки

| Ознака | **Палички** (*rods*) | **Колбочки** (*cones*) |
|---|---|---|
| **Кількість** | **~120 млн** | **~6–7 млн** |
| **Місце** | **периферія сітківки** | **центр (fovea — тільки колбочки)** |
| **Пігмент** | **родопсин** | **3 типи: S (синій, ~420 нм), M (зелений, ~530), L (червоний, ~560)** |
| **Чутливість** | **висока (1 фотон)** | низька |
| **Функція** | **сутінковий (скотопічний) зір, чорно-білий, периферичний, рух** | **денний (фотопічний) зір, колір, гострота** |
| **Гострота** | низька (конвергенція багатьох на 1 гангліонарну) | **висока (1:1 у ямці)** |
| **Адаптація** | **повільна (20–30 хв)** | швидка (5–10 хв) |
| **Хвороби** | **куряча сліпота** (дефіцит вітаміну A, пігментний ретиніт) | **дальтонізм, макулярна дегенерація** |

### Центральна ямка (fovea centralis)
- **Діаметр ~1,5 мм**; **тільки колбочки**; **найвища гострота (~1 кутова хвилина)**; **гангліонарні клітини зміщені** (прямий шлях світла).
- **Жовта пляма (macula)**: **пігмент лютеїн, зеаксантин** (захист від синього світла).

### Розподіл
Колбочки — **центр**, палички — **периферія (максимум 20° від ямки)**; **диск зорового нерва — сліпа пляма**.

## 6. Фототрансдукція (перетворення світла в сигнал)

### Темрява
- **Фоторецептор деполяризований (−40 мВ)**: **cGMP високий → відкриті cGMP-залежні Na⁺/Ca²⁺-канали («темновий струм»)**.
- **Постійно виділяє глутамат** (гальмівний для **ON-біполярних**).

### Світло
1. **Фотон** → **родопсин (11-цис-ретиналь + опсин)** → **11-цис → всі-транс-ретиналь**: **метародопсин II**.
2. **Трансдуцин (G-білок)** активується.
3. **Фосфодіестераза (ФДЕ6)** → **розщеплює cGMP**.
4. **↓ cGMP → закриття каналів** → **гіперполяризація (−70 мВ)** — **рецептор гіперполяризується на світлі!**
5. **↓ виділення глутамату** → **активація ON-біполярних, гальмування OFF**.

### Відновлення
**Всі-транс-ретиналь → у пігментний епітелій → 11-цис (ізомераза RPE65)**. **Вітамін A (ретинол)** — **попередник ретиналю** → **дефіцит → нічна сліпота, ксерофтальмія**.

### Каскад підсилення
**1 фотон → ~1000 трансдуцинів → ~10⁵ cGMP розщеплених**; **чутливість паличок — до 1 фотона**.

## 7. Адаптація до світла і темряви

| Адаптація | Час | Механізм |
|---|---|---|
| **До світла** | **5–10 хв** (разом ~15) | **розкладання пігментів**, **зменшення зіниці**, **нейрональні** |
| **До темряви** | **~30 хв (до максимуму; колбочки 5–10, потім палички)** | **ресинтез родопсину (вітамін A)**, **розширення зіниці** |

**Крива темнової адаптації**: **двофазна** (колбочки → палички; **злам ~7–10 хв**).

## 8. Колірний зір

**Тривимірна теорія Юнга — Гельмгольца**: **три типи колбочок (S, M, L)**; **колір = співвідношення сигналів**. **Теорія опонентних кольорів (Герінга)**: **червоний–зелений, синій–жовтий, чорний–білий** (на рівні гангліонарних клітин/ЛКТ).

### Порушення
| Стан | Суть |
|---|---|
| **Дальтонізм (червоно-зелений)** | **X-зчеплене (рецесивне)**; **чоловіки ~8%, жінки ~0,5%**; **протанопія (L), дейтеранопія (M)** |
| **Тританопія (синій)** | рідше, аутосомне |
| **Ахроматопсія** | відсутність колбочок |
| **Діагностика** | **таблиці Ішихари, аномалоскоп** |

## 9. Гострота зору і поле зору

### Гострота
- **Здатність розрізняти 2 точки** (**кутова роздільність**) — норма **1 кутова хвилина (1′)** = **візус 1,0 (20/20)**.
- **Таблиця Сівцева — Головіна**, **Снелена**.
- **Макула** — центр; **з віком ↓**.

### Поле зору
| Межі | Значення |
|---|---|
| **Вгору** | ~50° |
| **Вниз** | ~70° |
| **Назовні (скронево)** | ~90° |
| **Досередини (носове)** | ~60° |
| **Бінокулярне** | **~120°** |

**Периметрія** (діагностика глаукоми, пухлин, ураження шляху). **Сліпа пляма** — 15° назовні.
**Бінокулярний зір (стереопсис)**: **два зображення з різним паралаксом → глибина**; **косоокість → амбліопія**.

## 10. Зіничні рефлекси

| Рефлекс | Дуга | Результат |
|---|---|---|
| **Прямий і співдружній на світло** | **сітківка → II → претектальне ядро → Едінгера — Вестфаля (обидва боки) → III → війковий вузол → звужувач** | **міоз обох зіниць** |
| **Акомодація** | кора → III | міоз + конвергенція |
| **Циліоспінальний** | біль/емоція → симпатика → розширювач | **мідріаз** |

### Клініка
| Знахідка | Суть |
|---|---|
| **Аферентний зіничний дефект (Маркуса Ганна)** | **ураження II (оптична нейропатія)**: при освітленні враженого ока зіниці звужуються слабше, ніж при освітленні здорового; при швидкому переведенні світла на уражене око обидві зіниці розширюються |
| **Синдром Горнера** | **міоз + птоз + ангідроз**: [[Вегетативна нервова система]] |
| **Параліч III** | **мідріаз, птоз, розбіжна косоокість**: [[Черепні нерви]] |
| **Зіниця Аргайла Робертсона** | **немає реакції на світло, але є на акомодацію** (**нейросифіліс**, діабет) |
| **«Зіниця Едді»** | тонічна зіниця |
| **Міоз (опіати), мідріаз (атропін, кокаїн)** | **ліки** |

## 11. Зоровий шлях (коротко)

Деталі: [[Провідні шляхи]].
**Сітківка (гангліонарні клітини) → зоровий нерв (II) → хіазма (перехрест носових волокон) → зоровий тракт → бічне колінчасте тіло (ЛКТ, шарувате, 6 шарів) → зорова променистість (петля Мейєра — скронева частина, шлях Баума — тім'яна) → кора 17 (V1, шпорна борозна) → вторинні поля 18, 19 → дорсальний («де») і вентральний («що») потоки**.
- **Ліве поле зору** → **права кора**.
- **Ураження**: **монокулярна сліпота (нерв), бітемпоральна геміанопсія (хіазма), гомонімна (тракт, променистість, кора), квадрантна (Мейєр — скронева петля: «пиріг у небі»)**: [[Хвороби ока]].
- **Рефлекторні гілки**: **претектальні ядра (зіниця)**, **верхні горби (рухи очей, голови)**, **супрахіазматичне ядро (циркадні ритми — ipRGC, меланопсин)**.

## 12. Рухи очей (коротко)

Деталі м'язів — [[Око — допоміжний апарат і орбіта]]. **Типи**: **саккади (швидкі)**, **плавне слідкування**, **вестибуло-очний рефлекс (VOR)**, **оптокінетичний**, **конвергенція**, **фіксаційні мікрорухи**. **Ністагм** — ритмічні рухи.

## 13. Мнемоніки

- **Рогівка ~43 D, кришталик ~15–20 D**; **близько — війковий м'яз скорочений, зв'язки розслаблені, кришталик випуклий**.
- **Міопія — фокус перед сітківкою (мінус); гіперметропія — за сітківкою (плюс)**.
- **Палички — родопсин, ніч, периферія; колбочки — колір, день, центр (fovea)**.
- **Світло → гіперполяризація фоторецептора → ↓ глутамат.**
- **Дальтонізм: X-зчеплений, чоловіки 8%.**
- Зіницю звужує **III (парасимпатика)**; розширює **симпатика**.
