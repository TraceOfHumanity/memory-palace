# Око — будова очного яблука (*oculus*, *bulbus oculi*)

Око — орган зору. **Очне яблуко** лежить в очниці. Воно має три оболонки й прозорі середовища, що заломлюють світло та фокусують його на сітківці.

Пов'язані файли: [[Органи чуття — огляд]], [[Око — оптика і сітківка]], [[Око — допоміжний апарат і орбіта]], [[Хвороби ока]], [[Черепні нерви]], [[Провідні шляхи]], [[Череп — лицевий відділ]], [[Артерії голови і шиї]], [[Вени — верхня порожниста система]], [[Вегетативна нервова система]], [[Кора великих півкуль]].

## 1. Загальні відомості

| Показник | Значення |
|---|---|
| Форма | майже куля |
| **Переднє-задній розмір (довжина осі)** | **~24 мм** (норма 22–25) |
| Горизонтальний / вертикальний | ~23,5 / ~23 мм |
| Маса | **~7–8 г** |
| Об'єм | ~6,5 мл |

### Частини
- **Передній полюс** (рогівка), **задній полюс** (за диском зорового нерва).
- **Зорова вісь** — лінія між полюсами; **екватор**.
- **Передня камера, задня камера, склисте тіло** — порожнини.

## 2. Три оболонки очного яблука

| Оболонка | Склад | Частини |
|---|---|---|
| **Зовнішня (фіброзна)** | щільна сполучна тканина | **склера** (задні 5/6, біла) + **рогівка** (передня 1/6, прозора) |
| **Середня (судинна, увеа)** | судини, пігмент | **райдужка** + **війкове (циліарне) тіло** + **власне судинна оболонка (хоріоїдея)** |
| **Внутрішня** | нервова тканина | **сітківка (ретина)** |

## 3. Фіброзна оболонка

### Склера (*sclera*)
- **Біла непрозора** (~0,5–1 мм), **колаген**.
- **Функція**: **опора, захист**, **прикріплення зовнішніх м'язів ока**.
- **Решітчаста пластинка** — отвір для аксонів зорового нерва.
- **Склерокорнеальний перехід — лімбус**.
- **Венозний синус склери (Шлемів канал)** — **відтік внутрішньоочної рідини**.

### Рогівка (*cornea*)
**Прозорий диск** (діаметр ~11,5 мм, товщина **~0,5 мм**), **без судин**.

| Шар (ззовні всередину) | Особливості |
|---|---|
| **Епітелій** | багатошаровий плоский **неороговілий** (5–6 шарів); **швидка регенерація (за 3–5 днів)**; **дуже багато чутливих закінчень (V1)** |
| **Боуменова мембрана** | |
| **Строма (субстанція)** | **90% товщини**; **колагенові волокна впорядковані** → **прозорість** |
| **Десцеметова мембрана** | |
| **Ендотелій** | **один шар**; **відкачує воду** (підтримує прозорість); **не відновлюється** |

- **Прозорість** — **відсутність судин, правильна організація волокон, дегідратація (насоси ендотелію)**.
- **Сила заломлення ~43 діоптрії (2/3 всієї оптичної сили ока)**.
- **Живлення**: **сльоза, внутрішньоочна рідина, судини лімбу**.
- **Іннервація**: **V1 (війкові нерви)** — **кон'юнктивальний/корнеальний рефлекс (V1 → VII)**: [[Черепні нерви]].
- **Пересадка рогівки (кератопластика)** — найчастіша трансплантація (немає судин → **рідко відторгається**).

## 4. Судинна оболонка (увеальний тракт)

### Райдужка (*iris*)
- **Діафрагма** з **отвором (зіниця)**; **пігмент визначає колір очей** (**меланін**).
- **М'язи**: **звужувач зіниці (*m. sphincter pupillae*)** — **парасимпатика (III, Едінгера — Вестфаля)**; **розширювач зіниці (*m. dilator pupillae*)** — **симпатика (верхній шийний вузол)**: [[Вегетативна нервова система]].
- **Діаметр зіниці**: **2–4 мм (світло), 4–8 мм (темрява)**.
- **Передня поверхня** — **крипти, борозни**; **задня — пігментний епітелій**.

### Війкове (циліарне) тіло (*corpus ciliare*)
| Частина | Функція |
|---|---|
| **Війковий м'яз** (гладкі м'язи) | **акомодація** (парасимпатика III): **скорочення → розслаблення цинових зв'язок → кришталик випуклішає** |
| **Війкові відростки** (~70) | **секреція внутрішньоочної рідини (водянистої вологи)** |
| **Циннові зв'язки** (*zonula ciliaris*) | утримують кришталик |

### Хоріоїдея (*choroidea*)
- **Тонка (0,2–0,3 мм) судинна оболонка**, **багато судин, пігмент**.
- **Живить зовнішні шари сітківки** (**фоторецептори, пігментний епітелій**).
- **Хоріокапіляри**, **мембрана Бруха**.

## 5. Внутрішня оболонка — сітківка (*retina*)

Детально: [[Око — оптика і сітківка]].

| Частина | Опис |
|---|---|
| **Зорова частина** | світлочутлива (**до зубчастої лінії**) |
| **Сліпа частина** | **війкове тіло, райдужка** (без фоторецепторів) |
| **Диск зорового нерва (сліпа пляма)** | **місце виходу аксонів**; **без рецепторів**; **діаметр ~1,5 мм**; **~15° від осі** |
| **Жовта пляма (macula lutea)** | **~5,5 мм** темніша; **центральна ямка (fovea centralis)** — **найвища гострота зору** (**тільки колбочки**) |

**Очне дно** (офтальмоскопія): **диск (світло-рожевий), судини, макула**.

## 6. Камери і прозорі середовища

### Камери
| Камера | Положення | Вміст |
|---|---|---|
| **Передня** | між **рогівкою** і **райдужкою** | **водяниста волога** |
| **Задня** | між **райдужкою** і **кришталиком** | водяниста волога |
| **Склисте тіло** | позаду кришталика | **склисте тіло (гель)** |

**Кут передньої камери** (між рогівкою і райдужкою) — **дренаж** (**трабекулярна сітка → Шлемів канал**).

### Внутрішньоочна рідина (водяниста волога)
| Показник | Значення |
|---|---|
| Об'єм | **~0,25–0,3 мл** |
| Утворення | **війкові відростки** (~2–3 мкл/хв) |
| Шлях | **задня камера → зіниця → передня камера → кут → трабекулярна сітка → Шлемів канал → вени** |
| **Внутрішньоочний тиск (ВОТ)** | **10–21 мм рт. ст.** (норма) |
| Функції | **живить рогівку і кришталик**, **підтримує тиск і форму** |

**Порушення відтоку → ВОТ ↑ → глаукома (ураження зорового нерва)**: [[Хвороби ока]].

### Кришталик (*lens*)
| Показник | Значення |
|---|---|
| Форма | **двоопукла лінза**, діаметр **~9–10 мм**, товщина 3,6–4 мм (↑ з віком) |
| **Сила** | **~15–20 діоптрій** (змінна; **акомодація до +10–14 D**) |
| Будова | **капсула, епітелій (передній), волокна (зростання впродовж життя)**; **без судин і нервів**; **білки кристаліни (прозорість)** |
| Підвіска | **циннові зв'язки** до війкового тіла |
| Старіння | **ущільнення, ↓ еластичність → пресбіопія (40+); помутніння → катаракта** |

### Склисте тіло (*corpus vitreum*)
**Гель (~4 мл, 80% об'єму ока)**: **вода (99%), колаген, гіалуронова кислота**; **прозорий**, **підтримує форму**; **гіалоїдний канал**. **Плаваючі «мушки»** — помутніння; **відшарування склистого тіла (з віком)** → **відшарування сітківки (ризик)**.

## 7. Кровопостачання ока

### Артерії
**Очна артерія** (з **внутрішньої сонної**): [[Артерії голови і шиї]].
| Гілка | Живить |
|---|---|
| **Центральна артерія сітківки** | **внутрішні 2/3 сітківки** (**кінцева — закупорка: раптова сліпота**; **вишнево-червона пляма на макулі**) |
| **Задні короткі війкові** | **хоріоїдея, зовнішні шари сітківки** |
| **Задні довгі війкові** | **війкове тіло, райдужка** |
| **Передні війкові** | **склера, лімбус, райдужка** |
| **Сльозова, м'язові** | сльозова залоза, зовнішні м'язи |

### Вени
**Верхня і нижня очні вени** → **печеристий синус** (+ **лицева вена** — анастомоз: **небезпечний трикутник**): [[Вени — верхня порожниста система]]. **Центральна вена сітківки**. **Вихрові вени** хоріоїдеї.

## 8. Іннервація

| Нерв | Функція |
|---|---|
| **II (зоровий)** | **зір** |
| **III (окоруховий)** | **зіниця (звужувач), акомодація (війковий м'яз), 4 з 6 зовнішніх м'язів, піднімач повіки** |
| **IV, VI** | **верхній косий / бічний прямий м'язи** |
| **V1 (очний)** | **чутливість рогівки, кон'юнктиви, шкіри повік**; **довгі війкові нерви** |
| **Симпатика** (верхній шийний вузол) | **розширювач зіниці**, м'яз Мюллера (повіка) |
| **Парасимпатика** | **війковий вузол → короткі війкові нерви** |

### Війковий вузол (*ganglion ciliare*)
**У задній частині очниці**; **парасимпатичні волокна (III) перемикаються**; **короткі війкові нерви → звужувач зіниці, війковий м'яз**.

## 9. Розвиток ока (коротко)

- **Очні міхурці** (вирости **проміжного мозку**, 4 тиждень) → **очний келих** → **сітківка (2 шари), зоровий нерв** (**тому — частина ЦНС, має оболонки мозку**).
- **Кришталикова плакода (ектодерма)** → **кришталик**.
- **Мезенхіма** → склера, хоріоїдея, рогівка (строма).
- **Вади**: **колобома (щілина), анофтальм, мікрофтальм, катаракта вроджена, аніридія**.

## 10. Мнемоніки

- Оболонки: **фіброзна (склера + рогівка), судинна (райдужка + війкове тіло + хоріоїдея), сітківка**.
- Прозорі середовища: **рогівка → водяниста волога → кришталик → склисте тіло**.
- Шлях рідини: **війкові відростки → задня камера → зіниця → передня камера → кут → Шлемів канал**.
- **Звужувач — парасимпатика (III); розширювач — симпатика.**
- Рогівка — **~43 D (2/3 сили)**, кришталик **~15–20 D (змінна)**.
