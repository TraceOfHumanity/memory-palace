# Нюх і смак (*olfactio*, *gustatio*)

Нюх і смак — хімічні відчуття. Вони допомагають оцінювати їжу, помічати небезпеку (дим, продукти, що зіпсувалися), впливають на апетит, емоції й пам'ять. Разом вони створюють **смак їжі (флейвор)**.

Пов'язані файли: [[Органи чуття — огляд]], [[Ніс — порожнина носа]], [[Ротова порожнина і язик]], [[Черепні нерви]], [[Стовбур мозку]], [[Проміжний мозок і базальні ядра]], [[Кора великих півкуль]], [[Глотка і ковтання]], [[Регуляція травлення]], [[Нервова тканина — нейрон і глія]], [[Хвороби дихальної системи]].

## 1. Нюх (*olfactus*)

### Нюховий епітелій
| Показник | Значення |
|---|---|
| Положення | **склепіння порожнини носа**, **верхня носова раковина і верхня частина перегородки** |
| Площа | **~5 см²** (кожна половина) |
| Колір | **жовтуватий** (пігмент) |
| Епітелій | **псевдобагатошаровий**; **тонкий шар слизу (сироватка)** |

### Клітини
| Клітина | Функція |
|---|---|
| **Нюхові рецепторні нейрони (ОРН)** | **біполярні нейрони**; **кілька мільйонів**; **дендрит — з війками (рецептори)**; **аксон — через решітчасту пластинку**; **живуть 30–60 діб, замінюються (єдині нейрони, що регенерують у дорослого)** |
| **Опорні (сустентакулярні) клітини** | **підтримка, секреція, детоксикація** |
| **Базальні клітини** | **стовбурові** (регенерація) |
| **Боуменові залози** | **секреція слизу** (розчиняє запахові речовини, **запахозв'язувальні білки**) |

### Рецептори і кодування
- **Рецептори запахів** (G-білок-спряжені; **~400 функціональних генів — найбільша родина**; **Нобелівська премія 2004 (Аксель, Бак)**).
- **Одна клітина — один тип рецептора**; **один запах активує комбінацію рецепторів** («комбінаторний код») → **людина розрізняє багато тисяч запахів**.
- **Механізм**: **запахова молекула → рецептор → G_olf → аденілатциклаза → cAMP ↑ → відкриття CNG-каналів (Na⁺, Ca²⁺) → деполяризація → потенціал дії**.
- **Адаптація**: **швидка** (запах перестаєш відчувати за хвилини).

### Шлях нюху
1. **Рецепторні нейрони (I нейрон)** → аксони (**нюхові нитки, fila olfactoria**) → **через решітчасту пластинку**.
2. **Нюхова цибулина** (*bulbus olfactorius*): **клубочки (гломерули)** — **мітральні й чубаті клітини (II нейрон)**; **латеральне гальмування (гранулярні клітини)**.
3. **Нюховий тракт** → **нюховий трикутник → бічна і медіальна смужки**.
4. **Первинна нюхова кора**: **грушоподібна кора, мигдалик, енторинальна кора, нюховий горбок, переднє нюхове ядро**.
5. **Лімбічна система**: **мигдалик, гіпокамп** (**емоції, пам'ять — «ефект Пруста»**).
6. **Неокортекс**: **орбітофронтальна кора** — **усвідомлення, комбінація зі смаком**.

**Нюх — єдиний аналізатор, що не перемикається в таламусі** на шляху до кори (**пряма лімбічна проекція**). **Іпсилатеральний** (не перехрещується в основному).

### Нерв
**I пара — нюховий нерв** (**20 ниток, не один стовбур**): [[Черепні нерви]]. **V1, V2** — **подразнювальні речовини (аміак, ментол — «трійчасте відчуття»)**: **чхання, сльозотеча**.

### Нюхова функція і пороги
- **Поріг дуже низький** (**етилмеркаптан — 1 частина на 10¹⁰**).
- **Сприйняття**: **ортоназальне** (через ніздрі) і **ретроназальне** (з роту вгору: **смак їжі**).
- **Гендерні, вікові відмінності**: **жінки чутливіші; з віком ↓**.
- **Феромони** (у людини — дискусійно; **вомероназальний орган — рудимент**).

### Розлади нюху
| Термін | Значення |
|---|---|
| **Аносмія** | **втрата нюху** |
| **Гіпосмія** | зниження |
| **Паросмія** | **спотворення** |
| **Фантосмія** | **відчуття запаху без джерела** |
| **Гіперосмія** | підвищена |

#### Причини
| Причина | Приклад |
|---|---|
| **Кондуктивні (обструкція носа)** | **риніт, поліпи, викривлення перегородки, пазухи** |
| **Сенсорні** | **вірусні (грип, COVID-19 — поширена причина, часто тимчасова)**, **травма (перелом решітчастої пластинки, зсув нитки)**, **токсини, паління, ліки** |
| **Нейрогенні** | **пухлини (менінгіома нюхової ямки), нейродегенерація (Паркінсона, Альцгеймера — ранній маркер)** |
| **Вроджена (Каллмана)** | **аносмія + гіпогонадотропний гіпогонадизм** |

**Небезпека**: **не відчуває газ, дим, зіпсовану їжу**. **Діагностика**: **тест на запахи (UPSIT)**, **КТ, МРТ, ендоскопія**. **Лікування**: **причини; нюховий тренінг**: [[Ніс — порожнина носа]].

### Нюх і травлення
**Запах їжі → цефалічна фаза (слина, шлунковий сік)**: [[Регуляція травлення]].

## 2. Смак (*gustatio*)

### Смакові бруньки
| Показник | Значення |
|---|---|
| Кількість | **~2000–5000** (діти більше; з віком ↓) |
| Розташування | **язик (сосочки: грибоподібні, листоподібні, жолобоваті)**, **м'яке піднебіння, надгортанник, глотка, гортань** |
| **Будова** | **цибулина**: **50–100 клітин** (**рецепторні — 3 типи**, опорні, базальні) |
| **Смаковий пор** | отвір на поверхні; **мікроворсинки** |
| **Живуть** | **10–14 діб** (оновлюються) |

Деталі: [[Ротова порожнина і язик]].

### П'ять основних смаків
| Смак | Подразник | Рецептор / механізм | Функція |
|---|---|---|---|
| **Солодкий** | **цукри, амінокислоти, штучні підсолоджувачі** | **T1R2 + T1R3 (G-білок: густдуцин)** | **калорії** |
| **Умамі (м'ясний, бульйонний)** | **глутамат, аспартат (і нуклеотиди)** | **T1R1 + T1R3; mGluR** | **білок** |
| **Гіркий** | **алкалоїди, токсини** | **T2R (~25 типів)** (G-білок) | **захист від отрут** |
| **Кислий** | **H⁺ (кислоти)** | **іонні канали (PKD2L1, ENaC; H⁺ входить)** | **стиглість, зіпсованість** |
| **Солоний** | **Na⁺** | **ENaC (Na⁺-канал)** | **електроліти** |

- **«Карта язика»** (солодке — кінчик, гірке — корінь) — **міф**: **усі смаки відчуваються скрізь** (з відмінностями).
- **Додатково**: **жир (CD36), кальцій**; **«кокуми»**; **термічні (V1/V2): гостре (капсаїцин — TRPV1)** — **біль, не смак**.

### Трансдукція
**Хімічна речовина → рецептор → деполяризація (**для кислого і солоного — вхід іонів, для солодкого/гіркого/умамі — G-білок → IP₃ → Ca²⁺ → TRPM5**) → **АТФ (нейромедіатор)** → **аферентні волокна**.

### Нерви смаку
| Ділянка язика | Нерв | Ядро |
|---|---|---|
| **Передні 2/3 язика** | **VII (барабанна струна, chorda tympani)** | **ядро одиночного шляху (рострально)** |
| **Задня 1/3 язика (жолобоваті)** | **IX (язикоглотковий)** | те саме |
| **Надгортанник, глотка** | **X (верхній гортанний)** | те саме |

### Шлях смаку
**Смакова клітина → VII/IX/X (вузол колінця, нижній вузол) → ядро одиночного шляху (довгастий мозок) → переважно іпсилатерально → вентральне задньо-медіальне ядро таламуса (VPM) → первинна смакова кора (острівець і лобова покришка, поле 43) → орбітофронтальна кора (інтеграція з нюхом)**. **Ядро одиночного шляху → гіпоталамус, мигдалик** (**емоції, апетит**); **→ рефлекси (слина, блювання)**.

**Загальна чутливість язика** — **V3 (язиковий нерв)** (дотик, температура, біль): [[Черепні нерви]].

### Властивості смаку
- **Поріг**: **гіркий найнижчий** (захист), **солодкий найвищий**.
- **Адаптація**: **швидка (хвилини)**.
- **Контраст** (солодке підсилює кисле).
- **Температура** впливає (холодне ↓ солодке).
- **Слина** розчиняє, транспортує; **сухий рот — ↓ смаку**.
- **Генетика**: **PTC/PROP (гіркота) — «супертастери»**.

### Нюх + смак = флейвор
**Більшість «смаку» — це нюх (ретроназально)**: **при закладеному носі їжа «безсмакова»**; **ціле відчуття збирається в орбітофронтальній корі**.

### Розлади смаку
| Термін | Значення |
|---|---|
| **Агевзія** | втрата смаку |
| **Гіпогевзія** | зниження |
| **Дисгевзія** | спотворення (металевий смак) |
| **Фантогевзія** | |

#### Причини
**Параліч VII (Белла) — втрата смаку передніх 2/3**; **ушкодження барабанної струни (отит, операція)**; **Рамсей Хант**; **ліки (металевий смак: метронідазол, ліки)**; **COVID-19**; **хіміотерапія**; **дефіцит цинку**; **ксеростомія**; **паління**; **вік**; **неврологічні (острівець)**; **кандидоз язика**.

**Діагностика**: **електрогустометрія, тести розчинами**. **Вогнищеві симптоми VII**: **параліч обличчя + втрата смаку + гіперакузія + ↓ сльозопродукції (залежить від рівня)**.

## 3. Хеморецепція інших типів (коротко)
| Тип | Де | Реагує |
|---|---|---|
| **Каротидні і аортальні тільця** | судини | **O₂ ↓, CO₂ ↑, H⁺**: [[Дихання — регуляція]] |
| **Центральні хеморецептори** | довгастий мозок | **CO₂/H⁺** |
| **Area postrema** | дно IV шлуночка | **токсини → блювання** |
| **Осморецептори** | гіпоталамус | **осмолярність → АДГ, спрага** |

## 4. Розвиток
- **Нюхова плакода (ектодерма)** → **нюховий епітелій; нюхова цибулина — вирост переднього мозку**.
- **Смакові бруньки — з ентодерми (епітелій язика) і ектодерми**; **іннервуються нервами 1–3 арок**.

## 5. Мнемоніки
- **Нюх: I нерв → нюхова цибулина → кора (без таламуса) → мигдалик, гіпокамп.**
- **Смак: передні 2/3 — VII, задня 1/3 — IX, глотка — X → ядро одиночного шляху → VPM → острівець.**
- **5 смаків: солодкий, кислий, солоний, гіркий, умамі.**
- **Нюхові нейрони регенерують (30–60 діб); смакові клітини 10–14 діб.**
- **Флейвор = смак + ретроназальний нюх.**
