# Шкірна чутливість і біль (соматосенсорна система)

Соматосенсорна система сприймає **дотик, тиск, вібрацію, температуру, біль** та **положення тіла**. Рецептори розташовані в шкірі, м'язах, суглобах і внутрішніх органах. Сигнали проходять спинним мозком і таламусом до **соматосенсорної кори**.

### Соматосенсорна кора
- **S1 (постцентральна звивина: поля 3, 1, 2)** — **сенсорний гомункулус**: [[Кора великих півкуль]].
- **S2** — **глибоко в бічній борозні; складна інтеграція**.
- **Асоціативна тім'яна (5, 7)** — **стереогноз, схема тіла**.
- **Ураження**: **втрата дискримінації, астереогноз, гемінеглект**.

## 5. Біль (*dolor*)

**Біль** — **неприємне сенсорне й емоційне відчуття**, пов'язане з реальним або потенційним пошкодженням тканин (визначення IASP). **Захисна функція**; **хворобливий — коли хронічний**.

### Ноцицептори
| Тип | Подразник |
|---|---|
| **Механічні (Aδ)** | **сильний тиск, поріз, укол** |
| **Термічні (Aδ, C)** | **> 45 °C, < 5 °C** |
| **Хемічні/полімодальні (C)** | **брадикінін, гістамін, простагландини, H⁺, АТФ, калій, субстанція P** |
| **«Сплячі» (мовчазні)** | **активуються при запаленні** |

**Медіатори запалення (периферична сенситизація)**: **брадикінін, простагландини E₂ (НПЗП блокують ЦОГ), цитокіни, NGF** → **↓ порогу** (**гіпералгезія, алодинія**).
**Нейропептиди**: **субстанція P, CGRP** → **нейрогенне запалення**.

### Шлях болю
1. **Ноцицептор** (Aδ, C) → **спинномозковий вузол (I нейрон)** → **задній ріг (Лісауер → I, II (желатинозна субстанція))**.
2. **II нейрон**: **ноцицептивно-специфічні і широкого динамічного діапазону (WDR) нейрони** → **перехрещується через білу спайку** → **бічний спинно-таламічний шлях**.
3. **Таламус**: **VPL (латеральна система: де, наскільки)**; **медіальні ядра (медіальна система: емоційний компонент)**.
4. **Кора**: **S1/S2 (локалізація, інтенсивність)**; **передня поясна, острівець (емоційний компонент, страждання)**; **префронтальна (оцінка)**.
- **Спинно-ретикулярний, спинно-мезенцефалічний** — **збудження, емоції, модуляція**.

### Нейромедіатори болю
**Глутамат, субстанція P, CGRP (у заднього рогу)**; **NMDA-рецептори (wind-up, центральна сенситизація)**.

### Теорія воріт (Мелзак — Волл, 1965)
**Сигнали Aβ (дотик)** **активують гальмівні вставні нейрони** → **«закривають ворота»** для **Aδ/C (біль)**. **Приклад**: **розтирання забитої ділянки зменшує біль**; **ТЕНС**.

### Низхідна модуляція болю (ендогенна аналгезія)
**Періакведуктальна сіра речовина (PAG) → ядра шва (серотонін) → задній ріг (енкефаліни → гальмування)**; **блакитна пляма (норадреналін)**. **Ендорфіни, енкефаліни, динорфіни** (**опіатні рецептори μ, δ, κ**). **Опіоїди (морфін) діють тут**. **Плацебо, стрес, увага** ↑ аналгезія. Деталі: [[Стовбур мозку]].

## 6. Типи болю

### За тривалістю
| Тип | Характеристика |
|---|---|
| **Гострий** | **< 3 місяців**; **причина зрозуміла**; **захисний** |
| **Хронічний** | **> 3 місяців**; **патологічний**; **депресія, безсоння** |

### За механізмом
| Тип | Суть | Приклад |
|---|---|---|
| **Ноцицептивний (соматичний)** | **шкіра, м'язи, кістки; гострий, добре локалізований** | **поріз, перелом** |
| **Вісцеральний** | **внутрішні органи; тупий, нечіткий, іррадіація, вегетативні (нудота, піт)** | **коліка, інфаркт** |
| **Нейропатичний** | **ураження нервової системи; пекучий, стріляючий, «електричний струм»; алодинія** | **діабетична нейропатія, невралгія трійчастого нерва, оперізувальний герпес, пошкодження нерва** |
| **Ноціпластичний/дисфункціональний (центральна сенситизація)** | **фіброміалгія, хронічний біль спини** | |

### Вісцеральний біль і іррадіація
**Конвергенція вісцеральних і шкірних аферентів на одних нейронах заднього рогу** → **відбитий біль** (**мозок «приписує» шкірі**).
| Орган | Зона болю |
|---|---|
| **Серце** | **центр грудей, ліва рука, плече, щелепа (C8–T5)** |
| **Діафрагма, жовчний міхур** | **право плече / лопатка (C3–C5; T7–T9)** |
| **Апендикс** | **навколо пупка → права клубова ямка** |
| **Нирка/сечовід** | **поперек → пахвина (T10–L2)** |
| **Підшлункова залоза** | **спина (T10)** |

Деталі: [[Серце — іннервація]], [[Вегетативна нервова система]].

### Особливі форми
| Стан | Суть |
|---|---|
| **Невралгія** | **біль по ходу нерва**: **трійчастого (V2, V3; «електрошок»)**, **потиличного**, **міжребрового** |
| **Каузалгія / комплексний регіонарний больовий синдром (КРБС)** | **інтенсивний біль, набряк, вазомоторні зміни після травми** |
| **Фантомний біль** | **біль в ампутованій кінцівці (центральна реорганізація)** |
| **Радикулярний біль (радикулопатія)** | **грижа диска → біль по дерматому**: [[Спинномозкові нерви і сплетення]] |
| **Головний біль** | **мігрень, напруження, кластерний; оболонки (V, X, C1–C3)**; **мозок біль не відчуває** |
| **Фіброміалгія** | **дифузний біль, втома, чутливі точки** |
| **Алодинія** | **біль від непорушуючого стимулу (дотик)** |
| **Гіпералгезія** | **посилений біль на больовий стимул** |
| **Гіперпатія** | **неприємна, затримана, вибухова реакція** |

## 7. Оцінка болю

**Шкала VAS/NRS (0–10)**, **вербальні шкали**, **для дітей — «обличчя» (Вонга — Бейкера)**, **опитувальники (DN4 — нейропатичний)**.
**Характеристики болю (схема PQRST)**: **локалізація, початок, характер, тяжкість, провокація/полегшення, іррадіація**.

## 8. Лікування болю (принципи)

| Група | Приклад | Механізм |
|---|---|---|
| **НПЗП** | **ібупрофен, диклофенак, кеторолак** | **↓ ЦОГ → ↓ простагландини (периферія)**; **ризик: шлунок, нирки, серце** |
| **Парацетамол** | | **ймовірно центральна**; **гепатотоксичний у надлишку** |
| **Опіоїди** | **морфін, фентаніл, трамадол, кодеїн** | **μ-рецептори (PAG, задній ріг)**; **дихальна депресія, запор, нудота, залежність** |
| **Ад'юванти (нейропатичний)** | **габапентин, прегабалін (Ca²⁺-канали α₂δ); амітриптилін, дулоксетин (SNRI); карбамазепін (невралгія V)** | |
| **Місцеві анестетики** | **лідокаїн, бупівакаїн** | **блок Na⁺-каналів**: [[Нервовий імпульс і синапс]] |
| **Капсаїцин (місцево)** | | **десенситизація TRPV1** |
| **Немедикаментозні** | **ТЕНС, фізіотерапія, КПТ, акупунктура, масаж** | **теорія воріт, модуляція** |
| **Блокади/інтервенції** | **епідуральна, нервові блокади, радіочастота, нейромодуляція** | |
| **Хірургія** | **декомпресія (невралгія V — мікросудинна декомпресія)** | |

**Сходинки ВООЗ**: **1) неопіоїдні → 2) слабкі опіоїди → 3) сильні опіоїди** (+ ад'юванти).

## 10. Мнемоніки

- **Рецептори: Мейснер — легкий дотик (швидкий), Меркель — форма (повільний), Пачіні — вібрація, Руффіні — розтяг.**
- **Біль: Aδ — швидкий гострий (мієлінізовані); C — повільний тупий.**
- **Шляхи: тонкий дотик/вібрація — задні канатики (перехрест у довгастому); біль/температура — спинно-таламічний (перехрест на рівні входу).**
- **Теорія воріт: Aβ закривають ворота для болю.**
- **Опіоїди → μ-рецептори; НПЗП → ЦОГ.**
- **Мозок не болить; біль — від оболонок і судин.**
