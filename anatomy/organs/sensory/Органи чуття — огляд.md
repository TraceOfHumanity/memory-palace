# Органи чуття — огляд (*organa sensuum*)

Органи чуття сприймають подразнення з довкілля й внутрішнього середовища. Вони перетворюють їх на нервові імпульси, які мозок розпізнає як зір, слух, нюх, смак, дотик, біль та положення тіла. Одне сприйняття забезпечує **аналізатор** (за Павловим): рецептор, провідний шлях і кіркова зона.

## 1. Аналізатор: три ланки

| Ланка | Функція |
|---|---|
| **Периферична (рецептор)** | сприймає подразник, перетворює його енергію на **рецепторний потенціал** (трансдукція) |
| **Провідникова** | **нерв, шлях, ядра таламуса** — передає сигнал |
| **Центральна (кіркова)** | **зона кори** — розпізнає, створює відчуття |

Шляхи й кіркові зони: [[Провідні шляхи]], [[Кора великих півкуль]].

## 2. Класифікація рецепторів

### За модальністю (який подразник)
| Тип | Подразник | Приклади |
|---|---|---|
| **Фоторецептори** | світло | палички, колбочки |
| **Механорецептори** | деформація, тиск, вібрація, розтяг | дотик, слух, рівновага, пропріорецептори, барорецептори |
| **Хеморецептори** | хімічні речовини | нюх, смак, О₂/CO₂ (каротидне тільце) |
| **Терморецептори** | температура | холодові, теплові |
| **Ноцицептори** | пошкодження | біль |
| **Осморецептори** | осмолярність | гіпоталамус |

### За положенням
| Тип | Де | Приклад |
|---|---|---|
| **Екстерорецептори** | поверхня тіла, органи чуття | шкіра, око, вухо |
| **Інтерорецептори (вісцеро-)** | внутрішні органи | барорецептори, хеморецептори |
| **Пропріорецептори** | м'язи, сухожилки, суглоби | м'язове веретено, орган Гольджі |

### За будовою
| Тип | Опис | Приклади |
|---|---|---|
| **Первинно-чутливі** | **нейрон-рецептор** сам генерує потенціал дії | нюхові клітини, больові та дотикові закінчення |
| **Вторинно-чутливі** | **окрема рецепторна клітина** + синапс на нейроні | смакові, слухові, вестибулярні клітини; **сітківка (фоторецептори)** |

## 3. Властивості рецепторів

| Властивість | Опис |
|---|---|
| **Специфічність (адекватний подразник)** | кожен рецептор найчутливіший до **свого** подразника (закон «специфічної енергії» Мюллера: відчуття визначає **шлях**, а не подразник; удар по оку → «іскри») |
| **Поріг** | **мінімальна сила**, що викликає відчуття |
| **Адаптація** | зниження чутливості при **тривалій дії**: **швидко адаптуються** (дотик, нюх, **фазичні**) і **повільно** (біль, **тонічні**: розтяг, положення) |
| **Закон Вебера — Фехнера** | відчуття **пропорційне логарифму** сили подразника: **ΔI / I = const** |
| **Кодування інтенсивності** | **частота імпульсів**, **кількість активних рецепторів** |
| **Кодування модальності** | **«мічена лінія»** (шлях → зона кори) |
| **Рецептивне поле** | ділянка, з якої нейрон отримує сигнал (**мале — висока гострота**, пальці; **велике** — спина) |
| **Латеральне гальмування** | підсилює контраст (сітківка, шкіра) |

### Рецепторний потенціал
Подразник → **відкриття іонних каналів** → **деполяризація (або гіперполяризація — фоторецептори)** → **градуальний** (не «все або нічого») → **потенціал дії** в аферентному нейроні: [[Нервовий імпульс і синапс]].

## 4. Огляд відчуттів

| Відчуття | Орган | Нерв | Шлях / кірка |
|---|---|---|---|
| **Зір** | око (сітківка) | **II** | **бічне колінчасте тіло → кора 17 (V1)** |
| **Слух** | вухо (завитка) | **VIII** | **нижні горби → медіальне колінчасте тіло → 41, 42** |
| **Рівновага** | вухо (присінок, канали) | **VIII** | **вестибулярні ядра → мозочок, ядра очних м'язів** |
| **Нюх** | нюховий епітелій | **I** | **нюхова цибулина → нюхова кора (без таламуса)** |
| **Смак** | смакові бруньки | **VII, IX, X** | **ядро одиночного шляху → таламус (VPM) → острівець, кришка** |
| **Дотик, біль, температура** | шкіра, слизові | **V, спинномозкові** | **спинно-таламічний, медіальна петля → S1** |
| **Пропріорецепція** | м'язи, суглоби | **спинномозкові** | **задні канатики, спинно-мозочкові** |
| **Вісцеральна чутливість** | органи | **X, симпатичні** | |

## 5. Розвиток органів чуття

| Орган | Походження |
|---|---|
| **Око** | **вирости проміжного мозку** (очні міхури → сітківка, зоровий нерв); **ектодерма** (кришталик, рогівкова епітелій); **мезенхіма** (склера, судинна оболонка) |
| **Внутрішнє вухо** | **слухова плакода (ектодерма)** → слуховий міхурець → перетинчастий лабіринт |
| **Середнє вухо** | **1-а глоткова кишеня** (ентодерма; слухова труба); **слухові кісточки — 1-а і 2-а глоткові дуги (нервовий гребінь)** |
| **Зовнішнє вухо** | **1-а глоткова борозна** (зовнішній слуховий прохід) + горбки 1-ї і 2-ї дуг (вушна раковина) |
| **Нюховий епітелій** | **нюхова плакода** |
| **Смакові бруньки** | **ентодерма, ектодерма** |

## 7. Мнемоніки

- **Аналізатор: рецептор → шлях → кора.**
- **Адаптація: швидка (дотик, нюх), повільна (біль, розтяг).**
- **Нюх — єдиний без перемикання в таламусі.**
- **Фоторецептори — гіперполяризуються на світлі.**
- **Зір II, слух і рівновага VIII, нюх I, смак VII–IX–X.**
