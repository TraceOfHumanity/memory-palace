# Слух і рівновага

Слух — сприйняття звуку. Рівновага — відчуття положення й руху голови та керування позою й рухами очей. Обидва процеси починаються у внутрішньому вусі, а потім сигнали проходять стовбуром мозку до кори.

## 1. Звук

| Характеристика | Фізика | Відчуття |
|---|---|---|
| **Частота (Гц)** | кількість коливань за секунду | **висота тону** |
| **Амплітуда (інтенсивність, дБ)** | сила коливання | **гучність** |
| **Спектр (гармоніки)** | суміш частот | **тембр** |

### Діапазон людини
| Показник | Значення |
|---|---|
| **Частоти** | **20–20 000 Гц** (мова: **300–3400 Гц**; найчутливіше **1000–4000 Гц**) |
| **Інфразвук / ультразвук** | < 20 Гц / > 20 кГц |
| **З віком** | **пресбіакузія** — втрата **високих частот** |

### Децибел (дБ)
**Логарифмічна шкала**: **дБ = 10 log (I/I₀)**; **+10 дБ = ×10 інтенсивність**; **+3 дБ ≈ ×2**.
| Звук | дБ |
|---|---|
| **Поріг чутності** | **0** (SPL) |
| **Шепіт** | ~30 |
| **Розмова** | ~60 |
| **Рух міста / пилосос** | 70–80 |
| **Шум, що пошкоджує (> 8 год)** | **> 85** |
| **Концерт, навушники на максимум** | **100–110** |
| **Больовий поріг** | **120–140** (реактивний двигун) |

## 2. Шлях звуку (кондукція)

1. **Звукові хвилі** → **вушна раковина** → **зовнішній слуховий прохід**.
2. **Барабанна перетинка** вібрує.
3. **Кісточки (молоточок → коваделко → стремінце)** — **підсилення ~22×**.
4. **Стремінце штовхає овальне вікно** → **хвиля в перилімфі присінкових сходів**.
5. **Базилярна мембрана** — **бігуча хвиля**; **кругле вікно** розтягується (зняття тиску).
6. **Кортієв орган** → **трансдукція** → **VIII нерв**.

Деталі: [[Вухо — зовнішнє і середнє]], [[Вухо — внутрішнє]].

### Повітряна і кісткова провідність
| Тип | Шлях |
|---|---|
| **Повітряна** | повітря → перетинка → кісточки → завитка (**основна**) |
| **Кісткова** | **вібрація кісток черепа → завитка** (**обходить середнє вухо**); **власний голос звучить «глибше»**; **діагностика** |

## 3. Трансдукція в завитці

### Бігуча хвиля (Бекеші)
**Хвиля, що рухається вздовж базилярної мембрани** від основи до верхівки; **максимум амплітуди** — **в точці, що залежить від частоти**.
- **Висока частота** → **максимум біля основи**.
- **Низька** → **біля верхівки**.
**Кодування частоти**: **тонотопія (місце)** + **для низьких — тимчасове (синхронізація імпульсів з фазою)**.

### Механізм
Бігуча хвиля → **відхилення стереоцилій ВВК** → **K⁺ входить (ендолімфа +80 мВ)** → **деполяризація** → **Ca²⁺** → **глутамат** → **спіральний гангліон → VIII**.
**ЗВК** — **«активний підсилювач»** (престин): **до +40–60 дБ чутливості і гострота настройки**. **Отоакустична емісія (ОАЕ)** — **ЗВК виробляють звук**; **скринінг новонароджених**.

### Кодування інтенсивності
**Частота імпульсів**, **кількість активованих клітин (ВВК з різними порогами)**.

## 4. Слуховий шлях

Деталі: [[Провідні шляхи]].
**Спіральний вузол (I нейрон) → VIII → завиткові ядра (дорсальне і вентральне; довгастий/міст; II нейрон) → верхнє оливне ядро (перші бінауральні) → бічна петля → нижній горб (середній мозок) → медіальне колінчасте тіло (таламус) → слухова променистість → первинна слухова кора (41, 42; поперечні звивини Гешля; верхня скронева)**.
- **Двобічне представництво** (більшість волокон перехрещується, частина — ні): **одностороннє ураження кори — без глухоти**.
- **Тонотопія** зберігається в кожному відділі.
- **Слухові рефлекси**: **нижні горби → верхні горби (поворот голови до звуку)**, **стременевий рефлекс**.
- **Зона Верніке (22)** — **розуміння мови**: [[Кора великих півкуль]].

### Локалізація звуку
| Сигнал | Механізм |
|---|---|
| **Горизонтальна площина** | **міжвушна різниця часу (ITD, низькі частоти)** і **різниця інтенсивності (ILD, високі)** — **верхнє оливне ядро** |
| **Вертикальна** | **вушна раковина (спектральні відбиття)** |

## 5. Тести слуху

| Тест | Принцип |
|---|---|
| **Шепітна мова** | відстань 6 м |
| **Камертонові проби** | **Рінне**, **Вебера** |
| **Аудіометрія тональна** | **порогова: повітряна і кісткова (0–120 дБ), 125–8000 Гц** |
| **Мовна аудіометрія** | розбірливість |
| **Тимпанометрія** | **рухливість перетинки, тиск у середньому вусі** |
| **Акустичний рефлекс** | **VII, VIII** |
| **Отоакустична емісія (ОАЕ)** | **ЗВК; скринінг новонароджених** |
| **Слухові викликані потенціали ствола (ABR)** | **стовбур; невринома** |

### Проби Рінне й Вебера (камертон 512 Гц)
| Проба | Норма | Кондуктивна глухота | Нейросенсорна |
|---|---|---|---|
| **Рінне** (повітря vs кістка) | **повітряна > кісткова (позитивна)** | **кістка > повітря (негативна)** | **повітряна > кісткова (обидві ↓)** |
| **Вебера** (камертон на тім'я) | **посередині** | **в хворе вухо** (латералізація) | **в здорове вухо** |

### Аудіограма: що показує
| Тип | Аудіограма |
|---|---|
| **Норма** | **0–20 дБ** (до 25) |
| **Кондуктивна** | **повітряна ↓, кісткова норма (air-bone gap)** |
| **Нейросенсорна** | **обидві ↓ однаково** |
| **Змішана** | обидві ↓ з розривом |
| **Шумова (4 кГц «виїмка»)** | **«нотч» на 4 кГц** |

**Ступені**: **легка 26–40, помірна 41–60, тяжка 61–80, глибока > 80 дБ**.

## 7. Рівновага: вестибулярна система

### Сигнали (три джерела)
| Система | Що відчуває |
|---|---|
| **Вестибулярна (лабіринт)** | **положення голови, прискорення** |
| **Зорова** | **навколишній світ, положення** |
| **Соматосенсорна (пропріорецепція)** | **положення тіла, опора** |

**Мозок інтегрує всі три**; **конфлікт сигналів** → **запаморочення, нудота (укачування)**.

### Лабіринт (нагадування)
- **Отолітові органи (маточка, мішечок)** — **лінійні прискорення, нахил**.
- **Напівколові канали** — **кутові прискорення (обертання)**: [[Вухо — внутрішнє]].

### Вестибулярні шляхи
**Присінковий вузол → VIII → вестибулярні ядра (4) → :**
| Шлях | Мета | Функція |
|---|---|---|
| **Вестибуло-очний** | **ядра III, IV, VI** (через MLF) | **вестибуло-очний рефлекс (VOR)**: **утримання погляду** |
| **Вестибуло-спінальний (латеральний і медіальний)** | **спинний мозок** (розгиначі) | **постуральні рефлекси, тонус** |
| **Вестибуло-мозочковий** | **флокуло-вузликова частка мозочка** | **корекція** |
| **Вестибуло-таламо-кірковий** | **таламус → кора (острівцева, тім'яна)** | **усвідомлення** |
| **Вестибуло-вегетативний** | **блювотний центр** | **нудота** |

Деталі: [[Стовбур мозку]], [[Мозочок]].

### Вестибуло-очний рефлекс (VOR)
**Поворот голови вправо → ліві й праві очі повертаються вліво (з швидкістю = швидкість голови)** → **зображення стабільне на сітківці**. **Затримка ~7 мс (швидкий!)**.
- **Калорична проба** (холодна/тепла вода у вусі): **ністагм** — **COWS: Cold Opposite, Warm Same** (швидка фаза).
- **Ністагм**: **повільна фаза (вестибулярна), швидка (корекція)**; **названо за швидкою фазою**.

### Постуральні рефлекси
**Випрямлення голови, тіла**; **тонічні рефлекси шиї**; **стартові (Moro) у новонароджених**.

### Рух і положення
- **Нахил голови вбік → отолітова відповідь → тонус м'язів тулуба**.
- **Падіння (різка ротація) → рефлекс «парашута»**.

## 8. Запаморочення (вертиго)

**Вертиго** — **ілюзія руху (обертання)**; **не плутати з «передзомлінням» (presyncope) і нестійкістю**.

### Периферична vs центральна
| Ознака | **Периферичне (лабіринт, VIII)** | **Центральне (стовбур, мозочок)** |
|---|---|---|
| **Інтенсивність** | **сильне** | помірне |
| **Нудота/блювання** | **виражені** | менше |
| **Ністагм** | **односпрямований, горизонтально-ротаторний, пригнічується фіксацією погляду** | **вертикальний, різнонаправлений, не пригнічується фіксацією** |
| **Слух** | **часто порушений (↓, шум)** | **рідко** |
| **Неврологічні ознаки (диплопія, дизартрія, парез)** | **немає** | **є** |
| **Тест HINTS** | **HINTS «периферичний»** | **«центральний»** |
| **Причини** | **ДППЗ, вестибулярний неврит, Меньєр, лабіринтит, невринома** | **інсульт, РС, пухлина, мігрень** |

### Основні захворювання
| Хвороба | Суть |
|---|---|
| **ДППЗ (BPPV)** | **найчастіша; «позиційне»**: **секунди при зміні положення (поворот у ліжку)**; **маневр Дікса — Холпайка**, **лікування — Епплі** |
| **Вестибулярний неврит / лабіринтит** | вірусний; гострий вертиго, що триває дні; слух збережений (неврит); стероїди |
| **Хвороба Меньєра** | **ендолімфатичний гідропс**: **нападами: вертиго (20 хв–годин), шум, ↓ слуху (низькі), відчуття повноти**; **сіль ↓, діуретики** |
| **Невринома VIII (вестибулярна шваннома)** | **односторонній ↓ слуху, шум, нестійкість**: [[Стовбур мозку]] |
| **Інсульт у задній циркуляції** | **вертиго + інші ознаки (диплопія, атаксія)**: [[Кровопостачання мозку]] |
| **Мігрень вестибулярна** | |
| **Ортостатична гіпотензія / серцеві причини** | передзомління |
| **Ототоксичність (аміноглікозиди)** | **двобічна втрата — осцилопсія** |

## 9. Укачування

**Конфлікт** вестибулярної і зорової систем → **нудота, блідість, пітливість, слинотеча, блювання**; **центр блювання (area postrema)**; **ліки**: **скополамін, антигістамінні (дименгідринат)**: [[Вегетативна нервова система]].

## 10. Космічна фізіологія
У невагомості **отоліти не відчувають сили тяжіння** → **«космічна хвороба»** (адаптація 2–3 дні).

## 11. Мнемоніки

- **Слух: звук → перетинка → кісточки (×22) → овальне вікно → перилімфа → базилярна мембрана → кортієв орган → VIII → завиткові ядра → верхнє оливне → бічна петля → нижній горб → МКТ → 41, 42**.
- **Високі частоти — біля основи; низькі — біля верхівки.**
- **Рінне: повітря > кістка в нормі; Вебер: в хворе вухо — кондуктивна, в здорове — нейросенсорна.**
- **Рівновага: лабіринт + зір + пропріорецепція; VOR утримує погляд.**
- **COWS: холодна — швидка фаза в протилежний бік, тепла — в той же.**
- **Периферичний вертиго — сильний, з нудотою, ністагм односпрямований; центральний — інші неврологічні ознаки.**
