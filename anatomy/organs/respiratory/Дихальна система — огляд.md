# Дихальна система — огляд (*systema respiratorium*)

Дихальна система забезпечує **газообмін**: вона доставляє в кров кисень (O₂) і виводить вуглекислий газ (CO₂). Вона також зігріває й очищає повітря, бере участь у голосоутворенні, нюху, регуляції pH і захисті.

## 1. Функції

| Функція | Зміст |
|---|---|
| **Газообмін** | поглинання O₂ і виведення CO₂ в альвеолах |
| **Кондиціювання повітря** | зігрівання, зволоження, очищення в носі й бронхах |
| **Голосоутворення** | гортань, голосові складки |
| **Нюх** | нюховий епітелій верхньої носової раковини |
| **Кислотно-лужний баланс** | видалення CO₂ регулює pH крові |
| **Захист** | війчастий епітелій, слиз, макрофаги, імунні клітини |
| **Метаболізм** | ангіотензинперетворювальний фермент (АПФ) у ендотелії легень, фільтр дрібних тромбів |
| **Терморегуляція, водний баланс** | випаровування води (~400–500 мл/добу) |

## 2. Склад: дихальні шляхи і дихальний відділ

| Відділ | Органи | Функція |
|---|---|---|
| **Верхні дихальні шляхи** | порожнина носа, навколоносові пазухи, носоглотка, ротоглотка | проведення, кондиціювання |
| **Нижні дихальні шляхи** | гортань, трахея, бронхи | проведення повітря |
| **Дихальний відділ (респіраторна зона)** | респіраторні бронхіоли, альвеолярні ходи, альвеолярні мішечки, **альвеоли** | газообмін |

- **Провідна зона**: від носа до термінальних бронхіол. Газообмін не відбувається. Її об'єм — **анатомічний мертвий простір** (~150 мл).
- **Респіраторна зона**: від респіраторних бронхіол. Тут газообмін.

Гортань, трахея й бронхи мають **хрящовий каркас**, що не дає їм спадатись. У стінці глотки перетинаються дихальний і травний шляхи.

## 3. Шлях повітря

Ніздрі → **переддвер'я носа** → порожнина носа → хоани → **носоглотка** → ротоглотка → гортаноглотка → **гортань** (голосова щілина) → **трахея** → **головні бронхи** → часткові (лобарні) → сегментарні → ... → термінальні бронхіоли → **респіраторні бронхіоли** → **альвеолярні ходи** → **альвеоли**.

Ротове дихання обходить носовий шлях (повітря не зігрівається й не очищується).

## 5. Основні органи і їхні нерви

| Орган | Нерви | Особливість |
|---|---|---|
| **Ніс** | **I** (нюх), **V1, V2** (чутливість), судинна симпатика | нюх, кондиціювання |
| **Гортань** | **X**: верхній гортанний (чутливий вище голосових складок, перснещитоподібний), нижній (поворотний) гортанний (рухові, чутливий нижче) | голос |
| **Трахея, бронхи, легені** | **X** (парасимпатика: звуження бронхів, секреція), **симпатика T2–T7** (розширення) | рефлекси |
| **Діафрагма** | **діафрагмовий нерв C3–C5** | головний м'яз вдиху |
| **Міжреброві м'язи** | міжреброві нерви | вдих/видих |

## 6. Розвиток (коротко)

- **4-й тиждень**: **респіраторний дивертикул** (легеневий зачаток) відокремлюється від **передньої кишки**: утворюється гортанно-трахеальна борозна.
- Епітелій дихальних шляхів — **ентодерма**; хрящі, м'язи, судини — **мезодерма** (спланхнічна).
- Стадії розвитку легень: **псевдогландулярна** (5–17 тижнів), **канальцева** (16–26), **мішкоподібна** (26–вродж.), **альвеолярна** (з 32 тижня — до 8 років).
- **Сурфактант** з 24–26 тижнів (II тип пневмоцитів); достатній ~34–36 тиж. Недостатність → **респіраторний дистрес-синдром** недоношених.
- **Трахео-стравохідна нориця**, **атрезія стравоходу** — вади відокремлення.
- Перший вдих після народження: розправлення альвеол, падіння легеневого опору, закриття овального отвору ([[Серце — розвиток і вади]]).

## 7. Захисні механізми

| Механізм | Опис |
|---|---|
| **Волоски ніздрів, носові раковини** | фільтрація, турбулентність |
| **Слиз і війки (мукоциліарний кліренс)** | війки здійснюють ~1000 ударів/хв, просувають слиз до глотки зі швидкістю до 1–2 см/хв |
| **Кашель, чхання** | рефлекси видалення подразників |
| **Альвеолярні макрофаги** | фагоцитоз частинок і мікробів |
| **IgA, лізоцим, дефензини** | імунний захист |
| **Лімфоїдна тканина** (мигдалики, БАЛТ) | імунітет |

Порушення (паління, вірус, муковісцидоз, **синдром Картагенера**) → хронічні інфекції.

## 8. Клінічні поняття

| Термін | Значення |
|---|---|
| **Задишка (диспное)** | відчуття нестачі повітря |
| **Тахіпное / брадіпное** | частіше / рідше за норму |
| **Апное** | зупинка дихання |
| **Гіпоксія, гіпоксемія** | нестача O₂ в тканинах / в крові |
| **Гіперкапнія** | ↑ CO₂ в крові |
| **Ціаноз** | синюшність (≥ 5 г/дл дезоксигемоглобіну): центральний, периферичний |
| **Кашель, мокротиння, кровохаркання** | симптоми |
| **Свистяче дихання, стридор** | звуження бронхів / гортані |
| **Пульсоксиметрія (SpO₂)** | норма ≥ 95% |

## 9. Мнемоніки

- Шлях повітря: **ніс → глотка → гортань → трахея → бронхи → бронхіоли → альвеоли**.
- **Провідна зона — мертвий простір (150 мл)**; **респіраторна — газообмін**.
- Діафрагмовий нерв: **C3, C4, C5** («C3–5 тримають діафрагму живою»).
- Сурфактант: з **~24–26 тижня**.
