# Трахея і головні бронхи (*trachea*, *bronchi principales*)

Трахея — трубка, що проводить повітря від гортані до бронхів. Вона має хрящові напівкільця й не спадається. Внизу вона ділиться на два головні бронхи.

## 1. Трахея (*trachea*)

| Показник | Значення |
|---|---|
| Початок | нижній край **перснеподібного хряща (C6)** |
| Кінець | **біфуркація трахеї** на рівні **T4–T5** (кут груднини); при глибокому вдиху опускається до T6 |
| Довжина | **9–15 см** (10–11 см у середньому) |
| Діаметр | 1,5–2,5 см (дорослий) |
| Хрящі | **16–20 неповних хрящових півкілець** (гіаліновий хрящ) |
| Відділи | **шийний** (6–7 півкілець) і **грудний** (10–13 півкілець) |

При дихальних рухах і ковтанні трахея **рухається**: вгору при вдиху, вниз при видиху; у дітей коротка (4 см у немовляти).

### Стінка (4 оболонки)
| Оболонка | Склад |
|---|---|
| **Слизова** | **війчастий псевдобагатошаровий епітелій** (келихоподібні клітини, війчасті, базальні, ендокринні), базальна мембрана, власна пластинка з залозами |
| **Підслизова** | пухка сполучна тканина, залози |
| **Фіброзно-м'язово-хрящова** | **півкільця** + кільцеві зв'язки; задня частина — **перетинчаста стінка** з гладкою **трахеальною м'язою** |
| **Адвентиція** | зовнішня; сполучна тканина |

- **Перетинчаста стінка** (задня) прилягає до **стравоходу**. Гладка м'язова трахеальна м'яз скорочується при кашлі → звужує просвіт, збільшує швидкість повітря.
- **Кільцеві зв'язки** з'єднують півкільця.
- Перше півкільце може зростатися з перснеподібним хрящем.

### Мукоциліарний кліренс
Війки рухають слиз **вгору, до глотки** (~1–2 см/хв). Куріння паралізує війки → накопичення слизу, кашель курця.

## 2. Біфуркація і кіль

На рівні **T4–T5** (кут груднини спереду) трахея ділиться на **правий і лівий головні бронхи**. Всередині між ними — **кіль трахеї** (*carina*): гострий поздовжній гребінь, дуже чутлива зона (**кашльовий рефлекс**); ширина кута біфуркації 55–75°.

- **Карина** — орієнтир при **бронхоскопії**.
- Роздвоєння **розширюється** при збільшенні лімфатичних вузлів (рак, туберкульоз) → «розірваний кіль».

## 3. Топографія трахеї

### Шийна частина
| Сусід | Відношення |
|---|---|
| **Спереду** | перешийок **щитоподібної залози** (2–4 півкільця), шкіра, фасції, підпід'язикові м'язи |
| **З боків** | частки щитоподібної залози, **сонні артерії**, поворотні гортанні нерви |
| **Ззаду** | **стравохід** (трохи ліворуч) |

### Грудна частина
| Сусід | Відношення |
|---|---|
| **Спереду** | рукоятка груднини, **тимус**, ліва плечоголовна вена, **дуга аорти**, плечоголовний стовбур, ліва сонна артерія |
| **Справа** | права плевра, **непарна вена** (дугою), верхня порожниста вена, правий блукаючий нерв |
| **Зліва** | **дуга аорти**, ліва сонна і підключична артерії, лівий поворотний нерв |
| **Ззаду** | стравохід, хребет (T3–T4) |

Аневризма дуги аорти — стиснення трахеї (кашель, стридор). Збільшена щитоподібна залоза (зоб) → ретростернальний зоб → стиснення.

## 4. Кровопостачання, нерви, лімфа

| | Опис |
|---|---|
| **Артерії** | **нижня щитоподібна**, бронхіальні гілки грудної аорти, внутрішня грудна |
| **Вени** | щитоподібні вени → плечоголовні; бронхіальні → непарна |
| **Нерви** | **блукаючий (парасимпатика**: звужує, ↑ секреція), **симпатичний** стовбур (**T2–T4**: розслабляє); **поворотний гортанний** |
| **Лімфа** | **паратрахеальні, трахеобронхіальні** вузли |

## 5. Головні бронхи (*bronchi principales*)

Лежать в **корені легені**. Відрізняються праворуч і ліворуч:

| Ознака | **Правий** | **Лівий** |
|---|---|---|
| **Довжина** | **коротший** (~2,5 см) | **довший** (~5 см) |
| **Діаметр** | **ширший** (~15 мм) | вужчий (~11 мм) |
| **Напрямок** | **більш вертикальний** (кут 20–25° до трахеї) — «продовження трахеї» | **більш горизонтальний** (кут 40–45°) |
| **Півкільця** | 6–8 | 9–12 |
| **Відношення** | **непарна вена** над ним (дугою) | **дуга аорти** над ним |
| **Артерія** | легенева артерія **спереду-нижче** | легенева артерія **над** бронхом |

### Практичне значення
- **Стороннє тіло** і **аспірація** потрапляють частіше у **правий головний бронх** (коротший, ширший, більш вертикальний): **правий нижньочастковий** (сегменти 6, 10) у положенні сидячи; **верхньочастковий** (задній сегмент) у положенні лежачи на спині.
- **Інтубація** надто глибока → **правий бронх** → ателектаз лівої легені.

## 6. Рентген і КТ

- Трахея видна як **світла смуга** (повітря) спереду від хребта; зсув → пухлина, пневмоторакс (напружений), зоб.
- Біфуркація на рівні T4–T5.
- **Бронхоскопія** (гнучка/жорстка).

## 7. Хвороби трахеї

| Стан | Суть |
|---|---|
| **Трахеїт** | запалення (вірус): сухий кашель, біль за грудниною |
| **Стеноз трахеї** | після інтубації/трахеостомії; стридор |
| **Трахеомаляція** | м'яка стінка; колапс при видиху |
| **Трахеостравохідна нориця** | вроджена (атрезія стравоходу) або пухлина, травма |
| **Стороннє тіло** | діти; кашель, задуха |
| **Пухлини** | рідкісні (аденоїдно-кістозна, плоскоклітинна) |
| **Стиснення ззовні** | зоб, аневризма, лімфовузли |
| **Травма** | розрив при ушкодженні грудної клітки |

### Трахеостомія
Розріз трахеї (2–4 півкільця) для постійного доступу повітря: тривала вентиляція, обструкція. Ризики: кровотеча, пневмоторакс, стеноз.

## 8. Мнемоніки

- Трахея: **C6 → T4–T5**, 16–20 півкілець, **задня стінка м'язова**.
- Правий бронх — **коротший, ширший, вертикальніший** (стороннє тіло — праворуч).
- Над правим бронхом — **непарна вена**; над лівим — **дуга аорти**.
- **Карина** — чутливий кіль (кашель).
