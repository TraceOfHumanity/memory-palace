# Бронхіальне дерево (*arbor bronchialis*)

Головні бронхи багаторазово діляться (приблизно 23 рази) і утворюють **бронхіальне дерево**. Воно закінчується альвеолами. Будова стінки змінюється: хрящ зникає, збільшується частка гладких м'язів.

Пов'язані файли: [[Дихальна система — огляд]], [[Трахея і головні бронхи]], [[Легені — будова і частки]], [[Легені — бронхолегеневі сегменти]], [[Легені — альвеоли і кровопостачання]], [[Вегетативна нервова система]], [[Дихання — механіка і об'єми]], [[Дихання — регуляція]], [[Хвороби дихальної системи]].

## 1. Генерації (поділи)

Нумерація за Вайбелем: **генерація 0** — трахея.

| Генерація | Структура | Діаметр | Особливості |
|---|---|---|---|
| **0** | трахея | 18 мм | хрящові півкільця |
| **1** | **головні бронхи** | 12 мм | півкільця |
| **2–3** | **часткові (лобарні) бронхи** | 8–5 мм | пластини хряща |
| **4** | **сегментарні бронхи** | 4,5 мм | пластини |
| **5–11** | **субсегментарні бронхи** | 3 → 1 мм | **острівці хряща** (зникають) |
| **12–16** | **термінальні (малі) бронхіоли** | ≤ 1 мм | **без хряща**, без залоз; війчастий кубічний епітелій, **клітини Клара** |
| **17–19** | **респіраторні бронхіоли** (3 порядки) | 0,5 мм | є **альвеоли в стінці**; початок газообміну |
| **20–22** | **альвеолярні ходи** | 0,3–0,4 мм | стінки з альвеол |
| **23** | **альвеолярні мішечки** | 0,3 мм | кінцеві |

Усього **~300–500 млн альвеол**. Загальний переріз дихальних шляхів зростає від бронхів до альвеол (швидкість повітря падає майже до нуля в альвеолах — дифузія).

### Три зони
| Зона | Генерації | Роль |
|---|---|---|
| **Провідна** | 0–16 | провідні шляхи, **мертвий простір (~150 мл)** |
| **Перехідна** | 17–19 | респіраторні бронхіоли |
| **Респіраторна** | 20–23 | газообмін |

## 2. Зміни стінки за рівнями

| Рівень | Епітелій | Хрящ | Гладкі м'язи | Залози |
|---|---|---|---|---|
| Головні бронхи | війчастий псевдобагатошаровий | **кільця (півкільця)** | є | є |
| Часткові, сегментарні | війчастий | **пластини** | кільцеві | є |
| Малі (субсегментарні) | війчастий, **келихоподібні клітини** | **острівці** | **більше** (спіральні пучки) | є |
| **Бронхіоли** | **війчастий кубічний** (**клітини Клара**) | **нема** | **добре розвинені (найбільше відносно товщини стінки)** | **нема** |
| Респіраторні бронхіоли | кубічний | нема | мало | нема |

| **Келихоподібна** | слиз (багато при курінні, бронхіті) |
| **Базальна** | камбіальна |

## 3. Гладка мускулатура і тонус

Гладкі м'язи бронхів і бронхіол регулюють **просвіт**:

| Вплив | Рецептор | Результат |
|---|---|---|
| **Парасимпатика** (X; ACh) | **M₃** | **бронхоконстрикція**, ↑ секреція слизу |
| **Симпатика / адреналін** | **β₂** | **бронходилатація** |
| **Гістамін, лейкотрієни, ацетилхолін** | H₁, CysLT | звуження (астма) |
| **Хімічні подразники, холодне повітря** | рефлекс | звуження |
| **↑ CO₂ (гіперкапнія)** | | розширення (місцево) |

- **β₂-агоністи** (сальбутамол) — розширюють (астма).
- **Антихолінергічні** (іпратропій, тіотропій) — розширюють (ХОЗЛ).
- **Інгібітори ацетилхолінестерази** і β-блокатори можуть спровокувати бронхоспазм.

Деталі: [[Вегетативна нервова система]].

## 4. Кровопостачання і лімфа

- **Бронхіальні артерії** (2–4, з грудної аорти): живлять **стінку бронхів**, до рівня респіраторних бронхіол.
- Альвеоли живляться з легеневих артерій (мале коло): [[Легеневе коло кровообігу]].
- **Лімфа**: бронхолегеневі (корінь), трахеобронхіальні вузли.
- **Бронхіальні вени** → непарна, напівнепарна, легеневі вени.

## 5. Бронхолегеневий сегмент (*segmentum bronchopulmonale*)

Ділянка легені, що вентилюється **сегментарним бронхом** і живиться **сегментарною артерією** (відокремлена сполучнотканинними перегородками). Одиниця хірургічної резекції. Докладно: [[Легені — бронхолегеневі сегменти]].

### Часточка легені (ацинус)
- **Часточка** — основна анатомічна одиниця (1–2 см): бронхіола + артерія.
- **Ацинус** (*acinus*) — функціональна одиниця: **усі респіраторні бронхіоли від однієї термінальної бронхіоли** з альвеолярними ходами й мішечками.

## 6. Мертвий простір

| Тип | Опис | Об'єм |
|---|---|---|
| **Анатомічний** | провідна зона: нос → термінальні бронхіоли | ~150 мл (2 мл/кг) |
| **Альвеолярний** | вентильовані альвеоли без кровотоку (емболія) | ~0 у здорових |
| **Фізіологічний** | анатомічний + альвеолярний | ~150 мл |

Залежить від росту, положення тіла, розтягу легень. Приклад: з дихального об'єму 500 мл до альвеол доходить 350 мл, а 150 мл залишається в мертвому просторі.

## 7. Бронхоскопія

- **Фіброоптична бронхоскопія**: огляд до сегментарних/субсегментарних бронхів; біопсія, лаваж (**БАЛ**), видалення стороннього тіла.
- Орієнтири: карина, гирла часткових бронхів.

## 8. Хвороби бронхів

| Хвороба | Суть | Ключове |
|---|---|---|
| **Гострий бронхіт** | вірус; запалення слизової | кашель, мокротиння |
| **Хронічний бронхіт** | куріння; **кашель з мокротою ≥ 3 міс 2 роки поспіль**; гіпертрофія залоз | Reid index > 0,5 |
| **Бронхіальна астма** | хронічне запалення; гіперреактивність; **зворотна** обструкція | напади свистячого дихання, задишки, ночі; еозинофіли; сальбутамол |
| **ХОЗЛ** | необоротна обструкція (бронхіт + емфізема) | куріння; ОФВ₁/ФЖЄЛ < 0,7 |
| **Бронхоектази** | незворотне розширення бронхів | гнійна мокрота, кровохаркання; муковісцидоз, інфекції |
| **Муковісцидоз** | мутація CFTR (7-ма хромосома); в'язкий слиз | хронічні інфекції, ПЖ недостатність, піт солоний |
| **Бронхіоліт** | діти; RSV | свистяче дихання |
| **Рак бронха (рак легені)** | | кашель, кровохаркання; див. [[Хвороби дихальної системи]] |
| **Стороннє тіло** | | |

### Астма: механізм
Алерген → IgE → **тучні клітини** → гістамін, лейкотрієни → **спазм**, набряк, слиз. Тріада: **спазм + набряк + слиз**. Лікування: **інгаляційні кортикостероїди**, β₂-агоністи, антилейкотрієнові.

### ХОЗЛ
**Емфізема**: руйнування альвеол (дефіцит α1-антитрипсину; куріння) → бочкоподібна грудна клітка, худі «рожеві» хворі з задишкою (*pink puffers*). **Хронічний бронхіт**: «сині набряклі» хворі (*blue bloaters*).

## 9. Мнемоніки

- Генерації: **бронх → часткові → сегментарні → субсегментарні → бронхіоли (без хряща) → термінальні → респіраторні → ходи → мішечки → альвеоли**.
- **Хрящ зникає в бронхіолах (діаметр < 1 мм)**; гладкі м'язи залишаються → астма вражає бронхіоли.
- **Парасимпатика (M₃) — звужує; симпатика (β₂) — розширює.**
- Мертвий простір: **150 мл**.
