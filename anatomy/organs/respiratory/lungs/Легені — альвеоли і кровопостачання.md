# Легені — альвеоли і кровопостачання

**Альвеоли** — дрібні повітряні мішечки, де відбувається газообмін. Їхня стінка торкається капілярів. Тонкий **аерогематичний бар'єр** дає змогу O₂ і CO₂ дифундувати за мілісекунди.

## 1. Альвеоли (*alveoli pulmonis*)

| Показник | Значення |
|---|---|
| Кількість | **~300–500 млн** |
| Діаметр | ~0,2–0,3 мм (200–300 мкм) |
| Площа поверхні | **70–100 м²** (площа тенісного корту) |
| Стінка | **міжальвеолярна перегородка** з капілярами |
| Капіляри | ~280 млрд; площа ~70 м² |

Кожна альвеола відкривається в **альвеолярний хід** або мішечок. Між сусідніми альвеолами є **пори Кона** (колатеральна вентиляція); між бронхіолою й альвеолою — **канали Ламберта**.

## 2. Клітини альвеоли

| Клітина | Частка | Функція |
|---|---|---|
| **Альвеолоцити I типу** (*pneumocyti I*) | ~95% **поверхні** | **плоскі**, дуже тонкі (0,1–0,2 мкм); газообмін; не діляться |
| **Альвеолоцити II типу** (*pneumocyti II*) | ~5% поверхні | **кубічні**; синтезують **сурфактант**; **діляться** і диференціюються в I типу (регенерація) |
| **Альвеолярні макрофаги** («пилові клітини») | | фагоцитоз пилу, бактерій; при серцевій недостатності — «клітини серцевих вад» (з гемосидерином) |
| **Ендотелій капілярів** | | |
| **Фібробласти, перицити** | | еластин, колаген |
| **Тучні клітини, лімфоцити** | | |

## 3. Аерогематичний (гемато-альвеолярний) бар'єр

Шлях газу з альвеоли в кров (**3 шари + сурфактант**):
1. **Шар сурфактанту** (рідина на поверхні).
2. **Альвеолоцит I типу** (епітелій).
3. **Спільна базальна мембрана** (епітелій + ендотелій).
4. **Ендотелій капіляра**.

| Показник | Значення |
|---|---|
| Товщина | **0,2–0,6 мкм** (у найтоншому місці ~0,2) |
| Дифузія | **пасивна** (за градієнтом парціальних тисків) |

Товщання бар'єра (**фіброз, набряк, пневмонія**) → **порушення дифузії** → гіпоксемія.

## 4. Сурфактант

**Сурфактант** — поверхнево-активна речовина (ліпопротеїн), що вистеляє альвеоли.

### Склад
- **~90% ліпіди**: **дипальмітоїлфосфатидилхолін (DPPC, лецитин)** — основний.
- **~10% білки** (**SP-A, SP-B, SP-C, SP-D**).

### Функції
1. **Знижує поверхневий натяг** води на межі повітря — рідина → альвеоли не спадаються.
2. **Запобігає ателектазу** (спаданню), особливо при видиху.
3. **Збільшує розтяжність легень** (комплайнс) → полегшує вдих.
4. **Вирівнює тиск у альвеолах різного розміру** (закон Лапласа: P = 2T/r; маленькі альвеоли мали б більший тиск і «закачували» б повітря у великі).
5. Захищає від набряку, імунна функція (SP-A, SP-D).

### Закон Лапласа
**P = 2T / r** (T — поверхневий натяг, r — радіус). Без сурфактанту маленька альвеола (малий r) мала б вищий тиск і спадалась би в більшу. Сурфактант **зменшує T більше в малих альвеолах** (концентрується) → стабільність.

### Розвиток
- II тип пневмоцитів з **~24 тижня**; сурфактант **достатній ~34–36 тижнів**.
- **Глюкокортикоїди** (бетаметазон) дають матері при ризику передчасних пологів → **дозрівання легень**.
- **Співвідношення лецитин/сфінгомієлін (L/S)** у навколоплодових водах (>2 — зріле).

### Клінічне
| Стан | Суть |
|---|---|
| **Респіраторний дистрес-синдром (РДС) новонароджених** | **дефіцит сурфактанту** (недоношені): задишка, втягнення, «матове скло» на рентгені, **гіалінові мембрани**; лікування — **екзогенний сурфактант**, CPAP |
| **ГРДС дорослих** | ушкодження альвеол (сепсис, аспірація, пневмонія) |
| **Діабет матері** | затримка дозрівання |

## 5. Колатеральна вентиляція

- **Пори Кона** (3–13 мкм) у міжальвеолярних перегородках: вирівнюють тиск, дають повітря при закупорці бронхіоли.
- **Канали Ламберта**: бронхіола — альвеола.
- **Канали Мартіна**: між бронхіолами.

Значення: захист від ателектазу, поширення інфекції.

## 6. Кровопостачання легень

Подвійне.

| Система | Судини | Функція |
|---|---|---|
| **Легеневе (мале) коло** | легеневі артерії ← правий шлуночок; вени → ліве передсердя | **газообмін** (функціональне) |
| **Велике коло** | **бронхіальні артерії** (з грудної аорти, 2–4) | **живлення тканини** бронхів, плеври, судин |

- **Легенева артерія** несе венозну кров, гілкується разом із бронхами (**супроводжують бронхіальне дерево**), закінчується капілярною сіткою навколо альвеол.
- **Легеневі вени**: збирають кров **між сегментами** (міжсегментарні), несуть артеріальну кров у ліве передсердя.
- **Бронхіальні артерії** (2–4): ~1–2% серцевого викиду; вени → легеневі (частково) і непарна.
- **Анастомози** між бронхіальними й легеневими судинами; при хронічних хворобах (бронхоектази) **бронхіальні артерії розширюються** (**кровохаркання**).

Деталі: [[Легеневе коло кровообігу]].

## 7. Лімфатична система легень

- **Поверхнева сітка** (під плеврою) і **глибока** (по бронхах, судинах).
- Ведуть до **бронхолегеневих (ворітних)** → **трахеобронхіальних** → **паратрахеальних** → **бронхосередостінних стовбурів** → грудна протока / права протока.
- Метастази рака легені: ворітні → середостінні лімфовузли.
- Деталі: [[Мікроциркуляція і лімфатична система]].

## 8. Іннервація легень

Легеневе сплетення (*plexus pulmonalis*) — **передні й задні**, біля кореня.

| Нерви | Функція |
|---|---|
| **Блукаючий (X)** — парасимпатика | **звуження бронхів**, ↑ секреція слизових залоз, **розширення судин** |
| **Симпатичні** (T2–T7) | **розширення бронхів**, ↓ секреція, звуження судин |
| **Чутливі** (X) | рецептори розтягу, подразнення (кашель), **J-рецептори** (капілярні) |

- Паренхіма легень **не має больових рецепторів**; біль — від **парієтальної плеври** (іннервація міжребровими, діафрагмовим нервами).
- Рефлекс **Герінга — Брейера**: розтяг легень → гальмування вдиху.

## 9. Клітини Клара (клітини *club*) і нейроендокринні

- **Клітини Клара** — у бронхіолах: захист, секреція.
- **Нейроендокринні** (Кульчицького): джерело **дрібноклітинного раку**.

## 11. Мнемоніки

- Аерогематичний бар'єр: **сурфактант → альвеолоцит I → спільна базальна мембрана → ендотелій**.
- Пневмоцит I — **газообмін** (95% поверхні); пневмоцит II — **сурфактант + регенерація**.
- Сурфактант: **ліпіди (DPPC) 90%**, зменшує поверхневий натяг, **з 24–26 тиж.**
- Подвійне кровопостачання: **легеневі — газообмін; бронхіальні — живлення**.
