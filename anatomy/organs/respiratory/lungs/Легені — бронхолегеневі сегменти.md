# Легені — бронхолегеневі сегменти

**Бронхолегеневий сегмент** — ділянка легені, яку вентилює один **сегментарний бронх** і живить одна **сегментарна артерія**. Сегменти відокремлені сполучнотканинними перегородками. Це одиниця для хірургії й діагностики: запалення й пухлини часто обмежуються одним сегментом.

Пов'язані файли: [[Дихальна система — огляд]], [[Легені — будова і частки]], [[Бронхіальне дерево]], [[Трахея і головні бронхи]], [[Легені — альвеоли і кровопостачання]], [[Плевра і середостіння]], [[Грудна клітка]], [[Хвороби дихальної системи]].

## 1. Принципи

- Сегмент має форму піраміди (верхівка до кореня, основа до поверхні).
- Сегментарний бронх — **кінцева гілка часткового бронха**; сегментарна артерія йде **поруч** з бронхом, **вена — між сегментами** (міжсегментарна).
- Резекція за межами сегмента (**сегментектомія**) зберігає здорову тканину.
- Нумерація сегментів — за Джексоном і Гюбером (міжнародна номенклатура).

## 2. Права легеня (10 сегментів)

| Частка | № | Сегмент | Положення |
|---|---|---|---|
| **Верхня** | **S1** | **верхівковий** (*apicale*) | верхівка |
| | **S2** | **задній** (*posterius*) | задньо-верхній |
| | **S3** | **передній** (*anterius*) | передньо-верхній |
| **Середня** | **S4** | **латеральний** (*laterale*) | бічна частина |
| | **S5** | **медіальний** (*mediale*) | до серця |
| **Нижня** | **S6** | **верхній** (*superius*, Нельсона) | верхівка нижньої частки (позаду) |
| | **S7** | **медіальний базальний** (*basale mediale*, серцевий) | біля серця (нема в лівій як окремий) |
| | **S8** | **передній базальний** | передньо-нижній |
| | **S9** | **латеральний базальний** | бічний |
| | **S10** | **задній базальний** | задньо-нижній (найнижчий) |

## 3. Ліва легеня (8–10 сегментів)

Відмінності від правої: немає окремого S7 (злитий з S8 → **S7+8**), верхньої частки — язичок.

| Частка | № | Сегмент |
|---|---|---|
| **Верхня** | **S1+2** | **верхівково-задній** (злиті) |
| | **S3** | **передній** |
| | **S4** | **верхній язичковий** (*lingulare superius*) |
| | **S5** | **нижній язичковий** (*lingulare inferius*) |
| **Нижня** | **S6** | **верхній** |
| | **S7+8** | **передній медіальний базальний** (часто) |
| | **S9** | **латеральний базальний** |
| | **S10** | **задній базальний** |

Язичок (S4–S5) — аналог правої **середньої частки**.

## 4. Часткові бронхи і сегментарні

| Часткові бронхи | Сегментарні |
|---|---|
| **Верхній правий** (*eparterial*) | апікальний, задній, передній |
| **Середній правий** | латеральний, медіальний |
| **Нижній правий** | верхній, медіальний базальний, передній базальний, латеральний базальний, задній базальний |
| **Верхній лівий** | верхівково-задній, передній + **язичковий** (верхній, нижній) |
| **Нижній лівий** | верхній, (передньо-медіальний базальний), латеральний, задній базальний |

## 5. Положення при аспірації (де застряє)

| Положення тіла | Сегмент |
|---|---|
| **Сидячи/стоячи** | **задній базальний (S10)** і інші базальні правої нижньої частки |
| **Лежачи на спині** | **задній сегмент верхньої частки (S2)** і **верхній сегмент нижньої частки (S6)** (права) — **аспіраційна пневмонія** |
| **Лежачи на правому боці** | правий S2, S6 |

Лікувальне **дренажне положення** (постуральний дренаж) використовує гравітацію для видалення мокротиння з певного сегмента.

## 6. Проекції на грудній клітці

| Частка | Де вислуховувати |
|---|---|
| **Верхні частки** | спереду — верхні відділи до 4-го ребра; ззаду — до ості лопатки |
| **Середня частка (права)** | спереду і збоку між 4 і 6 ребрами (праворуч) |
| **Нижні частки** | ззаду нижче ості лопатки (T3–T10); бічно нижче 4-го ребра |
| **Язичок** | зліва спереду і збоку (4–6 ребра) |

Поява хрипів над сегментом допомагає локалізувати **пневмонію**.

## 7. Клінічне значення сегментів

- **Рентген і КТ**: ураження описують за сегментами (**правий S6**, **лівий S1+2**).
- **Туберкульоз**: **верхівкові і задні сегменти верхніх часток** (S1, S2) та **верхній сегмент нижньої частки** (S6) — найбільше повітря.
- **Аспіраційна пневмонія**: **задній верхньої частки (S2)**, **верхній нижньої (S6)** і **базальні нижньої**.
- **Бронхоектази**: часто **нижні частки**, **середня частка** (синдром Брока: середня частка стискається лімфовузлами).
- **Рак**: центральний (біля кореня) і периферичний.
- **Сегментектомія**, **лобектомія**, **пневмонектомія**.
- **Бронхоскопічна навігація**: гирла сегментарних бронхів: розрізняють за кутом.

## 8. Ацинус і часточка

- **Первинна легенева часточка** (Міллера) — респіраторна бронхіола з альвеолярними ходами.
- **Ацинус** — функціональна одиниця (6–10 мм): усі респіраторні бронхіоли від однієї термінальної.
- **Вторинна легенева часточка** (Міллера) 1–2,5 см — на КТ видно **центрилобулярну артерію** і міжчасточкові перегородки; основа інтерпретації **КТ високої роздільності**.

Деталі: [[Бронхіальне дерево]].

## 9. Мнемоніки

- Праворуч **10** сегментів: **верхня 3 (1–3), середня 2 (4–5), нижня 5 (6–10)**.
- Ліворуч **8–10**: верхня (S1+2, S3, S4–S5 язичок), нижня (S6, S7+8, S9, S10).
- **Аспірація лежачи на спині → S2 і S6 (задні сегменти)**.
- **Туберкульоз — верхівки (S1, S2)**.
