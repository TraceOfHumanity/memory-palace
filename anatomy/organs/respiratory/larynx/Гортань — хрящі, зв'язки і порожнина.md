# Гортань — хрящі, зв'язки і порожнина (*larynx*)

Гортань — орган дихання й голосоутворення. Вона розташована в передньому відділі шиї на рівні **C4–C6** (у дітей вище). Вона з'єднує глотку з трахеєю й **захищає дихальні шляхи під час ковтання**.

Пов'язані файли: [[Дихальна система — огляд]], [[Гортань — м'язи, голос і хвороби]], [[Трахея і головні бронхи]], [[Ніс — порожнина носа]], [[М'язи ротової порожнини, глотки й гортані]], [[М'язи шиї]], [[Черепні нерви]], [[Артерії голови і шиї]], [[Вегетативна нервова система]], [[Хвороби дихальної системи]], [[Хребет]], [[Глотка і ковтання]].

## 1. Положення і відношення

| Показник | Значення |
|---|---|
| Рівень | **C4–C6** у дорослого (у дитини C3–C5; у літніх нижче) |
| Верхня межа | вхід у гортань (надгортанник), під'язикова кістка підвішена вище |
| Нижня межа | нижній край перснеподібного хряща (початок трахеї) |
| Спереду | підпід'язикові м'язи, шкіра, шийна фасція |
| З боків | частки **щитоподібної залози**, сонні судини |
| Ззаду | **гортаноглотка** (лежить на хребті) |

Гортань **піднімається** при ковтанні й високих тонах (під'язиково-гортанні м'язи). Пальпується: під'язикова кістка → щитоподібний хрящ → перснеподібний хрящ.

## 2. Хрящі гортані

**9 хрящів**: 3 непарні + 3 парні.

### Непарні
| Хрящ | Тип | Особливості |
|---|---|---|
| **Щитоподібний** (*cartilago thyroidea*) | гіаліновий | **дві чотирикутні пластинки**, зрощені під кутом спереду (**кадик**, *prominentia laryngea*: у чоловіків 90°, у жінок 120°); **верхня й нижня вирізки**; **верхні й нижні роги** (нижні з'єднуються з перстнеподібним) |
| **Перснеподібний** (*cartilago cricoidea*) | гіаліновий | **кільце** (повне): вузька **дуга** спереду, широка **пластинка** (печатка) ззаду; **єдине повне хрящове кільце** дихальних шляхів; основа гортані |
| **Надгортанник** (*epiglottis*) | **еластичний** | листоподібний; **стебельце** прикріплене до щитоподібного хряща; закриває вхід у гортань при ковтанні |

### Парні
| Хрящ | Тип | Особливості |
|---|---|---|
| **Черпакуваті (аритеноїдні)** (*cartilagines arytenoideae*) | гіаліновий (верхівка еластична) | піраміди на пластинці перснеподібного; **голосовий відросток** (до голосової зв'язки), **м'язовий відросток** |
| **Ріжкуваті** (*cartilagines corniculatae*) | еластичні | на верхівках черпакуватих |
| **Клиновидні** (*cartilagines cuneiformes*) | еластичні | у черпакувато-надгортанних складках |

Окостеніння гіалінових хрящів починається з **20–25 років** (пізніше — кальцифікація; видно на рентгені).

## 3. Суглоби

| Суглоб | Між | Рухи |
|---|---|---|
| **Перстнещитоподібний** (парний) | нижній ріг щитоподібного + перснеподібний | нахил щитоподібного вперед/назад → **змінює натяг голосових зв'язок** (висота голосу) |
| **Перснечерпакуватий** (парний) | основа черпакуватого + пластинка перснеподібного | **ковзання і обертання** → зближення/розведення голосових зв'язок |

Суглоби гортані і хрящі: [[М'язи ротової порожнини, глотки й гортані]].

## 4. Зв'язки і мембрани

| Структура | Положення |
|---|---|
| **Щитопід'язикова мембрана** | від під'язикової до щитоподібного хряща; проходить **верхній гортанний нерв і судини** |
| **Під'язиково-надгортанна зв'язка** | |
| **Щитонадгортанна зв'язка** | |
| **Перснещитоподібна (серединна) зв'язка** (*lig. cricothyroideum medianum*, *conus elasticus*) | між щитоподібним і перснеподібним: **місце коніотомії** (екстрена трахеостомія) |
| **Еластичний конус** (*conus elasticus*) | еластична мембрана від перснеподібного вгору до голосових зв'язок; верхній край утворює **голосові зв'язки** |
| **Чотирикутна мембрана** | від надгортанника до черпакуватих; нижній край — **вестибулярні зв'язки** |
| **Перснетрахеальна зв'язка** | |

## 5. Порожнина гортані (*cavitas laryngis*)

Ділиться на **три відділи** двома парами складок:

### Складки
| Складка | Положення | Основа |
|---|---|---|
| **Вестибулярна (несправжня голосова)** (*plica vestibularis*) | верхня | вестибулярна зв'язка; не бере участі в голосі |
| **Голосова** (*plica vocalis*) | нижня | голосова зв'язка + голосовий м'яз; **справжня голосова складка** |

Між складками з кожного боку — **шлуночок гортані** (*ventriculus laryngis*, Морганьї) — виріст слизової.

### Відділи
| Відділ | Межі | Особливості |
|---|---|---|
| **Присінок гортані** (*vestibulum laryngis*) | вхід (надгортанник) → вестибулярні складки | |
| **Міжшлуночковий (середній) відділ** | вестибулярні → голосові складки | **шлуночки** |
| **Підголосовий відділ** (*cavitas infraglottica*) | голосові складки → перснеподібний | **у дітей — вузький, багата клітковина → набряк (ложний круп)** |

### Голосова щілина (*rima glottidis*)
Щілина між голосовими складками (**голосова зв'язка + голосові відростки**); **найвужче місце** гортані дорослого.
- Довжина: у чоловіків ~23 мм, у жінок ~17 мм.
- **Міжзв'язкова частина** (передня, 3/5) і **міжхрящова частина** (задня, 2/5).
- При вдиху — розширюється; при фонації — вузька; при шепоті — задня частина відкрита.

### Вхід у гортань (*aditus laryngis*)
Обмежений **надгортанником** спереду, **черпакувато-надгортанними складками** з боків, **черпакуватими хрящами** ззаду.

### Грушоподібний синус (*recessus piriformis*)
Глибокий кишеня по боках входу в гортань (гортаноглотка). Часто застрягають **риб'ячі кістки**; рак.

## 6. Слизова оболонка

- Війчастий **псевдобагатошаровий епітелій** (дихальний тип) — на більшій частині.
- **Багатошаровий плоский неороговілий епітелій** — на **голосових складках**, **надгортаннику** (задня поверхня верхньої частини), вході. Витримує тертя.
- Під епітелієм **голосових складок** — **простір Рейнке** (пухка рідка тканина) → **слизова хвиля** (вібрація при фонації); набряк Рейнке — куріння.
- Залози в слизовій, лімфоїдна тканина; **підголосовий відділ** — пухка клітковина (набряк у дітей).

## 7. Кровопостачання, лімфа й іннервація

### Артерії
| Артерія | Походження | Живить |
|---|---|---|
| **Верхня гортанна** | верхня щитоподібна (зовнішня сонна) | вестибулярний і середній відділи |
| **Нижня гортанна** | нижня щитоподібна (щитошийний стовбур) | підголосовий відділ |
| **Перснещитоподібна** (гілка верхньої щитоподібної) | | перстнещитоподібна зв'язка (**ризик кровотечі при коніотомії**) |

Деталі: [[Артерії голови і шиї]].

### Вени
Супроводжують артерії → верхні й нижні щитоподібні, внутрішня яремна.

### Лімфа
- **Вище голосових складок** → **глибокі шийні** вузли (верхні).
- **Нижче голосових складок** → **претрахеальні, паратрахеальні**, нижні глибокі шийні.
- **Голосові складки** майже **без лімфатичних судин** → рак голосової складки метастазує пізно; хороший прогноз.

### Нерви (X, блукаючий)
| Нерв | Волокна | Іннервує |
|---|---|---|
| **Верхній гортанний** (*n. laryngeus superior*) | | |
| — **внутрішня гілка** | чутливі | слизова **вище голосових складок**; **кашльовий рефлекс** |
| — **зовнішня гілка** | рухові | **перснещитоподібний м'яз** (єдиний) |
| **Поворотний (нижній) гортанний** (*n. laryngeus recurrens*) | | |
| — рухові | | **усі інші внутрішні м'язи** гортані |
| — чутливі | | слизова **нижче голосових складок** |

- **Правий** поворотний обходить **підключичну артерію**; **лівий** — **дугу аорти** (артеріальна зв'язка); їде в борозні між трахеєю і стравоходом.
- Ураження: **охриплість, афонія, стридор** ([[Черепні нерви]]).
- Нерви пов'язані з **щитоподібною залозою**: ризик при тиреоїдектомії.

## 8. Вікові і статеві особливості

| Особливість | Опис |
|---|---|
| **Новонароджений** | гортань розташована **високо** (C1–C3), надгортанник торкається м'якого піднебіння → можна дихати й ковтати одночасно (сосання); просвіт вузький |
| **Дитина** | підголосовий відділ найвужчий (по перстню); схильність до набряку |
| **Пубертат** | у хлопчиків ріст гортані, **мутація голосу**; кадик |
| **Старість** | окостеніння хрящів, опущення |
| **Жінки** | гортань менша; голос вищий (голосові складки коротші) |

## 9. Коніотомія і трахеостомія

- **Коніотомія** — розріз **перстнещитоподібної зв'язки** (під кадиком, над перснеподібним хрящем): швидкий доступ при **гострій обструкції** (наприклад, стороннє тіло, набряк); місце — **між щитоподібним і перснеподібним хрящами**; ризик — щитоподібні артерії.
- **Трахеостомія** — розріз трахеї на 2–4 хрящовому півкільці.

## 10. Мнемоніки

- Хрящі: **непарні** — щитоподібний, перснеподібний, надгортанник; **парні** — черпакуваті, ріжкуваті, клиновидні.
- **Перснеподібний — єдине повне кільце**; його ураження → стеноз.
- Нерви: **верхній гортанний — чутливий (вище) + перснещитоподібний; поворотний — усі інші м'язи + чутливий нижче**.
- Голосова щілина — **найвужче** місце гортані дорослого; **підголосовий** — найвужче в дитини (перстень).
- Гортань: **C4–C6**.
