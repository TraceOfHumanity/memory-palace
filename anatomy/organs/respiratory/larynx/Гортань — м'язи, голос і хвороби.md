# Гортань — м'язи, голос і хвороби

М'язи гортані змінюють натяг і положення голосових складок. Завдяки цьому гортань відкриває й закриває голосову щілину, змінює висоту голосу й захищає дихальні шляхи.

Пов'язані файли: [[Дихальна система — огляд]], [[Гортань — хрящі, зв'язки і порожнина]], [[Трахея і головні бронхи]], [[М'язи ротової порожнини, глотки й гортані]], [[М'язи шиї]], [[Черепні нерви]], [[Стовбур мозку]], [[Кора великих півкуль]], [[Артерії голови і шиї]], [[Хвороби дихальної системи]].

## 1. Внутрішні м'язи гортані

Усі (крім одного) іннервує **поворотний гортанний нерв** (X). Детальні таблиці початку й прикріплення — у файлі [[М'язи ротової порожнини, глотки й гортані]].

| М'яз | Дія на голосову щілину / складки | Нерв |
|---|---|---|
| **Задній перснечерпакуватий** (*m. cricoarytenoideus posterior*) | **розширює** голосову щілину (відводить складки) — **єдиний розширювач**; при двобічному паралічі цього м'яза щілина закрита, виникає загроза задухи | поворотний |
| **Бічний перснечерпакуватий** | **звужує** голосову щілину (зводить складки) | поворотний |
| **Поперечний черпакуватий** | зводить черпакуваті хрящі (закриває задню частину щілини) | поворотний |
| **Косий черпакуватий** + **черпакувато-надгортанна частина** | звужує вхід у гортань (сфінктер); при ковтанні | поворотний |
| **Щиточерпакуватий** (*m. thyroarytenoideus*): зовнішня частина | зближення, розслаблення | поворотний |
| **Голосовий м'яз** (*m. vocalis*, внутрішня частина щиточерпакуватого) | **напружує або розслаблює голосову зв'язку**, змінює форму | поворотний |
| **Перснещитоподібний** (*m. cricothyroideus*) | нахиляє щитоподібний хрящ вперед → **напружує голосові зв'язки** (↑ висота) | **зовнішня гілка верхнього гортанного** |

**Зовнішні м'язи**: підняття гортані (щитопід'язиковий, шилопід'язиковий, двочеревцевий...) і опускання (груднинно-щитоподібний, груднинно-під'язиковий...). Див. [[М'язи шиї]].

### Групи за функцією
| Функція | М'язи |
|---|---|
| **Відкривачі** (розширювачі) | задній перснечерпакуватий |
| **Закривачі** (зводять складки) | бічний перснечерпакуватий, поперечний черпакуватий, косі |
| **Напружувачі** | перснещитоподібний, голосовий |
| **Розслаблювачі** | щиточерпакуватий |
| **Сфінктер входу** | косий черпакуватий, черпакувато-надгортанний |

**Серединне («кадаверне») положення** складок — при повному паралічі нерва.

## 3. Голосоутворення (фонація)

Голос виникає, коли **повітря з легень проходить крізь зведені голосові складки**, і вони **вібрують**.

### Механізм (міоеластично-аеродинамічна теорія)
1. Складки зводяться (напруження м'язів).
2. Підголосовий тиск зростає (видих).
3. Тиск розсуває складки; повітря проривається.
4. Швидкий потік створює **ефект Бернуллі** (зниження тиску) + пружність → складки зближуються.
5. Цикл повторюється **100–300 разів/с** (основна частота).

### Параметри голосу
| Параметр | Від чого залежить |
|---|---|
| **Висота** (частота, Гц) | **довжина, натяг, маса** складок; перснещитоподібний м'яз |
| **Гучність** | підголосовий тиск, амплітуда вібрації |
| **Тембр** | резонатори: глотка, рот, ніс, пазухи, грудна клітка |

| | Основна частота (F₀) |
|---|---|
| Чоловіки | ~100–150 Гц (бас, баритон, тенор) |
| Жінки | ~200–250 Гц (альт, сопрано) |
| Діти | ~300–400 Гц |

**Діапазон голосу**: ~2 октави (у співаків більше).

### Резонатори і артикуляція
- **Надгортанні порожнини** (глотка, рот, ніс) формують **голосні** й **приголосні** разом із язиком, губами, м'яким піднебінням — **артикуляційний апарат**.
- Мовлення — функція кори: **зона Брока** (44, 45) і **зона Верніке**, моторна кора: [[Кора великих півкуль]].
- Керування: ядра **X** (подвійне ядро) у стовбурі: [[Стовбур мозку]], [[Черепні нерви]].

## 4. Захисні функції гортані

1. **Закриття входу** під час ковтання: підйом гортані, зсув надгортанника, замикання складок — їжа йде у стравохід.
2. **Кашльовий рефлекс**: рецептори слизової (X) → довгастий мозок → глибокий вдих → закриття голосової щілини → тиск ↑ → різке відкриття → потік повітря з швидкістю десятків м/с.
3. **Ларингоспазм** — рефлекторне замикання складок (подразнення, анестезія, судоми).
4. **Фіксація грудної клітки** (натуга при дефекації, пологах, піднятті ваги: **маневр Вальсальви**).

Порушення → **аспірація** (їжа, рідина в дихальні шляхи) → пневмонія.

## 5. Хвороби гортані

### Запальні
| Хвороба | Суть | Ознаки |
|---|---|---|
| **Гострий ларингіт** | вірус, голосове перенапруження | охриплість, сухий кашель, біль |
| **Хронічний ларингіт** | куріння, професійні | стійка охриплість |
| **Гострий епіглотит** | бактеріальне (*Haemophilus influenzae* тип b, нині рідко завдяки вакцині); **невідкладний** | лихоманка, **сильний біль у горлі, слинотеча, «поза триножника»**, стридор; **не обстежувати шпателем** — спазм; інтубація |
| **Круп (ларинготрахеобронхіт)** | вірус парагрипу; **діти 6 міс–3 роки** | «гавкаючий» кашель, інспіраторний стридор; рентген — **«шпиль церкви»** (звуження); дексаметазон |
| **Набряк гортані** | алергія (ангіоневротичний набряк), опік, травма | стридор, ціаноз; адреналін, **коніотомія** |

### Паралічі голосових складок
| Ураження | Наслідок |
|---|---|
| **Односторонній поворотний нерв** | охриплість, слабкий голос (складка в серединному положенні) |
| **Двобічний поворотний** | **стридор, задишка** (складки зведені) — може бути потрібна трахеостомія |
| **Верхній гортанний** | слабкий високий тон (нема натягу), втрата чутливості → аспірація |
| **Центральний** | лише вищі центри |

Причини: **операції на щитоподібній залозі**, пухлини легень/середостіння (ліва складка частіше: довгий хід навколо аорти), аневризма дуги аорти, інсульт стовбура (Валленберг), вірусні.

### Пухлини
| Пухлина | Суть |
|---|---|
| **Вузлики співаків** (вузлики голосових складок) | мозолі при перевантаженні голосу (на межі 1/3 і 2/3 складки) |
| **Поліпи, кісти** | |
| **Папіломатоз гортані** | ВПЛ (дітей) |
| **Рак гортані** | плоскоклітинний; **куріння, алкоголь**; охриплість > 3 тижнів — тривожна; ларингоскопія; прогноз кращий при **голосовому** (рано дає симптом, мало лімфи) |
| **Лейкоплакія** | передрак |

### Інші
- **Стороннє тіло**: діти; **прийом Геймліха**.
- **Стеноз** (після інтубації/трахеостомії).

- **Дисфонія** (розлад голосу): функціональна/органічна.

## 7. Мнемоніки

- **Задній перснечерпакуватий — єдиний відкривач** голосової щілини; всі інші м'язи зводять складки або змінюють натяг.
- **Перснещитоподібний** — єдиний, що іннервується **верхнім** гортанним нервом, **напружує** складки (висока нота).
- Охриплість після операції на щитоподібній — **поворотний нерв**.
- **Епіглотит** — **поза триножника, слинотеча, не чіпати шпателем**.
- Круп — **«гавкаючий кашель», шпиль**.
