# Тромбоцити і гемостаз (*thrombocyti*, *haemostasis*)

Гемостаз — це зупинка кровотечі при пошкодженні судини. Він має три етапи: судинний спазм, тромбоцитарна пробка і згортання крові (коагуляція). Тромбоцити — фрагменти цитоплазми мегакаріоцитів.

## 1. Тромбоцити

| Ознака | Значення |
|---|---|
| Походження | **мегакаріоцит** кісткового мозку |
| Розмір | 2–4 мкм; **без ядра** |
| Кількість | **180–320 ×10⁹/л** |
| Тривалість життя | **8–10 днів** |
| Депо | **селезінка** (~⅓) |
| Регулятор | **тромбопоетин** (печінка) |
| Руйнування | селезінка, печінка |

- **Тромбоцитопенія** < 150 ×10⁹/л; кровотеча при < 30–50, спонтанна при < 20.
- **Тромбоцитоз** > 400 ×10⁹/л.

### Гранули
| Тип | Вміст |
|---|---|
| **Щільні** (δ) | ADP, серотонін, Ca²⁺ |
| **α-гранули** | фібриноген, фактор фон Віллебранда (vWF), фактор V, PDGF |

## 2. Етапи гемостазу

### 2.1. Судинний спазм
Пошкоджена судина скорочується (рефлекс, **серотонін, тромбоксан A₂**) → ↓ витікання крові на секунди–хвилини.

### 2.2. Первинний (тромбоцитарний) гемостаз
| Фаза | Механізм |
|---|---|
| **Адгезія** | тромбоцити прилипають до оголеного колагену через **vWF** і рецептор GPIb |
| **Активація** | зміна форми, виділення гранул (ADP, TXA₂) |
| **Агрегація** | зв'язування між собою через **фібриноген** і рецептор GPIIb/IIIa |
| Результат | **білий тромб** (м'яка пробка), зупиняє кровотечу з дрібних судин за **1–3 хв** |

**Аспірин** блокує ЦОГ → ↓ TXA₂. **Клопідогрел** блокує рецептор ADP (P2Y12).

### 2.3. Вторинний (коагуляційний) гемостаз
Каскад ферментів, що закінчується утворенням **фібрину**.

| Шлях | Запуск | Фактори | Тест |
|---|---|---|---|
| **Зовнішній** | **тканинний фактор (III)** з пошкодженої тканини | VII | **ПЧ, МНВ** |
| **Внутрішній** | контакт із негативно зарядженою поверхнею | XII, XI, IX, VIII | **АЧТЧ** |
| **Загальний** | активація X | X, V, II (протромбін) | |

Схема загального шляху:
**Xa + Va + Ca²⁺ (протромбіназа)** → **протромбін (II) → тромбін (IIa)** → **фібриноген (I) → фібрин** → фактор XIIIa зшиває фібрин → **червоний тромб**.

- **Тромбін** — центральний фермент: активує V, VIII, XI, XIII, тромбоцити.
- **Ca²⁺ (фактор IV)** потрібен майже на всіх етапах (цитрат зв'язує Ca²⁺ і запобігає згортанню).
- **Вітамін K** потрібен печінці для синтезу **II, VII, IX, X** і білків C, S. **Варфарин** блокує вітамін K.

### 2.4. Ретракція і фібриноліз
- **Ретракція**: тромбоцити стискають згусток, вичавлюючи сироватку.
- **Фібриноліз**: **плазмін** (з плазміногену, активатор — **tPA**) розщеплює фібрин → **D-димери**.

## 3. Антикоагулянтні механізми

| Механізм | Дія |
|---|---|

## 4. Тести

| Тест | Що оцінює | Норма |
|---|---|---|
| **Кількість тромбоцитів** | | 180–320 ×10⁹/л |

## 5. Хвороби

| Стан | Суть |
|---|---|
| **Гемофілія A** | дефіцит VIII; X-зчеплена рецесивна; гемартрози; ↑ АЧТЧ |
| **Гемофілія B** | дефіцит IX |
| **Хвороба фон Віллебранда** | дефіцит vWF; найчастіше спадкове порушення; слизові кровотечі |
| **ІТП** | імунна тромбоцитопенія; антитіла проти тромбоцитів |
| **ДВЗ-синдром** | розсіяне внутрішньосудинне згортання → витрата факторів → кровотечі і тромбози |
| **Дефіцит вітаміну K** | ↓ II, VII, IX, X; новонароджені, холестаз, антибіотики |
| **Тромбоз** | утворення тромба в судині ([[Хвороби судин]]): тріада Вірхова — стаз, ендотеліальне пошкодження, гіперкоагуляція |
| **Тромбофілії** | мутація фактора V Лейдена, дефіцит антитромбіну, білків C і S |

Деталі: [[Хвороби крові і імунітету]].

## 6. Мнемоніки

- Гемостаз: **спазм → пробка → згусток**.
- Вітамін K-залежні фактори: **1972** (II, VII, IX, X).
- Зовнішній — **ПЧ** (VII); внутрішній — **АЧТЧ**.
- **Тріада Вірхова**: стаз, пошкодження стінки, гіперкоагуляція.
