# Еритроцити і гемоглобін (*erythrocyti*, *haemoglobinum*)

Еритроцит — безядерна клітина у формі двоввігнутого диска. Вона переносить O₂ і частково CO₂. Це найчисленніші формені елементи крові.

## 1. Будова еритроцита

| Ознака | Значення |
|---|---|
| Форма | **двоввігнутий диск** (*дискоцит*) |
| Діаметр | **~7,5 мкм** (норма — нормоцит) |
| Товщина | ~2 мкм по краю, ~1 мкм у центрі |
| Ядро і органели | **немає** (втрачені при дозріванні) |
| Метаболізм | **анаеробний гліколіз** (не споживає O₂ що переносить) |
| Мембрана | **спектрин** + актин — еластичний цитоскелет; **антигени груп крові** |
| Вміст | ~**95% сухої маси — гемоглобін** |
| Тривалість життя | **~120 днів** |

- Двоввігнута форма збільшує **площу поверхні** і дає змогу проходити крізь капіляри діаметром 3–5 мкм.
- **Загальна кількість**: ~25 трильйонів; ~2,4 млн нових клітин за секунду.

## 2. Гемоглобін (Hb)

**Гемоглобін** — тетрамер із **4 субодиниць**; кожна має **гем** з іоном **Fe²⁺** і поліпептидний ланцюг (глобін).

| Тип | Ланцюги | Коли |
|---|---|---|
| **HbA** | α₂β₂ | **~97%** дорослого |
| **HbA₂** | α₂δ₂ | ~2–3% |
| **HbF** (фетальний) | α₂γ₂ | плід і новонароджений; **більша спорідненість до O₂** |
| **HbS** | α₂β₂ (зміна Glu→Val) | серпоподібноклітинна анемія |

- **Норма Hb**: чоловіки 130–160 г/л; жінки 120–150 г/л.
- Одна молекула Hb зв'язує **4 O₂**; 1 г Hb — ~1,34 мл O₂.
- **Кооперативність**: кожен приєднаний O₂ збільшує спорідненість → **S-подібна** крива дисоціації (див. [[Дихання — газообмін і транспорт газів]]).

### Похідні гемоглобіну
| Форма | Утворення | Значення |
|---|---|---|
| **Оксигемоглобін** (HbO₂) | Hb + O₂ | яскраво-червоний (артеріальна кров) |
| **Дезоксигемоглобін** | віддав O₂ | темніший (венозна кров) |
| **Карбгемоглобін** | Hb + CO₂ (на глобіні) | ~20% CO₂ |
| **Карбоксигемоглобін** | Hb + **CO** | спорідненість до CO **у 200–250 разів вища**; отруєння чадним газом |
| **Метгемоглобін** | Fe²⁺ → **Fe³⁺** | не зв'язує O₂; нітрити, анілін |

## 3. Показники

| Показник | Норма | Значення |
|---|---|---|
| **MCV** | 80–100 фл | об'єм клітини |
| **MCH** | 27–33 пг | Hb в одній клітині |
| **MCHC** | 320–360 г/л | концентрація Hb |
| **Ретикулоцити** | 0,2–1,2% | молоді клітини; індекс кісткового мозку |
| **Гематокрит** | чол. 40–50%, жін. 36–46% | частка клітин |

Анізоцитоз — різний розмір; пойкілоцитоз — різна форма.

## 4. Утворення: еритропоез

Повний шлях: **гемоцитобласт** → **проеритробласт** → **еритробласт** → **нормобласт** (викидає ядро) → **ретикулоцит** → **еритроцит**. Займає **~7 днів** у червоному кістковому мозку ([[Кровотворення]]).

| Фактор | Роль |
|---|---|
| **Еритропоетин** (EPO) | нирки (інтерстиційні клітини) відповідають на **гіпоксію**; стимулює еритропоез |
| **Залізо** | синтез гему |
| **Вітамін B₁₂ і фолієва кислота** | синтез ДНК, поділ клітин |
| **Вітамін B₆, мідь, білок** | синтез гему, транспорт заліза |
| **Андрогени, тироксин, кортизол** | стимулюють |

### Обмін заліза
- Усього **3–4 г**; ~65% — у гемоглобіні.
- **Всмоктується** у дванадцятипалій кишці (Fe²⁺; вітамін C покращує) ([[Тонка кишка — травлення і всмоктування]]).
- **Транспорт**: **трансферин**; **запас**: **феритин**, гемосидерин (печінка, селезінка, кістковий мозок).
- **Гепсидин** (печінка) регулює всмоктування.
- Втрата ~1–2 мг/добу; жінки втрачають більше (менструація).

## 5. Руйнування

- **Місце**: **селезінка** (червона пульпа), також печінка і кістковий мозок ([[Селезінка]]). Старі клітини втрачають еластичність → фагоцитоз макрофагами.
- Гем → **білівердин → білірубін** (непрямий) → печінка → жовч (див. [[Печінка — функції]]).
- Залізо повторно використовується.
- **Гемоліз** — руйнування в судині → ↑ білірубін, жовтяниця.

## 6. Хвороби еритроцитів

| Стан | Суть |
|---|---|
| **Анемія** | ↓ Hb: чол. < 130, жін. < 120 г/л |
| **Залізодефіцитна анемія** | найчастіша; **мікроцити, гіпохромія** (↓ MCV, MCH); кровотеча, дефіцит у їжі |
| **B₁₂-дефіцитна (пернічозна)** | **мегалобласти, макроцити** (↑ MCV); немає внутрішнього фактора Касла (атрофія шлунка); неврологічні симптоми |
| **Фолієводефіцитна** | мегалобластна, без неврології |
| **Гемолітичні** | вроджені (сфероцитоз, серпоподібна, таласемія) і набуті |
| **Апластична** | аплазія кісткового мозку |
| **Постгеморагічна** | крововтрата |
| **Поліцитемія** | ↑ еритроцити: істинна (JAK2); вторинна (гіпоксія) |

Деталі: [[Хвороби крові і імунітету]].

## 7. Мнемоніки

- **120 днів** життя; 7 днів дозрівання.
- Гем: **Fe²⁺ — O₂**; CO в 200+ разів міцніше.
- **EPO — нирки**; **B₁₂ + фолат — ДНК**; **залізо — гем**.
- MCV: **мікро** (залізо), **макро** (B₁₂/фолат).
