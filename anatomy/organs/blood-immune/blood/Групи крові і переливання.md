# Групи крові і переливання (*systema AB0*, *Rhesus*)

Група крові визначається антигенами на мембрані еритроцитів. Найважливіші системи — **AB0** і **резус (Rh)**. Помилка при переливанні викликає гемоліз і може вбити пацієнта.

## 1. Система AB0

Відкрив **Карл Ландштейнер** (1901). Антигени (аглютиногени) стоять на еритроцитах; антитіла (аглютиніни) є у плазмі **природно**, без попередньої зустрічі.

| Група | Антиген на еритроцитах | Антитіла в плазмі | Частота (Європа) |
|---|---|---|---|
| **I (0)** | немає | **анти-A, анти-B** | ~40% |
| **II (A)** | **A** | анти-B | ~40% |
| **III (B)** | **B** | анти-A | ~15% |
| **IV (AB)** | **A і B** | немає | ~5% |

- Антигени A і B — цукри, приєднані до H-антигена (ген *ABO*, хромосома 9).
- Спадкування: A і B **домінантні**, 0 рецесивний. Генотип: 00 → I; AA/A0 → II; BB/B0 → III; AB → IV.

### Сумісність переливання еритроцитів
| Реципієнт ↓ \ Донор → | 0 | A | B | AB |
|---|---|---|---|---|
| **0** | + | − | − | − |
| **A** | + | + | − | − |
| **B** | + | − | + | − |
| **AB** | + | + | + | + |

- **Універсальний донор еритроцитів**: група **0(I) Rh−**.
- **Універсальний реципієнт**: група **AB(IV) Rh+**.
- Для **плазми** — навпаки: універсальний донор AB.

## 2. Резус-система

Антиген **D** (резус-фактор). Є — **Rh⁺** (~85%); немає — **Rh⁻** (~15%).

- Антитіл проти Rh **природно немає**; вони утворюються після контакту (переливання, вагітність).
- Rh⁻ реципієнту **не можна** переливати Rh⁺ кров (при повторному — гемоліз).

### Резус-конфлікт при вагітності
| Умова | Наслідок |
|---|---|
| Мати **Rh⁻**, плід **Rh⁺** | при пологах еритроцити плода потрапляють до матері → **анти-D IgG** |
| Наступна вагітність Rh⁺ плодом | IgG проходять плаценту → **гемолітична хвороба новонародженого** (анемія, жовтяниця, набряк плода *hydrops fetalis*) |
| Профілактика | **анти-D імуноглобулін** матері на 28 тижні і після пологів Rh⁺ дитини |

Також є гемолітична хвороба через AB0 (мати 0, дитина A/B); зазвичай легша.

## 3. Інші системи

Kell, Duffy, Kidd, MNS, Lewis — мають значення при багаторазових переливаннях. **Бомбейський фенотип** — немає H-антигена; реагує як 0, але має анти-H.

## 4. Переливання крові

| Компонент | Показання |
|---|---|
| **Еритроцитарна маса** | анемія, крововтрата |
| **Тромбоцитарна маса** | тромбоцитопенія з кровотечею |
| **Свіжозаморожена плазма** | дефіцит факторів згортання |
| **Кріопреципітат** | гіпофібриногенемія, гемофілія A |
| **Альбумін** | гіпоальбумінемія |

### Перед переливанням
1. Визначення групи AB0 і Rh реципієнта.
2. **Проба на індивідуальну сумісність** (перехресна).
3. **Біологічна проба** (повільно перелити 10–15 мл, спостерігати).

### Реакції і ускладнення
| Тип | Причина | Прояви |
|---|---|---|
| **Гострий гемоліз** | несумісність AB0 | лихоманка, біль у попереку, гіпотензія, гемоглобінурія, ниркова недостатність, ДВЗ |
| **Фебрильна негемолітична** | антитіла до лейкоцитів | підвищення температури |
| **Алергічна / анафілаксія** | IgE; IgA-дефіцит | висип, бронхоспазм |
| **TRALI** | антитіла донора в легенях | гостра дихальна недостатність |
| **Перевантаження об'ємом** | | набряк легень |
| **Інфекції** | віруси, бактерії | |
| **Цитратна інтоксикація** | зв'язування Ca²⁺ | судоми, аритмія |

## 5. Мнемоніки

- 0 — «ніщо» на еритроцитах → універсальний донор; AB — «все» → універсальний реципієнт.
- **Rh⁻ мати + Rh⁺ дитина** → проблема з **другою** вагітністю.
- **Ландштейнер** — AB0; **Мечников** — фагоцитоз.
