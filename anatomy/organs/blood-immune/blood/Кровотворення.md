# Кровотворення (*haemopoesis*)

Кровотворення — це утворення клітин крові з однієї **гемопоетичної стовбурової клітини** (HSC). У дорослого воно відбувається в **червоному кістковому мозку**. Щосекунди організм виробляє мільйони нових клітин.

## 1. Місця кровотворення за віком

| Період | Орган |
|---|---|
| **3 тиждень – 2 міс.** (ембріон) | **жовтковий мішок** (мезобластичний) |
| **2–7 міс.** (плід) | **печінка** (основне), селезінка |
| **з 5 міс.** | **червоний кістковий мозок** |
| **Після народження** | кістковий мозок усіх кісток |
| **Дорослий** | червоний мозок: **грудина, ребра, хребці, кістки таза, череп, проксимальні кінці стегнових і плечових**; у діафізах довгих кісток — **жовтий** (жировий) мозок |

- У дорослого ~**1,5–3 кг** кісткового мозку; близько половини — кровотворна.
- **Позамедулярне кровотворення** (печінка, селезінка) виникає при тяжкому ураженні мозку (мієлофіброз).

## 2. Ієрархія клітин

| Рівень | Клітини | Властивості |
|---|---|---|
| **1. Стовбурова (HSC)** | CD34⁺ | самооновлення, плюрипотентна; дуже рідкісна (~1 на 10⁵ клітин мозку) |
| **2. Клітини-попередниці** | **CFU-GEMM** (мієлоїдна), **CLP** (лімфоїдна) | обмежена потентність |
| **3. Унипотентні попередниці** | CFU-E, CFU-G, CFU-M, CFU-Meg, CFU-Eo, CFU-Ba | одна лінія |
| **4. Бласти** | еритробласт, мієлобласт, лімфобласт, мегакаріобласт | впізнавані під мікроскопом |
| **5. Дозріваючі форми** | промієлоцит → мієлоцит → метамієлоцит → паличкоядерний → сегментоядерний | |
| **6. Зрілі клітини** | еритроцити, лейкоцити, тромбоцити | виходять у кров |

### Лінії
| Мієлоїдна лінія (CMP) | Лімфоїдна лінія (CLP) |
|---|---|
| еритроцити | В-лімфоцити |
| тромбоцити (з мегакаріоцитів) | Т-лімфоцити (дозрівають у тимусі) |
| нейтрофіли, еозинофіли, базофіли | NK-клітини |
| моноцити → макрофаги, дендритні клітини | |

## 3. Мікросередовище (ніша)

Стовбурові клітини живуть у нішах: **остеобласти, ендотелій синусоїдів, ретикулярні клітини (CAR), мезенхімні клітини**. Вони дають сигнали (SCF, CXCL12) для виживання і поділу. Кістковий мозок має **синусоїдні капіляри**: клітини виходять у кров через пори.

## 4. Регуляція (цитокіни і гормони)

| Фактор | Джерело | Дія |
|---|---|---|
| **Еритропоетин (EPO)** | **нирки** (90%), печінка | еритроцити; ↑ при гіпоксії |
| **Тромбопоетин (TPO)** | печінка | мегакаріоцити, тромбоцити |
| **G-CSF** | моноцити, ендотелій | нейтрофіли |
| **GM-CSF** | Т-клітини, макрофаги | гранулоцити і моноцити |
| **M-CSF** | | моноцити |
| **IL-3, SCF** | | всі лінії |
| **IL-7** | | лімфоцити |
| **Андрогени, тироксин** | | стимулюють |
| **Вітамін B₁₂, фолат, залізо** | їжа | потрібні для синтезу ДНК і гему |

Лікарські аналоги: рекомбінантний EPO (анемія при хворобі нирок), G-CSF (нейтропенія після хіміотерапії).

## 5. Тривалість життя і оновлення

| Клітина | Життя | Місце загибелі |
|---|---|---|
| Еритроцит | 120 днів | селезінка |
| Тромбоцит | 8–10 днів | селезінка, печінка |
| Нейтрофіл | години в крові, дні в тканині | тканина |
| Моноцит | 1–3 доби в крові | → макрофаг (місяці) |
| Лімфоцит | дні – роки (пам'ять — десятиліття) | |

## 6. Трансплантація стовбурових клітин

| Джерело | Приклад |
|---|---|
| **Кістковий мозок** | пункція клубової кістки |
| **Периферична кров** | після мобілізації G-CSF |
| **Пуповинна кров** | банки пуповинної крові |

Показання: лейкози, лімфоми, апластична анемія, імунодефіцити. Ризик: **реакція «трансплантат проти хазяїна»** (GVHD), інфекції.

## 7. Пункція і аналіз мозку

**Стернальна пункція** або **трепанобіопсія клубової кістки**. Оцінюють **мієлограму** (відсоток клітин), клітинність, бласти. Норма: бластів < 5%.

## 8. Мнемоніки

- Плід: **жовток → печінка → кістка**.
- **EPO — нирки; TPO — печінка**.
- Дві лінії: **мієлоїдна** (еритро-, тромбо-, гранулоцити, моноцити) і **лімфоїдна** (В, Т, NK).
