# Селезінка (*splen*, *lien*)

Селезінка — найбільший лімфоїдний орган. Вона розташована в лівому підребер'ї. Фільтрує кров, знищує старі еритроцити, є депо крові й місцем імунної відповіді на антигени крові. Лімфатичні вузли фільтрують лімфу; селезінка фільтрує кров.

## 1. Положення і зв'язки

| Показник | Значення |
|---|---|
| Положення | **ліве підребер'я** (*hypochondrium sinistrum*), під діафрагмою; проекція на ребра **IX–XI** (по середній пахвовій лінії) |
| Розміри | довжина ~12 см, ширина 8 см, товщина 4 см |
| Маса | **150–200 г** |
| Вісь | уздовж X ребра |
| Покриття | **інтраперитонеально** (з усіх боків, крім воріт); капсула + серозна оболонка |

### Поверхні
| Поверхня | Прилягає до |
|---|---|
| **Діафрагмальна** (*facies diaphragmatica*) | діафрагма, ребра |
| **Вісцеральна** (*facies visceralis*) | **шлункова** (шлунок), **ниркова** (ліва нирка), **кишкова** (ободова кишка), **підшлункова** (хвіст підшлункової залози) |
| **Ворота** (*hilum splenicum*) | вхід судин і нервів |

### Зв'язки очеревини
- **Шлунково-селезінкова** (*lig. gastrosplenicum*) — короткі шлункові судини.
- **Селезінково-ниркова** (*lig. splenorenale*) — хвіст підшлункової залози, селезінкові судини.
- **Діафрагмово-ободовокишкова** — опора.

Докладно про зв'язки: [[Очеревина]].

## 2. Судини і нерви

| Структура | Походження |
|---|---|
| **Селезінкова артерія** (*a. lienalis*) | найбільша гілка **черевного стовбура** ([[Аорта і її гілки]]); іде вздовж верхнього краю підшлункової залози |
| **Селезінкова вена** (*v. lienalis*) | зливається з верхньою брижовою → **ворітна вена** ([[Вени — нижня порожниста і ворітна системи]]) |
| **Нерви** | **селезінкове сплетення** (симпатичні волокна з чревного сплетення) |
| Лімфа | вузли воріт селезінки |

Спленомегалія при портальній гіпертензії: застій у ворітній системі.

## 3. Гістологія

Капсула має гладком'язові клітини й трабекули.

### Біла пульпа (~20%)
Лімфоїдна тканина навколо артеріол.

| Структура | Клітини |
|---|---|
| **Періартеріальна лімфатична піхва (PALS)** | **Т-клітини** |
| **Лімфатичні фолікули** | **В-клітини**, центри розмноження |
| **Крайова зона** | макрофаги, В-клітини; захоплює антигени крові (інкапсульовані бактерії) |

### Червона пульпа (~80%)
- **Селезінкові синуси** (венозні) — фенестровані стінки.
- **Тяжі Більрота** — макрофаги, еритроцити, плазматичні клітини.
- **Фільтр**: щілини між клітинами ендотелію ~2–3 мкм; **здорові еритроцити протискуються, старі й дефектні — ні** та фагоцитуються.

### Кровообіг
Селезінкова артерія → трабекулярні → **центральні артерії** → **пензлики (penicilli)** → відкритий і закритий кровотік → синуси → пульпарні вени → трабекулярні → селезінкова вена.

## 4. Функції

| Функція | Опис |
|---|---|
| **Знищення еритроцитів** | старі клітини (>120 днів), дефектні; гем → білірубін, залізо повторно використовується ([[Еритроцити і гемоглобін]]) |
| **Видалення включень** | тільця Говелла–Джоллі, Гейнца, паразити (малярія) |
| **Імунна** | захист від **інкапсульованих бактерій** (*Streptococcus pneumoniae*, *Haemophilus influenzae*, *Neisseria meningitidis*) |
| **Депо крові** | ~**200–250 мл** крові (у людини невелике); депо **тромбоцитів** (~⅓) |
| **Кровотворення** | у плода (2–7 міс.); у дорослого — при мієлофіброзі |
| **Утворення лімфоцитів і плазматичних клітин** | |

## 5. Хвороби і стани

| Стан | Суть |
|---|---|
| **Спленомегалія** | збільшення: портальна гіпертензія, лейкози, лімфоми, малярія, мононуклеоз, гемолітична анемія |
| **Гіперспленізм** | надмірне руйнування клітин → ↓ еритроцити, лейкоцити, тромбоцити |
| **Розрив селезінки** | травма лівого підребер'я, мононуклеоз; **кровотеча**; **симптом Кера** (біль у лівому плечі) |
| **Інфаркт селезінки** | емболія селезінкової артерії |
| **Спленектомія** | після розриву, ІТП; наслідки: тромбоцитоз, **тільця Говелла–Джоллі**, ризик **OPSI** (тяжкий сепсис) — потрібні вакцини проти пневмокока, менінгокока, Hib |
| **Додаткова селезінка** | у ~10–30% (*lien accessorius*); при ІТП може підтримувати хворобу |

## 6. Мнемоніки

- Селезінка: **1–3–5–7–9–11**: розмір 1×3×5 дюймів, маса 7 унцій, ребра 9–11.
- Фільтр крові (як лімфовузол для лімфи).
- Білу пульпу — лімфоцити; червону — еритроцити.
- Після видалення — **вакцини** проти інкапсульованих бактерій.
