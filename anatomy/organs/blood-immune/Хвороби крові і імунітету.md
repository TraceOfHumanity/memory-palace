## 1. Анемії

| Тип | MCV | Причина | Особливості |
|---|---|---|---|
| **Залізодефіцитна** | ↓ | кровотеча, дефіцит, всмоктування | ↓ феритин, ↓ сироваткове залізо, ↑ трансферин; койлонихія |
| **Анемія хронічних хвороб** | ↓/N | запалення, гепсидин ↑ | ↑ феритин |
| **Таласемія** | ↓ | мутації генів глобіну | мішенеподібні клітини; Середземномор'я |
| **B₁₂-дефіцитна** | ↑ | пернічозна (Касл), вегани, резекція шлунка | неврологія (фунікулярний мієлоз) |
| **Фолієводефіцитна** | ↑ | алкоголь, вагітність | без неврології |
| **Гемолітична** | N | сфероцитоз, G6PD, серпоподібна, аутоімунна | ↑ ретикулоцити, ↑ непрямий білірубін, ↓ гаптоглобін |
| **Апластична** | N | аплазія мозку | панцитопенія |
| **Гостра крововтрата** | N | | |

Ознаки анемії: слабкість, блідість, тахікардія, задишка.

### Серпоподібноклітинна анемія
Мутація β-глобіну (HbS); в умовах гіпоксії клітини стають серпоподібними → оклюзія судин (кризи), гемоліз. Захист від малярії у носіїв.

## 3. Лейкози і лімфоми

| Хвороба | Суть |
|---|---|
| **ГЛЛ (гострий лімфобластний)** | діти; бласти > 20%; лікується добре |
| **ГМЛ (гострий мієлоїдний)** | дорослі; **тільця Ауера**; промієлоцитарний варіант — t(15;17), ATRA |
| **ХМЛ** | **t(9;22), BCR-ABL** (Філадельфійська хромосома); іматиніб |
| **ХЛЛ** | літні; лімфоцитоз; «тіні Готкіна–Ґумпрехта» |
| **Лімфома Годжкіна** | клітини Рід–Штернберга; шийні вузли, молодий вік |
| **Неходжкінські лімфоми** | дифузна В-великоклітинна, фолікулярна, Беркітта |
| **Множинна мієлома** | пухлина плазматичних клітин; **CRAB** (↑Ca, нирки, анемія, кістки), білок Бенс-Джонса |

Прояви: лихоманка, нічна пітливість, втрата ваги (**B-симптоми**), лімфаденопатія, спленомегалія, кровотечі, інфекції.

## 4. Порушення гемостазу

| Група | Приклади |
|---|---|
| **Тромбоцитарні** | ІТП, ТТП, ГУС, ДВЗ |
| **Коагуляційні** | гемофілії A/B, хвороба фон Віллебранда, дефіцит вітаміну K, хвороба печінки |
| **Судинні** | васкуліти, цинга (вітамін C), геморагічний васкуліт |
| **Тромбофілії** | фактор V Лейдена, дефіцит антитромбіну, білків C/S, антифосфоліпідний синдром |

Лікування: антикоагулянти (гепарин, НМГ, варфарин, ривароксабан), антиагреганти (аспірин). Деталі: [[Тромбоцити і гемостаз]].

## 8. Мнемоніки

- Анемія: **мікро** (залізо, таласемія), **макро** (B₁₂, фолат), **нормо** (гемоліз, гостра втрата, аплазія).
- **CRAB** при мієломі: Calcium, Renal, Anemia, Bone.
- **ХМЛ = 9;22 (BCR-ABL), іматиніб**.
- **B-симптоми**: лихоманка, нічна пітливість, схуднення.
