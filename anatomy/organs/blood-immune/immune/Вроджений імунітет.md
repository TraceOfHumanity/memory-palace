# Вроджений імунітет (*immunitas innata*)

Вроджений імунітет — це перша лінія захисту. Він діє **одразу** (хвилини–години), не потребує попереднього контакту з антигеном і **не має пам'яті**. Розпізнає загальні ознаки мікробів, а не окремі антигени.

## 1. Бар'єри

| Бар'єр | Механізм |
|---|---|
| **Шкіра** | зроговілий епідерміс; кисла поверхня (pH 4–6); дефензини; нормальна флора ([[Шкіра — епідерміс]]) |
| **Слизові** | слиз, війки (**мукоциліарний кліренс** дихальних шляхів), чхання, кашель |
| **Рідини** | сльози, слина (**лізоцим**, IgA), піт |
| **Шлунок** | HCl, pH 1–2 ([[Шлунок — секреція і моторика]]) |
| **Сеча** | потік, кисла реакція |
| **Мікробіота** | конкуренція з патогенами (кишка, піхва, шкіра) |

## 2. Розпізнавання патогенів

| Елемент | Приклад |
|---|---|
| **PAMP** (патоген-асоційовані молекулярні структури) | ліпополісахарид (LPS) бактерій, пептидоглікан, РНК вірусів, бета-глюкан грибів |
| **PRR** (рецептори розпізнавання) | **TLR** (Toll-подібні рецептори), NLR, RLR, рецептори-«сміттярі» |
| **DAMP** | сигнали пошкоджених власних клітин (АТФ, HMGB1) |

Зв'язування PAMP з PRR → активація клітини → цитокіни (**IL-1, IL-6, TNF-α**) → запалення.

## 3. Клітини

| Клітина | Функція |
|---|---|
| **Нейтрофіл** | фагоцитоз, NET; перший на місці |
| **Макрофаг** | фагоцитоз, цитокіни, презентація антигена |
| **Дендритна клітина** | захоплює антиген і несе його до лімфовузла ([[Лімфатичні вузли і мигдалики]]) |
| **Тучна клітина / базофіл** | гістамін при пошкодженні й алергії |
| **Еозинофіл** | паразити |
| **NK-клітина** | вбиває заражені віруси та пухлинні клітини, що не мають MHC I; перфорин, гранзими |
| **Епітелій** | дефензини, цитокіни |

### Фагоцитоз (етапи)
1. **Хемотаксис** — рух до сигналу (C5a, IL-8, бактеріальні пептиди).
2. **Розпізнавання і прикріплення** (опсоніни: **IgG, C3b**).
3. **Поглинання** — утворення **фагосоми**.
4. **Злиття з лізосомою** → **фаголізосома**.
5. **Знищення** — кисневі радикали, NO, ферменти.
6. **Виведення залишків**.

## 4. Запалення (*inflammatio*)

**Класичні ознаки (Цельс + Гален):** **rubor** (почервоніння), **tumor** (набряк), **calor** (жар), **dolor** (біль), **functio laesa** (порушення функції).

| Фаза | Що відбувається |
|---|---|
| **Судинна** | розширення судин (гістамін, NO, простагландини) → ↑ кровотік; ↑ проникність → **ексудат** |
| **Клітинна** | **маргінація** → адгезія до ендотелію (селектини, інтегрини) → **діапедез** → хемотаксис |
| **Завершення** | видалення агента, регенерація або рубець |

Системні прояви: **лихоманка** (IL-1, IL-6 → простагландин E₂ у гіпоталамусі), лейкоцитоз, **білки гострої фази** (**C-реактивний білок**, фібриноген) → ↑ ШОЕ, сонливість.

Види: **серозне**, **фібринозне**, **гнійне** (абсцес, флегмона, емпієма), **геморагічне**. Гостре і **хронічне** (макрофаги, лімфоцити, гранульома).

## 5. Система комплементу

Близько 30 білків плазми (синтез — печінка). Каскад активації:

| Шлях | Запуск |
|---|---|
| **Класичний** | комплекси антиген–антитіло (IgM, IgG) → C1 |
| **Лектиновий** | маноза на бактерії → MBL |
| **Альтернативний** | прямий контакт C3 з поверхнею мікроба |

Усі шляхи сходяться на **C3** → **C3b** (опсонізація) → **C5** → **C5b-C9** = **мембраноатакуючий комплекс (MAC)**, що продірявлює мембрану бактерії. **C3a, C5a** — анафілатоксини (хемотаксис, гістамін).

## 6. Інтерферони і цитокіни

- **Інтерферони I типу (α, β)**: клітини, заражені вірусом, виробляють їх → сусіди переходять в «антивірусний стан».
- **IFN-γ**: NK і Т-клітини активують макрофаги.
- **TNF-α**: запалення, шок при сепсисі.

## 7. Хвороби

| Стан | Суть |
|---|---|
| **Сепсис** | системна відповідь на інфекцію; **септичний шок** — гіпотензія |
| **Дефіцит комплементу** | C3 — часті бактеріальні інфекції; C5–C9 — нейсерії |
| **Хронічна грануломатозна хвороба** | дефект респіраторного вибуху нейтрофілів |
| **Аутозапальні синдроми** | надмірна активація без антигена |

## 8. Мнемоніки

- Запалення: **rubor, tumor, calor, dolor, functio laesa**.
- Вроджений: **швидко, неспецифічно, без пам'яті**.
- Комплемент: **C3 — ключ; C5b-C9 — «дірокол»**.
