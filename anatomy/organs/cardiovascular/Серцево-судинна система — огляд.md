# Серцево-судинна система — огляд (*systema cardiovasculare*)

Серцево-судинна система транспортує кров по тілу. Вона доставляє кисень і поживні речовини, забирає CO₂ і продукти обміну, переносить гормони та клітини імунітету, підтримує температуру й pH.

## 1. Склад системи

| Складова | Функція |
|---|---|
| **Серце** (*cor*) | м'язовий насос; створює тиск і напрямок руху крові |
| **Артерії** (*arteriae*) | несуть кров **від** серця |
| **Артеріоли** | регулюють опір і розподіл крові |
| **Капіляри** | обмін між кров'ю й тканинами |
| **Венули і вени** (*venae*) | несуть кров **до** серця; резервуар крові |
| **Лімфатична система** | повертає рідину з тканин у кров, імунний захист |

Артерія — судина **від** серця (незалежно від складу крові). Вена — судина **до** серця.

## 2. Два кола кровообігу

| Коло | Шлях | Мета |
|---|---|---|
| **Мале (легеневе)** | правий шлуночок → легеневий стовбур → легеневі артерії → капіляри легень → 4 легеневі вени → ліве передсердя | газообмін: кров віддає CO₂ й бере O₂ |
| **Велике (системне)** | лівий шлуночок → аорта → артерії → капіляри органів → вени → верхня й нижня порожнисті вени → праве передсердя | живлення всіх органів |

Правило: у малому колі **артерії несуть венозну** кров, **вени — артеріальну**. У великому — навпаки.

Серце й кола з'єднані **послідовно**. Праве й ліве серце перекачують однаковий об'єм за хвилину.

### Допоміжні кола
- **Коронарне** (серцеве): живить сам міокард, див. [[Серце — коронарні судини]].
- **Ворітне** (печінкове): кров від непарних органів черева через ворітну вену до печінки.
- **Плацентарне** (у плода): через пуповину; див. [[Серце — розвиток і вади]].

## 3. Основні числа

| Показник | Значення (дорослий у спокої) |
|---|---|
| Об'єм крові | 4,5–5,5 л (~7% маси тіла) |
| ЧСС | 60–100/хв |
| Ударний об'єм | ~70 мл |
| Серцевий викид (хвилинний об'єм) | ~5 л/хв (при навантаженні до 20–25 л/хв) |
| Артеріальний тиск | ~120/80 мм рт. ст. |
| Швидкість крові в аорті | ~30–50 см/с |
| Швидкість у капілярах | ~0,03 см/с (0,3–1 мм/с) |
| Час повного кола | ~20–30 с |

Серце скорочується ~100 000 разів на добу й перекачує ~7000 л крові.

## 4. Типи судин (коротко)

| Судина | Діаметр | Стінка | Особливість |
|---|---|---|---|
| **Аорта** | 25–30 мм | еластична | «компресійна камера» |
| **Артерії м'язового типу** | 0,5–10 мм | гладком'язова | розподіл крові |
| **Артеріоли** | 10–100 мкм | гладком'язова | головний опір (регуляція тиску) |
| **Капіляри** | 5–10 мкм | ендотелій + базальна мембрана | обмін |
| **Венули** | 10–100 мкм | тонка | збір крові |
| **Вени** | до 30 мм | тонка, **клапани** | ємність; містять ~65% крові |

## 5. Регуляція

1. **Нервова**: симпатика (↑ ЧСС, звуження судин) і парасимпатика (↓ ЧСС). Див. [[Вегетативна нервова система]], [[Серце — іннервація]].
2. **Гуморальна**: адреналін, ренін-ангіотензин-альдостерон, АДГ, передсердний натрійуретичний пептид.
3. **Місцева**: NO, аденозин, CO₂, H⁺ розширюють судини (ауторегуляція).

## 6. Розташування в тілі (орієнтири)

- Серце лежить у **середостінні**, в грудній клітці. Див. [[Серце — огляд і положення]], [[Грудна клітка]].
- Аорта виходить з лівого шлуночка, утворює дугу й іде вздовж хребта. Верхня порожниста вена збирає кров від голови й рук, нижня — від ніг і тулуба.
- Судини мозку: [[Кровопостачання мозку]].

## 7. Клінічні поняття

| Термін | Значення |
|---|---|
| **Ішемія** | нестача кровотоку |
| **Інфаркт** | некроз тканини через ішемію |
| **Атеросклероз** | відкладення бляшок у стінці артерій |
| **Тромбоз, емболія** | закупорка судини згустком |
| **Гіпертензія** | підвищений тиск (> 140/90) |
| **Гіпотензія** | знижений тиск |
| **Шок** | гостра недостатність перфузії тканин |
| **Серцева недостатність** | серце не забезпечує потреб організму |

Докладніше: [[Серце — хвороби]].

## 8. Мнемоніки

- **Артерія — Від серця**, вена — до серця.
- Мале коло: *ПШ → легені → ЛП*; велике: *ЛШ → тіло → ПП*.
- Серце «йде» по колу в порядку: **ПП → ПШ → легені → ЛП → ЛШ → аорта**.
