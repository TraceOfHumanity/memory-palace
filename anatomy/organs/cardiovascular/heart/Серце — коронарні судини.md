# Серце — коронарні судини

Міокард живлять власні **вінцеві (коронарні) артерії**. Вони відходять від початку аорти. Кров повертається через **вени серця** і **коронарний синус** у праве передсердя.

## 1. Загальні відомості

- Кількість артерій: **2** (права і ліва).
- Початок: **синуси Вальсальви** аортального клапана; гирла вінцевих артерій лежать над півмісячними заслінками (див. [[Серце — камери і клапани]]).
- Кровотік: **~250 мл/хв** у спокої (4–5% серцевого викиду), при навантаженні в 4–5 разів більше.
- Особливість: **кровотік лівого шлуночка — переважно в діастолу**, бо під час систоли стиснутий міокард перетискає судини.
- Витяг кисню з крові **~70–80%** (максимальний в організмі) — резерв лише в розширенні судин.
- Артерії кінцеві (**функціонально**), анастомози слабкі.

## 2. Ліва вінцева артерія (*a. coronaria sinistra*, ЛВА, LCA)

Відходить з лівого синуса. Довжина стовбура 1–2 см. Ховається за легеневим стовбуром і ділиться на **дві гілки** (іноді три).

### Передня міжшлуночкова гілка (*ramus interventricularis anterior*, ПМШГ, LAD)
«**вдовотворець**» (англ. *widow maker*): закупорка небезпечна. Іде в передній міжшлуночковій борозні до верхівки.

| Гілка | Живить |
|---|---|
| **Діагональні гілки** | передньо-бічну стінку ЛШ |
| **Перегородкові перфоранти** | **передні 2/3 міжшлуночкової перегородки**, ніжки пучка Гіса |
| Гілка до правого шлуночка | передня стінка ПШ (частково) |
| Верхівка | **верхівка серця** |

LAD живить ~**45–55% маси ЛШ**.

### Огинаюча гілка (*ramus circumflexus*, ОГ, LCx)
Іде в лівій вінцевій борозні, обходить лівий край.

| Гілка | Живить |
|---|---|
| **Гілки тупого краю** (*rr. marginales obtusi*) | бічну стінку ЛШ |
| **Передсердні гілки** | ліве передсердя |
| **Артерія SA-вузла** (у ~40%) | синусно-передсердний вузол |
| **Задня шлуночкова гілка** (при лівому типі) | задню стінку ЛШ |

## 3. Права вінцева артерія (*a. coronaria dextra*, ПВА, RCA)

Відходить з правого синуса. Іде у правій вінцевій борозні вперед, до правого краю, далі на діафрагмальну поверхню.

| Гілка | Живить |
|---|---|
| **Артерія конуса** | артеріальний конус |
| **Артерія SA-вузла** (~60%) | синусно-передсердний вузол |
| **Гілки правого краю** (*rr. marginales acuti*) | правий шлуночок |
| **Артерія AV-вузла** (~90%) | AV-вузол — при правому типі |
| **Задня міжшлуночкова гілка** (*r. interventricularis posterior*, ЗМШГ, PDA) | **задні 1/3 перегородки**, нижня стінка обох шлуночків |
| **Задня бічна (задньо-шлуночкова) гілка** | задньо-нижня частина ЛШ |

## 4. Типи кровопостачання (домінантність)

Домінантність визначає, **яка артерія дає задню міжшлуночкову гілку** (PDA).

| Тип | Частота | Опис |
|---|---|---|
| **Правий** | ~**70–80%** | PDA від ПВА |
| **Лівий** | ~10% | PDA від огинаючої |
| **Змішаний (збалансований)** | ~10–15% | PDA від обох |

«Домінантність» не означає, що артерія більша; важливо для оцінки зони ураження.

## 5. Колатералі

- Між гілками ПВА, ЛВА є **анастомози** (дрібні, 20–200 мкм) — «природні шунти».
- При хронічній ішемії (стеноз) вони розширюються → **колатеральний кровотік**, захищає від інфаркту.
- При гострій закупорці не встигають розкритись.

## 6. Венозний відтік

### Система коронарного синуса (до 85%)
**Коронарний синус** (*sinus coronarius*) — широка вена (2–3 см) на задній стороні в задній вінцевій борозні, впадає в **праве передсердя** (отвір з клапаном Тебезія).

| Вена | Шлях | Притоки |
|---|---|---|
| **Велика вена серця** (*v. cordis magna*) | передня міжшлуночкова борозна → вінцева борозна ліворуч → синус | супроводжує ПМШГ і огинаючу |
| **Середня вена серця** (*v. cordis media*) | задня міжшлуночкова борозна | супроводжує ЗМШГ |
| **Мала вена серця** (*v. cordis parva*) | правий край | супроводжує ПВА |
| **Задня вена лівого шлуночка**, **коса вена лівого передсердя (Маршалла)** | | |

### Передні вени серця
Дрібні, впадають **безпосередньо** у праве передсердя.

### Найменші вени (Тебезія)
Відкриваються в усі камери (особливо праві) через **отвори найменших вен**.

## 7. Лімфатичні судини і нерви

- Лімфа: коронарні лімфатичні судини → **трахеобронхіальні** і передні середостінні вузли.
- Нерви: [[Серце — іннервація]]. Вінцеві артерії розширюються під дією симпатичної (β₂) і метаболічних сигналів (аденозин).

## 8. Регуляція коронарного кровотоку

| Фактор | Ефект |
|---|---|
| **Метаболічна (ауторегуляція)** | ↑ потреба → ↑ **аденозин**, ↓ O₂, ↑ CO₂, H⁺, K⁺ → **вазодилатація** (основна) |
| Нервова | слабка; симпатика → непряма дія (↑ ЧСС → метаболіти) |
| **Діастолічний тиск** | перфузійний тиск у діастолі: **АТ діастолічний − тиск у ЛШ у кінці діастоли** |
| **ЧСС** | ↑ ЧСС → скорочується діастола → ↓ кровотік (зокрема в ЛШ) |

Тому **тахікардія** небезпечна при стенозі вінцевих. **β-блокатори** зменшують потребу в O₂.

## 9. Атеросклероз вінцевих артерій

**Ішемічна хвороба серця (ІХС)** — найчастіша причина смерті в світі.

### Патогенез
1. Ушкодження ендотелію (гіпертензія, паління, глюкоза, ЛПНЩ).
2. Накопичення ЛПНЩ у інтимі → пінисті клітини (макрофаги) → **жирова смужка**.
3. **Атеросклеротична бляшка** (холестерин, фіброзна капсула).
4. **Стеноз** → ішемія при навантаженні.
5. **Розрив бляшки** → тромбоз → гостра закупорка.

### Клінічні форми
| Форма | Суть | Ознаки |
|---|---|---|
| **Стабільна стенокардія** | стеноз > 70% | біль за грудниною при навантаженні, минає за 5–10 хв у спокої або після нітрогліцерину |
| **Нестабільна стенокардія** | бляшка тріснула, часткова закупорка | біль у спокої, наростає; **без** підвищення тропоніну |
| **Інфаркт міокарда (ІМ)** | повна закупорка → некроз | біль > 20 хв; ↑ **тропонін** |
| **Раптова коронарна смерть** | шлуночкова аритмія | |
| **Серцева недостатність** (ішемічна) | | |

## 10. Інфаркт міокарда

### Локалізація за артерією
| Артерія | Зона інфаркту | ЕКГ-відведення |
|---|---|---|
| **LAD (ПМШГ)** | **передня стінка**, верхівка, перегородка | V1–V4 (передньо-перегородковий), I, aVL |
| **Огинаюча** | **бічна стінка** ЛШ | I, aVL, V5–V6 |
| **ПВА** | **нижня (діафрагмальна) стінка**, ПШ | II, III, aVF |
| ПВА (проксимальна) | + інфаркт ПШ | V4R |
| **ЗМШГ** | нижньо-задній | II, III, aVF, V7–V9 (задній) |

### Ускладнення (за часом)
| Час | Ускладнення |
|---|---|
| Хвилини–години | **фібриляція шлуночків**, шлуночкова тахікардія |
| 2–4 дні | перикардит (епістенокардитичний) |
| 3–7 днів | **розрив вільної стінки** (тампонада), розрив перегородки (ДМШП), розрив сосочкового м'яза (мітральна недостатність) |
| Тижні | аневризма ЛШ, тромби, **синдром Дресслера** |
| Роки | хронічна серцева недостатність |

### Лікування (принципи)
- **Реперфузія**: чрескожне коронарне втручання (**ЧКВ**, стентування) протягом 90–120 хв; тромболізис.
- **Антитромботичні**: аспірин, клопідогрель/тикагрелор, гепарин.
- **Статини, β-блокатори, інгібітори АПФ**.
- **Час — це міокард**: до 6–12 год необхідно відновити кровотік.

### Хірургія
- **Аортокоронарне шунтування (АКШ)**: обхід стенозу; використовують **внутрішню грудну артерію** (до ЛВА) і **велику підшкірну вену** гомілки (у ПВА, діагональ).
- **Стентування**: балон + каркас-стент.

## 11. Інші судинні стани

- **Вазоспастична стенокардія (Принцметала)** — спазм вінцевої артерії, біль у спокої, підйом ST.
- **Синдром Х** — мікросудинна ішемія.
- **Аномальне відходження** вінцевих артерій (вроджене; раптова смерть у спортсменів).
- **Спонтанне розшарування вінцевої артерії** — молоді жінки, пов'язане з вагітністю.
- **Хвороба Кавасакі** — васкуліт дітей: аневризми коронарних артерій.

## 12. Мнемоніки

- **ПМШГ (LAD)** — «вдова-творець»; **ПВА** — «Правий + Нижній + Вузол» (нижній інфаркт, AV-вузол).
- Домінантність правого типу ~ **80%**.
- ЕКГ: **II, III, aVF — нижній (ПВА)**; **I, aVL, V5–V6 — бічний (ОГ)**; **V1–V4 — передній (LAD)**.
- **Вени**: велика — з ПМШГ, середня — з ЗМШГ, мала — з ПВА; усі → коронарний синус → ПП.
- Живлення у **діастолу** — тому аортальна недостатність (низький діастолічний тиск) погіршує коронарний кровотік.
