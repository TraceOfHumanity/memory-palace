# Серце — іннервація

Серце має власну автоматику ([[Серце — провідна система]]). Нерви її **не запускають**, а лише **змінюють**: частоту, силу скорочення й швидкість проведення. Серце іннервують вегетативні (симпатичні й парасимпатичні) та чутливі волокна.

Пов'язані файли: [[Серцево-судинна система — огляд]], [[Серце — огляд і положення]], [[Серце — серцевий цикл і гемодинаміка]], [[Серце — ЕКГ]], [[Серце — хвороби]], [[Вегетативна нервова система]], [[Черепні нерви]], [[Спинний мозок]], [[Стовбур мозку]], [[Спинномозкові нерви і сплетення]], [[Нервовий імпульс і синапс]].

## 1. Парасимпатична іннервація

| Ланка | Опис |
|---|---|
| **Центр** | дорсальне рухове ядро X і подвійне ядро (довгастий мозок) |
| **Прегангліонарні** | волокна **блукаючого нерва** (X) |
| **Постгангліонарні** | в **інтрамуральних вузлах** серця (короткі) |
| **Медіатор** | ацетилхолін → **M₂-рецептори** |

### Гілки блукаючого нерва до серця
- **Верхні шийні серцеві гілки**, **нижні шийні серцеві гілки** (від блукаючого й поворотного гортанного).
- **Грудні серцеві гілки**.

Вони входять у серцеві сплетення, потім до SA-, AV-вузлів і передсердь.

### Ефекти (блукаючий нерв)
| Ефект | Результат |
|---|---|
| **Негативний хронотропний** | ↓ ЧСС (SA-вузол) |
| **Негативний дромотропний** | ↓ швидкість проведення в AV-вузлі; повна блокада можлива |
| **Негативний інотропний** | ↓ сила скорочення передсердь (шлуночки — слабко) |
| **Негативний батмотропний** | ↓ збудливість |

- **Правий блукаючий** переважно на SA-вузол, **лівий** — на AV-вузол.
- Шлуночки мають мало парасимпатичної іннервації.
- Сильна стимуляція блукаючого → **асистолія** (короткочасна), «вихід із-під впливу» (escape).
- **Тонус блукаючого нерва** у спокої: ЧСС ~70 (власний ритм SA ~100).
- Механізм: ACh → M₂ → G-білок → ↑ K⁺-вихід (гіперполяризація), ↓ cAMP → ↓ I_f.

## 2. Симпатична іннервація

| Ланка | Опис |
|---|---|
| **Центр** | бічні роги спинного мозку **T1–T5 (T4)** |
| **Прегангліонарні** | коротке волокно від бічного рога → симпатичний стовбур |
| **Вузли** | **верхній, середній і нижній шийні**; **зірчастий вузол** (нижній шийний + T1); верхні грудні вузли (T1–T4) |
| **Постгангліонарні** | **верхній, середній, нижній серцеві нерви** → серцеві сплетення |
| **Медіатор** | норадреналін → **β₁-рецептори** (ЧСС, сила); β₂ (вінцеві), α₁ (вінцеві — звуження) |

Деталі: [[Вегетативна нервова система]], [[Спинний мозок]].

### Ефекти (симпатика)
| Ефект | Результат |
|---|---|
| **Позитивний хронотропний** | ↑ ЧСС |
| **Позитивний дромотропний** | ↑ швидкість проведення |
| **Позитивний інотропний** | ↑ сила скорочення (передсердя і шлуночки) |
| **Позитивний батмотропний** | ↑ збудливість, ризик аритмій |
| **Люзитропний** | швидше розслаблення |
| **Вінцеві судини** | розширення (β₂ + метаболічне) |

Механізм: норадреналін → β₁ → G_s → ↑ cAMP → ПКА → фосфорилювання Ca²⁺-каналів L-типу й фосфоламбану.

## 3. Серцеві сплетення (*plexus cardiacus*)

| Сплетення | Положення |
|---|---|
| **Поверхневе** | під дугою аорти, перед правою легеневою артерією |
| **Глибоке** | позаду дуги аорти, перед біфуркацією трахеї |
| **Епікардіальні сплетення** | на поверхні серця, навколо вінцевих судин |
| **Інтрамуральні** | в стінці серця (ганглії) |

Ці сплетення містять змішані волокна: симпатичні, парасимпатичні та чутливі.

## 4. Чутлива (аферентна) іннервація

### Шляхи
- **Блукаючий нерв**: механорецептори, хеморецептори; рефлекси (не біль).
- **Симпатичні нерви → T1–T5 (T4) спинномозкові вузли**: **больова чутливість** (ішемія).

### Серцевий біль і іррадіація
Ішемічний біль (стенокардія) іде симпатичними аферентами в сегменти **C8–T5**. Ці ж нейрони заднього рогу сприймають сигнал від шкіри лівої руки, плеча → мозок «приписує» біль шкірі (відбитий біль).

| Зона іррадіації | Сегмент |
|---|---|
| За грудниною (центр) | T1–T4 |
| **Ліва рука** (медіальна поверхня), мізинець | **C8–T1** |
| Ліва лопатка, шия, **нижня щелепа** | C3–C4, T1–T4 |
| Епігастрій (нижній ІМ) | T6–T9 |

Атипові ознаки (жінки, діабетики, літні): нудота, задишка, слабкість без болю («німий ІМ» — через діабетичну нейропатію).

## 5. Рефлекси серцево-судинної системи

| Рефлекс | Аферент | Центр | Еферент | Ефект |
|---|---|---|---|---|
| **Барорецепторний** | IX (каротидний синус), X (дуга аорти) | ядро одиночного шляху, довгастий | X ↑, симпатика ↓ | ↑ АТ → ↓ ЧСС, ↓ тонус судин (швидке регулювання) |
| **Бейнбриджа** | рецептори розтягу передсердь | довгастий | симпатика | розтяг ПП → ↑ ЧСС |
| **Бецольда — Яриша** | хеморецептори ЛШ | | X | брадикардія, гіпотензія, апное (при ІМ нижньої стінки) |
| **Хеморецепторний** | каротидне тіло (IX), аортальне (X) | | | ↓ O₂ або ↑ CO₂ → ↑ дихання, ↑ АТ |
| **Окулокардіальний** (Даньїні — Ашнера) | V (очний) | | X | тиск на очі → брадикардія |
| **Рефлекс Кушинга** | ішемія стовбура при ↑ ВЧТ | | | гіпертензія + брадикардія |
| **Рефлекс пірнання** | V (холод на обличчя) | | X | брадикардія |
| **Вазовагальний** (синкопе) | | | X ↑ | брадикардія + розширення судин → ↓ АТ → втрата свідомості |

### Барорецептори
- **Каротидний синус** (IX нерв, нерв Герінга): діапазон реакції 60–180 мм рт. ст.
- **Дуга аорти** (X нерв, депресорний нерв Ціона — Людвіга).
- Швидко (секунди) вирівнюють АТ при зміні положення тіла. Ортостатична гіпотензія — збій цього рефлексу.
- **Масаж каротидного синуса** (при надшлуночковій тахікардії) стимулює блукаючий.

## 6. Центральна регуляція

| Центр | Роль |
|---|---|
| **Довгастий мозок** (ростральна вентролатеральна частина, ядро одиночного шляху, ядро блукаючого) | основний кардіоваскулярний центр |
| **Гіпоталамус** | стрес, терморегуляція (↑ ЧСС при гарячці) |
| **Кора, лімбічна система** | емоції → «серце калатає» |
| **Спинний мозок** | симпатичні преганглі T1–T5 |

Деталі: [[Стовбур мозку]].

## 7. Гуморальна регуляція

- **Адреналін, норадреналін** (мозкова речовина надниркових): ↑ ЧСС і сила.
- **Тироксин**: підсилює дію катехоламінів, ↑ ЧСС.
- **Іони**: **K⁺ ↑** → брадикардія/зупинка; **Ca²⁺ ↑** → ↑ сила; **Na⁺**.
- **ANP, BNP** (натрійуретичні пептиди) — з міокарда при розтягу: ↓ АТ, ↓ об'єм. **BNP/NT-proBNP** — маркер серцевої недостатності.
- **Ангіотензин II, альдостерон, АДГ** — об'єм і тонус судин.

## 8. Механізми саморегуляції серця

### Закон Франка — Старлінга
Чим більше наповнення шлуночка в діастолу (переднавантаження, довжина волокон), **тим сильніше скорочення** (ударний об'єм ↑). Забезпечує баланс між правим і лівим серцем.

### Ефект Анрепа
↑ постнавантаження (тиск в аорті) → ↑ сила скорочення (через кілька хвилин).

### Ефект Боудіча (драбина)
↑ ЧСС → ↑ сила скорочення (накопичення Ca²⁺).

Ці механізми діють у **денервованому серці** (трансплантат).

## 9. Серце після трансплантації

- Парасимпатичні й симпатичні нерви **перерізані**.
- ЧСС у спокої **~100** (немає тонусу блукаючого).
- Підвищення ЧСС при навантаженні **повільне** (залежить від циркулюючих катехоламінів).
- Біль при ішемії **відсутній** (денервація) → «німий» ІМ.
- З часом (роки) частково реіннервується.

## 10. Фармакологія (для розуміння нервового контролю)

| Препарат | Механізм | Ефект |
|---|---|---|
| **β-блокатори** (метопролол, бісопролол) | блок β₁ | ↓ ЧСС, ↓ сила, ↓ потреба O₂ |
| **Атропін** | блок M₂ | ↑ ЧСС (при брадикардії) |
| **Адреналін, добутамін** | β₁ агоніст | ↑ ЧСС, ↑ сила |
| **Дигоксин** | ↑ тонус блукаючого, ↑ Ca²⁺ | ↓ ЧСС, ↑ сила (серцева недостатність, фібриляція) |
| **Верапаміл, дилтіазем** | блок Ca²⁺ каналів L-типу | ↓ ЧСС, ↓ проведення AV |
| **Аденозин** | A₁ → ↑ K⁺ | коротка AV-блокада; лікує надшлуночкову тахікардію |

## 11. Мнемоніки

- **Блукаючий — «гальмо»** (↓ ЧСС), **симпатика — «газ»** (↑ ЧСС).
- Симпатика до серця: **T1–T5 → зірчастий вузол → серцеві нерви**.
- Больові волокна серця: **симпатичні**; **рефлекси** — блукаючий.
- **Франк — Старлінг**: більше наповнення → сильніше скорочення.
- Хроно (частота), дромо (проведення), іно (сила), батмо (збудливість).
