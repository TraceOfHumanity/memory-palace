# Серце — серцевий цикл і гемодинаміка

**Серцевий цикл** — одне скорочення і розслаблення серця. Він включає систолу і діастолу передсердь та шлуночків. При ЧСС 75/хв цикл триває **0,8 с**.

Пов'язані файли: [[Серцево-судинна система — огляд]], [[Серце — камери і клапани]], [[Серце — провідна система]], [[Серце — іннервація]], [[Серце — ЕКГ]], [[Серце — коронарні судини]], [[Серце — хвороби]], [[Серце — стінка і перикард]], [[Скелетний м'яз — будова і скорочення]], [[Судини — будова і типи]], [[Мікроциркуляція і лімфатична система]], [[Нирка — регуляція гомеостазу]].

## 1. Тривалість фаз (при ЧСС 75/хв, цикл 0,8 с)

| Фаза | Тривалість, с |
|---|---|
| **Систола передсердь** | 0,1 |
| **Діастола передсердь** | 0,7 |
| **Систола шлуночків** | **0,33** |
| — період напруги | 0,08 (0,05 асинхронне + 0,03 ізометричне) |
| — період вигнання | 0,25 (швидке 0,12 + повільне 0,13) |
| **Діастола шлуночків** | **0,47** |
| — протодіастола | 0,04 |
| — ізометричне розслаблення | 0,08 |
| — наповнення (швидке 0,08–0,09 + повільне 0,17 + систола передсердь 0,1) | 0,35 |
| **Загальна пауза** (обидва відділи в діастолі) | 0,4 |

Діастола довша за систолу: серце відпочиває і наповнюється (**міокард і коронарний кровотік працюють у діастолі**). При тахікардії **скорочується діастола**.

## 2. Фази серцевого циклу (шлуночки)

### Систола шлуночків
1. **Фаза асинхронного скорочення**: збудження охоплює міокард (0,05 с).
2. **Фаза ізометричного (ізоволюмічного) скорочення** (0,03 с): тиск зростає при **закритих усіх клапанах**; об'єм стабільний.
   - Тиск у ЛШ перевищує тиск у передсерді → **закривається мітральний клапан** → **I тон**.
3. **Фаза вигнання** (0,25 с): тиск у ЛШ > тиск в аорті (~80 мм рт. ст.) → **відкривається аортальний клапан**, кров викидається.
   - Швидке вигнання (~2/3 об'єму), повільне.
   - Тиск у ЛШ досягає ~120 мм рт. ст.

### Діастола шлуночків
4. **Протодіастола** (0,04 с): початок розслаблення.
5. **Фаза ізометричного розслаблення** (0,08 с): тиск падає при закритих клапанах; **закривається аортальний клапан** → **II тон**; інцизура (вирізка) на кривій тиску в аорті.
6. **Фаза наповнення**: тиск у ЛШ < тиск у ЛП → **відкривається мітральний клапан**.
   - **Швидке наповнення** (~70–80% об'єму) → ІІІ тон (у дітей норма).
   - **Повільне наповнення (діастаза)**.
   - **Систола передсердь**: додаткові 15–25% (**«передсердний поштовх»** важливий при гіпертрофії ЛШ, IV тон).

## 3. Об'єми

| Показник | Значення |
|---|---|
| **Кінцево-діастолічний об'єм** (КДО, EDV) | ~120–130 мл |
| **Кінцево-систолічний об'єм** (КСО, ESV) | ~50–60 мл |
| **Ударний об'єм** (УО, SV) = КДО − КСО | **~70 мл** |
| **Фракція викиду** (ФВ) = УО / КДО | **55–70%** |
| **Резервний об'єм** | ~100 мл |
| **Хвилинний об'єм (серцевий викид, СО)** = УО × ЧСС | ~5 л/хв |
| **Серцевий індекс** = СО / площа тіла | 2,5–4 л/хв/м² |

- **Фракція викиду < 40%** — систолічна серцева недостатність.
- При навантаженні СО до 20–25 л/хв: ↑ ЧСС (до 200) і ↑ УО.

### Детермінанти ударного об'єму
| Фактор | Опис |
|---|---|

| **Постнавантаження** (*afterload*) | тиск в аорті, периферичний опір |
| **Скоротливість** (*contractility*) | інотропія: симпатика, ↑ Ca²⁺ |

## 4. Тиск у камерах (мм рт. ст.)

| Камера | Систолічний | Діастолічний |
|---|---|---|
| Праве передсердя | 2–6 (середній) | |
| Правий шлуночок | 15–30 | 0–8 |
| Легеневий стовбур | 15–30 | 4–12 (сер. 9–18) |
| **Ліве передсердя** | 6–12 (середній) | |
| **Лівий шлуночок** | **100–140** | 3–12 |
| **Аорта** | **100–140** | 60–90 (сер. ~93) |

- **Тиск легеневої артерії** у 5–6 разів нижчий (мале коло — низький опір).
- **Клиновий тиск** легеневих капілярів ≈ тиск у ЛП (діагностична проба).

## 5. Тони серця

| Тон | Походження | Час | Звук |
|---|---|---|---|
| **I** (систолічний) | закриття **мітрального і тристулкового** клапанів + напруга міокарда | початок систоли | «бум» (довгий, низький) |
| **II** (діастолічний) | закриття **аортального і легеневого** клапанів | початок діастоли | «тук» (короткий, високий) |
| **III** | швидке наповнення шлуночків | рання діастола | норма у дітей, **патологія** (серцева недостатність, «ритм галопу») |
| **IV** | систола передсердь у жорсткий шлуночок | кінець діастоли | гіпертрофія ЛШ, ІХС |

- **Розщеплення II тону**: на вдиху — фізіологічне (аортальний закривається раніше легеневого).
- **Шуми**: турбулентний потік (стеноз, недостатність, дефекти). Див. [[Серце — камери і клапани]].

## 6. Артеріальний тиск (АТ)

| Категорія | Значення |
|---|---|
| Оптимальний | < 120/80 |
| Нормальний | 120–129 / 80–84 |
| Високий нормальний | 130–139 / 85–89 |
| **Гіпертензія** (≥ 140/90) | I ст. 140–159/90–99; II ст. 160–179/100–109; III ст. ≥ 180/110 |

- **Систолічний (САТ)** — максимум під час систоли.
- **Діастолічний (ДАТ)** — мінімум у діастолу.
- **Пульсовий тиск** = САТ − ДАТ (норма ~40; ↑ при аортальній недостатності).
- **Середній АТ** = ДАТ + ⅓ пульсового (~93 мм рт. ст.).
- **Вимірювання**: за Коротковим (тони Короткова).

### Основні закони
**Закон Пуазейля — Гагена**: опір потоку обернено пропорційний **r⁴**. Невелике звуження (r) різко збільшує опір.
**Основне рівняння**: **АТ = СО × ЗПОС** (загальний периферичний опір).

Регуляція: [[Серце — іннервація]].

## 7. Пульс

- **Пульс** — ритмічні коливання стінки артерій при викиді крові.
- Норма: **60–80/хв** (60–100). Ритмічний, достатнього наповнення, симетричний.
- Місця пальпації: променева, сонна, стегнова, підколінна, тильна артерія стопи, скронева.
- **Швидкість пульсової хвилі**: 5–10 м/с (набагато швидша за кровоплин).
- **Ознаки**: частота, ритм, наповнення, напруга, форма.
- **Дефіцит пульсу** (ЧСС > пульс) — при фібриляції передсердь.

## 8. Швидкість і тиск по судинах

| Відділ | Лінійна швидкість | Тиск |
|---|---|---|
| Аорта | 50 см/с | 120/80 |
| Артерії | | ~100 |
| **Артеріоли** (основне падіння тиску) | | 80 → 35 |
| **Капіляри** (найбільша сумарна площа перерізу; поверхня обміну ~600 м²) | **0,03–0,05 см/с** | 35 → 15 |
| Венули, вени | 5–20 см/с | 15 → 5 |
| Порожнисті вени | 20 см/с | 0–5 |

**Рівняння безперервності**: швидкість обернено пропорційна сумарній площі перерізу. У капілярах найповільніше — час на обмін.

## 9. Венозне повернення

Чинники:
1. Залишковий тиск після капілярів.
2. **Клапани вен** (одностороннє).
3. **М'язова помпа** (скорочення литкових м'язів).
4. **Дихальна помпа**: на вдиху ↓ внутрішньогрудний тиск → присмоктування крові.
5. **Присмоктувальна дія серця** і передсердь.
6. **Венозний тонус** (симпатика).
7. Гравітація.

Недостатність → **варикозне розширення вен**, ортостатична гіпотензія.

## 10. Мікроциркуляція (коротко)

Обмін у капілярах за **Старлінгом**: **фільтрація** на артеріальному кінці (гідростатичний тиск ~35 > онкотичний ~25), **реабсорбція** на венозному (гідростатичний 15 < онкотичний 25). Надлишок повертає лімфа. Набряки: ↓ білок, ↑ венозний тиск, ↑ проникність.

## 11. Робота і енергетика серця

- Потужність серця: ~1–1,5 Вт (≈ 100–130 кДж за добу).
- Споживання O₂ міокардом: **8–10 мл/хв/100 г** (в 10 разів більше за скелетний у спокої).
- Енергія: жирні кислоти (60–70%), глюкоза, лактат.
- ККД ~ 15–25%.

## 13. Мнемоніки

- Тони: **I — закриття мітрального/тристулкового, II — закриття аортального/легеневого**.
- **«Систола — Закрито-Відкрито»**: передсердно-шлуночкові клапани **закриті**, півмісячні **відкриті**.
- Ударний об'єм = **КДО − КСО**; ФВ = УО/КДО.
- **АТ = СО × ЗПОС**.
- **Фаза ізометричного скорочення**: **усі клапани закриті**.
