# Серце — ЕКГ (електрокардіографія)

**ЕКГ** — запис електричної активності серця з поверхні тіла. Це сума електричних сил усіх кардіоміоцитів. ЕКГ показує ритм, провідність, ішемію і гіпертрофію. Вона **не показує** силу скорочення.

Пов'язані файли: [[Серцево-судинна система — огляд]], [[Серце — провідна система]], [[Серце — серцевий цикл і гемодинаміка]], [[Серце — коронарні судини]], [[Серце — іннервація]], [[Серце — хвороби]], [[Серце — огляд і положення]], [[Нервовий імпульс і синапс]].

## 1. Принцип

- Деполяризація кардіоміоцитів створює **диполь** (позитивний і негативний полюси).
- Електрод, до якого рухається хвиля деполяризації, пише **позитивне відхилення**; від електрода — негативне.
- Електрична вісь серця — результуючий вектор (в нормі направлена вниз і ліворуч).
- Папір: швидкість **25 мм/с**; 1 мм = **0,04 с**; 1 мВ = 10 мм (стандарт калібрування).

## 2. Відведення (12)

### Стандартні кінцівкові (Ейнтховен)
| Відведення | Полюси |
|---|---|
| **I** | права рука (−), ліва рука (+) |
| **II** | права рука (−), ліва нога (+) |
| **III** | ліва рука (−), ліва нога (+) |

**Закон Ейнтховена**: II = I + III.

### Підсилені однополюсні кінцівкові (Голдбергер)
**aVR** (права рука), **aVL** (ліва рука), **aVF** (ліва нога).

### Грудні (однополюсні, Вілсон)
| Відведення | Положення електрода | Дивиться на |
|---|---|---|
| **V1** | 4-те міжребер'я праворуч від груднини | правий шлуночок, перегородка |
| **V2** | 4-те міжребер'я ліворуч від груднини | перегородка |
| **V3** | між V2 і V4 | передня стінка |
| **V4** | 5-те міжребер'я, серединно-ключична лінія (верхівка) | передня стінка, верхівка |
| **V5** | передня пахвова лінія, рівень V4 | бічна стінка |
| **V6** | середня пахвова лінія, рівень V4 | бічна стінка |

### Групи за стінками ЛШ
| Стінка | Відведення | Судина |
|---|---|---|
| **Нижня** | II, III, aVF | ПВА |
| **Бічна** | I, aVL, V5, V6 | огинаюча |
| **Передня / перегородка** | V1–V4 | ПМШГ |
| **Задня** | V7–V9 (дзеркально V1–V2) | ЗМШГ |
| **Правий шлуночок** | V4R | ПВА (проксимальна) |

## 3. Елементи нормальної ЕКГ

Послідовність зубців: **P → Q → R → S → T**. Перші три з Q по S утворюють комплекс QRS.

| Елемент | Що відображає | Норма |
|---|---|---|
| **Хвиля P** | деполяризація передсердь | < 0,12 с; < 2,5 мм |
| **Інтервал PQ (PR)** | проведення від передсердь до шлуночків (через AV-вузол) | **0,12–0,20 с** |
| **Комплекс QRS** | деполяризація шлуночків | **0,06–0,10 с** (до 0,12) |
| — **Q** | деполяризація перегородки (зліва направо) | вузька, < 0,04 с, глибина < ¼ R |
| — **R** | деполяризація стінок ЛШ | |
| — **S** | деполяризація основи | |
| **Сегмент ST** | плато (повна деполяризація шлуночків) | на ізолінії (±1 мм) |
| **Хвиля T** | реполяризація шлуночків | зазвичай позитивна (крім aVR, V1) |
| **Інтервал QT** | електрична систола шлуночків | **QTc < 440 мс** (чол.), < 460 (жін.) |
| **Хвиля U** | пізня реполяризація | рідко; при гіпокаліємії |

**Реполяризація передсердь** (хвиля Ta) прихована в QRS.

### Часові інтервали
| Показник | Значення |
|---|---|
| P | 0,08–0,11 с |
| PQ | 0,12–0,20 с |
| QRS | 0,06–0,10 с |
| QT | 0,35–0,44 с (залежить від ЧСС) |
| RR | 0,6–1,0 с (при ЧСС 60–100) |

## 4. Правило аналізу ЕКГ (покроково)

1. **Калібрування й якість**: 25 мм/с, 10 мм/мВ.
2. **Ритм**: синусовий? (P перед кожним QRS, позитивна в II).
3. **ЧСС**: 300 / (кількість великих клітин між R–R) або 1500 / (малих клітин).
4. **Електрична вісь**: нормальна (від −30° до +90°).
5. **P-хвиля**: форма, тривалість.
6. **PQ**: 0,12–0,20 с.
7. **QRS**: тривалість, амплітуда, Q-патологічні.
8. **Сегмент ST**: елевація/депресія.
9. **T**: інверсія, високі.
10. **QT**: подовжений?

### Визначення ЧСС
- **300 / N** (N — великі клітини між R–R): 1 → 300; 2 → 150; 3 → 100; 4 → 75; 5 → 60; 6 → 50.

## 5. Електрична вісь серця

Результуюча спрямованість деполяризації шлуночків. Норма: **від −30° до +90°** (QRS позитивний у I і II).

| Вісь | Відведення | Значення |
|---|---|---|
| Нормальна | I (+), II (+), aVF (+) | |
| **Відхилення ліворуч** (−30…−90°) | I (+), II (−), aVF (−) | гіпертрофія ЛШ, блокада передньої гілки лівої ніжки, нижній ІМ |
| **Відхилення праворуч** (+90…+180°) | I (−), aVF (+) | гіпертрофія ПШ, блокада задньої гілки, емболія легень |

Швидко: **I (+) і aVF (+)** — нормальна вісь.

## 6. Ознаки хвороб

### Інфаркт міокарда
Еволюція змін:
| Етап | Зміни |
|---|---|
| **Гіперострий** (хвилини) | високі гострі T |
| **Гострий** (години) | **елевація ST** («купол», «надгробок») |
| **Підгострий** (дні) | формується **патологічний зубець Q** (≥ 0,04 с, ≥ ¼ R), інверсія T |
| **Рубцевий** (тижні–роки) | залишається **патологічний Q**, ST повертається |

- **STEMI**: елевація ST ≥ 1 мм у двох суміжних відведеннях → негайна реперфузія. Деталі: [[Серце — коронарні судини]].
- **NSTEMI / нестабільна стенокардія**: депресія ST, інверсія T; підвищений тропонін (NSTEMI).
- **Дзеркальна депресія** ST у протилежних відведеннях.

### Гіпертрофія
| Тип | Ознаки |
|---|---|
| **ЛШ** | Соколова — Лайона: **S(V1) + R(V5 або V6) > 35 мм**; вісь ліворуч; зміни ST–T |
| **ПШ** | високий R у V1, вісь праворуч |
| **ЛП** | широка двогорба **P mitrale** (≥ 0,12 с) |
| **ПП** | високий загострений **P pulmonale** (> 2,5 мм) |

### Електролітні порушення
| Зсув | Ознаки |
|---|---|
| **Гіперкаліємія** | високі загострені T, розширення QRS, зникнення P, **«синусоїда»** → фібриляція |
| **Гіпокаліємія** | пласкі T, **хвиля U**, депресія ST, подовження QT |
| **Гіпокальціємія** | подовження QT (подовжений ST) |
| **Гіперкальціємія** | скорочення QT |

### Інші стани
| Стан | Ознаки |
|---|---|
| **Гострий перикардит** | дифузна **елевація ST** («сідлоподібна») + депресія PR |
| **ТЕЛА** | **S₁Q₃T₃**, синусова тахікардія, вісь праворуч |
| **Брадикардія** | RR > 1 с |
| **Синдром подовженого QT** | ризик **torsades de pointes** |
| **Синдром Бругада** | елевація ST у V1–V2 («сідло») |
| **Дигіталіс** | коритоподібна депресія ST |
| **Гіпотермія** | хвиля Осборна (J-хвиля) |

### Блокади
| Блокада | ЕКГ |
|---|---|
| **AV I ст.** | PR > 0,20 с |
| **AV II ст.** | випадіння QRS (Мобітц I/II) |
| **AV III ст.** | дисоціація P і QRS |
| **Блокада правої ніжки** | QRS ≥ 0,12 с; rSR′ у V1; широкий S в I, V6 |
| **Блокада лівої ніжки** | QRS ≥ 0,12 с; широкий R у I, V5–V6; ST зсунуто дискордантно |
| **Пучок Кента (WPW)** | коротка PR, **дельта-хвиля**, широкий QRS |

Докладно про ритми: [[Серце — провідна система]].

## 7. Зв'язок із фазами потенціалу дії

- **QRS** ≈ фаза 0 потенціалу дії робочих кардіоміоцитів шлуночків.
- **ST** ≈ фаза 2 (плато).
- **T** ≈ фаза 3 (реполяризація).
- **QT** ≈ вся тривалість потенціалу дії.
Ці зв'язки використовуються для розуміння: **подовження QT** = подовження плато (блок K⁺-каналів).

## 8. Додаткові методи

| Метод | Показання |
|---|---|
| **Холтерівське моніторування** (24–72 год) | епізодичні аритмії, ішемія |
| **Навантажувальні проби** (велоергометрія, тредміл) | ІХС |
| **Подовжене моніторування** (імплантований реєстратор) | рідкісні синкопе |
| **Електрофізіологічне дослідження (ЕФД)** | складні аритмії |
| **Телеметрія** | реанімація |
| **ЕКГ-сигнал у смартгодинниках** | скринінг фібриляції передсердь |

## 9. Мнемоніки

- **PQRST**: P — передсердя, QRS — шлуночки (деполяризація), T — реполяризація.
- ЧСС: **300–150–100–75–60–50** (великі клітини між R–R).
- **ST-елевація** — «загроза»: ІМ, перикардит; **ST-депресія** — ішемія, дигіталіс, гіпертрофія.
- Інфаркт: **II, III, aVF — нижній; I, aVL, V5–6 — бічний; V1–V4 — передній**.
- Осі: **I + aVF позитивні → нормальна вісь**.
