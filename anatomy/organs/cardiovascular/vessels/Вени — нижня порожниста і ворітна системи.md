# Вени — нижня порожниста і ворітна системи

**Нижня порожниста вена** збирає кров з ніг, таза, живота. **Ворітна вена** збирає кров від непарних органів черевної порожнини й несе її в печінку на очищення. Між системами є **кава-кавальні** та **портокавальні анастомози**.

## 1. Нижня порожниста вена (*v. cava inferior*, НПВ)

| Показник | Значення |
|---|---|
| Утворення | злиття **двох загальних клубових вен** на рівні **L5**, праворуч від аорти |
| Довжина | ~20–25 см |
| Діаметр | ~2–3 см |
| Хід | вгору праворуч від аорти, позаду очеревини; **борозна на задній поверхні печінки**; крізь **отвір нижньої порожнистої вени діафрагми (T8)** |
| Впадає | у праве передсердя (клапан Євстахія) |
| Клапани | **немає** (тільки рудимент) |

### Відносини
Позаду — тіла L3–L5, права ниркова артерія, права діафрагма, права симпатична ланка; спереду — корінь брижі, дванадцятипала кишка, голівка підшлункової залози, ворітна вена, печінка; ліворуч — аорта.

### Притоки (за рівнями знизу вгору)
| Приплив | Рівень |
|---|---|
| **Загальні клубові** (права й ліва) | L5 |
| **Поперекові** (3–4 пари) | L1–L4 |
| **Яєчкова / яєчникова (права)** — впадає в НПВ; **ліва** — у ліву ниркову | L2 |
| **Ниркові** (права, ліва) | L1–L2 |
| **Права надниркова** (ліва — у ліву ниркову) | L1 |
| **Нижні діафрагмові** | T12 |
| **Печінкові вени** (3 великі: права, середня, ліва) | T9–T10 (під діафрагмою) |

**Асиметрія справа й зліва**: ліва яєчкова і ліва надниркова вени впадають у **ліву ниркову вену**; праві — безпосередньо в НПВ.
- **Варикоцеле** — частіше зліва (довга ліва яєчкова вена впадає під прямим кутом у ліву ниркову; **синдром лускунчика**).

## 2. Загальна клубова вена

Утворена злиттям **зовнішньої** і **внутрішньої клубових**. Права коротша, майже вертикальна; ліва довша й позаду правої загальної клубової **артерії** → компресія → **синдром Мея — Тернера** (ліва клубова вена тромбується частіше).

### Внутрішня клубова вена
Збирає від органів таза й промежини. Утворює **венозні сплетення таза** (сечового міхура, прямої кишки, матки/простати) — **без клапанів**, багато анастомозів. Метастазування (простата → хребет через хребтові сплетення).

### Зовнішня клубова вена
Продовження стегнової вени (від пахвинної зв'язки). Лежить медіально від артерії.

## 3. Вени нижньої кінцівки

### Глибокі вени
Супроводжують артерії (парні): передні/задні великогомілкові, малогомілкові → **підколінна вена** → **стегнова вена** (в привідному каналі) → зовнішня клубова.
- Клапани часті. **М'язова помпа** литки (литковий, камбалоподібний) гонить кров вгору.
- **Камбалоподібні синуси** — місце тромбів (ТГВ).

### Поверхневі (підшкірні) вени
Дві магістралі:
| Вена | Хід | Впадає |
|---|---|---|
| **Велика підшкірна** (*v. saphena magna*) | від **медіального краю стопи**, **спереду медіальної кісточки**, по медіальній поверхні гомілки й стегна | в **стегнову вену** через **підшкірну щілину (овальний отвір)** — **сафено-феморальне з'єднання** |
| **Мала підшкірна** (*v. saphena parva*) | від **латерального краю стопи**, **позаду латеральної кісточки**, по задній поверхні гомілки | в **підколінну вену** у підколінній ямці (сафено-підколінне з'єднання) |

- Між підшкірними і глибокими венами — **перфорантні (комунікантні) вени** (Коккета, Бойда, Додда, Хантера). Клапани спрямовують кров **з поверхневих у глибокі**.
- Велика підшкірна вена — **найдовша вена** тіла; її використовують для **аортокоронарного шунтування**.
- **Венепункція** над медіальною кісточкою (венесекція, коли інші вени недоступні).

### Варикозна хвороба
Недостатність клапанів → кров тече назад → розширення. Деталі: [[Хвороби судин]].

## 4. Вени живота і таза

| Вена | Збирає |
|---|---|
| **Печінкові вени** (права, середня, ліва) | кров печінки → НПВ |
| **Ниркові** | нирки |
| **Яєчкові / яєчникові** | гонади (праві → НПВ, ліві → ліва ниркова) |
| **Надниркові** | надниркові залози |
| **Поперекові** (вертикально зв'язані **висхідними поперековими**) | стінка черева; висхідні поперекові → непарна система |
| **Крижова серединна** | куприк |

## 5. Ворітна система (*systema portae*)

Збирає кров від **непарних органів черевної порожнини** (шлунково-кишковий тракт, підшлункова залоза, селезінка, жовчний міхур) і несе її в **печінку**. У печінці розгалужується на **синусоїди** (друга капілярна мережа), а потім через печінкові вени → НПВ.

### Ворітна вена (*v. portae*)
| Показник | Значення |
|---|---|
| Утворення | злиття **селезінкової** і **верхньої брижової** вен позаду шийки підшлункової залози (на рівні L1–L2) |
| Довжина | 6–8 см |
| Діаметр | 1–1,2 см |
| Клапани | **немає** |
| Хід | в **печінково-дванадцятипалій зв'язці** (**разом з власною печінковою артерією і загальною жовчною протокою** — «портальна тріада»), до **воріт печінки** |
| Кров | **~75%** об'єму печінкового кровотоку (з поживними речовинами, але менш насичена O₂); решта 25% — печінкова артерія |

### Притоки
| Вена | Збирає від |
|---|---|
| **Верхня брижова** (*v. mesenterica superior*) | тонка кишка, права половина товстої, головка підшлункової залози |
| **Нижня брижова** (*v. mesenterica inferior*) | ліва половина товстої, верхня прямокишкова | 
| **Селезінкова** (*v. splenica*) | селезінка, шлунок (короткі), підшлункова залоза; нижня брижова часто впадає в неї |
| **Ліва шлункова** (вінцева) | мала кривина шлунка |
| **Права шлункова** | |
| **Міхурова**, **навколопупкові вени** | |

Нижня брижова вена впадає в селезінкову (приблизно 40%), у верхню брижову (30%) або в злиття (30%).

### Ворітна вена в печінці
Воріта печінки: ліва і права гілки → часткові → сегментарні → **синусоїди** → центральні вени → печінкові вени → НПВ. Деталі печінки — в окремому файлі (розділ травної системи).

## 6. Портокавальні анастомози

Між ворітною (портальною) та порожнистими (кавальними) системами є **сполучення**. При **портальній гіпертензії** кров обходить печінку цими шляхами, вони розширюються.

| Місце | Портальна ланка | Кавальна ланка | Клінічна картина |
|---|---|---|---|
| **Гастроезофагеальне** (стравохідне) | ліва шлункова вена | стравохідні вени → непарна → ВПВ | **варикоз вен стравоходу** → **кровотеча** (блювота кров'ю — найнебезпечніше) |
| **Аноректальне** (пряма кишка) | верхня прямокишкова → нижня брижова | середня й нижня прямокишкові → внутрішня клубова → НПВ | **геморой**, кровотеча |
| **Пупкове (параумбілікальне)** | навколопупкові вени → ворітна | поверхневі надчеревні вени → стегнова, бічна грудна → ВПВ | **«голова медузи»** (*caput medusae*): розширені вени навколо пупка |
| **Ретроперитонеальне** (Реціуса) | вени ободової кишки, підшлункової залози | поперекові, нирково-надниркові | |
| **Печінкова** (діафрагмальне) | поверхня печінки | діафрагмальні | |

Мнемоніка: **«Стравохід — Пряма кишка — Пупок»** (3 основні).

### Портальна гіпертензія
Тиск у ворітній вені > 10–12 мм рт. ст. (норма 5–10).
- **Причина**: найчастіше **цироз печінки** (внутрішньопечінковий блок); тромбоз ворітної вени (позапечінковий); застій (недостатність серця).
- **Наслідки**: **асцит**, **спленомегалія**, **варикоз вен стравоходу** (кровотеча), **геморой**, **caput medusae**, енцефалопатія (аміак з кишки обходить печінку).
- Лікування: β-блокатори, лігування вен стравоходу, **TIPS** (внутрішньопечінковий портосистемний шунт).

## 7. Кава-кавальні анастомози

Сполучення між ВПВ і НПВ:
1. **Непарна — напівнепарна** система ↔ поперекові вени.
2. **Хребтові венозні сплетення.**
3. **Поверхневі**: **бічна грудна вена** (з пахвової, ВПВ) ↔ **поверхнева надчеревна вена** (зі стегнової, НПВ) — видимі при закупорці НПВ на передньо-бічній стінці живота.
4. Внутрішня грудна ↔ верхня і нижня надчеревні вени.

При **тромбозі НПВ** розширюються поверхневі вени живота; кров іде вгору в ВПВ.

## 9. Мнемоніки

- **НПВ**: утворюється на **L5**, діафрагма **T8**, праворуч від аорти.
- **Ворітна вена** = **селезінкова + верхня брижова** (позаду шийки підшлункової залози).
- Портокавальні анастомози: **«стравохід, пряма кишка, пупок»** (шлунок→ВПВ; пряма кишка→НПВ; пупок→обидва).
- Велика підшкірна вена: **спереду медіальної кісточки**; мала: **позаду латеральної**.
- Ліва яєчкова вена → **ліва ниркова**; права → **НПВ**.
