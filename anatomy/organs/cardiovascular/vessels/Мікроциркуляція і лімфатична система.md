# Мікроциркуляція і лімфатична система

**Мікроциркуляція** — рух крові через найдрібніші судини: артеріоли, капіляри, венули. Тут відбувається обмін між кров'ю й тканинами. Надлишок рідини повертає **лімфатична система**.

## 1. Мікроциркуляторне русло

| Ланка | Діаметр | Роль |
|---|---|---|
| **Термінальна артеріола** | 20–50 мкм | регулює потік у капілярну сітку |
| **Метартеріола** | 10–20 мкм | сполучна ланка; не повністю м'язова |
| **Прекапілярний сфінктер** | | кільце гладких м'язів: відкриває/закриває капіляр |
| **Капіляр** | 5–10 мкм | обмін |
| **Постапілярна венула** | 10–30 мкм | міграція лейкоцитів, обмін (проникна) |
| **Збірна венула** | до 100 мкм | збір |
| **Артеріоло-венулярний анастомоз** | | шунт (шкіра пальців, вуха; терморегуляція) |

Одночасно відкрито лише **~25%** капілярів у спокої. При навантаженні відкриваються нові.

### Вазомоція
Ритмічне скорочення метартеріол і сфінктерів (5–10 раз/хв) — потік у капілярах **переривчастий**. Регулюється **місцевими метаболітами** (O₂ ↓, CO₂ ↑, аденозин, K⁺, H⁺, лактат).

## 2. Обмін через стінку капіляра

### Способи
| Спосіб | Що проходить |
|---|---|
| **Проста дифузія** | O₂, CO₂, жиророзчинні речовини; крізь ендотелій |
| **Дифузія через пори (міжклітинні щілини)** | вода, іони, глюкоза, сечовина |
| **Піноцитоз (трансцитоз)** | білки |
| **Фільтрація й реабсорбція** (об'ємний потік) | вода з розчинами |

### Закон Старлінга (сили на капілярі)
Рух рідини визначається чотирма силами:

| Сила | Значення, мм рт. ст. | Напрямок |
|---|---|---|
| **Гідростатичний тиск капіляра** (Pc) | артеріальний кінець **~35**, венозний **~15** | **з капіляра** (фільтрація) |
| **Гідростатичний тиск інтерстиція** (Pi) | ~0 (−2…+2) | в капіляр |
| **Онкотичний тиск плазми** (πc) | **~25–28** | **в капіляр** (реабсорбція) |
| **Онкотичний тиск інтерстиція** (πi) | ~1–5 | з капіляра |

**Ефективний тиск фільтрації** = (Pc − Pi) − (πc − πi).
- Артеріальний кінець: 35 − 25 = **+10** → **фільтрація**.
- Венозний кінець: 15 − 25 = **−10** → **реабсорбція**.

Підсумок: ~**90%** фільтрату повертається в капіляр, ~**10%** (2–4 л/добу) повертає **лімфа**.

### Онкотичний тиск
Створюють білки плазми, переважно **альбумін** (80%): 25–28 мм рт. ст. Низький альбумін → набряки.

## 3. Набряк (*oedema*)

Накопичення рідини в інтерстиції. Причини (за законом Старлінга):

| Механізм | Приклад |
|---|---|
| **↑ гідростатичний тиск** | правошлуночкова недостатність, тромбоз вен, вагітність, тривале стояння |
| **↓ онкотичний тиск плазми** | **гіпоальбумінемія**: нефротичний синдром, цироз, голодування |
| **↑ проникність капілярів** | запалення, опіки, алергія (гістамін), сепсис |
| **Порушення лімфовідтоку** | лімфедема (після мастектомії, філяріатоз — слоновість) |
| **↑ осмотичний тиск інтерстиція** | |

Види: **серцеві** (симетричні, ноги, ввечері), **нирковий** (обличчя, вранці), **печінковий** (асцит), **лімфатичний** (щільний, не залишає ямки), **алергічний** (набряк Квінке).

## 4. Лімфатична система (*systema lymphaticum*)

Паралельна однобічна дренажна система. Складається з **лімфатичних капілярів**, **судин**, **стовбурів**, **проток** і **вузлів**.

### Функції
1. **Повернення рідини й білків** у кров (~2–4 л/добу).
2. **Всмоктування жирів** (хіломікрони) з кишки — **лактеалі** (молочні судини).
3. **Імунний захист** (лімфовузли, фільтрація, антитіла).
4. Транспорт лімфоцитів.

### Лімфа
Прозора рідина (у кишці молочна — хілус). Склад: вода, білки (менше, ніж плазма), **лімфоцити**, жири. Тече в **одному напрямку**: тканини → вени.

## 5. Лімфатичні судини

| Тип | Особливості |
|---|---|
| **Лімфатичні капіляри** | **сліпі** початки в тканинах; стінка — ендотелій без базальної мембрани, з «клапанами»; **немає** в мозку, хрящі, епітелії, кістковому мозку, плаценті, рогівці |
| **Лімфатичні судини** | **клапани** (кожні 2–3 мм); стінка з гладкими м'язами (самостійна перистальтика) |
| **Лімфатичні стовбури** | великі збірні |
| **Лімфатичні протоки** | **грудна** і **права лімфатична** |

### Рух лімфи
- Тиск у лімфі низький.
- **М'язова помпа** (скорочення скелетних м'язів).
- **Пульсація артерій**, дихальні рухи (**дихальна помпа**).
- **Клапани** (напрямок).
- Скорочення стінок судин.

## 6. Лімфатичні стовбури і протоки

### Грудна протока (*ductus thoracicus*) — головний
| Показник | Значення |
|---|---|
| Довжина | 35–45 см |
| Початок | **цистерна хілі** (*cisterna chyli*) на рівні **L1–L2** (злиття поперекових і кишкових стовбурів) |
| Хід | через **аортальний отвір діафрагми**, позаду аорти і стравоходу, ліворуч до хребта; на шиї дугою |
| Закінчення | **лівий венозний кут** (злиття лівої ВЯВ і підключичної) |
| Збирає лімфу | від **3/4 тіла**: ніг, таза, живота, лівої половини грудної клітки, голови й шиї, лівої руки |

Припливи: **лівий поперековий, кишковий, лівий підключичний, лівий яремний, лівий бронхосередостінний** стовбури.

### Права лімфатична протока (*ductus lymphaticus dexter*)
Коротка (1–1,5 см); впадає у **правий венозний кут**. Збирає лімфу від **правої верхньої чверті** тіла: права рука, права половина голови й шиї, права половина грудної клітки.

### Стовбури
- **Яремні** (голова й шия).
- **Підключичні** (руки).
- **Бронхосередостінні** (грудна клітка).
- **Поперекові** (ноги, таз).
- **Кишковий** (органи черева).

### Клінічне
- **Хілоторакс** — витік лімфи (хілусу) в плевральну порожнину при пораненні грудної протоки (операції на стравоході).
- **Вузол Вірхова** — лівий надключичний лімфатичний вузол: збільшується при **раку шлунка** (метастаз по грудній протоці; **ознака Труазьє**).

## 7. Лімфатичні вузли (*nodi lymphatici*)

Розмір 1–25 мм, бобоподібні; їх **500–700** у тілі. Будова: капсула, **кора** (фолікули В-лімфоцитів), **паракортекс** (Т-клітини), **мозкова речовина**, синуси.

Лімфа: **приносні судини** → крайовий синус → кора → мозкова речовина → **виносна судина** (одна, у воротах вузла).

### Групи вузлів
| Група | Область дренажу |
|---|---|
| **Підборідні, піднижньощелепні, привушні, потиличні, шийні** | голова й шия |
| **Надключичні (Вірхова)**, підключичні | |
| **Пахвові** | рука, молочна залоза (**сторожовий вузол** при раку); 20–30 вузлів |
| **Ліктьові (надблокові)** | кисть, передпліччя |
| **Пахвинні** (поверхневі і глибокі) | нога, зовнішні статеві органи, нижня частина живота, анус (нижче лінії зубчастої) |
| **Підколінні** | гомілка, стопа |
| **Грудні: трахеобронхіальні, біфуркаційні, середостінні** | легені, серце, стравохід |
| **Черевні: черевні, брижові, ободові** | органи черева |
| **Клубові, поперекові, крижові** | таз, статеві органи |

### Клінічне
- **Лімфаденіт** — запалення (болісні).
- **Лімфаденопатія** — збільшення (інфекція, пухлина, лімфома).
- **Метастази** — пухлини поширюються по лімфі; **сторожовий вузол** — перший на шляху.
- **Лімфедема** — набряк після видалення вузлів.

Інші лімфоїдні органи (селезінка, тимус, мигдалики) — в розділі імунної системи.

## 8. Селезінка і тимус (коротко)

- **Селезінка**: червона (фільтр крові) і біла (імунна) пульпа; лежить у лівому підребер'ї на рівні ребер 9–11.
- **Тимус**: за грудниною; дозрівання Т-клітин; зменшується з віком.
- **Мигдалики** (піднебінні, глоткові, язиковий).
- **Лімфоїдні структури кишки** (бляшки Пейєра).

Докладніше — окремі файли (розділ імунної системи).

## 10. Мнемоніки

- Закон Старлінга: **фільтрація на артеріальному кінці (+10), реабсорбція на венозному (−10)**.
- Грудна протока: **цистерна хілі (L1–L2) → аортальний отвір → лівий венозний кут**; збирає **3/4** тіла.
- Вузол **Вірхова** = лівий надключичний = рак **шлунка**.
- **Набряки**: ↑ тиск, ↓ білок, ↑ проникність, лімфа.
