# Судини — будова і типи

Судини утворюють замкнену мережу трубок. Їхня стінка пристосована до тиску й функції. Артерії витримують високий тиск, капіляри обмінюють речовини, вени накопичують кров.

## 1. Три оболонки стінки

Стінка артерії і вени має три шари (від просвіту назовні):

| Оболонка | Латинська назва | Склад | Функція |
|---|---|---|---|
| **Внутрішня** | *tunica intima* | **ендотелій**, базальна мембрана, підендотеліальний шар; внутрішня еластична мембрана (в артеріях) | гладка поверхня, обмін, антитромботичні властивості |
| **Середня** | *tunica media* | **гладком'язові клітини**, еластичні волокна, колаген | тонус, діаметр, пружність |
| **Зовнішня** | *tunica adventitia (externa)* | пухка сполучна тканина, колаген, **судини судин** (*vasa vasorum*), нерви | опора, живлення стінки, іннервація |

- Між середньою і зовнішньою оболонками в артеріях є **зовнішня еластична мембрана**.
- *Vasa vasorum* живлять зовнішні шари великих судин (внутрішні шари живляться з просвіту). При атеросклерозі та аортиті вони ушкоджуються.
- **Капіляри** мають лише ендотелій і базальну мембрану (є ще перицити).

## 2. Ендотелій

Один шар плоских клітин на внутрішній поверхні. Це активний орган, а не пасивна вистилка.

| Функція | Механізм |
|---|---|
| **Регуляція тонусу** | виділяє **NO** (оксид азоту, розширює), **простациклін** (розширює), **ендотелін-1** (звужує) |
| **Антитромботична поверхня** | простациклін, NO, тромбомодулін, гепариноподібні речовини |
| **Прокоагулянтна дія** (при ушкодженні) | фактор фон Віллебранда, тканинний фактор |
| **Бар'єр і транспорт** | міжклітинні контакти, піноцитозні везикули |
| **Запалення** | адгезивні молекули для лейкоцитів |
| **Ангіогенез** | VEGF |

**Ендотеліальна дисфункція** — перший крок атеросклерозу (див. [[Хвороби судин]]).

## 3. Артерії

Класифікація за будовою середньої оболонки:

| Тип | Приклади | Середня оболонка | Функція |
|---|---|---|---|
| **Еластичні** (великі) | аорта, легеневий стовбур, сонні, підключичні | багато **еластичних мембран** (40–70 шарів) | «компресійна камера» (ефект Віндкесселя): згладжує пульсацію |
| **М'язові** (середні) | більшість артерій (променева, стегнова, вінцеві) | переважно **гладком'язові клітини** | розподіл крові органами |
| **Змішані** | сонна, підключична | поєднання | |
| **Артеріоли** (до 100 мкм) | | 1–2 шари гладких м'язів | **головний периферичний опір**, регуляція АТ |
| **Прекапілярні артеріоли** (метартеріоли) | | окремі м'язові клітини, **прекапілярні сфінктери** | відкривають і закривають капілярне русло |

### Ефект Віндкесселя
Під час систоли еластична аорта розтягується й накопичує частину енергії. Під час діастоли стінка стискається й проштовхує кров далі. Тому кровотік у судинах **безперервний**, а пульсація згасає до капілярів. З віком еластичність падає → ↑ систолічний тиск і ↑ пульсовий тиск.

## 4. Вени

Стінка тонша, ніж в артерії. Просвіт більший. Еластична мембрана слабка.

| Тип | Особливості |
|---|---|
| **Безм'язові** | у мозку, сітківці, кістках, селезінці, плаценті; стінка без гладких м'язів |
| **М'язові слабо розвинені** | верхня половина тіла (верхня порожниста): кров тече вниз за гравітацією |
| **М'язові сильно розвинені** | нижні кінцівки: гладкі м'язи й **клапани** допомагають рухові вгору |

### Клапани вен
- Складки внутрішньої оболонки; зазвичай **стулкові (по 2)**.
- Пропускають кров **лише до серця**.
- Є у венах кінцівок, відсутні в порожнистих, ворітній, мозкових, нирковій.
- Недостатність клапанів → **варикозне розширення вен**.

### Ємнісна функція
У венах міститься **~60–70% об'єму крові** («депо»). Симпатика звужує вени й повертає ~10–15% об'єму у циркуляцію (**венозний тонус**).

## 5. Капіляри

Найтонші судини (діаметр **5–10 мкм**, довжина ~0,5–1 мм). Загальна поверхня обміну ~**600 м²**, довжина всіх судин тіла ~100 000 км.

### Типи капілярів
| Тип | Ендотелій | Де | Особливість |
|---|---|---|---|
| **Соматичні (безперервні)** | суцільний, базальна мембрана суцільна | м'язи, шкіра, легені, мозок (з ГЕБ), жирова тканина | обмін через дифузію, піноцитоз |
| **Фенестровані** | з **порами (фенестрами)**, діафрагма | нирки (клубочки), кишка, ендокринні залози | висока проникність |
| **Синусоїдні (перервні)** | великі щілини, неповна базальна мембрана | печінка, кістковий мозок, селезінка | проходять білки й клітини |

Мозкові капіляри мають щільні контакти та ніжки астроцитів → [[Нервова тканина — нейрон і глія]] (гематоенцефалічний бар'єр).

### Перицити
Клітини навколо капілярів: регулюють діаметр, підтримують ендотелій, беруть участь в ангіогенезі.

## 6. Мікроциркуляторне русло

Включає: **артеріоли → метартеріоли → капіляри → венули**, а також **артеріоло-венулярні анастомози (шунти)**. Деталі: [[Мікроциркуляція і лімфатична система]].

## 7. Анастомози

- **Артеріальні**: з'єднання між гілками різних артерій (колатерали, дуги). Створюють обхідний кровоплин при закупорці.
- **Артеріоло-венулярні**: прямі шунти (шкіра, терморегуляція).
- **Венозні**: широка мережа (сплетення) — міжсистемні зв'язки (кава-кавальні, портокавальні).
- **Кінцеві (термінальні) артерії**: майже без колатералей (мозок, нирки, селезінка, сітківка) → закупорка веде до **інфаркту**.

## 8. Іннервація судин

| Тип нервів | Дія |
|---|---|
| **Симпатичні вазоконстрикторні** | норадреналін → α₁ → звуження (шкіра, органи черевної порожнини, нирки) |
| **Симпатичні вазодилататорні** | у скелетних м'язах (холінергічні; у людини роль обмежена); β₂-рецептори відповідають на адреналін |
| **Парасимпатичні** | розширення в окремих органах (статеві, слинні залози, мозок) |
| **Чутливі** | барорецептори, хеморецептори (сонний синус, дуга аорти) |

Більшість судин іннервовано **тільки симпатикою**; тонус підтримується постійним потоком імпульсів. Деталі: [[Вегетативна нервова система]].

## 9. Регуляція тонусу

### Нервова
Вазомоторний центр довгастого мозку. Рефлекси: барорецепторний (див. [[Серце — іннервація]]).

### Гуморальна
| Речовина | Ефект |
|---|---|
| **Адреналін** | β₂ — розширення (м'язи, серце); α — звуження (шкіра) |
| **Норадреналін** | звуження (α) |
| **Ангіотензин II** | сильне звуження, ↑ альдостерон |
| **Вазопресин (АДГ)** | звуження, затримка води |
| **Передсердний натрійуретичний пептид** | розширення, ↓ об'єм |
| **Брадикінін, гістамін** | розширення |
| **Ендотелін** | звуження |
| **NO** | розширення |

### Місцева (ауторегуляція)
- **Міогенна**: розтяг стінки → скорочення гладких м'язів (Остроумов — Бейліс); підтримує сталий кровотік.
- **Метаболічна**: ↓ O₂, ↑ CO₂, H⁺, K⁺, аденозин → розширення.
- Реактивна гіперемія, функціональна гіперемія.

## 10. Опір і закон Пуазейля

**Опір** R = 8ηL / πr⁴ (η — в'язкість, L — довжина, r — радіус). Радіус у **4-му степені**: звуження вдвічі збільшує опір у 16 разів. Тому артеріоли — головний регулятор. Основне рівняння: **АТ = СО × ЗПОС**. Див. [[Серце — серцевий цикл і гемодинаміка]].

## 11. Розподіл крові

| Орган | Частка серцевого викиду (спокій) |
|---|---|
| Печінка (разом з ворітною) | ~25% |
| Нирки | ~20% |
| Мозок | ~15% |
| Скелетні м'язи | ~20% (при навантаженні до 80%) |
| Шлунково-кишковий тракт | (входить у печінку) |
| Серце | ~5% |
| Шкіра | ~5% (при спеці більше) |
| Інші | ~10% |

## 12. Вікові зміни

- Збільшення жорсткості артерій (**артеріосклероз**): колаген заміщує еластин → ↑ САТ.
- Кальцифікація, потовщення інтими, ендотеліальна дисфункція.
- Вени: розширюються, клапани слабшають.
- Капіляри: потоншення базальної мембрани, зменшення густини.

## 13. Мнемоніки

- Оболонки: **Інтима — Медіа — Адвентиція** (від просвіту): «Всередині — Мускул — Ззовні».
- **Артерії — еластичні великі, м'язові середні, артеріоли — опір; капіляри — обмін; вени — ємність.**
- Типи капілярів: **суцільні — мозок, м'язи; фенестровані — нирки, кишка; синусоїдні — печінка, кістковий мозок**.
- Закон Пуазейля: **радіус⁴**.
