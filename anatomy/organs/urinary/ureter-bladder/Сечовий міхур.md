# Сечовий міхур (*vesica urinaria*)

Сечовий міхур — порожнистий м'язовий орган. Він **накопичує сечу** між сечовипусканнями й виштовхує її. Розтяжна стінка дає змогу міхуру вміщувати 300–500 мл без помітного зростання тиску.

## 1. Положення

| Показник | Значення |
|---|---|
| Положення | **малий таз**, **позаду лобкового симфіза** |
| **Порожній** | **за симфізом**, не виступає над його верхнім краєм |
| **Наповнений** | піднімається **над симфізом** у **надлобкову ділянку**; **пальпується і перкутується** |
| Ємність | **300–500 мл** (фізіологічна), **до 700–800 мл** |
| Позив | при **150–250 мл** (перший), **~400 мл** — сильний |
| Діти | у **новонароджених — орган черевної порожнини** (високо, над симфізом), опускається в таз до 6 років |

**Над симфізом (надлобкова пункція)**: доступ до міхура **без пошкодження очеревини** (при наповненому): між лобком і очеревинною складкою.

## 2. Частини

| Частина | Опис |
|---|---|
| **Верхівка** (*apex vesicae*) | вгорі, **спереду**; від неї йде **серединна пупкова зв'язка (урахус)** — залишок **сечового протоку (урахуса)** |
| **Тіло** (*corpus vesicae*) | основна частина |
| **Дно** (*fundus vesicae*) | задньо-нижня, **у чоловіків — до прямої кишки**, **у жінок — до піхви** |
| **Шийка** (*cervix vesicae*) | **нижня, звужена**, **виходить у сечівник**; у чоловіків — **навколо передміхурової залози** |

Урахус: нормально облітерується (**серединна пупкова зв'язка**). Вади: **нориця урахуса** (виділення з пупка), **кіста**, **дивертикул**.

## 3. Внутрішня поверхня

| Структура | Опис |
|---|---|
| **Складки слизової** (в спорожненому) | розправляються при наповненні |
| **Трикутник Льєто (міхуровий трикутник)** (*trigonum vesicae*) | **гладкий** (без складок); межі: **два отвори сечоводів + внутрішній отвір сечівника**; **прикріплена слизова до м'яза** |
| **Отвори сечоводів** | **щілиноподібні**, **косо** в стінці; **міжсечовідна складка** (*plica interureterica*) між ними |
| **Внутрішній отвір сечівника** | у шийці; **язичок міхура (uvula vesicae)** (у чоловіків — випин **передміхурової залози**) |

**Трикутник Льєто** — **часто** місце запалення (**тригоніт**), пухлин, **цистоскопія**.

## 4. Стінка

| Оболонка | Склад |
|---|---|
| **Слизова** | **перехідний епітелій (уротелій)**: **3 шари** — **поверхневі «парасолькові» клітини**, **проміжні**, **базальні**; **плакіни** (**бар'єр** від сечі); **розтягується** (1–3 клітини → 5–6 при порожньому) |
| **Підслизова** | пухка сполучна тканина (в області трикутника — слабка) |
| **М'язова (детрузор)** (*m. detrusor vesicae*) | **3 шари гладких м'язів**: зовнішній поздовжній, середній циркулярний, внутрішній поздовжній; **скорочення виштовхує сечу** |
| **Адвентиція / серозна** | **очеревина** (верхня поверхня і частина бічних) |

### Сфінктери (шийка)
| Сфінктер | Склад | Іннервація |
|---|---|---|
| **Внутрішній (*m. sphincter vesicae internus*)** | **гладкий**; петлеподібні волокна шийки | **симпатика (T10–L2; α₁)** — **скорочує**; парасимпатика — розслабляє |
| **Зовнішній (*m. sphincter urethrae externus*)** | **посмугований**, **довільний**; в **діафрагмі таза** (*sphincter urethrae membranaceae*) | **статевий нерв (S2–S4)**; **ядро Онуфа** |

У чоловіків внутрішній сфінктер **запобігає ретроградній еякуляції** (в міхур).

## 5. Відношення до очеревини і сусідніх органів

### Очеревина
- **Верхня поверхня** і **бічні** — частково вкриті очеревиною → **латеральні заглибини**; **міхурова заглибина** — перед.
- **Порожній**: очеревина лише **верхівка**.
- **Наповнений**: очеревина **піднімається** — **передня стінка** прилягає до передньої черевної стінки **без очеревини** → **надлобкова пункція**.

### Сусідні органи
| | Чоловіки | Жінки |
|---|---|---|
| **Спереду** | лобковий симфіз, **передміхурова клітковина (простір Ретціуса)** | те саме |
| **Ззаду** | **пряма кишка**, **сім'яні міхурці**, ампули сім'явивідних проток, **передміхурова залоза (знизу)** | **шийка матки**, піхва (пухирно-піхвова перегородка) |
| **Зверху** | петлі кишок | матка (пузирно-маткова заглибина) |
| **Знизу** | **передміхурова залоза** | **діафрагма таза** (сечівник) |

**Простір Ретціуса** (позаочеревинний, перед міхуром): шлях поширення гною, **розрив міхура** (позаочеревинний).

## 6. Кровопостачання і лімфа

| | Опис |
|---|---|
| **Артерії** | **верхні міхурові** (з **пупкової артерії**), **нижні міхурові** (з **внутрішньої клубової**; у жінок — **піхвова**), **запірна (затульна)**, внутрішня статева |
| **Вени** | **міхурове венозне сплетення** → **внутрішня клубова вена**; **зв'язок із сплетеннями простати/матки/прямої кишки** (**без клапанів**) → метастази |
| **Лімфа** | **внутрішні та зовнішні клубові** вузли |

Деталі: [[Артерії нижньої кінцівки і таза]], [[Вени — нижня порожниста і ворітна системи]].

## 7. Іннервація і контроль сечовипускання

### Нерви
| Нерв | Склад | Дія |
|---|---|---|
| **Тазові нерви** (*nn. splanchnici pelvici*) | **парасимпатичні S2–S4** | **скорочення детрузора** (M₃), **розслаблення внутрішнього сфінктера**; **чутливі від розтягу** |
| **Підчеревні нерви** (*n. hypogastricus*) | **симпатичні T10–L2** | **розслаблення детрузора (β₃)**, **скорочення внутрішнього сфінктера (α₁)** → **накопичення**; **еякуляція** |
| **Статевий нерв** (*n. pudendus*) | **соматичний S2–S4** (ядро Онуфа) | **зовнішній сфінктер (довільне утримання)**, чутливість уретри |

### Рефлекс сечовипускання
1. **Наповнення міхура** (200–400 мл) → **рецептори розтягу** → **тазові нерви (S2–S4)** → **спинний мозок**.
2. **Спинальний рефлекс** (немовлята): **скорочення детрузора + розслаблення сфінктерів** → **мимовільно**.
3. **У дорослих**: **центр сечовипускання в мості (Баррінгтона, PMC)** — **керує** рефлексом; **кора (лобова)** — **довільний контроль** (гальмує до зручного моменту).
4. **Довільне**: кора → міст → S2–S4 → **розслаблення зовнішнього сфінктера**, **скорочення детрузора** → сечовипускання.

Деталі: [[Сечівник і сечовипускання]], [[Спинний мозок]], [[Стовбур мозку]].

### Фази
| Фаза | Механізм |
|---|---|
| **Накопичення** | **симпатика (α, β₃)**, **статевий нерв**, розтяжність → низький тиск (10 см вод. ст.) |
| **Спорожнення** | **парасимпатика**, **центр у мості**, розслаблення сфінктерів |

## 8. Цистометрія (тиск–об'єм)

- **Розтяжність (compliance)** висока: тиск майже **не зростає** до 300–400 мл (**закон Лапласа**: тиск ↓ при розширенні).
- При **сильному позиві** — **скорочення детрузора** (30–60 см вод. ст. при сечовипусканні).
- **Залишковий об'єм** (після спорожнення) **< 50 мл** (**> 100 мл — патологія**).

## 9. Розвиток

- З **урогенітальної пазухи** (ентодерма клоаки) — **епітелій**; **мезенхіма** — м'язи.
- **Трикутник Льєто** утворюється з розширених кінців мезонефричних проток (мезодерма); решта міхура — з ентодерми.
- **Урахус**: з **алантоїса** → облітерація.
- **Вади**: **екстрофія міхура** (відкритий міхур, дефект передньої стінки), **подвоєння**, **дивертикули**, **нориця урахуса**.

## 10. Хвороби сечового міхура

| Хвороба | Суть | Ознаки |
|---|---|---|
| **Цистит** | запалення (бактерії, **E. coli** у 80%; **жінки** — короткий сечівник) | **дизурія, часті позиви, надлобковий біль, мутна сеча, гематурія**; **без лихоманки** (якщо без пієлонефриту) |
| **Інтерстиціальний цистит** | хронічний біль | |
| **Гостра затримка сечі** | **аденома простати**, камінь, травма, ліки (антихолінергічні, опіоїди), післяопераційна | **неможливість сечовипускання**, болісний позив, **розтягнутий міхур**; **катетеризація** |
| **Нетримання** | **стресове (кашель, чхання — слабке тазове дно)**, **ургентне** (гіперактивний міхур), **за переповнення**, змішане | |
| **Гіперактивний міхур** | ургентність, частота; **антимускаринові**, β₃-агоністи |
| **Нейрогенний міхур** | ураження нервів: **спастичний** (вище S2; детрузор-сфінктерна дисинергія), **в'ялий** (ураження S2–S4, діабет, конус) |
| **Сечові камені міхура** | |
| **Пухлини** | **уротеліальна карцинома** (**куріння, анілінові барвники, шистосомоз**; **безболісна гематурія**; **цистоскопія**) |
| **Дивертикули** | |
| **Травма** | **внутрішньоочеревинний** (верхня стінка) і **позаочеревинний** (перелом таза) розрив |
| **Урахус**: нориця, кіста | |
| **Інфекції** | **цистит, пієлонефрит**: [[Хвороби сечової системи]] |

### Діагностика
- **Аналіз сечі**, **посів**.
- **УЗД** (залишковий об'єм), **цистоскопія**, **цистографія**, **уродинаміка** (цистометрія).

## 11. Мнемоніки

- Міхур: **верхівка (урахус), тіло, дно, шийка**; **трикутник Льєто: 2 сечоводи + уретра**.
- Іннервація: **парасимпатика (S2–S4) — «Pee» (спорожнення)**; **симпатика (T10–L2) — «Store» (накопичення)**; **статевий нерв — «Control»** (довільний).
- **S2–S4** — сегменти спинного мозку, що керують сечовипусканням, дефекацією і статевою функцією.
- **Ємність 300–500 мл; позив 150–250 мл**.
- **Рак міхура**: безболісна гематурія → цистоскопія.
