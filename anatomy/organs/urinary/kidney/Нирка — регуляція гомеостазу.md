# Нирка — регуляція гомеостазу

Нирка підтримує постійний **об'єм рідини, осмолярність, склад електролітів, pH** і **артеріальний тиск**. Вона також є ендокринним органом: виробляє **ренін, еритропоетин, кальцитріол**.

## 1. Рідинні простори тіла

| Простір | Об'єм (70 кг) | % маси |
|---|---|---|
| **Загальна вода** | **~42 л** | 60% |
| **Внутрішньоклітинна** | ~28 л | 40% |
| **Позаклітинна** | ~14 л | 20% |
| — інтерстиційна | ~10,5 л | |
| — плазма | ~3,5 л | |

Основний катіон позаклітинної рідини — **Na⁺**, внутрішньоклітинної — **K⁺**. **Осмолярність плазми 285–295 мОсм/кг**.

## 2. Регуляція водного балансу (осмолярності)

### Антидіуретичний гормон (АДГ, вазопресин)
| Показник | Значення |
|---|---|
| Синтез | **супраоптичне і паравентрикулярне ядра гіпоталамуса**; **зберігається в нейрогіпофізі** |
| **Тригер** | **↑ осмолярності плазми** (осморецептори гіпоталамуса, **+1–2%**); **↓ ОЦК** (на > 10%); ангіотензин II; стрес, біль, нудота |
| **Дія** | **V₂-рецептори** збірної трубки → **аквапорини-2** → **↑ реабсорбція води**; **V₁** — звуження судин; **↑ проникність для сечовини** |
| **Підсумок** | **концентрована сеча, мало; ↓ осмолярність плазми** |

Нейрон: [[Проміжний мозок і базальні ядра]]. **Центр спраги** — гіпоталамус.

### Спрага
↑ осмолярність, ↓ ОЦК → **питво**.

### Порушення
| Стан | Суть |
|---|---|
| **Нецукровий діабет** | немає АДГ (центральний — травма, пухлина) або нирки не реагують (нефрогенний — літій); **поліурія, спрага, гіпернатріємія** |
| **СНАДГ** (синдром неадекватної секреції АДГ) | ↑ АДГ (пухлини легені, ЦНС, ліки): **затримка води, гіпонатріємія**, концентрована сеча |
| **Гіпонатріємія** | **Na⁺ < 135** → набряк мозку: головний біль, судоми |
| **Гіпернатріємія** | **Na⁺ > 145** → зневоднення клітин мозку |

## 3. Регуляція Na⁺ і ОЦК (об'єму)

| Система | Дія |
|---|---|
| **Ренін — ангіотензин — альдостерон (РААС)** | ↑ Na⁺, ↑ ОЦК, ↑ АТ |
| **Симпатична нервова система** | затримка Na⁺ (β₁ → ренін; α → реабсорбція) |
| **Передсердний натрійуретичний пептид (ANP, BNP)** | ↓ Na⁺, ↓ ОЦК |
| **АДГ** | вода |
| **Тиск у нирці (натрійурез тиску)** | ↑ АТ → ↑ виведення Na⁺ і води (довготривала регуляція АТ) |

### Система РААС
1. **Тригери виділення реніну** (**юкстагломерулярні клітини**): **↓ тиск у приносній артеріолі (барорецептор)**, **↓ NaCl** у macula densa, **симпатика (β₁)**.
2. **Ренін** (фермент) розщеплює **ангіотензиноген** (печінка) → **ангіотензин I** (10 амінокислот).
3. **АПФ** (ангіотензинперетворювальний фермент, **легені**, ендотелій) → **ангіотензин II** (8 амінокислот).
4. **Ангіотензин II**:
   - **Системна вазоконстрикція** (AT₁) → ↑ АТ.
   - **Звуження виносної артеріоли** → підтримка ШКФ.
   - **↑ реабсорбція Na⁺ у проксимальному канальці**.
   - **↑ альдостерон** (кора надниркових).
   - **↑ АДГ**, **↑ спрага**.
   - Симпатична активація.
5. **Альдостерон**: **збірна трубка (головні клітини)** → **↑ ENaC** → **↑ Na⁺ реабсорбція**, **↑ K⁺ і H⁺ секреція**; затримка води.

### Ліки, що діють на РААС
| Група | Приклад | Ефект |
|---|---|---|
| **Інгібітори АПФ** | еналаприл, раміприл | ↓ ангіотензин II; **кашель (брадикінін)**, **гіперкаліємія**, ангіоневротичний набряк |
| **Сартани (БРА)** | лозартан | блок AT₁ |
| **Інгібітори реніну** | аліскірен | |
| **Антагоністи альдостерону** | спіронолактон, еплеренон | ↑ K⁺ |
| **Діуретики** | | [[Нирка — утворення сечі]] |

### Ниркова гіпертензія
**Стеноз ниркової артерії** (атеросклероз; фіброзно-м'язова дисплазія) → **↓ тиск → ↑ ренін → ↑ АТ**; **шум над нирковою артерією**; **ІАПФ можуть погіршити ШКФ** (при двобічному стенозі).

## 4. Регуляція K⁺

| Показник | Значення |
|---|---|
| Норма плазми | **3,5–5,0 ммоль/л** (98% — **всередині клітин**) |
| Виведення | **~90% нирками**, 10% кишкою |

| Механізм | Опис |
|---|---|
| **Секреція в ДЗК і збірній трубці** | **головні клітини**; регулюється **альдостероном**, **K⁺ плазми**, **потоком** |
| **Розподіл** | **інсулін, β₂-агоністи, альдостерон** → K⁺ в клітини; **ацидоз** → K⁺ з клітин |

### Порушення
| Стан | Причина | ЕКГ |
|---|---|---|
| **Гіперкаліємія (> 5,5)** | ниркова недостатність, ІАПФ, спіронолактон, ацидоз, гемоліз | **високі гострі T, розширення QRS** → фібриляція: [[Серце — ЕКГ]] |
| **Гіпокаліємія (< 3,5)** | **діуретики**, блювання, діарея, гіперальдостеронізм | пласкі T, **U-хвиля**, аритмії |

## 5. Регуляція Ca²⁺, фосфату, вітаміну D

| Гормон | Дія |
|---|---|
| **Паратгормон (ПТГ)** (паращитоподібні) | ↑ Ca²⁺ реабсорбція в ДЗК; **↓ фосфат реабсорбція (фосфатурія)**; **↑ 1α-гідроксилазу** (активний вітамін D) |
| **Кальцитріол** (1,25-(OH)₂D₃) | утворюється **в проксимальних канальцях** (1α-гідроксилаза); **↑ всмоктування Ca²⁺ і фосфату в кишці**; ↑ реабсорбція |
| **Кальцитонін** | слабко |

**Ниркова остеодистрофія** при хронічній хворобі нирок: ↓ кальцитріол → ↓ Ca²⁺ → **вторинний гіперпаратиреоз** → **ураження кісток**: [[Кісткова тканина]], [[Хвороби сечової системи]].

## 6. Кислотно-лужна рівновага

**pH крові 7,35–7,45.** Нирка — **довготривалий (повільний, години–дні)** регулятор (легені — швидкий): [[Дихання — газообмін і транспорт газів]].

### Механізми нирки
1. **Реабсорбція HCO₃⁻** (проксимальний, **~85%**; ДЗК): через секрецію H⁺ і **карбоангідразу**; повернення **все** фільтрованого.
2. **Нова генерація HCO₃⁻** (**титровані кислоти** + **аміак**): **секреція H⁺** (збірна — вставні α-клітини) → зв'язується з **фосфатним буфером (HPO₄²⁻ → H₂PO₄⁻)** і **аміаком (NH₃ → NH₄⁺)**.
3. **Аміакогенез**: з **глутаміну** (проксимальний каналець) → **NH₄⁺ у сечу**; ↑ при ацидозі (хронічно).
4. **Виведення H⁺**: **40–80 ммоль/добу** (нелеткі кислоти з метаболізму).

### Реакція на порушення
| Стан | Нирка |
|---|---|
| **Ацидоз** | ↑ секреція H⁺, ↑ аміакогенез, ↑ реабсорбція HCO₃⁻ → **кисла сеча (pH до 4,5)** |
| **Алкалоз** | ↓ реабсорбція HCO₃⁻ (виведення), **лужна сеча** |

### Ниркові ацидози
- **Ниркова недостатність**: ↓ аміакогенез, ↓ виведення H⁺ → **метаболічний ацидоз**.
- **Тубулярний ацидоз (RTA)**: типи 1 (дистальний — дефект секреції H⁺), 2 (проксимальний — втрата HCO₃⁻), 4 (↓ альдостерон — **гіперкаліємія**).
- **Аніонний розрив** (anion gap): диференціювання метаболічних ацидозів.

## 7. Ендокринна функція нирки

| Гормон | Місце | Тригер | Дія |
|---|---|---|---|
| **Ренін** | ЮГ-клітини | ↓ тиск, ↓ NaCl, симпатика | РААС |
| **Еритропоетин (ЕПО)** | **інтерстиціальні фібробласти кори (перитубулярні клітини)** | **гіпоксія** (↓ O₂ у нирці) → **HIF** | **↑ еритропоез** у кістковому мозку |
| **Кальцитріол** | проксимальний каналець | ПТГ, ↓ Ca²⁺, ↓ фосфат | кишка, кістки |
| **Простагландини (E₂, I₂)** | мозок нирки | ангіотензин II, симпатика | **вазодилатація, захист кровотоку** (НПЗП блокують!) |
| **Брадикінін, калікреїн** | | | вазодилатація |

### Еритропоетин
- **90% — нирка**, 10% — печінка.
- **Хронічна хвороба нирок** → **↓ ЕПО** → **нормохромна нормоцитарна анемія**; лікування **рекомбінантним ЕПО** + залізо.
- **Пухлини нирки** можуть виробляти ЕПО → **поліцитемія**.

## 8. Інші функції

- **Глюконеогенез** (до 20–25% при голодуванні; з лактату, глутаміну).
- **Деградація** пептидних гормонів (інсулін, глюкагон, ПТГ): ↓ при ХХН → **гіпоглікемія у діабетиків**.
- **Виведення** ліків і токсинів.
- **Метаболізм** вітаміну D, білків.

## 9. Регуляція артеріального тиску нирками

| Механізм | Швидкість | Опис |
|---|---|---|
| **Натрійурез тиску** | **довготривало (дні)** | ↑ АТ → ↑ виведення Na⁺/води → ↓ ОЦК → ↓ АТ (**основа довготривалого контролю**) |
| **РААС** | хвилини–години | ↓ АТ → ренін → ↑ АТ |
| **Ауторегуляція ШКФ** | секунди | |
| **ANP** | | ↓ ОЦК |

**Порушення**: **ниркова гіпертензія** (стеноз ниркової артерії, паренхіматозні хвороби: гломерулонефрит, діабет, полікістоз) — найчастіша **вторинна** причина: [[Хвороби судин]], [[Серце — серцевий цикл і гемодинаміка]].

## 10. Хвороби регуляції

| Стан | Суть |
|---|---|
| **Хронічна хвороба нирок (ХХН)** | ↓ ШКФ > 3 міс: ↓ ЕПО (анемія), ↓ кальцитріол (остеодистрофія), ацидоз, гіперкаліємія, гіпертензія, уремія |
| **Гостре ураження нирок (ГУН)** | раптове ↓ ШКФ: олігурія, ↑ креатинін |
| **Нефротичний синдром** | втрата білка → набряки |
| **Гіпер- і гіпонатріємія, калій** | |
| **Ренінома** | пухлина ЮГ-клітин: гіпертензія, гіпокаліємія |
| **Гіперальдостеронізм (Конна)** | ↑ альдостерон: гіпертензія, **гіпокаліємія**, алкалоз; ренін ↓ |

## 11. Мнемоніки

- **АДГ**: ↑ осмолярність → гіпоталамус → нейрогіпофіз → **аквапорини-2** у збірній → вода повертається.
- **РААС**: **ренін (нирка) → ангіотензин I → АПФ (легені) → ангіотензин II → альдостерон (надниркові)**.
- **Альдостерон**: **↑ Na⁺ (ENaC), ↓ K⁺, ↓ H⁺** (у сечі).
- Нирка виробляє: **ЕПО, ренін, кальцитріол**.
- **K⁺ норма 3,5–5**; гіперкаліємія → **високі T**; гіпокаліємія → **U-хвиля**.
- **Нирки — повільний буфер pH; легені — швидкий**.
