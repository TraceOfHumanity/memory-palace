# Нирка — утворення сечі

Сеча утворюється в три етапи: **фільтрація** в клубочках, **реабсорбція** (повернення потрібних речовин у кров) і **секреція** (додаткове виведення речовин з крові в канальці). Підсумок: **виділення = фільтрація − реабсорбція + секреція**.

Пов'язані файли: [[Сечова система — огляд]], [[Нирка — будова і положення]], [[Нефрон і судини нирки]], [[Нирка — регуляція гомеостазу]], [[Хвороби сечової системи]], [[Серце — серцевий цикл і гемодинаміка]], [[Мікроциркуляція і лімфатична система]], [[Вегетативна нервова система]], [[Дихання — газообмін і транспорт газів]].

## 1. Клубочкова фільтрація

**Фільтрація** — перехід плазми без клітин і більшості білків з капілярів клубочка в капсулу. Утворюється **первинна сеча (ультрафільтрат)**.

### Сили (Старлінг)
| Сила | Значення, мм рт. ст. | Напрямок |
|---|---|---|
| **Гідростатичний тиск у капілярі клубочка** (P_gc) | **~55–60** | **фільтрація** |
| **Гідростатичний тиск у капсулі** (P_Bs) | ~15 | проти |
| **Онкотичний тиск плазми** (π_gc) | **~30** (зростає вздовж капіляра) | проти |
| **Ефективний фільтраційний тиск** | **55 − 15 − 30 = ~10** | |

**Ефективний тиск = P_gc − P_Bs − π_gc ≈ 10 мм рт. ст.** (фільтрація ↓ до нуля до кінця капіляра).

### Швидкість клубочкової фільтрації (ШКФ, GFR)
| Показник | Значення |
|---|---|
| **ШКФ** | **~125 мл/хв** (чоловіки 90–140, жінки 80–125) = **180 л/добу** |
| Фільтраційна фракція | ШКФ / плазмотік = 125/650 ≈ **20%** |
| Фільтрат | **вода, іони, глюкоза, амінокислоти, сечовина, креатинін** (склад як у плазми **без білка**) |
| Не фільтруються | **клітини, білки (альбумін)** |

**ШКФ = K_f × (P_gc − P_Bs − π_gc)** (K_f — коефіцієнт фільтрації: площа × проникність).

### Регуляція ШКФ
| Фактор | Дія |
|---|---|
| **Діаметр приносної артеріоли** (розширення) | ↑ P_gc → **↑ ШКФ** |
| **Діаметр виносної артеріоли** (звуження) | ↑ P_gc → **↑ ШКФ** (помірне); сильне — ↓ кровотік |
| **Симпатика** | звуження приносної → ↓ ШКФ (при стресі, кровотечі) |
| **Ангіотензин II** | **переважно звужує виносну** → **підтримує ШКФ** при ↓ тиску |
| **Простагландини** (розширюють приносну) | **НПЗП** блокують → ↓ ШКФ (ризик ГПН) |
| **Передсердний натрійуретичний пептид (ANP)** | розширює приносну → ↑ ШКФ |
| **Ауторегуляція** | міогенна + **канальцево-клубочковий зворотний зв'язок**: ШКФ стала при АТ 80–180 |

### Вимірювання ШКФ: кліренс
**Кліренс (*clearance*)** — об'єм плазми, повністю очищений від речовини за хвилину:
**C = (U × V) / P** (U — концентрація в сечі, V — об'єм сечі за хв, P — у плазмі).

| Речовина | Кліренс | Використання |
|---|---|---|
| **Інулін** | = ШКФ (фільтрується, не реабсорбується, не секретується) | **золотий стандарт** (дослідження) |
| **Креатинін** | ≈ ШКФ (слабка секреція; +10–20%) | **клінічно** (формули **CKD-EPI**, Кокрофта — Голта, MDRD) |
| **Глюкоза** | 0 (реабсорбується повністю) | |
| **ПАГ (парааміногіпурова кислота)** | ≈ **ефективний плазмотік (~625 мл/хв)** (фільтрується + секретується) | |
| **Сечовина** | ~ 60% ШКФ | |
| **Цистатин C** | | альтернатива |

**Норма ШКФ > 90**; **< 60 мл/хв (3 міс) — ХХН**; **< 15 — кінцева стадія**: [[Хвороби сечової системи]].

## 2. Канальцева реабсорбція

**Реабсорбція** — повернення з канальців у кров. З 180 л фільтрату в сечу потрапляє **1–2 л**: **>99% реабсорбується**.

### Шляхи
| Шлях | Опис |
|---|---|
| **Трансклітинний** | через клітини (апікальна → базолатеральна мембрана) |
| **Парацелюлярний** | між клітинами (щільні контакти; вода, Ca²⁺, Mg²⁺, K⁺) |

### Типи транспорту
- **Первинний активний** (Na⁺/K⁺-АТФаза на базолатеральній мембрані — **двигун** усього).
- **Вторинний активний** (кониспорт Na⁺-глюкоза, Na⁺-АК; обмін Na⁺/H⁺).
- **Пасивний** (дифузія, **осмос**, **вода слідує за Na⁺**).

### Проксимальний каналець (65% Na⁺ і води)
| Що | Скільки | Механізм |
|---|---|---|
| **Na⁺, вода** | **~65%** | Na⁺/K⁺-АТФаза; **Na⁺/H⁺-обмін (NHE3)**; вода — осмотично (аквапорини-1); **ізоосмотична** реабсорбція |
| **Глюкоза** | **100%** | **SGLT2** (90%), **SGLT1** (10%) апікально + **GLUT2** базолатерально; **поріг ~10 ммоль/л (180 мг/дл)**; **ниркова глюкозурія** при перевищенні (**діабет**) |
| **Амінокислоти** | 100% | Na⁺-залежні транспортери |
| **HCO₃⁻** | **~80–90%** | через H⁺-секрецію і **карбоангідразу** (CO₂) |
| **Cl⁻** | | парацелюлярно |
| **K⁺** | ~65% | |
| **Фосфат** | 80% | **ПТГ ↓ реабсорбцію** (фосфатурія) |
| **Кальцій** | ~65% | пасивно |
| **Білки (малі)** | | **ендоцитоз** (мегалін) |
| **Сечовина** | ~50% | пасивно |
| **Вітаміни** | | |

**Інгібітори SGLT2** (ліки: емпагліфлозин) — ↓ реабсорбцію глюкози → **глюкозурія, діуретична дія** (кардіо- і нефропротекція).

### Петля Генле (25% Na⁺, 15% води)
| Відділ | Проникність | Реабсорбція |
|---|---|---|
| **Низхідна тонка** | **вода** (AQP1) | вода виходить → **сеча згущується** (↑ осмолярність) |
| **Висхідна тонка** | Na⁺, Cl⁻ | пасивно іони |
| **Висхідна товста** | **непроникна для води** | **Na⁺-K⁺-2Cl⁻ (NKCC2)** — активна (**петльові діуретики: фуросемід — блокують**) → **розведення сечі**, ↑ мозкова осмолярність |

### Дистальний каналець (5–8%)
- **NCC (Na⁺/Cl⁻)** — **тіазидні діуретики** блокують.
- **Ca²⁺** (ПТГ ↑ реабсорбцію; кальцитріол).
- Непроникний для води (без АДГ).

### Збірна трубка (залишок)
| Клітини | Функція |
|---|---|
| **Головні** | **Na⁺** (альдостерон → ENaC; **амілорид** блокує), **K⁺ секреція** (**спіронолактон** блокує альдостерон); **вода (АДГ → аквапорини-2)** |
| **Вставні α** | **секреція H⁺** (H⁺-АТФаза) → **кислотна сеча** |
| **Вставні β** | **секреція HCO₃⁻** |

### Підсумок сегментів
| Сегмент | % Na⁺ | Діуретик |
|---|---|---|
| **Проксимальний** | 65% | ацетазоламід (карбоангідраза), SGLT2i |
| **Товста висхідна** | 25% | **петльові** |
| **Дистальний** | 5% | **тіазидні** |
| **Збірна** | 3–5% | **калійзберігаючі** (спіронолактон, амілорид) |

## 3. Канальцева секреція

**Секреція** — перенесення речовин з крові/клітин у просвіт канальця.

| Речовина | Місце | Значення |
|---|---|---|
| **H⁺** | ПЗК, збірна | кислотно-лужний баланс |
| **K⁺** | **ДЗК, збірна (головні клітини)** | **основний шлях виведення K⁺**; ↑ альдостероном |
| **NH₄⁺** (аміак) | ПЗК | буфер сечі, виведення H⁺ |
| **Органічні кислоти і основи** (**ОАТ, ОСТ**) | **проксимальний** | **ліки (пеніцилін, діуретики)**, сечова кислота, **ПАГ**; **пробенецид** конкурує |
| **Креатинін** (слабко) | | |

## 4. Концентрація і розведення сечі

Нирка здатна виробляти **сечу різної осмолярності**: **50 мОсм/кг (розведена)** — **1200 мОсм/кг (концентрована)** при плазмі ~290.

### Протиточний механізм
1. **Висхідна товста** петля: **активно** виводить Na⁺, Cl⁻, K⁺ в інтерстицій **без води** → **гіперосмолярний мозок** (градієнт від 300 мОсм/кг у корі до **1200** у верхівці сосочка).
2. **Низхідна тонка**: вода → в інтерстицій (осмотично) → рідина концентрується.
3. **Протиточна помножувальна система (петля Генле)** створює градієнт; **прямі судини (*vasa recta*)** — **протиточний обмін** зберігає його.
4. **Сечовина** (збірна трубка, медулярна) **рециркулює** (АДГ ↑ проникність) → **ще ~40% градієнта**.
5. У **збірній трубці**: **АДГ → аквапорини-2** → **вода виходить за градієнтом** → **концентрована сеча**; без АДГ — розведена.

| Умови | АДГ | Збірна трубка | Сеча |
|---|---|---|---|
| **Зневоднення** | ↑ | проникна для води | **концентрована, малий об'єм (антидіурез)** |
| **Надлишок води** | ↓ | **непроникна** | **розведена, великий об'єм (водний діурез)** |

**Нецукровий діабет**: **центральний** (мало АДГ) або **нефрогенний** (нирки не реагують на АДГ) → **поліурія (3–20 л/добу), спрага**; **розведена сеча** (щільність < 1,005).

### Осмотичний діурез
Нереабсорбовані речовини (глюкоза при діабеті, манітол) утримують воду → **поліурія**.

## 5. Сеча: формування і склад

| Етап | Об'єм |
|---|---|
| **Фільтрат** | 180 л/добу |
| **Реабсорбція** | **>99%** |
| **Сеча** | **1–2 л** |

| Показник | Фільтрат → Сеча |
|---|---|
| **Вода** | 180 л → 1,5 л |
| **Na⁺** | 25 000 ммоль → ~150 |
| **Глюкоза** | 180 г → **0** |
| **Сечовина** | 54 г → 30 г |
| **Креатинін** | реабсорбція ≈ 0 → усе виводиться |

## 8. Мнемоніки

- **Фільтрація → реабсорбція → секреція**; **виділення = фільтрація − реабсорбція + секреція**.
- **Ефективний тиск фільтрації ≈ 55 − 15 − 30 = 10**.
- **Інулін = ШКФ**, **ПАГ = плазмотік**, **глюкоза = 0**.
- **ПЗК: 65% води/Na⁺, 100% глюкози і АК**.
- **Петльові — товста висхідна; тіазиди — ДЗК; спіронолактон — збірна**.
- **АДГ → аквапорини-2 → концентрована сеча**.
