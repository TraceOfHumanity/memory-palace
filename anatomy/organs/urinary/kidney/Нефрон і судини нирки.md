# Нефрон і судини нирки

**Нефрон** — функціональна одиниця нирки. У кожній нирці їх близько **1 млн**. Нефрон складається з **ниркового тільця** (де фільтрується кров) і **канальців** (де фільтрат змінюється й перетворюється на сечу). Особливі судини нирки забезпечують фільтрацію і концентрацію сечі.

Пов'язані файли: [[Сечова система — огляд]], [[Нирка — будова і положення]], [[Нирка — утворення сечі]], [[Нирка — регуляція гомеостазу]], [[Хвороби сечової системи]], [[Аорта і її гілки]], [[Вени — нижня порожниста і ворітна системи]], [[Мікроциркуляція і лімфатична система]], [[Судини — будова і типи]], [[Вегетативна нервова система]].

## 1. Типи нефронів

| Тип | Частка | Положення клубочка | Петля Генле | Особливості |
|---|---|---|---|---|
| **Кіркові (поверхневі)** | **~85%** | зовнішня/середня кора | **коротка** | **основна фільтрація**; пері-тубулярні капіляри |
| **Юкстамедулярні** | **~15%** | **на межі кори і мозкової речовини** | **довга, глибоко в мозок** | **концентрація сечі**; **прямі судини (*vasa recta*)** |

## 2. Будова нефрона

Шлях фільтрату: **ниркове тільце → проксимальний звивистий каналець → петля Генле → дистальний звивистий каналець → збірна трубка**.

```
Ниркове тільце (клубочок + капсула)
   ↓
Проксимальний звивистий каналець (ПЗК)
   ↓
Петля Генле: низхідна → висхідна (тонка і товста частини)
   ↓
Дистальний звивистий каналець (ДЗК)
   ↓
Збірна трубка → сосочкова протока → мала чашка
```

## 3. Ниркове тільце (*corpusculum renale*)

Розташоване в **корі**; діаметр ~200 мкм. Складається з:
1. **Клубочка** (*glomerulus*) — **капілярна сітка** (~30–50 петель).
2. **Капсули Шумлянського — Боумена** (*capsula glomeruli*) — подвійна стінка: **внутрішній (вісцеральний) листок** (**подоцити**) і **зовнішній (парієтальний)** (плоский епітелій). Між ними — **порожнина капсули (просвіт)**, куди надходить **первинна сеча (фільтрат)**.

### Полюси
| Полюс | Структури |
|---|---|
| **Судинний полюс** | входить **приносна артеріола**, виходить **виносна артеріола** |
| **Сечовий (канальцевий) полюс** | початок проксимального канальця |

### Клубочкова судинна система — «чудова мережа»
**Приносна (аферентна) артеріола → капіляри клубочка → виносна (еферентна) артеріола** — **артеріо-артеріальна** мережа (**унікальна: капіляри між двома артеріолами**). **Тиск у клубочку високий (~55–60 мм рт. ст.)** — забезпечує фільтрацію.

### Клітини клубочка
| Клітина | Функція |
|---|---|
| **Ендотелій капілярів** | **фенестри** (70–100 нм), **без діафрагм** — пропускають воду, малі молекули; **затримують клітини** |
| **Базальна мембрана клубочка (БМК)** | **~300 нм**; **колаген IV**, ламінін, **гепарансульфат (негативний заряд)** — **відштовхує альбумін** |
| **Подоцити** (*podocyti*) | відростки (**педикули**) з **щілинними діафрагмами** (**нефрин**) — **фільтраційні щілини (~25–60 нм)**; затримують великі білки |
| **Мезангіальні клітини** | між капілярами; **опора, скорочення** (регуляція ШКФ), **фагоцитоз**, виробляють матрикс |

### Фільтраційний бар'єр (3 шари)
1. **Фенестрований ендотелій** (затримує клітини).
2. **Базальна мембрана** (**розмір і заряд**; відштовхує негативні білки).
3. **Щілинні діафрагми подоцитів** (**нефрин**).

Проходять: вода, іони, **глюкоза, амінокислоти, сечовина, креатинін, малі білки** (< 5–6 нм; **молекулярна маса < 68 кДа**). **Не проходять**: **клітини крові, більшість білків (альбумін 69 кДа — майже ні; негативний заряд)**.
Порушення: **протеїнурія** — [[Хвороби сечової системи]].

## 4. Канальці

| Відділ | Довжина | Епітелій | Особливості |
|---|---|---|---|
| **Проксимальний звивистий (ПЗК)** | ~14 мм | **кубічний, щіткова облямівка**, багато мітохондрій, **базальна складчастість** | **реабсорбція ~65% води, Na⁺, глюкози, амінокислот, HCO₃⁻**, секреція H⁺, органічних кислот/основ |
| **Петля Генле: низхідна тонка** | | **плоский** | **проникна для води**, мало для іонів |
| **Висхідна тонка** | | плоский | проникна для **Na⁺/Cl⁻**, **не** для води |
| **Висхідна товста** | | **кубічний**, багато мітохондрій | **активна реабсорбція Na⁺, K⁺, 2Cl⁻** (NKCC2), **непроникна для води** — **розведення сечі** |
| **Дистальний звивистий (ДЗК)** | | **кубічний**, без щіткової облямівки | **Na⁺/Cl⁻ (NCC)**, **Ca²⁺ (ПТГ)**; **щільна пляма (macula densa)** |
| **З'єднувальний відділ** | | | |
| **Збірна трубка** | ~20 мм | **світлі (головні) клітини**; **вставні (α і β)** | **вода (АДГ — аквапорини-2)**, Na⁺ (альдостерон, ENaC), K⁺ секреція; **вставні клітини**: **H⁺ (α), HCO₃⁻ (β)** |
| **Сосочкова протока** | | | в малу чашку |

## 5. Юкстагломерулярний апарат (ЮГА)

Розташований біля **судинного полюса**, **регулює ШКФ і АТ**.

| Складова | Опис |
|---|---|
| **Юкстагломерулярні (гранулярні) клітини** | в стінці **приносної артеріоли**, **синтезують і виділяють ренін** (**барорецептор** + симпатика β₁) |
| **Щільна пляма (*macula densa*)** | **клітини ДЗК**, прилягають до артеріол; **сенсор NaCl** у канальцевій рідині |
| **Позаклубочкові мезангіальні клітини (Гурмагтіга)** | між артеріолами |

### Механізми
- **Канальцево-клубочковий зворотний зв'язок**: ↑ NaCl в macula densa → **аденозин** → **звуження приносної артеріоли** → ↓ ШКФ (**стабільність фільтрації**).
- **↓ NaCl / ↓ тиск** → **ренін** ↑ → **ангіотензин II**: [[Нирка — регуляція гомеостазу]].

## 6. Кровопостачання нирки

### Артерії (послідовність)
| Судина | Опис |
|---|---|
| **Ниркова артерія** (*a. renalis*) | від **черевної аорти (L1–L2)**; **права довша** (проходить позаду НПВ); ділиться на **передню і задню гілки** (5 сегментарних); **діаметр 5–7 мм** |
| **Сегментарні артерії** | **кінцеві** (5 сегментів) |
| **Міждольові (міжпірамідні)** | між пірамідами (в стовпах) |
| **Дугоподібні** (*aa. arcuatae*) | **на межі кори і мозку**, над основами пірамід |
| **Міждольчасткові (радіальні)** | у корі |
| **Приносні артеріоли** | до клубочків |
| **Клубочкові капіляри** | **фільтрація** |
| **Виносні артеріоли** | з клубочка |
| **Кіркові: навколоканальцеві (перитубулярні) капіляри** | **реабсорбція** (низький тиск ~10 мм рт. ст.) |
| **Юкстамедулярні: прямі судини (*vasa recta*)** | **ведуть в мозок** — **протиточний обмін**, **живлення мозку**; **ниркова мозкова речовина отримує мало крові (~5–10%)** → **гіпоксія** → **сосочковий некроз** (діабет, НПЗП) |

### Подвійна капілярна мережа
**Артеріола → клубочок → артеріола → навколоканальцеві капіляри → венули**: **перша** (клубочкова) — **високий тиск (фільтрація)**; **друга** (навколоканальцева) — **низький (реабсорбція)**. **Виносна артеріола регулює тиск у клубочку**.

### Вени
Венули → зіркоподібні → **міждольчасткові → дугоподібні → міждольові → ниркова вена** → **НПВ**. **Ліва ниркова вена довша** (перед аортою, **під ВБА — «нутракер»**), приймає **ліву яєчкову/яєчникову та ліву надниркову**: [[Вени — нижня порожниста і ворітна системи]].

### Особливості
- **Ауторегуляція**: кровотік і **ШКФ сталі** при АТ **80–180 мм рт. ст.** (**міогенна** — розтяг артеріоли → скорочення; **канальцево-клубочковий зворотний зв'язок**).
- **Низька вилучена фракція O₂**: артеріо-венозна різниця O₂ мала (нирка споживає O₂ для активного транспорту Na⁺; **кровотік більший за потреби**).
- Артерії: [[Аорта і її гілки]].

## 7. Мозкова речовина: протиточний механізм (коротко)

- **Висхідна товста** → іони йдуть у інтерстицій (без води) → **гіперосмолярний мозок** (до 1200 мОсм/кг у верхівці сосочка).
- **Низхідна тонка** → вода виходить, **концентрується**.
- **Прямі судини** — **протиточний обмін** (зберігають градієнт).
- **Сечовина** рециркулює (АДГ).
Деталі: [[Нирка — утворення сечі]].

## 9. Мнемоніки

- Шлях нефрона: **клубочок → ПЗК → петля Генле → ДЗК → збірна трубка**.
- **Фільтраційний бар'єр: ендотелій (фенестри) → БМК → подоцити (нефрин)**.
- ЮГА: **гранулярні клітини (ренін) + macula densa (сенсор NaCl)**.
- **Судини**: **приносна → клубочок → виносна → перитубулярні / vasa recta**.
- Кора — **85% нефронів** (короткі петлі); **юкстамедулярні 15%** — довгі петлі, концентрація.
