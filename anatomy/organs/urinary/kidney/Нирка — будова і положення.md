# Нирка — будова і положення (*ren*, *nephros*)

Нирка — парний бобоподібний орган. Вона лежить заочеревинно на задній стінці живота. Нирка складається з **кіркової** і **мозкової** речовини та системи порожнин (**чашки, миска**), що збирають сечу.

## 1. Положення

| Показник | Значення |
|---|---|
| Положення | **заочеревинно**, по боках хребта, в **поперековій ділянці** |
| Рівень | **T12–L3** (ліва нирка вище; **права на 1–1,5 см нижче** — печінка) |
| Орієнтир | **верхній полюс** — ~T12; **нижній полюс** — L3; **ворота** — **L1–L2** (**транспілорична площина** Аддісона) |
| Нахил | осі нирок сходяться вгору (нижні полюси далі від серединної лінії) |
| Рухомість | 2–3 см при диханні (нефроптоз — надмірна) |

**Проєкція ззаду**: **кут між XII ребром і довгими м'язами спини** (**реберно-хребтовий кут**): місце **болю при нирковій кольці**, **симптом Пастернацького** (поколочування ребром долоні — біль при пієлонефриті, камінні).
Права нирка виступає **з-під XII ребра**, у худих **пальпується**.

### Розміри
| Показник | Значення |
|---|---|
| Довжина | 10–12 см |
| Ширина | 5–6 см |
| Товщина | 3–4 см |
| Маса | **120–200 г** (чоловіки ~150 г) |

## 2. Зовнішня будова

| Структура | Опис |
|---|---|
| **Верхній і нижній полюс** | кінці |
| **Латеральний (опуклий) і медіальний (увігнутий) краї** | |
| **Передня і задня поверхні** | |
| **Ворота нирки** (*hilum renale*) | на медіальному краї; входять: **ниркова артерія**, нерви; виходять: **ниркова вена**, **миска (сечовід)**, лімфатичні судини |
| **Ниркова пазуха** (*sinus renalis*) | порожнина всередині, що відкривається воротами: чашки, миска, судини, жир |

### Порядок структур у воротах (спереду назад)
**Вена — артерія — миска (сечовід)** («**ВАМ**»): вена найпереду, миска найглибше.

## 3. Оболонки нирки (від нирки назовні)

| Оболонка | Опис |
|---|---|
| **Фіброзна капсула** (*capsula fibrosa*) | тонка, щільна, знімається з нирки (при хворобах зростається) |
| **Жирова капсула** (*capsula adiposa*, паранефрій) | жировий шар; **амортизація**; збільшується при ожирінні; **паранефральна блокада** |
| **Ниркова фасція** (*fascia renalis*, Героти) | **передній і задній листки**; охоплюють нирку і надниркову залозу; **нижче відкрита** (спуск гною, нефроптоз) |

**Утримують нирку на місці**: **жирова капсула**, фасція, **ниркова ніжка** (судини), **внутрішньочеревний тиск (м'язи живота)**, **ложа нирки**. Ослаблення → **нефроптоз** («блукаюча нирка»).

## 4. Відношення нирок (топографія)

### Спільне
- **Заочеревинні**, вкриті очеревиною **спереду частково**.
- Позаду: **діафрагма, квадратний м'яз попереку, поперековий м'яз, поперечний м'яз живота**; **XII ребро**; **підреброві і клубово-підчеревний нерви**.
- Зверху: **надниркова залоза**.
- Оточені жировою капсулою.

### Права нирка
| Спереду | |
|---|---|
| **Печінка** (права частка) | верхні 2/3 |
| **Правий (печінковий) згин ободової кишки** | нижній полюс |
| **Низхідна частина дванадцятипалої кишки** | медіально, **біля воріт** |
| **Тонка кишка** | |

### Ліва нирка
| Спереду | |
|---|---|
| **Шлунок, селезінка** | верхня частина |
| **Хвіст і тіло підшлункової залози** | середина |
| **Лівий (селезінковий) згин ободової** | |
| **Тонка кишка** | |

Деталі сусідів: [[Печінка — будова]], [[Підшлункова залоза]], [[Товста кишка]], [[Очеревина]]. **Травма селезінки/печінки** і нирок разом; **пухлина нирки** → зсув ободової кишки (на рентгені).

## 5. Будова на розрізі

На **фронтальному розрізі**:

| Частина | Опис |
|---|---|
| **Кіркова речовина** (*cortex renalis*) | **зовнішня**, 0,5–1 см, темно-червона, зерниста; містить **ниркові тільця** (клубочки), звивисті канальці; **ниркові стовпи** (Бертіні) — між пірамідами |
| **Мозкова речовина** (*medulla renalis*) | внутрішня, світліша, **8–18 пірамід (в середньому 10–12)**; **основа піраміди** до кори, **верхівка** — **ниркові сосочки** (*papillae renales*) |
| **Промениста частина кіркової речовини** | **мозкові промені** (Феррейна) — в кору від пірамід |

### Частки нирки
**Ниркова частка** (*lobus renalis*) = **піраміда + кіркова речовина навколо**. У плода часточкова будова зберігається (**бугриста поверхня**), у дорослого — гладка.

### Порожнини (збирання сечі)
| Структура | Опис |
|---|---|
| **Малі чашки** (*calyces renales minores*) | охоплюють сосочок піраміди; **8–10** |
| **Великі чашки** (*calyces renales majores*) | **2–3** (верхня, середня, нижня) |
| **Ниркова миска** (*pelvis renalis*) | лійка; у пазусі; переходить у **сечовід** на рівні **нижнього краю нирки** |

**Миска**: **внутрішньопазушна** (більша частина в пазусі — частіше), **позапазушна** (виходить за ворота; легко пальпується, часто розширена — легше оперувати).

**Пієлоуретеральний сегмент (ПУС)** — звуження біля переходу миски в сечовід: **стеноз → гідронефроз**.

## 6. Стінка порожнин

Слизова (**перехідний епітелій — уротелій**), м'язова (гладка, перистальтика), адвентиція. **Скорочення чашок і миски** виштовхують сечу в сечовід. Вона **захищена** від агресивної сечі: **уроплакіни**, глікозаміноглікани.

## 7. Сегменти нирки

Нирка має **5 сегментів** (за артеріями):
| Сегмент | Артерія |
|---|---|
| **Верхній** | верхня сегментарна |
| **Верхній передній** | |
| **Нижній передній** | |
| **Нижній** | |
| **Задній** | задня сегментарна |

Сегментарні артерії — **кінцеві**: **закупорка → інфаркт сегмента**. **Безсудинна зона** (лінія Брюделя) — на задній поверхні, **розріз** — мінімум кровотечі. Деталі: [[Нефрон і судини нирки]].

## 8. Лімфатичні судини, іннервація

| | Опис |
|---|---|
| **Лімфа** | **бічні аортальні (поперекові) вузли** |
| **Іннервація** | **ниркове сплетення**: **симпатичні (T10–L1)** — звуження судин, ↑ ренін; **парасимпатичні (блукаючий)** — вазодилатація; **чутливі** — **біль T10–L1** |
| **Іррадіація болю** | ниркова колька → **поперек, бік, пахвина, статеві органи, внутрішня поверхня стегна (L1–L2)** |

Деталі: [[Вегетативна нервова система]].

## 9. Вікові особливості

- **Новонароджений**: нирки **відносно великі** (~12 г), **часточкові**, **нижній полюс на рівні гребеня клубової кістки**; **функція незріла** (ШКФ ~25% дорослого, ↓ концентрація).
- **Дитина**: «піднімаються»; нефрони дозрівають до ~1 року.
- **Старість**: ↓ маса, нефрони (~**1% на рік після 40**), ШКФ **↓ ~1 мл/хв/рік**.

## 12. Мнемоніки

- Нирки: **заочеревинні, T12–L3, права нижче лівої**.
- Ворота (спереду назад): **вена — артерія — миска** («ВАМ»).
- Шари: **фіброзна капсула → жирова → фасція Героти** (від нирки назовні).
- Сечу збирають: **малі чашки (8–10) → великі (2–3) → миска → сечовід**.
- Кора: **клубочки і звивисті канальці**; мозок: **піраміди, прямі канальці, сосочки**.
