# Сечова система — огляд (*systema urinarium*)

Сечова система очищає кров від продуктів обміну й підтримує постійний склад внутрішнього середовища. Нирки утворюють сечу, а сечоводи, сечовий міхур і сечівник виводять її.

## 1. Склад системи

| Орган | Функція |
|---|---|
| **Нирки** (*renes*), парні | утворення сечі, регуляція гомеостазу, ендокринна функція |
| **Сечоводи** (*ureteres*), парні | проводять сечу з нирки в міхур |
| **Сечовий міхур** (*vesica urinaria*) | накопичує сечу |
| **Сечівник** (*urethra*) | виводить сечу назовні |

Верхні сечові шляхи: нирки й сечоводи. Нижні: міхур і сечівник.

## 2. Функції нирок

| Функція | Зміст |
|---|---|
| **Виділення** | сечовина, креатинін, сечова кислота, токсини, ліки, надлишок іонів |
| **Регуляція об'єму рідини і осмолярності** | вода, Na⁺ |
| **Регуляція електролітів** | K⁺, Ca²⁺, Mg²⁺, фосфат, H⁺ |
| **Кислотно-лужний баланс** | виведення H⁺, регенерація HCO₃⁻ |
| **Регуляція артеріального тиску** | система **ренін — ангіотензин — альдостерон**, об'єм крові |
| **Ендокринна** | **еритропоетин**, **ренін**, активна форма **вітаміну D** (кальцитріол), простагландини |
| **Метаболізм** | **глюконеогенез** при голодуванні, розпад пептидних гормонів (інсулін) |

## 3. Основні числа

| Показник | Значення |
|---|---|
| Кровотік нирок | **~1,2 л/хв** (≈20–25% серцевого викиду) |
| Плазмотік нирок | ~600–650 мл/хв |
| **Клубочкова фільтрація (ШКФ, GFR)** | **~125 мл/хв** (≈180 л/добу) |
| Сеча за добу | **1–2 л** (≈1% фільтрату) |
| Реабсорбція | **>99%** фільтрату |
| Маса нирки | 120–200 г |
| Нефронів | ~**1 млн** у кожній нирці |
| Частота сечовипускання | 4–8 разів/добу |
| Ємність міхура | 300–500 мл (до 700) |

Нирки складають ~0,5% маси тіла, але отримують 20–25% серцевого викиду.

## 4. Склад сечі

| Показник | Значення |
|---|---|
| **Об'єм** | 1–2 л/добу (діурез); **< 400–500 мл — олігурія**, **< 100 мл — анурія**, **> 2,5–3 л — поліурія** |
| **Колір** | солом'яно-жовтий (**урохром**) |
| **Відносна щільність** | 1,010–1,025 (1,003–1,035) |
| **pH** | 4,5–8 (зазвичай ~6) |
| **Осмолярність** | 50–1200 мОсм/кг |
| **Білок** | < 150 мг/добу (сліди) |
| **Глюкоза** | немає |
| **Основні складники** | **вода (95%)**, **сечовина (~25–30 г/добу)**, креатинін (1–1,5 г), сечова кислота, Na⁺, K⁺, Cl⁻, NH₄⁺ |

Патологічні складники: **білок** (протеїнурія), **кров** (гематурія), **глюкоза** (діабет), **кетони**, **лейкоцити** (піурія), **бактерії**, **циліндри**: [[Хвороби сечової системи]].

## 5. Розвиток

Сечова система розвивається з **проміжної мезодерми** (нефрогенний тяж). Три покоління нирок:

| Нирка | Час | Доля |
|---|---|---|
| **Переднирка** (*pronephros*) | 4-й тиждень | зникає |
| **Первинна нирка** (*mesonephros*) | 4–8 тиждень | протока (Вольфова) → **у чоловіків придаток яєчка, сім'явивідна протока**; жінки — рудименти |
| **Остаточна нирка** (*metanephros*) | з 5 тижня; працює з 10–12 тижня | нирка |

- **Нефрони** — з **метанефрогенної бластеми**.
- **Збірні протоки, чашки, миска, сечовід** — з **сечовідного (метанефричного) дивертикула** (відгалуження мезонефричної протоки).
- **Сечовий міхур і сечівник** — з **урогенітальної пазухи** (ентодерма клоаки).
- Нирки «**піднімаються**» з тазу в поперекову ділянку (6–9 тиждень): порушення → **тазова ектопія**, **підковоподібна нирка** (зрощення нижніх полюсів під нижньою брижовою артерією).
- Амніотична рідина в другому триместрі — переважно **сеча плода**: при відсутності нирок — **маловоддя**, гіпоплазія легень (послідовність Поттер).

Вади: **агенезія**, **подвоєння**, **полікістоз**, **гідронефроз**, **ектопія**, **підковоподібна нирка**, **вади сечовода (ВМР)**, **гіпоспадія**, **клапани задньої уретри**.

## 6. Кровопостачання і іннервація (загальне)

- Артерії: **ниркові** з черевної аорти: [[Аорта і її гілки]]. Вени: **ниркові** → нижня порожниста: [[Вени — нижня порожниста і ворітна системи]].
- Іннервація: **ниркове сплетення** (симпатика T10–L1), блукаючий нерв, **тазові нерви S2–S4** до міхура; соматична — зовнішній сфінктер.

## 7. Топографія і проєкції (стисло)

Нирки лежать **заочеревинно** на задній стінці живота по боках хребта (**T12–L3**). Деталі: [[Нирка — будова і положення]]. Сечоводи йдуть донизу до таза, міхур лежить за лобковим симфізом.

## 8. Клінічні поняття

| Термін | Значення |
|---|---|
| **Дизурія** | болісне сечовипускання |
| **Полакіурія** | часте |
| **Ніктурія** | нічні сечовипускання |
| **Олігурія, анурія, поліурія** | зміни об'єму |
| **Гематурія** | кров у сечі |
| **Протеїнурія** | білок у сечі |
| **Затримка сечі, нетримання (енурез)** | |
| **Ниркова колька** | гострий біль від камінця |
| **Уремія** | накопичення азотистих шлаків |
| **Азотемія** | ↑ сечовина, креатинін |

Деталі: [[Хвороби сечової системи]].

## 9. Мнемоніки

- Шлях сечі: **нирка → миска → сечовід → міхур → сечівник**.
- Нирка: **ШКФ 125 мл/хв, 180 л/добу, діурез 1–2 л**.
- **Нирки — заочеревинно T12–L3**; **ліва вище правої**.
- Ендокринна функція нирки: **ЕПО, ренін, кальцитріол**.
