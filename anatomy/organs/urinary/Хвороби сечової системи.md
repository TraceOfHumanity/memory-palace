# Хвороби сечової системи

Це зведення основних хвороб нирок і сечових шляхів. Для кожної дано суть, ключові ознаки, діагностику й принципи лікування. Анатомію та фізіологію шукай у файлах про окремі органи.

## 1. Симптоми й синдроми

| Ознака | Значення |
|---|---|
| **Дизурія** | болісне, утруднене сечовипускання (цистит, уретрит) |
| **Полакіурія** | часті сечовипускання малими порціями |
| **Ніктурія** | нічне сечовипускання (> 1 раз) — ДГПЗ, серцева недостатність, діабет, ХХН |
| **Поліурія** | > 2,5–3 л/добу (діабет, нецукровий діабет, ХХН) |
| **Олігурія** | < 400–500 мл/добу (ГПН, зневоднення) |
| **Анурія** | < 100 мл/добу (повна обструкція, ГПН) |
| **Гематурія** | **макро-** (видима, «м'ясні помиї») / **мікро-** (ер. > 3 у п/з); **безболісна** — **рак**!; **з болем** — камінь; **деформовані еритроцити + циліндри** — **клубочкова** (гломерулонефрит) |
| **Протеїнурія** | > 150 мг/добу; **> 3,5 г/добу — нефротичний** |
| **Піурія** | лейкоцити > 10 у п/з (інфекція) |
| **Ниркова колька** | гострий переймоподібний біль від камінця |
| **Набряки** | обличчя вранці (нирковий), ноги ввечері (серцевий) |
| **Гіпертензія** | ниркова |
| **Уремія** | нудота, свербіж, перикардит, енцефалопатія |

### Синдроми
| Синдром | Ознаки |
|---|---|
| **Нефритичний** | **гематурія** (еритроцитарні циліндри), **протеїнурія (помірна)**, **набряки, гіпертензія, олігурія, ↑ креатинін**; **гострий постстрептококовий** |
| **Нефротичний** | **протеїнурія > 3,5 г/добу**, **гіпоальбумінемія (< 30 г/л)**, **набряки (масивні)**, **гіперліпідемія**, ліпідурія; ризик тромбозів, інфекцій |

## 2. Захворювання клубочків (гломерулопатії)

| Хвороба | Суть | Ключове |
|---|---|---|
| **Гострий постстрептококовий гломерулонефрит** | **імунні комплекси** після **стрептококової** ангіни/шкіри (**через 1–3 тижні**); діти | **нефритичний синдром**, «колір кока-коли», **↓ C3**, АСЛО ↑; зазвичай **одужання** |
| **ІгА-нефропатія (Берже)** | **найчастіший** гломерулонефрит у світі | **макрогематурія** під час або **одразу після ГРВІ** (1–3 дні); хронічна |
| **Швидкопрогресуючий (напівмісяцевий)** | **Гудпасчера** (анти-БМК антитіла: легені + нирки), **васкуліти** (АНЦА) | швидка втрата ШКФ; **напівмісяці** в капсулі |
| **Мінімальні зміни** | **нефротичний синдром у дітей**; злиття ніжок подоцитів | **стероїди** добре діють |
| **Фокально-сегментарний гломерулосклероз (ФСГС)** | нефротичний у дорослих; ВІЛ, ожиріння | |
| **Мембранозна нефропатія** | **нефротичний синдром** у дорослих; **PLA2R**, рак, лікарські | потовщення БМК |
| **Діабетична нефропатія** | **найчастіша причина ХХН/діалізу**; **гломерулосклероз Кіммельстіля — Вільсона** | **мікроальбумінурія → протеїнурія → ХХН** |
| **Вовчаковий нефрит** | СЧВ; імунні комплекси | |
| **Амілоїдоз** | нефротичний | |
| **Синдром Альпорта** | **колаген IV**; гематурія + **глухота + очі** | |
| **Мембранопроліферативний** | | |

**Діагноз**: аналіз сечі, **протеїнурія, ШКФ**, серологія (ANA, C3, АНЦА, анти-БМК), **біопсія нирки**.

## 4. Інфекції сечових шляхів (ІСШ)

| Тип | Суть | Ознаки |
|---|---|---|
| **Безсимптомна бактеріурія** | бактерії без симптомів | лікувати лише **вагітних** |
| **Цистит** (нижні шляхи) | **E. coli** (80%), *Staphylococcus saprophyticus*, Klebsiella; **жінки** (короткий сечівник, 50% хоча б раз) | **дизурія, часті позиви, надлобковий біль**, мутна сеча; **без лихоманки** |
| **Гострий пієлонефрит** (верхні) | висхідна інфекція; **вагітні, ВМР, камені, діабет** | **лихоманка, озноб, біль у попереку, нудота**, **симптом Пастернацького**, піурія; **бактеріємія/сепсис** |
| **Уретрит** | гонорея, хламідіоз | |
| **Простатит** | гострий (лихоманка, біль), хронічний | |
| **Ускладнений ІСШ** | чоловіки, камені, катетери, ВМР, діабет | |

- **Діагноз**: **загальний аналіз сечі** (лейкоцити, нітрити, бактерії), **посів з антибіограмою**, УЗД.
- **Лікування**: **цистит** — нітрофурантоїн, фосфоміцин (3–5 днів); **пієлонефрит** — фторхінолони/цефалоспорини (7–14 днів); обструктивний — **дренування** (невідкладно).
- **Рецидивуючий** (≥ 3/рік): профілактика, ВМР, камені.

## 5. Сечокам'яна хвороба (уролітіаз)

| Тип каменів | Частка | Особливості |
|---|---|---|
| **Кальцій-оксалатні** | **75–80%** | гіперкальціурія, гіпероксалурія; рентген-позитивні |
| **Фосфатні (кальцій-фосфатні)** | | лужна сеча |
| **Сечова кислота (урати)** | 5–10% | **кисла сеча**, подагра; **рентген-негативні**; розчинні (**лужна терапія**) |
| **Струвіт (магній-амоній-фосфат)** | 10% | **інфекція (Proteus)**, **коралові камені**; лужна сеча; рентген-позитивні |
| **Цистинові** | 1% | спадкова цистинурія; шестикутні кристали |

- **Ризик**: мала кількість води, подагра, гіперпаратиреоз, інфекції, дієта (оксалати, білок).
- **Ниркова колька**: **різкий біль у попереку → пахвина, статеві органи, нудота**, гематурія; **не знаходить позиції**; **КТ без контрасту** (золотий стандарт); УЗД; аналіз сечі.
- **Лікування**: **НПЗП** (діклофенак), **α₁-блокатори** (тамсулозин) для виходу; **< 5 мм — самостійно (~80%)**; **> 10 мм, обструкція, інфекція, колька** — **ударно-хвильова літотрипсія (ЕУХЛ)**, **уретероскопія**, **черезшкірна нефролітотомія**; **профілактика**: **> 2,5 л води/добу**, обмеження солі, тіазиди (кальцій), цитрат.
- **Невідкладно**: **камінь + інфекція (піонефроз)** — **дренування** (стент/нефростома).

## 6. Обструктивна уропатія

| Причина | Приклади |
|---|---|
| **Внутрішня** | камені, згустки, стриктури, пухлини |
| **Зовнішня** | **ДГПЗ**, рак простати/шийки матки, **вагітна матка**, **ретроперитонеальний фіброз**, пухлини таза |
| **Функціональна** | **нейрогенний міхур**, ВУР |

- **Гідронефроз** — розширення чашково-мискової системи; **УЗД**; **при односторонній — компенсація**; **двобічна → ХХН/ГПН**.
- **Піонефроз** — гнійне перетворення при обструкції + інфекція: **невідкладно**.
- **Післяобструктивний діурез** — після зняття (потрібен контроль рідини/електролітів).

## 7. Гостре ураження нирок (ГУН, гостра ниркова недостатність)

**Раптове (годин–діб) ↓ ШКФ**: **креатинін ↑ ≥ 0,3 мг/дл за 48 год** або **олігурія**.

| Тип | Причина | Ознаки |
|---|---|---|
| **Преренальна (~50–60%)** | **↓ перфузія**: **гіповолемія** (кровотеча, діарея), **шок**, **серцева недостатність**, **НПЗП/ІАПФ** | **↑ сечовина/креатинін (> 20:1)**, **концентрована сеча**, **Na⁺ сечі < 20**; **оборотна** при корекції |
| **Ниркова (внутрішня, ~35%)** | **гострий тубулярний некроз** (ішемія, токсини), **гломерулонефрит**, інтерстиційний нефрит | **коричневі «зернисті» циліндри**, **Na⁺ сечі > 40**, **ізостенурія** |
| **Постренальна (~5%)** | **обструкція** (ДГПЗ, камені, пухлини) | **анурія/олігурія**, гідронефроз на УЗД |

### Перебіг ГПН
1. **Олігоанурична** (7–14 днів): **уремія, гіперкаліємія, ацидоз, перевантаження рідиною**.
2. **Поліурична (відновлення)**: тубули ще не концентрують → **втрата рідини/електролітів**.
3. **Одужання** (місяці).

### Невідкладні показання до діалізу («AEIOU»)
**A**cidosis (тяжкий ацидоз), **E**lectrolytes (**гіперкаліємія**), **I**ntoxication (отруєння), **O**verload (набряк легень), **U**remia (перикардит, енцефалопатія).

**Гіперкаліємія** — **небезпечна для серця**: [[Нирка — регуляція гомеостазу]], [[Серце — ЕКГ]]: **кальцій глюконат**, інсулін + глюкоза, **сальбутамол**, діуретики, **діаліз**.

## 8. Хронічна хвороба нирок (ХХН)

**ШКФ < 60 мл/хв ≥ 3 місяці** або **ураження нирок** (альбумінурія).

### Стадії (КДІГО, GFR)
| Стадія | ШКФ, мл/хв/1,73 м² | Опис |
|---|---|---|
| **G1** | **≥ 90** | норма з ураженням |
| **G2** | 60–89 | легке |
| **G3a / G3b** | 45–59 / 30–44 | помірне |
| **G4** | 15–29 | тяжке |
| **G5** | **< 15** | **термінальна ниркова недостатність (ТНН)** → **діаліз/трансплантація** |

### Причини
**Діабет (~40%)**, **гіпертензія (~25%)**, **гломерулонефрити**, **полікістоз**, **обструктивна уропатія**, пієлонефрит, ліки.

### Наслідки (уремічний синдром)
| Система | Прояви |
|---|---|
| **Азотемія, уремія** | ↑ сечовина, креатинін; нудота, анорексія, **свербіж**, «запах сечі», **уремічна «пудра»**, **перикардит** (шум тертя), **тромбоцитопатія** (кровоточивість), **периферична нейропатія**, енцефалопатія |
| **Об'єм** | набряки, гіпертензія, **набряк легень** |
| **Електроліти** | **гіперкаліємія**, **гіперфосфатемія**, **гіпокальціємія** |
| **Ацидоз** | метаболічний |
| **Анемія** | ↓ **еритропоетин** |
| **Кістки** | **ниркова остеодистрофія** (↓ кальцитріол, **вторинний гіперпаратиреоз**) |
| **Серцево-судинні** | **головна причина смерті** (прискорений атеросклероз) |

### Лікування
- **Контроль**: **АТ (ІАПФ/сартани)**, **глюкози**, **ліпідів**, **SGLT2-інгібітори** (нефро- і кардіопротекція), **обмеження білка/солі**, уникати **НПЗП, контрасту**.
- **Корекція**: **ЕПО + залізо** (анемія), **кальцитріол, фосфат-зв'язувачі** (остеодистрофія), **бікарбонат** (ацидоз).
- **Замісна терапія (ЗНТ)**: **гемодіаліз** (3×/тиж, судинний доступ — **АВ-фістула**), **перитонеальний діаліз**, **трансплантація нирки** (найкраща: кращі виживаність і якість життя).

## 9. Діаліз і трансплантація

## 13. Мнемоніки

- Нефритичний: **гематурія + гіпертензія + набряки + олігурія**; нефротичний: **протеїнурія > 3,5 г + набряки + ↓ альбумін + ліпіди**.
- **Гематурія без болю** → **рак**; **з болем** → **камінь**.
- ГПН: **пре-, ренальна, пост-**; діаліз: **AEIOU** (acidosis, electrolytes, intoxication, overload, uremia).
- ХХН: **ШКФ < 60 більше 3 місяців**; **діабет + гіпертензія** — найчастіші причини.
- Камені: **оксалат Ca (80%), струвіт — інфекція, урат — кислий pH, цистин — спадковий**.
- Нирка виробляє **ЕПО, ренін, кальцитріол** → при ХХН: **анемія, гіпертензія, остеодистрофія**.
