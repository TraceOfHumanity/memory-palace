# Шкіра — огляд (*cutis*, *systema integumentarium*)

Шкіра — найбільший орган тіла. Вона покриває всю поверхню, межує із зовнішнім середовищем і захищає організм. Покривна система складається зі **шкіри** та її **придатків**: волосся, нігтів і залоз.

Пов'язані файли: [[Шкіра — епідерміс]], [[Шкіра — дерма і гіподерма]], [[Шкіра — захист, терморегуляція і загоєння]], [[Волосся і нігті]], [[Шкірні залози]], [[Хвороби шкіри]], [[Шкірна чутливість і біль]], [[Органи чуття — огляд]], [[Вегетативна нервова система]], [[Мікроциркуляція і лімфатична система]], [[Паращитоподібні залози і кальцієвий обмін]], [[Ендокринна система — огляд]], [[Анатомічна термінологія]].

## 1. Загальні відомості

| Показник | Значення |
|---|---|
| **Площа** | **1,5–2 м²** (дорослий) |
| **Маса** | **~4–5 кг** (~16% маси тіла) — **найбільший орган** |
| **Товщина** | **0,5 мм (повіки) – 4–5 мм (спина, долоні, підошви)**; в середньому **1–2 мм** |
| **Кровотік** | **5% серцевого викиду** (до 60% при спеці) |
| **Оновлення епідермісу** | **~28–40 діб** |

## 2. Функції

| Функція | Зміст |
|---|---|
| **Бар'єрна (захисна)** | **механічна, хімічна, мікробна, УФ, водна** (від зневоднення) |
| **Терморегуляція** | **судини, піт, волосся** |
| **Чутлива** | **дотик, тиск, біль, температура**: [[Шкірна чутливість і біль]] |
| **Імунна** | **клітини Лангерганса, Т-клітини**; **бар'єр** |
| **Синтез вітаміну D** | **УФ-B → 7-дегідрохолестерин → D₃**: [[Паращитоподібні залози і кальцієвий обмін]] |
| **Виділення** | **піт (вода, сіль, сечовина, лактат)** |
| **Депонування** | **кров (~5–10%), вода, жир** |
| **Всмоктування** | **ліки (пластирі), жиророзчинні речовини** |
| **Комунікація** | **вираз обличчя, колір, запах, дотик** |
| **Відновлення** | **регенерація при пошкодженнях** |

## 3. Три шари

| Шар | Латинська назва | Тканина | Основна роль |
|---|---|---|---|
| **Епідерміс** | *epidermis* | **багатошаровий плоский ороговілий епітелій** | **бар'єр, пігмент** |
| **Дерма** | *dermis, corium* | **щільна неоформлена сполучна тканина** | **міцність, судини, нерви** |
| **Гіподерма (підшкірна клітковина)** | *hypodermis, tela subcutanea* | **жирова + пухка сполучна тканина** | **ізоляція, запас енергії, амортизація** |

Деталі: [[Шкіра — епідерміс]], [[Шкіра — дерма і гіподерма]].

## 4. Типи шкіри

| Тип | Де | Особливості |
|---|---|---|
| **Тонка (волосиста)** | **більша частина тіла** | **епідерміс 0,07–0,12 мм**, **волосся, сальні залози**; **4–5 шарів епідермісу** |
| **Товста (безволоса)** | **долоні, підошви** | **епідерміс 0,4–1,6 мм**, **5 шарів**, **товстий роговий**, **без волосся і сальних залоз**, **багато потових залоз**; **папілярні лінії (відбитки пальців)** |

### Папілярні лінії (дерматогліфіка)
**Відбитки пальців** — **індивідуальні** (**не змінюються протягом життя**; формуються на 10–16 тижні плода). **Покращують захоплення**, збільшують чутливість. **Дерматогліфіка** — **ідентифікація, генетика (синдром Дауна — особливості)**.

## 5. Колір шкіри

Залежить від чотирьох чинників:
| Чинник | Внесок |
|---|---|
| **Меланін** | **коричневий/чорний (еумеланін), червонувато-жовтий (феомеланін)**; **головний** |
| **Каротин** | жовтий (товстий роговий шар) |
| **Гемоглобін (судини дерми)** | **рожевий/червоний** |
| **Товщина, прозорість** | |

Клінічні відтінки: **блідість** (анемія, шок, спазм), **ціаноз** (гіпоксемія), **жовтяниця** (білірубін), **гіперемія** (запалення), **«бронзова» (Аддісон)**, **вишнево-червона (отруєння CO)**. Деталі: [[Шкіра — епідерміс]].

## 6. Топографія і складки

- **Лінії Лангера (розтягу)**: **напрямок колагенових волокон; розрізи вздовж них гояться краще, з меншим рубцем**.
- **Складки і борозни**: **згинальні (суглоби)**, **мімічні зморшки (лінії обличчя)**, **папілярні**.
- **Пігментація**: **ареоли, мошонка, статеві губи — темніше**.

## 7. Кровопостачання шкіри (коротко)

**Артеріальні сплетення** (**глибоке і поверхневе (підсосочкове)**), **капілярні петлі в сосочках**, **венозні сплетення (більше — резервуар)**, **артеріо-венозні анастомози (шкіра пальців, вух; терморегуляція)**. Деталі: [[Шкіра — дерма і гіподерма]], [[Мікроциркуляція і лімфатична система]].

## 8. Розвиток

| Структура | Походження |
|---|---|
| **Епідерміс і його придатки (волосся, нігті, залози)** | **поверхнева ектодерма** |
| **Дерма, гіподерма** | **мезодерма** (дерматом сомітів, бічна пластинка) |
| **Меланоцити** | **нервовий гребінь** |
| **Клітини Меркеля** | нервовий гребінь/ектодерма |
| **Клітини Лангерганса** | **кістковий мозок (моноцити)** |

- **Двошаровий (6 тиждень)**: **базальний + перидерма** → **багатошаровий (11–12 тижнів)**; **роговий шар — 20–24 тиждень**.
- **Вроджені**: **ихтіоз, епідермоліз бульозний, альбінізм, родимки, гемангіоми**: [[Хвороби шкіри]].
- **Лануго** (пушок) → **вернікс казеозна (змазка)** у плода.

## 9. Вікові зміни

| Вік | Особливості |
|---|---|
| **Новонароджений** | **тонка, ніжна, вернікс**; **проникність↑**; **фізіологічна жовтяниця** |
| **Дитина** | **швидке загоєння** |
| **Пубертат** | **акне (сальні залози + андрогени)**, **апокринні залози (запах), оволосіння** |
| **Старіння** | **↓ колаген/еластин → зморшки; тонший епідерміс; ↓ сальні залози → сухість; ↓ меланоцити → сивина; ↑ ризик раку; повільніше загоєння** |
| **Фотостаріння** | **УФ: грубі зморшки, пігментація, солярний елластоз** |

## 10. Мнемоніки

- **Шари: епідерміс (бар'єр) → дерма (міцність) → гіподерма (жир).**
- **Шкіра: 15% маси, 2 м², 5% кровотоку.**
- **Колір: меланін + каротин + гемоглобін.**
- **Товста — долоні, підошви (без волосся); тонка — решта.**
- **Лінії Лангера — розрізати вздовж.**
