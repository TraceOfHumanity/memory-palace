# Волосся і нігті (*pili*, *ungues*)

Волосся й нігті — похідні епідермісу. Вони побудовані з **кератину** і мають захисну та чутливу функції. Волосся також бере участь у терморегуляції, а нігті захищають кінчики пальців і допомагають захоплювати предмети.

Пов'язані файли: [[Шкіра — огляд]], [[Шкіра — епідерміс]], [[Шкіра — дерма і гіподерма]], [[Шкірні залози]], [[Хвороби шкіри]], [[Сперматогенез і чоловічі гормони]], [[Менструальний цикл і жіночі гормони]], [[Щитоподібна залоза]], [[Гормони надниркових і їхні хвороби]], [[Вегетативна нервова система]], [[Шкірна чутливість і біль]].

## 1. Волосся (*pilus*, *capillus*)

### Загальні дані
| Показник | Значення |
|---|---|
| Кількість | **~5 млн волосин на тілі** (**~100 000 на голові**) |
| Де немає | **долоні, підошви, червона кайма губ, головка статевого члена, малі статеві губи** |
| **Ріст** | **~0,3–0,4 мм/добу (1 см/міс; ~15 см/рік)** |
| **Колір** | **меланін (еумеланін — чорне/коричневе; феомеланін — руде)**; **сивина — ↓ меланоцитів** |
| **Функції** | **захист (УФ, тертя), терморегуляція, чутливість (дотик), сигнальна** |

### Типи волосся
| Тип | Опис |
|---|---|
| **Лануго** | **пушок плода (20–24 тижні), скидається до народження** |
| **Веллюс (пушкове)** | **тонке, коротке, безпігментне; більшість тіла (діти, жінки)** |
| **Термінальне (довге)** | **товсте, довге, пігментоване: голова, вії, брови; в пубертаті — лобок, пахви; чоловіки — борода, груди** |

### Будова волосини
| Частина | Опис |
|---|---|
| **Стрижень (*scapus*)** | **над поверхнею** (мертві клітини, кератин) |
| **Корінь (*radix*)** | **у шкірі (дерма/гіподерма)** |
| **Цибулина (*bulbus*)** | **розширений кінець кореня**, **осередок росту (матриксні клітини)**, містить **сосочок (папілу)** |
| **Дермальний сосочок** | **судини → живлення**; **індукує ріст** |
| **Шари стрижня** | **кутикула (зовнішня, черепиця) → кора (cortex; кератин, меланін) → мозкова речовина (медулла; не завжди)** |

### Волосяний фолікул (*folliculus pili*)
| Складова | Опис |
|---|---|
| **Внутрішня і зовнішня епітеліальні піхви** | **з епідермісу** |
| **Сполучнотканинна піхва** | **з дерми** |
| **Цибулина** | **ріст** |
| **Сальна залоза** | **впадає у воронку фолікула**: **себум** |
| **М'яз, що піднімає волосся (*m. arrector pili*)** | **гладкий; симпатика; «гусяча шкіра»**, видавлює себум |
| **Зона випуклості (bulge)** | **стовбурові клітини фолікула** (регенерація епідермісу і волосся) |
| **Нервове сплетення** | **навколо фолікула (дотик до волосся)** |

**Піломоторний рефлекс** — **скорочення піднімача (холод, страх)**; у людини **рудиментарний**.

### Цикл росту
| Фаза | Тривалість | Опис |
|---|---|---|
| **Анаген (ріст)** | **2–6 років (голова)**; **~85–90% волосся** | **активний ріст**; **довжина залежить від тривалості** |
| **Катаген (регрес)** | **2–3 тижні** | **припинення, скорочення фолікула** |
| **Телоген (спокій)** | **2–4 місяці** | **волосина випадає**; **~10–15%** |
| **Екзоген** | | **випадіння** |

**Норма випадіння: 50–100 волосин/добу**.

### Гормональна регуляція
| Гормон | Дія |
|---|---|
| **Андрогени (тестостерон, ДГТ)** | **термінальне волосся в пубертаті (лобок, пахви, обличчя, груди)**; **андрогенна алопеція (ДГТ → мініатюризація фолікулів на тімені/скронях)** |
| **Естрогени** | **подовжують анаген (вагітність — густіше; після пологів — «телогеновий ефект»)** |
| **Щитоподібна (T₃, T₄)** | **нормальний ріст**; **гіпотиреоз — випадіння, ламке**: [[Щитоподібна залоза]] |
| **Кортизол, ІФР-1** | |

### Іннервація і кровопостачання
**Судини з дерми (сосочок)**; **нерви**: **чутливі (дотик до волосся)**, **симпатичні (піднімач)**: [[Вегетативна нервова система]].

### Клінічні поняття
| Стан | Суть |
|---|---|
| **Андрогенна алопеція** | **найчастіша**; **чоловіки (залисини, «М»-подібно), жінки (дифузне зниження на тімені)**; **міноксидил, фінастерид (чоловікам)** |
| **Телогенова алопеція** | **дифузне випадіння через 2–3 місяці після стресу, хвороби, пологів, дієти, ліків** (**оборотна**) |
| **Гніздова алопеція** | **аутоімунна; круглі ділянки** |
| **Рубцева (цикатрична)** | **знищення фолікулів (запалення, опіки)** |
| **Трихотиломанія** | **вириває волосся** |
| **Гірсутизм** | **надмірне волосся за чоловічим типом у жінок**: **СПКЯ, ВГНЗ, пухлини, ліки**: [[Хвороби статевої системи]] |
| **Гіпертрихоз** | **надмірне волосся (будь-де)** |
| **Передчасна сивина** | **спадкова, дефіцит B₁₂, аутоімунні** |
| **Педикульоз (воші), короста** | паразити |
| **Мікози (стригучий лишай)** | **гриби** |
| **Дефіцити (залізо, цинк, біотин, білок)** | **випадіння** |

## 2. Нігті (*unguis*, *onyx*)

### Будова
| Частина | Опис |
|---|---|
| **Нігтьова пластинка (*lamina*)** | **твердий, прозорий кератин (3 шари, тверді α-кератини)**; **рожевий колір — судини ложа** |
| **Корінь (*radix*)** | **під нігтьовою складкою — матриця** |
| **Тіло** | **видима частина** |
| **Вільний край** | |
| **Матриця (*matrix*)** | **осередок росту; стовбурові клітини; ураження → деформація, відсутність нігтя** |
| **Лунка (*lunula*)** | **білий півмісяць — видима частина матриці** |
| **Ложе (*hyponychium*)** | **під пластинкою; судини, нерви** |
| **Нігтьові валики (*paronychium*)** | **навколо** |
| **Епонихій (кутикула)** | **захищає від інфекції** |
| **Гіпоніхій** | **під вільним краєм** |

### Ріст
- **Нігті рук: ~3 мм/місяць (0,1 мм/добу); повна заміна ~4–6 місяців**.
- **Нігті ніг: ~1 мм/місяць; повна заміна ~12–18 місяців**.
- **Швидше**: **літо, молодь, домінантна рука, середній палець**; **повільніше — старіння, хвороби**.

### Функції
**Захист кінчиків пальців, скребіння, дрібні рухи, поліпшення тактильної чутливості (протиопора), вираз естетики**.

### Хвороби і ознаки нігтів
| Знахідка | Можливі причини |
|---|---|
| **Онихомікоз** | **грибкова інфекція (дерматофіти): товсті, жовті, ламкі** (**найчастіша хвороба нігтів**) |
| **Паронихія** | **запалення валика (бактерії, Candida)** |
| **Вростання нігтя** | **великий палець ноги; запалення** |
| **Ямки на нігтях (пітинг)** | **псоріаз, гніздова алопеція** |
| **Ложкоподібні нігті (койлонихія)** | **дефіцит заліза** |
| **«Барабанні палички» + вигнуті нігті** | **гіпоксія: рак легені, бронхоектази, вроджені вади серця, цироз**: [[Хвороби дихальної системи]] |
| **Лінії Бо (поперечні борозни)** | **тяжка хвороба, стрес, хіміотерапія** |
| **Лінії Мюрке (білі смуги)** | **гіпоальбумінемія (цироз, нефроз)** |
| **Білі нігті (Терріс)** | **цироз, ХСН, діабет** |
| **Крововиливи «скалки»** | **ендокардит (+ вузли Ослера), травма** |
| **Синюшні** | **ціаноз** |
| **Жовті нігті** | **грибок, синдром жовтих нігтів (лімфедема, легені)** |
| **Меланонихія (смуга)** | **доброякісна (темношкірі) або меланома нігтя (одна, поширюється) — біопсія** |
| **Блідість (анемія)** | |
| **Розшарування, ламкість** | **вода, хімікати, дефіцити** |

## 3. Розвиток

- **Волосяні фолікули**: **ектодерма (епідерм. зачатки на 9–12 тижні) індукуються дермою**; **волосся з'являється 18–20 тижня (лануго)**.
- **Нігті**: **10 тиждень** (нігтьове поле), **завершення ~32 тиждень**.
- **Вади**: **гіпотрихоз, атрихія, синдроми (ектодермальна дисплазія)**.

## 4. Мнемоніки

- **Волосина: стрижень + корінь + цибулина (ріст); фолікул — сальна залоза + піднімач.**
- **Цикл: анаген (ріст, роки) → катаген (2 тижні) → телоген (спокій, 3 місяці).**
- **Норма: 50–100 волосин/добу.**
- **Андрогени — тіло; ДГТ — облисіння.**
- **Нігті: матриця — ріст; лунка — її видима частина; руки 3 мм/міс.**
- **Койлонихія — залізо; «барабанні палички» — гіпоксія.**
