# Шкірні залози (*glandulae cutis*)

У шкірі є три групи залоз: **потові** (еккринні й апокринні), **сальні** та видозмінені (молочна, вушна сірка, мейбомієві). Потові залози регулюють температуру, сальні змащують шкіру й волосся.

Пов'язані файли: [[Шкіра — огляд]], [[Шкіра — епідерміс]], [[Шкіра — дерма і гіподерма]], [[Шкіра — захист, терморегуляція і загоєння]], [[Волосся і нігті]], [[Хвороби шкіри]], [[Молочна залоза]], [[Вухо — зовнішнє і середнє]], [[Око — допоміжний апарат і орбіта]], [[Вегетативна нервова система]], [[Статева система — огляд]], [[Нирка — регуляція гомеостазу]].

## 1. Потові залози (*glandulae sudoriferae*)

### Еккринні (мерокринні) потові залози
| Показник | Значення |
|---|---|
| **Кількість** | **2–4 млн** на тілі |
| **Розподіл** | **вся шкіра**; **найбільше: долоні, підошви (~600/см²), чоло, пахви** |
| **Будова** | **проста трубчаста**: **секреторна частина — клубок у глибокій дермі/гіподермі**; **вивідна протока — спіральна → пора на поверхні епідермісу** |
| **Секреторні клітини** | **світлі (піт)**, **темні (слиз)**, **міоепітеліальні (виштовхують)** |
| **Секрет** | **піт: 99% вода, Na⁺, Cl⁻ (гіпотонічний — протока реабсорбує), K⁺, сечовина, лактат, IgA, дермцидин** |
| **Іннервація** | **симпатична, але **холінергічна (ацетилхолін, мускаринові)** — **виняток**: [[Вегетативна нервова система]] |
| **Функція** | **терморегуляція (випаровування)**, **виділення**, **захист (кисла мантія, дермцидин)** |

**Типи потовиділення**:
| Тип | Тригер | Де |
|---|---|---|
| **Терморегуляторне** | **спека, фізичне навантаження** | **все тіло (крім долонь і підошов)** |
| **Емоційне** | **страх, тривога, біль** | **долоні, підошви, пахви, чоло** |
| **Смакове** | **гостра їжа** | **обличчя, чоло** |

**Склад поту**: **Na⁺ 20–80 ммоль/л (≪ плазми); при акліматизації ↓**. **Муковісцидоз — Cl⁻ > 60 ммоль/л (потова проба — діагностика)**: [[Нирка — регуляція гомеостазу]].
**Об'єм**: **до 1–2 л/год**.

### Апокринні потові залози
| Показник | Значення |
|---|---|
| **Розподіл** | **пахви, навколо сосків, промежина, статеві органи, зовнішній слуховий прохід (залози церумена)** |
| **Початок** | **пубертат** (під впливом андрогенів) |
| **Будова** | **більші, глибші; відкриваються у воронку волосяного фолікула** |
| **Секрет** | **густий, білуватий, багатий білками і ліпідами; без запаху — запах від бактерій** |
| **Іннервація** | **адренергічна (норадреналін, адреналін)** — **емоції, статеві** |
| **Функція** | **феромони (у людини — спірно), запах** |

**Модифіковані**: **цераменні (вушна сірка)**, **молочні залози (апокринні)**, **залози Молля (повіки)**: [[Молочна залоза]], [[Вухо — зовнішнє і середнє]].

### Хвороби потових залоз
| Хвороба | Суть |
|---|---|
| **Гіпергідроз** | **надмірна пітливість**: **первинний (долоні, підошви, пахви; без причини; лікування: антиперспіранти, іонофорез, ботулотоксин, симпатектомія)**, **вторинний (гіпертиреоз, інфекції, ліки, менопауза, діабет, феохромоцитома, лімфома)** |
| **Ангідроз/гіпогідроз** | **відсутність поту: ризик теплового удару (ектодермальна дисплазія, нейропатія, Горнер, ліки (антихолінергічні))** |
| **Бромгідроз** | **неприємний запах** |
| **Потниця (міліарія)** | **закупорка проток (спека, вологість)** |
| **Гідраденіт гнійний (інверсна акне)** | **хронічне запалення апокринних залоз (пахви, пах)**; **болісні вузли, нориці, рубці** |
| **Нічна пітливість** | **туберкульоз, лімфома, ВІЛ, ендокардит, менопауза, гіпертиреоз** |
| **Гіперпітливість при гіпоглікемії** | [[Інсулін, глюкагон і цукровий діабет]] |

## 2. Сальні залози (*glandulae sebaceae*)

| Показник | Значення |
|---|---|
| **Розподіл** | **вся шкіра, крім долонь і підошов**; **найбільше: обличчя, шкіра голови, груди, спина** |
| **Будова** | **альвеолярні (кінцеві відділи — часточки)**; **голокринні (клітини руйнуються разом з секретом)**; **протока відкривається у воронку волосяного фолікула** (**самостійно — повіки, губи, статеві органи, ареола**) |
| **Секрет** | **себум**: **тригліцериди, воскові ефіри, сквален, вільні жирні кислоти, холестерин** |
| **Регуляція** | **андрогени (↑ розмір і секрецію)**; **естрогени ↓**; **не нервова** |
| **Функція** | **змащення шкіри й волосся, захист (водовідштовхувальний, антимікробний — жирні кислоти)**, **кисла мантія** |

- **Розвиток**: **вернікс (змазка плода)**; **активні в пубертаті**; **↓ з віком, менопаузою**.
- **Бактерія *Cutibacterium acnes*** — **живе в сальних залозах, розщеплює себум → запалення (акне)**.

### Хвороби сальних залоз
| Хвороба | Суть |
|---|---|
| **Акне (вугрі)** | **найчастіша шкірна хвороба підлітків**: **↑ себум (андрогени) + гіперкератоз фолікула + C. acnes + запалення**; **комедони (відкриті — чорні; закриті — білі), папули, пустули, вузли, кісти, рубці**; **лікування: ретиноїди (топічні, ізотретиноїн), бензоїл пероксид, антибіотики, гормональна (КОК, спіронолактон)**; **ізотретиноїн — тератогенний** |
| **Себорейний дерматит** | **шкіра голови (лупа), брови, носогубні складки; дріжджі Malassezia; жовті жирні лусочки** |
| **Кіста (атерома, епідермальна)** | **закупорка протоки** |
| **Себорейна гіперплазія** | **доброякісні жовті папули у старших** |
| **Ксероз (суха шкіра)** | **↓ себум, ліпіди** |
| **Карцинома сальної залози** | рідкісна; пов'язана із синдромом Мюїра — Торре |

## 4. Розвиток
**Ектодерма (епідермальні зачатки) → вростають у дерму**: **потові (з 10 тижня), сальні (з 15-го тижня — з фолікулів), апокринні (в пубертаті)**; **молочні — молочні лінії**.

## 5. Регуляція
| Залоза | Нервова | Гормональна |
|---|---|---|
| **Еккринна** | **симпатика (холінергічна)** | — (альдостерон ↓ Na⁺ в поті) |
| **Апокринна** | **симпатика (адренергічна)** | **андрогени (пубертат)** |
| **Сальна** | немає | **андрогени ↑, естрогени ↓** |

## 6. Мнемоніки
- **Еккринні — все тіло, піт (терморегуляція), холінергічна симпатика.**
- **Апокринні — пахви, промежина; запах від бактерій; з пубертату.**
- **Сальні — з волосяним фолікулом; андрогени; акне.**
- **Голокринна секреція — клітина руйнується (сальні).**
- **Долоні, підошви: піт є, сальних залоз немає.**
