# Шкіра — захист, терморегуляція і загоєння

Шкіра виконує кілька життєво важливих функцій. Вона створює **бар'єр**, підтримує **температуру тіла** й відновлюється після ушкоджень. Тут описано, як вона це робить.

## 1. Захисна (бар'єрна) функція

| Тип захисту | Механізм |
|---|---|
| **Механічний** | **товщина, колаген, еластин, роговий шар, жир** — удари, тертя, тиск |
| **Хімічний** | **кисла мантія (pH 4,5–5,5)**, **ліпіди шкіри**, **себум**, **дефензини, кателіцидини (антимікробні пептиди)** |
| **Мікробний** | **мікробіом (колонізаційна резистентність)**, **цілісність епідермісу**, **імунітет** |
| **Імунний** | **клітини Лангерганса, Т-клітини, тучні клітини, макрофаги** |
| **Водний** | **церамід, корнеоцити** — **запобігає втраті води (трансепідермальна втрата води — TEWL)** і проникненню рідини |
| **Променевий (УФ)** | **меланін, роговий шар** |
| **Електричний** | **опір сухої шкіри ~10⁵ Ом (волога — в 100 разів нижче)** |

Деталі: [[Шкіра — епідерміс]].

## 2. Терморегуляція

### Температура тіла
| Показник | Значення |
|---|---|
| **Ядро (внутрішня)** | **~37 °C** (36,5–37,5) |
| **Поверхня шкіри** | **~32–34 °C** (змінна) |
| **Центр** | **гіпоталамус (передня преоптична ділянка — «термостат»)**: [[Проміжний мозок і базальні ядра]] |

### Тепловіддача
| Механізм | Частка | Опис |
|---|---|---|
| **Випромінювання (радіація)** | **~60%** | **інфрачервоне**; без контакту |
| **Випаровування (піт, дихання)** | **~22%** (при спеці — головний) | **1 г води = 0,58 ккал**; **піт** |
| **Конвекція** | ~12% | **рух повітря** |
| **Теплопровідність** | ~3% | **контакт** |

**У спеці (> 35 °C)** — **випаровування єдиний шлях** (**волога повітря обмежує**).

### Реакції на холод
| Реакція | Механізм |
|---|---|
| **Звуження судин шкіри (вазоконстрикція)** | **симпатика (α₁)** — **↓ втрата тепла, блідість, «гусяча шкіра»** |
| **Піломоторний рефлекс («гусяча шкіра»)** | **скорочення м'язів, що піднімають волосся** (у людини рудимент) |
| **Тремтіння (дрижання)** | **скелетні м'язи: ↑ теплопродукція в 4–5 разів** |
| **Нетремтячий термогенез** | **бурий жир (немовлята)**, **адреналін, T₃** |
| **Поведінка** | **одяг, рух, обігрів** |
| **Протитечійний теплообмін** | **артерія і вена кінцівок поряд** |

### Реакції на спеку
| Реакція | Механізм |
|---|---|
| **Розширення судин** | ↓ симпатика; **активна вазодилатація (потові залози — калікреїн, брадикінін)** — **↑ кровотік шкіри до 60% викиду** |
| **Потовиділення** | **холінергічна симпатика → еккринні залози: 1–2 л/год (до 3–4)**: [[Шкірні залози]] |
| **↓ метаболізму, ↓ тонусу** | |
| **Поведінка** | **тінь, вода, легкий одяг** |

### Лихоманка (гарячка)
**Пірогени (ІЛ-1, ІЛ-6, ФНП, ПГЕ₂) → ↑ «уставки» термостата** → **озноб, вазоконстрикція, тремтіння до нового рівня**; **зниження** (жарознижувальні) → **піт, розширення судин**. **Не плутати з гіпертермією** (перегрів без зміни уставки).

### Порушення
| Стан | Суть |
|---|---|
| **Тепловий удар** | **> 40 °C + порушення ЦНС, відмова потовиділення (класичний) — невідкладно: охолодження** |
| **Злоякісна гіпертермія** | **реакція на анестетики, генетична** |
| **Переохолодження (гіпотермія)** | **< 35 °C**: **тремтіння → сплутаність → брадикардія, аритмії; хвиля Осборна** |
| **Обмороження** | **ураження тканин при < 0 °C: блідість, оніміння, пухирі, некроз** |
| **Лихоманка** | |

Деталі: [[Мікроциркуляція і лімфатична система]], [[Серце — серцевий цикл і гемодинаміка]].

## 3. Вода і виділення

- **Неощутимі втрати води**: **~600 мл/добу** (шкіра, ~300–400) + **легені (~300–400)**.
- **Піт**: **0,5 л/добу (спокій) — до 10–12 л/добу (екстремально)**.
- **Склад поту**: **вода (99%), Na⁺, Cl⁻ (гіпотонічний), K⁺, лактат, сечовина, амінокислоти**.
- **Втрата солі → акліматизація знижує Na⁺**; **муковісцидоз — солоний піт (діагностика потової проби)**: [[Нирка — регуляція гомеостазу]].

## 5. Загоєння ран

### Фази
| Фаза | Час | Події |
|---|---|---|
| **1. Гемостаз** | **хвилини–години** | **спазм судин, тромбоцити, фібрин → тромб** |
| **2. Запалення** | **1–5 днів** | **нейтрофіли (0–2 дні), макрофаги (2–5 днів)** — очищення, цитокіни; **почервоніння, набряк, біль, жар** |
| **3. Проліферація (грануляція)** | **3–21 день** | **фібробласти → колаген III; ангіогенез; грануляційна тканина; епітелізація (з країв, фолікулів); скорочення рани (міофібробласти)** |
| **4. Ремоделювання (дозрівання рубця)** | **3 тижні – 1–2 роки** | **колаген III → I; зменшення судин; рубець — 70–80% міцності нормальної шкіри** |

### Типи загоєння
| Тип | Опис |
|---|---|
| **Первинним натягом** | **краї зближені (шви, клей, чиста рана)** — **швидко, мінімальний рубець** |
| **Вторинним натягом** | **рана відкрита (великий дефект)** — **грануляція, скорочення; повільно, більший рубець** |
| **Третинним (відстрочені шви)** | **забруднена рана → очищення → шов через 3–5 днів** |

### Чинники, що погіршують загоєння
| Група | Приклади |
|---|---|
| **Місцеві** | **інфекція, некроз, стороннє тіло, тиск (пролежні), ішемія, набряк, натяг** |
| **Загальні** | **діабет, судинні хвороби (артерії, вени), недоїдання (білок, цинк, вітамін C), стероїди, імуносупресія, паління, старіння, анемія, ожиріння, хіміо-/променева терапія** |
| **Дефіцити** | **вітамін C (колаген), A, цинк, білок** |

Деталі: [[Інсулін, глюкагон і цукровий діабет]], [[Хвороби судин]], [[Гормони надниркових і їхні хвороби]].

### Рубці
| Тип | Суть |
|---|---|
| **Нормальний (зрілий)** | **блідий, плоский** |
| **Гіпертрофічний** | **виступає, червоний, у межах рани; регресує** |
| **Келоїд** | **виходить за межі рани, не регресує; темношкірі; вуха, груди, плечі; лікування — стероїди, силікон, криотерапія** |
| **Атрофічний** | **акне, вітряна віспа** |
| **Контрактура** | **скорочення над суглобами (опіки)** |

### Регенерація
- **Епідерміс** — **повна**.
- **Дерма** — **рубець (без придатків: волосся, залози, лінії)**.
- **Стовбурові клітини**: **фолікули (bulge), базальний шар, сальні залози**.
- **Шкірна пластика**: **розщеплені (епідерміс + частина дерми) і повношарові трансплантати**; **штучна шкіра**.

## 6. Опіки

**Ураження тканин від високої температури, хімічних речовин, струму, радіації.**

### Глибина (ступені)
| Ступінь | Глибина | Ознаки | Загоєння |
|---|---|---|---|
| **I (поверхневий)** | **епідерміс** | **почервоніння, біль, сухість (як сонячний опік)** | **3–7 днів, без рубця** |
| **II-A (поверхневий частковий)** | **сосочковий шар дерми** | **пухирі, волога поверхня, червона, дуже болісна, «білішає при натисканні»** | **7–21 день, зазвичай без рубця** |
| **II-B (глибокий частковий)** | **сітчастий шар** | **біла/червона, суха, менш болісна** | **> 3 тижнів, рубець, пересадка** |
| **III (повношаровий)** | **вся дерма (+ гіподерма)** | суха, шкірястна, білувата, коричнева або чорна; **безболісна (знищені нерви)**; не білішає при натисканні | **пересадка** |
| **IV** | **м'язи, кістки** | обвуглення | ампутація/реконструкція |

### Площа (правило дев'яток, Уоллеса)
| Ділянка | % площі тіла |
|---|---|
| **Голова і шия** | **9%** |
| **Кожна верхня кінцівка** | **9%** |
| **Груди + живіт (передня)** | **18%** |
| **Спина (задня поверхня тулуба)** | **18%** |
| **Кожна нижня кінцівка** | **18%** |
| **Промежина** | **1%** |
| **Долоня (з пальцями) пацієнта** | **~1%** |

**Діти** — **голова більша (18%), ноги менші**.

### Опікова хвороба (> 15–20% площі)
**Опікова травма → системна запальна відповідь**: **↑ проникність капілярів → втрата плазми → гіповолемічний шок**; **інфекції, сепсис, гіперметаболізм**.
**Лікування**: **охолодження (10–20 хв прохолодною водою)**, **не лід; не масла**; **інфузія (формула Паркленда: 4 мл × маса (кг) × % ураження за 24 год; половина за перші 8 год)**, **знеболення, профілактика правця, догляд за раною (перев'язки, антибіотики місцево), харчування, пересадка**.

### Особливості
- **Електричні опіки**: **вхідний/вихідний отвір; ураження глибше (м'язи → рабдоміоліз → нирки; серце — аритмії)**.
- **Хімічні**: **промивання водою (30+ хв)**.
- **Опіки дихальних шляхів (інгаляційні)** — **невідкладно: інтубація**.

## 7. Пролежні

**Ішемічний некроз шкіри і тканин від тривалого тиску** (**кістки: крижі, п'ятки, вертлюги, лікті**). **Чинники**: **іммобілізація, вологість, тертя, дефіцит харчування**. **Стадії I–IV** (від еритеми до кістки). **Профілактика**: **зміна положення кожні 2 год, матраци, догляд за шкірою**.

## 8. Мнемоніки

- **Тепловіддача: випромінювання 60%, випаровування 22% (в спеку — головне), конвекція, провідність.**
- **Холод: вазоконстрикція, тремтіння, «гусяча шкіра»; спека: вазодилатація, піт.**
- **Загоєння: гемостаз → запалення (нейтрофіли → макрофаги) → проліферація (колаген III) → ремоделювання (I).**
- **Опіки: I епідерміс (біль); II дерма (пухирі, біль); III вся дерма (безболісний).**
- **Правило дев'яток: голова 9, рука 9, груди 18, спина 18, нога 18.**
