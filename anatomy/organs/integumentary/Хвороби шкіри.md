# Хвороби шкіри

Це зведення основних шкірних хвороб. Для кожної наведено суть, ознаки й принципи лікування. Анатомію шукай у файлах про шари шкіри та її придатки.

## 1. Первинні елементи висипу

| Елемент | Опис | Приклад |
|---|---|---|
| **Пляма (*macula*)** | **зміна кольору, < 1 см; не виступає** | **веснянка, вітиліго, ерітема** |
| **Пляма велика (*patch*)** | **> 1 см** | **вітиліго** |
| **Папула (*papula*)** | **щільний вузлик < 1 см** | **акне, бородавка, лишай** |
| **Бляшка (*plaque*)** | **> 1 см, плоска** | **псоріаз** |
| **Вузол (*nodus*)** | **глибокий щільний > 1 см** | **кіста, пухлина** |
| **Пухирець (*vesicula*)** | **< 1 см, рідина** | **герпес, вітряна віспа** |
| **Пухир (*bulla*)** | **> 1 см, рідина** | **пемфігус, опік** |
| **Пустула** | **гнійний пухирець** | **акне, фолікуліт** |
| **Волдир (*urtica*)** | **набряк дерми, минущий (години)** | **кропив'янка** |
| **Телеангіектазія** | **розширені судини** | **розацеа** |
| **Пурпура/петехії** | **крововиливи (не білішають)** | **тромбоцитопенія, васкуліти** |

### Вторинні елементи
**Лусочки (десквамація)**, **кірки**, **ерозії**, **виразки**, **тріщини**, **лихенізація (потовщення від чухання)**, **атрофія**, **рубці**, **екскоріації**.

## 3. Запальні (імунні) хвороби

### Атопічний дерматит (екзема)
**Хронічне рецидивуюче запалення; діти; генетика (філагрин) + бар'єр + імунітет (Th2)**; **свербіж, сухість, червоні лусочки (складки)**; **атопічний марш (астма, алергічний риніт)**.
**Лікування**: **зволожувачі (емоленти), топічні стероїди, інгібітори кальциневрину, дупілумаб (тяжкий), уникати тригерів**.

### Контактний дерматит
| Тип | Суть |
|---|---|
| **Подразливий** | **пряме ушкодження (миючі, кислоти)** |
| **Алергічний** | **IV тип (затримана алергія; нікель, косметика, ліки): свербіж, пухирці; патч-тести** |

### Псоріаз
**Хронічний аутоімунний; Т-клітини + кератиноцити; швидке оновлення (3–5 днів)**: **добре окреслені червоні бляшки зі сріблястими лусочками (розгиначі, шкіра голови)**; **симптом Ауспітца (кров'яна роса)**; **нігті (ямки, онихолізис)**; **артрит (псоріатичний)**; **лікування**: **стероїди, вітамін D (кальципотріол), УФ, метотрексат, біологічні (анти-ФНП, ІЛ-17)**.

### Кропив'янка і ангіоневротичний набряк
**Гістамін (тучні клітини): волдирі, свербіж, зникають за < 24 год**; **ангіоневротичний набряк — набряк глибоких тканин (повіки, губи, гортань — небезпека)**; **причини: ліки, їжа, інфекції, холод, аутоімунні**; **лікування: антигістамінні; анафілаксія — адреналін**.

## 4. Пухлини шкіри

### Доброякісні
**Невуси (родимки)**, **себорейний кератоз («прилиплі»)**, **ангіоми, ліпоми, дерматофіброма, келоїд, акрохордони (поліпи)**.

### Передрак
**Актинічний (сонячний) кератоз** — **ороговіла лусочка на сонячній шкірі (> 40 років); ризик → плоскоклітинна карцинома**.

### Злоякісні
| Рак | Частка | Суть |
|---|---|---|
| **Базальноклітинна карцинома (БКК)** | **~80%** | **найчастіша; повільна, не метастазує; «перламутрова папула з телеангіектазіями», виразка («гризуча»); обличчя; Мооса/висічення** |
| **Плоскоклітинна карцинома** | **~16%** | **кератиноцити; виразка, лусочка; може метастазувати; УФ, імуносупресія** |
| **Меланома** | **~4%, але найсмертельніша** | **меланоцити; метастазує рано (лімфа, кров: легені, печінка, мозок)** |
| **Карцинома Меркеля** | **рідкісна** | **агресивна** |
| **Саркома Капоші** | | **ВІЛ, HHV-8** |
| **Т-клітинна лімфома шкіри** | | |

### Меланома
**Фактори ризику**: **УФ (опіки в дитинстві), світла шкіра, багато невусів (> 50), атипові невуси, спадковість, вік, імуносупресія**.
**ABCDE-правило** (**ознаки тривоги**):
- **A**symmetry — **асиметрія**.
- **B**order — **нерівні краї**.
- **C**olor — **неоднорідний колір (кілька відтінків)**.
- **D**iameter — **> 6 мм**.
- **E**volving — **зміна (розмір, форма, колір, свербіж, кровоточивість)**.
**«Гидке каченя»** (ознака) — **родимка, що відрізняється від інших**.
**Діагноз**: **дерматоскопія → ексцизійна біопсія (повністю, з відступом)**; **прогноз — товщина за Бреслоу (мм) + виразка + вузли**.
**Лікування**: **широке висічення, біопсія сторожового вузла, імунотерапія (інгібітори PD-1), таргетна (BRAF)**.
**Профілактика**: **захист від сонця (SPF 30+, одяг, тінь), уникати солярію, самообстеження щомісяця, щорічний огляд**.

| Стан | Ознаки |

| **Некротизуючий фасціїт** | **біль, швидке поширення, шок — операція** |

## 10. Мнемоніки

- **Первинні елементи: пляма, папула, бляшка, вузол, пухирець, пухир, пустула, волдир.**
- **Рак шкіри: БКК 80% (не метастазує), плоскоклітинний 16%, меланома 4% (найнебезпечніша).**
- **Меланома: ABCDE (асиметрія, краї, колір, діаметр > 6 мм, еволюція).**
- **Псоріаз: срібні бляшки на розгиначах, нігті-ямки, Ауспітц.**
- **Пемфігус: в'ялі, десмоглеїн, Нікольський +; пемфігоїд: напружені, гемідесмосоми.**
- **Синдром Стівенса — Джонсона і ТЕН — ліки; невідкладно.**
