# Аномалії і варіанти розвитку скелета

**Варіант** (*variatio*) — відхилення від типової будови, яке не порушує функцію (наприклад, швові кістки, лобовий шов у дорослого). **Аномалія** (вада розвитку, *anomalia*) — відхилення, що порушує форму або функцію (розщеплення дуг хребців, вроджений вивих стегна). На іспиті ці поняття розрізняють.

## 1. Механізми виникнення

| Механізм | Що відбувається | Приклад |
|---|---|---|
| Недорозвинення (агенезія, аплазія, гіпоплазія) | кістка або її частина не закладається чи мала | відсутність ключиці при ключично-черепному дизостозі, аплазія променевої кістки |
| Незрощення частин | центри окостеніння не зливаються | розщеплення дуг хребців, біпартитний надколінок, *os acromiale* |
| Надмірне зрощення (синостоз, злиття) | кістки, що мали бути окремими, зростаються | сакралізація L5, блокові хребці, променево-ліктьовий синостоз |
| Надлишкові закладки | з'являються додаткові елементи | шийне ребро, полідактилія, швові кістки |
| Атавізм | зберігається ознака предків | надвиростковий відросток плечової кістки, третій вертлюг |
| Передчасне закриття ростових зон | порушується ріст | краніосиностоз |
| Генетичні дисплазії | дефект синтезу матриксу або регуляції росту | ахондроплазія, недосконалий остеогенез |
| Тератогени | зовнішній чинник у критичний період (3–8-й тиждень) | талідомід → фокомелія; дефіцит фолієвої кислоти → дефекти нервової трубки |

Кінцівки закладаються як **ниркоподібні вирости** наприкінці 4-го тижня (верхні на 1–2 дні раніше). Критичний період для вад кінцівок — 24–36-й день.

## 2. Череп

### Варіанти
| Варіант | Опис |
|---|---|
| **Швові кістки** (*ossa suturalia*, вормієві) | дрібні кістки у швах, найчастіше в ламбдоподібному; багато швових кісток — ознака недосконалого остеогенезу, гідроцефалії, ключично-черепного дизостозу |
| **Кістка Інків** (*os interparietale, os Incae*) | верхня частина луски потиличної кістки (над вищою карковою лінією) лишається окремою: не зрослися сполучнотканинна й хрящова частини |
| **Лобовий (метопічний) шов у дорослого** (*metopismus*) | 5–10 % людей; на рентгені не плутати з переломом |
| **Тім'яні отвори** | непостійні; іноді дуже великі (*foramina parietalia permagna*) |
| **Венозний отвір** (*foramen venosum*, Везалія) | непостійний отвір присередньо від овального |
| **Піднебінний валик** (*torus palatinus*) і **нижньощелепний валик** (*torus mandibularis*) | кісткові виступи на піднебінні й на внутрішній поверхні нижньої щелепи біля премолярів |
| **Шилоподібний відросток понад 3 см** | окостеніння шило-під'язикової зв'язки; синдром Ігла |
| **Відсутність лобової пазухи** | близько 5 % |
| **Розміри й асиметрія пазух** | дуже мінливі |

### Аномалії
| Аномалія | Суть | Наслідок |
|---|---|---|
| **Краніосиностоз** | передчасне зарощення шва | деформація черепа (скафоцефалія, брахіцефалія, тригоноцефалія, плагіоцефалія, оксицефалія); можливе підвищення внутрішньочерепного тиску |
| **Аненцефалія з акранією** | відсутність склепіння й великих півкуль (незакриття переднього нейропора) | несумісна з життям |
| **Черепно-мозкова грижа** (*encephalocele, meningocele*) | вип'ячування оболонок і мозку через дефект кістки, частіше в потиличній ділянці або в ділянці перенісся | |
| **Мікроцефалія, макроцефалія** | малий або великий череп; часто відображає розмір мозку | |
| **Розщілина губи** (*cheiloschisis*) | незрощення верхньощелепного й присереднього носового виростів (5–6-й тиждень) | |
| **Розщілина піднебіння** (*palatoschisis*) | незрощення піднебінних відростків між собою або з різцевою кісткою (7–12-й тиждень) | порушення смоктання, мовлення |
| **Платибазія** | сплощення основи черепа (кут між скатом і передньою черепною ямкою більший за норму) | |
| **Базилярна імпресія** | вдавлення країв великого отвору в порожнину черепа, зуб C2 піднімається вище лінії Чемберлена | стиснення стовбура мозку |
| **Ключично-черепний дизостоз** | порушення сполучнотканинного окостеніння (ген *RUNX2*) | відсутність або недорозвинення ключиць, пізнє закриття тім'ячок, багато швових кісток, аномалії зубів |
| **Синдроми першої глоткової дуги** (Тричера Коллінза, Робена) | недорозвинення нижньої щелепи, виличних кісток, слухових кісточок | мікрогнатія, глухота |

## 3. Хребет

| Аномалія або варіант | Суть | Клінічне значення |
|---|---|---|
| **Асиміляція атланта** (окципіталізація) | атлант зростається з потиличною кісткою | звуження великого отвору, неврологічні симптоми |
| **Проатлант** | залишки додаткового хребця між потиличною кісткою й атлантом | |
| **Кістковий місток над борозною хребтової артерії** (*ponticulus posticus*, *foramen arcuale*) | окостеніння задньої атланто-потиличної мембрани над борозною хребтової артерії на задній дузі атланта; 10–15 % | ризик ушкодження хребтової артерії під час встановлення гвинтів у бічні маси C1 |
| **Зубоподібна кістка** (*os odontoideum*) | зуб C2 не зростається з тілом | нестабільність атланто-осьового з'єднання |
| **Синдром Кліппеля–Фейля** | зрощення кількох шийних хребців (блокові хребці) | коротка шия, низька межа росту волосся, обмежені рухи |
| **Шийне ребро** | надмірний розвиток реберного елемента C7 (0,5–1 %) | стиснення нижнього стовбура плечового сплетення й підключичної артерії (синдром верхньої апертури грудної клітки) |
| **Поперекове ребро** | реберний елемент L1 | на рентгені не плутати з переломом поперечного відростка |
| **Напівхребець** (*hemivertebra*) | закладається лише одна половина тіла | вроджений сколіоз |
| **Метеликоподібний хребець** | незрощення двох половин тіла (сагітальна щілина) | |
| **Блоковий хребець** | зрощення тіл двох хребців | |
| **Сакралізація** | L5 повністю або частково зростається з крижовою кісткою (4 поперекових хребці) | біль у попереку, утруднення нумерації хребців |
| **Люмбалізація** | S1 відокремлюється й стає шостим поперековим | |
| **Перехідні хребці** | ознаки двох відділів (наприклад, C7 з ребром, T12 без ребер) | |
| **Розщеплення дуг хребців** (*spina bifida*) | незрощення половин дуги; найчастіше L5–S1 | див. нижче |
| **Спондилоліз** | дефект міжсуглобової частини (вроджена слабкість + стресовий перелом) | спондилолістез |
| **Зміна числа хребців** | 32–35 хребців: зміна кількості куприкових або додатковий хребець в одному відділі | |

### Форми розщеплення дуг (*spina bifida*)
| Форма | Що вип'ячується | Тяжкість |
|---|---|---|
| Прихована (*spina bifida occulta*) | нічого; над дефектом пучок волосся, ямка, пігментна пляма | найлегша, 10–20 % людей |
| Менінгоцеле | оболонки й ліквор | середня |
| Мієломенінгоцеле | оболонки, спинний мозок і корінці | тяжка; паралічі, порушення функції тазових органів, часто з мальформацією Кіарі II і гідроцефалією |
| Рахішизис (мієлошизис) | відкрита нервова пластинка | найтяжча |

Профілактика дефектів нервової трубки — фолієва кислота (400 мкг/добу) до зачаття й у перші 12 тижнів вагітності.

## 5. Верхня кінцівка

| Варіант або аномалія | Суть | Значення |
|---|---|---|
| **Хвороба Шпренгеля** | вроджене високе стояння лопатки (лопатка не опускається з шийного рівня); часто з *os omovertebrale* — кісткою між лопаткою й хребцями | обмеження відведення руки |
| **Акроміальна кістка** (*os acromiale*) | акроміон не зростається з остю (3–8 %) | імпіджмент-синдром, плутання з переломом |
| **Отвір лопатки** | окостеніння верхньої поперечної зв'язки перетворює вирізку лопатки на отвір | стиснення надлопаткового нерва |
| **Надвиростковий відросток** (*processus supracondylaris humeri*) | гачкоподібний виступ на присередній поверхні плечової кістки приблизно за 5 см над присереднім надвиростком (близько 1 %); від нього до надвиростка йде **зв'язка Стразерса** | атавізм; під зв'язкою може стискатися серединний нерв і плечова артерія |
| **Надблоковий отвір** (*foramen supratrochleare*) | отвір між вінцевою ямкою й ямкою ліктьового відростка (4–8 %) | |
| **Вроджений променево-ліктьовий синостоз** | зрощення проксимальних кінців кісток передпліччя | неможливі пронація й супінація |
| **Деформація Маделунга** | порушення росту присередньої частини дистальної ростової пластинки променевої кістки | виступає головка ліктьової кістки, кисть зміщена долонно |
| **Променева косорукість** | аплазія або гіпоплазія променевої кістки (часто з відсутністю великого пальця) | кисть відхилена в променевий бік |
| **Фокомелія** | кисть або стопа відходить прямо від тулуба (немає проксимальних сегментів) | класичний наслідок талідоміду |
| **Амелія** | відсутність кінцівки | |
| **Полідактилія** | додаткові пальці (частіше з боку мізинця — постаксіальна) | |
| **Синдактилія** | зрощення пальців (шкірне або кісткове) | |
| **Брахідактилія** | короткі фаланги або п'ясткові кістки | |
| **Клинодактилія** | викривлення пальця вбік (частіше мізинця) | |
| **Камптодактилія** | згинальна контрактура міжфалангового суглоба мізинця | |
| **Центральна кістка зап'ястка** (*os centrale*) | окремий центр між човноподібною, головчастою й трапецієподібною (у ембріона є завжди) | |
| **Двочасткова човноподібна кістка** | плутають із переломом | |
| **Шилоподібна кістка** (*os styloideum*) | окремий шилоподібний відросток III п'ясткової кістки | «карпальний горб» на тилі кисті |

## 6. Таз і нижня кінцівка

| Варіант або аномалія | Суть | Значення |
|---|---|---|
| **Дисплазія кульшового суглоба** (вроджений вивих стегна) | неглибока кульшова западина, вальгусна шийка з надмірною антеверсією; частіше в дівчат, при сідничному передлежанні | скринінг у новонароджених (проби Ортолані, Барлоу, УЗД); без лікування — кульгання, ранній коксартроз |
| **Coxa vara** | шийково-діафізарний кут менший за 120° | укорочення кінцівки, кульгання |
| **Coxa valga** | кут більший за 135° | схильність до підвивиху |
| **Третій вертлюг** (*trochanter tertius*) | виражена сіднична горбистість | атавізм |
| **Кульшова кістка** (*os acetabuli*) | окремий центр на краю кульшової западини | |
| **Двочастковий (біпартитний) надколінок** | незрощення верхньобічного центру окостеніння (2–3 %, частіше з обох боків) | не плутати з переломом: краї гладкі, заокруглені |
| **Фабела** (*fabella*) | сесамоподібна кістка в латеральній головці литкового м'яза | |
| **Тибіальна торсія, вальгусне й варусне коліно** | фізіологічні до 5–6 років | |
| **Вроджена косолапість** (*pes equinovarus*) | стопа в підошовному згинанні, супінації й приведенні; таранна кістка деформована | лікування за Понсеті |
| **Вертикальна таранна кістка** (*talus verticalis*) | тяжка вроджена плоска стопа («стопа-гойдалка») | |
| **Зрощення кісток заплесна** (*coalitio tarsi*) | кістковий, хрящовий або волокнистий місток (частіше п'ятково-човноподібний або таранно-п'ятковий) | ригідна плоскостопість у підлітків |
| **Трикутна кістка** (*os trigonum*) | бічний горбок заднього відростка таранної кістки не приростає (7–14 %) | біль у балерин і футболістів (задній імпіджмент) |
| **Додаткова човноподібна кістка** (*os naviculare accessorium*, *os tibiale externum*) | окремий центр горбистості човноподібної кістки | біль над присередньою частиною стопи, слабкість заднього великогомілкового м'яза |
| **Малогомілкова кістка** (*os peroneum*) | сесамоподібна кістка в сухожилку довгого малогомілкового м'яза біля кубоподібної кістки | |
| **Кістка Везалія** (*os vesalianum*) | окрема горбистість V плеснової кістки | плутання з відривним переломом |
| **Міжплеснова кістка** (*os intermetatarseum*) | між основами I і II плеснових кісток | |
| **Зрощення фаланг мізинця** | середня й дистальна фаланги V пальця стопи зростаються (близько 40 %) | норма |

**Як відрізнити додаткову кістку від перелому на рентгені:** додаткова кістка має гладкі заокруглені краї з кортикальним шаром по всьому периметру, часто симетрична з обох боків. Свіжий уламок має гострі нерівні краї без кортикального шару на лінії перелому.

## 7. Системні вади (дисплазії) скелета

| Хвороба | Дефект | Ознаки |
|---|---|---|
| **Ахондроплазія** | мутація *FGFR3* пригнічує проліферацію хондроцитів ростових пластинок | короткі кінцівки (ризомелія), нормальний тулуб, великий череп із виступаючим лобом, сідлоподібний ніс, вузький великий отвір; сполучнотканинне окостеніння не порушене |
| **Недосконалий остеогенез** (*osteogenesis imperfecta*) | дефект колагену I типу (*COL1A1*, *COL1A2*) | множинні переломи, сині склери, глухота (отосклероз), недосконалий дентиногенез, швові кістки |
| **Ключично-черепний дизостоз** | *RUNX2* — порушення сполучнотканинного окостеніння | відсутність ключиць (плечі зводяться спереду), відкриті тім'ячка, швові кістки |
| **Остеопетроз** | дефект остеокластів | щільні, але крихкі кістки, анемія (немає місця для кісткового мозку), стиснення черепних нервів у вузьких отворах |
| **Синдром Марфана** | фібрилін-1 | довгі кінцівки й пальці (арахнодактилія), сколіоз, деформація грудної клітки |
| **Множинні екзостози** | *EXT1/EXT2* | хрящові вирости біля ростових пластинок |
| **Гіпофосфатемічний рахіт** | *PHEX* — надлишок FGF23 | О-подібні ноги, низький зріст |

## 8. Клінічні кореляції

- Додаткові кістки й незрощені центри окостеніння — найчастіша причина хибного діагнозу «перелом» на рентгені. Допомагає знімок протилежної кінцівки.
- Сакралізація й люмбалізація змінюють нумерацію хребців. Перед операцією рівень хребця визначають, рахуючи від C2 або від 12-го ребра.
- Шийне ребро дає симптоми з боку нижнього стовбура плечового сплетення (C8–T1): біль і оніміння по ліктьовому краю кисті, слабкість дрібних м'язів кисті, ослаблення пульсу на променевій артерії при відведенні руки.
- Отвір груднини робить небезпечною пункцію в нижній частині тіла груднини: голка проходить у перикард.
- Асиміляція атланта, базилярна імпресія й мальформація Кіарі часто поєднуються. Симптоми — головний біль у потилиці, ураження нижніх черепних нервів.
- Вади ростових пластинок дають диспропорційну низькорослість (коротші кінцівки), а ендокринні причини (дефіцит гормону росту, гіпотиреоз) — пропорційну.

**22.** Порівняйте скафоцефалію і тригоноцефалію: який шов заріс у кожному випадку?

**23.** Чим біпартитний надколінок відрізняється від перелому на рентгені?

**25.** Чим пропорційна низькорослість відрізняється від диспропорційної? Наведіть причини.

**26.** Що спільного між *os acromiale*, біпартитним надколінком і *os trigonum*?

**27.** Чим *ponticulus posticus* відрізняється від нормальної борозни хребтової артерії і чому він важливий для хірурга?

**29.** Порівняйте хворобу Шпренгеля і крилоподібну лопатку за причиною.

**30.** Які вади належать до атавізмів? Наведіть два приклади на кістках кінцівок.

### Рівень 4. Клінічні ситуації

**31.** У молодої жінки біль і оніміння по ліктьовому краю кисті, слабкість дрібних м'язів кисті, пульс на променевій артерії слабшає при відведенні руки. Яку кісткову аномалію шукати і що вона стискає?

**32.** На рентгені поперекового відділу видно лише чотири вільні поперекові хребці, а L5 зрощений з крижовою кісткою. Як це назвати і чому це важливо перед операцією?

**33.** Під час груднинної пункції голка несподівано пройшла глибоко без опору. Яку вроджену варіацію груднини можна запідозрити і чим вона небезпечна?

**34.** У дитини з частими переломами сині склери й багато швових кісток на рентгені черепа. Який діагноз і дефект якого білка?

**35.** Новонароджена дівчинка після сідничного передлежання; проба Ортолані позитивна. Яку ваду запідозрити і що буде без лікування?

**36.** Підліток-футболіст скаржиться на біль у задній частині гомілковостопного суглоба при підошовному згинанні. На рентгені — заокруглена кісточка позаду таранної кістки. Що це?

**37.** У хворого з онімінням у ділянці серединного нерва на рентгені плеча знайдено гачкоподібний виступ над присереднім надвиростком. Що це за структура і що стискає серединний нерв?

**38.** Дитина не може повернути долоню вниз або вгору; лікоть згинається нормально. Яка вроджена вада найімовірніша?

**39.** Підліток із ригідною плоскою стопою, біль після навантаження. Яку ваду заплесна шукають на КТ?

**40.** Новонароджений має мішкоподібне вип'ячування в попереку, слабкість ніг і нетримання сечі. Яка форма *spina bifida* і з якою вадою мозку її часто поєднують?

### Відповіді

1. Варіант не порушує функцію (швові кістки, метопічний шов); аномалія порушує форму або функцію (шийне ребро зі стисненням сплетення, *spina bifida*, вроджений вивих стегна).
2. Дрібні додаткові кістки у швах черепа (*ossa suturalia*, вормієві); найчастіше в ламбдоподібному шві.
3. Окрема верхня частина луски потиличної кістки (*os interparietale*); виникає, коли сполучнотканинна (верхня) частина луски не зростається з хрящовою (нижньою).
4. Метопізм (*metopismus*); близько 5–10 % людей.
5. Сакралізація — L5 зростається з крижовою кісткою; люмбалізація — S1 відокремлюється й стає шостим поперековим хребцем.
6. З реберного елемента поперечного відростка C7 (надмірний розвиток).
7. Незрощений з остю лопатки акроміон, окрема кістка (3–8 %).
8. Окремий бічний горбок заднього відростка таранної кістки; лежить позаду тіла таранної кістки.
9. У латеральній головці литкового м'яза, позаду латерального виростка стегнової кістки.
10. Зв'язка від надвиросткового відростка плечової кістки до присереднього надвиростка; під нею можуть проходити серединний нерв і плечова артерія.
11. Сполучнотканинне (ендесмальне); відсутні або недорозвинені ключиці, відкриті тім'ячка й шви, багато швових кісток (також аномалії зубів).
12. Мутація *FGFR3* пригнічує ендохондральний ріст у ростових пластинках довгих кісток; склепіння черепа окостеніває сполучнотканинно й не залежить від ростових пластинок; тулуб вкорочений менше, бо ріст хребців у висоту менше залежить від довгих ростових пластинок, ніж ріст стегнової й плечової кісток.
13. Незрощення піднебінних відростків верхньої щелепи між собою (і з різцевою кісткою); 7–12-й тиждень.
14. Менінгоцеле — вип'ячуються лише оболонки з ліквором; мієломенінгоцеле — оболонки разом зі спинним мозком і корінцями.
15. Фолієва кислота (400 мкг/добу) до зачаття й протягом перших 12 тижнів вагітності.
16. 24–36-й день (4–5-й тиждень); талідомід.
17. Закладається лише одна половина тіла хребця; клиноподібний хребець дає вроджений сколіоз.
18. Зрощення кількох шийних хребців (блокові хребці); коротка шия, низька межа росту волосся на потилиці, обмежені рухи шиї.
19. Зубоподібна кістка (*os odontoideum*).
20. Зрощення атланта з потиличною кісткою (окципіталізація атланта).
21. Coxa vara — кут менший за 120°; coxa valga — більший за 135° (норма близько 125°).
22. Скафоцефалія — сагітальний шов; тригоноцефалія — лобовий (метопічний) шов.
23. Біпартитний надколінок має гладкі заокруглені краї з кортикальним шаром, уламок лежить верхньобічно, часто з обох боків; перелом має гострі нерівні краї і зазвичай поперечну лінію.
24. Додаткова кістка: гладкі краї, кортикальний шар по всьому периметру, часто симетрія з другого боку; уламок: гострі краї, немає кортикального шару на лінії відриву, болючість і набряк у цьому місці.
25. Пропорційна — всі сегменти зменшені рівномірно (дефіцит гормону росту, гіпотиреоз, хронічні хвороби); диспропорційна — кінцівки коротші за тулуб або навпаки (скелетні дисплазії: ахондроплазія).
26. Усі виникають через незрощення окремого центру окостеніння з основною кісткою.
27. Над борозною на задній дузі атланта утворюється кістковий місток (окостеніла задня атланто-потилична мембрана), борозна стає каналом; хірург може прийняти місток за пластинку і пошкодити хребтову артерію гвинтом.
28. Окостеніння верхньої поперечної зв'язки лопатки (отвір замість вирізки, стиснення надлопаткового нерва); *os acromiale* (імпіджмент-синдром).
29. Хвороба Шпренгеля — вроджене високе стояння лопатки (лопатка не опустилася в ембріогенезі); крилоподібна лопатка — параліч переднього зубчастого м'яза (ушкодження довгого грудного нерва).
30. Надвиростковий відросток плечової кістки, третій вертлюг стегнової кістки (також *os centrale*).
31. Шийне ребро; стискає нижній стовбур плечового сплетення (C8–T1) і підключичну артерію.
32. Сакралізація L5; змінюється рахунок хребців, хірург може помилитися з рівнем, тому рахують від C2 або від 12-го ребра.
33. Отвір груднини (*foramen sterni*); голка може пройти в перикард і серце.
34. Недосконалий остеогенез; колаген I типу.
35. Дисплазія кульшового суглоба (вроджений вивих стегна); без лікування — кульгання, укорочення ноги, ранній коксартроз.
36. Трикутна кістка (*os trigonum*) — незрощений бічний горбок заднього відростка таранної кістки; задній імпіджмент.
37. Надвиростковий відросток плечової кістки; зв'язка Стразерса, що йде від нього до присереднього надвиростка.
38. Вроджений променево-ліктьовий синостоз.
39. Зрощення кісток заплесна (*coalitio tarsi*): п'ятково-човноподібне або таранно-п'яткове.
40. Мієломенінгоцеле; часто з мальформацією Кіарі II і гідроцефалією.
