## 1. Переломи (*fracturae*)

**Перелом** — порушення цілості кістки.

### Причини
- **Травматичний** — сила більша за міцність кістки (удар, падіння, ДТП).
- **Патологічний** — кістка ослаблена хворобою (остеопороз, пухлина, метастаз, кіста, остеомієліт). Мала сила зламує кістку.
- **Стресовий (втомний)** — повторні малі навантаження (військові марші, біг).
- **Фрагільний (крихкості)** — при мінімальній травмі (падіння з висоти свого зросту) на тлі остеопорозу.

### Класифікація

**За цілістю шкіри:**
- **Закритий** — шкіра ціла.
- **Відкритий** — рана сполучається з уламками. Ризик інфекції. Класифікація Густіло–Андерсона (I–III).

**За напрямком лінії перелому:**
| Тип | Опис |
|---|---|
| Поперечний | Лінія під прямим кутом до осі кістки (пряма сила) |
| Косий | Лінія під кутом (30–60°) |
| Спіральний | Закручена лінія (скручувальна сила) |
| Оскольчастий (багатоуламковий) | Три і більше уламків (висока енергія) |
| Вбитий (імпактований) | Уламки вбиті один в один |
| Компресійний | Тіло хребця або кістка стиснута |
| Відривний (авульсійний) | М'яз або зв'язка відриває шматок кістки |
| Сегментарний | Дві лінії; середній сегмент вільний |
| Вдавлений | Череп: уламок вдавлений усередину |

**За зміщенням:**
- **Без зміщення** (*non-displaced*).
- **Зі зміщенням** (*displaced*): за довжиною, шириною, під кутом, з ротацією.

**За стабільністю:**
- Стабільний — уламки не зміщуються при русі.
- Нестабільний — уламки зміщуються (потрібна фіксація).

**У дітей:**
- **Перелом за типом «зеленої гілки»** (*greenstick*) — кістка згинається, надламується з одного боку (надкістниця ціла з іншого).
- **Торусний (buckle)** — кістка стиснута, випинається.
- **Пластична деформація** — кістка зігнута без перелому.
- **Перелом ростової пластинки** — класифікація **Солтер–Гаррис**:

| Тип | Опис | Мнемоніка |
|---|---|---|
| I | Лінія перелому по всій ростовій пластинці (розділяє епіфіз і метафіз) | **S**traight across |
| II | Лінія йде по пластинці й виходить через метафіз (найчастіший, ~75 %) | **A**bove |
| III | Лінія йде по пластинці й виходить через епіфіз у суглоб | **L**ower |
| IV | Лінія проходить крізь метафіз, пластинку й епіфіз | **T**hrough |
| V | Стиснення пластинки (рідко, найгірший прогноз) | **R**ammed |

Загальна мнемоніка: **SALTR**. Вище типу — гірший прогноз для росту.

### Клінічні ознаки перелому
- Біль, набряк, синець (гематома).
- Деформація, ненормальна рухливість, крепітація (хрускіт уламків).
- Порушення функції (неможливість навантажити).
- Укорочення кінцівки.
- **Достовірні ознаки**: ненормальна рухливість, крепітація, видимі уламки, деформація.
- Діагностика: **рентген** у двох проєкціях, КТ (складні переломи), МРТ (стрес-переломи, ушкодження м'яких тканин).

### Ускладнення
| Ускладнення | Опис |
|---|---|
| Кровотеча | Стегно — до 1–1,5 л; таз — до 2–3 л. Шок |
| Пошкодження нервів, судин | Перелом плеча — [[Плечове сплетення і нерви верхньої кінцівки\|променевий нерв]]; шийка малогомілкової — загальний [[Поперекове і крижове сплетення\|малогомілковий нерв]] |
| **Компартмент-синдром** | Набряк у закритому фасціальному футлярі → ішемія. Біль, що не відповідає травмі, болісне пасивне розтягнення. Невідкладна фасціотомія |
| **Жирова емболія** | Жир із кісткового мозку потрапляє в кров. Дихальна недостатність, неврологічні порушення, петехії. Через 24–72 години |
| **Тромбоемболія** | Тромбоз глибоких вен ніг, ТЕЛА |
| **Інфекція** | Остеомієліт (відкриті переломи) |
| **Асептичний некроз** | Перелом шийки стегна, човноподібної кістки, шийки таранної кістки — порушення кровопостачання |
| Незрощення (*nonunion*) | Немає зрощення за 6–9 місяців |
| Неправильне зрощення (*malunion*) | Зрощення в хибному положенні |
| Затримка зрощення | Більше очікуваного часу |
| **Контрактури** | Тугорухливість суглобів |
| **Синдром Зудека (КРБС)** | Біль, набряк, зміна шкіри |
| **Пошкодження росту** | Для переломів ростової пластинки — деформація, укорочення |

### Лікування (принципи)
1. **Репозиція** — повернення уламків у правильне положення.
2. **Іммобілізація (фіксація)** — гіпсова або пластикова пов'язка, шини, ортез.
3. **Остеосинтез** — хірургічна фіксація: пластини з гвинтами, інтрамедулярні стрижні, спиці, апарат зовнішньої фіксації.
4. **Ендопротезування** — заміна суглоба (перелом шийки стегна в літніх).
5. **Реабілітація** — відновлення рухів і сили.

Перша допомога: іммобілізація (шина на уражену ділянку й сусідні суглоби), зупинка кровотечі, холод, знеболення, не вправляти уламки, терміновий транспорт.

## 3. Вивихи й травми суглобів

- **Вивих** (*luxatio*) — повна втрата контакту суглобових поверхонь. Біль, деформація, неможливість руху, пружна фіксація.
- **Підвивих** (*subluxatio*) — часткова втрата контакту.
- **Розтягнення** — травма зв'язок (I–III ступінь).
- **Розрив менісків, хрестоподібних зв'язок.**
- Лікування вивиху: **вправлення**, іммобілізація, реабілітація.
- Найчастіші вивихи: плечовий (передній), ліктьовий, пальців, надколінка, нижньої щелепи, кульшовий (при ДТП; ризик некрозу голівки).

## 4. Остеопороз і метаболічні захворювання кісток

### Остеопороз (*osteoporosis*)
- Зменшення кісткової маси й порушення мікроархітектури → крихкі кістки.
- **Типи:** первинний (постменопаузальний; старечий), вторинний (глюкокортикоїди, гіпертиреоз, гіперпаратиреоз, діабет, хвороби кишок, лікарські засоби).
- **Діагностика:** **ДЕКСА** (рентгенівська денситометрія), **T-критерій**:
  - норма: T ≥ −1,0;
  - остеопенія: від −1,0 до −2,5;
  - остеопороз: T ≤ −2,5;
  - тяжкий остеопороз: T ≤ −2,5 + перелом.
- **Типові переломи:** тіл хребців (компресійні, особливо T12–L1), дистальна променева кістка (Коллес), шийка стегнової кістки.
- **Фактори ризику:** жіноча стать, менопауза, вік, мала маса тіла, паління, алкоголь, мала фізична активність, дефіцит кальцію й вітаміну D, спадковість, прийом глюкокортикоїдів.
- **Профілактика:** кальцій, вітамін D ([[Вітамін D]]), вправи з навантаженням, відмова від паління.
- **Лікування:** бісфосфонати (алендронат), деносумаб (антитіло до RANKL), терипаратид (аналог ПТГ), ромосозумаб (проти склеростину), ЗГТ/SERM.

### Остеомаляція й рахіт
- **Рахіт** — у дітей. Недостатня мінералізація кісток через дефіцит вітаміну D (або кальцію, фосфору). Ознаки: розм'якшення кісток, деформації (О-подібні ноги, «реберні чотки», «браслети», лобові горби, тім'ячко закривається пізно).
- **Остеомаляція** — аналогічний стан у дорослих. Болі в кістках, слабкість м'язів, псевдопереломи (зони Лоозера).
- Причини: нестача сонця й вітаміну D, порушення всмоктування, хвороби нирок, генетичні (гіпофосфатемічний рахіт).
- Лікування: вітамін D, кальцій. Див. [[Вітамін D]].

### Інші
- **Гіперпаратиреоз** — надлишок ПТГ: резорбція кісток (фіброзно-кістозний остеїт), камені в нирках («кістки, камені, стогін, психічні розлади»).
- **Хвороба Педжета** (*osteitis deformans*) — хаотичне ремоделювання. Товсті, деформовані й слабкі кістки. Череп, таз, хребет, великогомілкова. Підвищений рівень лужної фосфатази.
- **Остеопетроз** («мармурова хвороба») — надмірна густина кістки (дефект остеокластів).
- **Ниркова остеодистрофія** — при хронічній хворобі нирок.

## 5. Інфекції й запалення

- **Остеомієліт** (*osteomyelitis*) — гнійне запалення кістки й кісткового мозку. Часто *Staphylococcus aureus*. Гематогенний (діти: метафізи довгих кісток), після травми й операції. Ознаки: біль, лихоманка, набряк. Хронічний → секвестри (мертві ділянки), свищі. Діагностика: МРТ, лабораторні (ШОЕ, СРБ), посів. Лікування: антибіотики тривало, хірургічне очищення.
- **Туберкульоз кісток** — хребет (хвороба Потта): руйнування тіл, горб.
- **Септичний артрит** — гнійне запалення суглоба. Невідкладний стан.
- **Остеохондрит.**

## 6. Асептичний (аваскулярний) некроз кістки

Відмирання ділянки кістки через порушення кровопостачання (без інфекції).
- **Причини:** перелом шийки стегна, вивих, глюкокортикоїди, алкоголь, серпоподібноклітинна анемія, дисбаризм (кесонна хвороба), радіація.
- **Типові локалізації:** головка стегнової кістки, головка плечової, півмісяцева кістка (**хвороба Кінбека**), човноподібна, таранна.
- **Остеохондропатії у дітей:**

| Хвороба | Місце |
|---|---|
| **Легга–Кальве–Пертеса** | головка стегнової кістки (4–8 років) |
| **Осгуда–Шлаттера** | горбистість великогомілкової кістки (10–15 років) |
| **Севера** | апофіз п'яткового горба (8–14 років) |
| **Шейєрмана–Мау** | апофізи хребців (кіфоз у підлітків) |
| **Келера I** | човноподібна кістка стопи |
| **Фрейберга** | головка II плеснової кістки |
| **Кінбека** | півмісяцева кістка |
| **Блаунта** | проксимальна медіальна великогомілкова кістка (викривлення) |

## 7. Пухлини кісток

### Доброякісні
- **Остеохондрома** (екзостоз) — найчастіша; метафізи довгих кісток у дітей.
- **Остеоїд-остеома** — малий вузол; нічний біль, зникає від аспірину.
- **Хондрома** — у дрібних кістках кисті.
- **Гігантоклітинна пухлина** — 20–40 років; епіфізи (дистальний стегна, проксимальний великогомілкової).
- **Остеома** — кістки черепа й пазух.
- **Фіброзна дисплазія** — кістка заміщена фіброзною тканиною.
- **Солітарна кіста.**

### Злоякісні
| Пухлина | Вік | Локалізація | Особливості |
|---|---|---|---|
| **Остеосаркома** | 10–25 років (другий пік >60) | метафізи довгих кісток (дистальний стегна, проксимальні великогомілкової, плеча) | Найчастіша первинна злоякісна пухлина кістки. Рентген: «променевий» періостит, трикутник Кодмана |
| **Саркома Юїнга** | 5–20 років | діафізи довгих кісток, таз | «Цибулинний» періостит. Транслокація t(11;22) |
| **Хондросаркома** | 40–70 років | таз, плечовий пояс, проксимальне стегно | Хрящова тканина |
| **Мієломна хвороба** (множинна мієлома) | >50 років | череп, хребет, ребра, таз | «Штамповані» дефекти черепа; патологічні переломи; гіперкальціємія |

### Метастази в кістки
Найчастіше з раку: молочної залози, передміхурової залози, легенів, нирки, щитоподібної залози. Метастази частіші, ніж первинні пухлини. Осьовий скелет (хребет, таз, ребра, проксимальні відділи стегна й плеча). Остеолітичні (руйнування) або остеобластичні (передміхурова: щільні осередки). Біль, патологічні переломи, гіперкальціємія, стиснення [[Спинний мозок|спинного мозку]].

## 8. Деформації

- **Сколіоз** — бічне викривлення хребта >10° (за Коббом) з обертанням хребців. Ідіопатичний (80 %, найчастіше в підлітків-дівчат), вроджений, нервово-м'язовий. Лікування: спостереження, корсет, операція (кут >40–50°).
- **Кіфоз** — посилений грудний вигин (>45°). Постуральний, хвороба Шейєрмана, остеопороз (горб), туберкульоз.
- **Лордоз** (гіперлордоз) — посилений поперековий.
- **Лійкоподібна грудна клітка** (*pectus excavatum*) — западання груднини; **кілеподібна** (*pectus carinatum*).
- **Вальгусне / варусне викривлення** (X- і O-подібні ноги). Фізіологічне до 5–6 років.
- **Плоскостопість** (*pes planus*), **високе склепіння** (*pes cavus*), **косолапість**, **hallux valgus** (відхилення великого пальця).
- **Кривошия** (*torticollis*) — вроджена (м'яз) або набута.
- **Дисплазія кульшового суглоба** — недорозвинення (діти).
- **Краніосиностоз** — передчасне закриття швів (форма черепа змінена).

## 9. Захворювання суглобів, що торкаються кісток

- **Остеоартроз** — дегенерація хряща, остеофіти, склероз.
- **Ревматоїдний артрит** — аутоімунне запалення; ерозії кісток.
- **Анкілозивний спондиліт (хвороба Бехтерева)** — запалення крижово-клубових суглобів і хребта; «бамбукова палиця».
- **Подагра** — кристали сечової кислоти.
- **Остеохондроз хребта** — дегенерація дисків.
- Детальніше: [[Суглоби]].

## 10. Генетичні захворювання кісток

- **Недосконалий остеогенез** (*osteogenesis imperfecta*, «кришталеві кістки») — дефект колагену I типу. Крихкі кістки, сині склери, глухота, слабкі зуби.
- **Ахондроплазія** — мутація FGFR3; порушений ріст у довжину; карликовість, великий череп, короткі кінцівки.
- **Синдром Марфана** — дефект фібриліну; довгі кінцівки, арахнодактилія, сколіоз, ураження серця й очей.
- **Синдром Елерса–Данлоса** — слабкість колагену, гіпермобільність суглобів.
- **Остеопетроз.**
- **Фіброзна дисплазія** (синдром Олбрайта).

## 11. Діагностика захворювань кісток

| Метод | Що показує |
|---|---|
| **Рентгенографія** | Переломи, деформації, інфекція, пухлини, остеопороз (пізні стадії) |
| **КТ** | Складні переломи, дрібні структури, пухлини |
| **МРТ** | Кістковий мозок, м'які тканини, стрес-переломи, некроз, інфекція |
| **ДЕКСА** | Мінеральна щільність кістки (T-критерій) |
| **Сцинтиграфія кісток** | Метастази, стрес-переломи, запалення (підвищене накопичення) |
| **УЗД** | Суглоби, сухожилки, переломи у дітей |
| **Біопсія** | Пухлини, інфекції |

**Лабораторні показники:**
- Кальцій (загальний, іонізований), фосфор.
- **Лужна фосфатаза** (ALP) — остеобласти; підвищена при рості, переломах, хворобі Педжета, метастазах, остеомаляції.
- **ПТГ**, 25(OH)-вітамін D.
- **Маркери формування кістки:** P1NP, остеокальцин.
- **Маркери резорбції:** CTX, NTX (С-телопептид).
- Кисла фосфатаза (метастази простати), білок Бенс-Джонса (мієлома).

## 12. Профілактика

- Кальцій: 1000–1200 мг на добу (залежно від віку й статі).
- Вітамін D: 600–800 МО на добу (за рекомендаціями; залежить від рівня в крові).
- Білок у раціоні.
- Фізична активність із навантаженням (ходьба, біг, силові вправи).
- Не палити, помірно алкоголь.
- Профілактика падінь (літні): освітлення, зір, взуття, силові вправи, баланс.
- Скринінг остеопорозу: жінки після 65 років (раніше при ризику), чоловіки після 70.
