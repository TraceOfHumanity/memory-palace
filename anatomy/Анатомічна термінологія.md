## 1. Анатомічне положення

Усі напрямки описують для тіла в **анатомічному положенні**:
- Людина стоїть прямо.
- Голова й очі дивляться вперед.
- Руки опущені вздовж тулуба.
- Долоні дивляться вперед, великі пальці — назовні.
- Ступні разом, пальці стоп дивляться вперед.

Права й ліва сторони — це сторони **пацієнта**, не спостерігача.

## 2. Напрямки

| Український | Латинський | Значення |
|---|---|---|
| верхній | superior | ближче до голови |
| нижній | inferior | ближче до стоп |
| краніальний | cranialis | у бік черепа |
| каудальний | caudalis | у бік куприка |
| передній (вентральний) | anterior (ventralis) | ближче до живота |
| задній (дорсальний) | posterior (dorsalis) | ближче до спини |
| присередній (медіальний) | medialis | ближче до серединної площини |
| бічний (латеральний) | lateralis | далі від серединної площини |
| проміжний | intermedius | між двома структурами |
| проксимальний | proximalis | ближче до тулуба (кінцівки) |
| дистальний | distalis | далі від тулуба (кінцівки) |
| поверхневий | superficialis | ближче до поверхні тіла |
| глибокий | profundus | далі від поверхні тіла |
| правий / лівий | dexter / sinister | сторона тіла |
| внутрішній / зовнішній | internus / externus | відносно порожнини |

Спеціальні терміни для кінцівок:
- **Долонний** (palmaris, volaris) — сторона долоні. **Тильний** (dorsalis) — протилежна сторона кисті або стопи.
- **Підошовний** (plantaris) — сторона підошви.
- **Променевий** (radialis) — сторона променевої кістки (бік великого пальця).
- **Ліктьовий** (ulnaris) — сторона ліктьової кістки (бік мізинця).
- **Великогомілковий** (tibialis) — присередня сторона гомілки.
- **Малогомілковий** (fibularis) — бічна сторона гомілки.

## 3. Площини

| Площина | Латинська назва | Як ділить тіло |
|---|---|---|
| сагітальна | planum sagittale | на праву й ліву частини |
| серединна (медіана) | planum medianum | сагітальна площина точно посередині |
| парасагітальна | planum parasagittale | сагітальна площина збоку від середини |
| лобова (фронтальна, коронарна) | planum frontale (coronale) | на передню й задню частини |
| поперечна (горизонтальна, аксіальна) | planum transversale | на верхню й нижню частини |

Осі:
- **Поздовжня (вертикальна)** — з верху вниз.
- **Сагітальна** — спереду назад.
- **Поперечна (фронтальна)** — зліва направо.

Обертання відбувається навколо осі, перпендикулярної до площини руху.

## 7. Суглобові поверхні

- **Facies articularis** — суглобова поверхня, вкрита хрящем.
- **Fovea articularis** — суглобова ямка.
- **Facet (facies, foveola)** — мала суглобова площадка.
- **Condylus** — виросток: випукла суглобова поверхня.
- **Caput** — головка: випукла сферична поверхня.
- **Fossa** (суглобова) — увігнута поверхня, у яку входить головка.

## 8. Назви за формою

- **Longum** — довгий. **Breve** — короткий. **Latum** — широкий.
- **Planum** — плоский. **Irregulare** — неправильний.
- **Pneumaticum** — повітроносний (містить порожнину з повітрям).
- **Sesamoideum** — сесамоподібний (вбудований у сухожилок).
- **Major / minor** — більший / менший.
- **Superior / medius / inferior** — верхній / середній / нижній.
- **Anterior / posterior** — передній / задній.
- **Dexter / sinister** — правий / лівий.

## 9. Як читати латинську назву кістки

Назва складається з двох слів: іменник + прикметник.
- *Os frontale* = лобова кістка. *Os* = кістка, *frontale* = лобова.
- *Os coxae* = тазова кістка.
- Множина *ossa* = кістки.
- Іменники в родовому відмінку вказують на приналежність: *processus styloideus ossis temporalis* = шилоподібний відросток скроневої кістки.
- У описах кісток використовують лише латинські назви ділянок. Українські назви в цьому розділі мають латинський відповідник у дужках.
- Слово *os* має два значення: «кістка» (*os, ossis*) і «рот» (*os, oris*). Контекст визначає значення.

## 10. Як зберігати текст у цьому розділі

Загальний формат опису кістки у файлах:
1. Назва (латинська) і кількість.
2. Положення.
3. Частини й орієнтири.
4. З'єднання з іншими кістками.
5. Отвори та їхній вміст.
6. Прикріплення м'язів (назви м'язів без деталей).
7. Окостеніння.
8. Клінічні примітки.
