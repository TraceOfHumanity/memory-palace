# Вегетативна нервова система (*pars autonomica*)

Вегетативна (автономна) нервова система керує **внутрішніми органами**, судинами, залозами та гладкими м'язами **мимоволі**. Вона підтримує гомеостаз.

Пов'язані файли: [[Нервова система — огляд]], [[Спинний мозок]], [[Стовбур мозку]], [[Проміжний мозок і базальні ядра]], [[Черепні нерви]], [[Спинномозкові нерви і сплетення]], [[Поперекове і крижове сплетення]], [[Нервовий імпульс і синапс]], [[Неврологічне обстеження і синдроми]], [[Серце — іннервація]], [[Серце — провідна система]], [[Бронхіальне дерево]], [[Легені — альвеоли і кровопостачання]], [[Регуляція травлення]], [[Шлунок — секреція і моторика]], [[Товста кишка]].

## 1. Загальна будова

Відмінність від соматичної: від ЦНС до органа йдуть **два нейрони**.

| Нейрон | Положення | Волокно |
|---|---|---|
| **Прегангліонарний** | ЦНС (бічні роги спинного мозку або ядра стовбура) | мієлінізоване (тип B); у симпатичній частині коротке, у парасимпатичній довге |
| **Постгангліонарний** | вегетативний вузол (ганглій) | немієлінізоване (тип C); у симпатичній частині довге, у парасимпатичній коротке |

- Соматична система: один нейрон від ЦНС до м'яза.
- Вегетативна: **прегангліонарний → вузол → постгангліонарний → орган**.

### Відділи
1. **Симпатичний** (*pars sympathica*) — «бий або тікай».
2. **Парасимпатичний** (*pars parasympathica*) — «відпочинь і травлення».
3. **Ентеральний** (*systema nervosum enterale*) — нервова система кишки (сплетення Ауербаха і Мейснера); працює автономно.

Більшість органів має **подвійну іннервацію** (симпатика + парасимпатика) з протилежним ефектом.

### Медіатори
| Нейрон | Медіатор | Рецептор |
|---|---|---|
| **Прегангліонарний (обидва відділи)** | **ацетилхолін** | **нікотиновий** (N-н) на нейронах вузла |
| **Постгангліонарний парасимпатичний** | **ацетилхолін** | **мускариновий** (M₁–M₅) в органі |
| **Постгангліонарний симпатичний** | **норадреналін** | α₁, α₂, β₁, β₂ |
| Винятки симпатичні: **потові залози** (ацетилхолін, мускариновий), **мозкова речовина надниркових** (прегангліонарне → адреналін у кров) | | |

## 2. Симпатична частина

### Центральний відділ
**Бічні роги** (*cornu laterale*) спинного мозку, сегменти **T1–L2** — **проміжно-латеральне ядро**. Бічний ріг на рівні C8 містить циліоспінальний центр.

### Периферичний відділ
1. **Симпатичний стовбур** (*truncus sympathicus*) — ланцюг вузлів з обох боків хребта від основи черепа до куприка.
2. **Передхребтові (превертебральні) вузли** — на передній поверхні аорти.
3. **Сполучні гілки** (*rami communicantes*) — з'єднують нерви зі стовбуром.

### Шлях волокон
1. Прегангліонарне волокно виходить із **переднім корінцем**.
2. Через **білу сполучну гілку** (*ramus communicans albus*; T1–L2) входить у симпатичний стовбур.
3. Далі три варіанти:

| Варіант | Опис | Результат |
|---|---|---|
| **A. Перемикається в вузлі на тому ж рівні** | постгангліонарне волокно повертається через **сіру сполучну гілку** (*r. communicans griseus*) у спинномозковий нерв | іннервує судини, потові залози, м'язи, що піднімають волосся, у тій же ділянці |
| **B. Йде вгору або вниз по стовбуру** і перемикається в іншому вузлі | | голова (з T1–T4), кінцівки |
| **C. Проходить стовбур без перемикання** | утворює **внутрішностні нерви** (*nn. splanchnici*) до **превертебральних вузлів** | органи черевної порожнини, таза |

Сірі гілки є у **всіх** 31 парі спинномозкових нервів; білі — лише T1–L2.

### Симпатичний стовбур: відділи
| Відділ | Вузли | Основні гілки |
|---|---|---|
| **Шийний** | **верхній** (великий; до C2–C3), **середній**, **нижній** (зірчастий — разом із T1) | до голови (внутрішні сонні нерви), серця (верхній, середній, нижній серцеві нерви) |
| **Грудний** | 10–12 вузлів | серце (T1–T5), легені, стравохід; **великий внутрішностний** (T5–T9) і **малий внутрішностний** (T10–T11), **найнижчий** (T12) → черевні вузли |
| **Поперековий** | 3–5 вузлів | **поперекові внутрішностні нерви** → міжбрижові і нижнє брижове сплетення |
| **Крижовий** | 4–5 вузлів | органи таза; нерви до нижніх кінцівок |
| **Куприковий** | непарний вузол | |

### Шийні вузли
- **Верхній шийний вузол** (*ganglion cervicale superius*) — найбільший; на рівні C2–C3. Дає волокна для голови: **внутрішній сонний нерв** (сплетення навколо ВСА) → **розширювач зіниці**, потові залози обличчя, гладкі м'язи повіки (Мюллера).
- **Зірчастий вузол** (*g. stellatum*) = нижній шийний + перший грудний — серце, верхня кінцівка.
- **Блокада зірчастого вузла** — лікування болю в руці, синдрому Рейно, ішемії.

### Превертебральні вузли
Лежать навколо відгалужень аорти:
| Вузол | Іннервація |
|---|---|
| **Чревні вузли** (*ganglia coeliaca*) | печінка, шлунок, селезінка, підшлункова залоза, надниркові залози, тонка кишка |
| **Верхній брижовий вузол** | тонка кишка, права половина товстої |
| **Нижній брижовий вузол** | ліва половина товстої, пряма кишка |
| **Міжбрижові** і **аортово-ниркові** | нирки |
| **Верхнє і нижнє підчеревні сплетення** | таз: сечовий міхур, статеві органи |

### Мозкова речовина надниркових залоз
Спеціалізований «вузол»: клітини **хромафінні** — прегангліонарні волокна (ACh) → виділяють **адреналін** (80%) і **норадреналін** (20%) у кров.

### Симпатична система: ефекти
| Орган | Ефект |
|---|---|
| **Серце** | ↑ ЧСС, ↑ сила скорочення (β₁) |
| **Судини** | звуження (α₁) шкіри, органів черева; розширення (β₂) в скелетних м'язах |
| **Бронхи** | розширення (β₂) |
| **Зіниця** | розширення (α₁; розширювач зіниці) |
| **Війковий м'яз** | розслаблення (далекий зір) |
| **Шлунково-кишковий тракт** | ↓ перистальтика, ↓ секреція, скорочення сфінктерів |
| **Печінка** | глікогеноліз → ↑ глюкоза |
| **Жирова тканина** | ліполіз |
| **Нирки** | ↑ секреція реніну (β₁) |
| **Сечовий міхур** | розслаблення детрузора, скорочення сфінктера (затримка) |
| **Потові залози** | ↑ потовиділення (холінергічні!) |
| **Статеві органи** | еякуляція (чоловік) |
| **Гладкі м'язи волосся** | «гусяча шкіра» |
| **Слинні залози** | в'язка слина |

## 3. Парасимпатична частина

### Центральний відділ
| Відділ | Ядра |
|---|---|
| **Краніальний (стовбурний)** | ядро Едінгера — Вестфаля (III), верхнє слинне ядро (VII), нижнє слинне ядро (IX), дорсальне ядро блукаючого нерва (X) |
| **Сакральний (крижовий)** | **S2–S4**, бічні роги (парасимпатичні ядра) |

### Периферичний відділ — нерви і вузли
| Нерв | Прегангліонарне → вузол | Іннервація |
|---|---|---|
| **III** | → **війковий вузол** | звужувач зіниці, війковий м'яз |
| **VII** | великий кам'янистий нерв → **крилопіднебінний вузол** | сльозова, носові, піднебінні залози |
| **VII** | барабанна струна → **піднижньощелепний вузол** | піднижньощелепна й під'язикова залози |
| **IX** | малий кам'янистий нерв → **вушний вузол** | привушна залоза |
| **X** | довгі прегангліонарні волокна → **інтрамуральні вузли** в стінках органів | серце, легені, стравохід, шлунок, кишка (до лівого згину ободової кишки), печінка, підшлункова залоза, нирки |
| **Тазові внутрішностні нерви** (*nn. splanchnici pelvici*, S2–S4) | → **інтрамуральні / тазові вузли** | нижня половина товстої кишки, сечовий міхур, статеві органи |

Особливість: парасимпатичні прегангліонарні волокна **довгі**, постгангліонарні — **короткі** (вузол біля органа або в його стінці). У симпатичній частині навпаки: прегангліонарні волокна короткі, постгангліонарні довгі.

### Парасимпатична система: ефекти
| Орган | Ефект |
|---|---|
| **Серце** | ↓ ЧСС (M₂) |
| **Судини** | майже не іннервовані (розширення статевих органів → ерекція) |
| **Бронхи** | звуження, ↑ секреція слизу (M₃) |
| **Зіниця** | **звуження** (міоз) |
| **Війковий м'яз** | скорочення (акомодація на близьке) |
| **ШКТ** | ↑ перистальтика, ↑ секреція, розслаблення сфінктерів |
| **Печінка, підшлункова** | ↑ жовч, ↑ інсулін |
| **Сечовий міхур** | скорочення детрузора, розслаблення сфінктера (сечовипускання) |
| **Слинні, сльозові залози** | ↑ секреція (рідка слина) |
| **Статеві органи** | ерекція (S2–S4); мнемоніка *point and shoot*: парасимпатика — ерекція, симпатика — еякуляція |

Мнемоніка парасимпатики **SLUDD**: слиновиділення (*salivation*), сльозовиділення (*lacrimation*), сечовипускання (*urination*), дефекація (*defecation*), травлення (*digestion*). Симпатика: **«4F»** — *Fight, Flight, Fright, Fornication* (бій, втеча, страх, статева активність).

## 4. Ентеральна нервова система (*systema nervosum enterale*)

«Мозок кишки»: ~100–500 млн нейронів у стінці ШКТ. Працює автономно, регулюється симпатикою і парасимпатикою.

| Сплетення | Положення | Функція |
|---|---|---|
| **Міжм'язове (Ауербаха)** | між поздовжнім і колоподібним шарами | перистальтика (моторика) |
| **Підслизове (Мейснера)** | у підслизовому шарі | секреція, кровотік, всмоктування |

Ураження: **хвороба Гіршпрунга** — відсутність гангліїв у стінці дистального відділу товстої кишки → мегаколон; **ахалазія кардії** — втрата нейронів Ауербаха в стравоході.

## 5. Вісцеральні рефлекси

**Вісцеро-вісцеральні** (орган → орган) і **вісцеро-соматичні**. Вісцеральна чутливість: аферентні волокна супроводжують вегетативні нерви.

### Вісцеральний біль
- Спазм, розтяг, ішемія → біль; різання, опік — слабко.
- Біль тупий, нечіткий, супроводжується нудотою, потом.
- **Іррадіація (відбитий біль)**: аферентні волокна органа і шкіри сходяться на тих самих нейронах заднього рогу → мозок «приписує» біль шкірі.

| Орган | Зона відбитого болю |
|---|---|
| Серце | ліва рука, ліве плече, шия, щелепа (T1–T5) |
| Діафрагма | плече (C3–C5; **симптом Кера**) |
| Жовчний міхур | права лопатка, плече (T7–T9) |
| Підшлункова залоза | спина (T10) |
| Апендикс | початок — навколо пупка (T10), потім права клубова ямка |
| Нирка, сечовід | попереково-пахвинна ділянка (T10–L1) |
| Сечовий міхур | надлобкова ділянка |
| Яєчко | пахвина (T10–L1) |

### Рефлекси
- **Каротидний синус** (IX → X): ↑ тиск → ↓ ЧСС.
- **Барорецепторний рефлекс** (дуга аорти, каротидний синус) — швидка регуляція тиску.
- **Око-серцевий рефлекс** (Даньїні — Ашнера): тиск на очі → брадикардія.
- **Рефлекс сечовипускання** (S2–S4 + міст).
- **Рефлекс дефекації**.

| **Спинний мозок** | сегментарні вегетативні рефлекси |

## 7. Клінічні поняття

### Синдром Горнера (*Horner's syndrome*)
Ураження симпатичної іннервації голови (ланцюг: гіпоталамус → стовбур → бічний ріг C8–T2 → верхній шийний вузол → ВСА → око).

**Тріада**: **міоз** (звужена зіниця), **птоз** (легкий; м'яз Мюллера), **ангідроз** (сухість шкіри обличчя) + ентофтальм.

| Рівень | Причина |
|---|---|
| **Центральний** | синдром Валленберга, інсульт стовбура |
| **Прегангліонарний** | **пухлина Панкоста**, травма шиї, плечового сплетення, розтин аорти |
| **Постгангліонарний** | розтин сонної артерії, кластерний головний біль |

### Інші
- **Вегетативна нейропатія**: діабет, амілоїдоз, хвороба Паркінсона → ортостатична гіпотензія, гастропарез, імпотенція.
- **Синдром Рейно** — вазоспазм (симпатика).
- **Феохромоцитома** — пухлина мозкової речовини надниркових: гіпертонічні кризи.
- **Хвороба Гіршпрунга**, **ахалазія**.
- **Нейрогенний сечовий міхур**: ураження S2–S4 → в'ялий міхур з переповненням; вище S2 → спастичний.
- **Ваготомія** (перерізання блукаючого нерва) — раніше при виразці.
- **Симпатектомія** — при гіпергідрозі, облітеруючих хворобах.
- Лікарські засоби: **β-блокатори** (↓ ЧСС), **атропін** (блокує M-рецептори: тахікардія, мідріаз, сухість), **адреналін** (анафілаксія), **холіноміметики** (пілокарпін — міоз), **антихолінестеразні** (неостигмін).

## 9. Мнемоніки

- **Симпатика**: «**T1–L2**» (грудно-поперекова); **парасимпатика**: «**Cranio-Sacral**» (череп і крижі — III, VII, IX, X і S2–S4).
- Парасимпатичні нерви голови: **III, VII, IX, X**.
- Симпатика: **«Fight or Flight»**, парасимпатика: **«Rest and Digest»**.
- Холінергічна симпатика: **потові залози**.
- **M** — мускарин (парасимпатичні органи), **N** — нікотин (вузли та м'язи).
