# Провідні шляхи (*viae conductoriae*)

Провідний шлях — ланцюг нейронів, що передає сигнал від рецептора до кори (**висхідний, чутливий**) або від кори до ефектора (**низхідний, руховий**).

Пов'язані файли: [[Нервова система — огляд]], [[Спинний мозок]], [[Стовбур мозку]], [[Мозочок]], [[Проміжний мозок і базальні ядра]], [[Кора великих півкуль]], [[Черепні нерви]], [[Спинномозкові нерви і сплетення]], [[Неврологічне обстеження і синдроми]].

---

## 1. Загальні принципи

- Висхідний шлях має **три нейрони** (I — у вузлі, II — у спинному мозку або стовбурі, III — у таламусі), потім кора.
- **Перехрест** (*decussatio*) — шлях переходить на протилежний бік. Правило: кожна півкуля працює з **протилежним** боком тіла.
- Рівень перехреста визначає симптоми ураження.
- **Соматотопія** — волокна розташовані за ділянками тіла.

### Види чутливості
| Вид | Рецептор | Шлях |
|---|---|---|
| **Біль, температура** (протопатична) | вільні нервові закінчення | спинно-таламічний |
| **Грубий дотик, тиск** | Меркеля, Руффіні | спинно-таламічний (передній) |
| **Тонкий дотик, вібрація, положення суглобів, дискримінація** (епікритична, глибока) | Мейснера, Фатера — Пачіні | задні канатики → медіальна петля |
| **Несвідома пропріорецепція** | м'язові веретена, сухожилкові органи | спинно-мозочкові шляхи |

## 2. Висхідні шляхи

### 2.1. Шляхи задніх канатиків — медіальна петля (DCML)
Свідомий дотик, вібрація, положення (пропріорецепція), стереогноз.

| Нейрон | Положення | Хід |
|---|---|---|
| **I** | спинномозковий вузол | аксон входить у задній канатик **без перехреста** |
| | | піднімається по **тонкому пучку (Голля)** — нижня половина тіла (нижче T6) і **клиноподібному пучку (Бурдаха)** — верхня половина (вище T6) |
| **II** | ядра тонкого і клиноподібного пучків (довгастий мозок) | аксони **перехрещуються** (внутрішні дугоподібні волокна) → **медіальна петля** |
| **III** | **вентральне задньолатеральне ядро таламуса (VPL)** | через заднє плече внутрішньої капсули |
| Кора | **задньоцентральна звивина** (S1) | |

Правило: тонкий пучок (Голля) несе сигнали від **ніг** (нижче T6), клиноподібний (Бурдаха) — від **рук і верхньої половини тулуба** (вище T6).

Ураження: втрата вібрації й положення **на тому ж боці** (нижче рівня ураження спинного мозку); **атаксія** (сенсорна), симптом Ромберга позитивний.

### 2.2. Спинно-таламічний шлях (*tractus spinothalamicus*)
Біль, температура, грубий дотик.

| Нейрон | Положення | Хід |
|---|---|---|
| **I** | спинномозковий вузол | входить у задній ріг; вище-нижче на 1–2 сегменти (тракт Ліссауера) |
| **II** | задній ріг (губчаста речовина, власне ядро) | аксон **перехрещується через білу спайку** на тому ж рівні → **бічний канатик** (біль, температура — **латеральний** тракт) або **передній** (грубий дотик — **передній** тракт) |
| **III** | **VPL таламуса** | заднє плече внутрішньої капсули |
| Кора | **задньоцентральна звивина** | |

Ураження: втрата болю й температури **на протилежному** боці, на 1–2 сегменти нижче ураження. **Сирингомієлія**: розрив у білій спайці → «підвісна» втрата болю й температури з обох боків при збереженні дотику.

### 2.3. Спинно-мозочкові шляхи (несвідома пропріорецепція)
| Шлях | Початок | Перехрест | Вхід у мозочок |
|---|---|---|---|
| **Задній спинно-мозочковий** (Флексига) | ядро Кларка (C8–L3), одностороннє | не перехрещується | нижня мозочкова ніжка |
| **Передній спинно-мозочковий** (Говерса) | проміжна зона | **двічі перехрещується** (у спинному мозку й у мозочку) | верхня мозочкова ніжка |
| **Клино-мозочковий** (для руки) | додаткове клиноподібне ядро | | нижня мозочкова ніжка |

Інформація не досягає свідомості; регулює координацію.

### 2.4. Шляхи обличчя
**Трійчастий шлях:** біль/температура — **ядро спинномозкового шляху V** (довгий хід від моста до C3) → перехрест → **VPM таламуса** → кора. Дотик — головне чутливе ядро V (міст) → VPM.
- Ураження довгастого мозку (синдром Валленберга): втрата болю обличчя **на боці ураження**, тіла — **на протилежному**.

### 2.5. Інші висхідні шляхи
- **Спинно-покришковий** — до верхніх горбів (рефлекс повороту голови).
- **Спинно-ретикулярний** — до сітчастої формації (біль, активація).
- **Спинно-оливний** — до оливи.

## 3. Низхідні шляхи

### 3.1. Пірамідна система

#### Кортико-спінальний шлях (*tractus corticospinalis*)
Руховий шлях до спинного мозку; керує **довільними, тонкими рухами**.

| Етап | Положення |
|---|---|
| **Початок** | пірамідні клітини V шару **моторної кори** (4), премоторної (6), соматосенсорної (3,1,2) |
| **Променистий вінець** | віялоподібний пучок |
| **Внутрішня капсула** | **заднє плече** (передні 2/3) |
| **Ніжки мозку** | середня 3/5 основи ніжки |
| **Міст** | розщеплюється пучками |
| **Довгастий мозок** | піраміди |
| **Перехрест пірамід** | на межі довгастого й спинного мозку: ~85–90% волокон переходять |

Далі:
- **Латеральний кортико-спінальний** (85–90%): бічний канатик на **протилежному** боці; закінчується в передньому розі на мотонейронах кінцівок (дистальні м'язи).
- **Передній кортико-спінальний** (10–15%): неперехрещений до сегмента, потім перехрещується; м'язи тулуба й проксимальні.

Закінчується на **α-мотонейронах** передніх рогів (прямо або через вставні нейрони).

#### Кортико-ядерний (кортико-бульбарний) шлях (*tractus corticonuclearis*)
До ядер черепних нервів. Проходить через **коліно** внутрішньої капсули. Більшість ядер мають **двобічну** кіркову іннервацію.

**Винятки (тільки протилежна кора):**
- нижня частина ядра **VII** (нижні мімічні м'язи);
- ядро **XII** (язик, частково);
- ядро **XI** (трапецієподібний; частково).

Тому при інсульті лоб (верхня частина ядра VII) **зберігається**, а нижня половина обличчя на протилежному боці паралізована.

### 3.2. Екстрапірамідна система
Керує **тонусом, поставою, автоматизованими рухами**, фоном для довільного руху.

| Шлях | Початок | Закінчення | Функція |
|---|---|---|---|
| **Руброспінальний** | червоне ядро (середній мозок), перехрещується | спинний мозок (шийні) | тонус згиначів, рухи рук |
| **Ретикулоспінальний (медіальний, латеральний)** | сітчаста формація стовбура | спинний мозок | постава, тонус, дихання, автономна регуляція |
| **Вестибулоспінальний (латеральний)** | латеральне вестибулярне ядро (Дейтерса) | спинний мозок, **односторонньо** | тонус розгиначів, рівновага |
| **Тектоспінальний** | верхні горби | шийні сегменти | рефлекторний поворот голови до зорових стимулів |
| **Кортико-понто-церебелярний** | кора → ядра моста → мозочок | | планування рухів |

### Верхній і нижній мотонейрон

| Ознака | Верхній мотонейрон (кора → передній ріг) | Нижній мотонейрон (передній ріг → м'яз) |
|---|---|---|
| **Параліч** | спастичний | в'ялий |
| **Тонус** | ↑ (складаного ножа) | ↓ |
| **Рефлекси** | ↑ (гіперрефлексія), клонуси | ↓ або відсутні |
| **Патологічні рефлекси** | **Бабінського** та ін. | немає |
| **Атрофія** | мала (від бездіяльності) | виражена |
| **Фасцикуляції** | немає | є |

#### Патологічні рефлекси (пірамідні знаки)
- **Рефлекс Бабінського**: при штриховому подразненні підошви — розгинання великого пальця, віялоподібне розходження інших. Норма у немовлят до ~2 років.
- Рефлекси Оппенгейма, Гордона, Шеффера, Россолімо, Хоффмана.

## 4. Інші важливі зв'язки

### 4.1. Зоровий шлях
1. **Сітківка** (паличкові, колбочкові → біполярні → гангліонарні клітини).
2. **Зоровий нерв** → **хіазма** (перехрещуються **носові (медіальні) половини** сітківки).
3. **Зоровий тракт** (волокна від скроневої половини свого ока і носової половини протилежного).
4. **Бічне колінчасте тіло**.
5. **Зорова променистість** (Грасіоле): через **петлю Мейєра** (скронева частка; верхні квадранти поля зору) і тім'яну частку (нижні квадранти).
6. **Зорова кора (17)**.

Поля зору: ліва половина поля зору → права зорова кора.

Рефлекторні гілки:
- До **претектальних ядер** → зіничний рефлекс.
- До **верхніх горбів** → рух очей.
- До **супрахіазматичного ядра** → циркадний ритм.

### 4.2. Слуховий шлях
Дивись [[Черепні нерви]] (VIII): завиткові ядра → верхнє оливне ядро → бічна петля → нижній горб → медіальне колінчасте тіло → слухова кора. Двобічне представництво.

### 4.3. Зіничний рефлекс
- **Аферентна дуга:** сітківка → зоровий нерв (II) → претектальне ядро.
- **Еферентна дуга:** ядро Едінгера — Вестфаля → окоруховий нерв (III) → війковий вузол → звужувач зіниці.
- **Прямий** і **співдружній** (на обох очах) відповіді.
- Ураження: **аферентний дефект зіниці** (Маркуса Ганна).

### 4.4. Лімбічні шляхи
Коло Пейпеса: див. [[Проміжний мозок і базальні ядра]].

### 4.5. Мозочкові петлі
- **Мозочок → зубчасте ядро → верхня ніжка → перехрест → червоне ядро / таламус (VL) → моторна кора → кортико-спінальний** шлях.
- **Кора → ядра моста → середня ніжка → мозочок** (замикає петлю).

## 5. Рівні перехресту

| Шлях | Де перехрещується |
|---|---|
| Кортико-спінальний (латеральний) | **довгастий мозок** (перехрест пірамід) |
| DCML (тонкий дотик, вібрація) | **довгастий мозок** (після ядер Голля/Бурдаха) |
| Спинно-таламічний (біль, температура) | **спинний мозок** (на рівні входу, в білій спайці) |
| Зоровий | **хіазма** (носові волокна) |
| Руброспінальний | середній мозок |
| Кортико-бульбарний | ядро (двобічно) |
| Задній спинно-мозочковий | не перехрещується |

## 6. Приклади локалізації за симптомами

| Ураження | Симптоми |
|---|---|
| **Внутрішня капсула (заднє плече)** | контралатеральний спастичний гемідефіцит (рука + нога + обличчя), геміанестезія |
| **Ніжка мозку** | синдром Вебера: параліч III на боці ураження + контралатеральний геміпарез |
| **Піраміда довгастого мозку** | контралатеральний геміпарез без обличчя |
| **Спинний мозок: бічний канатик** | іпсилатеральний параліч, контралатеральна втрата болю/температури нижче рівня (Броун-Секар) |
| **Спинний мозок: задній канатик** | втрата вібрації й положення на тому ж боці |
| **Таламус** | контралатеральна геміанестезія + таламічний біль |
| **Кора (S1)** | контралатеральна втрата дискримінації |

## 7. Мнемоніки

- Висхідні чутливі шляхи мають 3 нейрони й один перехрест.
- **DCML**: *Dorsal Column — Medial Lemniscus*: вібрація, положення, тонкий дотик.
- **Спинно-таламічний: Біль-Температура — перехрещується одразу.**
- **DCML перехрещується пізно** (у довгастому), **спинно-таламічний — рано** (на рівні входу).
- Верхній мотонейрон: **«Спастика + гіперрефлексія + Бабінський»**.
- Нижній мотонейрон: **«в'ялість + арефлексія + фасцикуляції + атрофія»**.
