# Проміжний мозок і базальні ядра

**Проміжний мозок** (*diencephalon*) лежить між середнім мозком і півкулями. Півкулі його обгортають. **Базальні (підкіркові) ядра** лежать у глибині півкуль і керують рухом.

## 1. Склад проміжного мозку

| Частина | Складники |
|---|---|
| **Таламічна ділянка** (*regio thalamica*) | таламус, епіталамус, метаталамус |
| **Гіпоталамус** (*hypothalamus*) | гіпоталамічна ділянка, гіпофіз, зорова хіазма, сірий горб, соскоподібні тіла |

Порожнина — **III шлуночок** (вузька щілина між таламусами). Міжшлуночковий отвір (Монро) з'єднує його з бічними шлуночками.

## 2. Таламус (*thalamus*)

**Таламус** — парне яйцеподібне скупчення сірої речовини (~3×1,5 см). Це **«воротар кори»**: майже вся чутлива інформація (крім нюху) проходить через таламус до кори.

### Положення
- Дах і бічна стінка III шлуночка.
- Латерально від нього — внутрішня капсула.
- Між таламусами — **міжталамічне зрощення** (*adhesio interthalamica*).

### Ядра таламуса
Поділяються **Y-подібною внутрішньою мозковою пластинкою** (*lamina medullaris interna*) на передню, медіальну, латеральну групи.

| Група | Ядро | Вхід | Вихід у кору |
|---|---|---|---|
| **Передня** | передні ядра | соскоподібні тіла | поясна звивина (лімбічна система, пам'ять) |
| **Медіальна** | медіодорсальне (MD) | лімбічна система, гіпоталамус | префронтальна кора |
| **Латеральна (вентральна група)** | **VPL** (*ventral posterolateral*) | медіальна петля, спинно-таламічний шлях (тіло) | постцентральна звивина |
| | **VPM** (*ventral posteromedial*) | трійчастий нерв (обличчя), смак | постцентральна звивина |
| | **VL** (*ventral lateral*) | мозочок, базальні ядра | моторна кора |
| | **VA** (*ventral anterior*) | базальні ядра | премоторна кора |
| **Заднє (метаталамус)** | **бічне колінчасте тіло** (*corpus geniculatum laterale*, LGN) | зоровий тракт | зорова кора (17-е поле) |
| | **медіальне колінчасте тіло** (MGN) | нижні горби (слух) | слухова кора (41–42) |
| **Подушка** (*pulvinar*) | | верхні горби, асоціативні зони | зорово-асоціативні зони |
| **Ретикулярне ядро** | | | гальмує інші ядра («воріт») |
| **Інтраламінарні ядра** | | сітчаста формація | пильнування, активація кори |

### Функції
1. **Релейна станція** для всіх відчуттів (дотик, біль, температура, смак, зір, слух).
2. **Моторна ланка** для мозочка й базальних ядер.
3. **Пильнування** і увага.
4. **Лімбічні зв'язки** (емоції, пам'ять).

### Клініка
- **Таламічний синдром** (Дежеріна — Руссі): геміанестезія, спонтанний **таламічний біль**, гіперпатія на протилежному боці.
- Фатальне сімейне безсоння (прионна хвороба).
- Інсульт у басейні таламо-перфорантних артерій (задня мозкова артерія).

## 3. Епіталамус (*epithalamus*)

| Структура | Функція |
|---|---|
| **Епіфіз (шишкоподібне тіло)** (*glandula pinealis*) | виділяє **мелатонін** (циркадні ритми); немає ГЕБ |
| **Повідки** (*habenulae*) | зв'язок лімбічної системи з середнім мозком |
| **Задня спайка** | зв'язок зіничних рефлексів |
| **Мозкові смужки** | |

Кальцифікація епіфіза — орієнтир на рентгені (зміщення = об'ємний процес).

## 4. Метаталамус

Два колінчасті тіла:
- **Бічне** — зоровий шлях.
- **Медіальне** — слуховий шлях.

## 5. Гіпоталамус (*hypothalamus*)

Невелика ділянка (~4 г, 0,3% мозку), але **головний центр гомеостазу** і зв'язку нервової та ендокринної систем.

### Зовнішні структури (на основі мозку)
- **Зорова хіазма** (*chiasma opticum*) — перехрест зорових нервів.
- **Сірий горб** (*tuber cinereum*) і **лійка** (*infundibulum*) → гіпофіз.
- **Соскоподібні тіла** (*corpora mamillaria*) — лімбічна система (пам'ять); зв'язок із склепінням.

### Ядра (за областями)
| Область | Ядра | Функція |
|---|---|---|
| **Передня (супраоптична)** | **супраоптичне**, **паравентрикулярне** | синтез **АДГ (вазопресину)** і **окситоцину** → задня частка гіпофіза |
| | **передні (преоптична область)** | терморегуляція (охолодження), сон |
| | **супрахіазматичне** | **біологічний годинник** (циркадний ритм) |
| **Середня (туберальна)** | **вентромедіальне** | центр насичення |
| | **дугоподібне** (*arcuate*) | вивільнювальні гормони; апетит |
| | **дорсомедіальне** | |
| **Задня (мамілярна)** | **задні ядра** | терморегуляція (нагрівання), симпатика |
| | **соскоподібні ядра** | пам'ять |
| **Латеральна область** | **латеральне ядро** | центр голоду, орексин/гіпокретин (неспання) |

### Функції гіпоталамуса
| Функція | Механізм |
|---|---|
| **Терморегуляція** | передня — тепловіддача; задня — теплопродукція |
| **Водний баланс** | осморецептори → АДГ → нирки; центр спраги |
| **Апетит** | латеральне — голод; вентромедіальне — насичення |
| **Сон — неспання** | супрахіазматичне ядро; орексин |
| **Статева поведінка і розмноження** | гонадоліберини |
| **Емоції** | зв'язок із лімбічною системою |
| **Вегетативна регуляція** | передня — парасимпатика; задня — симпатика |
| **Ендокринна регуляція** | вивільнювальні гормони (ліберини) і гальмівні (статини) → аденогіпофіз |

### Зв'язок з гіпофізом
| Частина гіпофіза | Зв'язок | Гормони |
|---|---|---|
| **Нейрогіпофіз** (задня частка) | **гіпоталамо-гіпофізарний тракт** (нервові волокна) | АДГ, окситоцин (синтезуються в гіпоталамусі, зберігаються в нейрогіпофізі) |
| **Аденогіпофіз** (передня частка) | **портальна система судин** | ліберини/статини → ТТГ, АКТГ, ФСГ, ЛГ, СТГ, пролактин |

Окремого файла про гіпофіз і ендокринну систему в палаці поки немає.

### Клініка
- **Нецукровий діабет** — дефіцит АДГ: поліурія, спрага.
- **Ожиріння** — ураження вентромедіального ядра; **кахексія** — латерального.
- **Гіпертермія** — ураження передніх ядер.
- **Гіпотермія** — ураження задніх ядер.
- **Синдром Вернике — Корсакова** — дефіцит тіаміну, ураження соскоподібних тіл (амнезія).
- **Нарколепсія** — втрата орексинових нейронів.

## 6. III шлуночок

Вузька щілина між таламусами.
- Стінки: бічні — таламуси і гіпоталамус; дно — гіпоталамус; склепіння — судинне сплетення.
- Зв'язки: **міжшлуночковий отвір** (Монро) — з бічними шлуночками; **водопровід мозку** — з IV шлуночком.
- Кишені: **зорова** (над хіазмою), **лійкова**, **надепіфізарна**, **епіфізарна**.

Деталі: [[Оболонки, шлуночки і ліквор]].

## 7. Базальні ядра (*nuclei basales*)

Групи сірої речовини в глибині півкуль. Вони **вибирають, запускають і гальмують** руху за програмою.

### Складові
| Структура | Складники |
|---|---|
| **Смугасте тіло** (*corpus striatum*) | **хвостате ядро** (*nucleus caudatus*) + **шкаралупа** (*putamen*) = **неостріатум (стріатум)**; **бліда куля** (*globus pallidus*) = палеостріатум |
| **Сочевицеподібне ядро** (*nucleus lentiformis*) | шкаралупа + бліда куля |
| **Огорожа** (*claustrum*) | тонка пластина сірої речовини |
| **Мигдалеподібне тіло** (*corpus amygdaloideum*) | лімбічна система (емоції страху) |
| **Допоміжні (функціонально)** | **чорна субстанція** (середній мозок), **субталамічне ядро** (проміжний мозок) |

### Положення
- **Хвостате ядро**: «C-подібне», навколо бічного шлуночка; голова, тіло, хвіст.
- **Шкаралупа** — латерально.
- **Бліда куля** — медіально від шкаралупи; два сегменти (зовнішній GPe і внутрішній GPi).
- **Внутрішня капсула** (*capsula interna*) проходить між хвостатим ядром, таламусом і сочевицеподібним ядром. Вона має **коліно** і два плеча (**переднє і заднє**).

### Внутрішня капсула
| Частина | Волокна |
|---|---|
| **Переднє плече** | лобно-мостові; таламо-кіркові (передні) |
| **Коліно** | кортико-ядерний (кортико-бульбарний) шлях |
| **Заднє плече** | **кортико-спінальний** шлях; таламо-кіркові (чутливі) шляхи; далі позаду й під ядром — зорова й слухова радіація |

Ураження внутрішньої капсули (лакунарний інсульт, лентикуло-стріарні гілки середньої мозкової артерії) → **контралатеральна геміплегія**, геміанестезія. Це найчастіше місце інсульту.

### Прямий і непрямий шлях
Базальні ядра працюють як «гальмо-акселератор» для кори.

| Шлях | Ефект на рух | Нейрони стріатума | Медіатор |
|---|---|---|---|
| **Прямий** (*direct*) | **запускає** рух | D₁ | дофамін збуджує |
| **Непрямий** (*indirect*) | **гальмує** небажані рухи | D₂ | дофамін гальмує |

Дофамін чорної субстанції → стріатум: збуджує прямий і гальмує непрямий шляхи → загальне полегшення руху.

## 8. Захворювання базальних ядер

| Хвороба | Патологія | Симптоми |
|---|---|---|
| **Паркінсона** | загибель дофамінергічних нейронів чорної субстанції (*pars compacta*) | тремор спокою («скочування пігулок»), ригідність («зубчасте колесо»), брадикінезія, постуральна нестабільність; лікування — леводопа |
| **Гентінгтона** | дегенерація хвостатого ядра (аутосомно-домінантна, CAG-повтори, 4-та хромосома) | хорея, деменція, психічні розлади |
| **Гемібалізм** | ураження субталамічного ядра | розмашисті рухи кінцівки на протилежному боці |
| **Хвороба Вільсона** | накопичення міді (ген ATP7B) | тремор, дистонія, кільце Кайзера — Флейшера |
| **Дистонії**, **атетоз**, **тики**, **Туретта** | | |
| **Пізня дискінезія** | довге лікування нейролептиками | |

- **Ригідність** при Паркінсоні — рівномірний опір («свинцева труба», із зубчастим колесом).
- **Спастичність** (пірамідна) — «складаного ножа»: різко зростає й падає.

## 9. Лімбічна система

Група структур, що керують **емоціями, мотивацією і пам'яттю**.

| Структура | Функція |
|---|---|
| **Гіпокамп** | формування довготривалої пам'яті |
| **Мигдалеподібне тіло** | страх, агресія, емоційна пам'ять |
| **Поясна звивина** | емоції, увага, біль |
| **Склепіння** (*fornix*) | гіпокамп → соскоподібні тіла |
| **Соскоподібні тіла** | пам'ять |
| **Передні ядра таламуса** | |
| **Парагіпокампальна звивина**, **енторинальна кора** | |
| **Гіпоталамус**, **перегородка** | |

**Коло Пейпеса**: гіпокамп → склепіння → соскоподібні тіла → передні ядра таламуса → поясна звивина → парагіпокампальна звивина → гіпокамп.

Хвороба Альцгеймера починається з **гіпокампа і енторинальної кори** (втрата короткочасної пам'яті).

## 10. Мнемоніки

- Ядра гіпоталамуса: **«ЛГ — голод, ВМ — ситість»** («Латеральне — голодний, ВентроМедіальне — ситий»); у разі ураження — відповідно **худнення** і **ожиріння**.
- Таламус = «**воротар**» кори: усе, крім нюху.
- Паркінсон: тремор спокою, ригідність, брадикінезія — **«ТРБП»**.
- Внутрішня капсула: **коліно — обличчя** (кортико-ядерні), **заднє плече — тіло** (кортико-спінальні).
