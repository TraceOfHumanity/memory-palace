# Неврологічне обстеження і синдроми

Це зведення того, як визначити **рівень ураження** нервової системи за ознаками. Правило: спочатку запитай «де?», потім «що?».

## 1. Логіка локалізації

1. **Верхній чи нижній мотонейрон?** (спастика чи в'ялість)
2. **Який рівень?** кора, внутрішня капсула, стовбур, спинний мозок, корінець, сплетення, нерв, нервово-м'язовий синапс, м'яз.
3. **Який бік?** Пам'ятай про перехрести.
4. **Один чи кілька вогнищ?** (один: інсульт, пухлина; кілька: розсіяний склероз, метастази).
5. **Як швидко?** (секунди — судинне; години — запалення; тижні — пухлина; роки — дегенерація).

| **Хода і постава** | |

## 3. Шкала коми Глазго (*Glasgow Coma Scale*)

Сума трьох оцінок: 3–15.

| Реакція | Бали |
|---|---|
| **Відкривання очей (E)** | спонтанно 4; на мову 3; на біль 2; немає 1 |
| **Мовна реакція (V)** | орієнтований 5; сплутана 4; окремі слова 3; звуки 2; немає 1 |
| **Рухова реакція (M)** | виконує команди 6; локалізує біль 5; відсмикує 4; **декортикація** 3; **децеребрація** 2; немає 1 |

- 15 — ясна свідомість; 13–14 — легке порушення; 9–12 — помірне; **≤ 8 — кома** (потрібна інтубація: «8 — час інтубувати»).
- **Декортикаційна ригідність**: руки зігнуті до грудей, ноги розігнуті — ураження вище червоного ядра.
- **Децеребраційна ригідність**: руки й ноги розігнуті, пронація — ураження нижче червоного ядра (стовбур). Гірший прогноз.

## 4. Руховий огляд

### Сила (шкала MRC, 0–5)
| Бал | Опис |
|---|---|
| **0** | немає скорочення |
| **1** | видно слід скорочення |
| **2** | рух без сили тяжіння |
| **3** | рух проти сили тяжіння |
| **4** | рух проти помірного опору |
| **5** | норма |

### Тонус
- **Спастичність** (пірамідна): підвищення при швидкому русі, симптом **складаного ножа**; мінімально в розгиначах ніг і згиначах рук.
- **Ригідність** (екстрапірамідна): рівномірна («свинцева труба»); з тремором — **зубчасте колесо**.
- **Гіпотонія**: мозочок, нижній мотонейрон.

### Рефлекси (оцінка 0–4+)
| Рефлекс | Сегмент | Нерв |
|---|---|---|
| **Біцепс** | C5–C6 | м'язово-шкірний |
| **Брахіорадіальний** | C5–C6 | променевий |
| **Трицепс** | C7–C8 | променевий |
| **Колінний** | L2–L4 | стегновий |
| **Ахілловий** | S1–S2 | великогомілковий |
| **Черевні (верхні, середні, нижні)** | T7–T12 | міжреброві |
| **Підошвовий** | L5–S2 | великогомілковий |
| **Кремастерний** | L1–L2 | статево-стегновий |
| **Анальний** | S4–S5 | статевий |

Ступені: 0 — немає; 1+ — знижений; 2+ — норма; 3+ — підвищений; 4+ — клонус.

### Патологічні рефлекси
- **Бабінського** (розгинання великого пальця) — **ураження верхнього мотонейрона**.
- **Хоффмана** — згинання пальців при ударі по кінчику середнього.
- Клонус стопи.

## 5. Чутливість

- **Поверхнева**: біль (голка), температура, дотик.
- **Глибока**: вібрація (камертон 128 Гц), положення суглобів, стереогноз, дискримінація двох точок.
- **Розподіл**: за дерматомами (корінцевий), нервом (периферичний), «рукавичка–шкарпетка» (полінейропатія), «підвісний» (сирингомієлія), геміанестезія (таламус, капсула), сегментарний рівень (спинний мозок).

## 6. Координація і хода

| Проба | Що перевіряє |
|---|---|
| Пальце-носова | мозочок |
| П'ятково-колінна | мозочок |
| Адіадохокінез | мозочок |
| **Ромберга** | глибока чутливість / вестибулярний апарат |
| Ходьба по лінії (тандем) | мозочок |

### Типи хід
| Хода | Причина | Опис |
|---|---|---|
| **Спастична (геміплегічна)** | пірамідний шлях | нога розігнута, «косить» півколом, рука зігнута |
| **Степаж (півнева)** | малогомілковий нерв | стопа звисає, високе піднімання коліна |
| **Паркінсонічна** | базальні ядра | дрібні кроки, згорблена, відсутність розмаху рук, «застигання» |
| **Атактична** | мозочок / сенсорна | широко розставлені ноги, хитка |
| **«Качина»** | слабкість сідничних м'язів (проксимальна міопатія) | перевалювання таза |
| **Апраксична (магнітна)** | лобові частки | ноги «прилипають» |
| **Хода при нормотензивній гідроцефалії** | порушення лобових зв'язків | широкий крок, «прилипає» до підлоги |

## 7. Менінгеальні знаки

Ригідність потиличних м'язів, симптоми Керніга й Брудзинського. Див. [[Оболонки, шлуночки і ліквор]].

## 8. Основні синдроми за рівнем

### 8.1. Кора
| Частка | Синдром |
|---|---|
| **Лобова** | параліч, афазія Брока, зміна особистості, лобова деменція |
| **Тім'яна** | апраксія, агнозія, гемінеглект, акалькулія |
| **Скронева** | афазія Верніке, квадрантна геміанопсія, судоми, прозопагнозія |
| **Потилична** | геміанопсія, зорова агнозія |

### 8.2. Підкіркові (білі речовина, капсула)
- **Внутрішня капсула** — контралатеральна **чиста рухова** геміплегія (лакунарний інсульт).
- **Таламус** — геміанестезія + таламічний біль.

### 8.3. Базальні ядра (екстрапірамідні)
- **Паркінсонізм**: тремор спокою, ригідність, брадикінезія.
- **Хорея** (Гентінгтон), **атетоз**, **гемібалізм**, **дистонія**.

### 8.4. Стовбур
Усі синдроми — **«перехресні»**: ураження черепного нерва на боці вогнища + контралатеральний геміпарез.
| Рівень | Синдром |
|---|---|
| Середній мозок | **Вебера** (III + геміплегія), **Бенедикта** (III + тремор) |
| Міст | **Мілларда — Гублера** (VII + геміплегія), **Фовіля** (VI, VII), «замкнена людина» |
| Довгастий мозок | **Валленберга** (бічний), **Дежеріна** (медіальний) |

### 8.5. Мозочок
Атаксія, дисметрія, інтенційний тремор, ністагм, скандована мова — на боці вогнища.

### 8.6. Спинний мозок
| Синдром | Опис |
|---|---|
| **Повна поперечна травма** | втрата руху, чутливості нижче рівня; спочатку спінальний шок |
| **Броун-Секара** | ізольований парез + втрата вібрації на боці ураження; втрата болю й температури на протилежному |
| **Передньої спинномозкової артерії** | параліч + втрата болю й температури нижче рівня при збереженні вібрації |
| **Центрального каналу (сирингомієлія)** | «підвісна» втрата болю й температури, слабкість рук |
| **Заднього канатика** | втрата вібрації/положення, сенсорна атаксія |
| **Конуса і кінського хвоста** | сфінктери, сідлова анестезія |
| **Бічний аміотрофічний склероз** | змішані верхній + нижній мотонейрони, без чутливих порушень |
| **Поліомієліт** | асиметричний в'ялий параліч (передні роги) |

### 8.7. Корінці, сплетення, нерви
- **Радикулопатія**: біль + слабкість + втрата рефлексу за сегментом. Див. [[Спинномозкові нерви і сплетення]].
- **Плексопатія**: ураження кількох нервів однієї кінцівки (Ерба, Клюмпке).
- **Мононейропатія**: один нерв (карпальний канал, малогомілковий, ліктьовий). Див. [[Плечове сплетення і нерви верхньої кінцівки]], [[Поперекове і крижове сплетення]].
- **Полінейропатія**: симетричні «шкарпетки–рукавички» (діабет, алкоголь, B₁₂).
- **Множинна мононейропатія**: кілька нервів асиметрично (васкуліт).

### 8.8. Нервово-м'язовий синапс і м'яз
| Захворювання | Ознаки |
|---|---|
| **Міастенія** (*myasthenia gravis*) | вечірня втома, птоз, диплопія; антитіла до ACh-рецепторів |
| **Синдром Ламберта — Ітона** | проксимальна слабкість, поліпшення при навантаженні; паранеопластичний (дрібноклітинний рак легені) |
| **Ботулізм** | низхідний параліч; токсин блокує вивільнення ACh |
| **Міопатії** | проксимальна слабкість, рефлекси збережені |
| **Міопатія Дюшена** | у хлопчиків; псевдогіпертрофія литок, симптом Говерса |

## 9. Часті захворювання

| Хвороба | Суть | Ключова ознака |
|---|---|---|
| **Ішемічний інсульт** | закупорка мозкової артерії | раптове вогнищеве порушення |
| **Геморагічний інсульт** | розрив судини | раптовий головний біль, зниження свідомості |
| **Розсіяний склероз** | аутоімунна демієлінізація | різні вогнища «у часі й просторі»; неврит зорового нерва, міжядерна офтальмоплегія |
| **Епілепсія** | повторні напади | судоми; ЕЕГ |
| **Хвороба Паркінсона** | загибель нейронів чорної субстанції | тремор, ригідність, брадикінезія |
| **Хвороба Альцгеймера** | амілоїд, тау | втрата короткочасної пам'яті |
| **Мігрень** | судинно-нервовий | односторонній пульсівний біль, аура, фото- і фонофобія |
| **Менінгіт** | інфекція оболонок | лихоманка, ригідність потилиці, головний біль |
| **Енцефаліт** | запалення мозку | лихоманка, порушення свідомості, судоми |
| **Пухлини мозку** | гліома, менінгіома, метастази | головний біль, судоми, вогнищеві симптоми |
| **Синдром Гійєна — Барре** | аутоімунна демієлінізація ПНС | висхідний в'ялий параліч, арефлексія |
| **Бічний аміотрофічний склероз** | загибель мотонейронів | прогресуюча слабкість без чутливих розладів |
| **Невралгія трійчастого нерва** | стиснення | стріляючий біль на обличчі |
| **Параліч Белла** | периферичний параліч VII | перекошене обличчя, лоб не морщиться |
| **Радикулопатія** | грижа диска | біль «простріл» по дерматому |

### Епілепсія: типи нападів
- **Фокальні** (парціальні): починаються в одній ділянці; свідомість збережена або порушена.
- **Генералізовані**: тоніко-клонічні («гранд мал»), абсанси (дитинство, ЕЕГ 3 Гц), міоклонічні.
- **Status epilepticus** — напад > 5 хв: невідкладний стан.

### Мігрень: фази
Продром → аура → головний біль → постдром.

## 12. Мнемоніки

- **«Де чи що?»**: спочатку локалізація, потім причина.
- **Верхній мотонейрон — «Все вгору»** (тонус, рефлекси ↑); **нижній — «Все вниз»** (тонус, рефлекси ↓, атрофія).
- Мозочок — **той самий** бік; кора — **протилежний**.
- Стовбур: «**нерв на боці, тіло — навпаки**».
- Інсульт: **FAST**.
