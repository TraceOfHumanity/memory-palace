# React: `useDebugValue`

Виміряно на React 18.3.1 (`react-test-renderer`).

## 1. Що це

`useDebugValue(value, format?)` додає **мітку до кастомного хука** в **React DevTools** (вкладка Components → hooks). На роботу застосунку **не впливає**: нічого не повертає, не змінює рендер.

```jsx
function useOnlineStatus() {
  const isOnline = useSyncExternalStore(subscribe, getSnapshot);
  useDebugValue(isOnline ? "Online" : "Offline");     // у DevTools: OnlineStatus: "Online"
  return isOnline;
}
```
У DevTools поруч із назвою хука (без префікса `use`) з'явиться `"Online"`.

## 2. Другий аргумент — форматер

```jsx
useDebugValue(date, (d) => d.toISOString());
```
Функція форматування викликається **лише коли DevTools відкриті й розгортають хук** — для дорогих перетворень. Виміряно: у звичайному рендері форматер **не викликається** (лог `formatter called?` не з'явився); хук відрендерився 1 раз.

## 3. Коли використовувати

- У **кастомних хуках бібліотек**, коли важливо показати стан (`status`, `isLoading`, `value`) без відкриття внутрішніх `useState`.
- Не потрібен у кожному кастомному хуку — DevTools і так показують стан внутрішніх вбудованих хуків (`useState`, `useRef`, …).
- Для дорогих значень — використовуй форматер.

## 4. Обмеження

- Працює лише в **кастомних хуках**, не в «звичайних» компонентах (там DevTools показують пропси й стан).
- Лише розробка/DevTools; у production він нічого не робить корисного (не прибирає, але не впливає).
- Не місце для логіки: значення — лише для відображення.

## 5. Типові помилки

1. Дорогі обчислення в аргументі `value` (виконуються щоразу) — використовуй форматер.
2. Вважати, що це `console.log` — у консолі нічого не з'явиться.
3. Додавати до кожного хука бездумно — шум.
4. Розраховувати на побічні ефекти (форматер може не викликатись зовсім).
5. Умовний виклик (порушення правил хуків).

## 6. Алгоритм

1. Пишеш бібліотечний кастомний хук? Додай `useDebugValue(зрозуміла мітка)`.
2. Дороге перетворення → другий аргумент-форматер.
3. Перевір у React DevTools → Components, що мітка відображається.
