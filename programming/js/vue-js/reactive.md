# Vue 3: `reactive`, `readonly`, `shallowReactive`, `markRaw`

Виміряно на Vue 3.5.44 (`vue`, `jsdom`). Теорія: [reactivity.md](reactivity.md).

## 1. Що це

`reactive(obj)` повертає **Proxy** над об'єктом (масивом, `Map`, `Set`), через який Vue відстежує читання й запис **кожної властивості** на будь-якій глибині. Звертаєшся як до звичайного об'єкта — **без `.value`**.

```js
const state = reactive({ count: 0, user: { name: "Ann" } });
state.count++;               // запускає залежних
state.user.name = "Bo";      // глибоко — теж
```

## 2. Як це працює

- Пастка `get`: читання `state.count` → **track** (запам'ятати «ефект E читав властивість `count` цього об'єкта»).
- Пастка `set`/`deleteProperty`/`has`/`ownKeys`: запис → **trigger** (запустити ефекти, що залежать саме від цієї властивості).
- Вкладені об'єкти перетворюються на проксі **ліниво**, при першому доступі.

Виміряно: додавання й видалення властивостей відстежується (у Vue 3 на відміну від Vue 2): ефект `Object.keys(p)` дав `["n"] | ["n","added"] | ["n"]`.

## 3. Ідентичність проксі

```js
const raw = { x: 1 };
const rx = reactive(raw);
rx === raw;               // false (проксі ≠ оригінал)
reactive(rx) === rx;      // true  (повторне обгортання повертає той самий проксі)
toRaw(rx) === raw;        // true
```
Мутація `raw` **напряму** реактивність не запускає (оминає проксі) — працюй із проксі.
Пошук у реактивному масиві: `arr.push(raw); arr.includes(raw)` → `true`, `indexOf` → `0` (Vue виправляє пошук за сирим значенням).

## 4. Масиви, `Map`, `Set`

Усі колекції реактивні: `reactive(new Map())` — ефект на `m.size` перераховується після `m.set("a", 1)` (`size=0 | size=1`). Мутувальні методи масиву (`push`, `splice`…) відстежуються.

## 5. Пастки

1. **Деструктуризація втрачає реактивність:** `const { a } = state` → `a` — звичайне число. Рішення: `toRefs(state)` ([toRefs.md](toRefs.md)).
2. **Заміна об'єкта втрачає зв'язок.** Виміряно: компонент рендерить `st.n`; після `st = reactive({ n: 2 })` DOM залишається `<p>1</p>`, і навіть `st.n = 3` нічого не змінює (`<p>1</p>`): рендер підписаний на **старий** проксі. Рішення: мутувати наявний (`Object.assign(state, { n: 2 })` — виміряно, працює), або використовувати `ref`.
3. **Лише об'єкти:** примітив у `reactive` не обгорнути (`reactive(1)` повертає `1` + попередження).
4. **`ref` у `reactive` розгортається** (`reactive({ r: ref(5) }).r` → `5`), але **в масиві/Map — ні** (`reactive([ref(1)])[0]` лишається ref).
5. **`watch(state.n, …)`** — передається число → `Invalid watch source`; потрібен геттер `() => state.n`.
6. **Складні об'єкти класів** (DOM-вузли, екземпляри бібліотек) краще `markRaw` або `shallowRef`.

## 6. `readonly`

`readonly(obj)` — проксі, що **забороняє запис**. Виміряно: `ro.a = 2` ігнорується (`a` лишилось `1`), консоль: `[Vue warn] Set operation on key "a" failed: target is readonly.` Корисно для передачі стану вниз (provide/inject) без права зміни. `isReadonly(readonly({}))` → `true`. Пропси компонента теж readonly: `props.n = 5` → те саме попередження.

## 7. `shallowReactive`

Реактивний лише **перший рівень**: `isReactive(shallowReactive({ nested: {} }).nested)` → `false`. Для великих структур або зовнішніх об'єктів.

## 8. `markRaw`

`markRaw(obj)` позначає об'єкт «ніколи не проксувати»: `isReactive(reactive({ big }).big)` → `false`. Для великих незмінних даних, екземплярів класів, компонентів-об'єктів (Vue попереджає: «Vue received a Component that was made a reactive object» — використай `markRaw`/`shallowRef`).

## 9. Корисні перевірки

`isReactive`, `isReadonly`, `isProxy`, `isRef`, `toRaw`, `toRef`, `toRefs`.

## 10. `reactive` чи `ref`

Vue рекомендує **`ref` за замовчуванням** (працює з примітивами, можна замінювати значення повністю). `reactive` — для згрупованого стану форми, коли ти не будеш замінювати об'єкт цілком і не деструктуруєш.

## 11. Типові помилки

1. Деструктуризація `reactive`.
2. Присвоєння нового об'єкта змінній `reactive`.
3. Очікувати реактивності від мутації `raw`.
4. Передати `state.prop` у `watch`.
5. Покласти великі/чужі об'єкти без `markRaw`/`shallowRef`.
6. Порівнювати проксі й оригінал через `===`.
7. Рефи в реактивних масивах без `.value`.

## 12. Алгоритм

1. Група пов'язаних полів, які не замінюються цілком → `reactive`.
2. Один примітив чи значення, що замінюється → `ref`.
3. Деструктурувати → `toRefs`.
4. Заборонити запис вниз → `readonly`.
5. Великі/сторонні об'єкти → `markRaw` / `shallowReactive` / `shallowRef`.
