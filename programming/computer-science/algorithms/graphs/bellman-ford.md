# Bellman–Ford — алгоритм Беллмана—Форда

Беллман—Форд знаходить найкоротші шляхи від однієї вершини в графі, де ваги ребер **можуть бути від'ємними**, і **виявляє від'ємні цикли**. Він повільніший за Дейкстру (`O(V·E)` проти `O((V + E) log V)`), зате простіший, не потребує пріоритетної черги й працює там, де Дейкстра ламається: курси валют (арбітраж), системи обмежень, маршрутизація RIP, найкоротші шляхи з обмеженою кількістю ребер.

## 1. Ідея: релаксація всіх ребер, `V − 1` разів

**Релаксація** ребра `(u → v, w)`: якщо `dist[u] + w < dist[v]`, то `dist[v] = dist[u] + w`.

Алгоритм:

1. `dist[s] = 0`, решта `∞`.
2. Повторити `V − 1` разів: для **кожного** ребра виконати релаксацію.
3. Ще один (V-й) прохід: якщо якесь ребро все ще можна релаксувати — у графі є **від'ємний цикл**, досяжний із `s`.

**Чому `V − 1` проходів?** Найкоротший простий шлях має не більше `V − 1` ребер. Після `i`-го проходу `dist[v]` не гірша за найкоротший шлях із не більше `i` ребрами (інваріант). Індукція: шлях із `i` ребрами — це шлях із `i − 1` ребер плюс останнє ребро, яке релаксується в `i`-му проході. Тому після `V − 1` проходів усі відстані остаточні.

**Від'ємний цикл.** Якщо цикл має сумарну вагу `< 0`, то кожен обхід цього циклу зменшує відстань — і нескінченна релаксація ніколи не зупиниться. Тому V-й прохід, який ще щось змінює, — доказ існування від'ємного циклу. Найкоротшого шляху в такому разі не існує (він «мінус нескінченність»).

## 2. Приклад

Орієнтований граф: `A→B (4)`, `A→C (5)`, `B→C (−3)`, `C→D (4)`, `B→D (6)`. Найкоротші від `A`: `[0, 4, 1, 5, Infinity]` (вершини: A=0, B=1, C=2, D=3; індекс 4 — ізольована). `A→B→C` коштує `4 − 3 = 1`, що краще за пряме `A→C (5)`.

Трасування проходів (стан `dist` після кожного):

- початок: [0, Infinity, Infinity, Infinity, Infinity]
- прохід 1: [0, 4, 1, 5, Infinity]
- прохід 2: [0, 4, 1, 5, Infinity]

Зверніть увагу: порядок ребер у списку впливає на кількість **потрібних** проходів; ранній вихід, коли за прохід нічого не змінилось, прискорює типові випадки.

## 3. Реалізація

```js
const edgesNeg = [
  [0, 1, 4],
  [0, 2, 5],
  [1, 2, -3],
  [2, 3, 4],
  [1, 3, 6],
];

function bellmanFord(n, edges, s) {
  const dist = new Array(n).fill(Infinity);
  const parent = new Array(n).fill(-1);
  dist[s] = 0;
  let passes = 0;
  for (let i = 0; i < n - 1; i++) {
    let changed = false;
    for (const [u, v, w] of edges) {
      if (dist[u] !== Infinity && dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        parent[v] = u;
        changed = true;
      }
    }
    passes++;
    if (!changed) break;
  }
  let negCycle = false;
  for (const [u, v, w] of edges) {
    if (dist[u] !== Infinity && dist[u] + w < dist[v]) negCycle = true;
  }
  return { dist, parent, negCycle, passes };
}

function bellmanFordTrace(n, edges, s) {
  const dist = new Array(n).fill(Infinity);
  dist[s] = 0;
  const out = ['початок: [' + dist.join(', ') + ']'];
  for (let i = 1; i < n; i++) {
    let changed = false;
    for (const [u, v, w] of edges) {
      if (dist[u] !== Infinity && dist[u] + w < dist[v]) { dist[v] = dist[u] + w; changed = true; }
    }
    out.push('прохід ' + i + ': [' + dist.join(', ') + ']');
    if (!changed) break;
  }
  return out;
}

function pathTo(parent, t) {
  const path = [];
  for (let v = t; v !== -1; v = parent[v]) path.push(v);
  return path.reverse();
}

function negativeCycleVertices(n, edges) {
  const dist = new Array(n).fill(0);
  const parent = new Array(n).fill(-1);
  let last = -1;
  for (let i = 0; i < n; i++) {
    last = -1;
    for (const [u, v, w] of edges) {
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        parent[v] = u;
        last = v;
      }
    }
  }
  if (last === -1) return null;
  for (let i = 0; i < n; i++) last = parent[last];
  const cycle = [];
  for (let v = last; ; v = parent[v]) {
    cycle.push(v);
    if (v === last && cycle.length > 1) break;
  }
  return cycle.reverse();
}

function spfa(n, edges, s) {
  const adj = Array.from({ length: n }, () => []);
  for (const [u, v, w] of edges) adj[u].push([v, w]);
  const dist = new Array(n).fill(Infinity);
  const inQ = new Array(n).fill(false);
  const cnt = new Array(n).fill(0);
  dist[s] = 0;
  const q = [s];
  inQ[s] = true;
  for (let h = 0; h < q.length; h++) {
    const v = q[h];
    inQ[v] = false;
    for (const [u, w] of adj[v]) {
      if (dist[v] + w < dist[u]) {
        dist[u] = dist[v] + w;
        if (!inQ[u]) {
          if (++cnt[u] >= n) return null;
          q.push(u);
          inQ[u] = true;
        }
      }
    }
  }
  return dist;
}

function cheapestWithinKStops(n, flights, src, dst, k) {
  let dist = new Array(n).fill(Infinity);
  dist[src] = 0;
  for (let i = 0; i <= k; i++) {
    const next = dist.slice();
    for (const [u, v, w] of flights) if (dist[u] + w < next[v]) next[v] = dist[u] + w;
    dist = next;
  }
  return dist[dst] === Infinity ? -1 : dist[dst];
}

function hasArbitrage(rates) {
  const n = rates.length;
  const edges = [];
  for (let i = 0; i < n; i++) for (let j = 0; j < n; j++) if (i !== j) edges.push([i, j, -Math.log(rates[i][j])]);
  const dist = new Array(n).fill(0);
  for (let k = 0; k < n; k++) {
    let ch = false;
    for (const [u, v, w] of edges) if (dist[u] + w < dist[v] - 1e-12) { dist[v] = dist[u] + w; ch = true; }
    if (!ch) return false;
  }
  return true;
}

function differenceConstraints(n, constraints) {
  const edges = constraints.map(([i, j, c]) => [j, i, c]);
  for (let i = 0; i < n; i++) edges.push([n, i, 0]);
  const r = bellmanFord(n + 1, edges, n);
  return r.negCycle ? null : r.dist.slice(0, n);
}
```

## 4. Виявлення від'ємного циклу й відновлення

Якщо `V`-й прохід ще релаксує ребро — цикл існує. Щоб його **знайти**: запам'ятати вершину `x`, що була оновлена на останньому проході, і пройти `V` кроків по `parent`, щоб гарантовано потрапити **всередину** циклу, потім обійти його.

`bellmanFord(3, [[0, 1, 1], [1, 2, -1], [2, 0, -1]], 0).negCycle` = `true` (цикл `0→1→2→0` має вагу `−1`). `negativeCycleVertices(3, [[0, 1, 1], [1, 2, -1], [2, 0, -1]])` = `[0, 1, 2, 0]`. Для `edgesNeg` циклу немає: `false`.

**Нюанс.** Від'ємний цикл, **недосяжний** з `s`, не шкодить відстаням від `s` (до нього не дійти); саме тому в `bellmanFord` перевіряємо `dist[u] !== Infinity`.

## 5. Застосування

- **Арбітраж валют.** Курси `rate[i][j]`; цикл, добуток коефіцієнтів якого `> 1`, дає прибуток. Беремо `−log(rate)` — добуток стає сумою, а `> 1` — від'ємним циклом: `hasArbitrage([[1, 0.5, 0.2], [2, 1, 0.4], [5.1, 2.5, 1]])` = `true`, а для узгоджених курсів `[[1, 2], [0.5, 1]]` — `false`.
- **Найдешевший переліт із не більше `k` пересадками:** обмежена кількість проходів = обмеження на кількість ребер: `cheapestWithinKStops(3, [[0, 1, 100], [1, 2, 100], [0, 2, 500]], 0, 2, 1)` = `200`. Тут важливо **копіювати** `dist` перед проходом (оновлюємо `next`), інакше шлях може використати більше ребер, ніж дозволено.
- **Системи різницевих обмежень** `x_j − x_i ≤ c`: ребро `i → j` із вагою `c`; розв'язок існує тоді й лише тоді, коли немає від'ємного циклу. `differenceConstraints(3, [[1, 0, 2], [2, 1, 3], [0, 2, -4]])` = `[-4, -2, 0]` (допустимі значення змінних `x0, x1, x2`).
- **Маршрутизація RIP** (розподілений Беллман—Форд): кожен роутер обмінюється таблицями відстаней із сусідами; обмеження «15 стрибків».
- **Перший крок алгоритму Джонсона** для усіх пар із від'ємними вагами.

## 6. Оптимізація SPFA

**SPFA** (Shortest Path Faster Algorithm) тримає чергу лише тих вершин, чия відстань **змінилась**, і релаксує тільки їхніх сусідів. Середня швидкість — близько `O(E)` на випадкових графах, найгірша — все ще `O(V·E)`. Від'ємний цикл виявляється за лічильником вставок (`≥ V`). `spfa(5, edgesNeg, 0)` = `[0, 4, 1, 5, Infinity]`.

## 7. Складність

- **Час:** `O(V·E)` — `V − 1` проходів по `E` ребрах (з ранньою зупинкою часто значно менше).
- **Пам'ять:** `O(V)` (+ `E` для списку ребер).
- Для графа з 1000 вершин і 5000 ребер — 5 мільйонів релаксацій у найгіршому випадку; Дейкстра — десятки тисяч. Тому Беллман—Форд обирають лише при від'ємних вагах.

| | Ваги | Час |
|---|---|---|
| BFS | рівні | `O(V + E)` |
| Дейкстра | `≥ 0` | `O((V + E) log V)` |
| Беллман—Форд | будь-які | `O(V·E)` |
| Флойд—Воршелл (усі пари) | будь-які | `O(V³)` |
| DAG + топологічний порядок | будь-які | `O(V + E)` |

## 8. Типові помилки

1. **Релаксувати з `dist[u] = ∞`:** `∞ + (−3)` усе ще `∞`, але в інших мовах `INF + w` переповнюється; завжди перевіряйте.
2. **Обмеження на кількість ребер без копії `dist`** — шлях використає більше ребер, ніж дозволено.
3. **Проходів `V` замість `V − 1`** для відстаней (`V`-й — перевірка циклу).
4. **Вважати, що від'ємний цикл є завжди «поганим»:** недосяжний із `s` не впливає.
5. **Неорієнтований граф із від'ємним ребром** — це вже від'ємний цикл (`u → v → u`).
6. **Використовувати для графа без від'ємних ваг** — Дейкстра швидше.
7. **Відновлення шляху при від'ємному циклі** — шлях не визначений.
8. **Плутати «від'ємний цикл» і «від'ємну вагу».**

## 9. Алгоритм (стисло)

1. `dist[s] = 0`, інші `∞`.
2. `V − 1` разів: для всіх ребер `(u, v, w)` — `dist[v] = min(dist[v], dist[u] + w)`; якщо нічого не змінилось — зупинитись.
3. Ще один прохід: якщо щось змінилось — від'ємний цикл.
4. Час `O(V·E)`, пам'ять `O(V)`.
