# Convex Hull — опукла оболонка

**Опукла оболонка** множини точок на площині — найменший **опуклий багатокутник**, що містить усі точки. Уявіть цвяхи, вбиті в дошку, і гумову стрічку, натягнуту навколо всіх: її контур — це опукла оболонка. Задача лежить в основі обчислювальної геометрії: розпізнавання образів, комп'ютерна графіка, зіткнення об'єктів у іграх, геоінформатика, діаметр множини точок, найближчі пари. Класичні алгоритми: **Джарвіса** (`O(n·h)`), **Грема** і **Ендрю (monotone chain)** (`O(n log n)`).

## 1. Основа: векторний (перехресний) добуток та орієнтація

Для трьох точок `a, b, c` розглянемо `cross(a, b, c) = (b.x − a.x)·(c.y − a.y) − (b.y − a.y)·(c.x − a.x)` — **знакова подвоєна площа** трикутника.

- `> 0` — поворот **проти годинникової стрілки** (ліво): `c` ліворуч від променя `a → b`;
- `< 0` — **за годинниковою** (право);
- `= 0` — точки **колінеарні**.

Опукла оболонка проти годинникової стрілки складається лише з **лівих поворотів**. Тому алгоритми будуються на видаленні точок, що створюють правий (або нульовий) поворот. Цілі координати дають **точний** результат — важливо для колінеарних випадків.

`cross([0, 0], [4, 0], [2, 3])` = `12` (ліво), `cross([0, 0], [4, 0], [2, -3])` = `-12` (право), `cross([0, 0], [2, 2], [4, 4])` = `0` (на одній прямій).

## 2. Алгоритм Ендрю (monotone chain)

1. Відсортувати точки за `(x, y)`.
2. Побудувати **нижню** оболонку: проходячи точки зліва направо, тримати стек; поки останні дві точки зі стека й нова утворюють **неліве** (`cross ≤ 0`) повертання — видалити вершину стека; додати точку.
3. Так само **верхню** оболонку — зі зворотного проходу.
4. З'єднати (відкинути повторювані кінці).

Сортування `O(n log n)`, обидва проходи `O(n)` (кожна точка додається й видаляється раз). **Загальний час `O(n log n)`**.

Приклад: точки `[[0, 0], [2, 1], [4, 0], [4, 4], [0, 4], [2, 2], [1, 3], [3, 3]]` → оболонка `[[0, 0], [4, 0], [4, 4], [0, 4]]` (чотири кути; решта точок — усередині чотирикутника, зокрема `[2, 1]` лежить над нижньою стороною `[0,0]–[4,0]`).

Трасування стеку нижньої оболонки:

- [(0,0)]
- [(0,0) (0,4)]
- [(0,0) (1,3)]
- [(0,0) (2,1)]
- [(0,0) (2,1) (2,2)]
- [(0,0) (2,1) (3,3)]
- [(0,0) (4,0)]
- [(0,0) (4,0) (4,4)]

## 3. Алгоритм Джарвіса (gift wrapping)

Починаємо з найлівішої точки; на кожному кроці обираємо наступну вершину так, щоб усі решта точок були **ліворуч** від ребра (максимально «правий» вектор). Складність `O(n·h)`, де `h` — кількість вершин оболонки: чудовий, коли `h` малий; у найгіршому (усі точки на колі) — `O(n²)`. **Вихідно-чутливий** алгоритм: найшвидший вихідно-чутливий — Чана `O(n log h)`.

## 4. Алгоритм Грема

Вибирають найнижчу точку, сортують решту за **полярним кутом** навколо неї, обходять із стеком і видаленням правих поворотів. `O(n log n)`. Ендрю — його зручна версія без кутів (лише сортування за координатами).

## 5. Реалізація

```js
function cross(a, b, c) {
  return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0]);
}

function sortPoints(points) {
  return points
    .map((p) => p.slice())
    .sort((p, q) => p[0] - q[0] || p[1] - q[1])
    .filter((p, i, a) => i === 0 || p[0] !== a[i - 1][0] || p[1] !== a[i - 1][1]);
}

function convexHull(points) {
  const pts = sortPoints(points);
  if (pts.length <= 2) return pts;
  const lower = [];
  for (const p of pts) {
    while (lower.length >= 2 && cross(lower[lower.length - 2], lower[lower.length - 1], p) <= 0) lower.pop();
    lower.push(p);
  }
  const upper = [];
  for (let i = pts.length - 1; i >= 0; i--) {
    const p = pts[i];
    while (upper.length >= 2 && cross(upper[upper.length - 2], upper[upper.length - 1], p) <= 0) upper.pop();
    upper.push(p);
  }
  lower.pop();
  upper.pop();
  return lower.concat(upper);
}

function convexHullKeepCollinear(points) {
  const pts = sortPoints(points);
  if (pts.length <= 2) return pts;
  const build = (list) => {
    const h = [];
    for (const p of list) {
      while (h.length >= 2 && cross(h[h.length - 2], h[h.length - 1], p) < 0) h.pop();
      h.push(p);
    }
    return h;
  };
  const lower = build(pts);
  const upper = build(pts.slice().reverse());
  lower.pop();
  upper.pop();
  const res = lower.concat(upper);
  const seen = new Set();
  return res.filter((p) => { const k = p.join(','); if (seen.has(k)) return false; seen.add(k); return true; });
}

function lowerHullTrace(points) {
  const pts = sortPoints(points);
  const out = [];
  const h = [];
  for (const p of pts) {
    while (h.length >= 2 && cross(h[h.length - 2], h[h.length - 1], p) <= 0) h.pop();
    h.push(p);
    out.push('[' + h.map((q) => '(' + q.join(',') + ')').join(' ') + ']');
  }
  return out;
}

function jarvis(points) {
  const pts = sortPoints(points);
  if (pts.length <= 2) return pts;
  const hull = [];
  let cur = pts[0];
  do {
    hull.push(cur);
    let next = pts[0] === cur ? pts[1] : pts[0];
    for (const p of pts) {
      if (p === cur) continue;
      const c = cross(cur, next, p);
      if (c < 0 || (c === 0 && dist2(cur, p) > dist2(cur, next))) next = p;
    }
    cur = next;
  } while (cur !== hull[0]);
  return hull;
}

function dist2(a, b) {
  return (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2;
}

function polygonArea(poly) {
  let s = 0;
  for (let i = 0; i < poly.length; i++) {
    const [x1, y1] = poly[i];
    const [x2, y2] = poly[(i + 1) % poly.length];
    s += x1 * y2 - x2 * y1;
  }
  return Math.abs(s) / 2;
}

function perimeter(poly) {
  let p = 0;
  for (let i = 0; i < poly.length; i++) p += Math.sqrt(dist2(poly[i], poly[(i + 1) % poly.length]));
  return +p.toFixed(6);
}

function insideConvex(hull, q) {
  if (hull.length < 3) return false;
  for (let i = 0; i < hull.length; i++) {
    if (cross(hull[i], hull[(i + 1) % hull.length], q) < 0) return false;
  }
  return true;
}

function strictlyInsideConvex(hull, q) {
  for (let i = 0; i < hull.length; i++) {
    if (cross(hull[i], hull[(i + 1) % hull.length], q) <= 0) return false;
  }
  return hull.length >= 3;
}

function diameterSquared(hull) {
  let best = 0;
  for (let i = 0; i < hull.length; i++) for (let j = i + 1; j < hull.length; j++) best = Math.max(best, dist2(hull[i], hull[j]));
  return best;
}

function rotatingCalipersDiameter2(hull) {
  const n = hull.length;
  if (n === 1) return 0;
  if (n === 2) return dist2(hull[0], hull[1]);
  let best = 0;
  let j = 1;
  for (let i = 0; i < n; i++) {
    const ni = (i + 1) % n;
    while (Math.abs(cross(hull[i], hull[ni], hull[(j + 1) % n])) > Math.abs(cross(hull[i], hull[ni], hull[j]))) j = (j + 1) % n;
    best = Math.max(best, dist2(hull[i], hull[j]), dist2(hull[ni], hull[j]));
  }
  return best;
}

function hullLayers(points) {
  let rest = sortPoints(points);
  const layers = [];
  while (rest.length > 0) {
    const h = rest.length <= 2 ? rest : convexHull(rest);
    layers.push(h);
    const on = new Set(h.map((p) => p.join(',')));
    rest = rest.filter((p) => !on.has(p.join(',')));
  }
  return layers;
}

function isConvexPolygon(poly) {
  let sign = 0;
  const n = poly.length;
  for (let i = 0; i < n; i++) {
    const c = cross(poly[i], poly[(i + 1) % n], poly[(i + 2) % n]);
    if (c !== 0) {
      const s = c > 0 ? 1 : -1;
      if (sign === 0) sign = s;
      else if (sign !== s) return false;
    }
  }
  return true;
}

function erectFence(trees) {
  return convexHullKeepCollinear(trees);
}

function segmentsIntersect(p1, p2, p3, p4) {
  const d1 = cross(p3, p4, p1);
  const d2 = cross(p3, p4, p2);
  const d3 = cross(p1, p2, p3);
  const d4 = cross(p1, p2, p4);
  if (((d1 > 0 && d2 < 0) || (d1 < 0 && d2 > 0)) && ((d3 > 0 && d4 < 0) || (d3 < 0 && d4 > 0))) return true;
  const on = (a, b, c) => cross(a, b, c) === 0 && Math.min(a[0], b[0]) <= c[0] && c[0] <= Math.max(a[0], b[0]) && Math.min(a[1], b[1]) <= c[1] && c[1] <= Math.max(a[1], b[1]);
  return on(p3, p4, p1) || on(p3, p4, p2) || on(p1, p2, p3) || on(p1, p2, p4);
}
```

## 6. Деталі й гранично-випадкові ситуації

- **Колінеарні точки** на ребрі: `cross ≤ 0` видаляє їх (оболонка лише з кутових вершин). Якщо їх потрібно залишити (огорожа для дерев) — `cross < 0` (`convexHullKeepCollinear`). `convexHull([[0, 0], [1, 0], [2, 0], [2, 2], [0, 2]])` = `[[0, 0], [2, 0], [2, 2], [0, 2]]`, а з колінеарними — `[[0, 0], [1, 0], [2, 0], [2, 2], [0, 2]]`.
- **Усі точки на одній прямій:** оболонка — відрізок із двох крайніх (`convexHull([[0, 0], [1, 1], [2, 2]])` = `[[0, 0], [2, 2]]`).
- **Дублікати:** прибираються сортуванням.
- **Менше трьох точок:** оболонка — самі точки.
- **Цілі координати** дають точний `cross`; для дробових потрібен допуск (`ε`).

## 7. Застосування

- **Площа й периметр:** `polygonArea(convexHull(…))` для квадрата 4×4: `16`; периметр `16` (формула шнурування — Gauss shoelace).
- **Чи лежить точка всередині:** `insideConvex(hull, q)` — усі повороти ліві: `insideConvex(convexHull([[0, 0], [4, 0], [4, 4], [0, 4]]), [2, 2])` = `true`, для `[5, 5]` — `false`.
- **Діаметр множини** (найвіддаленіша пара): серед вершин оболонки; **ротаційні кронштейни** (rotating calipers) — `O(h)` замість `O(h²)`: `rotatingCalipersDiameter2(convexHull([[0, 0], [4, 0], [4, 3], [0, 3]]))` = `25` (квадрат діагоналі `4² + 3² = 25`).
- **Шари оболонки («цибулина»):** `hullLayers` — ядро ідеї «глибини» точки.
- **Огорожа для дерев (LeetCode 587):** `erectFence([[1, 1], [2, 2], [2, 0], [2, 4], [3, 3], [4, 2]])` = `[[1, 1], [2, 0], [4, 2], [3, 3], [2, 4]]`.
- **Зіткнення об'єктів, упакування, найменший обмежувальний прямокутник/коло, комп'ютерний зір, обробка зображень, геоінформатика, економіка (лінійне програмування)**.
- **Перетин відрізків:** `segmentsIntersect([0, 0], [4, 4], [0, 4], [4, 0])` = `true`.

## 8. Складність

| Алгоритм | Час | Примітка |
|---|---|---|
| Джарвіс | `O(n·h)` | чутливий до виходу |
| Грем | `O(n log n)` | сортування за кутом |
| **Ендрю** | `O(n log n)` | сортування за `x`, простий |
| Чан | `O(n log h)` | оптимальний за виходом |
| Нижня межа | `Ω(n log n)` | зводиться до сортування |

Нижня межа `Ω(n log n)` у моделі дерева рішень випливає зі зведення сортування до оболонки (точки на параболі `y = x²` — усі лежать на оболонці, її порядок — відсортовані `x`).

## 9. Типові помилки

1. **`cross` із зайвими знаковими помилками** (змінений порядок аргументів) — оболонка за годинниковою чи хибна.
2. **Не прибрати дублікати** — нульові повороти псують стек.
3. **Колінеарні точки:** `<= 0` чи `< 0` за умовою задачі.
4. **Забути `pop` останньої точки** при з'єднанні нижньої й верхньої оболонок (дублі кінців).
5. **Дробові координати** без допуску — нестабільні колінеарності.
6. **Усі точки колінеарні:** алгоритм має повернути відрізок (інакше `<= 0` дає одну точку).
7. **Переповнення `cross`** у мовах із 32-бітними `int` (добутки координат).
8. **Сортувати за `y` у Ендрю й використовувати сортування за `x`** — непослідовність.
9. **Повертати точки, а не індекси**, коли потрібні індекси вихідного масиву.

## 10. Алгоритм (стисло)

1. Відсортувати точки за `(x, y)`, прибрати дублі.
2. Нижня оболонка: для кожної точки видаляти зі стека, поки `cross ≤ 0`; додати.
3. Верхня — тим самим зі зворотного проходу.
4. З'єднати, відкинувши повторні кінці.
5. Час `O(n log n)`.
