# Dynamic Programming — основи динамічного програмування

Динамічне програмування (ДП) — спосіб розв'язувати задачі, розбиваючи їх на **підзадачі, що перекриваються**, і **запам'ятовуючи** відповіді, щоб кожну підзадачу порахувати лише раз. Саме так експоненційний перебір перетворюється на поліноміальний алгоритм. Назва «динамічне» — історична; суть: «не рахуй одне й те саме двічі».

## 1. Дві ознаки задачі для ДП

1. **Оптимальна підструктура:** оптимальний розв'язок задачі складається з оптимальних розв'язків її підзадач.
2. **Перекриття підзадач:** одні й ті самі підзадачі зустрічаються багаторазово.

Якщо друга ознака відсутня (підзадачі не повторюються — як у merge sort), потрібен звичайний «розділяй і володарюй». Якщо відсутня перша — ДП не підходить.

## 2. Приклад: числа Фібоначчі

`F(0) = 0`, `F(1) = 1`, `F(n) = F(n − 1) + F(n − 2)`. Наївна рекурсія:

`fibNaive(n)` викликає себе двічі, дерево викликів експоненційне: `F(5)` потребує 15 викликів, `F(10)` — 177, `F(20)` — 21891, `F(30)` — 2692537. Складність `O(φⁿ)`, `φ ≈ 1,618`.

Дерево викликів для `F(5)` містить `F(3)` двічі, `F(2)` тричі... — це **перекриття підзадач**. Усього різних підзадач лише `n + 1`.

### Згори вниз (top-down, мемоізація)

Лишаємо рекурсію, але зберігаємо результат кожної підзадачі в таблиці; перед обчисленням — перевіряємо. Викликів `F(30)`: 59 замість 2692537. Час `O(n)`, пам'ять `O(n)` (таблиця й стек рекурсії).

### Знизу вгору (bottom-up, табуляція)

Заповнюємо таблицю в порядку зростання підзадач — без рекурсії: `dp[0] = 0`, `dp[1] = 1`, `dp[i] = dp[i − 1] + dp[i − 2]`. Час `O(n)`, пам'ять `O(n)`.

### Оптимізація пам'яті

`dp[i]` залежить лише від двох попередніх — тримаємо дві змінні: пам'ять `O(1)`. `fib(50)` = `12586269025`, `fib(70)` = `190392490709135`; починаючи з `F(79)` числа перевищують `2^53` і в `Number` втрачають точність, тому далі потрібен `BigInt`: `fibBig(100)` = `354224848179261915075`.

| Підхід | Час | Пам'ять |
|---|---|---|
| Наївна рекурсія | `O(φⁿ)` | `O(n)` стек |
| Мемоізація | `O(n)` | `O(n)` |
| Табуляція | `O(n)` | `O(n)` |
| Дві змінні | `O(n)` | `O(1)` |
| Матричне піднесення до степеня / швидке подвоєння | `O(log n)` | `O(1)` |

## 3. Рецепт розв'язання задачі ДП

1. **Стан:** що однозначно описує підзадачу? (`dp[i]`, `dp[i][j]`, `dp[i][mask]`.)
2. **Перехід (recurrence):** як виразити стан через менші стани?
3. **База:** значення найпростіших станів.
4. **Порядок обчислення:** щоб залежності були вже готові (зростання `i`; для 2D — по рядках).
5. **Відповідь:** який стан (або комбінація) — результат?
6. **Складність:** кількість станів × вартість переходу; чи можна стиснути пам'ять.

Найважче — крок 1. Корисний прийом: **сформулюйте відповідь для малого вхідного розміру і подумайте, що змінюється, коли додається ще один елемент**.

## 4. Класичні одновимірні задачі

### 4.1. Сходи (climbing stairs)

На сходи з `n` сходинок піднімаються кроками по 1 чи 2. Скільки способів? `ways(n) = ways(n − 1) + ways(n − 2)` — знову Фібоначчі зі зсувом. `climbStairs(10)` = `89`.

### 4.2. Грабіжник будинків (house robber)

Не можна грабувати сусідні. `dp[i] = max(dp[i − 1], dp[i − 2] + a[i])`: або пропускаємо будинок `i`, або беремо його разом з найкращим до `i − 2`. `rob([2, 7, 9, 3, 1])` = `12`.

### 4.3. Мінімум монет для суми, кількість розкладів — див. [coin-change.md](coin-change.md).

### 4.4. Декодування рядка

`'226'` можна розшифрувати як `BZ`, `VF`, `BBF` (A=1…Z=26): `dp[i]` = кількість способів для префікса: `numDecodings('226')` = `3`, `numDecodings('06')` = `0`.

### 4.5. Розбиття числа, «сходи з вартістю», «найдовша послідовність»

`minCostClimbing([10, 15, 20])` = `15`.

## 5. Двовимірні задачі на сітці

**Унікальні шляхи** з лівого верхнього кута до правого нижнього, рухи вправо/вниз: `dp[i][j] = dp[i − 1][j] + dp[i][j − 1]`. `uniquePaths(3, 7)` = `28` (збігається з `C(8, 2) = 28`). **Зі перешкодами:** якщо клітинка — стіна, `dp = 0`: `uniquePathsObstacles([[0, 0, 0], [0, 1, 0], [0, 0, 0]])` = `2`.

**Мінімальна сума шляху:** `dp[i][j] = a[i][j] + min(dp[i − 1][j], dp[i][j − 1])`. `minPathSum([[1, 3, 1], [1, 5, 1], [4, 2, 1]])` = `7`. Пам'ять можна стиснути до одного рядка: `dp[j]` оновлюється «на місці».

**Трикутник** (мінімальний шлях зверху вниз): `minTriangle([[2], [3, 4], [6, 5, 7], [4, 1, 8, 3]])` = `11` — знизу вгору, `O(n)` пам'яті.

## 6. Мемоізація чи табуляція

| | Мемоізація (top-down) | Табуляція (bottom-up) |
|---|---|---|
| Код | близький до рекурентності | цикли |
| Підзадачі | лише потрібні | всі |
| Стек | може переповнитись | немає |
| Оптимізація пам'яті | складно | легко (стиснення таблиці) |
| Відкладені стани | природно | потрібен правильний порядок |

Мемоізація зручна, коли досяжних станів багато менше за всі можливі (рідкі простори). Табуляція — швидша на практиці й дозволяє «котити» пам'ять.

## 7. Реалізація

```js
function fibNaive(n) {
  return n < 2 ? n : fibNaive(n - 1) + fibNaive(n - 2);
}

function fibCalls(n) {
  let calls = 0;
  const go = (k) => {
    calls++;
    if (k < 2) return k;
    return go(k - 1) + go(k - 2);
  };
  go(n);
  return calls;
}

function fibMemoCalls(n) {
  let calls = 0;
  const memo = new Map();
  const go = (k) => {
    calls++;
    if (k < 2) return k;
    if (memo.has(k)) return memo.get(k);
    const v = go(k - 1) + go(k - 2);
    memo.set(k, v);
    return v;
  };
  go(n);
  return calls;
}

function fibTable(n) {
  const dp = new Array(n + 1).fill(0);
  dp[1] = 1;
  for (let i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
  return dp[n];
}

function fibIter(n) {
  let a = 0;
  let b = 1;
  for (let i = 0; i < n; i++) [a, b] = [b, a + b];
  return a;
}

function fibBig(n) {
  let a = 0n;
  let b = 1n;
  for (let i = 0; i < n; i++) [a, b] = [b, a + b];
  return a.toString();
}

function climbStairs(n) {
  let a = 1;
  let b = 1;
  for (let i = 2; i <= n; i++) [a, b] = [b, a + b];
  return b;
}

function rob(a) {
  let take = 0;
  let skip = 0;
  for (const x of a) [take, skip] = [skip + x, Math.max(skip, take)];
  return Math.max(take, skip);
}

function numDecodings(s) {
  const n = s.length;
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1;
  dp[1] = s[0] === '0' ? 0 : 1;
  for (let i = 2; i <= n; i++) {
    if (s[i - 1] !== '0') dp[i] += dp[i - 1];
    const two = Number(s.slice(i - 2, i));
    if (two >= 10 && two <= 26) dp[i] += dp[i - 2];
  }
  return dp[n];
}

function minCostClimbing(cost) {
  let a = 0;
  let b = 0;
  for (let i = 2; i <= cost.length; i++) [a, b] = [b, Math.min(b + cost[i - 1], a + cost[i - 2])];
  return b;
}

function uniquePaths(m, n) {
  const dp = new Array(n).fill(1);
  for (let i = 1; i < m; i++) for (let j = 1; j < n; j++) dp[j] += dp[j - 1];
  return dp[n - 1];
}

function uniquePathsObstacles(g) {
  const R = g.length;
  const C = g[0].length;
  const dp = new Array(C).fill(0);
  dp[0] = g[0][0] === 1 ? 0 : 1;
  for (let i = 0; i < R; i++) {
    for (let j = 0; j < C; j++) {
      if (g[i][j] === 1) dp[j] = 0;
      else if (j > 0) dp[j] += dp[j - 1];
    }
  }
  return dp[C - 1];
}

function minPathSum(g) {
  const R = g.length;
  const C = g[0].length;
  const dp = new Array(C).fill(Infinity);
  dp[0] = 0;
  for (let i = 0; i < R; i++) {
    for (let j = 0; j < C; j++) {
      dp[j] = g[i][j] + Math.min(dp[j], j > 0 ? dp[j - 1] : Infinity);
    }
  }
  return dp[C - 1];
}

function minTriangle(t) {
  const dp = t[t.length - 1].slice();
  for (let i = t.length - 2; i >= 0; i--) for (let j = 0; j <= i; j++) dp[j] = t[i][j] + Math.min(dp[j], dp[j + 1]);
  return dp[0];
}

function maxProductCutting(n) {
  const dp = new Array(n + 1).fill(0);
  dp[1] = 1;
  for (let i = 2; i <= n; i++) for (let j = 1; j < i; j++) dp[i] = Math.max(dp[i], j * (i - j), j * dp[i - j]);
  return dp[n];
}

function tribonacci(n) {
  const t = [0, 1, 1];
  for (let i = 3; i <= n; i++) t[i] = t[i - 1] + t[i - 2] + t[i - 3];
  return t[n];
}

function perfectSquares(n) {
  const dp = new Array(n + 1).fill(Infinity);
  dp[0] = 0;
  for (let i = 1; i <= n; i++) for (let s = 1; s * s <= i; s++) dp[i] = Math.min(dp[i], dp[i - s * s] + 1);
  return dp[n];
}

function wordBreak(s, dict) {
  const set = new Set(dict);
  const dp = new Array(s.length + 1).fill(false);
  dp[0] = true;
  for (let i = 1; i <= s.length; i++) for (let j = 0; j < i; j++) if (dp[j] && set.has(s.slice(j, i))) { dp[i] = true; break; }
  return dp[s.length];
}
```

## 8. Типові помилки

1. **Неправильно визначений стан:** стан не містить усієї інформації для переходу — відповідь неправильна.
2. **Забути базові випадки** (`dp[0]`, `dp[1]`, порожній рядок).
3. **Порядок заповнення:** використання ще не обчисленого `dp[i + 1]`.
4. **Індекси:** `dp[i]` — для префікса довжини `i` (з нуля) чи для індекса `i` (з нуля)? Тримайте одне правило.
5. **Мемоізація без урахування всіх параметрів стану** у ключі.
6. **Переповнення:** Фібоначчі від 79-го числа виходять за `2⁵³` — `BigInt`.
7. **Спроба застосувати ДП, коли немає перекриття підзадач.**
8. **Жадібність замість ДП:** локальний вибір не завжди оптимальний (задача про монети `[1, 3, 4]`, сума 6: жадібно 4 + 1 + 1, оптимально 3 + 3).
9. **Стиснення пам'яті, що перезаписує потрібні значення** (порядок обходу `j` вперед чи назад — критичний).

## 9. Алгоритм-шаблон

1. Визначити стан і перехід; записати базу.
2. Вибрати мемоізацію (рекурсія + `Map`) або табуляцію (цикли).
3. Перевірити порядок залежностей; за потреби стиснути пам'ять.
4. Складність: кількість станів × вартість переходу.

   ```js
   function fibMatrix(n) {
     const mul = (a, b) => [[a[0][0] * b[0][0] + a[0][1] * b[1][0], a[0][0] * b[0][1] + a[0][1] * b[1][1]], [a[1][0] * b[0][0] + a[1][1] * b[1][0], a[1][0] * b[0][1] + a[1][1] * b[1][1]]];
     let r = [[1n, 0n], [0n, 1n]], m = [[1n, 1n], [1n, 0n]];
     let k = BigInt(n);
     while (k > 0n) {
       if (k & 1n) r = mul(r, m);
       m = mul(m, m);
       k >>= 1n;
     }
     return r[0][1].toString();
   }
   ```

     let best = 0;
     for (const x of s) if (!s.has(x - 1)) {

   ```js
   function decodeWaysWithStar(s) {
     const M = 1000000007;
     let e0 = 1, e1 = s[0] === '*' ? 9 : s[0] === '0' ? 0 : 1;
     for (let i = 2; i <= s.length; i++) {
       const c = s[i - 1], p = s[i - 2];
       let cur = 0;
       if (c === '*') cur += 9 * e1;
       else if (c !== '0') cur += e1;
       if (p === '*') {
         if (c === '*') cur += 15 * e0;
         else if (c <= '6') cur += 2 * e0;
         else cur += e0;
       } else if (p === '1') cur += (c === '*' ? 9 : 1) * e0;
       else if (p === '2') cur += (c === '*' ? 6 : (c <= '6' ? 1 : 0)) * e0;
       cur %= M;
       e0 = e1;
       e1 = cur;
     }
     return e1 % M;
   }
   ```
