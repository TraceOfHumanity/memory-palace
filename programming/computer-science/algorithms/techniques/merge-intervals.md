# Merge Intervals — інтервали: злиття, вставка, перетини, планування

Інтервали (відрізки `[start, end]`) трапляються всюди: розклад зустрічей, бронювання кімнат, діапазони IP-адрес, часові лінії подій, відрізки на прямій. Майже всі задачі розв'язуються однією ідеєю: **спершу відсортувати за початком**, а тоді пройти один раз, порівнюючи кожен інтервал з **останнім** у результаті. Складність — `O(n log n)` через сортування, далі лінійний прохід.

## 1. Основна задача: злиття перекритих інтервалів

Дано `[[1, 3], [2, 6], [8, 10], [15, 18]]`. Інтервали `[1, 3]` і `[2, 6]` перекриваються → `[1, 6]`. Результат: `[[1, 6], [8, 10], [15, 18]]`.

**Умова перекриття** двох інтервалів `A = [a1, a2]`, `B = [b1, b2]`: вони **не** перекриваються, якщо `a2 < b1` або `b2 < a1` (один цілком лівіше іншого). Отже, перекриваються, якщо `a1 <= b2 && b1 <= a2` — тобто **початок кожного не пізніше кінця іншого**. Рівність (`[1, 2]` і `[2, 3]` торкаються в точці `2`) — залежить від умови задачі (замкнені інтервали — перекриття, напіввідкриті — ні).

**Алгоритм.**

1. Відсортувати за початком.
2. Покласти перший інтервал у результат.
3. Для кожного наступного `cur`: якщо `cur.start <= last.end` — **злити**: `last.end = max(last.end, cur.end)`; інакше додати `cur` у результат.

**Чому сортування за початком достатньо?** Після сортування жоден наступний інтервал не починається раніше за попередні, тому якщо `cur` не перекривається з **останнім** злитим інтервалом (його кінець — найбільший серед усіх попередніх), то він не перекривається ні з одним попереднім, і так буде для всіх наступних. Тому порівнювати достатньо лише з останнім.

Трасування для `[[1, 3], [8, 10], [2, 6], [15, 18], [17, 20]]` (після сортування):

- відсортовано: [[1,3],[2,6],[8,10],[15,18],[17,20]]
- [2,6] перекривається з [1,3] → [1,6]
- [8,10] не перекривається → новий інтервал
- [15,18] не перекривається → новий інтервал
- [17,20] перекривається з [15,18] → [15,20]
- результат: [[1,6],[8,10],[15,20]]

**Важливо: `max` при злитті.** `[1, 10]` і `[2, 3]` → `[1, 10]`, а не `[1, 3]`: другий інтервал **вкладений**, його кінець менший. Тому `last.end = max(last.end, cur.end)`.

## 2. Вставка нового інтервалу

Є відсортований список **без перекриттів**, треба вставити `newInterval` зі злиттям. Лінійний прохід (без сортування, `O(n)`) у три фази:

1. Усі інтервали, що закінчуються **до** початку нового (`end < new.start`) — копіюємо.
2. Усі, що перекриваються з новим (`start <= new.end`) — зливаємо в нього: `new.start = min(...)`, `new.end = max(...)`.
3. Решту (що починаються після `new.end`) — копіюємо.

`insertInterval([[1, 3], [6, 9]], [2, 5])` = `[[1, 5], [6, 9]]`; `insertInterval([[1, 2], [3, 5], [6, 7], [8, 10], [12, 16]], [4, 8])` = `[[1, 2], [3, 10], [12, 16]]`.

## 3. Перетин двох списків інтервалів

Два відсортовані списки без перекриттів (двома вказівниками, [two-pointers.md](two-pointers.md)): перетин `[max(a1, b1), min(a2, b2)]` існує, якщо `max <= min`. Далі просуваємо той вказівник, чий інтервал **закінчується раніше**. `intervalIntersection([[0, 2], [5, 10], [13, 23], [24, 25]], [[1, 5], [8, 12], [15, 24], [25, 26]])` = `[[1, 2], [5, 5], [8, 10], [15, 23], [24, 24], [25, 25]]`.

## 4. «Чи можна відвідати всі зустрічі?» і мінімум кімнат

- **Чи можна відвідати всі зустрічі:** відсортувати й перевірити, що `next.start >= prev.end`. `canAttendAll([[0, 30], [5, 10], [15, 20]])` = `false`, `canAttendAll([[7, 10], [2, 4]])` = `true`.
- **Мінімум кімнат (meeting rooms II)** — максимум одночасно активних інтервалів. Два способи:
  - **Подієва лінія (sweep line):** події `+1` у початку й `−1` у кінці, відсортувати, накопичувати лічильник; для рівних моментів **кінець раніше за початок** (інтервали `[a, b)`).
  - **Купа (min-heap) кінців:** сортуємо за початком; кожна кімната — її час завершення; якщо `start >= heap.min` — використовуємо ту саму кімнату (замінюємо), інакше додаємо нову.
  `minMeetingRooms([[0, 30], [5, 10], [15, 20]])` = `2`, `minMeetingRooms([[7, 10], [2, 4]])` = `1`.

## 5. Мінімальне видалення для безперервності

**Non-overlapping intervals:** скільки інтервалів треба видалити, щоб решта не перекривалась? Жадібний вибір (як в [activity-selection.md](../greedy/activity-selection.md)): сортуємо за **кінцем** і залишаємо інтервал, що закінчується раніше всіх (залишає найбільше місця): `eraseOverlapIntervals([[1, 2], [2, 3], [3, 4], [1, 3]])` = `1`.

**Мінімум стріл для лопання куль** (`[start, end]` — діаметри): те саме з жадібним вибором за кінцем: `findMinArrowShots([[10, 16], [2, 8], [1, 6], [7, 12]])` = `2`.

## 6. Реалізація

```js
function mergeIntervals(intervals) {
  if (intervals.length === 0) return [];
  const a = intervals.map((x) => x.slice()).sort((p, q) => p[0] - q[0]);
  const res = [a[0]];
  for (let i = 1; i < a.length; i++) {
    const last = res[res.length - 1];
    if (a[i][0] <= last[1]) last[1] = Math.max(last[1], a[i][1]);
    else res.push(a[i]);
  }
  return res;
}

function mergeTrace(intervals) {
  const a = intervals.map((x) => x.slice()).sort((p, q) => p[0] - q[0]);
  const out = ['відсортовано: ' + JSON.stringify(a)];
  const res = [a[0]];
  for (let i = 1; i < a.length; i++) {
    const last = res[res.length - 1];
    if (a[i][0] <= last[1]) {
      const before = JSON.stringify(last);
      last[1] = Math.max(last[1], a[i][1]);
      out.push(JSON.stringify(a[i]) + ' перекривається з ' + before + ' → ' + JSON.stringify(last));
    } else {
      res.push(a[i]);
      out.push(JSON.stringify(a[i]) + ' не перекривається → новий інтервал');
    }
  }
  out.push('результат: ' + JSON.stringify(res));
  return out;
}

function insertInterval(intervals, nw) {
  const res = [];
  let i = 0;
  const n = intervals.length;
  while (i < n && intervals[i][1] < nw[0]) res.push(intervals[i++]);
  let cur = nw.slice();
  while (i < n && intervals[i][0] <= cur[1]) {
    cur = [Math.min(cur[0], intervals[i][0]), Math.max(cur[1], intervals[i][1])];
    i++;
  }
  res.push(cur);
  while (i < n) res.push(intervals[i++]);
  return res;
}

function intervalIntersection(A, B) {
  const res = [];
  let i = 0;
  let j = 0;
  while (i < A.length && j < B.length) {
    const lo = Math.max(A[i][0], B[j][0]);
    const hi = Math.min(A[i][1], B[j][1]);
    if (lo <= hi) res.push([lo, hi]);
    if (A[i][1] < B[j][1]) i++;
    else j++;
  }
  return res;
}

function canAttendAll(intervals) {
  const a = intervals.slice().sort((p, q) => p[0] - q[0]);
  for (let i = 1; i < a.length; i++) if (a[i][0] < a[i - 1][1]) return false;
  return true;
}

function minMeetingRooms(intervals) {
  const events = [];
  for (const [s, e] of intervals) {
    events.push([s, 1]);
    events.push([e, -1]);
  }
  events.sort((p, q) => p[0] - q[0] || p[1] - q[1]);
  let cur = 0;
  let best = 0;
  for (const [, d] of events) {
    cur += d;
    best = Math.max(best, cur);
  }
  return best;
}

function eraseOverlapIntervals(intervals) {
  const a = intervals.slice().sort((p, q) => p[1] - q[1]);
  let end = -Infinity;
  let removed = 0;
  for (const [s, e] of a) {
    if (s >= end) end = e;
    else removed++;
  }
  return removed;
}

function findMinArrowShots(points) {
  const a = points.slice().sort((p, q) => p[1] - q[1]);
  let arrows = 0;
  let end = -Infinity;
  for (const [s, e] of a) {
    if (s > end) {
      arrows++;
      end = e;
    }
  }
  return arrows;
}

function maxOverlapPoint(intervals) {
  const events = [];
  for (const [s, e] of intervals) {
    events.push([s, 1]);
    events.push([e + 1, -1]);
  }
  events.sort((p, q) => p[0] - q[0] || p[1] - q[1]);
  let cur = 0;
  let best = 0;
  let at = null;
  for (const [x, d] of events) {
    cur += d;
    if (cur > best) { best = cur; at = x; }
  }
  return { count: best, at };
}

function employeeFreeTime(schedules) {
  const all = schedules.flat().sort((p, q) => p[0] - q[0]);
  const merged = mergeIntervals(all);
  const free = [];
  for (let i = 1; i < merged.length; i++) free.push([merged[i - 1][1], merged[i][0]]);
  return free;
}

function totalCovered(intervals) {
  return mergeIntervals(intervals).reduce((s, [a, b]) => s + (b - a), 0);
}
```

## 7. Складність

| Операція | Час | Пам'ять |
|---|---|---|
| Злиття (з сортуванням) | `O(n log n)` | `O(n)` |
| Злиття (вхід уже відсортований) | `O(n)` | `O(1)` додатково |
| Вставка в відсортований список | `O(n)` | `O(n)` |
| Перетин двох списків | `O(n + m)` | `O(n + m)` |
| Мінімум кімнат (події або купа) | `O(n log n)` | `O(n)` |

## 8. Інші підходи

- **Подієва лінія (sweep line):** перетворює інтервали на події на осі часу; універсальна для «скільки інтервалів покриває точку», «найзавантаженіший момент», «загальна покрита довжина» (`totalCovered([[1, 4], [2, 6], [8, 10]])` = `7`).
- **Різницевий масив** ([prefix-sums.md](prefix-sums.md)): коли координати малі, `D[start]++`, `D[end+1]--` і префіксні суми.
- **Дерево інтервалів** (interval tree) і **дерево відрізків** — для динамічних запитів «які інтервали перекривають точку/відрізок»: `O(log n + k)`.
- **Вільний час працівників:** `employeeFreeTime([[[1, 3], [6, 7]], [[2, 4]], [[2, 5], [9, 12]]])` = `[[5, 6], [7, 9]]` — злити всі зайняті інтервали й узяти проміжки.

## 9. Типові помилки

1. **Не відсортувати** перед злиттям — результат неправильний.
2. **Забути `max` для кінця** при вкладених інтервалах (`[1, 10]`, `[2, 3]`).
3. **Нестрога чи строга нерівність:** `[1, 2]` і `[2, 3]` — злиття чи ні? Уточнюйте задачу: замкнені інтервали зливаються (`<=`), напіввідкриті — ні (`<`).
4. **Мутація вхідного масиву** (`last[1] = …` змінює оригінальні об'єкти): копіюйте інтервали.
5. **Сортувати за кінцем у задачі злиття** — для злиття потрібно за початком; для «максимум непересічних» — за кінцем.
6. **Порядок подій для рівних моментів** у sweep line: кінець раніше початку для `[a, b)`; для замкнених — початок раніше.
7. **Порожній вхід:** `a[0]` — `undefined`.
8. **Порівняння чисел як рядків:** `sort()` без компаратора для чисел сортує лексикографічно (`[10, 9]`).
9. **Плутанина «перекриття» і «вкладення»:** вкладений інтервал також перекривається.

## 10. Алгоритм (стисло)

1. Відсортувати за `start`.
2. Результат = `[перший]`; для кожного наступного: якщо `start <= останній.end` — `останній.end = max(останній.end, end)`, інакше додати.
3. Час `O(n log n)`, пам'ять `O(n)`.

33. Приклад розв'язку:

   ```js
   function mergeSorted(a) {
     const res = [];
     for (const x of a) {
       if (res.length && x[0] <= res[res.length - 1][1]) res[res.length - 1] = [res[res.length - 1][0], Math.max(res[res.length - 1][1], x[1])];
       else res.push(x);
     }
     return res;
   }
   ```

   Виклик `mergeSorted([[1, 3], [2, 6], [8, 10], [15, 18]])` → `[[1, 6], [8, 10], [15, 18]]`

34. Приклад розв'язку:

   ```js
   function minMeetingRoomsHeap(iv) {
     const s = iv.slice().sort((a, b) => a[0] - b[0]);
     const ends = [];
     for (const [st, en] of s) {
       ends.sort((a, b) => a - b);
       if (ends.length && ends[0] <= st) ends[0] = en;
       else ends.push(en);
     }
     return ends.length;
   }
   ```

   Виклик `[minMeetingRoomsHeap([[0, 30], [5, 10], [15, 20]]), minMeetingRoomsHeap([[1, 5], [5, 10]])]` → `[2, 1]`

35. Приклад розв'язку:

   ```js
   function removeCoveredIntervals(iv) {
     const a = iv.slice().sort((x, y) => x[0] - y[0] || y[1] - x[1]);
     let c = 0, maxEnd = -Infinity;
     for (const [, e] of a) {
       if (e > maxEnd) {
         c++;
         maxEnd = e;
       }
     }
     return c;
   }
   ```

   Виклик `[removeCoveredIntervals([[1, 4], [3, 6], [2, 8]]), removeCoveredIntervals([[1, 4], [2, 3]])]` → `[2, 1]`

36. Приклад розв'язку:

   ```js
   function summaryRanges(a) {
     const out = [];
     let i = 0;
     while (i < a.length) {
       let j = i;
       while (j + 1 < a.length && a[j + 1] === a[j] + 1) j++;
       out.push(i === j ? String(a[i]) : a[i] + '->' + a[j]);
       i = j + 1;
     }
     return out;
   }
   ```

   Виклик `[summaryRanges([0, 1, 2, 4, 5, 7]), summaryRanges([0, 2, 3, 4, 6, 8, 9]), summaryRanges([])]` → `[['0->2', '4->5', '7'], ['0', '2->4', '6', '8->9'], []]`

37. Приклад розв'язку:

   ```js
   function missingRanges(nums, lo, hi) {
     const out = [];
     let prev = lo - 1;
     for (const x of [...nums, hi + 1]) {
       if (x - prev >= 2) out.push(x - prev === 2 ? String(prev + 1) : (prev + 1) + '->' + (x - 1));
       prev = x;
     }
     return out;
   }
   ```

   Виклик `[missingRanges([0, 1, 3, 50, 75], 0, 99), missingRanges([], 1, 1)]` → `[['2', '4->49', '51->74', '76->99'], ['1']]`

39. Приклад розв'язку:

   ```js
   function partitionLabels(s) {
     const last = {};
     [...s].forEach((c, i) => last[c] = i);
     const res = [];
     let start = 0, end = 0;
     [...s].forEach((c, i) => { end = Math.max(end, last[c]); if (i === end) { res.push(i - start + 1); start = i + 1; } });
     return res;
   }
   ```

   Виклик `[partitionLabels('ababcbacadefegdehijhklij'), partitionLabels('eccbbbbdec')]` → `[[9, 7, 8], [10]]`

40. Приклад розв'язку:

   ```js
   function jumpToCover(clips, T) {
     const a = clips.slice().sort((x, y) => x[0] - y[0]);
     let cnt = 0, curEnd = 0, far = 0, i = 0;
     while (curEnd < T) {
       while (i < a.length && a[i][0] <= curEnd) far = Math.max(far, a[i++][1]);
       if (far === curEnd) return -1;
       curEnd = far;
       cnt++;
     }
     return cnt;
   }
   ```

   Виклик `[jumpToCover([[0, 2], [4, 6], [8, 10], [1, 9], [1, 5], [5, 9]], 10), jumpToCover([[0, 1], [1, 2]], 5)]` → `[3, -1]`
