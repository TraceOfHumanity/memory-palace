# Kadane's Algorithm — максимальна сума підмасиву

Алгоритм Кадане знаходить **неперервний підмасив із найбільшою сумою** за один прохід, `O(n)` часу й `O(1)` пам'яті. Це найкоротший приклад **динамічного програмування**: усе рішення — один рядок `cur = max(x, cur + x)`. Розібравшись, чому він працює, ви зрозумієте саму ідею ДП: «найкраща відповідь, що закінчується тут» будується з «найкращої відповіді, що закінчувалась у попередній точці».

## 1. Задача

Дано масив цілих `a` (є й від'ємні). Знайти максимум суми `a[l] + … + a[r]` по всіх `0 ≤ l ≤ r < n`. Підмасив має бути **неперервним** і **непорожнім**.

Приклад: `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` → відповідь `6` (підмасив `[4, -1, 2, 1]`).

Брутфорс: перебрати всі пари `(l, r)` — `O(n²)` із префіксними сумами, `O(n³)` без них. Divide and conquer: `O(n log n)`. Кадане — `O(n)`.

## 2. Ідея: «закінчується тут»

Визначимо `best_here[i]` — **максимальну суму підмасиву, що закінчується рівно в позиції `i`**. Тоді відповідь — `max_i best_here[i]`.

Як отримати `best_here[i]` із `best_here[i − 1]`? Підмасив, що закінчується в `i`, є одним із двох:

1. Лише сам елемент `a[i]` (починаємо **заново**).
2. Найкращий підмасив, що закінчувався в `i − 1`, **продовжений** елементом `a[i]`.

Отже `best_here[i] = max(a[i], best_here[i − 1] + a[i])`. Рівнозначно: якщо накопичена сума `best_here[i − 1]` **від'ємна** — вона лише шкодить, відкидаємо її й починаємо з `a[i]`; якщо невід'ємна — продовжуємо.

Рахуємо лише одне попереднє значення, тому пам'ять `O(1)`.

## 3. Покроковий приклад

Масив `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`:

| `i` | `a[i]` | `best_here` (закінчується в `i`) | `best` (максимум досі) |
|---|---|---|---|
| 0 | -2 | -2 | -2 |
| 1 | 1 | 1 | 1 |
| 2 | -3 | -2 | 1 |
| 3 | 4 | 4 | 4 |
| 4 | -1 | 3 | 4 |
| 5 | 2 | 5 | 5 |
| 6 | 1 | 6 | 6 |
| 7 | -5 | 1 | 6 |
| 8 | 4 | 5 | 6 |

Зверніть увагу, що в `i = 3` ми «забули» минулу від'ємну суму й почали з `4`; на `i = 7` сума впала до `1`, але ще додатна — продовжуємо, і на `i = 8` отримуємо `5`, менше за рекорд `6`.

## 4. Доведення коректності

Індукція за `i`. База: `best_here[0] = a[0]`. Крок: будь-який підмасив, що закінчується в `i`, або має довжину 1, або є підмасивом, що закінчується в `i − 1`, плюс `a[i]`. Сума другого варіанта — `sum + a[i]`, і вона максимальна, коли `sum` максимальна (це і є `best_here[i − 1]`), бо `a[i]` — константа. Тому `best_here[i] = max(a[i], best_here[i − 1] + a[i])`. Максимум по всіх `i` покриває всі можливі позиції кінця — отже, дає глобальний максимум.

**Зв'язок із префіксними сумами** ([prefix-sums.md](prefix-sums.md)): `sum(l, r) = P[r + 1] − P[l]`. Для фіксованого `r` максимум досягається при мінімальному `P[l]`, `l ≤ r`. Кадане — це те саме, лише мінімум префікса «вбудований» у скидання `cur`.

## 5. Реалізація

```js
function maxSubArray(a) {
  let cur = a[0];
  let best = a[0];
  for (let i = 1; i < a.length; i++) {
    cur = Math.max(a[i], cur + a[i]);
    best = Math.max(best, cur);
  }
  return best;
}

function kadaneTrace(a) {
  const out = [];
  let cur = a[0];
  let best = a[0];
  out.push({ i: 0, x: a[0], cur, best });
  for (let i = 1; i < a.length; i++) {
    cur = Math.max(a[i], cur + a[i]);
    best = Math.max(best, cur);
    out.push({ i, x: a[i], cur, best });
  }
  return out;
}

function maxSubArrayWithIndices(a) {
  let cur = a[0];
  let best = a[0];
  let start = 0;
  let bestL = 0;
  let bestR = 0;
  for (let i = 1; i < a.length; i++) {
    if (a[i] > cur + a[i]) {
      cur = a[i];
      start = i;
    } else {
      cur += a[i];
    }
    if (cur > best) {
      best = cur;
      bestL = start;
      bestR = i;
    }
  }
  return { sum: best, l: bestL, r: bestR, slice: a.slice(bestL, bestR + 1) };
}

function maxSubArrayAllowEmpty(a) {
  let cur = 0;
  let best = 0;
  for (const x of a) {
    cur = Math.max(0, cur + x);
    best = Math.max(best, cur);
  }
  return best;
}

function minSubArray(a) {
  let cur = a[0];
  let best = a[0];
  for (let i = 1; i < a.length; i++) {
    cur = Math.min(a[i], cur + a[i]);
    best = Math.min(best, cur);
  }
  return best;
}

function maxSubarrayCircular(a) {
  const total = a.reduce((s, x) => s + x, 0);
  const maxLinear = maxSubArray(a);
  const minLinear = minSubArray(a);
  if (maxLinear < 0) return maxLinear;
  return Math.max(maxLinear, total - minLinear);
}

function maxProductSubarray(a) {
  let curMax = a[0];
  let curMin = a[0];
  let best = a[0];
  for (let i = 1; i < a.length; i++) {
    const x = a[i];
    const c = [x, curMax * x, curMin * x];
    curMax = Math.max(...c);
    curMin = Math.min(...c);
    best = Math.max(best, curMax);
  }
  return best;
}

function maxProfit(prices) {
  let minPrice = Infinity;
  let best = 0;
  for (const p of prices) {
    minPrice = Math.min(minPrice, p);
    best = Math.max(best, p - minPrice);
  }
  return best;
}

function maxSumAfterOneDeletion(a) {
  let keep = a[0];
  let del = 0;
  let best = a[0];
  for (let i = 1; i < a.length; i++) {
    del = Math.max(keep, del + a[i]);
    keep = Math.max(a[i], keep + a[i]);
    best = Math.max(best, keep, del);
  }
  return best;
}

function maxSubMatrixRowPair(m) {
  const R = m.length;
  const C = m[0].length;
  let best = -Infinity;
  for (let top = 0; top < R; top++) {
    const col = new Array(C).fill(0);
    for (let bottom = top; bottom < R; bottom++) {
      for (let j = 0; j < C; j++) col[j] += m[bottom][j];
      best = Math.max(best, maxSubArray(col));
    }
  }
  return best;
}
```

Приклади: `maxSubArrayWithIndices([-2, 1, -3, 4, -1, 2, 1, -5, 4])` → `{ sum: 6, l: 3, r: 6, slice: [4, -1, 2, 1] }`.

## 6. Варіанти

### 6.1. Усі числа від'ємні

`maxSubArray([-3, -1, -2])` = `-1`: найкращий непорожній підмасив — найбільший елемент. Якщо ініціалізувати `best = 0` (нібито «порожній підмасив дозволено»), отримаємо `0`, що неправильно для умови «непорожній». Версія з дозволеним порожнім підмасивом — `maxSubArrayAllowEmpty` — повертає `0`.

### 6.2. Циклічний масив

Підмасив може «обгортатись» через кінець. Він або звичайний (Кадане), або **доповнення** до мінімального підмасиву: `total − minSubArray`. Виняток — усі числа від'ємні (тоді доповнення порожнє, а ми шукаємо непорожній): `maxSubarrayCircular([5, -3, 5])` = `10`; `maxSubarrayCircular([-3, -2, -3])` = `-2`.

### 6.3. Максимальний добуток

Добуток двох від'ємних дає додатне, тому тримаємо **і максимум, і мінімум**, що закінчуються в `i`: `maxProductSubarray([2, 3, -2, 4])` = `6`, `maxProductSubarray([-2, 0, -1])` = `0`, `maxProductSubarray([-2, 3, -4])` = `24`.

### 6.4. Торгівля акціями (одна операція)

Ціни `p`; купити раніше, продати пізніше. Прибуток — це різниця цін, тобто підмасив **денних змін** `p[i] − p[i − 1]` із максимальною сумою: `maxProfit([7, 1, 5, 3, 6, 4])` = `5`.

### 6.5. Одне видалення

Максимальна сума підмасиву, де можна видалити не більше одного елемента: два стани — `keep` (без видалення) і `del` (видалення вже було). `maxSumAfterOneDeletion([1, -2, 0, 3])` = `4`.

### 6.6. Двовимірний випадок

Максимальна сума підматриці: фіксуємо пару рядків `(top, bottom)`, стискаємо стовпці в один масив і застосовуємо Кадане. `O(R²·C)`. `maxSubMatrixRowPair([[1, 2, -1], [-3, 4, 2], [1, -5, 3]])` = `7`.

## 7. Складність

- **Час `O(n)`**, один прохід.
- **Пам'ять `O(1)`** — дві змінні.
- Divide and conquer (ліва половина, права, перетин) — `O(n log n)`; наївний — `O(n²)`.

## 8. Типові помилки

1. **`best = 0` для масиву з усіх від'ємних** — відповідь `0` замість найбільшого від'ємного.
2. **Ініціалізація `cur = 0` замість `a[0]`** при вимозі непорожнього підмасиву.
3. **Скидання при `cur < 0`, а не `cur <= 0`** — обидва варіанти дають ту саму суму, але різні межі; для «найкоротшого» чи «найдовшого» підмасиву потрібна точна умова.
4. **Забути оновити `best` після кожного кроку** (оновлюють лише при скиданні).
5. **Індекси:** `start` оновлюють під час скидання, а `bestL/bestR` — лише коли встановлено новий рекорд.
6. **Циклічний масив:** забути виняток «усі від'ємні» → відповідь `0` (порожнє доповнення).
7. **Добуток:** тримати лише максимум — втрачається від'ємний добуток, що може стати найбільшим.
8. **Переповнення сум** у мовах із фіксованою розрядністю.
9. **Плутати підмасив і підпослідовність:** підпослідовність дозволяє пропуски — там відповідь тривіальна (сума додатних).

## 9. Алгоритм (стисло)

1. `cur = best = a[0]`.
2. Для `i = 1..n − 1`: `cur = max(a[i], cur + a[i])`; `best = max(best, cur)`.
3. Повернути `best`. Час `O(n)`, пам'ять `O(1)`.

31. Приклад розв'язку:

   ```js
   function maxSubArrayDC(a, lo = 0, hi = a.length - 1) {
     if (lo === hi) return a[lo];
     const mid = (lo + hi) >> 1;
     let ls = -Infinity, s = 0;
     for (let i = mid; i >= lo; i--) {
       s += a[i];
       ls = Math.max(ls, s);
     }
     let rs = -Infinity;
     s = 0;
     for (let i = mid + 1; i <= hi; i++) {
       s += a[i];
       rs = Math.max(rs, s);
     }
     return Math.max(maxSubArrayDC(a, lo, mid), maxSubArrayDC(a, mid + 1, hi), ls + rs);
   }
   ```

   Виклик `[maxSubArrayDC([-2, 1, -3, 4, -1, 2, 1, -5, 4]), maxSubArrayDC([-3, -1, -2])]` → `[6, -1]`

   function maxSubArrayLongest(a) {
     let cur = a[0], best = a[0], len = 1, bestLen = 1;
     for (let i = 1; i < a.length; i++) {
       if (a[i] > cur + a[i]) {
         cur = a[i];
         len = 1;
       } else {
         cur += a[i];
         len++;
       }
       if (cur > best || (cur === best && len > bestLen)) {
         best = cur;
         bestLen = len;
       }
     }
     return bestLen;
   }
