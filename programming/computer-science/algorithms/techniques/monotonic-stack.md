# Monotonic Stack — монотонний стек

Монотонний стек — звичайний стек, у якому елементи завжди впорядковані (за зростанням або за спаданням) завдяки правилу: **перед додаванням нового елемента викидаємо з вершини все, що порушує порядок**. Цей простий прийом розв'язує за `O(n)` цілий клас задач «найближчий більший/менший елемент ліворуч чи праворуч» — які наївно коштують `O(n²)`. Це один із найкорисніших шаблонів інтерв'ю.

## 1. Задача: наступний більший елемент

Для кожного `a[i]` знайти найближчий елемент **праворуч**, більший за нього. Наприклад, `a = [2, 1, 2, 4, 3]` → `[4, 2, 4, -1, -1]`.

Наївно: для кожного `i` шукати вправо — `O(n²)`.

Ідея стека: проходимо масив зліва направо й тримаємо в стеку **індекси елементів, для яких наступний більший ще не знайдено**. Нехай прийшов `a[i]`. Усі елементи на вершині стека, які **менші** за `a[i]`, щойно знайшли свій наступний більший — це `a[i]`! Видаляємо їх зі стека й записуємо відповідь. Потім додаємо `i`.

Інваріант: значення в стеку (від дна до вершини) **не зростають** (монотонно спадають). Якби нове число було більше за вершину, вершину було б знято. Тому стек залишається впорядкованим.

Трасування для `[2, 1, 2, 4, 3]`:

- i=0, a[i]=2, нічого не знято, стек значень: [2]
- i=1, a[i]=1, нічого не знято, стек значень: [2, 1]
- i=2, a[i]=2, знято: a[1]=1 → 2, стек значень: [2, 2]
- i=3, a[i]=4, знято: a[2]=2 → 4; a[0]=2 → 4, стек значень: [4]
- i=4, a[i]=3, нічого не знято, стек значень: [4, 3]

Результат: `nextGreater([2, 1, 2, 4, 3])` = `[4, 2, 4, -1, -1]`.

## 2. Чому це `O(n)`

Кожен індекс **додається** у стек рівно один раз і **видаляється** не більше одного разу. Внутрішній цикл `while` у сумі виконується не більше `n` разів за весь прохід — амортизований аналіз (як у [ковзному вікні](sliding-window.md)). Разом `O(n)` часу, `O(n)` пам'яті у гіршому випадку (спадний масив).

## 3. Чотири варіанти (запам'ятайте матрицю)

| Шукаємо | Напрям обходу | Стек тримає | Виймаємо, коли |
|---|---|---|---|
| Наступний **більший** праворуч | зліва направо | спадні значення | `a[i] > a[top]` |
| Наступний **менший** праворуч | зліва направо | зростаючі значення | `a[i] < a[top]` |
| Попередній більший ліворуч | зліва направо | спадні | `a[top] <= a[i]` (після виймання вершина — відповідь) |
| Попередній менший ліворуч | зліва направо | зростаючі | `a[top] >= a[i]` |

`nextSmaller([4, 8, 5, 2, 25])` = `[2, 5, 2, -1, -1]`; `previousGreater([10, 4, 2, 20, 40, 12, 30])` = `[-1, 10, 4, -1, -1, 40, 40]`.

## 4. Класичні задачі

### 4.1. Щоденні температури

Скільки днів чекати теплішої погоди: `dailyTemperatures([73, 74, 75, 71, 69, 72, 76, 73])` = `[1, 1, 4, 2, 1, 1, 0, 0]`. Те саме, що наступний більший, але відповідь — відстань між індексами.

### 4.2. Найбільший прямокутник у гістограмі

Для стовпчика `h[i]` найбільший прямокутник висоти `h[i]` простягається вліво й вправо, поки сусіди **не нижчі**. Межі — це «попередній менший» і «наступний менший». Стек зростаючих висот знаходить обидві межі за один прохід: коли новий стовпчик нижчий за вершину, вершина має праву межу в `i` й ліву — за елементом під нею у стеку. `largestRectangle([2, 1, 5, 6, 2, 3])` = `10` (прямокутник `5, 6` висоти 5 і ширини 2 → 10). Максимальний прямокутник із одиниць у бінарній матриці зводиться до цього по рядках.

### 4.3. Захоплена дощова вода

Стек спадних висот: коли приходить вищий стовпчик, «яма» між ним і лівою стінкою заповнюється: `trapStack([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])` = `6` (те саме, що й [два вказівники](two-pointers.md)).

### 4.4. Видалення `k` цифр, щоб число було найменшим

Жадібно: якщо поточна цифра менша за вершину стека — вершина робить число більшим, тому видаляємо її (поки є ліміт). `removeKDigits('1432219', 3)` = `'1219'`, `removeKDigits('10200', 1)` = `'200'`.

### 4.5. Сума мінімумів усіх підмасивів

Для кожного `a[i]` рахуємо, у скількох підмасивах він мінімум: `(i − left) · (right − i)`, де `left` — попередній менший, `right` — наступний менший (із розв'язанням рівних: з одного боку нестрого). `sumSubarrayMins([3, 1, 2, 4])` = `17`.

### 4.6. Максимум у ковзному вікні (монотонна черга)

Монотонний **deque**: стек, у якому елементи видаляються ще й з початку, коли виходять із вікна: `maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3)` = `[3, 3, 5, 5, 6, 7]`.

### 4.7. Зірчасте сусідство: «видимі люди в черзі», «зіткнення астероїдів», «дужки»

Зіткнення астероїдів: `asteroidCollision([5, 10, -5])` = `[5, 10]`, `asteroidCollision([8, -8])` = `[]`, `asteroidCollision([10, 2, -5])` = `[10]`.

## 5. Реалізація

```js
function nextGreater(a) {
  const res = new Array(a.length).fill(-1);
  const st = [];
  for (let i = 0; i < a.length; i++) {
    while (st.length && a[st[st.length - 1]] < a[i]) res[st.pop()] = a[i];
    st.push(i);
  }
  return res;
}

function nextGreaterTrace(a) {
  const out = [];
  const res = new Array(a.length).fill(-1);
  const st = [];
  for (let i = 0; i < a.length; i++) {
    const popped = [];
    while (st.length && a[st[st.length - 1]] < a[i]) {
      const j = st.pop();
      res[j] = a[i];
      popped.push('a[' + j + ']=' + a[j] + ' → ' + a[i]);
    }
    st.push(i);
    out.push('i=' + i + ', a[i]=' + a[i] + (popped.length ? ', знято: ' + popped.join('; ') : ', нічого не знято') + ', стек значень: [' + st.map((j) => a[j]).join(', ') + ']');
  }
  return out;
}

function nextSmaller(a) {
  const res = new Array(a.length).fill(-1);
  const st = [];
  for (let i = 0; i < a.length; i++) {
    while (st.length && a[st[st.length - 1]] > a[i]) res[st.pop()] = a[i];
    st.push(i);
  }
  return res;
}

function previousGreater(a) {
  const res = new Array(a.length).fill(-1);
  const st = [];
  for (let i = 0; i < a.length; i++) {
    while (st.length && a[st[st.length - 1]] <= a[i]) st.pop();
    res[i] = st.length ? a[st[st.length - 1]] : -1;
    st.push(i);
  }
  return res;
}

function dailyTemperatures(t) {
  const res = new Array(t.length).fill(0);
  const st = [];
  for (let i = 0; i < t.length; i++) {
    while (st.length && t[st[st.length - 1]] < t[i]) {
      const j = st.pop();
      res[j] = i - j;
    }
    st.push(i);
  }
  return res;
}

function largestRectangle(h) {
  const st = [];
  let best = 0;
  for (let i = 0; i <= h.length; i++) {
    const cur = i === h.length ? 0 : h[i];
    while (st.length && h[st[st.length - 1]] > cur) {
      const height = h[st.pop()];
      const left = st.length ? st[st.length - 1] : -1;
      best = Math.max(best, height * (i - left - 1));
    }
    st.push(i);
  }
  return best;
}

function trapStack(h) {
  const st = [];
  let water = 0;
  for (let i = 0; i < h.length; i++) {
    while (st.length && h[st[st.length - 1]] < h[i]) {
      const bottom = h[st.pop()];
      if (!st.length) break;
      const left = st[st.length - 1];
      water += (Math.min(h[left], h[i]) - bottom) * (i - left - 1);
    }
    st.push(i);
  }
  return water;
}

function removeKDigits(num, k) {
  const st = [];
  for (const d of num) {
    while (k > 0 && st.length && st[st.length - 1] > d) { st.pop(); k--; }
    st.push(d);
  }
  while (k > 0) { st.pop(); k--; }
  const s = st.join('').replace(/^0+/, '');
  return s === '' ? '0' : s;
}

function sumSubarrayMins(a) {
  const n = a.length;
  const left = new Array(n);
  const right = new Array(n);
  let st = [];
  for (let i = 0; i < n; i++) {
    while (st.length && a[st[st.length - 1]] > a[i]) st.pop();
    left[i] = st.length ? i - st[st.length - 1] : i + 1;
    st.push(i);
  }
  st = [];
  for (let i = n - 1; i >= 0; i--) {
    while (st.length && a[st[st.length - 1]] >= a[i]) st.pop();
    right[i] = st.length ? st[st.length - 1] - i : n - i;
    st.push(i);
  }
  let sum = 0;
  for (let i = 0; i < n; i++) sum += a[i] * left[i] * right[i];
  return sum;
}

function maxSlidingWindow(a, k) {
  const dq = [];
  const out = [];
  for (let i = 0; i < a.length; i++) {
    if (dq.length && dq[0] <= i - k) dq.shift();
    while (dq.length && a[dq[dq.length - 1]] <= a[i]) dq.pop();
    dq.push(i);
    if (i >= k - 1) out.push(a[dq[0]]);
  }
  return out;
}

function asteroidCollision(a) {
  const st = [];
  for (const x of a) {
    let alive = true;
    while (alive && x < 0 && st.length && st[st.length - 1] > 0) {
      const top = st[st.length - 1];
      if (top < -x) st.pop();
      else if (top === -x) { st.pop(); alive = false; }
      else alive = false;
    }
    if (alive) st.push(x);
  }
  return st;
}

function nextGreaterCircular(a) {
  const n = a.length;
  const res = new Array(n).fill(-1);
  const st = [];
  for (let i = 0; i < 2 * n; i++) {
    const x = a[i % n];
    while (st.length && a[st[st.length - 1]] < x) res[st.pop()] = x;
    if (i < n) st.push(i);
  }
  return res;
}

function stockSpan(prices) {
  const res = [];
  const st = [];
  for (let i = 0; i < prices.length; i++) {
    while (st.length && prices[st[st.length - 1]] <= prices[i]) st.pop();
    res.push(st.length ? i - st[st.length - 1] : i + 1);
    st.push(i);
  }
  return res;
}
```

## 6. Складність

- **Час `O(n)`** (амортизовано), **пам'ять `O(n)`**.
- Гістограма: один прохід із «сторожем» `h[n] = 0`, щоб звільнити стек наприкінці.
- Чому не `O(n²)`: кожен елемент потрапляє в стек і виходить зі стека лише один раз.

## 7. Як розпізнати монотонний стек

- У задачі фігурують слова «**найближчий** більший/менший», «скільки днів/кроків до…», «**видимість**», «**діапазон** впливу елемента».
- Відповідь для `i` залежить від **найближчого сусіда**, який перевершує `a[i]`.
- Потрібно підрахувати внесок кожного елемента як мінімуму/максимуму у підмасивах.
- Складні жадібні задачі на рядках/числах: «видалити, щоб результат був мінімальним/максимальним лексикографічно» (`removeKDigits`, «Remove Duplicate Letters»).

## 8. Типові помилки

1. **Порядок «спочатку знімаємо, потім додаємо»** — інакше нове значення порівнюється з самим собою.
2. **Строгість нерівності:** `<` чи `<=` визначає, як обробляються **рівні** елементи. У `sumSubarrayMins` нерівності з двох боків мають відрізнятися, інакше підмасиви з рівними мінімумами порахуються двічі.
3. **Зберігати значення замість індексів**, коли потрібні відстані — бракує позицій.
4. **Забути «сторожа»** у гістограмі: стек лишається непорожнім після циклу.
5. **Порожній стек:** звернення до `st[st.length − 1]` без перевірки.
6. **Колові масиви:** обхід `2n` без повторного додавання в стек.
7. **Плутанина напряму:** шукаємо ліворуч — обхід зліва, праворуч — або обхід справа наліво, або «виймання» при приході більшого.
8. **Використання `shift()` для черги:** `O(n)` на операцію; для великих масивів — індекс-вказівник голови.

## 9. Алгоритм-шаблон

1. Створити порожній стек (індексів).
2. Для кожного `i`: поки стек не порожній і `a[вершина]` порушує порядок відносно `a[i]` — зняти вершину й **зафіксувати для неї відповідь** (використовуючи `i`).
3. Покласти `i` у стек.
4. Після циклу залишки стека не мають відповіді (`−1`/кінець масиву).
5. Час `O(n)`, пам'ять `O(n)`.

   ```js
   function nextGreaterIndex(a) {

     const st = [];

   }
   ```

   ```js
   function minStack() {
     const s = [], m = [];
     return { push(x) {
       s.push(x);
       m.push(m.length ? Math.min(x, m[m.length - 1]) : x);
     }, pop() {
       m.pop();
       return s.pop();
     }, top: () => s[s.length - 1], getMin: () => m[m.length - 1] };
   }
   ```

   ```js
   function evalRPN(t) {
     const st = [];
     for (const x of t) {
       if (['+', '-', '*', '/'].includes(x)) {
         const b = st.pop(), a = st.pop();
         st.push(x === '+' ? a + b : x === '-' ? a - b : x === '*' ? a * b : Math.trunc(a / b));
       } else st.push(Number(x));
     }
     return st[0];
   }
   ```

40. Приклад розв'язку:

   ```js
   function decodeString(s) {
     const st = [];
     let cur = '', num = 0;
     for (const c of s) {
       if (/\d/.test(c)) num = num * 10 + Number(c);
       else if (c === '[') {
         st.push([cur, num]);
         cur = '';
         num = 0;
       } else if (c === ']') {

         cur = prev + cur.repeat(k);

     }
     return cur;
   }
   ```
